title: "Fumadocs"

Fumadocs turns `content/docs` and `content/blog` into localized page trees. `bun run content` runs `fumadocs-mdx` and writes `.source/`; `dev`, `typegen` and every build script run it first.

| File                 | Purpose                                                                                                                            |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `fumadocs.config.ts` | The `docs` collection, the `blog` collection with its frontmatter schema, and the code highlighting themes and colour replacements |
| `fumadocs.i18n.ts`   | The locales from `I18N`, `en-US` as default and fallback, the `dot` parser for `<slug>.<locale>.mdx`, hidden locale prefix         |
| `fumadocs.source.ts` | `source` at `/docs` with the Lucide icons plugin, `blogSource` at `/blog`, `getPublishedBlogPosts` with reading time               |
| `fumadocs.docs.ts`   | `getDocsPage` server function, `loadDocsPage` and `docsHead` for the `docs.$` route                                                |
| `fumadocs.search.ts` | The search index served by `/api/search`                                                                                           |

The locale prefix is hidden in Fumadocs URLs because the router adds it. Blog frontmatter requires `title`, `authorName` and `date` and accepts `description`, `excerpt`, `faq`, `featured`, `image`, `published`, `tags`, `updated` and `authorImage`.

## Components

`src/presentation/components/custom/mdx.tsx` maps the MDX components: the Fumadocs defaults (including `Cards` and `Callout`), `Accordions`, `Steps` and `Tabs`, and the shadcn `Alert`, `Badge`, `Button`, card parts, `Separator` and `Table`; `RepositoryFact`, which prints a value measured from the repository at build time or defined in the code, as in `<RepositoryFact name="testFiles" />`, and `RepositoryTable`, which prints a table built from the code, as in `<RepositoryTable name="commitTypes" columns={["Type", "Emoji"]} />`. `TierPrice` prints a tier's list price from `TIER_PRICES` in the page locale, as in `<TierPrice tier="core" />`, so no page types a price. `ActivationLimit` prints a tier's activation limit from `LICENSE_ACTIVATION_LIMITS`, as in `<ActivationLimit tier="core" />`, and `RegionalDiscounts` lists the regional discount percentages derived from `PPP_TIERS`. Internal links are localized with `localizePathname`, and a task list item wraps its checkbox and text in a `label`. `docs-content.tsx` and `blog-content.tsx` render the pages.

`@fumadocs/base-ui` is pinned to 16.19.0 with a Bun patch: its `CodeBlock` gave every code block's scroll area the `region` role without a name, so a page with two code blocks had duplicate unnamed landmarks. With the patch, the scroll area is a region named by the block's title when there is one, and stays focusable without a role otherwise. See [Dependencies](/docs/conventions/dependencies).

## Content rules

Every page exists once per locale as `<slug>.<locale>.mdx`, and each folder has a `meta.<locale>.json` with the same `pages` array in every locale. `icon` in a meta file takes a Lucide icon name. `scripts/check-content.ts`, part of `bun run check:i18n`, fails when a translation is missing, a code block differs, the navigation differs or an English paragraph remains in another locale.
