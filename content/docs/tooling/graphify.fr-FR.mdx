---
title: "Graphify"
description: "Un graphe de connaissances facultatif de la base de code pour les agents."
---

Graphify est une skill externe et facultative pour agents qui transforme un dossier en graphe de connaissances. Ce n'est pas une dépendance du projet, et `.gitignore` exclut son dossier de sortie `graphify-out/`.

Une fois la skill installée dans votre agent :

- `/graphify .` construit le graphe du dépôt.
- `/graphify . --update` ne réextrait que les fichiers nouveaux ou modifiés.
- `/graphify query "<question>"` répond à une question à partir du graphe.

Lisez `graphify-out/GRAPH_REPORT.md` pour les questions générales sur la structure, puis vérifiez les détails dans le code. Le graphe est un instantané : après des modifications importantes, mettez-le à jour avant de vous y fier.
