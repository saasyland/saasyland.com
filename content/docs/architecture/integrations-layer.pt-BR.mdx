## O que não é uma integração

- A contagem de estrelas do GitHub é uma server function em `src/lib/github.ts`, com cache no KV.
- O rate limiting fica em `src/lib/rate-limit.ts`, apoiado na tabela `rate_limit`.
- Os bindings do Cloudflare não precisam de adaptador. O código de servidor os lê de `env` em `cloudflare:workers`.

## A lógica de negócio fica nos módulos

Uma integração configura um fornecedor. As decisões sobre os dados da aplicação pertencem ao módulo dono da tabela:

- O plugin da Polar, um dos `plugins` de `src/integrations/better-auth/auth.server.ts`, verifica as assinaturas dos webhooks com `POLAR_WEBHOOK_SECRET` e repassa cada evento para `handlePolarEvent`, em `src/integrations/polar/polar.webhooks.ts`. Essa função o repassa a cada elemento de `POLAR_EVENT_HANDLERS` que lista o evento; o elemento da licença chama `licenseWebhookHandlers`, em `src/modules/license/license.webhooks.ts`, que chamam os casos de uso de licença, e os elementos dos pedidos e das assinaturas chamam `recordOrder` e `recordSubscription`. Os IDs dos produtos dos planos de licença, `POLAR_PRODUCT_IDS`, também pertencem à funcionalidade de licenças, em `src/modules/license/license.utils.ts`.
- Os hooks de e-mail do Better Auth chamam diretamente `sendVerifyEmail`, `sendExistingAccountEmail`, `sendResetPasswordEmail`, `sendPasswordChangedEmail`, `sendDeleteAccountEmail` e `sendChangeEmailConfirmationEmail`, dos módulos de verificação, de conta e de usuário.
- Um caso de uso envia um e-mail no locale que o chamador repassa (o e-mail de verificação o lê da URL de callback): ele carrega o namespace do template, renderiza o template e chama `sendEmail`:

```ts
const messages = await loadNamespace<typeof verifyEmailMessages>({ locale, namespace: VERIFY_EMAIL_NAMESPACE })
await sendEmail({
  idempotency: { purpose: VERIFICATION_EMAIL_PURPOSE.VERIFY_EMAIL, token: crypto.randomUUID() },
  react: createElement(VerifyEmail, { locale, messages, name: user.name, verifyUrl: verifyUrl.toString() }),
  subject: createTranslator({ locale, messages })("subject"),
  to: user.email,
})
```
