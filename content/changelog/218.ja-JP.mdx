- 修正: ランディングページの CLI コンフィギュレーターのすべてのオプションが、最初の1回の押下で反応するようになりました。押したときに縮むコントロールはなくなり（コピーボタンも含む）、オプションの端の近くを押しても外れません。また回答によって周囲のオプションが動くこともなくなりました。選択したオプションは文字の太さではなく色が変わり、各質問はすべてのオプションを常に表示し、コンフィギュレーターは浮き上がらずにフェードインします。各質問はラジオグループ、追加機能はトグルグループで、どちらも shadcn の `ToggleGroup` です。矢印キーで質問内を移動し、Space または Enter で回答し、Tab で次の質問へ進みます。それより前の回答で除外されたオプションは無効のままその場に残り、質問の下の注記がその理由をキーボード、タッチ、スクリーンリーダーの利用者に等しく伝えます。以前はツールチップがマウスにしか示していませんでした。[CLI コンフィギュレーター](/docs/features/landing-page#cli-configurator)と[アクセシビリティ](/docs/conventions/accessibility)を参照してください。
- 変更: CLI コンフィギュレーターは専用の `Suspense` 境界でハイドレーションされるため、40 個の React Aria ボタンがあってもデスクトップの Total Blocking Time は変わりません。現在はすべて低優先度になった TanStack Start のプリロードヒントを残す案も測り直しました。ページのハイドレーションは早まりますが First Contentful Paint が遅れるため、引き続き削除します。[パフォーマンス](/docs/conventions/performance)を参照してください。
