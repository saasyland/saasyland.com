Tutti i file e le cartelle usano il kebab-case.

## File sorgente

| Pattern                                                      | Significato                                                                                                                            |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | Route basata su file; i punti sono segmenti del percorso, `_` indica un layout senza percorso, `$` uno splat, `index` una route indice |
| `src/routes/api/<name>.ts`                                   | Handler HTTP                                                                                                                           |
| `modules/<table>/<table>.schema.ts`                          | Tabella Drizzle                                                                                                                        |
| `modules/<table>/<table>.zod.ts`                             | Schemi Zod                                                                                                                             |
| `modules/<table>/<table>.constants.ts`                       | Chiavi di query, chiavi di mutazione ed enum                                                                                           |
| `modules/<table>/<table>.types.ts`                           | Tipi derivati dalla tabella                                                                                                            |
| `modules/<table>/<table>.utils.ts`                           | Helper puri per la tabella                                                                                                             |
| `modules/<table>/<table>.server.ts`                          | Helper solo server per il modulo                                                                                                       |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | Un caso d'uso                                                                                                                          |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | Configurazione o adapter del fornitore, ad esempio `auth.server.ts`                                                                    |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | Colonne della tabella dati                                                                                                             |
| `presentation/emails/<name>.tsx`                             | Template email che esporta `<NAME>_NAMESPACE`                                                                                          |
| `hooks/use-<name>.ts`                                        | Hook React condiviso                                                                                                                   |
| `providers/<name>-provider.tsx`                              | Provider dell'applicazione                                                                                                             |

## Test

| Pattern                               | Runner                        |
| ------------------------------------- | ----------------------------- |
| `__test__/<file>.test.ts`             | Progetto Vitest `node`        |
| `__test__/<file>.integration.test.ts` | Progetto Vitest `integration` |
| `__test__/<file>.component.test.tsx`  | Progetto Vitest `component`   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                    |

I file di test prendono il nome dal file sorgente che coprono, ad esempio `user.schema.test.ts` per `user.schema.ts`.

## Contenuti e messaggi

| Pattern                                   | Significato                                                  |
| ----------------------------------------- | ------------------------------------------------------------ |
| `messages/<locale>/<namespace>.json`      | Namespace di traduzione, ad esempio `pages.admin.users.json` |
| `content/docs/<path>/<page>.<locale>.mdx` | Pagina della documentazione                                  |
| `content/docs/<path>/meta.<locale>.json`  | Navigazione della documentazione                             |
| `content/blog/<slug>.<locale>.mdx`        | Articolo del blog                                            |
