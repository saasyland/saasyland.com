The `saasyland` CLI, `create-saasyland` and `@saasyland/stack` are released together under one version, and each prerelease below was published on npm's `beta` tag. The [CLI guide](/docs/cli) describes the current release, and the [changelog](/docs/project/changelog) lists the changes to this website.

## 0.1.0-beta.1

### saasyland

- `saasyland activate` activates your licence key on this machine: pass the key as an argument or in <RepositoryFact name="cliLicenseKeyVariable" />, or type it when asked, hidden as you type. `saasyland whoami` shows your tier, the slots in use and this machine's name, and `saasyland deactivate` frees this machine's slot.
- The licence is kept in a file only your user can read in your config directory, every run of one CI repository shares one activation, and a licence that was refunded or revoked is removed from the machine.
- Each of the three prints its result as one JSON document with `--json`, and they no longer accept `--cwd` and `--dry-run`, which never applied to them.

### create-saasyland

No changes in this release.

### @saasyland/stack

- `@saasyland/stack/api` caps a CLI version and a release at `API_LIMIT.VERSION_MAX_LENGTH` characters, so the licence API answers a longer one with `invalidRequest` like any other malformed field.

## 0.1.0-beta.0

### saasyland

- First preview of the `saasyland` CLI. `saasyland --help` lists every command, and `saasyland init --help` lists every stack choice as a flag.
- Flags are checked before anything runs: an unknown value or a combination that cannot work, such as `--provider neon` without `--db postgres`, is refused with the reason and exit code <RepositoryFact name="cliExitUsage" />.
- Output is available in English, German, Spanish, French, Italian, Japanese, Polish, Brazilian Portuguese and Ukrainian, chosen with `--locale` or from your system language, and `--json` prints one JSON document for scripts and coding agents.
- Generating a project and activating a licence arrive in the next previews; until then those commands say so and exit with code <RepositoryFact name="cliExitNotAvailable" />.

### create-saasyland

- First preview of `create-saasyland`: `npm create saasyland`, `bun create saasyland`, `pnpm create saasyland` and `yarn create saasyland` run `saasyland init` with the same flags.

### @saasyland/stack

- New entry point: `@saasyland/stack/api`, the contract of the saasyland.com licence API that the `saasyland` CLI calls. It defines the <RepositoryFact name="cliApiBasePath" /> routes, headers, request and response schemas, error codes and limits, and builds and reads every request and response. Importing `@saasyland/stack` alone loads none of it.
