## リンクの請求

`/auth/forgot-password` は `ForgotPasswordForm` を表示します。フォームは `requestPasswordReset`（`src/modules/verification/use-cases/request-password-reset.ts`、`RATE_LIMITS.SENSITIVE` で制限）を、現在の言語の `/auth/reset-password` を指す `redirectTo` 付きで呼び出します。続いて Better Auth が `sendResetPasswordEmail` を呼び出し、`ResetPasswordEmail` テンプレートを送信します。

## 新しいパスワードの設定

メールのリンクは `/auth/reset-password?token=…` を開きます。トークンがない場合や `?error=` がある場合、ページは無効なリンクのメッセージと `/auth/forgot-password` へ戻るリンクを表示します。トークンがあれば `ResetPasswordForm` が `resetPassword`（`RATE_LIMITS.TOKEN` で制限）を呼び出し、`/auth/sign-in` へ移動します。`revokeSessionsOnPasswordReset` が有効なため、そのユーザーの既存セッションはすべて終了します。

## その他のパスワード変更

- サインイン済みのユーザーは **設定 → セキュリティ** でパスワードを変更します（[設定](/docs/features/settings)）。
- 管理者はユーザーテーブルから他のユーザーのパスワードを設定します（[ユーザー（管理）](/docs/features/users-admin)）。
