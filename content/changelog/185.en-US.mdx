- The browser no longer downloads Drizzle. Each `<table>.zod.ts` built `insert`, `select` and `update` schemas from its table with `drizzle-zod`, which only tests read, and several enum tuples lived in the `.schema.ts` files, so the forms, the query options and the `/admin` and `/app` pending skeletons brought the tables, `drizzle-orm` and, through `drizzle-zod`, every zod locale to every page. Every enum tuple, `TIMEZONE_CODES` and `LICENSE_STATUSES` included, now sits in its module's `<table>.constants.ts`, the derived schemas and the `drizzle-zod` dependency are gone, and each page loads about 75 KiB less gzipped JavaScript: the landing page went from 526.2 KiB to 450.7 KiB. TanStack Start's import protection denies `drizzle-orm` in the client build, so an import that would bring it back fails the build and prints its import chain. See [Keep the ORM out of the browser](/docs/conventions/performance#keep-the-orm-out-of-the-browser).
