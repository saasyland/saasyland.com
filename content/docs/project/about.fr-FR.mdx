---

SaaSy Land 2.0 est le code source du site saasyland.com, de son espace client et de sa console d'administration. Une seule application TanStack Start sur Cloudflare Workers réunit un site marketing multilingue, une documentation et un blog, l'authentification, les abonnements à la newsletter, la diffusion de vidéos et les cours, et le paiement Polar avec gestion des clés de licence.

Le code est écrit comme un vrai produit : un module par table de base de données, des fonctions serveur typées avec leur propre autorisation, un espace de noms de traduction par page, une couverture de code à <RepositoryFact name="coverageThreshold" unit="percent" /> et des tests dans le navigateur de ses parcours utilisateur et administrateur en CI. Il s'adresse aux développeurs qui souhaitent étudier ou réutiliser une mise en place de production de l'authentification, de l'administration, de l'internationalisation et de l'infrastructure Cloudflare.

Les utilisateurs, les sessions, les vidéos, les cours, la progression des leçons, les abonnés à la newsletter, les licences et les copies des commandes et des abonnements de Polar reposent sur D1, et les fichiers vidéo sur R2, tandis que la page des produits lit le catalogue directement chez Polar. Chaque écran d'administration lit des données réelles : l'administration n'a aucun écran de démonstration, et une règle de lint tient les données de démonstration hors de son code.

La CLI SaaSy Land et ses modèles de génération privés constituent un produit propriétaire distinct et ne font pas partie de cette base de code. Voir [Licence](/docs/project/license).
