| パス                                                    | 内容                                                                                                                                                                                                               |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/presentation/components/shadcn/`                   | 生成された shadcn プリミティブ（React Aria 版）                                                                                                                                                                    |
| `src/presentation/components/custom/`                   | アプリのコンポーネント。フラットに置かれた共有ファイル（`footer.tsx`、`navigation.tsx`、`data-table.tsx`、`locale-switcher.tsx` など）と、領域ごとのフォルダー `admin/`、`app/`、`auth/`、`blog/`、`landing-page/` |
| `src/presentation/styles/`                              | `globals.css`（Tailwind、トークン、タイプスケール）、`fonts.css`、`docs.css`、`typeset.css`                                                                                                                        |
| `src/presentation/theme/`、`src/presentation/branding/` | テーマとブランドの定数                                                                                                                                                                                             |
| `src/presentation/document-assets.ts`                   | グローバルスタイルシートとフォントのプリロード                                                                                                                                                                     |
| `src/providers/`                                        | `AriaProvider`、`ThemeProvider`、`TranslationsProvider`、`MotionProvider`                                                                                                                                          |
