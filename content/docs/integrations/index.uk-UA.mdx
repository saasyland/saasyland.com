---
title: "Вступ"
description: "Адаптери постачальників у src/integrations."
---

Кожна папка в `src/integrations/<vendor>/` обгортає одного постачальника у файли `<prefix>.<concern>.ts`, де префікс — коротка назва постачальника (`auth`, `drizzle`, `i18n`, `form`): конфігурацію, клієнти й тонкі адаптери. Бізнес-правила та операції з базою даних залишаються в `src/modules`, а компоненти ніколи не імпортують клієнт постачальника напряму.

| Папка            | Файли                                                                                                                                                                           | Призначення                                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `affonso`        | `affonso.constants.ts`, `affonso.program.ts`, `affonso.referral.ts`                                                                                                             | Параметри партнерських рекомендацій, ID програми та метадані оформлення замовлення                                                             |
| `better-auth`    | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.roles.ts`, `auth.session.ts`                                                | Сесії, OAuth, плагіни, гарди маршрутів, middleware серверних функцій, ролі та дозволи                                                          |
| `drizzle-orm`    | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `drizzle.local.config.ts`, `drizzle.errors.ts`, `drizzle.columns.ts`, `drizzle.time-series.ts`, `migrations/` | Клієнт D1, barrel-файл схем, конфігурація drizzle-kit, `rethrowAsConflict`, `timestamps()`, `bucketOf`                                         |
| `fumadocs`       | `fumadocs.config.ts`, `fumadocs.schema.ts`, `fumadocs.i18n.ts`, `fumadocs.indexes.ts`, `fumadocs.docs.ts`, `fumadocs.blog.ts`, `fumadocs.changelog.ts`, `fumadocs.icons.ts`     | Колекції документації та блогу, індекси, зібрані під час збірки, пошук, записи changelog та іконки бічної панелі                               |
| `motion`         | `motion.features.ts`, `motion.tokens.ts`                                                                                                                                        | Ліниво завантажувані можливості Motion і спільні переходи                                                                                      |
| `polar`          | `polar.config.ts`, `polar.constants.ts`, `polar.customers.ts`, `polar.webhooks.ts`, `polar.vite.ts`                                                                             | Клієнт Polar SDK, власні значення Polar, облікові записи клієнтів, код, до якого потрапляє кожна подія вебхука, і налаштування збірки для SDK  |
| `resend`         | `resend.config.ts`, `resend.utils.ts`                                                                                                                                           | Клієнт Resend, `sendEmail` і `EMAIL_PURPOSE`                                                                                                   |
| `takumi`         | `takumi.fonts.ts`, `takumi.render.tsx`                                                                                                                                          | Рендерить соціальні картки й логотип організації під час збірки шрифтами самого сайту                                                          |
| `tanstack-form`  | `form.fields.ts`, `form.submit.ts`                                                                                                                                              | `fieldErrorMessage` для помилок полів форми, а також `submitForm` і `showFieldError`, які позначають недійсне поле й переводять на нього фокус |
| `tanstack-query` | `query.cache.ts`                                                                                                                                                                | Типовий час кешування `QueryClient` для кожного запиту                                                                                         |
| `use-intl`       | `i18n.config.ts`, `i18n.loaders.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                                                                 | Локалі, простори імен повідомлень, middleware локалі, помічники URL                                                                            |
| `zod`            | `zod.config.ts`                                                                                                                                                                 | Запускає Zod у браузері в режимі `jitless`, тож під Content Security Policy він ніколи не пробує `eval`                                        |
