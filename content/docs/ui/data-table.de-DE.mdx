## Fähigkeiten.

- Spaltengrößenanpassung / Fixierungshilfen
- Werkzeugleiste: Suche, Filter, Einstellungen (Darstellung), CSV-Export, asynchrone Datenabfrage/Aktualisierung.
- Auswahlbereich für Spaltenaktionen und Zeilenaktionen.
- Seitennavigation

## Testen.

Komponententests befinden sich unter `data-table/__test__`. Achten Sie auf eine vollständige Abdeckung, wenn Sie die Status der Symbolleiste ändern.
