## Propriété

`integrations/better-auth` — `auth.server.ts`, `auth.client.ts`, validations, erreurs, gardes.

## Capacités

- Courriel/mot de passe
- GitHub + Google OAuth
- Cookies de session via Better Auth
- Protection renforcée par le proxy pour `/admin` et `/app`

## Élargir

Ajouter des fournisseurs sociaux dans la configuration du serveur auth; garder des secrets dans env; mettre à jour les documents + `.env.example`.
