## Ownership

`integrations/better-auth` — `auth.server.ts`, `auth.client.ts`, validations, errors, guards.

## Capabilities

- Email/password
- GitHub + Google OAuth
- Session cookies via Better Auth
- Proxy-enforced protection for `/admin` and `/app`

## Extend

Add social providers in auth server config; keep secrets in env; update docs + `.env.example`.
