## Désignation

- Cas d'utilisation: `verb-noun.ts`
- Essais: colocalisés `__test__`
- Routes privées: `_components`, `_lib`

## Marchandises

Les commits conventionnels (`feat`, `fix`, `refactor`, ...) avec préfixe emoji via `scripts/commit-msg.ts`.

## PR

Plomb avec type orienté vers l'utilisateur (`feat` lorsque le comportement change). Remarquez les refacteurs dans le corps.
