- Футер посилається на профіль в Instagram, `APP_INSTAGRAM_URL`, поруч із репозиторієм на GitHub і відкриває його в новій вкладці, як і посилання на GitHub. Головна сторінка описує організацію в JSON-LD, як Google радить для головної сторінки: `Organization` з назвою, URL, контактною адресою і, в `sameAs`, профілями на GitHub та в Instagram; дописи блогу називають ту саму організацію своїм `publisher`. `sameAs` називає організацію на GitHub, `APP_GITHUB_OWNER_URL`, з якої тепер виводиться `APP_GITHUB_URL`, бо репозиторій — не профіль.
