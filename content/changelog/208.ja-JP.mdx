- 変更: CLI ライセンス API へのバンドルのリクエストは、R2 にあるリリースのアーカイブそのものではなく、そのヘッドを読み取るようになりました。アーカイブの SHA-256 は、CLI リポジトリの `bundle:upload` が書き込むカスタムメタデータ `sha256` としてアーカイブと一緒に保存されるため、Worker はリクエストのたびにバンドル全体をダウンロード、展開、ハッシュ化しなくなりました。現在の 1.7 MB のバンドルでは、ローカルのテスト Worker で 1 リクエストあたり約 31 ms かかっていた CPU 時間が約 3 ms になり、バンドルがどれだけ大きくなっても変わりません。ダイジェストのないオブジェクトには `serviceUnavailable` を返し、ログにそのオブジェクトを記録します。`wrangler r2 object put` ではカスタムメタデータを設定できないため、`bun run db:reset:test` は Wrangler の `getPlatformProxy` でローカルのバンドルとそのダイジェストを投入します。[テンプレートバンドル](/docs/features/cli-licence-api#template-bundles)と[バンドルの公開](/docs/features/cli-licence-api#publishing-bundles)を参照してください。
