---
title: "概要"
description: "src/integrations 配下のベンダーアダプターです。"
---

`src/integrations/<vendor>/` の各フォルダーは、1 つのベンダーを `<vendor>.<concern>.ts` ファイル群でラップします。内容は設定、クライアント、薄いアダプターです。ビジネスルールとデータベース操作は `src/modules` に置き、コンポーネントがベンダーのクライアントを直接インポートすることはありません。

| フォルダー      | ファイル                                                                                                        | 目的                                                                |
| --------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `better-auth`   | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.session.ts` | セッション、OAuth、ルートガード、サーバー関数のミドルウェア、ロール |
| `drizzle-orm`   | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `migrations/`                                 | D1 クライアント、スキーマのバレル、drizzle-kit の設定               |
| `fumadocs`      | `fumadocs.config.ts`, `fumadocs.i18n.ts`, `fumadocs.source.ts`, `fumadocs.docs.ts`, `fumadocs.search.ts`        | ドキュメントとブログのコレクション、ローカライズされたソース、検索  |
| `motion`        | `motion.features.ts`, `motion.tokens.ts`                                                                        | 遅延読み込みされる Motion の機能と共通のトランジション              |
| `polar`         | `polar.config.ts`, `polar.constants.ts`                                                                         | Polar SDK クライアントとチェックアウト用の商品                      |
| `resend`        | `resend.config.ts`, `resend.utils.ts`                                                                           | Resend クライアントと `sendEmail`                                   |
| `tanstack-form` | `form.fields.ts`                                                                                                | フォームフィールドのエラー用の `fieldErrorMessage`                  |
| `use-intl`      | `i18n.config.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                    | ロケール、メッセージの名前空間、ロケールミドルウェア、URL ヘルパー  |
