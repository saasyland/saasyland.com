## Інструменти

| Інструмент | Версія                                           | Навіщо                                                                                            |
| ---------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| Bun        | <RepositoryFact name="bunVersion" />             | Менеджер пакетів і засіб запуску скриптів; версію фіксують `packageManager` у `package.json` і CI |
| Node.js    | <RepositoryFact name="nodeVersion" /> або новіша | Версія з `.nvmrc`, яку читають `nvm use` і CI. Тестова база даних використовує `node:sqlite`      |
| Git        | Будь-яка актуальна версія                        | Крок встановлення налаштовує Git-хуки                                                             |

Wrangler, drizzle-kit, Playwright і Vite+ CLI — це dev-залежності; запускайте їх через скрипти пакета або `bunx`. Для браузерних тестів також потрібні браузери Playwright, які встановлює `bun run test:e2e:install`.

## Облікові записи

Ізольований тестовий preview і всі автоматизовані тести не потребують облікових записів чи облікових даних. Розробка та розгортання використовують справжні сервіси:

- Обліковий запис Cloudflare з D1, KV, R2 і Workers. Dev-сервер підключається до віддалених ресурсів preview.
- OAuth-застосунки GitHub і Google для входу через соціальні мережі.
- Resend з підтвердженим відправником. Реєстрація за електронною поштою вимагає підтвердженої адреси, тож без нього реєстрація не працює.
- Polar (для розробки — пісочниця) з трьома продуктами для тарифів Core, Complete і Agency.
