SaaSy Land est le code source du site saasyland.com, de l'espace client et de la console d'administration : une seule application TanStack Start sur Cloudflare Workers avec D1, KV, Better Auth, Polar, Resend, use-intl et Fumadocs. La CLI SaaSy Land et ses modèles de génération se trouvent dans un dépôt privé distinct.

<Callout title="Comment utiliser cette documentation">
  Commencez par **Prise en main** pour lancer l'application. **Architecture** explique où se trouve le code, **Guides** propose des recettes
  pas à pas, **Fonctionnalités** décrit le comportement du produit et **Intégrations** documente chaque adaptateur de fournisseur sous
  `src/integrations`.
</Callout>

## Modifier la documentation

Les pages se trouvent dans `content/docs` sous la forme `<slug>.<locale>.mdx`, un fichier pour chacune des neuf langues, et chaque dossier liste ses pages dans `meta.<locale>.json`. Toutes les langues listent les mêmes slugs et conservent des blocs de code identiques octet pour octet ; `bun run check:i18n` le vérifie au moyen de `scripts/check-content.ts`. `bun run content` régénère `.source/`, et `dev` ainsi que chaque script de build l'exécutent pour vous.

Les pages MDX peuvent utiliser les composants Fumadocs (`<Cards>`, `<Callout>`, `<Steps>`, `<Tabs>`, `<Accordions>`) et une sélection de primitives shadcn (`<Button>`, `<Badge>`, `<Alert>`, `<Table>`). Les liens internes comme `/docs/tooling/testing` reçoivent automatiquement le préfixe de langue du lecteur.
