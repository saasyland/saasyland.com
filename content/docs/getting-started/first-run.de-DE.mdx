## Isolierte Test-Preview

Die Test-Preview baut die Anwendung für die Umgebung `test`: lokale D1, KV und R2 in `.wrangler/test`, Platzhalter-Zugangsdaten aus `.env.test`, per Seed angelegte Konten und abgefangene Anfragen an Resend und Polar. Sie benötigt keine Konten.

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

Öffne http://127.0.0.1:3000 und melde dich mit einem der Konten an, die `e2e/data/accounts.ts` anlegt. Jedes verwendet das Passwort <RepositoryFact name="testPassword" />. Admins landen auf `/admin`, Kunden auf `/app`, und die lizenzierten Konten und ihre Lizenzen stammen aus `e2e/data/licenses.ts`. Die Complete-Lizenz öffnet jede kostenpflichtige Lektion des Beispielkurses.

<RepositoryTable columns={["E-Mail", "Rolle", "Lizenz"]} name="seededAccounts" />

Die Preview liefert einen Build aus; baue sie daher neu, um Änderungen am Quellcode zu sehen.

## Entwicklung mit Cloudflare

`bun run dev` startet den Dev-Server mit Hot Reload unter http://localhost:3000. Seine Bindings `DB`, `CACHE`, `MEDIA` und `BUNDLES` sind lokal, in `.wrangler/state`, daher liest oder schreibt die Entwicklung nie die Daten von Preview oder Produktion, und sie braucht keine Anmeldung bei Cloudflare.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

1. Fülle `.env.development` wie unter [Umgebungsvariablen](/docs/getting-started/environment-variables) beschrieben aus, mit `POLAR_SERVER=sandbox`.
2. Lege mit `db:reset:local` die lokale Datenbank an und wende die Migrationen an.
3. Befülle sie mit `db:seed:local`: ein Admin, der Lehrplan der Kurse, Lizenzen und eine Bestellung.
4. Starte den Server und melde dich als <RepositoryFact name="localAdminEmail" /> mit `LOCAL_ADMIN_PASSWORD` aus `.env.development` an, oder mit <RepositoryFact name="localAdminPassword" />, wenn es nicht gesetzt ist.

`bun run db:studio:local` öffnet die lokalen Daten in Drizzle Studio. Die Registrierung per E-Mail benötigt eine funktionierende Resend-Konfiguration: Ein neues Konto ist sofort angemeldet, aber sein Lizenzschlüssel und die kostenpflichtigen Lektionen warten auf den Bestätigungslink, und eine erneute Anmeldung erfordert eine bestätigte Adresse. [Datenbank](/docs/tooling/database) beschreibt die drei Datenbanken, den Seed und wie du auf Preview und Produktion den ersten Admin anlegst.
