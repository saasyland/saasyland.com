title: "Sessioni"

Le sessioni si trovano nella tabella `session` di D1 (`src/modules/session/session.schema.ts`). `auth.session.ts` le legge con `getRequestSession`, memorizzata per richiesta, ed espone `getCurrentSessionQuery` a rotte e componenti. La copia lato client non include mai il token di sessione.

## Casi d’uso

| Caso d’uso                                | Middleware                         | Usato da           |
| ----------------------------------------- | ---------------------------------- | ------------------ |
| `getActiveSessions`                       | autenticato                        | `SettingsSessions` |
| `revokeSession`                           | autenticato; solo sessioni proprie | `SessionRow`       |
| `revokeOtherSessions`                     | autenticato                        | `SettingsSessions` |
| `listUserSessions`                        | `session: ["list"]`                | nessuna schermata  |
| `revokeUserSession`, `revokeUserSessions` | `session: ["revoke"]`              | nessuna schermata  |

`getActiveSessions` restituisce le sessioni non scadute dell’utente corrente, dalla più recente, ed esclude le sessioni di impersonificazione.

## Interfaccia

**Impostazioni → Sicurezza** in `/admin/settings` mostra `SettingsSessions` (`src/presentation/components/custom/admin/settings/sessions.tsx`). Ogni `SessionRow` mostra il dispositivo (user agent o indirizzo IP), l’ultima attività e un badge sulla sessione corrente, e può revocare quella sessione. Un pulsante nell’intestazione revoca tutte le altre sessioni. Anche il cambio della password aggiorna l’elenco delle sessioni.

Le varianti di amministrazione per le sessioni di altri utenti esistono solo come funzioni server.
