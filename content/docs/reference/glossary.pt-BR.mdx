- **Rota:** Uma rota de arquivos nativa do TanStack com um componente, guarda, carregador ou manipulador HTTP.
- **Função do servidor:** Uma operação RPC datilografada criada com `createServerFn`.
- **Consulta:** Dados guardados com uma chave estável, compartilhados entre o carregador e React.
- **Mutação:** uma operação submetida através de TanStack Query e apoiada por uma função de servidor.
- **Espaço de nomes:** Um arquivo de tradução pontilhada sob um diretório local.
- **Encadernação:** a Cloudflare recurso fornecido ao trabalhador como `env.DB`, `env.CACHE` ou `env.ASSETS`.
- **Renda-se:** HTML em tempo de construção para uma rota pública.
