---
title: "組織"
description: "未実装: 組織、チーム、テナント単位の分離はありません。"
---

このアプリには組織、チーム、メンバーシップのモデルがありません。

- Better Auth の組織プラグインはインストールされていません。
- 組織やメンバーシップを保存するモジュールやテーブルはありません。
- クエリはサインイン中のユーザーに限定されるか、管理者権限で保護されています。
- ロールはグローバルで、`auth.access.ts` の `admin` と `customer` です。

**設定 → 一般** のワークスペース項目は静的なデモ入力であり、組織ではありません。

組織を追加する場合は Better Auth のプラグインから始めてください。`.agents/skills/better-auth` のエージェントスキル `organization-best-practices` がその使い方を説明しています。新しいテーブルは `src/modules` 配下の専用モジュールに置きます。
