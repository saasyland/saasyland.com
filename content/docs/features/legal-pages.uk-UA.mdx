| ------------- | ------------------------------------ | ------------------------ |
| `/privacy`    | `src/routes/_landing.privacy.tsx`    | `pages.legal.privacy`    |
| `/terms`      | `src/routes/_landing.terms.tsx`      | `pages.legal.terms`      |
| `/refunds`    | `src/routes/_landing.refunds.tsx`    | `pages.legal.refunds`    |
| `/licence`    | `src/routes/_landing.licence.tsx`    | `pages.legal.licence`    |
| `/affiliates` | `src/routes/_landing.affiliates.tsx` | `pages.legal.affiliates` |

Кожен файл маршруту визначає власний компонент сторінки, статичний `NAMESPACE` і константу модуля з ключами розділів у порядку відображення:

```tsx
const SECTIONS = ["operator", "accounts", "purchases", "payments", "licence", "conduct", "refunds", "responsibility", "law"] as const
```

Сторінка показує `lastUpdated`, `title` і `description`, а потім `sections.<key>.title` і `sections.<key>.body` для кожного ключа. Спільного компонента для юридичних сторінок немає. Політика конфіденційності та умови партнерської програми передають у свої повідомлення значення з `AFFILIATE_TERMS` (`src/data/affiliates.ts`), тож комісію, тривалість cookie, строк утримання й мінімальну виплату ніколи не вписують у тексти вручну.

## Редагування

- Змінюйте тексти в `messages/<locale>/pages.legal.<doc>.json` для кожної мови й запускайте `bun run check:i18n`.
- Щоб додати розділ, додайте його ключ до `SECTIONS` і повідомлення кожною мовою.
- Посилання у футері — це пункти футера з `LEGAL_NAVIGATION` у `src/data/legal.navigation.ts`: юридична колонка, а в колонці продукту — умови партнерської програми; сторінка реєстрації посилається на умови та політику конфіденційності.

Сторінка ліцензії відокремлює ліцензію MIT публічного репозиторію від окремо наданих платних матеріалів. Політика повернень зберігає обов’язкові права споживачів. Узгоджуйте кожен документ із фактичним оператором, процесом оплати, постачальниками й обробкою даних.
