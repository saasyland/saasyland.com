---
title: "Scripts del proyecto"
description: "Los comandos que usará a diario."
---

| Tarea                                                        | Comando                  |
| ------------------------------------------------------------ | ------------------------ |
| Iniciar el servidor de desarrollo                            | `bun run dev`            |
| Comprobar el formato, el lint, los tipos y las traducciones  | `bun run check`          |
| Ejecutar todos los proyectos de Vitest                       | `bun run test`           |
| Ejecutar el umbral de cobertura                              | `bun run test:coverage`  |
| Ejecutar la prueba smoke en el navegador                     | `bun run test:e2e:smoke` |
| Ejecutar la suite de navegador en Chromium que ejecuta la CI | `bun run test:e2e:pr`    |
| Generar una migración                                        | `bun run db:generate`    |
| Compilar el Worker de preview                                | `bun run build`          |
| Servir la última compilación                                 | `bun run start`          |
| Desplegar la preview                                         | `bun run deploy:preview` |

Antes de abrir una pull request, ejecute la misma secuencia que la CI:

```sh
bun run check
bun run test:coverage
bun run test:e2e:pr
```

En local, Playwright migra la base de datos de pruebas y carga sus datos iniciales, compila el Worker de pruebas y lo inicia, salvo que ya haya un servidor en marcha en el puerto 3000.

Use `bun run test`, no `bun test`, para que Vitest se ejecute con la configuración del proyecto. Los scripts que terminan con el nombre de un entorno, como `db:migrate:preview` o `deploy:production`, solo actúan sobre ese entorno.

Consulte [Scripts del proyecto](/docs/tooling/scripts) para ver la lista completa.
