## Pliki środowiskowe

| Plik               | W repozytorium | Używany przez                                                                                                              |
| ------------------ | -------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `.env.example`     | Tak            | Wymienia wszystkie sekrety z pustymi wartościami                                                                           |
| `.env.development` | Nie            | `bun run dev`, `polar:verify:development`, `db:studio:development`, `db:introspect:development`                            |
| `.env.preview`     | Nie            | `deploy:preview` (zadeklarowane sekrety), `polar:verify:preview`, `db:studio:preview`, `db:introspect:preview`             |
| `.env.production`  | Nie            | `deploy:production` (zadeklarowane sekrety), `polar:verify:production`, `db:studio:production`, `db:introspect:production` |
| `.env.test`        | Tak            | Vitest i środowisko Wranglera `test`; wyłącznie fikcyjne wartości                                                          |

## Zmienne

| Zmienna                     | Używana przez                                                                                                |
| --------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `AUTH_SECRET`               | Podpisywanie, szyfrowanie i tokeny weryfikacji adresu e-mail w Better Auth                                   |
| `AUTH_GITHUB_CLIENT_ID`     | OAuth GitHuba; uwierzytelnia też żądanie pobierające liczbę gwiazdek na GitHubie                             |
| `AUTH_GITHUB_CLIENT_SECRET` | OAuth GitHuba; uwierzytelnia też żądanie pobierające liczbę gwiazdek na GitHubie                             |
| `AUTH_GOOGLE_CLIENT_ID`     | OAuth Google                                                                                                 |
| `AUTH_GOOGLE_CLIENT_SECRET` | OAuth Google                                                                                                 |
| `RESEND_API_KEY`            | Klient Resend                                                                                                |
| `RESEND_EMAIL_FROM`         | Domyślny nadawca dla `sendEmail`                                                                             |
| `POLAR_ACCESS_TOKEN`        | Klient Polar SDK                                                                                             |
| `POLAR_SERVER`              | `sandbox` dla trybu deweloperskiego i preview, `production` dla produkcji                                    |
| `POLAR_WEBHOOK_SECRET`      | Weryfikacja podpisów webhooków Polar                                                                         |
| `POLAR_ORGANIZATION_ID`     | Dezaktywacja kluczy licencyjnych Polar i wyszukiwanie zniżek                                                 |
| `POLAR_PRODUCT_ID_CORE`     | Produkt w checkoucie dla pakietu Core                                                                        |
| `POLAR_PRODUCT_ID_COMPLETE` | Produkt w checkoucie dla pakietu Complete                                                                    |
| `POLAR_PRODUCT_ID_AGENCY`   | Produkt w checkoucie dla pakietu Agency                                                                      |
| `CLOUDFLARE_ACCOUNT_ID`     | Sterownik D1 HTTP w Drizzle Kit                                                                              |
| `CLOUDFLARE_DATABASE_ID`    | Sterownik D1 HTTP w Drizzle Kit                                                                              |
| `CLOUDFLARE_ACCESS_TOKEN`   | Sterownik D1 HTTP w Drizzle Kit                                                                              |
| `AFFONSO_PROGRAM_ID`        | Opcjonalne publiczne ID programu Affonso, które włącza śledzenie poleceń partnerskich                        |
| `FFMPEG`, `FFPROBE`         | Opcjonalne pliki wykonywalne FFmpeg i ffprobe dla `scripts/publish-video.ts`; domyślnie `ffmpeg` i `ffprobe` |

Każde środowisko w `wrangler.jsonc` wymienia potrzebne sekrety w `secrets.required`; środowisko `test` pomija trzy zmienne Cloudflare. `AFFONSO_PROGRAM_ID` nie jest sekretem: pojawia się w tagu skryptu na stronie, więc jest zmienną Workera w `vars`, ustawianą tylko w środowisku, które przyjmuje prawdziwe płatności. Obecnie ustawia ją tylko `test`, z fikcyjnym ID dla testów przeglądarkowych ([Program partnerski](/docs/features/affiliates)). `FFMPEG` i `FFPROBE` to opcjonalne zmienne powłoki dla `scripts/publish-video.ts`, a nie sekrety Workera. Kod Workera odczytuje je z `env` w `cloudflare:workers`, a ich typy definiuje `src/types/bindings.d.ts`. Nie ma zmiennych `VITE_`: publiczny URL i domena są stałymi w `src/presentation/branding`.

## Bindingi

| Binding  | Typ              | `development`                   | `preview` | `production` | `test`                   |
| -------- | ---------------- | ------------------------------- | --------- | ------------ | ------------------------ |
| `DB`     | D1               | Baza preview, zdalna            | Preview   | Produkcyjna  | Lokalna `saasyland_test` |
| `CACHE`  | KV               | Przestrzeń nazw preview, zdalna | Preview   | Produkcyjna  | Lokalna                  |
| `MEDIA`  | R2               | Bucket preview, zdalny          | Preview   | Produkcyjny  | Lokalny `saasyland-test` |
| `ASSETS` | Zasoby statyczne | Tak                             | Tak       | Tak          | Tak                      |

Skrypty wdrożeniowe dla preview i produkcji najpierw uruchamiają `scripts/verify-bindings.ts`, który kończy się błędem, dopóki środowisku brakuje bindingu lub ma ono zastępcze identyfikatory D1 lub KV, a także wtedy, gdy produkcja współdzieli zasób z preview. Buckety R2 są wiązane po nazwie (`saasyland-preview` dla trybu deweloperskiego i preview, `saasyland` dla produkcji) i muszą istnieć przed wdrożeniem.
