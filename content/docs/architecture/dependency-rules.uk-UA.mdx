## Напрямки імпорту

| Папка                     | Може імпортувати                                                                                                                                                                                                                                                                                                                                            | Не має імпортувати                                         |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `src/routes`              | представлення, опції запитів і мутацій модулів, інтеграції (guard-функції, i18n, Fumadocs), `src/data`, `src/lib`                                                                                                                                                                                                                                           | клієнти бази даних або провайдерів поза серверною функцією |
| `src/presentation`        | опції модулів, Zod-схеми, константи й типи, хуки, `src/data`, `src/lib`, безпечні для браузера інтеграції                                                                                                                                                                                                                                                   | `db`, `auth` з `auth.server.ts`, Polar, Resend             |
| `src/modules/*/use-cases` | інтеграції (`db`, `auth`, `sendEmail`, `polar`), `_core`, схеми модулів, шаблони листів                                                                                                                                                                                                                                                                     | компоненти                                                 |
| `src/integrations`        | `_core`, схеми модулів і сценарії використання, до яких звертається вендор через зворотні виклики                                                                                                                                                                                                                                                           | компоненти                                                 |
| `src/server.ts`           | допоміжні функції локалей, cookie, константи `_core`, префікси шляхів файлів, які він віддає сам, `ROUTES`, `polarCheckoutOrigin` (`polar.constants.ts`), перезаписи документа `rewritePppOffer` (`license.pricing.ts`) і `markSession` (`session.rewrite.ts`), допоміжні функції Content Security Policy (`content-security-policy.ts`), ресурси документа | базу даних, Better Auth або Polar SDK                      |
| `src/routes.ts`           | нічого                                                                                                                                                                                                                                                                                                                                                      | нічого: його завантажує кожне середовище виконання         |
| `src/data/navigation.ts`  | `lucide-react`, `~/src/routes`, `~/src/data/navigation.constants`                                                                                                                                                                                                                                                                                           | нічого іншого: його завантажує проєкт Remotion             |

До безпечних для браузера інтеграцій належать `i18n.paths.ts`, `i18n.utils.ts`, `auth.client.ts`, `auth.access.ts`, `auth.roles.ts` і `form.fields.ts`. `auth.access.ts` сам оголошує декларації дозволів, а з `auth.roles.ts` імпортує лише коди ролей і `isRole`. `src/__test__/source-layout.test.ts` падає, коли `src/routes.ts` щось імпортує або `src/data/navigation.ts` імпортує щось, крім своїх трьох модулів.

## Межі суто серверного коду

- **Серверні функції.** TanStack Start вилучає обробник кожного `createServerFn` із браузерного бандла й замінює виклик RPC-запитом. Саме тому компонент може імпортувати `createCourseMutation` з того самого файлу, який імпортує `db`.
- **Суто серверні модулі.** Файли, що читають секрети або прив'язки, починаються з `import "@tanstack/react-start/server-only"`, і це тримає їх поза клієнтською збіркою. Приклади: `drizzle.database.ts`, `auth.server.ts`, `polar.config.ts`, `resend.utils.ts`, `src/lib/rate-limit.ts` і `i18n.middleware.ts`. Виняток — файли, що експортують серверну функцію, як-от `src/lib/github.ts` і `deactivate-license.ts`: компоненти імпортують їх для RPC-виклику, тому вони читають `env` лише в обробнику та допоміжних функціях, які він викликає, а збірка не включає їх у клієнтський бандл.
- **Функції для конкретного середовища.** `createServerOnlyFn` обгортає код, який виконується лише на сервері (`getRequestSession`). `createIsomorphicFn` надає окремі реалізації для сервера й браузера (`getCurrentLocale`).
- **Прив'язки та секрети** надходять з `env` у `cloudflare:workers` і їх читає лише серверний код: суто серверні модулі, обробники серверних функцій і допоміжні функції, які імпортують лише вони. `scripts/verify-build.ts` зупиняє збірку з помилкою, коли клієнтський ресурс імпортує `cloudflare:workers`.
- **Точка входу Worker.** `src/server.ts` виконується для кожного запиту, крім `/assets/*`, `/fonts/*`, `/robots.txt` і `/llms.txt`, які `run_worker_first` у `wrangler.jsonc` віддає безпосередньо зі статичних ресурсів. Його статичні імпорти мінімальні, і обробники Worker із можливостей, які він імпортує статично, дотримуються того самого правила: обробник можливості курсів завантажує `serveCover`, `serveAttachment` або `serveMedia` динамічним `import()` лише для шляхів `/media/` і `serveCourseSitemap` лише для `/sitemap-courses.xml`, обробник можливості ліцензій завантажує `serveBundle` лише для шляхів `/bundles/`, а `server.ts` завантажує обробник TanStack Start лише тоді, коли не знайдено відповідного статичного ресурсу.

```ts
import "@tanstack/react-start/server-only"

import { env } from "cloudflare:workers"

import { drizzle } from "drizzle-orm/d1"

import * as schema from "~/src/integrations/drizzle-orm/drizzle.schemas"

export const db = drizzle(env.DB, { schema })
```
