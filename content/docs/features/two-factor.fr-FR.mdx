## Module

`modules/two-factor/use-cases` — activer, désactiver, vérifier TOTP, vérifier le code de sauvegarde.

## UX

Configuration de l'onglet de sécurité + `/auth/two-factor` défier l'itinéraire. Suivez les contraintes du plugin Better Auth 2FA dans `auth.constraints.ts`.
