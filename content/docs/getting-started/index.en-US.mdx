There are two ways to run SaaSy Land locally. The isolated test preview needs no accounts: it uses local D1 and KV, seeded test accounts and intercepted provider requests. Development with hot reload connects to Cloudflare and the real providers.

<Steps>
  <Step>[Prerequisites](/docs/getting-started/prerequisites): Bun, Node.js and the accounts each mode needs.</Step>
  <Step>[Installation](/docs/getting-started/installation): install dependencies and generated files.</Step>
  <Step>[Environment variables](/docs/getting-started/environment-variables): fill in the environment file.</Step>
  <Step>[First run](/docs/getting-started/first-run): start the test preview or the dev server.</Step>
  <Step>[Project scripts](/docs/getting-started/project-scripts): the commands you use every day.</Step>
  <Step>[Deploy a preview](/docs/getting-started/deploy-preview): provision Cloudflare resources and deploy.</Step>
</Steps>
