Exécutez les scripts depuis la racine du dépôt avec `bun run <script>`.

## Développement et build

| Script              | Exécute                                                                                                                                       |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `dev`               | `generate:cn`, `content` et `vp dev` dans l'environnement `development` sur http://localhost:3000                                             |
| `build`             | Identique à `build:preview`                                                                                                                   |
| `build:preview`     | Nettoyage de `dist`, `generate:cn`, `content`, `vp build` pour `preview`, `scripts/verify-build.ts` et `scripts/optimize-prerendered-html.ts` |
| `build:production`  | Les mêmes étapes pour `production`                                                                                                            |
| `build:test`        | Les mêmes étapes pour l'environnement `test`                                                                                                  |
| `start`             | `vp preview` du dernier build sur http://127.0.0.1:3000                                                                                       |
| `start:test`        | `vp preview` du build de test                                                                                                                 |
| `deploy:preview`    | `scripts/verify-bindings.ts preview`, `build:preview` et `wrangler deploy --secrets-file .env.preview`                                        |
| `deploy:production` | `scripts/verify-bindings.ts production`, `build:production` et `wrangler deploy --secrets-file .env.production`                               |

`verify-build.ts` vérifie la configuration de déploiement, la langue du document, les liens canoniques et alternatifs des pages d'accueil et des pages légales localisées, les polices, que les pages protégées et les alias de langue n'ont pas été prérendus et qu'aucun asset client n'importe `cloudflare:workers`. `optimize-prerendered-html.ts` retire des pages prérendues les indications `modulepreload` des dépendances et conserve l'indication du point d'entrée en basse priorité.

## Vérifications

| Script             | Exécute                                                                                   |
| ------------------ | ----------------------------------------------------------------------------------------- |
| `check`            | `generate:cn`, `check:i18n` et `vp check` (formatage, lint et types)                      |
| `check:fix`        | La même chose avec `vp check --fix`                                                       |

| `check:pre-commit` | `generate:cn`, `check:i18n` et `vp staged` ; exécuté par le hook de pre-commit            |
| `lint`             | `vp lint`                                                                                 |
| `format`           | `vp fmt`                                                                                  |
| `format:check`     | `vp fmt --check`                                                                          |

## Génération et maintenance

| Script           | Exécute                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| `content`        | `fumadocs-mdx` : génère `.source/` à partir de `content/`                                                    |
| `generate:cn`    | Construit les tables de fusion des classes dans `.source/cn-tables.ts` à partir de `src/lib/cn.config.ts`    |
| `cf-typegen`     | `wrangler types` pour `development` : régénère `src/types/worker-configuration.d.ts`                         |
| `typegen`        | `cf-typegen`, `generate:cn` et `content`                                                                     |
| `skills:sync`    | `scripts/sync-skills.ts` : restaure les skills pour agents à partir de `skills-lock.json`                    |
| `clean`          | Supprime `.source`, `.tanstack`, `.wrangler`, `dist`, `coverage`, la sortie de Playwright et `*.tsbuildinfo` |
| `clean:deep`     | `clean` et `node_modules`                                                                                    |
| `clean:hardcore` | `clean:deep`, `bun.lock` et `skills-lock.json`                                                               |
| `prepare`        | S'exécute à l'installation : `vp config --no-agent` (hooks Git), `generate:cn` et `content`                  |

`clean` supprime `.wrangler`, y compris les bases de données locales de développement et de test : exportez donc d'abord les données locales que vous souhaitez conserver.
