---
title: Dateinamensgebung.
description: Suffixe für die Ablage und Namenskonventionen für Ordner.
---

| Muster.        | Bedeutung.                                  |
| -------------- | ------------------------------------------- |
| `_components/` | Routenlokale React-Komponenten.             |
| `_lib/`        | Routenlokale Helfer, Suchparameter, Mapper. |
| `_types/`      | Routenlokale Typen.                         |
| `use-cases/`   | Modulanwendungsdienste.                     |
| `*.server.ts`  | Serverseitige Integrationsoption.           |
| `__test__/`    | Standortbezogene Tests.                     |

Bevorzuge explizite Namen (`search-params.ts`) gegenüber ungenauen Ablagestellen wie `utils.ts`.
