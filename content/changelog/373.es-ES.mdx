- Cambiado: `bun run check:areas` ahora poda también, como la CLI `saasyland`, las pruebas que nombran un área retirada. Una prueba cuyo callback la nombra desaparece entera, una fila de una tabla `.each` desaparece sola, un hook pierde las sentencias que la nombran, desaparece cada `vi.mock` de un módulo borrado, y también un `describe` o un archivo de pruebas que se queda sin pruebas. Consulta [Pruebas](/docs/conventions/testing#tests-follow-the-areas).
- Cambiado: también poda el código construido a partir de un área retirada. Un declarador de variable cuyo valor sale solo del área desaparece con cada uso de los nombres que enlaza, y una sentencia que nombra el área desaparece en el nivel superior de un módulo, de un `describe` o de un hook. Un valor que también se apoya en código que se queda, como un enlace de menú construido a partir de una entrada que se queda, y las funciones, condiciones y exportaciones se informan en su lugar, porque lo que debe cambiar es el diseño, no la poda.
