---
title: "Script del progetto"
description: "I comandi che usi ogni giorno."
---

| Attività                                           | Comando                  |
| -------------------------------------------------- | ------------------------ |
| Avviare il server di sviluppo                      | `bun run dev`            |
| Controllare formattazione, lint, tipi e traduzioni | `bun run check`          |
| Eseguire tutti i progetti Vitest                   | `bun run test`           |
| Eseguire la soglia di copertura                    | `bun run test:coverage`  |
| Eseguire lo smoke test nel browser                 | `bun run test:e2e:smoke` |
| Generare una migrazione                            | `bun run db:generate`    |
| Compilare il Worker di preview                     | `bun run build`          |
| Servire l'ultima build                             | `bun run start`          |
| Eseguire il deploy della preview                   | `bun run deploy:preview` |

Prima di aprire una pull request, esegui la stessa sequenza della CI:

```sh
bun run check
bun run test:coverage
bun run test:e2e:smoke
```

Usa `bun run test`, non `bun test`, così Vitest viene eseguito con la configurazione del progetto. Gli script che terminano con il nome di un ambiente, come `db:migrate:preview` o `deploy:production`, agiscono solo su quell'ambiente.

Vedi [Script del progetto](/docs/tooling/scripts) per l'elenco completo.
