## Kit location

`src/presentation/components/custom/data-table`

## Feature pattern (users)

- `columns.tsx` / `cells.tsx` / `filters.tsx` / `actions.tsx` / `options.tsx`
- Map DB rows → table rows in `_lib` or module utils
- Toolbar refresh → invalidate the relevant TanStack Query key
- Keep Suspense fallbacks free of the table runtime

## Options

Configure toolbar (search, filters, export CSV, fetch, settings), pagination, selection, and density via `options` — see UI → DataTable.
