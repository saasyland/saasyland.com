description: Stato URL — SaaSy Land
---

Definire lo schema di ricerca di un percorso con `validateSearch`, leggilo con `Route.useSearch`, e aggiornarlo attraverso TanStack Router navigazione. Tenere filtri, schede, smistamento e impaginazione nella URL quando necessario. Lo stato componente rimane in React.

Le riscrizioni dell'URL locale si applicano ai collegamenti Router nativi. Uso `localizePathname` per gli URL costruiti manualmente, tra cui OAuth callback e link e-mail. Non prependere un locale a collegamenti esterni o API percorsi. Conservare la query e il frammento quando si passano le lingue.
