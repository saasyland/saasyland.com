- Modifié : les scripts et les plugins de lint du dépôt n'ont plus aucune branche `undefined` ou `null` ni aucun `return undefined`. Les plugins Vite déclarent des filtres sur leurs hooks, les plugins de lint partagent un même lecteur de noms de nœuds et une même analyse des classes, et chaque valeur des scripts, comme leurs arguments, le code de sortie, le dossier de build du client et les environnements D1, est déclarée une seule fois. `code-style/no-undefined-branch` s'applique désormais à `scripts` et à leurs tests, et les conventions de style de code montrent les formes qui remplacent une branche `undefined`. Voir [Style de code](/docs/conventions/code-style).
