この章の各ページは、コードの現状をそのまま説明します。モジュールのユースケース、Better Auth、Polar を通じて実データを読み書きする機能は**稼働中**です。管理画面はすべて稼働中です。データの取得元がまだない画面は作られず、lint ルールが管理画面のコードからデモデータを締め出します（[管理ダッシュボード](/docs/features/admin-dashboard#real-data-only)を参照）。

## 稼働中

- アカウント: [認証](/docs/features/authentication)、[OAuth プロバイダー](/docs/features/oauth)、[メール確認](/docs/features/email-verification)、[パスワードリセット](/docs/features/password-reset)、[二要素認証](/docs/features/two-factor)、[セッション](/docs/features/sessions), [なりすまし](/docs/features/impersonation)、[アカウント](/docs/features/account)。
- 管理: カウンター、売上、新規ユーザー、コースの進捗、パッケージ別のライセンス、ユーザーテーブルを備えた[ダッシュボード](/docs/features/admin-dashboard)、[ユーザー（管理）](/docs/features/users-admin)の **すべてのユーザー** タブと **顧客** タブ、[注文と顧客](/docs/features/orders)の注文一覧と注文ページ、[商品](/docs/features/products)と[カテゴリー](/docs/features/categories)の一覧、[設定](/docs/features/settings)、[コース](/docs/features/courses)のコースエディター、[動画](/docs/features/videos)の動画ライブラリ。
- 顧客: Polar の購入とライセンスを備えた[顧客アプリ](/docs/features/customer-app)（[ライセンス](/docs/features/licences)、[決済](/docs/features/payments)）と、顧客の端末で CLI をアクティベートする [CLI ライセンス API](/docs/features/cli-licence-api)。
- コース: 公開の[コースカタログとプレーヤー](/docs/features/courses)。レッスンは無料、アカウントが必要、Complete または Agency のライセンスが必要のいずれかで（[コンテンツアクセス](/docs/features/content-access)）、視聴の進捗が保存されます。
- 公開サイト: 地域別価格とニュースレターを備えた[ランディングページ](/docs/features/landing-page)、[ブログ](/docs/features/blog)、[ドキュメントサイト](/docs/features/docs-site)、[法務ページ](/docs/features/legal-pages)、そしてメタデータ、サイトマップ、ソーシャルカードを扱う[検索エンジンとソーシャルプレビュー](/docs/features/seo)。
- アフィリエイト: Affonso が紹介を計測し、Polar の注文で成果を計上し、`/affiliates` で規約を公開する[アフィリエイトプログラム](/docs/features/affiliates)。
- プラットフォーム: [国際化](/docs/features/internationalization)、[トランザクションメール](/docs/features/email)、[HTTP ハンドラー](/docs/features/api-surface)、[セキュリティ](/docs/features/security)。

## 未実装

- [組織](/docs/features/organizations): チーム、メンバーシップ、テナント単位の分離はありません。
- [アナリティクス](/docs/features/analytics): ページのアナリティクスはありません。管理ダッシュボードは D1 から売上と新規登録を表示します。
- [料金モデル](/docs/features/pricing-models)、返金、ブログ記事、ランディングページ、招待、ロールの管理画面: まだありません。価格はコードと Polar で設定し、記事は Git で管理します。
