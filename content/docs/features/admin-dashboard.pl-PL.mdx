## Struktura panelu

`src/routes/admin.tsx` chroni każdą stronę administracyjną za pomocą `requireAdmin` i wstępnie ładuje wspólne przestrzenie nazw. Layout wyświetla:

- `AdminSidebar`, `AdminBreadcrumbs` i `AdminCommandPalette` (otwierane skrótem ⌘K), zbudowane na podstawie `ADMIN_NAVIGATION` w `src/data/navigation.ts`, które grupuje pozycje dodane przez obszary, każdą z jej ikoną: Przegląd (Pulpit, Analityka), Oferta (Produkty, Modele cenowe), Treści (Blog, Kursy, Wideo, Strona główna) i Administracja (Zarządzanie użytkownikami, Płatności, Ustawienia).
- Widżet użytkownika u dołu paska bocznego z linkiem do ustawień i `SignOutButton`.

## Pulpit

`/admin` (`src/routes/admin.index.tsx`) wstępnie ładuje w loaderze `getUsersQuery` i zapytanie każdej statystyki pulpitu oraz składa trzy widżety z `src/presentation/components/custom/admin/dashboard`:

- `DashboardStats` (działający): statystyki z `ADMIN_DASHBOARD_STATS` w kolejności ich `order`: liczba użytkowników i użytkownicy czekający na weryfikację e-maila z `src/data/auth.dashboard.ts` oraz liczba produktów z `src/data/products.dashboard.ts`.
- `RevenueChart` (demonstracyjny): statyczny SVG ze stałymi osiami; przyciski zakresu nic nie robią.
- Karta użytkowników (działająca): najnowsi użytkownicy z filtrami wyszukiwania i statusu, wyświetlani po <RepositoryFact name="adminPreviewPageSize" /> na stronę.

```tsx
<DataTable
  columns={dashboardUserColumns}
  data={users.rows}
  filters={[
    { columnId: "user", placeholder: t("users.search"), type: "search" },
    {
      columnId: "status",
      label: t("users.filters.status"),
      options: USER_STATUSES.map((status) => ({ label: t(`users.table.status.${status}`), value: status })),
      type: "select",
    },
  ]}
  options={{ initialState: { pagination: ADMIN_DASHBOARD_PREVIEW_PAGINATION }, selectable: true }}
/>
```

Tabela działa w przeglądarce na pierwszej stronie `getUsersQuery` (liczba użytkowników: <RepositoryFact name="defaultPageSize" />). **Zobacz wszystkich** prowadzi do `/admin/users`, gdy użytkowników jest więcej. **Dodaj produkt**, pozycja obszaru produktów w `ADMIN_DASHBOARD_ACTIONS`, prowadzi do `/admin/products/create`; **Ostatnie 30 dni** jest wyłączone, a **Eksportuj** nie jest podłączone.
