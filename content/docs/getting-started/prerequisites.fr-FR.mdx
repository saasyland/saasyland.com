## Outils

| Outil   | Version                | Pourquoi                                                                                                                                                                                 |
| ------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bun     | 1.4.4                  | Gestionnaire de paquets et lanceur de scripts ; `packageManager` dans `package.json` et la CI fixent cette version                                                                       |
| Node.js | 26.13.1 ou plus récent | La version de `.nvmrc`, lue par `nvm use` et par la CI ; 26.13.1 est la version de sécurité de novembre 2026 de la branche LTS Node 26. La base de données de test utilise `node:sqlite` |
| Git     | Toute version récente  | L'étape d'installation configure les hooks Git                                                                                                                                           |

Wrangler, drizzle-kit, Playwright et la CLI Vite+ sont des dépendances de développement ; exécutez-les via les scripts du paquet ou `bunx`. Les tests dans le navigateur nécessitent aussi les navigateurs Playwright installés par `bun run test:e2e:install`.

## Comptes

La préversion de test isolée et tous les tests automatisés ne nécessitent ni compte ni identifiants. Le développement et le déploiement utilisent de vrais services :

- Un compte Cloudflare avec D1, KV et Workers. Le serveur de développement se connecte aux ressources de préversion distantes.
- Des applications OAuth GitHub et Google pour la connexion via les réseaux sociaux.
- Resend avec un expéditeur vérifié. L'inscription par e-mail exige une adresse vérifiée ; sans cela, l'inscription ne fonctionne pas.
- Polar, en mode sandbox pour le développement, avec trois produits pour les offres Core, Complete et Agency.
