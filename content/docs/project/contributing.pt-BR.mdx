---
title: Contribuir
description: Como propor mudanças no arranque.
---

1. Discuta grandes mudanças em um assunto.
2. Ramo da linha principal.
3. Siga convenções + habilidades
4. `bun run check` · testes · construir
5. Abra um PR com `feat`/`fix`/`docs` Título

Mantenha as páginas em sincronia quando você adicionar módulos ou rotas.
