---
title: "Conventional Commits"
description: "コミットメッセージの形式と絵文字フックです。"
---

コミットの件名は `<type>(<scope>): <description>` の形式に従います。スコープは省略でき、`!` は破壊的変更を示します。件名には絵文字を付けずに書いてください。

```sh
git commit -m "fix(auth): keep the locale in verification links"
```

`.vite-hooks/` の `prepare-commit-msg` フックは `bun scripts/commit-msg.ts` を実行します。このスクリプトは件名を検証し、タイプに対応する絵文字を先頭に付けます。そのため、上のコミットは `🐛 fix(auth): keep the locale in verification links` になります。

| タイプ     | 絵文字 |
| ---------- | ------ |
| `build`    | 🛠️     |
| `chore`    | ♻️     |
| `ci`       | ⚙️     |
| `docs`     | 📚     |
| `feat`     | ✨     |
| `fix`      | 🐛     |
| `perf`     | 🚀     |
| `refactor` | 📦     |
| `revert`   | 🗑️     |
| `style`    | 💎     |
| `test`     | 🚨     |

これ以外のタイプや、規約の形式に従っていない件名の場合は、許可されているタイプの一覧を表示してコミットを中止します。件名がすでに絵文字で始まっている場合、Git が生成した件名（`Merge`、`Revert "`、`fixup!`、`squash!`）の場合、そしてマージ、スカッシュ、テンプレートのメッセージの場合、フックは件名を変更しません。

メッセージフックの前に、`pre-commit` フックが `bun run check:pre-commit` を実行します。フックを迂回しないでください。
