## Strumenti

| Strumento | Versione                            | Perché                                                                                                         |
| --------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Bun       | 1.4.0                               | Gestore di pacchetti ed esecutore di script; `packageManager` in `package.json` e la CI ne fissano la versione |
| Node.js   | 24.11 o successiva nella serie 24.x | Vite+ accetta `^22.18.0`, `^24.11.0` o `>=26.0.0`; la CI usa Node 24 e il database di test usa `node:sqlite`   |
| Git       | Qualsiasi versione recente          | Il passaggio di installazione configura gli hook Git                                                           |

Wrangler, drizzle-kit, Playwright e la CLI di Vite+ sono dipendenze di sviluppo; eseguili tramite gli script del pacchetto o con `bunx`. I test nel browser richiedono anche i browser di Playwright installati con `bun run test:e2e:install`.

## Account

La preview di test isolata e tutti i test automatici non richiedono account né credenziali. Lo sviluppo e il deploy usano servizi reali:

- Un account Cloudflare con D1, KV e Workers. Il server di sviluppo si collega alle risorse di preview remote.
- App OAuth di GitHub e Google per l'accesso tramite social.
- Resend con un mittente verificato. La registrazione con email richiede un indirizzo verificato, quindi senza di esso la registrazione non funziona.
- Polar, usando la sandbox per lo sviluppo, con tre prodotti per i piani Core, Complete e Agency.
