---
title: Mitwirken.
description: Wie können Änderungen an der Standardkonfiguration vorgenommen werden?
---

1. Besprechen Sie umfassende Veränderungen in einem Sachverhalt.
2. Abzweig von der Hauptleitung.
3. Beachten Sie die üblichen Gepflogenheiten und entwickeln Sie Ihre Fähigkeiten weiter.
4. `bun run check` · Tests · Build
5. Öffnen Sie einen Pull Request mit einem Titel, der mit `feat`/`fix`/`docs` beginnt.

Stellen Sie sicher, dass die Dokumentationsseiten aktuell bleiben, wenn Sie Module oder Routen hinzufügen.
