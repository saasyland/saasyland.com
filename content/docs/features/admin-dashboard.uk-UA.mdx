## Каркас адмінпанелі

`src/routes/admin.tsx` захищає кожну сторінку адмінпанелі за допомогою `requireAdmin` і попередньо завантажує спільні простори імен. Макет показує:

- `AdminSidebar`, `AdminBreadcrumbs` і `AdminCommandPalette` (відкривається ⌘K), побудовані з `ADMIN_NAVIGATION` у `src/data/navigation.ts`, який групує пункти, додані розділами, кожен з його іконкою: Огляд (Панель, Аналітика), Пропозиції (Продукти, Цінові моделі), Вміст (Блог, Курси, Відео, Головна сторінка) та Адміністрування (Керування користувачами, Платежі, Налаштування).
- Віджет користувача внизу бічної панелі з посиланням на налаштування та `SignOutButton`.

## Панель

`/admin` (`src/routes/admin.index.tsx`) попередньо завантажує в loader `getUsersQuery` і запит кожної статистики панелі та складає три віджети з `src/presentation/components/custom/admin/dashboard`:

- `DashboardStats` (робочий): статистика з `ADMIN_DASHBOARD_STATS` у порядку її `order`: кількість користувачів і користувачі, що очікують підтвердження пошти, з `src/data/auth.dashboard.ts` та кількість продуктів із `src/data/products.dashboard.ts`.
- `RevenueChart` (демонстраційний): статичний SVG із фіксованими осями; кнопки діапазону нічого не роблять.
- Картка користувачів (робоча): найновіші користувачі з фільтрами пошуку та статусу, кількість рядків на сторінці: <RepositoryFact name="adminPreviewPageSize" />.

```tsx
<DataTable
  columns={dashboardUserColumns}
  data={users.rows}
  filters={[
    { columnId: "user", placeholder: t("users.search"), type: "search" },
    {
      columnId: "status",
      label: t("users.filters.status"),
      options: USER_STATUSES.map((status) => ({ label: t(`users.table.status.${status}`), value: status })),
      type: "select",
    },
  ]}
  options={{ initialState: { pagination: ADMIN_DASHBOARD_PREVIEW_PAGINATION }, selectable: true }}
/>
```

Таблиця працює в браузері з першою сторінкою `getUsersQuery` (кількість користувачів: <RepositoryFact name="defaultPageSize" />). **Переглянути всіх** веде на `/admin/users`, коли користувачів більше. **Додати продукт**, пункт розділу продуктів в `ADMIN_DASHBOARD_ACTIONS`, веде на `/admin/products/create`; **Останні 30 днів** вимкнено, а **Експорт** не підключено.
