## Font

Geist e Geist Mono sono self-hosted in `public/fonts` come sottoinsiemi WOFF2 variabili, serviti con una cache immutabile di un anno (`public/_headers`). `src/presentation/styles/fonts.css` dichiara un `@font-face` per ogni intervallo Unicode (latino, latino esteso, cirillico), font di fallback con metriche allineate e le variabili `--font-geist-sans` e `--font-geist-mono`. `globals.css` le associa a `--font-sans`, `--font-heading` e `--font-mono`. Il testo giapponese ricade sui font di sistema.

## Precaricamenti

`src/presentation/document-assets.ts` esporta `DOCUMENT_STYLESHEET` (`globals.css`) e i precaricamenti dei font per una lingua:

```ts
export const fontPreloads = (locale: SupportedLocale) => {
  const fonts = [GEIST_LATIN, GEIST_MONO_LATIN]
  if (locale === "pl-PL") {
    fonts.push(GEIST_LATIN_EXT)
  } else if (locale === "uk-UA") {
    fonts.push(GEIST_CYRILLIC)
  }
  return fonts
}
```

La rotta radice li aggiunge come tag `link`, e il Worker (`src/server.ts`) invia il foglio di stile e gli stessi font in un header di precaricamento `Link` a ogni risposta HTML. I nomi dei file dei font sono hash del contenuto: se sostituisci un font, aggiorna sia `fonts.css` sia `document-assets.ts`.

## Costanti del brand

`src/presentation/branding/index.ts` è l’unica fonte del brand:

```ts
export const APP_NAME = "SaaSy Land"
export const APP_DOMAIN = "saasyland.com"

export const APP_URL = `https://${APP_DOMAIN}`
export const CONTACT_EMAIL = `hello@${APP_DOMAIN}`
export const NOTIFICATIONS_EMAIL = `notifications@${APP_DOMAIN}`

export const APP_FOUNDED_YEAR = 2023

export const APP_GITHUB_OWNER = "saasyland"
export const APP_GITHUB_REPO = APP_DOMAIN
export const APP_GITHUB_URL = `https://github.com/${APP_GITHUB_OWNER}/${APP_GITHUB_REPO}`
```

Alimentano il nome dell’app in Better Auth e l’emittente della 2FA, i nomi dei cookie del tema e della lingua, gli host consentiti, il footer, la navigazione della documentazione, il numero di stelle di GitHub, i dati strutturati del blog e i mittenti e destinatari delle email.

## Logo e media

- `Wordmark` (`src/presentation/components/custom/wordmark.tsx`) mostra il logo come SVG inline accanto ad `APP_NAME`.
- La favicon è `public/favicon.ico`; le immagini del blog si trovano in `public/images/blog`.
- I video della landing page si trovano in `src/presentation/assets/motion` come file WebM con poster WebP. Un poster deve mantenere le dimensioni del proprio video.
