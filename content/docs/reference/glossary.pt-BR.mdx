title: "Glossário"
description: "Termos usados ao longo da documentação do SaaSy Land."
---

- **AppError:** a única classe de erro das server functions, que carrega um dos `ERROR_CODES`.
- **Binding:** um recurso do Cloudflare passado ao Worker: `DB` (D1), `CACHE` (KV) ou `ASSETS` (assets estáticos).
- **Guard:** uma função `beforeLoad`, como `requireAdmin`, que redireciona antes de uma rota carregar.
- **Integração:** uma pasta em `src/integrations` que configura um fornecedor, como o Better Auth ou o Resend.
- **Rota de layout:** uma rota que renderiza um `Outlet` para as rotas filhas e declara `NAMESPACES` compartilhados, por exemplo `admin.tsx`.
- **Prefixo de locale:** o segmento de caminho `/<locale>` usado por todos os locales exceto o en-US, por exemplo `/pl-PL`.
- **Middleware:** uma função que roda antes do handler de uma server function: `withRequest`, `authorized` ou `withRateLimit`.
- **Módulo:** uma pasta em `src/modules` que é dona de uma tabela do banco de dados e dos casos de uso dela.
- **Mutation options:** o objeto `mutationOptions` exportado ao lado de uma server function que altera dados.
- **Namespace:** um arquivo de tradução, identificado pelo nome do arquivo, por exemplo `pages.admin.users`.
- **Rota de página:** uma rota que renderiza uma página e declara um único `NAMESPACE`.
- **Pré-renderização:** a renderização das páginas públicas em HTML durante o build, para que o Worker possa servi-las como assets estáticos.
- **Query options:** o objeto `queryOptions` exportado ao lado de uma server function que lê dados. Loaders e componentes o compartilham.
- **Namespaces raiz:** `common`, `components.*` e `errors*`, pré-carregados em todas as páginas.
- **Server function:** uma operação RPC tipada, criada com `createServerFn`, que sempre roda no servidor.
- **Caso de uso:** uma operação sobre a tabela de um módulo, em `use-cases/<verb>-<noun>.ts`.
- **Ambiente Wrangler:** um dos ambientes `development`, `preview`, `production` ou `test` definidos em `wrangler.jsonc`, cada um com seus próprios bindings e secrets.
