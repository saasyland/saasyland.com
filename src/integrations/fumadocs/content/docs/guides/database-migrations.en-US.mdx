## Workflow

1. Edit `platform/db/schema.ts`
2. `bun run db:generate`
3. Review SQL under `platform/db/migrations`
4. `bun run db:migrate`

Use pooled `DATABASE_URL` at runtime; prefer unpooled for DDL when available.
