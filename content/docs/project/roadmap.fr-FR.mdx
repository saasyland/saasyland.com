## CLI

Disponible maintenant : `activate`, `whoami` et `deactivate` gèrent une clé de licence sur un appareil et en CI (voir le [guide de la CLI](/docs/cli)).

À venir :

- La génération de projets avec `init`, en commençant par la stack par défaut que signale le [configurateur](/#cli) de la page d’accueil : la stack sur laquelle tourne cette application
- Les autres options et extras que liste le configurateur
- `change`, pour modifier les réponses d’un projet généré, `update`, pour le passer à une version plus récente, et `status`
- La version stable sur le tag par défaut de npm

## Offres

Chaque carte d’offre de la [section des tarifs](/#pricing) indique ce qui est disponible maintenant et ce qui est à venir. `TIER_FEATURES` dans `src/data/marketing.ts` contient ce partage. À venir :

- Core : le code source généré de l’application avec uniquement les modules choisis, Better Auth, Polar et Resend déjà branchés, la suite de tests avec son seuil de 100 % et les projets illimités sous licence commerciale
- Complete : la formation vidéo du dossier vide à la production, et l’explication du code module par module
- Agency : les projets clients illimités, les places d’équipe pour le cours et reactprojects.com, la chaîne Discord privée et les fichiers Figma pour le concepteur de pages
