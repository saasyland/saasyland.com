Клонуйте репозиторій, а потім виконайте встановлення з його кореня за закоміченим lock-файлом:

```sh
bun install --frozen-lockfile
```

Після цього скрипт життєвого циклу `prepare`:

1. Запускає `vp config --no-agent`, що встановлює диспетчер Git-хуків для `.vite-hooks/` (перевірки pre-commit і хук повідомлення коміту).
2. Запускає `bun run generate:cn`, що будує таблиці злиття класів у `.source/cn-tables.ts`.
3. Запускає `bun run content`, що генерує колекції Fumadocs у `.source/`.

Якщо ви встановлюєте з `--ignore-scripts`, як це робить CI, після цього запустіть `bun run typegen`. Він також перегенеровує `src/types/worker-configuration.d.ts` з `wrangler.jsonc`.

## Додатково

```sh
bun run test:e2e:install
bun run skills:sync
```

Перша команда встановлює Chromium і WebKit для Playwright; друга відновлює [навички агентів](/docs/tooling/agent-skills).
