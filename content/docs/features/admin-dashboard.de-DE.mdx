## Admin-Shell

`src/routes/admin.tsx` schützt jede Admin-Seite mit `requireAdmin` und lädt die gemeinsamen Admin-Namespaces vorab. Das Layout rendert:

- `AdminSidebar`, `AdminBreadcrumbs` und `AdminCommandPalette` (Öffnen mit ⌘K), alle aufgebaut aus `ADMIN_NAVIGATION` in `src/data/navigation.ts`, das die Einträge der Bereiche samt Icon gruppiert: Überblick (Dashboard, Analytics), Angebote (Produkte, Preismodelle), Inhalte (Blog, Kurse, Videos, Landingpage) und Verwaltung (Benutzerverwaltung, Zahlungen, Einstellungen).
- Das Benutzer-Widget im Fußbereich der Seitenleiste mit einem Link zu den Einstellungen und `SignOutButton`.

## Dashboard

`/admin` (`src/routes/admin.index.tsx`) lädt im Loader `getUsersQuery` und die Query jeder Dashboard-Statistik vorab und setzt drei Widgets aus `src/presentation/components/custom/admin/dashboard` zusammen:

- `DashboardStats` (live): die Statistiken von `ADMIN_DASHBOARD_STATS`, nach ihrem `order` sortiert: die Anzahl der Benutzer und die Benutzer, deren E-Mail-Bestätigung noch aussteht, aus `src/data/auth.dashboard.ts` sowie die Anzahl der Produkte aus `src/data/products.dashboard.ts`.
- `RevenueChart` (Demo): ein statisches SVG mit festen Achsen; die Zeitraum-Schaltflächen haben keine Funktion.
- Eine Benutzerkarte (live): die neuesten Benutzer mit Suche und Statusfiltern, <RepositoryFact name="adminPreviewPageSize" /> Zeilen pro Seite.

```tsx
<DataTable
  columns={dashboardUserColumns}
  data={users.rows}
  filters={[
    { columnId: "user", placeholder: t("users.search"), type: "search" },
    {
      columnId: "status",
      label: t("users.filters.status"),
      options: USER_STATUSES.map((status) => ({ label: t(`users.table.status.${status}`), value: status })),
      type: "select",
    },
  ]}
  options={{ initialState: { pagination: ADMIN_DASHBOARD_PREVIEW_PAGINATION }, selectable: true }}
/>
```

Die Tabelle arbeitet im Browser mit der ersten Seite von `getUsersQuery` (<RepositoryFact name="defaultPageSize" /> Benutzer). **Alle anzeigen** verlinkt auf `/admin/users`, wenn es weitere Benutzer gibt. **Produkt hinzufügen**, der Eintrag des Produktbereichs in `ADMIN_DASHBOARD_ACTIONS`, verlinkt auf `/admin/products/create`; **Letzte 30 Tage** ist deaktiviert und **Exportieren** ist nicht angebunden.
