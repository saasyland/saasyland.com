- Changed: the header loads its pages, **Pricing**, **Courses**, **Blog**, **Docs** and **Sign in**, once the page you are on has loaded and the browser is idle, and again after each navigation, so a click, a tap in the phone menu or a key press opens them without waiting for a new Worker isolate. A click on **Docs**, which took 1.1 to 2.1 seconds whenever a docs server function met a new isolate, now waits for no server function. Nothing is preloaded with data saver on, and every other link keeps preloading on hover. `defaultPreloadStaleTime` is now the same as `defaultStaleTime`, so a click reuses the preloaded page instead of running the docs and blog server functions again. See [Performance](/docs/conventions/performance#the-headers-pages-load-before-a-click).
