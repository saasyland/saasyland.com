- 変更: 国、通貨、ロケール、タイムゾーン、価格のカタログを `src/modules/_core/constants` に、グラフの期間を `src/modules/_core/utils/time-series.ts` に戻しました。Zod フィールドと、注文・商品・サブスクリプションのスキーマがこれらの上に作られているためです。`REPOSITORY_FACTS` は `src/lib/repository-facts.ts`、Polar の定数は `src/integrations/polar/polar.constants.ts` にあります。[Core 共有カーネル](/docs/architecture/core)を参照してください。
- 変更: `src/data` には定数とリテラルの一覧だけを置き、そこにあるファイルが関数を export するか Zod を import すると `src/__test__/source-layout.test.ts` が失敗します。ルートの検索スキーマは `auth.zod.ts` と `license.zod.ts`、パスのヘルパーは `src/lib`、プランの価格と機能は `src/data/license.ts` にあります。[ディレクトリ構成](/docs/architecture/directory-structure)を参照してください。
- 変更: `bun run db:seed:local` はエリアごとに `LOCAL_SEEDS` の要素を 1 つずつ実行し、管理者とコースは `scripts/seed-local-admin.ts` と `scripts/seed-local-courses.ts` から投入します。`bun run check:areas` は、シード、ランディングページのコース紹介、レッスンの資料に、エリアを外すときに取り除けないものをもう見つけません。[データベース](/docs/tooling/database)を参照してください。
