- 追加: ランディングページの[CLI 構成ツール](/docs/features/landing-page#cli-configurator)は、最初に UI ライブラリを尋ねます。React を選択でき、Angular、Vue、Svelte、Solid はテンプレートが生成するまで砂時計付きで表示されます。コマンドは `--library react` から始まるようになりました。
- 追加: フレームワークの質問は、各フレームワークをそれが動作する UI ライブラリの下に並べます。React の下に TanStack Start、Next.js、React Router、Angular の下に Analog と Angular SSR、Vue の下に Nuxt、Svelte の下に SvelteKit、Solid の下に SolidStart で、Solid のグループは TanStack Start の名前も挙げます。選べるのは選んだライブラリのフレームワークだけで、テンプレートがまだ生成しないものにはすべて砂時計が付きます。
- 追加: 提供予定のランタイムに Deno が加わりました。Bun と同じく Cloudflare では除外され、Vercel でも除外されます。
- 変更: Web サイトは `@saasyland/stack` 0.1.0-beta.5 を使い、CLI の質問、オプション、ルール、フラグをそこから、テンプレートの対応状況、終了コード、環境変数、認証情報のディレクトリを `@saasyland/stack/cli` から取り込みます。`src/data/cli.ts` に独自の写しを持つことはなくなりました。プロバイダーの質問は、CLI と同じ順に、Postgres のプロバイダーを SQLite のプロバイダーより先に並べます。
