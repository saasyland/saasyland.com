title: "プロバイダー"

---

`src/providers` には 4 つのプロバイダーがあります。各プロバイダーは、それを利用するコンポーネントにできるだけ近い位置にマウントします。

| プロバイダー           | ラップするもの                                                                                                            | マウント位置                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `TranslationsProvider` | root とマッチしたルートの名前空間、名前付きの日付フォーマット、ユーザーのタイムゾーンを渡した、use-intl の `IntlProvider` | root シェル内で、ドキュメントの body を囲む                                        |
| `AriaProvider`         | React Aria の `I18nProvider` と `RouterProvider`                                                                          | root コンポーネント内で、すべてのルートを囲む                                      |
| `ThemeProvider`        | クッキーに保存する `@wrksz/themes` のプロバイダー                                                                         | root の `Toaster` と、ドキュメントサイドバーのテーマ切り替えを囲む                 |
| `MotionProvider`       | Motion の `LazyMotion`（strict）と、`reducedMotion="user"` を指定した `MotionConfig`                                      | ランディングページ、ブログのインデックス、ブログのアーカイブページ、`LicenseOffer` |

## root の構成

`src/routes/__root.tsx` は、`shellComponent` でドキュメントを、`component` でアプリケーションを描画します。

```tsx
const RootComponent = () => (
  <AriaProvider>
    <OfflineBanner />
    <AffiliateReferral />
    <Outlet />
    <ThemeProvider>
      <Toaster />
    </ThemeProvider>
  </AriaProvider>
)
```

- **TranslationsProvider** はシェルの `<body>` 内にあるため、デフォルトのエラーと not-found の各コンポーネントやルートのスケルトンを含め、すべての画面が翻訳されます。root 名前空間と、マッチした各ルートの `staticData.namespaces` から名前空間を集め、`useSuspenseQueries` で読み込んで 1 つのメッセージツリーを構築します。また、`I18N.FORMATS` と、`TIME_ZONE_HOOKS` の最初のフックが返すタイムゾーン（フックがなければ `UTC`）も渡します。そのフックは `useSessionTimeZone` で、ルートガードが読み込んだセッションを読み（セッションがなければ `UTC`）、セッションを自分で取得することはありません。[国際化とロケール](/docs/features/internationalization)を参照してください。
- **AriaProvider** は、現在のロケールを React Aria に渡し、React Aria のリンクを TanStack Router に接続します。`useHref` がパスをローカライズするため、React Aria コンポーネントの `href` にはロケールプレフィックスが付きます。
- **ThemeProvider** はルートのアウトレットをラップしません。ハイドレーション後に更新されるプロバイダーはすべてのページを再レンダリングしてしまうため、必要なコンポーネントだけをラップします。初期テーマは、ドキュメントの head にある `ThemeScript` がハイドレーションの前に適用します。
- **MotionProvider** は `domMax` の機能バンドルをオンデマンドで読み込み、アニメーションを実行する場所にだけマウントされます。対象は `_site._marketing.index.tsx`、`_site._marketing.blog.index.tsx`、`_site._marketing.blog.page.$page.tsx`、そして `/app` と `/app/license` のプランのカードである `license-offer.tsx` です。Bun による `framer-motion` 14.14.0 へのパッチにより、`LazyMotion` は読み込めなかったバンドルを無視します。たとえば訪問者がページを離れるために Safari が読み込みを中止しても、ページは未処理の拒否を報告せず、コンポーネントはアニメーションなしでレンダリングされます。
- **AffiliateReferral** はプロバイダーではありません。アウトレットの隣に置かれ、アフィリエイトプログラムが開いていて（`AFFILIATE_PROGRAM`）、訪問に紹介パラメーターが付いているときだけ Affonso のスクリプトをレンダリングします（[アフィリエイトプログラム](/docs/features/affiliates)）。

## プロバイダーコンポーネントではないもの

- **QueryClient。** `src/router.tsx` がリクエストごとに作成し、ルーターのコンテキストに入れて、`setupRouterSsrQueryIntegration` で接続します。
- **Fumadocs。** `/docs` レイアウトは、Fumadocs 独自のテーマ処理を無効にした状態で、Fumadocs の `RootProvider` をマウントします。
- **ドラッグ後の押下。** Safari は、ドラッグ＆ドロップのたびに、次のマウスボタンの押下を `pointerdown` ではなく `pointermove` として報告します（[WebKit のバグ 202287](https://bugs.webkit.org/show_bug.cgi?id=202287)）。そのため、`pointerdown` で押下を始める React Aria は、ドラッグ後の最初のクリックを無視していました。ルートコンポーネントは、`src/lib/lost-pointer-down.ts` の `restoreLostPointerDowns` をエフェクトで実行します。ほかのボタンを押していない状態でメインのマウスボタンの押下を報告する `pointermove` は、ほかのどのブラウザーも送らないため、これに対して欠けている `pointerdown` を同じ位置で発生させます。
