## CLI

提供中：`activate`、`whoami`、`deactivate` で、端末と CI のライセンスキーを管理できます（[CLI ガイド](/docs/cli)を参照）。

提供予定：

- `init` によるプロジェクト生成。ランディングページの[構成ツール](/#cli)で選択できるオプションから始めます
- テンプレートが生成するまで構成ツールで無効として表示される、その他のオプションと追加機能
- 生成したプロジェクトの回答を変更する `change`、新しいリリースに更新する `update`、そして `status`
- npm の既定タグでの安定版リリース

## プラン

[料金セクション](/#pricing)の各プランのカードには、提供中のものと提供予定のものが並んでいます。この区分は `src/data/marketing.ts` の `TIER_FEATURES` が持っています。提供予定：

- Core：選んだモジュールだけを含む生成されたアプリケーションのソースコード、接続済みの Better Auth・Polar・Resend、100% のしきい値付きのテストスイート、商用ライセンスでの無制限のプロジェクト
- Complete：空のフォルダから本番運用までの動画コースと、モジュールごとのコード解説
- Agency：無制限の顧客案件、コースと reactprojects.com のチーム席、プライベートな Discord チャンネル、ページデザイナー向けの Figma ファイル

## アプリケーション

- 管理画面のアナリティクス、決済、料金モデル、ブログ、招待、ロールの各画面とダッシュボードの売上グラフのデモデータを実データに置き換える
- 管理画面から商品と料金モデルを管理する
- 管理画面からブログとドキュメントを編集する
- `/admin/landing-page` の背後にあるビジュアルなページデザイナーと、投稿エディター
- 残りの商品と設定の操作を接続する
- 組織とチーム

## 長期

- ストアフロントでの販売
- 高度なアナリティクスのパイプライン
- プレミアムコンテンツのより細かなアクセス制御

GitHub の Issue とプルリクエストでのコントリビューションを歓迎します。
