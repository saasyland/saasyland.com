title: "Two-factor authentication"
description: "TOTP two-factor authentication with backup codes, set up in admin settings."

The Better Auth `twoFactor` plugin runs with `APP_NAME` as the issuer. Its server functions live in `src/modules/two-factor/use-cases`:

| Use case           | Middleware              | Used by                                |
| ------------------ | ----------------------- | -------------------------------------- |
| `enableTwoFactor`  | signed in, rate limited | `TwoFactorPasswordStep`                |
| `disableTwoFactor` | signed in, rate limited | `TwoFactorPasswordStep`                |
| `verifyTotp`       | rate limited            | `TwoFactorVerifyStep`, `TwoFactorForm` |
| `verifyBackupCode` | rate limited            | `TwoFactorForm`                        |

## Setup

**Settings → Security** in `/admin/settings` renders `TwoFactorDialog` (`src/presentation/components/custom/admin/settings`):

1. The password step calls `enableTwoFactor` and receives the TOTP URI and backup codes.
2. The verify step shows the secret from the URI (`extractTotpSecret`) for manual entry in an authenticator app and confirms a <RepositoryFact name="twoFactorCodeLength" />-digit code with `verifyTotp`.
3. The last step shows the backup codes.

When 2FA is on, the same button opens the password step with `disableTwoFactor`. The button reads `twoFactorEnabled` from the current session.

## Sign-in challenge

For an account with 2FA, Better Auth answers the sign-in with `twoFactorRedirect`, and `SignInForm` opens `/auth/two-factor`, keeping `redirect`. `TwoFactorForm` accepts a <RepositoryFact name="twoFactorCodeLength" />-digit code (`InputOTP`) or, after switching, a backup code, and sends `trustDevice: true`. On success `finishSignIn` from `useAuthRedirect` continues to `/auth/callback`.

Code lengths are in `auth.constraints.ts`: `TWO_FACTOR_CODE_LENGTH` is <RepositoryFact name="twoFactorCodeLength" />, backup codes are <RepositoryFact name="backupCodeMinLength" /> to <RepositoryFact name="backupCodeMaxLength" /> characters.
