## Tools

| Tool    | Version                         | Why                                                                                                           |
| ------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Bun     | 1.4.0                           | Package manager and script runner; `packageManager` in `package.json` and CI pin it                           |
| Node.js | 24.11 or newer in the 24.x line | Vite+ accepts `^22.18.0`, `^24.11.0` or `>=26.0.0`; CI uses Node 24, and the test database uses `node:sqlite` |
| Git     | Any recent version              | The install step sets up Git hooks                                                                            |

Wrangler, drizzle-kit, Playwright and the Vite+ CLI are dev dependencies; run them through the package scripts or `bunx`. Browser tests also need the Playwright browsers from `bun run test:e2e:install`.

## Accounts

The isolated test preview and all automated tests need no accounts or credentials. Development and deployment use real services:

- A Cloudflare account with D1, KV and Workers. The dev server connects to remote preview resources.
- GitHub and Google OAuth apps for social sign-in.
- Resend with a verified sender. Email sign-up requires a verified address, so sign-up does not work without it.
- Polar, using the sandbox for development, with three products for the Core, Complete and Agency tiers.
