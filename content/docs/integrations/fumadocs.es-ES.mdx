---
title: "Fumadocs"
description: "Colecciones MDX para la documentación y el blog, fuentes localizadas y búsqueda."
---

Fumadocs convierte `content/docs` y `content/blog` en árboles de páginas localizados. `bun run content` ejecuta `fumadocs-mdx` y escribe `.source/`; `dev`, `typegen` y todos los scripts de compilación lo ejecutan primero.

| Archivo              | Propósito                                                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `fumadocs.config.ts` | La colección `docs` y la colección `blog` con su esquema de frontmatter                                                                                |
| `fumadocs.i18n.ts`   | Los nueve idiomas de `I18N`, `en-US` como idioma predeterminado y de reserva, el parser `dot` para `<slug>.<locale>.mdx` y el prefijo de idioma oculto |
| `fumadocs.source.ts` | `source` en `/docs` con el plugin de iconos de Lucide, `blogSource` en `/blog` y `getPublishedBlogPosts` con el tiempo de lectura                      |
| `fumadocs.docs.ts`   | La función de servidor `getDocsPage`, `loadDocsPage` y `docsHead` para la ruta `docs.$`                                                                |
| `fumadocs.search.ts` | El índice de búsqueda servido por `/api/search`                                                                                                        |

El prefijo de idioma se oculta en las URL de Fumadocs porque lo añade el router. El frontmatter del blog exige `title`, `authorName` y `date`, y acepta `description`, `excerpt`, `faq`, `featured`, `image`, `published`, `tags`, `updated` y `authorImage`.

## Componentes

`src/presentation/components/custom/mdx.tsx` asigna los componentes MDX: los predeterminados de Fumadocs (incluidos `Cards` y `Callout`), `Accordions`, `Steps` y `Tabs`, y los componentes de shadcn `Alert`, `Badge`, `Button`, las partes de card, `Separator` y `Table`. Los enlaces internos se localizan con `localizePathname`. `docs-content.tsx` y `blog-content.tsx` renderizan las páginas.

## Reglas de contenido

Cada página existe una vez por idioma como `<slug>.<locale>.mdx`, y cada carpeta tiene un `meta.<locale>.json` con el mismo array `pages` en todos los idiomas. `icon` en un archivo meta admite el nombre de un icono de Lucide. `scripts/check-content.ts`, que forma parte de `bun run check:i18n`, falla cuando falta una traducción, un bloque de código es distinto, la navegación es distinta o queda un párrafo en inglés en otro idioma.
