## Database

**`no such table` in `bun run dev`.** The `development` environment uses the remote preview D1 database. Apply the migrations there with `bun run db:migrate:development`. `bun run db:migrate:local` only migrates a local database that `bun run dev` does not use.

**`no such table` in Playwright.** Browser tests use their own local database. Run `bun run db:reset:test`, or let Playwright start the app, which runs it.

**Vitest tables are out of date.** The D1 mock applies every SQL file in `src/integrations/drizzle-orm/migrations` at startup. After a schema change, generate a migration with `bun run db:generate`.

## Development server

**The dev server does not start.** It listens on `localhost:3000` with `strictPort`, so it fails when the port is busy. Stop the other process.

**Sign-in or OAuth fails.** Check `AUTH_SECRET` and the OAuth client credentials in the environment file, and that the provider's callback URL points to <RepositoryFact name="oauthCallbackPath" /> on the host you use. Better Auth only accepts the hosts configured for the build mode: `localhost:3000` and `127.0.0.1:3000` in development.

**Worker types are missing a binding or secret.** Run `bun run cf-typegen` after changing `wrangler.jsonc`: it types every binding and every secret in `secrets.required`. A value Wrangler cannot derive, such as a variable that only `test` sets, goes into the area's `src/types/<area>.d.ts`.

**Custom `text-*` classes disappear when merged.** `cn` depends on tables generated from `src/lib/cn.config.ts`. `bun run dev`, `bun run check` and the builds regenerate them; run `bun run generate:cn` if `.source/cn-tables.ts` is missing.

## Translations

**`No messages/<locale>/<namespace>.json`.** A route declares a namespace that has no file for that locale. Create the file in every locale.

**A key renders as its path, or `check:i18n` reports a missing key.** The key is missing in one locale, or the component reads it outside the scope of its `useTranslations` call. Use a single `useTranslations` per component and run `bun run check:i18n`.

## Documentation

**A docs page returns 404.** The file must be named `<page>.<locale>.mdx` and listed in `pages` of the folder's `meta.<locale>.json`. Run `bun run content` to regenerate `.source`.

**`check-content.ts` fails.** It compares every locale with en-US. `Changed code examples` means a code block differs from the English one; code blocks must be identical. `Untranslated English paragraph` means a paragraph was copied without translating it. `Missing <file>` means a locale file does not exist. `leaves out … from the English page` and `adds …, which the English page does not have` mean that a translation dropped or added inline code, a component or one of its props, or a link to another page; copy it as the English page has it. `has … table rows where the English page has …` means that a table lost or gained a row. `links to … instead of …` means an internal link that the site would redirect or that names a locale; write the path the message suggests.

**`check-message-formats.ts` fails.** `changed the path or command …` means that a translation changed a file path or a command of the English message; keep it as it is, or pass it as an ICU argument from `REPOSITORY_FACTS`. `unexpected Markdown code` means that a translation added backticks, which a message prints as they are.

## Tests and deployment

**`test:coverage` fails.** Coverage must be <RepositoryFact name="coverageThreshold" unit="percent" /> for lines, statements, functions and branches. The report in `coverage/` lists the uncovered lines.

**Deploy stops at `verify-bindings.ts`.** The target environment in `wrangler.jsonc` lacks a binding that the `development` environment declares (`DB`, `CACHE`, `MEDIA` or `BUNDLES`), still has placeholder D1 or KV IDs, or, for production, shares a resource with preview. Create the resources in Cloudflare and replace the IDs.

**Deploy stops at `polar:verify`.** Polar does not match the code: a key in `.env.<environment>` is missing or names the wrong Polar service, the token is rejected or lacks a scope, or a product, price, licence key, regional discount or webhook differs from what the code expects. The error lists each problem; [Polar setup](/docs/getting-started/polar-setup) explains every message. `bun run polar:verify:<environment>` runs the check again.

**Deploy stops at `prepare-deploy-secrets.ts`.** A key listed in the environment's `secrets.required` is missing or empty in `.env.<environment>`. The error names the keys.

**Deploy stops at `verify-deployment.ts`.** The Worker is deployed, but a checked path did not answer `200` with the expected content type, or a sign-in did not reach its provider as it should. The error lists each request and what was wrong; open the URL and read the Worker's logs in Cloudflare. A line ending in `client_id is not a Google OAuth client ID.` means that the Worker holds no real client ID for that provider; see the next entry. `bun scripts/verify-deployment.ts <preview|production>` runs the check again.

**Google answers `Error 401: invalid_client` and `The OAuth client was not found.`** The Worker sent Google a client ID that Google does not know, such as a placeholder in `.env.<environment>` that the deploy uploaded as the `AUTH_GOOGLE_CLIENT_ID` secret. To fix it:

1. In the Google Cloud console, open **Google Auth Platform → Clients** and create a client of type **Web application**, or open the one you want to use. Its client ID ends in `.apps.googleusercontent.com`.
2. Add `https://<host>` to **Authorized JavaScript origins** and <RepositoryFact name="googleCallbackUrl" /> to **Authorized redirect URIs** for every host you deploy to; Google can take a few minutes to apply them.
3. On **Google Auth Platform → Audience**, select **Publish app**, so that every Google account can sign in, not only the test users.
4. Put the client ID and secret into `AUTH_GOOGLE_CLIENT_ID` and `AUTH_GOOGLE_CLIENT_SECRET` in `.env.<environment>` and run `bun run deploy:<environment>`, which uploads both Worker secrets and checks the sign-in again.

**A prerender build fails.** The build output names the first URL that failed. Open that page with `bun run dev` to see the error.
