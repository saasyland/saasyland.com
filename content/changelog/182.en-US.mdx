- The footer links the Instagram profile, `APP_INSTAGRAM_URL`, next to the GitHub repository, and opens it in a new tab like the GitHub link. The home page describes the organisation in JSON-LD, as Google recommends for the home page: an `Organization` with its name, URL, contact address and, in `sameAs`, its profiles on GitHub and Instagram; blog posts name the same organisation as their `publisher`. `sameAs` names the GitHub organisation, `APP_GITHUB_OWNER_URL`, from which `APP_GITHUB_URL` is now derived, because the repository is not a profile.
