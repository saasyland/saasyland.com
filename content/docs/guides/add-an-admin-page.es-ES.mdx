title: Añadir una página de administración.
description: Registrar rutas, barra lateral y estructura de página.
---

## Pasos.

1. Añadir la ruta a `ROUTES`.
2. Añadir una entrada en la barra lateral en `admin/constants/sidebar.ts` (+ etiquetas de i18n).
3. Crear `app/[locale]/(admin)/admin/<feature>/page.tsx`
4. Coloca `_components` / `_lib`.
5. Datos de acceso con casos de uso + Suspense.
6. Documento en la sección de Características.
