---
title: Fügen Sie eine Funktion hinzu.
description: Fügen Sie eine Funktion hinzu – SaaSy Land.
---

Erstellen oder erweitern Sie das Schema, die Validierungsregeln, die Konstanten und die Anwendungsfälle des zugehörigen Moduls. Fügen Sie eine flache Route unter `src/routes` hinzu, einschließlich der Berechtigungsprüfung, der validierten Suchparameter, der Metadaten und des Namespace-Preloads. Platzieren Sie die Benutzeroberfläche der Funktion unter `presentation/components/custom/{feature}` zusammen mit zugehörigen Komponenten, Hooks und Konstanten.

Führen Sie unabhängige Datenabfragen im Loader zusammen, rendern Sie diese aus dem gemeinsamen QueryClient-Cache und übermitteln Sie sie über die nativen Mutationsoptionen. Fügen Sie Schlüssel für alle neun konfigurierten Sprachen zusammen. Behalten Sie das bestehende Layout und die zugänglichen Basiselemente bei, und überprüfen Sie anschließend die Funktionalität, das Verhalten der Komponente und die Browserperformance auf der entsprechenden Ebene.
