---
title: "Introducción"
description: "Adaptadores de proveedores en src/integrations."
---

Cada carpeta de `src/integrations/<vendor>/` encapsula un proveedor en archivos `<prefix>.<concern>.ts`, donde el prefijo es el nombre corto del proveedor (`auth`, `drizzle`, `i18n`, `form`): configuración, clientes y adaptadores ligeros. Las reglas de negocio y las operaciones de base de datos permanecen en `src/modules`, y los componentes nunca importan directamente un cliente de un proveedor.

| Carpeta          | Archivos                                                                                                                                                                        | Propósito                                                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `affonso`        | `affonso.constants.ts`, `affonso.program.ts`, `affonso.referral.ts`                                                                                                             | Parámetros de referido de afiliados, el ID del programa y los metadatos del checkout                                                                      |
| `better-auth`    | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.roles.ts`, `auth.session.ts`                                                | Sesiones, OAuth, plugins, guardas de ruta, middleware de funciones de servidor, roles y permisos                                                          |
| `drizzle-orm`    | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `drizzle.local.config.ts`, `drizzle.errors.ts`, `drizzle.columns.ts`, `drizzle.time-series.ts`, `migrations/` | Cliente de D1, barrel de esquemas, configuración de drizzle-kit, `rethrowAsConflict`, `timestamps()`, `bucketOf`                                          |
| `fumadocs`       | `fumadocs.config.ts`, `fumadocs.schema.ts`, `fumadocs.i18n.ts`, `fumadocs.indexes.ts`, `fumadocs.docs.ts`, `fumadocs.blog.ts`, `fumadocs.changelog.ts`, `fumadocs.icons.ts`     | Colecciones de documentación y blog, índices generados en el build, búsqueda, las entradas del changelog y los iconos de la barra lateral                 |
| `motion`         | `motion.features.ts`, `motion.tokens.ts`                                                                                                                                        | Funcionalidades de Motion cargadas de forma diferida y transiciones compartidas                                                                           |
| `polar`          | `polar.config.ts`, `polar.constants.ts`, `polar.customers.ts`, `polar.webhooks.ts`, `polar.vite.ts`                                                                             | Cliente del SDK de Polar, valores propios de Polar, cuentas de clientes, el código al que llega cada evento de webhook y el ajuste de compilación del SDK |
| `resend`         | `resend.config.ts`, `resend.utils.ts`                                                                                                                                           | Cliente de Resend, `sendEmail` y `EMAIL_PURPOSE`                                                                                                          |
| `takumi`         | `takumi.fonts.ts`, `takumi.render.tsx`                                                                                                                                          | Renderiza las tarjetas sociales y el logotipo de la organización durante el build con las fuentes del propio sitio                                        |
| `tanstack-form`  | `form.fields.ts`, `form.submit.ts`                                                                                                                                              | `fieldErrorMessage` para los errores de los campos de formulario, y `submitForm` y `showFieldError`, que marcan y enfocan el campo no válido              |
| `tanstack-query` | `query.cache.ts`                                                                                                                                                                | Tiempos de caché por defecto del `QueryClient` de cada petición                                                                                           |
| `use-intl`       | `i18n.config.ts`, `i18n.loaders.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                                                                 | Idiomas, espacios de nombres de mensajes, middleware de idioma, utilidades de URL                                                                         |
| `zod`            | `zod.config.ts`                                                                                                                                                                 | Ejecuta Zod en modo `jitless` en el navegador, para que nunca intente usar `eval` bajo la Content Security Policy                                         |
