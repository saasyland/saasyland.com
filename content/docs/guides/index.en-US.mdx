Each guide covers one task from start to finish and names the files it touches. Begin with [Add a feature](/docs/guides/add-a-feature) for the full path from database table to finished page.

## Build features

- [Add a feature](/docs/guides/add-a-feature): end-to-end walkthrough that links the guides below.
- [Add a module](/docs/guides/add-a-module): a new database table with its schema, validation, constants and types.
- [Add a use case](/docs/guides/add-a-use-case): one operation with its server function, query or mutation options and cache invalidation.
- [Server functions](/docs/guides/server-functions): how `createServerFn`, middleware, validation and the RPC call work.
- [Add an admin page](/docs/guides/add-an-admin-page): route, sidebar entry, messages and widgets.
- [Add a data table](/docs/guides/add-a-data-table): columns and the generic `DataTable`.
- [Forms and validation](/docs/guides/forms-and-validation): TanStack Form with the module Zod schema.
- [URL state](/docs/guides/url-state): validated search parameters.
- [Add an API route](/docs/guides/add-an-api-route): HTTP handlers for external callers.

## Content and presentation

- [Internationalization and locales](/docs/guides/i18n-messages): namespaces, keys and the translation checks.
- [Email templates](/docs/guides/email-templates): React Email templates sent from use cases.
- [Theming and branding](/docs/guides/theming-and-branding): name, domain, theme tokens and fonts.

## Authentication and security

- [Authentication flows](/docs/guides/auth-flows): sign-in, sign-up, verification, password reset, two-factor and OAuth.
- [Roles and permissions](/docs/guides/roles-and-permissions): statements, roles and where they are checked.
- [Security checklist](/docs/guides/security-checklist): what to verify before shipping a change.

## Quality and operations

- [Writing tests](/docs/guides/writing-tests): Vitest projects, the 100% coverage gate and Playwright.
- [Database migrations](/docs/guides/database-migrations): generating and applying D1 migrations.
- [Local debugging](/docs/guides/local-debugging): local environments, logs and data inspection.
