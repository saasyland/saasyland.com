The app exposes three HTTP routes, declared with `server.handlers` on `createFileRoute` in `src/routes/api`:

| Route         | Methods   | Handler                                                                                                                                                      |
| ------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `/api`        | GET       | Returns `{ "runtime": "cloudflare-workers" }`.                                                                                                               |
| `/api/auth/$` | GET, POST | Better Auth: sign-in, OAuth callbacks, `/api/auth/verify-email`, plus the Polar plugin endpoints `/api/auth/polar/webhooks` and `/api/auth/customer/portal`. |
| `/api/search` | GET       | Fumadocs search (`fumadocs.search.ts`).                                                                                                                      |

```ts
import { createFileRoute } from "@tanstack/react-router"

import { auth } from "~/src/integrations/better-auth/auth.server"

export const Route = createFileRoute("/api/auth/$")({
  server: { handlers: { GET: ({ request }) => auth.handler(request), POST: ({ request }) => auth.handler(request) } },
})
```

## Server functions instead of REST

Application operations are `createServerFn` functions in `src/modules/<table>/use-cases`. The others live in `src/lib` (`getStarCount` in `github.ts`), in an integration (`getCurrentSession` in `auth.session.ts`, `getDocsPage` in `fumadocs.docs.ts`) or inline in the single route that uses them (`getBlogPosts` in `blog.index.tsx`). TanStack Start calls them over RPC under `/_serverFn`, with middleware for sessions, permissions and rate limits. Do not add a REST endpoint for an operation that only this app calls; add an HTTP route only for external callers such as webhooks, and verify their signatures in the provider integration.

## Behaviour

- The Worker skips locale redirects for `/api` and `/_serverFn`. Their URLs carry no locale, so `getCurrentLocale()` returns `en-US` for them on the server; code that needs a locale receives it as input or reads it from a `callbackURL`.
- The build does not prerender `/api`.
- Handler tests live in `src/routes/api/__test__/handlers.test.ts`.
