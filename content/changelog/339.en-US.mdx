- Added: each lesson's **Video** card in the lesson editor (**Content → Courses**) takes its recording by drag and drop or a file picker. The recording goes to R2 in parts with its progress, an interrupted upload continues from the parts already stored, and the card follows it through the encoder (`bun run video:encode:<environment>`) to a player. **Replace video**, **Delete video** and **Use an existing video** work on the lesson itself. See [Videos](/docs/features/videos).
- Added: **This lesson has no video** makes a lesson a text lesson. The course pages list it as a **Text lesson**, count it as ready and let learners mark it complete, and course export and import keep it. See [Courses](/docs/features/courses#text-lessons).
- Removed: the **Videos** admin page and its menu entry. Its library is now the **Use an existing video** dialog of each lesson, which shows how many lessons use each video and deletes the ones no lesson uses. The placeholder switch is gone too: a video lesson without a video shows **Coming soon** on its own.
- Fixed: a dialog taller than the window scrolls, so the buttons at the end of a long form stay within reach.
