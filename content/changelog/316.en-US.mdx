- Added: `bun run deps:update` updates every dependency with a range to its latest release, Vite+ through `vp migrate`, and the agent skills in one command, then names the pinned packages that have a newer release. See [Dependencies](/docs/conventions/dependencies#upgrading).
- Added: `bun run check` fails when a package that an agent skill documents, such as `resend`, `better-auth` or `wrangler`, moved without `bun run skills:update`, and when the installed skills differ from `skills-lock.json`. `SKILL_SOURCES` in `src/data/skills.ts` maps each skill source to the packages it documents. See [Agent skills](/docs/tooling/agent-skills#drift-checks).
- Added: the weekly `updates.yml` workflow lists the available dependency and skill updates in one GitHub issue, which it opens, rewrites and closes. See [CI/CD](/docs/tooling/ci-cd#updates).
- Changed: the `skills` CLI is a development dependency, so `bun.lock` pins the version that installs and hashes the skills.
