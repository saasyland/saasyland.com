---
title: Ajouter une fonctionnalité
description: Ajouter une fonction — SaaSy Land
---

Créer ou étendre le schéma, la validation, les constantes et les cas d'utilisation du module propriétaire. Ajouter un itinéraire plat sous `src/routes` avec sa permission garde, paramètres de recherche validés, métadonnées et namespace préload. Placer la fonction UI sous `presentation/components/custom/{feature}` avec composants, crochets et constantes à proximité.

Précharger les requêtes de données indépendantes ensemble dans le chargeur, rendre à partir du même cache QueryClient, et soumettre par les options de mutation native. Ajoutez les touches pour les neuf langues configurées ensemble. Conserver la mise en page existante et les primitives accessibles, puis vérifier le cas d'utilisation, le composant et le comportement du navigateur au niveau approprié.
