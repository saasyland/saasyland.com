- La documentation ne saisit plus à la main les valeurs que le code définit. `<RepositoryFact>`, qui remplace `<RepositoryCount>`, affiche à partir du code et du build les limites de débit, les longueurs des mots de passe et des codes, les durées de cache, d'interrogation et de signature, les réglages d'encodage vidéo, les limites de lint, de formatage et de couverture, les versions de la chaîne d'outils et les langues prises en charge, et `<RepositoryTable>` affiche les déclarations de permissions, les types de commit et les multiplicateurs de prix régionaux. `scripts/check-content.ts` échoue aussi quand un bloc de code titré n'est pas un extrait de son fichier, quand une page nomme un hôte qu'aucun mode de build n'autorise et quand les tableaux des routes, des scripts ou des variables d'environnement ne concordent pas avec `ROUTES`, `package.json` ou `wrangler.jsonc`.
