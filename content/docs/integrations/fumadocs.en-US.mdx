---
title: "Fumadocs"
description: "MDX collections for the docs and blog, localized sources and search."
---

Fumadocs turns `content/docs` and `content/blog` into localized page trees. `bun run content` runs `fumadocs-mdx` and writes `.source/`; `dev`, `typegen` and every build script run it first. Both collections are `async`: the Worker keeps every page's frontmatter and imports a page's compiled MDX with `page.data.load()` when a request needs its headings or search text (see [Performance](/docs/conventions/performance#keep-the-route-tree-light)).

| File                    | Purpose                                                                                                                                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fumadocs.config.ts`    | The `docs` and `blog` collections, both `async`, the blog's frontmatter schema, and the code highlighting themes and colour replacements                                                                      |
| `fumadocs.i18n.ts`      | The locales from `I18N`, `en-US` as default and fallback, the `dot` parser for `<slug>.<locale>.mdx`, hidden locale prefix                                                                                    |
| `fumadocs.source.ts`    | `source` at `/docs` with the icons of `docsIcon`, `blogSource` at `/blog`, `getPublishedBlogPages`, and `getPublishedBlogPosts` with reading time                                                             |
| `fumadocs.icons.ts`     | `DOCS_ICONS`, the Lucide icons the meta files name, and `docsIcon`, which turns a meta file's `icon` into its icon                                                                                            |
| `fumadocs.docs.ts`      | `getDocsPage` server function, `loadDocsPage` and `docsHead` for the `docs.$` route                                                                                                                           |
| `fumadocs.search.ts`    | The search index served by `/api/search`                                                                                                                                                                      |
| `fumadocs.changelog.ts` | The `changelogEntries` plugin, which replaces `<ChangelogEntries unreleased="…" />` on the changelog page with the entries of `content/changelog` in the page's locale, under the UTC day each reached `main` |

The locale prefix is hidden in Fumadocs URLs because the router adds it. Blog frontmatter requires `title`, `authorName` and `date` and accepts `description`, `excerpt`, `faq`, `featured`, `image`, `published`, `tags`, `updated` and `authorImage`.

## Components

`src/presentation/components/custom/mdx.tsx` maps the MDX components: the Fumadocs defaults (including `Cards` and `Callout`), `Accordions`, `Steps` and `Tabs`, and the shadcn `Alert`, `Badge`, `Button`, card parts, `Separator` and `Table`; `RepositoryFact`, which prints a value measured from the repository at build time or defined in the code, as in `<RepositoryFact name="testFiles" />`, and `RepositoryTable`, which prints a table built from the code, as in `<RepositoryTable name="commitTypes" columns={["Type", "Emoji"]} />`. `TierPrice` prints a tier's list price from `TIER_PRICES` in the page locale, as in `<TierPrice tier="core" />`, so no page types a price. `ActivationLimit` prints a tier's activation limit from `LICENSE_ACTIVATION_LIMITS`, as in `<ActivationLimit tier="core" />`, and `RegionalDiscounts` lists the regional discount percentages derived from `PPP_TIERS`. Internal links are localized with `localizePathname`, and a task list item wraps its checkbox and text in a `label`. `docs-content.tsx` and `blog-content.tsx` render the pages. Fumadocs' own controls, such as the search, **On this page** and the copy buttons, take their text from the `fumadocs` namespace: `useFumadocsI18n` passes it, with the page's locale, to the `RootProvider` of the docs and blog layouts.

## Content rules

Every page exists once per locale as `<slug>.<locale>.mdx`, and each folder has a `meta.<locale>.json` with the same `pages` array in every locale. `icon` in a meta file takes the name of an icon in `DOCS_ICONS`; import a new icon there, and `fumadocs.icons.test.ts` fails when a meta file names one that is not imported or an imported one is no longer named. `scripts/check-content.ts`, part of `bun run check:i18n`, fails when a translation is missing, when its code blocks, inline code, components, links, tables or navigation differ from English, or when an English paragraph remains in another locale.
