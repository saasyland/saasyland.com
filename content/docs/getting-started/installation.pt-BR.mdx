Clone o repositório e, a partir da raiz dele, instale as dependências com o lockfile versionado:

```sh
bun install --frozen-lockfile
```

Em seguida, o script de ciclo de vida `prepare`:

1. Executa `vp config --no-agent`, que instala o dispatcher de hooks do Git para `.vite-hooks/` (verificações de pre-commit e o hook de mensagem de commit).
2. Executa `bun run generate:cn`, que gera as tabelas de mesclagem de classes em `.source/cn-tables.ts`.
3. Executa `bun run content`, que gera as coleções do Fumadocs em `.source/`.

Se você instalar com `--ignore-scripts`, como faz a CI, execute `bun run typegen` depois. Ele também gera novamente `src/types/worker-configuration.d.ts` a partir de `wrangler.jsonc`.

## Extras opcionais

```sh
bun run test:e2e:install
bun run skills:sync
```

O primeiro instala o Chromium e o WebKit para o Playwright; o segundo restaura as [skills para agentes](/docs/tooling/agent-skills).
