description: "Cadena de herramientas, controles de calidad, entornos, pruebas y CI."
---

El repositorio usa Bun como gestor de paquetes y ejecutor de scripts, y Vite+ (`vp`) para el servidor de desarrollo, las compilaciones, las pruebas, el linting y el formateo. Wrangler gestiona los entornos y las migraciones de Cloudflare, y Playwright ejecuta las pruebas en el navegador.

## En este capítulo

- [Entorno y bindings](/docs/tooling/environment): entornos de Wrangler, secretos y archivos de entorno
- [Migraciones de base de datos](/docs/tooling/database): generar, aplicar e inspeccionar migraciones de D1
- [Pruebas](/docs/tooling/testing): proyectos de Vitest, utilidades y el umbral de cobertura del 100 %
- [Lint y formato](/docs/tooling/lint-format): oxlint, oxfmt y los scripts de comprobación
- [Vite+](/docs/tooling/vite-plus): la cadena de herramientas `vp` y sus plugins
- [Playwright](/docs/tooling/playwright): pruebas en el navegador contra el Worker de pruebas aislado
- [Skills para agentes](/docs/tooling/agent-skills): skills de proveedores para agentes de programación
- [CI/CD](/docs/tooling/ci-cd): comprobaciones y despliegues con GitHub Actions
- [Scripts del proyecto](/docs/tooling/scripts): todos los scripts de `package.json`
- [Graphify](/docs/tooling/graphify): un grafo de conocimiento opcional del código base
- [Commits convencionales](/docs/tooling/conventional-commits): formato de los commits y el hook de emojis
