SaaSy Land 2.0 is the source code of the saasyland.com website, its customer workspace and its admin console. One TanStack Start application on Cloudflare Workers combines a multilingual marketing site, documentation and blog, authentication, newsletter subscriptions, and Polar checkout with licence-key management.

The code is written as a real product: modules per database table, typed server functions with their own authorization, one translation namespace per page, 100% test coverage and browser tests in CI. It is for developers who want to study or reuse a production setup of authentication, admin, internationalization and Cloudflare plumbing.

Users, sessions, products and categories are backed by D1. The analytics, payments, blog administration, invitations and roles screens still show demo data from `src/data/`.

The SaaSy Land CLI and its private generator templates are a separate, proprietary product and are not part of this codebase. See [Licence](/docs/project/license).
