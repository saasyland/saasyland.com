Vite+ працює Vitest в трьох проектах: тести вузлів, інтеграційні тести та тести компонентів jsdom. Зберігати існуючі тести поведінки коду, які вони виконуються під `__test__`. . Імпорт тестових API від `vite-plus/test`. . Використовуйте Playwright для повного потоку веб-переглядача та отримання перевірок.

Загальні налаштування постачає локальні D1 і KV мокс. D1 проводить перевірку міграції SQL на SQLite. Сервер-функція RPC Bridge зберігає реальну середню та валідуючу трубу. Доповідачі компонента забезпечують реальні контексти QueryClient та Router. Зовнішній електронний лист, OAuth і платіжні дзвінки наведені в тести.

Виконайте орієнтований проект під час редагування, потім запустіть повну люкс, висвітлення воріт, перевірте та попередню збірку. Тестування браузера перевіряють публічні сторінки, ауто перенаправлення, SSR без JavaScript, і навігація клієнтів. CI використовує локальні обов'язки і не вимагає секретів живої бази даних або провайдера.

```sh
bun run test:unit
bun run test:integration
bun run test:component
bun run test:coverage
bun run check
bun run build:preview
bun run test:e2e
```
