---
title: "Come contribuire"
description: "Come proporre modifiche a SaaSy Land."
---

1. Discuti prima le modifiche importanti in una issue.
2. Crea un branch a partire da `main`.
3. Segui l'[architettura](/docs/architecture) e le [convenzioni](/docs/reference/conventions), e leggi la [skill per agenti](/docs/tooling/agent-skills) corrispondente prima di modificare l'integrazione di un fornitore.
4. Tieni i test accanto al codice a cui appartengono e mantieni la soglia di copertura al 100%.
5. Esegui i controlli qui sotto.
6. Esegui il commit con un messaggio in formato [conventional commit](/docs/tooling/conventional-commits) e apri una pull request con un titolo convenzionale.

```sh
bun run check
bun run test:coverage
bun run test:e2e:install
bun run test:e2e:smoke
```

Esegui la suite completa di test nel browser (`bun run test:e2e`) per le modifiche che riguardano più route, l'autenticazione o il comportamento del browser. Verifica separatamente le integrazioni con i provider reali quando ne modifichi la configurazione.

Quando il comportamento cambia, aggiorna `content/docs` in tutti e nove i locale; `bun run check:i18n` rifiuta traduzioni mancanti, blocchi di codice e navigazione diversi. Nella pull request, descrivi il comportamento risultante, come l'hai verificato ed eventuali workflow dimostrativi o incompleti che lascia.
