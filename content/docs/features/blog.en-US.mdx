## Content

Posts live in `content/blog/<slug>.<locale>.mdx`, one file per locale. The frontmatter schema in `src/integrations/fumadocs/fumadocs.config.ts` requires `title`, `authorName` and `date`, and accepts `description`, `authorImage`, `excerpt`, `faq`, `featured`, `image`, `published` (default `true`), `tags` and `updated`.

## Source

`blogSource` in `fumadocs.source.ts` loads the collection under `/blog` with the same i18n settings as the docs. `getPublishedBlogPosts(locale)` returns published posts, newest first, as summaries with a reading time counted with `Intl.Segmenter` for that locale.

## Routes

- The `/blog` layout (`blog.tsx`) renders the blog header, `PageFrame` and `Footer`, and loads `docs.css` for article typography.
- `/blog` (`blog.index.tsx`) lists posts with `PostRow`; the list comes from a server function defined in the route file.
- `/blog/$` (`blog.$.tsx`) loads one post (404 when unpublished), preloads its compiled MDX with `blogContent`, and composes `PostMeta`, `PostToc` (or `InlineTOC` on small screens), `PostCta` and `PostShare` from `src/presentation/components/custom/blog`. It adds JSON-LD from `buildBlogPostStructuredDataHtml` and article metadata from `buildPageHead`.

The landing page Notes section shows the three latest posts.

## Admin blog (demo)

`/admin/blog` and `/admin/blog/create` render demo posts and stats from `src/data/admin-blog.ts` and a static editor. They do not read or write `content/blog`.

## Checks

Run `bun run content` after adding a post. `bun scripts/check-content.ts` verifies that every locale exists, that titles, descriptions and excerpts are translated, and that code blocks are identical.
