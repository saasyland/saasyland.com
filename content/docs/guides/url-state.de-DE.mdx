title: Zustand der URL.
description: Zustandsinformation der URL – SaaSy Land
---

Definieren Sie das Suchschema einer Route mit `validateSearch`, lesen Sie es mit `Route.useSearch` und aktualisieren Sie es über die Navigation des TanStack Routers. Bewahren Sie dabei, falls zutreffend, bookmarkfähige Filter, Tabs, Sortierung und Paginierung in der URL. Der Zustand, der nur von Komponenten verwendet wird, bleibt in React.

Locale-URL-Umschreibungen werden für native Router-Links verwendet. Verwenden Sie `localizePathname` für manuell erstellte URLs, einschließlich OAuth-Callbacks und E-Mail-Links. Fügen Sie keine Locale-Bezeichnung zu externen Links oder API-Pfaden hinzu. Behalten Sie die Query-Parameter und den Fragment-Teil bei, wenn Sie die Sprache wechseln.
