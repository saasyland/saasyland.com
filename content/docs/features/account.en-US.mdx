`src/modules/account` owns the Better Auth `account` table (`account.schema.ts`): one row per credential or OAuth provider linked to a user. OAuth tokens in it are encrypted.

## Use cases

| Use case                           | Middleware              | Used by                                |
| ---------------------------------- | ----------------------- | -------------------------------------- |
| `signUpWithPassword`               | rate limited            | `SignUpForm`                           |
| `signOutUser`                      | signed in               | `useSignOut`                           |
| `changePassword`                   | signed in, rate limited | `SettingsPasswordForm`                 |
| `changeEmail`                      | signed in, rate limited | not used by a screen                   |
| `updateUser`                       | signed in               | not used by a screen                   |
| `sendChangeEmailConfirmationEmail` | Better Auth hook        | `user.changeEmail` in `auth.server.ts` |

`sendChangeEmailConfirmationEmail` sends `ChangeEmailConfirmationEmail` to the current address with the confirmation link from Better Auth.

## Signing out

`useSignOut` (`src/hooks/use-sign-out.ts`) runs `signOutUserMutation`, clears the query cache, navigates to `/auth/sign-in` and shows a toast. The admin user widget and the `/app` sidebar each render a `SignOutButton` that uses it.
