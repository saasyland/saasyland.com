## Tools

| Tool    | Version                                        | Why                                                                                        |
| ------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Bun     | <RepositoryFact name="bunVersion" />           | Package manager and script runner; `packageManager` in `package.json` and CI pin it        |
| Node.js | <RepositoryFact name="nodeVersion" /> or newer | The version in `.nvmrc`, which `nvm use` and CI read. The test database uses `node:sqlite` |
| Git     | Any recent version                             | The install step sets up Git hooks                                                         |

Wrangler, drizzle-kit, Playwright and the Vite+ CLI are dev dependencies; run them through the package scripts or `bunx`. Browser tests also need the Playwright browsers from `bun run test:e2e:install`.

## Accounts

The isolated test preview and all automated tests need no accounts or credentials. Development and deployment use real services:

- A Cloudflare account with D1, KV, R2 and Workers for the preview and production deployments. The dev server runs on local resources and needs no account.
- GitHub and Google OAuth apps for social sign-in.
- Resend with a verified sender. A new email account is signed in at once, but without Resend no confirmation link arrives, so the licence key, the customer portal, paid lessons and signing in again stay locked.
- Polar, using the sandbox for development, with three products for the Core, Complete and Agency tiers.
