Wszystkie pliki i foldery używają kebab-case.

## Pliki źródłowe

| Wzorzec                                                      | Znaczenie                                                                                                             |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | Trasa plikowa; kropki to segmenty ścieżki, `_` oznacza layout bez ścieżki, `$` trasę splat, a `index` trasę indeksową |
| `src/routes/api/<name>.ts`                                   | Handler HTTP                                                                                                          |
| `modules/<table>/<table>.schema.ts`                          | Tabela Drizzle                                                                                                        |
| `modules/<table>/<table>.zod.ts`                             | Schematy Zod                                                                                                          |
| `modules/<table>/<table>.constants.ts`                       | Klucze zapytań, klucze mutacji i enumy                                                                                |
| `modules/<table>/<table>.types.ts`                           | Typy wyprowadzone z tabeli                                                                                            |
| `modules/<table>/<table>.utils.ts`                           | Czyste funkcje pomocnicze dla tabeli                                                                                  |
| `modules/<table>/<table>.server.ts`                          | Helpery modułu działające wyłącznie na serwerze                                                                       |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | Jeden przypadek użycia                                                                                                |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | Konfiguracja lub adapter dostawcy, na przykład `auth.server.ts`                                                       |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | Kolumny tabeli danych                                                                                                 |
| `presentation/emails/<name>.tsx`                             | Szablon e-maila eksportujący `<NAME>_NAMESPACE`                                                                       |
| `hooks/use-<name>.ts`                                        | Współdzielony hook React                                                                                              |
| `providers/<name>-provider.tsx`                              | Provider aplikacji                                                                                                    |

## Testy

| Wzorzec                               | Uruchamiane przez            |
| ------------------------------------- | ---------------------------- |
| `__test__/<file>.test.ts`             | Projekt Vitest `node`        |
| `__test__/<file>.integration.test.ts` | Projekt Vitest `integration` |
| `__test__/<file>.component.test.tsx`  | Projekt Vitest `component`   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                   |

Nazwy plików testowych pochodzą od pliku źródłowego, który pokrywają, na przykład `user.schema.test.ts` dla `user.schema.ts`.

## Treści i komunikaty

| Wzorzec                                   | Znaczenie                                                       |
| ----------------------------------------- | --------------------------------------------------------------- |
| `messages/<locale>/<namespace>.json`      | Przestrzeń nazw tłumaczeń, na przykład `pages.admin.users.json` |
| `content/docs/<path>/<page>.<locale>.mdx` | Strona dokumentacji                                             |
| `content/docs/<path>/meta.<locale>.json`  | Nawigacja dokumentacji                                          |
| `content/blog/<slug>.<locale>.mdx`        | Wpis na blogu                                                   |
