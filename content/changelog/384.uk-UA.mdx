- Змінено: необов’язкові можливості перелічено в `scripts/features.ts`, а `bun run check:features` прибирає можливості кожного сценарію, форматує змінені файли й перевіряє типи та переклади сайту, що лишається. Усі п’ять сценаріїв проходять без жодного посилання, яке не можна прибрати, а сценарій, що не пройшов, тепер провалює запуск CI. Див. [Тестування](/docs/conventions/testing).
- Змінено: файлів-збірників `*.entries.ts` більше немає. Кожен список сценаріїв, сторінок, початкових даних, дублерів провайдерів і тестових фікстур імпортує елементи з файлів, які їх оголошують. Див. [Тестування та CI](/docs/architecture/testing-architecture).
- Змінено: `bun run check:content` перевіряє вміст документації, блогу та журналу змін, а `bun run check:i18n` лише повідомлення. Див. [Скрипти проєкту](/docs/tooling/scripts).
