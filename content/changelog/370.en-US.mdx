- Fixed: in Safari, a course dragged in the admin course list stays where it is dropped. Each row now accepts the drag as soon as the pointer enters it, as Safari requires before it drops anything there, and so does each column header. `moveCourse` now moves a course by the number of places it was dragged or stepped, from the place it has when the move arrives, so a course that another administrator added or deleted elsewhere in the meantime no longer shifts where it lands. See [Data grid](/docs/ui/data-grid#row-order).
- Fixed: in Safari, the first click after a drag works, such as **Use an existing video** right after reordering a lesson's materials. After any drag, Safari reports the next press as a pointer move ([WebKit bug 202287](https://bugs.webkit.org/show_bug.cgi?id=202287)), and the site now turns that move back into the `pointerdown` that React Aria's buttons wait for.
- Fixed: in Safari, dialogs, menus, popovers and lists close however soon they are closed after opening, such as the command palette reopened right after one of its results. Their 100 ms animations no longer also start a transition of every property, which Safari left pending, so the closed dialog stayed on screen.
- Fixed: leaving the admin dashboard in Safari while it still loads a panel opens the page asked for instead of reloading the dashboard. The patched `lazyRouteComponent` also waits for a chunk that the page starts to load after `beforeunload`, which Safari fails at once. See [Dependencies](/docs/conventions/dependencies).
- Fixed: the browser tests drag curriculum and material rows by resting the pointer on the drop target before releasing it, as a person does, and the accessibility check scrolls only to the sections that still wait to be revealed, so the long changelog page is checked in time in WebKit.
