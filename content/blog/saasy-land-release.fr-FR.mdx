## Qu'est-ce que SaaSy Land ?

SaaSy Land est un kit de démarrage commercial Next.js SaaS. Un CLI pose cinq questions et n'écrit que les modules auxquels vous avez répondu : authentification sur votre propre base de données, facturation, email transactionnel, console d'administration, internationalisation et concepteur de pages visuelles. Il arrive avec 141 fichiers de test et une porte de couverture déjà en vigueur, de sorte que le code que vous recevez est vérifié plutôt que simplement présent.

Le code est MIT autorisé et public, de sorte que vous pouvez le lire avant de décider. Vous payez une fois pour le CLI, les modèles et les mises à jour de base à vie, et il n'y a pas de vérification de licence d'exécution, pas de rappel de fournisseur et pas d'abonnement.

## Choisissez votre pile, lancez une commande

Le CLI n'est pas un modèle que vous téléchargez, puis combattez. Il demande ce que vous construisez et écrit exactement cela, de sorte que le même outil échafaude un projet côté un-tenant et un produit multi-tenant avec un marchand de disques.

```bash
bunx saasyland@latest init my-app \
  --framework tanstack \
  --tenancy multi \
  --billing polar \
  --content mdx \
  --email resend
```

Cinq questions, avec des drapeaux délibérément ennuyeux pour que le commandement survive à être collé dans un script plutôt que dans une prompte :

| Question    | Options                                           | Pourquoi c'est une question                                                                                                                                                     |
| ----------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cadre       | `next`, `tanstack`                                | Les deux sont pris en charge; choisissez celui que votre équipe connaît déjà                                                                                                    |
| Location    | `multi`, `single`                                 | Rénover les organisations touche plus tard chaque requête que vous avez écrite                                                                                                  |
| Facturation | `stripe`, `polar`, `lemonsqueezy`, `--no-billing` | Polar et Lemon Squeezy sont des négociants inscrits et ont pour vous la TVA de l'UE et la taxe de vente américaine. Stripe ne le fait pas. Un fondateur fait cet appel une fois |
| Contenu     | `mdx`, `--no-content`                             | Un blog et des docs, ou aucun                                                                                                                                                   |
| Courriel    | `resend`, `--no-email`                            | Le courrier transactionnel est transféré dans les flux d'auth, ou aucun                                                                                                         |

Changez une réponse et la commande change avec elle. Exécutez-le à nouveau pour le projet suivant : les réponses changent, les CLI et les mises à jour à vie ne changent pas.

### Pourquoi la porte de couverture compte plus maintenant qu'elle ne l'a fait au lancement

Lorsque 2.0 a été expédié, le numéro de couverture était un argument de qualité. Il est devenu depuis un argument de débit, parce qu'une grande partie du code étant ajouté à SaaS bases de code est maintenant écrite par un agent.

Dans le [2025 Enquête auprès des développeurs de trop-pleins](https://survey.stackoverflow.co/2025/ai), 84% des développeurs ont déclaré utiliser ou planifier d'utiliser des outils d'IA, alors que la frustration la plus citée, nommée par 45%, était la sortie d'IA qui est « presque droite, mais pas tout à fait ».Un seuil qui échoue la construction est la réponse disponible la moins chère à cela: un agent ne peut pas ajouter de comportement sans ajouter un test, et tout ce qu'il casse surfaces à la demande de traction plutôt qu'à un client.

Nous l'avons écrit longuement. [pourquoi votre dépôt décide de la qualité de sortie de l'agent](/blog/ai-coding-agents-repository-readiness) et en [comment choisir une pile pour les agents de codage AI](/blog/choosing-a-saas-stack-for-ai-coding-agents)C'est vrai. La version courte est que ce dépôt marque 20 sur 20 sur notre propre fiche de pointage de préparation, par construction plutôt que par effort.

## Vérifiez chaque réclamation avant de payer

Aucun témoignage, parce qu'il n'y a rien à vérifier dans une citation. Chaque numéro de cette page est généré par le dépôt que vous achetez, et voici où le trouver.

| Réclamation                       | Où le vérifier?                                                              |
| --------------------------------- | ---------------------------------------------------------------------------- |
| Couverture de test à 100 %        | `coverage/coverage-summary.json`, généré par `bun run test:coverage`         |
| Appliquées, non signalées         | `.github/workflows/ci.yml`, sur chaque demande de traction et pousser à main |
| Navigateurs réels, pas jsdom      | `e2e/specs`, 5 suites Playwright sur Chrome et WebKit                        |
| 54 locaux, 156 monnaies           | `src/modules/_core/constants`, vérifié par `bun run check:i18n`              |
| Types stricts, zéro `any`         | `tsc --strict`, qui bloque la fusion sur une seule erreur                    |
| 56 composants, dans votre mémoire | `src/presentation/components`, source modifiable                             |

## Pour qui ce n'est pas pour

Si vous voulez apprendre quelque chose gratuitement, clonez un modèle et profitez-en. Si vous préférez un fournisseur hébergé exécutez votre authentification et facturez-vous par utilisateur actif mensuel pour le privilège, achetez-le plutôt.

C'est pour les gens qui ont l'intention de posséder encore leurs marges à cinquante mille utilisateurs, et qui préféreraient savoir à la demande de tirage que dans la production.
