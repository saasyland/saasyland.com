---
title: Catálogo de módulos
description: Inventário de domínios src/módulos e propriedade.
---

| Módulo         | Possuem                                                           |
| -------------- | ----------------------------------------------------------------- |
| `_core`        | Erros, catálogos locais/moedas/tempos, usos compartilhados.       |
| `account`      | Perfil / e-mail / senha / assinatura                              |
| `user`         | Administração de gestão de usuários + ajudantes de personificação |
| `session`      | Listar / revogar sessões                                          |
| `two-factor`   | TOTP habilitar / verificar / desativar                            |
| `verification` | E-mail verificar + senha repor orquestração                       |
| `product`      | Casos de uso de catálogo de produtos                              |
| `category`     | Casos de uso de categoria                                         |

Adicione uma linha quando você introduzir uma nova pasta de domínio.
