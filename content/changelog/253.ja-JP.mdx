- 追加: [テストカバレッジ](/docs/tooling/test-coverage) は、テストの層をそれぞれ個別に示し、ユーザーと管理者のすべてのフローを、それをエンドツーエンドで実行するブラウザーテスト、または欠けているものとその理由とともに一覧にします。ページ上の数値はすべてコードから表示されます。
- 追加: `bun run check` は `bun run check:flows` を実行します。フローがもう存在しないブラウザーテストやスキップされるテストを指しているとき、またはどのテストもそれを証明しない理由を書いていないときに失敗します。[テストカバレッジ](/docs/tooling/test-coverage#flow-coverage) を参照してください。
