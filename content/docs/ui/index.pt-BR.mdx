| Caminho                                                 | Conteúdo                                                                                                                                                                                                                |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/presentation/components/shadcn/`                   | Primitivas do shadcn geradas, variante React Aria                                                                                                                                                                       |
| `src/presentation/components/custom/`                   | Componentes do aplicativo: arquivos compartilhados sem subpastas (`footer.tsx`, `navigation.tsx`, `data-table.tsx`, `locale-switcher.tsx`, …) e as pastas por área `admin/`, `app/`, `auth/`, `blog/` e `landing-page/` |
| `src/presentation/styles/`                              | `globals.css` (Tailwind, tokens, escala tipográfica), `fonts.css`, `docs.css`, `typeset.css`                                                                                                                            |
| `src/presentation/theme/`, `src/presentation/branding/` | Constantes de tema e de marca                                                                                                                                                                                           |
| `src/presentation/document-assets.ts`                   | Folha de estilo global e pré-carregamento de fontes                                                                                                                                                                     |
| `src/providers/`                                        | `AriaProvider`, `ThemeProvider`, `TranslationsProvider`, `MotionProvider`                                                                                                                                               |
