## Кроки

1. Додати шлях до `ROUTES`
2. Додавання входу в бічну панель `admin/constants/sidebar.ts` (+ етикетки i18n)
3. Спілкування `app/[locale]/(admin)/admin/<feature>/page.tsx`
4. Колокація `_components` / `_lib`
5. Дані шлюзу з використанням-cases + Suspense
6. Документ за функціями
