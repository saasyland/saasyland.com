title: "Journal des modifications"
description: "Les changements notables au fil du temps."
---

Chaque section recense les changements arrivés sur `main` ce jour-là (UTC), les plus récents en premier, et chaque changement se termine par un lien vers la pull request dont il provient et, une fois déployé, vers la version qui l'a livré en premier. Chaque déploiement en production reçoit un tag et est publié comme GitHub Release, avec pour notes les entrées qu'il a livrées ; voir [Versions et tags](/docs/tooling/ci-cd#releases-and-tags). Les versions de la CLI elle-même figurent dans les [notes de version de la CLI](/docs/cli/releases). Chaque changement ajoute sa propre entrée ; voir [Entrées du journal des modifications](/docs/conventions/git-workflow#changelog-entries).
