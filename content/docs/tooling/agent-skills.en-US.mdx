title: "Agent skills"
description: "Vendor skills for coding agents, restored from skills-lock.json."
---

`skills-lock.json` pins the agent skills used with this repository. The installed skills are not committed: `.agents/` and `.claude/` are ignored by Git.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` deletes `.agents/skills` and `.claude/skills`, reinstalls every locked skill with `bunx skills experimental_install`, moves each skill into a vendor group at `.agents/skills/<group>/<skill>/SKILL.md` and links every group into `.claude/skills`. It fails when a skill source has no group mapping.

| Group                                                 | Source                                                               |
| ----------------------------------------------------- | -------------------------------------------------------------------- |
| `anthropic`                                           | `anthropics/skills`                                                  |
| `better-auth`                                         | `better-auth/skills`                                                 |
| `cloudflare`                                          | `cloudflare/skills`                                                  |
| `polar`                                               | `polarsource/skills`                                                 |
| `resend`                                              | `resend/resend-skills`                                               |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) and `TanStack/table` (`table`) |
| `remotion`                                            | `remotion-dev/skills`                                                |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | General engineering, design and marketing skills                     |

The sync replaces both directories, so keep custom skills elsewhere. `bun run clean:hardcore` deletes `skills-lock.json`.

## Rule

Before changing code that touches TanStack Start, Router or Table, Better Auth, Cloudflare, Polar or Resend, read the matching skill. Skills describe current vendor APIs; the conventions of this repository are documented in [Architecture](/docs/architecture) and [Conventions](/docs/reference/conventions).
