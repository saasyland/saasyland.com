L'application est une app TanStack Start. `src/router.tsx` crée le routeur avec un QueryClient par requête, l'intégration SSR des requêtes, des composants par défaut pour les erreurs et les pages introuvables, le préchargement à l'intention et le `rewrite` de langue. Il n'y a pas de composant d'attente par défaut : chaque route définit son propre squelette (voir [Squelettes de chargement](/docs/architecture/delivery-layer#squelettes-de-chargement)). `src/routes.ts` exporte `ROUTES`, les constantes de chemin utilisées par les liens, les gardes et les balises d'en-tête.

## Routes

`src/routes/` contient des routes de fichiers à plat : `admin.users.all.tsx` sert `/admin/users/all`, `_landing.tsx` est un layout sans chemin et `docs.$.tsx` est une route splat. L'identifiant dans `createFileRoute("…")` est une chaîne littérale maintenue par le générateur du routeur dans `src/routeTree.gen.ts` ; les dossiers `__test__` sont ignorés en tant que routes.

Un fichier de route ne fait que composer sa page. Il définit le composant `<Name>Page` ou `<Name>Layout`, `NAMESPACE` ou `NAMESPACES`, un loader qui exécute le chargement des métadonnées, des messages et des données dans un seul `Promise.all`, `head: pageHead(ROUTES.X)` et, pour les zones protégées, une garde dans `beforeLoad`. Les widgets, boîtes de dialogue, formulaires et colonnes de tableau se trouvent dans `src/presentation/components/custom/` et lisent leurs propres traductions et données. Voir [use-intl](/docs/integrations/use-intl) pour le loader et [Better Auth](/docs/integrations/better-auth) pour les gardes.

## Fonctions serveur

Les opérations sont des fonctions `createServerFn` natives exportées par les cas d'usage des modules ; l'application n'expose donc pas de point de terminaison REST pour elles. Voir [Fonctions serveur et cas d'usage](/docs/integrations/server-functions).

## Handlers HTTP

Seules trois routes déclarent `server.handlers` dans `src/routes/api/` :

| Route         | Handler                                                                                         |
| ------------- | ----------------------------------------------------------------------------------------------- |
| `/api`        | Renvoie le runtime au format JSON                                                               |
| `/api/auth/$` | Better Auth, y compris les callbacks OAuth et les webhooks Polar sur `/api/auth/polar/webhooks` |
| `/api/search` | Recherche dans la documentation Fumadocs                                                        |

```ts
import { createFileRoute } from "@tanstack/react-router"

import { auth } from "~/src/integrations/better-auth/auth.server"

export const Route = createFileRoute("/api/auth/$")({
  server: { handlers: { GET: ({ request }) => auth.handler(request), POST: ({ request }) => auth.handler(request) } },
})
```

## Prérendu

`vite.config.ts` active le prérendu avec exploration des liens. `build:preview`, `build:production` et `build:test` prérendent les pages publiques (page d'accueil, pages légales, blog et documentation) dans les neuf langues. Le filtre ignore `/admin`, `/api`, `/app`, `/auth` et `/newsletter`, avec ou sans préfixe de langue, ainsi que les liens contenant `?` ou `#`. Les pages ignorées sont rendues par le Worker à chaque requête.
