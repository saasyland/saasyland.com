決済は `auth.server.ts` の `@polar-sh/better-auth` プラグインを通じて Polar で処理されます。

```ts
polarPlugin({
  client: polarCore,
  use: [
    checkout({
      authenticatedUsersOnly: true,
      products: POLAR_CHECKOUT_PRODUCTS,
      successUrl: ROUTES.APP,
    }),
    portal(),
    webhooks({ ...licenseWebhookHandlers, secret: env.POLAR_WEBHOOK_SECRET }),
  ],
}),
```

`src/integrations/polar/polar.config.ts` は、`POLAR_ACCESS_TOKEN` と `POLAR_SERVER` からプラグインが使う `polarCore` を作成し、その上に割引、ライセンスキー、注文のサービスをまとめた `polar` を構築します。`POLAR_ORGANIZATION_ID` は割引の検索とライセンスキーの無効化の対象を絞り込みます。`POLAR_CHECKOUT_PRODUCTS` はプランのスラッグ `core`、`complete`、`agency` を `POLAR_PRODUCT_ID_CORE`、`POLAR_PRODUCT_ID_COMPLETE`、`POLAR_PRODUCT_ID_AGENCY` に対応付けます。

## 購入

ライセンスを持たないサインイン済みユーザーには、`/app` と `/app/license` に `CheckoutOptions` が表示されます。このコンポーネントは `startCheckout`（`src/modules/license/use-cases/start-checkout.ts`）を呼び出し、次の処理を行います。

1. `pppDiscountId`（`license.ppp.ts`）で地域割引を探します。`cf-ipcountry` の国に対応する割引率を、Polar で有効な自動のパーセント割引と照合します。`regional_pricing` Cookie が `off` の場合は適用しません。
2. 割引コードを無効にして、そのプランの Polar 購入セッションを作成します。訪問者がアフィリエイトリンク経由で来た場合は、アフィリエイトの紹介情報を `metadata` に含めます（[アフィリエイトプログラム](/docs/features/affiliates)を参照）。
3. 購入 URL を返し、ブラウザーがそれを開きます。

支払いが完了すると `/app` に戻ります。

## Webhook とライセンス

Polar は `/api/auth/polar/webhooks` にイベントを送信し、`POLAR_WEBHOOK_SECRET` で検証されます。`licenseWebhookHandlers`（`src/modules/license/license.webhooks.ts`）は Polar の顧客の `external_id` でユーザーを特定します。このアプリにアカウントがない顧客のイベントは、アカウントが必要な場合はログに記録したうえで受領し、Polar が再送しないようにします。

- `onOrderPaid` → `grantLicense`: 購入した商品のプランでユーザーの唯一のライセンスを作成または更新します。新しい購入が古い購入を置き換えます。
- `onBenefitGrantCreated` → `attachLicenseKey`: Polar のライセンスキーをライセンスに保存します。支払い済みの注文がまだ記録されていない間は失敗させ、Polar に再送させます。返金済みの注文やライセンスではない商品のキーは受領します。
- `onOrderRefunded`（注文が全額返金された場合のみ。一部返金ではライセンスを維持します）と `onBenefitGrantRevoked` → `revokeLicense`: ステータスを `revoked` にし、注文を `revoked_license_order` に記録して、遅れて届いた Webhook が再び付与できないようにします。

## 顧客向け画面

`/app/license` は `LicenseCard`（プラン、キー、インストールコマンド、`/api/auth/customer/portal` の Polar カスタマーポータルへのリンク）と `LicenseActivations` を表示します。`LicenseActivations` は Polar 上のキーのアクティベーションを一覧表示し、`deactivateLicense` で個別に解除します。[顧客アプリ](/docs/features/customer-app)を参照してください。

## 管理画面（デモ）

`/admin/payments` は `RefundStats` と、`src/data/admin.ts` の `ADMIN_PAYMENT_ROWS` を使う返金の `DataTable` を表示します。ボタンは未接続です。`order` の権限定義（`read`、`update`、`refund`）は `auth.access.ts` にありますが、注文や返金を読み取るユースケースはありません。
