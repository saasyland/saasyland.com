---
title: "Fumadocs"
description: "MDX collections for the docs and blog, localized sources and search."
---

Fumadocs turns `content/docs` and `content/blog` into localized pages. `bun run content` runs `fumadocs-mdx` and writes `.source/`; `dev`, `typegen` and every build script run it first. The app reads the compiled MDX of a page from `.source/browser.ts`, in the browser and while prerendering, and everything else about the content from the indexes below, so the deployed Worker holds no content at all (see [Performance](/docs/conventions/performance#the-worker-holds-no-docs-or-blog-content)).

| File                    | Purpose                                                                                                                                                                                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fumadocs.config.ts`    | The `docs` and `blog` collections, both `async`, and the code highlighting themes and colour replacements                                                                                                                                                                                                                 |
| `fumadocs.schema.ts`    | The blog's frontmatter schema                                                                                                                                                                                                                                                                                             |
| `fumadocs.i18n.ts`      | The locales from `I18N`, `en-US` as default and fallback, the `dot` parser for `<slug>.<locale>.mdx`, hidden locale prefix                                                                                                                                                                                                |
| `fumadocs.indexes.ts`   | Runs at build time: reads `content/docs` and `content/blog` and builds each locale's docs index, blog index and search index                                                                                                                                                                                              |
| `fumadocs.icons.ts`     | `DOCS_ICONS`, the Lucide icons the meta files name, and `docsIcon`, which turns a meta file's `icon` into its icon                                                                                                                                                                                                        |
| `fumadocs.docs.ts`      | `loadDocsPage` and `docsHead` for the `docs.$` route                                                                                                                                                                                                                                                                      |
| `fumadocs.blog.ts`      | `toBlogPostSummary`, which formats a post's title and localizes its URL                                                                                                                                                                                                                                                   |
| `fumadocs.changelog.ts` | The `changelogEntries` plugin, which replaces `<ChangelogEntries unreleased="…" />` on the changelog page with the entries of `content/changelog` in the page's locale, under the UTC day each reached `main`, each ending with `<ChangelogLinks>`; in CI it fails the build while an entry is unreleased that may not be |

The locale prefix is hidden in Fumadocs URLs because the router adds it. Blog frontmatter requires `title`, `author`, an id of `BLOG_AUTHOR` in `src/data/blog.ts`, and `date`, and accepts `description`, `excerpt`, `faq`, `image`, `published`, `tags` and `updated`.

## Content indexes

`scripts/content-indexes.ts` is a Vite plugin that loads `fumadocs.indexes.ts` with Vite's module runner and serves what it builds as virtual modules, in the build and in the dev server, where an edit under `content/` rebuilds them:

- `virtual:content-indexes`: `loadDocsIndex(locale)` gives the serialized page tree of a locale and its pages by slug, each with its title, description, section and MDX file; `loadBlogIndex(locale)` gives the published posts of a locale, newest first, with their frontmatter, their table of contents and their reading time. Each locale's index is a chunk of its own, which a loader imports when it first needs it.
- `virtual:docs-search`: `SEARCH_INDEXES` gives the URL of each locale's search index. The build writes each index to `/assets/search-index-<locale>-<hash>.json` with Fumadocs' `createSearchAPI("advanced")`, from the headings and text that Fumadocs' `structure` reads from each page, with the changelog entries in the changelog page and the breadcrumbs that Fumadocs' own search would give it.

`fumadocs.indexes.ts` validates each page's frontmatter with the collection's schema and builds the trees with Fumadocs' `loader`, the i18n settings of `fumadocs.i18n.ts` and the icons of `docsIcon`. A blog post's table of contents comes from `getTableOfContents` and its reading time from the words of its text, counted with `Intl.Segmenter` for its locale.

## Components

`src/presentation/components/custom/mdx.tsx` maps the MDX components: the Fumadocs defaults (including `Cards` and `Callout`), `Accordions`, `Steps` and `Tabs`, and the shadcn `Alert`, `Badge`, `Button`, card parts, `Separator` and `Table`; `RepositoryFact`, which prints a value measured from the repository at build time or defined in the code, as in `<RepositoryFact name="testFiles" />`, and `RepositoryTable`, which prints a table built from the code, as in `<RepositoryTable name="commitTypes" columns={["Type", "Emoji"]} />`. `TierPrice` prints a tier's list price from `TIER_PRICES` in the page locale, as in `<TierPrice tier="core" />`, so no page types a price. `ActivationLimit` prints a tier's activation limit from `LICENSE_ACTIVATION_LIMITS`, as in `<ActivationLimit tier="core" />`, and `RegionalDiscounts` lists the regional discount percentages derived from `PPP_TIERS`. `ChangelogLinks`, which the changelog page ends each entry with, links to the entry's pull request, as in `<ChangelogLinks pullRequest="257" />`, or to its commit, and with `release` to the release that first shipped it, and names the link for screen readers from the `components.custom.changelog-links` namespace. Internal links are localized with `localizePathname`, and a task list item wraps its checkbox and text in a `label`. `docs-content.tsx` and `blog-content.tsx` render the pages. Fumadocs' own controls, such as the search, **On this page** and the copy buttons, take their text from the `fumadocs` namespace: `useFumadocsI18n` passes it, with the page's locale, to the `RootProvider` of the docs and blog layouts.

## Content rules

Every page exists once per locale as `<slug>.<locale>.mdx`, and each folder has a `meta.<locale>.json` with the same `pages` array in every locale. `icon` in a meta file takes the name of an icon in `DOCS_ICONS`; import a new icon there, and `fumadocs.icons.test.ts` fails when a meta file names one that is not imported or an imported one is no longer named. `scripts/check-content.ts`, part of `bun run check:i18n`, fails when a translation is missing, when its code blocks, inline code, components, links, tables or navigation differ from English, or when an English paragraph remains in another locale.
