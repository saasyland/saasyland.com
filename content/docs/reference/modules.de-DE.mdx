---
title: Modulkatalog
description: Bestandsaufnahme der Quelldateiverzeichnisse, Domänen und Eigentumsverhältnisse.
---

| Modul          | Besitzt.                                                                             |
| -------------- | ------------------------------------------------------------------------------------ |
| `_core`        | Fehler, Ländereinstellungen/Währungskataloge und gemeinsam genutzte Hilfsfunktionen. |
| `account`      | Profil / E-Mail / Passwort / Abmelden                                                |
| `user`         | Benutzerverwaltung für Administratoren sowie Hilfsmittel zur Identitätsübernahme.    |
| `session`      | Auflisten / Sitzungen aufheben.                                                      |
| `two-factor`   | TOTP aktivieren / bestätigen / deaktivieren                                          |
| `verification` | E-Mail-Verifizierung und Passwort-Zurücksetzung.                                     |
| `product`      | Produktkatalog-Anwendungsfälle.                                                      |
| `category`     | Kategorien und Anwendungsfälle.                                                      |

Fügen Sie eine Zeile hinzu, wenn Sie einen neuen Ordner für eine Domäne hinzufügen.
