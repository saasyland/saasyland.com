## Eigentum.

`integrations/better-auth` — `auth.server.ts`, `auth.client.ts`, Validierungen, Fehler, Sicherheitsvorkehrungen.

## Fähigkeiten.

- E-Mail/Passwort
- GitHub + Google OAuth
- Sitzungs-Cookies über Better Auth
- Proxy-gesteuerter Schutz für `/admin` und `/app`.

## Erweitern.

Fügen Sie soziale Anmeldeanbieter in der Konfiguration des Authentifizierungsservers hinzu; speichern Sie die geheimen Schlüssel in den Umgebungsvariablen; aktualisieren Sie die Dokumentation und die `.env.example`-Datei.
