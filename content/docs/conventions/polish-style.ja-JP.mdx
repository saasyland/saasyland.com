ポーランド語は SaaSy Land を作っている人の母語で、読み手は直訳された文にすぐ気づくポーランドのエンジニアと購入者です。`messages/pl-PL/` のポーランド語メッセージ、ドキュメントのページ、ブログ記事、変更履歴の項目はすべてこのページに従います。最後の用語集がポーランド語の用語の唯一の情報源で、このページは `src/data/polish-glossary.ts` の `POLISH_TERMS`、`POLISH_NAMES`、`POLISH_PHRASES` を表示します。用語集でまだ決まっていない用語は、それを使う pull request の中でまず用語集に追加します。

## 文ではなく意味を書く

英語を読んだら閉じて、同じことを同僚や顧客に伝えるためにポーランドのシニアエンジニアが書く文を書きます。事実、数値、プレースホルダー、タグは残し、翻訳らしく聞こえるそれ以外の部分はすべて書き直します。

- 英語が名詞を重ねるところで、ポーランド語は動詞を働かせます。`Funkcjonalność generowania projektów zostanie dostarczona` ではなく `Generowanie projektów pojawi się w kolejnym wydaniu` と書きます。
- 動詞が主語を示すので、代名詞はたいてい不要です。`Skopiuj swój klucz licencyjny` ではなく `Skopiuj klucz licencyjny` と書きます。`Twoja baza danych, nie cudza` のように所有そのものが要点のときだけ `Twój` を残します。
- 言葉遊びや慣用句に頼る英語の決め台詞には、同じ言葉ではなく同じ意味のポーランド語の文を当てます。`You just shouldn’t have to` は `Po prostu nie powinieneś musieć` ではなく `Tylko po co?` です。
- スローガン、見出し、ボタンは短く保ちます。ポーランド語の単語は英語より長いので、内容ではなく言葉を削ります。

## 呼びかけと文体

サイトは 1 人の読み手に二人称単数で語りかけ、敬意を込めて大文字で書きます。`Ty`、`Twój`、`Ciebie`、`Ci`、`Tobie` です。ポーランド語の正書法では、手紙や 1 人に宛てた文章でこれらの代名詞を大文字で書きます。アカウントのページ、支払い、メールはまさにそうした文章なので、トップページとドキュメントも別の規則を作らず同じ形を使います。[文体は 1 つ](/docs/conventions/translations#one-form-of-address)では、`Pan`、`Pani`、`Państwo` と小文字の代名詞を拒否するチェックを説明しています。

- サイトは読み手の性別を知らないので、過去形や性別がわかる形容詞で読み手に語りかけません。`za co już zapłaciłeś` や `jesteś gotowy` ではなく、`Za co już zapłacono`、`Po zakupie`、`Jeśli masz już licencję` と書きます。
- ボタンとリンクは命令形（`Zapisz`、`Kup pakiet Komplet`、`Przejdź do płatności`）、見出し、メニュー項目、表の見出しは名詞（`Ustawienia`、`Licencja`、`Faktury`）、確認のメッセージは非人称（`Zapisano`、`Skopiowano`、`Miejsce aktywacji zwolnione`）にします。
- エラーは謝罪せずに、何が失敗したかと次に何をするかを伝えます。`Nie udało się zapisać zmian. Spróbuj ponownie.`
- 口調は率直で、自信があり、正確です。感嘆符も、事実が裏付けない最上級も、英語のマーケティングにしかない売り文句も使いません。

## 直訳も中途半端な英語も使わない

直訳は英語の単語を写し取ってポーランド語の意味を失います。`produkcyjny starter` は何かを製造するスターターのように聞こえ、`hydraulika` は浴室の配管です。下の表現の表には、サイトに入り込んだ直訳と、代わりに書く言い方を載せています。

文はポーランド語かコードのどちらかです。ポーランド語の文に英語が現れるのは、製品名、コードの識別子、ファイルパス、コマンド、そしてポーランドの開発者が英語のまま使う用語集の専門用語（`stack`、`framework`、`commit`、`pull request`、`webhook` など）だけです。こうした用語は斜体や引用符を付けずに書き、開発者が話すとおりにポーランド語の語尾を付けます。`commita`、`w pull requeście`、`frameworku`、`stacku` です。それ以外はすべて訳します。中途半端に訳したくなる単語も同じで、release は `wydanie`、deploy は `wdrożenie`、merge は `scalenie`、feature は `funkcja` です。

## 組版

- 引用符は „…” を使い、その中では »…« を使います。コードと識別子は、インラインコードの中でそれぞれの引用符を保ちます。
- 文の区切りのダッシュは両側に空白を入れ（`–` または `—`）、ハイフンは使いません。範囲は空白なしのエンダッシュで書きます。`10–20` です。
- 見出し、タイトル、ボタン、メニュー項目で大文字にするのは最初の単語と固有名詞だけです。`Zasady Zwrotów` ではなく `Zasady zwrotów` です。月、曜日、言語名は小文字で書きます。`po angielsku`、`w poniedziałek` です。
- ポーランド語では、従属節（`że`、`który`、`gdy`、`jeśli`、`aby`、`ponieważ`、`co`）の前に必ずコンマを置き、列挙の `i`、`oraz`、`lub` の前にはコンマを置きません。
- 数値、日付、通貨、単位はフォーマッターが出力し、3 桁区切りにノーブレークスペース、小数点にコンマを使うので、手で入力しません。サイトは `w` や `z` のような 1 文字の単語を次の単語につなげないので、文章でもノーブレークスペースを手で入力しません。

## 用語集のチェック [#glossary-check]

`bun run check` は `check:glossary` を実行し、ポーランド語のテキストが下の「使わない語」の列にある語を使うと失敗します。対象は `messages/pl-PL/` のメッセージ（メールを含む）、ポーランド語のドキュメントページ、ブログ記事、変更履歴の項目すべて（タイトル、説明、質問を含む）、`meta.pl-PL.json` のナビゲーションのタイトル、`content/courses/saasy-land-courses.json` のポーランド語のテキストです。ファイル、行、見つかった語、用語集が勧める語を出力します。

- 語は活用形のどれでも失敗します。`src/data/polish-glossary.ts` では縦線が語尾の始まる位置を示すので、`wspier|ać` は `wspierane`、`wspieranej`、`wspieramy` で失敗し、`wsparcie` では失敗しません。下の表は縦線を除いて語を表示します。縦線のない語は書かれたとおりの形でだけ失敗するので、`admin` は `administracyjny` では失敗しません。
- コード、リンク、パス、„…” の引用、`ang.` の後に括弧で示した英語の用語はポーランド語の本文ではないので、チェックはこれらを飛ばします。
- 大文字で始まる語は、文、見出し、リスト項目、表のセル、リンクのテキストの先頭でだけ失敗するので、Better Auth や Stripe Billing のような名前は `auth` や `billing` で失敗しません。
- 用語集が別の意味では勧めている語、たとえばブラウザーのタブには正しく、ページ内のタブには誤りの `karta` は、文によって正誤が決まるので、チェックは読み手に任せます：<RepositoryFact name="polishContextTerms" />。
