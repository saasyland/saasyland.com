## Admin screen (demo)

`/admin/analytics` shows five tab triggers (`overview`, `revenue`, `audience`, `retention`, `reports`); only **Overview** has content:

- `AnalyticsKpis` and `AnalyticsRevenueChart` render constants from their own files.
- `RegionsAndUpgrades` renders `ADMIN_ANALYTICS_REGION_ROWS` and `ADMIN_ANALYTICS_UPGRADE_ROWS` from `src/data/admin.ts`.
- The date picker button is not wired.

The revenue chart on the dashboard is a static SVG as well.

## What is collected

No analytics or tracking script is installed, and no events are stored. `wrangler.jsonc` enables Workers `observability`, so Worker logs, including the `console.error` output of failed server functions, appear in the Cloudflare dashboard.
