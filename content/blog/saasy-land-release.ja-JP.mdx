## SaaSy Land とは？

SaaSy Land は、商用の React SaaS スターターキットです。CLI が構成に関する質問を行い、回答したモジュールだけを書き出します。自分のデータベースで動く認証、課金、トランザクションメール、管理画面、国際化、ビジュアルページデザイナーです。<RepositoryCount fact="testFiles" /> 個のテストファイルと、それらを最初から強制するカバレッジゲートが付属しているため、受け取るコードはただ存在するだけでなく、検証済みです。

公開 Web サイトのソースコードは MIT ライセンスです。一方、別途提供する CLI と非公開テンプレートはプロプライエタリです。ライセンスを購入して saasyland.com にサインインし、CLI のインストールと利用に必要なキーを取得してください。オンラインでのライセンス認証は CLI に適用されます。生成したアプリケーションは商用ライセンスの下で編集・デプロイでき、実行時のキーは不要です。Web サイトのライセンスによって SaaSy Land の商標権が付与されることはありません。

## スタックを選んで、コマンドを 1 つ実行

CLI は、ダウンロードしてから格闘するテンプレートではありません。何を作るのかを尋ね、まさにそれだけを書き出します。そのため同じツールで、シングルテナントのサイドプロジェクトも、マーチャント・オブ・レコードを使うマルチテナントのプロダクトも生成できます。

```bash
bunx saasyland@latest init my-app \
  --framework tanstack \
  --tenancy multi \
  --billing polar \
  --content mdx \
  --email resend
```

選択肢の一部を紹介します。フラグはあえて地味にしてあるので、コマンドをプロンプトではなくスクリプトに貼り付けても、そのまま使えます。

| 質問           | オプション                                        | 質問する理由                                                                                                                                                       |
| -------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| フレームワーク | `next`, `tanstack`                                | どちらもサポートしています。チームが使い慣れている方を選んでください                                                                                               |
| テナンシー     | `multi`, `single`                                 | 後から組織機能を追加すると、それまでに書いたすべてのクエリに手を入れることになります                                                                               |
| 課金           | `stripe`, `polar`, `lemonsqueezy`, `--no-billing` | Polar と Lemon Squeezy はマーチャント・オブ・レコードとして、EU の VAT と米国の売上税を代わりに引き受けます。Stripe は引き受けません。創業者が一度だけ下す判断です |
| コンテンツ     | `mdx`, `--no-content`                             | ブログとドキュメントを入れるか、どちらも入れないか                                                                                                                 |
| メール         | `resend`, `--no-email`                            | 認証フローに組み込まれたトランザクションメールを使うか、使わないか                                                                                                 |

回答を変えると、コマンドもそれに合わせて変わります。次のプロジェクトでもう一度実行すれば、回答は変わりますが、CLI と無期限アップデートは変わりません。

### カバレッジゲートがリリース時よりも今重要になっている理由

2.0 をリリースした当時、カバレッジの数値は品質を示す論拠でした。その後、それはスループットを示す論拠になりました。いまや SaaS のコードベースに追加されるコードのかなりの割合を、エージェントが書いているからです。

[2025 Stack Overflow Developer Survey](https://survey.stackoverflow.co/2025/ai) では、開発者の 84% が AI ツールを使用している、または使用する予定だと回答しました。一方で、最も多く挙げられた不満は、45% が指摘した「ほぼ正しいが、完全ではない」AI の出力でした。ビルドを失敗させるしきい値は、これに対して取れる最も安価な答えです。エージェントはテストを追加しない限り振る舞いを追加できず、何かを壊せば、それは顧客のもとではなくプルリクエストの段階で表に出ます。

この点については、[リポジトリがエージェントの出力品質を左右する理由](/blog/ai-coding-agents-repository-readiness) と [AI コーディングエージェントのためのスタックの選び方](/blog/choosing-a-saas-stack-for-ai-coding-agents) で詳しく書いています。要点だけ言えば、このリポジトリは私たち自身の準備度スコアカードで 20 点中 18 点を獲得しており、それは努力ではなく構造によるものです。

## よくある質問

<Accordions>

<Accordion title="SaaSy Land とは何ですか？">

SaaSy Land は、本番運用向けの React SaaS スターターキットです。CLI が構成に関する質問を行い、回答した内容だけをスキャフォールドします。自分のデータベースで動く認証、課金、トランザクションメール、管理画面、9 ロケールの国際化、ビジュアルページデザイナーが含まれ、<RepositoryCount fact="testFiles" /> 個のテストファイルと 100% のカバレッジゲートが CI で最初からそれらを検証しています。支払いは $249 の一度だけで、ユーザーごとの料金はかかりません。

</Accordion>

<Accordion title="SaaSy Land の価格はいくらですか？">

買い切りの 3 つのプランがあります。Core は $249 で、編集可能な生成済みアプリのソース、CLI ライセンス、コアの無期限アップデートが含まれます。Complete は $399 で、フルビデオコースが加わります。Agency は $899 で、無制限のクライアントライセンス、Discord での優先サポート、Figma ファイルが加わります。サブスクリプションも、月間アクティブユーザーによる従量課金もありません。アクティベーションの条件と、席数の上限がある場合はその内容を、購入前に開示します。

</Accordion>

<Accordion title="SaaSy Land のテストカバレッジは本当に 100% ですか？">

はい。ステートメント、ブランチ、関数、行のすべてで 100% であり、バッジではなくゲートです。<RepositoryCount fact="testFiles" /> 個の Vitest ファイルに加えて、<RepositoryCount fact="e2eSpecs" /> 個の Playwright スイートが実際のブラウザで実行され（Chromium はプルリクエストごと、WebKit は main）、しきい値は `.github/workflows/ci.yml` によってすべてのプルリクエストで強制されます。リポジトリで `bun run test:coverage` を実行すれば、レポートが再生成されます。

</Accordion>

<Accordion title="SaaSy Land 2.0 はどのような技術スタックを使っていますか？">

公開リファレンスアプリケーションは、Cloudflare Workers 上の TanStack Start と React 19、型付きサーバー関数、Better Auth、Drizzle と Cloudflare D1、Zod、Polar、Resend、use-intl、Tailwind CSS 4、shadcn/ui、Fumadocs を使用しています。開発、チェック、テスト、ビルドは Bun と Vite+ が担います。生成するプロジェクトで選べる代替の選択肢は、CLI コンフィギュレーターで確認できます。

</Accordion>

<Accordion title="Clerk や Auth0 ではなく Better Auth を使うのはなぜですか？">

所有権と利益率のためです。ホスティング型の認証サービスは月間アクティブユーザーごとに課金するため、本来なら売上が伸びるはずのタイミングで、ちょうどコストも上がります。Better Auth はあなたのコードベースとデータベースの中にあります。つまり、ユーザーはあなたが所有するデータベースの行であり、認証ロジックは読んで拡張できるソースコードで、ユーザー単位の認証ライセンス料もかかりません。ただし、ホスティングとデータベースの費用は利用量に応じて変わります。

</Accordion>

<Accordion title="SaaSy Land をクライアントの案件に使えますか？">

$899 の Agency プランには無制限の商用クライアントライセンスが含まれているため、請求するクライアントの数だけ納品できます。Core と Complete のプランは、自社のプロダクトが対象です。3 つのプランはいずれも買い切りで、コアの無期限アップデートが付きます。

</Accordion>

<Accordion title="すべての機能を使う必要がありますか？">

いいえ。CLI は構成に関する質問を行い、回答した内容だけを書き出します。そのため、課金、コンテンツ、メールは、それぞれ `--no-billing`、`--no-content`、`--no-email` フラグで除外できます。7 つのモジュールは常に生成され、残りの 3 つは希望した場合にのみ生成されます。

</Accordion>

<Accordion title="SaaSy Land はオープンソースですか？">

公開 Web サイトのソースコードは MIT ライセンスです。一方、別途提供する CLI と非公開テンプレートはプロプライエタリです。ライセンスを購入して saasyland.com にサインインし、CLI のインストールと利用に必要なキーを取得してください。オンラインでのライセンス認証は CLI に適用されます。生成したアプリケーションは商用ライセンスの下で編集・デプロイでき、実行時のキーは不要です。Web サイトのライセンスによって SaaSy Land の商標権が付与されることはありません。

</Accordion>

<Accordion title="このページの説明どおりの製品だと、どうすれば確認できますか？">

支払う前に確認してください。ドキュメントは公開されており、カバレッジレポートはスクリーンショットではなくリポジトリ自体が生成し、ゲートを強制する CI ワークフローはそのリポジトリ内のファイルです。このページの数字はすべてコマンドかパスに対応しており、上の検証用の表に一覧にしています。

</Accordion>

<Accordion title="AI エージェントに作らせればよいのではありませんか？">

作れますし、結果はもっともらしく見えるでしょう。しかし、どの認証のエッジケースを飛ばしたのか、どの Webhook が冪等でないのか、そして書かれなかった翻訳のパリティチェックがあれば欠落したキーを検出できていたことは教えてくれません。エージェントの出力は、それをレビューしたチェックと同じ程度にしか信頼できません。そして、空のリポジトリにはチェックが 1 つもありません。

</Accordion>
