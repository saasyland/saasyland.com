## Pedir um link

`/auth/forgot-password` mostra `ForgotPasswordForm`. Ele chama `requestPasswordReset` (`src/modules/verification/use-cases/request-password-reset.ts`, limitada por `RATE_LIMITS.SENSITIVE`) com `redirectTo` apontando para `/auth/reset-password` no idioma atual. Em seguida, o Better Auth chama `sendResetPasswordEmail`, que envia o template `ResetPasswordEmail`.

## Definir uma nova senha

O link do e-mail abre `/auth/reset-password?token=…`. Sem token, ou com `?error=`, a página mostra a mensagem de link inválido e um link de volta para `/auth/forgot-password`. Com um token, `ResetPasswordForm` chama `resetPassword` (limitada por `RATE_LIMITS.TOKEN`) e navega para `/auth/sign-in`. Como `revokeSessionsOnPasswordReset` está ativado, todas as sessões existentes desse usuário são encerradas.

## Outras trocas de senha

- Usuários logados trocam a senha em **Configurações → Segurança** ([Configurações](/docs/features/settings)).
- Administradores definem a senha de outro usuário pela tabela de usuários ([Usuários (admin)](/docs/features/users-admin)).
