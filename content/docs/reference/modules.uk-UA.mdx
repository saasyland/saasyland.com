---
title: Модульний каталог
description: Інвентаризація доменів src/modules та власності.
---

| Модуль         | Власність                                                            |
| -------------- | -------------------------------------------------------------------- |
| `_core`        | Помилки, локальні / валютні / часові каталоги, спільні utils         |
| `account`      | Веб-сайт: www.facebook.com                                           |
| `user`         | Адміністрування користувачів адміністратора + імперіативні помічники |
| `session`      | Список / Відкликання сеансів                                         |
| `two-factor`   | Увімкнути / перевірити / вимкнути                                    |
| `verification` | Перевірка електронної пошти + списання пароля                        |
| `product`      | Виготовлення запчастин                                               |
| `category`     | Категорія використання-кейси                                         |

Додайте рядок, коли ви вводите нову папку домена.
