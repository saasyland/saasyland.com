| Ruta                                                    | Contenido                                                                                                                                                                                                             |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/presentation/components/shadcn/`                   | Primitivas de shadcn generadas, variante React Aria                                                                                                                                                                   |
| `src/presentation/components/custom/`                   | Componentes de la aplicación: archivos compartidos en plano (`footer.tsx`, `navigation.tsx`, `data-table.tsx`, `locale-switcher.tsx`, …) y las carpetas por área `admin/`, `app/`, `auth/`, `blog/` y `landing-page/` |
| `src/presentation/styles/`                              | `globals.css` (Tailwind, tokens, escala tipográfica), `fonts.css`, `docs.css`, `typeset.css`                                                                                                                          |
| `src/presentation/theme/`, `src/presentation/branding/` | Constantes de tema y de marca                                                                                                                                                                                         |
| `src/presentation/document-assets.ts`                   | Hoja de estilos global y precarga de fuentes                                                                                                                                                                          |
| `src/providers/`                                        | `AriaProvider`, `ThemeProvider`, `TranslationsProvider`, `MotionProvider`                                                                                                                                             |

## En este capítulo

- [Componentes de shadcn](/docs/ui/shadcn-components): las primitivas y cómo las usan las pantallas.
- [DataTable](/docs/ui/data-table): el único componente de tabla.
- [Tema](/docs/ui/theme): los temas claro, oscuro y del sistema, y los tokens CSS.
- [Fuentes y marca](/docs/ui/fonts-and-branding): fuentes alojadas en el propio proyecto, precargas y constantes de marca.
- [Patrones de composición](/docs/ui/composition-patterns): cómo encajan rutas, páginas y componentes.
