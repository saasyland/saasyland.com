## データ

`src/modules/product/product.schema.ts` は `product` テーブルを定義します。列は `name`、`description`、`priceCents`、`currency`、`type`（`one_time`、`subscription`、`course`）、`status`（`draft`、`published`、`archived`）、`billingCycle`、タイムスタンプです。

`src/modules/product/use-cases` のユースケースは、それぞれ対応する `product` 権限で保護されています。

- `getProducts` — ページ分割に対応し、`type` と `status` のフィルターを任意で指定できます。`getProductsPageQuery` と `getProductsQuery` をエクスポートします。
- `getProduct`、`createProduct`、`updateProduct`、`deleteProduct`。

## 管理画面

`/admin/products` は選択中のタブを検索パラメーター `?tab=` に保持します。値は `all`、`onetime`、`subscriptions`、`categories`、`collections`、`drafts` です。商品タブは `useProductColumns` を使った `DataGrid` である `ProductGrid`（`product-grid.tsx`）を表示し、各リクエストにタブの種類またはステータスを加えます。

```tsx
<DataGrid
  columns={columns}
  empty={t("empty")}
  id={PRODUCT_GRID_ID}
  label={label}
  query={(request) => getProductsPageQuery(productZodSchemas.getProducts.parse({ ...request, ...preset }))}
  search={t("search")}
  selectable
/>
```

`getProducts` はサーバー側で名前と説明を検索し、名前、種類、ステータス、商品の通貨での価格、作成日と更新日で絞り込み、すべての列で並べ替えます。`categories` と `collections` は `useCategoryColumns` と `getCategoriesPageQuery` を使って `CategoryGrid`（`category-grid.tsx`）を表示します（[カテゴリー](/docs/features/categories)を参照）。コースには専用の画面 `/admin/courses` があります（[コース](/docs/features/courses)を参照）。ダッシュボードのカウンターも `getProductsQuery` を読み取ります。

一覧は読み取り専用で、チェックボックスで商品を選択して CSV に書き出せます。列は商品、種類、価格、ステータス、更新日で、作成日は「列」メニューに控えています。作成フォームと行のメニューはありません。`createProduct`、`updateProduct`、`deleteProduct`、`getProduct` に接続された画面がまだないためです。また、売上の列を設けるにはこれらの行と Polar の商品との対応付けが必要ですが、このテーブルにはそれがありません。

`getProducts` は各行の `currency` を `currencyCodeField` で `CURRENCIES` の ISO 4217 コードと照合します。不明な通貨の価格を表示するより、一覧の読み込みを失敗させます。価格の列は `priceCents` を `fromMinorUnits` で通貨の主単位に換算し、ページの言語に合わせて書式を整えます。英語のページでは、最小単位で 4900 の価格は、USD では $49.00、指数が 0 の JPY では ¥4,900 と表示されます。

購入処理はこのテーブルを使いません。購入できるプランは Polar の商品です（[ライセンス](/docs/features/licences)を参照）。
