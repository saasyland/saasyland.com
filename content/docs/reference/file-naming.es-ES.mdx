title: "Nomenclatura de archivos"
description: "Patrones de nombre y sufijos de archivo que se usan en src, messages, content y e2e."
---

Todos los archivos y carpetas usan kebab-case.

## Archivos de código fuente

| Patrón                                                       | Significado                                                                                                                                           |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | Ruta basada en archivo; los puntos son segmentos de la ruta, `_` marca un layout sin segmento de ruta, `$` una ruta comodín e `index` una ruta índice |
| `src/routes/api/<name>.ts`                                   | Handler HTTP                                                                                                                                          |
| `modules/<table>/<table>.schema.ts`                          | Tabla de Drizzle                                                                                                                                      |
| `modules/<table>/<table>.zod.ts`                             | Esquemas Zod                                                                                                                                          |
| `modules/<table>/<table>.constants.ts`                       | Claves de consulta, claves de mutación y enums                                                                                                        |
| `modules/<table>/<table>.types.ts`                           | Tipos derivados de la tabla                                                                                                                           |
| `modules/<table>/<table>.utils.ts`                           | Utilidades puras para la tabla                                                                                                                        |
| `modules/<table>/<table>.server.ts`                          | Utilidades solo de servidor del módulo                                                                                                                |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | Un caso de uso                                                                                                                                        |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | Configuración o adaptador de un proveedor, por ejemplo `auth.server.ts`                                                                               |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | Columnas de una tabla de datos                                                                                                                        |
| `presentation/emails/<name>.tsx`                             | Plantilla de correo que exporta `<NAME>_NAMESPACE`                                                                                                    |
| `hooks/use-<name>.ts`                                        | Hook de React compartido                                                                                                                              |
| `providers/<name>-provider.tsx`                              | Provider de la aplicación                                                                                                                             |

## Pruebas

| Patrón                                | Ejecutor                         |
| ------------------------------------- | -------------------------------- |
| `__test__/<file>.test.ts`             | Proyecto `node` de Vitest        |
| `__test__/<file>.integration.test.ts` | Proyecto `integration` de Vitest |
| `__test__/<file>.component.test.tsx`  | Proyecto `component` de Vitest   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                       |

Los archivos de prueba se nombran como el archivo fuente que cubren, por ejemplo `user.schema.test.ts` para `user.schema.ts`.

## Contenido y mensajes

| Patrón                                    | Significado                                                   |
| ----------------------------------------- | ------------------------------------------------------------- |
| `messages/<locale>/<namespace>.json`      | Namespace de traducción, por ejemplo `pages.admin.users.json` |
| `content/docs/<path>/<page>.<locale>.mdx` | Página de la documentación                                    |
| `content/docs/<path>/meta.<locale>.json`  | Navegación de la documentación                                |
| `content/blog/<slug>.<locale>.mdx`        | Artículo del blog                                             |
