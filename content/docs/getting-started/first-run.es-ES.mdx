## Preview de pruebas aislada

La preview de pruebas compila la aplicación para el entorno `test`: D1, KV y R2 locales en `.wrangler/test`, credenciales ficticias de `.env.test`, cuentas precargadas y solicitudes a Resend y a Polar interceptadas. No necesita cuentas.

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

Abre http://127.0.0.1:3000 e inicia sesión con una de las cuentas que precarga `e2e/data/accounts.ts`. Todas usan la contraseña <RepositoryFact name="testPassword" />. Los administradores llegan a `/admin` y los clientes a `/app`, y las cuentas con licencia y sus licencias vienen de `e2e/data/licenses.ts`. La licencia Complete abre todas las lecciones de pago del curso de ejemplo.

<RepositoryTable columns={["Correo electrónico", "Rol", "Licencia"]} name="seededAccounts" />

La preview sirve una compilación, así que vuelve a compilarla para ver los cambios en el código fuente.

## Desarrollo con Cloudflare

`bun run dev` inicia el servidor de desarrollo con recarga en caliente en http://localhost:3000. Sus bindings `DB`, `CACHE`, `MEDIA` y `BUNDLES` son locales, en `.wrangler/state`, así que el desarrollo nunca lee ni escribe los datos de preview o de producción y no necesita iniciar sesión en Cloudflare.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

1. Rellena `.env.development` como se describe en [Variables de entorno](/docs/getting-started/environment-variables), con `POLAR_SERVER=sandbox`.
2. Crea la base de datos local y aplica las migraciones con `db:reset:local`.
3. Siémbrala con `db:seed:local`: un administrador, el temario de los cursos, licencias y un pedido.
4. Inicia el servidor e inicia sesión como <RepositoryFact name="localAdminEmail" /> con `LOCAL_ADMIN_PASSWORD` de `.env.development`, o con <RepositoryFact name="localAdminPassword" /> si no está definida.

`bun run db:studio:local` abre los datos locales en Drizzle Studio. El registro por correo electrónico necesita una configuración de Resend que funcione: una cuenta nueva inicia sesión al momento, pero su clave de licencia y las lecciones de pago esperan al enlace de confirmación, y volver a iniciar sesión exige una dirección confirmada. [Base de datos](/docs/tooling/database) describe las tres bases de datos, el seed y cómo crear el primer administrador en preview y en producción.
