## 管理画面

アナリティクスの画面はありません。[管理ダッシュボード](/docs/features/admin-dashboard)は D1 にあるデータを表示します。Polar の注文のコピーから算出した売上、新規アカウント、コースの進捗、ニュースレターの購読者です。ページビュー、訪問者数、リテンション、チャーンには、アプリが持たないアナリティクスのデータソースが必要なため、どの画面にも表示されません。

## 収集されるもの

アナリティクスのスクリプトはインストールされておらず、イベントも保存されません。唯一のサードパーティのスクリプトは Affonso の紹介ピクセルで、URL に紹介パラメーターが含まれる訪問で、かつ `AFFONSO_PROGRAM_ID` が設定され、`AFFILIATE_PROGRAM` がプログラムの開始を示している場合にのみ読み込まれます（[アフィリエイトプログラム](/docs/features/affiliates)）。`wrangler.jsonc` で Workers の `observability` が有効になっているため、失敗したサーバー関数の `console.error` 出力を含む Worker のログを Cloudflare ダッシュボードで確認できます。
