| Ścieżka                                                 | Zawartość                                                                                                                                                                                                                                            |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/presentation/components/shadcn/`                   | Wygenerowane komponenty bazowe shadcn w wariancie React Aria                                                                                                                                                                                         |
| `src/presentation/components/custom/`                   | Komponenty aplikacji: płasko ułożone pliki współdzielone (`footer.tsx`, `navigation.tsx`, `data-grid.tsx`, `locale-switcher.tsx`, …) oraz foldery obszarów `admin/`, `app/`, `auth/`, `billing/`, `blog/`, `courses/`, `landing-page/` i `settings/` |
| `src/presentation/styles/`                              | `globals.css` (Tailwind, tokeny, skala typograficzna), `fonts.css`, `docs.css`, `typeset.css`                                                                                                                                                        |
| `src/presentation/theme/`, `src/presentation/branding/` | Stałe motywu i marki                                                                                                                                                                                                                                 |
| `src/presentation/document-assets.ts`                   | Globalny arkusz stylów i wstępne ładowanie czcionek                                                                                                                                                                                                  |
| `src/providers/`                                        | `AriaProvider`, `ThemeProvider`, `TranslationsProvider`, `MotionProvider`                                                                                                                                                                            |
