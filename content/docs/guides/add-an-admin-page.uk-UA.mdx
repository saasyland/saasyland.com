Сторінки адмін-панелі — це пласкі файли маршрутів під layout `/admin` (`src/routes/admin.tsx`), який виконує `requireAdmin` у `beforeLoad` і рендерить бічну панель, хлібні крихти та палітру команд. Наведені нижче кроки додають сторінку за адресою `/admin/reports`; повний реальний приклад — `src/routes/admin.orders.index.tsx`.

## 1. Додайте шлях

Додайте шлях до `ROUTES.ADMIN` у `src/routes.ts`, на його місці за абеткою:

```ts
REPORTS: `${ADMIN}/reports`,
```

Якщо сторінка належить можливості, яку проєкт може пропустити, додайте ще й це ім’я до `names` цієї можливості в `scripts/features.ts`, щоб `bun run check:features` разом із можливістю прибирав шлях і кожен пункт, що його називає.

## 2. Створіть файл маршруту

Створіть `src/routes/admin.reports.tsx`. Маршрут визначає лише компонент сторінки, `NAMESPACE`, loader, `head` і `pendingComponent`; генератор роутера реєструє файл у `src/routeTree.gen.ts`.

```tsx
import type { JSX } from "react"

import { createFileRoute } from "@tanstack/react-router"
import { useTranslations } from "use-intl/react"

import { loadPageMetadata, preloadNamespaces } from "~/src/integrations/use-intl/i18n.messages"
import { getCurrentLocale } from "~/src/integrations/use-intl/i18n.utils"

import { pageHead } from "~/src/lib/seo"

import { AdminPageHeader } from "~/src/presentation/components/custom/admin/admin-page-header"
import { AdminReportsPending } from "~/src/presentation/components/custom/admin/reports-pending"
import { ReportStats } from "~/src/presentation/components/custom/admin/reports/report-stats"

import { ROUTES } from "~/src/routes"

const ReportsPage = (): JSX.Element => {
  const t = useTranslations("pages.admin.reports")

  return (
    <div className="flex w-full flex-col space-y-8">
      <AdminPageHeader description={t("metadata.description")} title={t("metadata.title")} />

      <ReportStats />
    </div>
  )
}

const NAMESPACE = "pages.admin.reports"

export const Route = createFileRoute("/admin/reports")({
  component: ReportsPage,
  loader: async ({ context }) => {
    const locale = getCurrentLocale()
    const [metadata] = await Promise.all([
      loadPageMetadata({ locale, namespace: NAMESPACE }),
      preloadNamespaces({ locale, namespaces: [NAMESPACE], queryClient: context.queryClient }),
    ])
    return { locale, metadata }
  },
  head: pageHead(ROUTES.ADMIN.REPORTS),
  pendingComponent: AdminReportsPending,
  staticData: { namespaces: [NAMESPACE] },
})
```

Запити, потрібні сторінці, додаються до того самого `Promise.all`, наприклад `context.queryClient.query({ ...getUsersQuery, staleTime: "static" })` у `src/routes/admin.users.all.tsx`. `pageHead` будує заголовок, опис, канонічний URL і посилання на інші мовні версії з `metadata` loader. `AdminReportsPending` — це власний скелетон сторінки, який показується лише тоді, коли перехід триває понад <RepositoryFact name="navigationPendingMs" unit="millisecond" />. Напишіть його у файлі скелетонів його розділу, тут у новому `custom/admin/reports-pending.tsx`, з `AdminPageHeaderPending` з `admin-page-header.tsx` для заголовка та з блоків із `pending-blocks.tsx`, щоб він відтворював структуру сторінки. Скелетон layout адмін-панелі читає його з маршруту, тож він показується й тоді, коли хтось заходить на `/admin/reports` ззовні адмін-панелі.

Див. [Скелетони завантаження](/docs/architecture/delivery-layer#loading-skeletons).

## 3. Додайте пункт бічної панелі

Додайте пункт до `items` його групи бічної панелі в `ADMIN_NAVIGATION` (`src/data/navigation.ts`) там, де він має з’явитися, наприклад після пункту Панель у групі огляду. Пункт називає свою іконку з `lucide-react`, повний ключ свого підпису і свій шлях:

```ts
{ icon: FileText, label: "navigation.reports.admin.reports", to: ROUTES.ADMIN.REPORTS },
```

Додайте підпис як `admin.reports` до `messages/<locale>/navigation.reports.json` для кожної мови. Нова група також потребує значення в `ADMIN_NAVIGATION_GROUP`, місця серед груп `ADMIN_NAVIGATION` і `groups.<group>` у `pages.admin.sidebar`. Бічна панель, хлібні крихти й палітра команд ⌘K читають `ADMIN_NAVIGATION` (`src/data/navigation.ts`), тож сторінка з'являється в усіх трьох місцях. Головна сторінка зараховує її до розділів адмін-панелі, а у відео `app-tour` на головній сторінці вона з'явиться в бічному меню адмін-панелі після повторного рендерингу відео (див. `remotion/README.md`). Третій сегмент URL, наприклад `/admin/reports/create`, показує хлібну крихту, коли `breadcrumbs` пункту називає для нього підпис, як-от `breadcrumbs: { create: "navigation.reports.breadcrumbs.create" }`, а якщо ні, третьої крихти немає.

## 4. Додайте повідомлення сторінки

Створіть `messages/<locale>/pages.admin.reports.json` для кожної мови. `metadata` обов'язковий, бо loader читає його для заголовка документа:

```json
{
  "metadata": {
    "title": "Reports",
    "description": "Revenue and usage reports."
  }
}
```

## 5. Додайте віджети

Розмістіть кожен віджет, діалог, форму й набір колонок таблиці в окремому файлі в `src/presentation/components/custom/admin/reports/`, наприклад `report-stats.tsx` або `report-columns.tsx`. Віджети викликають `useTranslations("pages.admin.reports")` і самі читають свої дані через `useSuspenseQuery`; сторінка не передає їм ні міток, ні даних. Таблиці використовують `DataGrid`; див. [Додавання сітки даних](/docs/guides/add-a-data-table).

## 6. Захистіть і протестуйте

- Guard layout контролює доступ до сторінки. Кожна серверна функція, яку викликає сторінка, однаково потребує `authorized(permission)`; див. [Ролі та дозволи](/docs/guides/roles-and-permissions).
- `/admin` виключено з попереднього рендерингу.
- Додайте тести маршрутів можливості в `src/routes/__test__/admin-<feature>-routes.component.test.tsx` і `admin-<feature>-loaders.test.ts`, тести віджетів у `src/presentation/components/custom/admin/__test__/` і сторінку в `e2e/data/<feature>.pages.ts`, а потім запустіть `bun run check:i18n`, `bun run test:coverage` і `bun run check:features`.
