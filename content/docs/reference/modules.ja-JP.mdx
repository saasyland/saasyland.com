モジュールは、実在するデータベーステーブルのためだけに存在します。各テーブルは `src/integrations/drizzle-orm/drizzle.schemas.ts` に登録されます。

| モジュール              | テーブル                           | ユースケース                                                                                                                                                                        |
| ----------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `account`               | `account`                          | `sign-up-with-password`、`sign-out-user`、`update-user`、`change-email`、`change-password`、`send-change-email-confirmation-email`                                                  |
| `category`              | `category`                         | `get-categories`、`get-category`、`create-category`、`update-category`、`delete-category`                                                                                           |
| `license`               | `license`、`revoked_license_order` | `get-current-license`、`get-license`、`start-checkout`、`deactivate-license`、`grant-license`、`revoke-license`、`attach-license-key`                                               |
| `newsletter-subscriber` | `newsletter_subscriber`            | `subscribe-to-newsletter`、`confirm-newsletter-subscription`、`unsubscribe-from-newsletter`、`get-newsletter-subscription`、`set-newsletter-subscription`                           |
| `product`               | `product`                          | `get-products`、`get-product`、`create-product`、`update-product`、`delete-product`                                                                                                 |
| `rate-limit`            | `rate_limit`                       | なし。`src/lib/rate-limit.ts` から使用                                                                                                                                              |
| `session`               | `session`                          | `get-active-sessions`、`revoke-session`、`revoke-other-sessions`、`list-user-sessions`、`revoke-user-session`、`revoke-user-sessions`                                               |
| `two-factor`            | `two_factor`                       | `enable-two-factor`、`disable-two-factor`、`verify-totp`、`verify-backup-code`                                                                                                      |
| `user`                  | `user`                             | `get-users`、`get-user`、`create-user`、`update-user`、`delete-user`、`ban-user`、`unban-user`、`set-user-role`、`set-user-password`、`impersonate-user`、`stop-impersonating-user` |
| `verification`          | `verification`                     | `send-verification-email`、`send-verify-email`、`request-password-reset`、`reset-password`、`send-reset-password-email`                                                             |
| `video`                 | `video`                            | `get-videos`、`get-video-playback`、`delete-video`                                                                                                                                  |

`_core` はテーブルを所有しません。[Core 共有カーネル](/docs/architecture/core)で説明している、共有のエラーコード、カタログ、ヘルパーを保持します。

## 標準セット以外のファイル

ほとんどのモジュールには、`<table>.schema.ts`、`.zod.ts`、`.constants.ts`、`.types.ts`、`.utils.ts`、`use-cases/` しかありません。いくつかのモジュールには、追加のファイルがあります。

- `license/license.webhooks.ts`：Better Auth に渡される Polar の Webhook ハンドラー
- `license/license.ppp.ts`：チェックアウト用の地域別価格の割引
- `newsletter-subscriber/newsletter-subscriber.server.ts`：ニュースレターのリンクに対するリクエストのオリジンチェック
- `video/video.files.ts`：R2 のオブジェクトキーと、保存・配信できるファイルとそのメディアタイプ
- `video/video.playback.ts`：署名済みの再生パス（`createPlayback`、`verifyPlayback`）
- `video/video.delivery.ts`：`/media/` リクエストに Workers のキャッシュまたは R2 から応答する `serveMedia`
- `video/video.encoding.ts`：`scripts/publish-video.ts` が実行する FFmpeg の計画（レンディション、引数、ストーリーボード）

## サーバー側で実行されるプレーンなユースケース

次のユースケースは、RPC エンドポイントを持たない async 関数です。Better Auth のフック、Polar の Webhook ハンドラー、または他のユースケースから呼び出されます。対象は `send-verify-email`、`send-reset-password-email`、`send-change-email-confirmation-email`、`grant-license`、`revoke-license`、`attach-license-key`、`get-license` です。
