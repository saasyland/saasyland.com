---
title: "コンテンツアクセス"
description: "アクセスを制御しているもの: ルートガード、権限、ライセンスの記録、コースの各レッスンのアクセスレベル。"
---

アクセスは次のもので制御されています。

- **ルートガード**: `/app` はセッションを要求し（`requireSignedIn`）、`/admin` は `admin: ["access"]` 権限を要求します（`requireAdmin`）。
- **サーバー関数**: `authorized(permission)` が `auth.access.ts` のロール権限を確認します。
- **ライセンス**: `license` テーブルはユーザーごとに最大 1 件のライセンスを `tier`（`core`、`complete`、`agency`）と `status`（`active`、`revoked`）付きで保持し、Polar の Webhook が書き込みます。`/app` と `/app/license` は `currentLicenseQuery` でこれを読み取り、ティアのカードかライセンスキーを表示します。また、ライセンスが `active` の間、`startCheckout` は新しい購入手続きを拒否します。
- **レッスン**: コースの各レッスンは `preview`（全員）、`account`（サインイン済みのユーザー）、`paid`（ティア `complete` または `agency` の `active` なライセンス）のいずれかで、`course: ["read"]` を持つロールはすべてのレッスンを視聴できます。`getCourse` は視聴者が見られないレッスンをロック済みとして示し、`getLessonPlayback` と `saveLessonProgress` はそれらを拒否するため、判定はページに依存しません。[コース](/docs/features/courses)を参照してください。

制限されているコンテンツはレッスンだけです。`/premium`（`src/routes/_landing.premium.tsx`）は、`pages.premium` のタイトルだけを表示するプレースホルダーです。

ほかのものを購入者だけに公開するには、`src/modules/lesson/lesson.viewer.ts` の `resolveViewer` と同じように、サーバー側で `src/modules/license/use-cases/get-license.ts` の `getLicense(userId)` を使ってライセンスを読み取り、`status` と `tier` を確認します。
