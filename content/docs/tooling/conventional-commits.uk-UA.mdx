---
title: "Conventional commits"
description: "Формат повідомлень комітів і хук з емодзі."
---

Заголовки комітів мають формат `<type>(<scope>): <description>`. Область (scope) необов'язкова, а `!` позначає несумісну зміну. Пишіть заголовок без емодзі:

```sh
git commit -m "fix(auth): keep the locale in verification links"
```

Хук `prepare-commit-msg` у `.vite-hooks/` запускає `bun scripts/commit-msg.ts`, який перевіряє заголовок і додає на початок емодзі відповідного типу, тож наведений вище коміт стає `🐛 fix(auth): keep the locale in verification links`.

| Тип        | Емодзі |
| ---------- | ------ |
| `build`    | 🛠️     |
| `chore`    | ♻️     |
| `ci`       | ⚙️     |
| `docs`     | 📚     |
| `feat`     | ✨     |
| `fix`      | 🐛     |
| `perf`     | 🚀     |
| `refactor` | 📦     |
| `revert`   | 🗑️     |
| `style`    | 💎     |
| `test`     | 🚨     |

Будь-який інший тип або заголовок не у форматі conventional commits перериває коміт і виводить список дозволених типів. Хук не змінює заголовки, які вже починаються з емодзі або які згенерував Git (`Merge`, `Revert "`, `fixup!`, `squash!`), а також повідомлення злиття, squash і шаблонів.

Перед хуком повідомлення хук `pre-commit` запускає `bun run check:pre-commit`. Не обходьте хуки.
