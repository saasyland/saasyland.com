- Corretto: `bun run check:features` pota gli script di `package.json` con la stessa regola del codice: un passo che avvia un file eliminato o uno script che se ne va viene rimosso, e così uno script rimasto senza passi, quindi un sito senza i contenuti non tiene più un `check:content` che punta a un file eliminato. Ogni scenario fallisce anche quando uno script nomina ancora un file eliminato o ne avvia uno che non c’è più. Vedi [Test](/docs/conventions/testing#tests-follow-the-features).
