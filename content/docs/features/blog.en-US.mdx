## Content

Posts live in `content/blog/<slug>.<locale>.mdx`, one file per locale. The frontmatter schema in `src/integrations/fumadocs/fumadocs.config.ts` requires `title`, `authorName` and `date`, and accepts `description`, `authorImage`, `excerpt`, `faq`, `featured`, `image`, `published` (default `true`), `tags` and `updated`.

## Figures from the code

A post prints the values the code defines instead of typing them: `<RepositoryFact>` for counts, the coverage threshold (`coverageThreshold`), React's major version (`reactMajor`), the illustrative hourly rate (`illustrativeHourlyRate`, with `unit="currency"`) and the hours the Core price buys (`corePriceInHours`, with `unit="hour"`), and `<TierPrice>`, `<ActivationLimit>` and `<HeadStartTable />` for prices, machine limits and the head start. The `title` and the `faq` questions and answers are ICU messages: `formatPostText` in `src/lib/post-text.ts` formats them with `REPOSITORY_FACTS` and each tier's `<tier>Price` and `<tier>Machines`. `toBlogPostSummary` formats the title, and `<PostFaq entries={frontmatter.faq} />` renders the FAQ that the post's FAQPage JSON-LD also reads. `post-faq.test.ts` formats every post's title, questions and answers in its locale.

## Source

`blogSource` in `fumadocs.source.ts` loads the collection under `/blog` with the same i18n settings as the docs. `getPublishedBlogPosts(locale)` returns published posts, newest first, as summaries with a reading time counted with `Intl.Segmenter` for that locale.

## Routes

- The `/blog` layout (`_site._marketing.blog.tsx`) sits in the `_site` and `_marketing` layouts, which add the site header, `PageFrame`, `Footer` and `BackToTop` around it (see [Landing page](/docs/features/landing-page#navigation-and-back-to-top)). It loads `docs.css` for article typography. The header marks **Blog** as the current section on the index and on every post.
- `/blog` (`_site._marketing.blog.index.tsx`) lists posts with `PostRow`; the list comes from a server function defined in the route file.
- `/blog/$` (`_site._marketing.blog.$.tsx`) loads one post (404 when unpublished), preloads its compiled MDX with `blogContent`, and composes `PostMeta`, `PostToc` (or `InlineTOC` on small screens), `PostCta` and `PostShare` from `src/presentation/components/custom/blog`. It adds JSON-LD from `buildBlogPostStructuredDataHtml` and article metadata from `buildPageHead`, with the blog's title from `pages.blog` as its `article:section` and its own social card; see [Search and social previews](/docs/features/seo).

The landing page Notes section shows the three latest posts.

## Admin blog (demo)

`/admin/blog` and `/admin/blog/create` render demo posts and stats from `src/data/admin-blog.ts` and a static editor. They do not read or write `content/blog`.

## Checks

Run `bun run content` after adding a post. `bun scripts/check-content.ts` verifies that every locale exists, that titles, descriptions and excerpts are translated, and that code blocks are identical.
