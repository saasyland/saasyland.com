- Changed: every dependency is on its latest release. Fumadocs, Video.js, TanStack Query, Lucide, React Email, React Resizable Panels, Testing Library's `user-event` and Wrangler took their patch releases. - Changed: the docs use Fumadocs' own skip link instead of a patch that removed it, so `@fumadocs/base-ui` is no longer patched or pinned. The link stays the first stop of the Tab key, because the docs layout now renders the site header after it, it carries the site's label and focus style, and it jumps to the article, whose id is Fumadocs' `nd-page` again. The other public pages keep the site's own skip link, which the marketing layout now renders. See [Docs site](/docs/features/docs-site).
