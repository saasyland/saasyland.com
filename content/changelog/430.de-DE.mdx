- Behoben: Die Browsertests scheitern nicht mehr zufällig bei der Installation des Browsers. Die Ubuntu-Runner von GitHub bringen die Paketquelle von Microsoft mit, die manchmal mit einem Fehler antwortete, und die Installation las jede Quelle. Deshalb entfernen jetzt jeder Shard und die Journey-Suite diese Quelle, die kein Schritt nutzt, bevor sie den Browser installieren. Siehe [CI/CD](/docs/tooling/ci-cd#checks).
