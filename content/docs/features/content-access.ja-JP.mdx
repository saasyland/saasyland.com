---
title: "コンテンツアクセス"
description: "現在アクセスを制御しているもの: ルートガード、権限、ライセンスの記録。プレミアムコンテンツの制限はありません。"
---

制限付きのプレミアムコンテンツはありません。アクセスは次のもので制御されています。

- **ルートガード**: `/app` はセッションを要求し（`requireSignedIn`）、`/admin` は `admin: ["access"]` 権限を要求します（`requireAdmin`）。
- **サーバー関数**: `authorized(permission)` が `auth.access.ts` のロール権限を確認します。
- **ライセンス**: `license` テーブルはユーザーごとに最大 1 件のライセンスを `tier`（`core`、`complete`、`agency`）と `status`（`active`、`revoked`）付きで保持し、Polar の Webhook が書き込みます。`/app` と `/app/license` は `currentLicenseQuery` でこれを読み取り、購入オプションかライセンスキーを表示します。

`/premium`（`src/routes/_landing.premium.tsx`）は、`pages.premium` のタイトルだけを表示するプレースホルダーです。

購入者だけに何かを公開するには、サーバー側で `src/modules/license/use-cases/get-license.ts` の `getLicense(userId)` を使ってライセンスを読み取り、`status` と `tier` を確認します。
