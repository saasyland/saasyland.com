ローカルクエリが不足しているテーブルを報告する場合、実行 `bun run db:migrate:local`; ブラウザのテストの使用 `db:migrate:test` 別の D1 の結合。 認証が失敗した場合は、環境 URL を確認してください。 `AUTH_SECRET`プロバイダーの認証情報とコールバックURL。

翻訳エラーを見逃すと、通常、ルートから省略された名前空間や、1つのロケールで欠落しているキーが表示されます。 ログイン `check:i18n`. . ドキュメント 404s の場合、ローカライズされた MDX ファイル名、ページメタデータ、および相対ソースリンクを確認します。 プレンダーの失敗については、ビルド出力で最初の失敗URLを調べます。

プレースホルダーのバインディングには、ターゲット環境で D1 と KV ID が使われます。 ビルドとテストの操作は、リモートリソースを自動的に作成しません。
