- Documentación y blog: todas las páginas cumplen WCAG 2.2 AA en ambos temas. El naranja de GitHub Light y el gris de los comentarios de GitHub Dark se sustituyen en `fumadocs.config.ts` para que todos los tokens de código alcancen 4,5:1, las casillas de las listas de tareas toman su nombre de su elemento, y un parche de Bun para `@fumadocs/base-ui` 16.19.0 hace que un bloque de código solo sea un landmark de región cuando su título le da nombre, así que las páginas con varios bloques de código ya no tienen landmarks duplicados sin nombre. `accessibility.spec.ts` también analiza todas las páginas de Convenciones, una página de cada sección de la documentación y una entrada del blog en ambos temas, y falla cuando una página analizada no se carga.
