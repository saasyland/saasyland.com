---
title: "Introdução"
description: "Adaptadores de fornecedores em src/integrations."
---

Cada pasta em `src/integrations/<vendor>/` encapsula um fornecedor em arquivos `<vendor>.<concern>.ts`: configuração, clientes e adaptadores enxutos. Regras de negócio e operações de banco de dados ficam em `src/modules`, e os componentes nunca importam diretamente o cliente de um fornecedor.

| Pasta           | Arquivos                                                                                                        | Finalidade                                                             |
| --------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `better-auth`   | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.session.ts` | Sessões, OAuth, guards de rota, middleware de server functions, papéis |
| `drizzle-orm`   | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `migrations/`                                 | Cliente D1, barrel de schemas, configuração do drizzle-kit             |
| `fumadocs`      | `fumadocs.config.ts`, `fumadocs.i18n.ts`, `fumadocs.source.ts`, `fumadocs.docs.ts`, `fumadocs.search.ts`        | Coleções da documentação e do blog, fontes localizadas, busca          |
| `motion`        | `motion.features.ts`, `motion.tokens.ts`                                                                        | Recursos do Motion carregados sob demanda e transições compartilhadas  |
| `polar`         | `polar.config.ts`, `polar.constants.ts`                                                                         | Cliente do SDK da Polar e produtos do checkout                         |
| `resend`        | `resend.config.ts`, `resend.utils.ts`                                                                           | Cliente do Resend e `sendEmail`                                        |
| `tanstack-form` | `form.fields.ts`                                                                                                | `fieldErrorMessage` para erros de campos de formulário                 |
| `use-intl`      | `i18n.config.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                    | Locales, namespaces de mensagens, middleware de locale, helpers de URL |
