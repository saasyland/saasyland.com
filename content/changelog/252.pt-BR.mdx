- Adicionado: o post [Lições aprendidas ao rodar uma equipe de agentes de programação com IA em uma única base de código](/blog/running-ai-coding-agents-in-parallel), um guia para rodar vários agentes de programação com IA em paralelo no mesmo repositório de produção: um worktree, uma porta, um banco de dados e uma pasta temporária por agente, uma única fila de merge com commits squash e histórico linear, por que commits de merge são proibidos, códigos de saída em vez de resumos, todas as verificações de novo depois de cada rebase, os limites de permissão, como fazer o briefing de um agente e revisar o pull request dele, carga e custo, e a recuperação, com os próprios incidentes do saasyland.com como exemplos práticos e um playbook para copiar.
