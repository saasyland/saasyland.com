---
title: "Introduction"
description: "Vendor adapters under src/integrations."
---

Each folder in `src/integrations/<vendor>/` wraps one vendor in `<prefix>.<concern>.ts` files, where the prefix is the vendor's short name (`auth`, `drizzle`, `i18n`, `form`): configuration, clients and thin adapters. Business rules and database operations stay in `src/modules`, and components never import a vendor client directly.

| Folder           | Files                                                                                                                                                                                           | Purpose                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `affonso`        | `affonso.constants.ts`, `affonso.program.ts`, `affonso.referral.ts`                                                                                                                             | Affiliate referral parameters, the program ID and the checkout metadata                                                  |
| `better-auth`    | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.roles.ts`, `auth.session.ts`                                                                | Sessions, OAuth, plugins, route guards, server-function middleware, roles and permissions                                |
| `drizzle-orm`    | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `drizzle.local.config.ts`, `drizzle.errors.ts`, `drizzle.columns.ts`, `drizzle.time-series.ts`, `migrations/`                 | D1 client, schema barrel, drizzle-kit configuration, `rethrowAsConflict`, `timestamps()`, `bucketOf`                     |
| `fumadocs`       | `fumadocs.config.ts`, `fumadocs.schema.ts`, `fumadocs.i18n.ts`, `fumadocs.indexes.ts`, `fumadocs.docs.ts`, `fumadocs.blog.ts`, `fumadocs.changelog.ts`, `fumadocs.icons.ts`, `fumadocs.vite.ts` | Docs and blog collections, build-time indexes, search, the changelog entries and the sidebar icons                       |
| `motion`         | `motion.features.ts`, `motion.tokens.ts`                                                                                                                                                        | Lazily loaded Motion features and shared transitions                                                                     |
| `polar`          | `polar.config.ts`, `polar.constants.ts`, `polar.customers.ts`, `polar.webhooks.ts`, `polar.vite.ts`                                                                                             | Polar SDK client, Polar's own values, customer accounts, the code each webhook event reaches and the SDK's build setting |
| `resend`         | `resend.config.ts`, `resend.utils.ts`                                                                                                                                                           | Resend client, `sendEmail` and `EMAIL_PURPOSE`                                                                           |
| `takumi`         | `takumi.fonts.ts`, `takumi.render.tsx`                                                                                                                                                          | Renders the social cards and the organisation logo at build time with the site's own fonts                               |
| `tanstack-form`  | `form.fields.ts`, `form.submit.ts`                                                                                                                                                              | `fieldErrorMessage` for form field errors, and `submitForm` and `showFieldError`, which mark and focus the invalid field |
| `tanstack-query` | `query.cache.ts`                                                                                                                                                                                | Default cache times of the per-request `QueryClient`                                                                     |
| `use-intl`       | `i18n.config.ts`, `i18n.loaders.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                                                                                 | Locales, message namespaces, locale middleware, URL helpers                                                              |
| `zod`            | `zod.config.ts`, `zod.vite.ts`                                                                                                                                                                  | Runs Zod `jitless` in the browser, so it never probes for `eval` under the Content Security Policy                       |
