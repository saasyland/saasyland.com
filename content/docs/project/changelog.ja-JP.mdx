各セクションには、その日（UTC）に `main` に入った変更を新しい順に記載し、各変更の末尾にはその変更のプルリクエストへのリンクを付けます。本番へのデプロイにはそれぞれタグが付き、その日のセクションをリリースノートとする GitHub Release として公開されます。[リリースとタグ](/docs/tooling/ci-cd#releases-and-tags)を参照してください。CLI 自体のリリースは [CLI のリリースノート](/docs/cli/releases)にあります。変更はそれぞれ専用のエントリを追加します。[変更履歴のエントリ](/docs/conventions/git-workflow#changelog-entries)を参照してください。
