- Corregido: cada viñeta del [registro de cambios](/docs/project/changelog) termina con la pull request de la que viene y la versión que la publicó, no solo la última viñeta de cada entrada, y cada viñeta de una GitHub Release termina con su `(#<number>)`. Una entrada del registro de cambios que no sea una lista de viñetas de una línea hace fallar ahora `bun run check`. Consulta [Entradas del registro de cambios](/docs/conventions/git-workflow#changelog-entries).
