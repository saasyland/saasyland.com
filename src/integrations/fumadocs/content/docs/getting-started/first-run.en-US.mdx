## Database

```bash
bun run db:migrate
# prototype-only alternative (not for shared envs):
# bun run db:push
```

Inspect schema with `bun run db:studio`. For preview or production, run the matching `bun run env:pull:preview|production` once, then `db:studio:preview|production` / `db:migrate:preview|production` — the target is always explicit in the command.

## Dev server

```bash
bun run dev
```

Visit `http://localhost:3000`. Locales are `en-US` and `pl-PL` (see `integrations/next-intl/i18n.config.ts`).

## Create an admin user

1. Sign up via `/auth/sign-up`
2. Verify email (Resend / logs depending on setup)
3. Promote the user to `admin` in the DB (or your seed path) — role codes live in `auth.access.ts` as `ROLE_CODES.ADMIN`
4. Open `/admin`

Auth callback routing: admins → `/admin`, customers → `/app` (`src/proxy.ts` + `ROUTES`).
