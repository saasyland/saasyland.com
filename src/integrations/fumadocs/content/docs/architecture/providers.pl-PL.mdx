## Registry (`src/providers`)

| Provider                | Role                                                                         |
| ----------------------- | ---------------------------------------------------------------------------- |
| `theme-provider`        | Next themes / class strategy                                                 |
| `nuqs-provider`         | `NuqsAdapter` + admin default options (`shallow: false`, `history: push`, …) |
| `translations-provider` | next-intl client                                                             |
| `docs-provider`         | Fumadocs UI wiring                                                           |
| `tooltip-provider`      | Shared tooltip scope                                                         |

Admin layout wraps the shell with `NuqsProvider` so URL state triggers server refreshes consistently.
