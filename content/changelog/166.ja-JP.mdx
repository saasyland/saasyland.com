- 修正: `/app/license` は購入者に `npx saasyland@latest init` を実行し、求められたらキーを入力するよう案内していましたが、`latest` は CLI の仮のリリースで、`init` はキーを受け付けません。このページは今後、`activate`、`whoami`、`deactivate` の各コマンドとその働きを表示し、CI が `SAASYLAND_LICENSE_KEY` からキーを読み取ることを示します。これらの唯一の情報源は `src/data/cli.ts` です。`CLI_RELEASE_CHANNEL` が npm のタグ（現在は `beta`）を表し、インストール済みの `@saasyland/stack` の公開時のタグと一致しなければテストが失敗します。そのため、依存関係を安定版に更新すると、同じ変更でランディングページのコマンド、リリースのブログ記事、ドキュメント、ジャーニースイートが npm のデフォルトのタグに切り替わります。端末の一覧と概要ページのドキュメントカードは、まだ存在しないプロジェクト生成やインストールガイドを約束しなくなりました。[CLI の手順](/docs/features/customer-app#cli-instructions)を参照してください。
- 修正: サインイン済みの購入者に対して、Polar のチェックアウトがメールアドレス欄の空いた状態で開いていました。Better Auth の Polar プラグインがアカウントの ID だけで購入セッションを作成するためです。`startCheckout` は今後、Polar SDK で購入セッションを作成し、アカウントのメールアドレスと名前を入力済みにします。Polar の厳密なテストダブルは両方を必須にしています。Polar プラグインは、HTTP では閉じられていて使われなくなった独自のチェックアウトを追加しなくなったため、`ROUTES.API_AUTH_POLAR` は Webhook だけを持ち、`POLAR_CHECKOUT_PRODUCTS` は削除されました。[決済とライセンス](/docs/features/payments)を参照してください。
