SaaSy Land — це один застосунок на TanStack Start, який працює як Cloudflare Worker. Код розділено за зонами відповідальності:

- **Маршрути** (`src/routes`) компонують сторінки. Файл маршруту оголошує свої простори імен перекладів, guard-функцію, loader-функцію та теги head, а потім рендерить компоненти.
- **Модулі** (`src/modules/<table>`) існують лише для справжніх таблиць бази даних. Модуль володіє схемою Drizzle для таблиці, Zod-схемами, константами, типами та сценаріями використання, які читають або змінюють цю таблицю.
- **Інтеграції** (`src/integrations/<vendor>`) налаштовують сторонні бібліотеки та сервіси.
- **Представлення** (`src/presentation`) містить примітиви shadcn, компоненти застосунку, шаблони React Email, стилі, тему та брендинг.
- **Спільний код** розміщено в `src/data` (дані, які використовують кілька файлів), `src/lib` (невеликі утиліти), `src/hooks` і `src/providers`.

```text
src/
├── routes/          Flat file routes that compose pages
├── modules/         One folder per database table, plus _core
├── integrations/    One folder per vendor
├── presentation/    Components, emails, styles, theme, branding
├── data/            Data shared by several files
├── lib/             Small shared utilities
├── hooks/           Shared React hooks
├── providers/       Application providers
├── platform/        Test runtime wiring
├── types/           Global type declarations
├── router.tsx       Router and per-request QueryClient
├── routes.ts        ROUTES path constants
└── server.ts        Cloudflare Worker entry
```

## Правила, що визначають код

- Файли маршрутів лише компонують. Віджети, діалоги, форми й колонки таблиць лежать у `src/presentation/components/custom`, по одному на файл.
- Компоненти самі читають свої переклади й дані через `useTranslations`, `useSuspenseQuery` або дані loader-функції маршруту. Маршрути не передають підписи чи дані вниз через пропси.
- Серверна функція, яка працює з таблицею, — це сценарій використання в модулі цієї таблиці. Серверну функцію, яку використовує лише один маршрут, можна визначити у файлі маршруту. Усе інше належить до `src/lib`.
- Немає ні контейнера впровадження залежностей, ні шару обгорток. Імпортуйте конкретну функцію з папки, яка нею володіє.
- Константа, яку використовує один файл, залишається в цьому файлі. У `src/data` переносяться лише дані, спільні для кількох файлів.
