title: "ロードマップ"
description: "短期および長期のプロダクトの方向性です。"
---

## 短期

- 管理画面のアナリティクス、決済、料金モデル、ブログ、招待、ロールの各画面とダッシュボードの売上グラフのデモデータを実データに置き換える
- 残りの商品、コース、設定、ランディングページエディターの操作を接続する
- 組織とチーム

## 長期

- ストアフロントでの販売
- コース受講者向けの体験
- 高度なアナリティクスのパイプライン
- プレミアムコンテンツのより細かなアクセス制御

GitHub の Issue とプルリクエストでのコントリビューションを歓迎します。
