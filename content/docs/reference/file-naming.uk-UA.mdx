Усі файли й папки називаються в kebab-case.

## Вихідні файли

| Шаблон                                                       | Значення                                                                                                                     |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | Файловий маршрут; крапки — це сегменти шляху, `_` позначає макет без шляху, `$` — splat-маршрут, `index` — індексний маршрут |
| `src/routes/api/<name>.ts`                                   | HTTP-обробник                                                                                                                |
| `modules/<table>/<table>.schema.ts`                          | Таблиця Drizzle                                                                                                              |
| `modules/<table>/<table>.zod.ts`                             | Zod-схеми                                                                                                                    |
| `modules/<table>/<table>.constants.ts`                       | Ключі запитів, ключі мутацій і переліки                                                                                      |
| `modules/<table>/<table>.types.ts`                           | Типи, похідні від таблиці                                                                                                    |
| `modules/<table>/<table>.utils.ts`                           | Чисті допоміжні функції для таблиці                                                                                          |
| `modules/<table>/<table>.server.ts`                          | Суто серверні допоміжні функції модуля                                                                                       |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | Один сценарій використання                                                                                                   |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | Конфігурація або адаптер вендора, наприклад `auth.server.ts`                                                                 |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | Колонки таблиці даних                                                                                                        |
| `presentation/emails/<name>.tsx`                             | Шаблон листа, що експортує `<NAME>_NAMESPACE`                                                                                |
| `hooks/use-<name>.ts`                                        | Спільний React-хук                                                                                                           |
| `providers/<name>-provider.tsx`                              | Провайдер застосунку                                                                                                         |

## Тести

| Шаблон                                | Засіб запуску               |
| ------------------------------------- | --------------------------- |
| `__test__/<file>.test.ts`             | Проєкт Vitest `node`        |
| `__test__/<file>.integration.test.ts` | Проєкт Vitest `integration` |
| `__test__/<file>.component.test.tsx`  | Проєкт Vitest `component`   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                  |

Тестові файли називаються за вихідним файлом, який вони покривають, наприклад `user.schema.test.ts` для `user.schema.ts`.

## Контент і повідомлення

| Шаблон                                    | Значення                                                    |
| ----------------------------------------- | ----------------------------------------------------------- |
| `messages/<locale>/<namespace>.json`      | Простір імен перекладів, наприклад `pages.admin.users.json` |
| `content/docs/<path>/<page>.<locale>.mdx` | Сторінка документації                                       |
| `content/docs/<path>/meta.<locale>.json`  | Навігація документації                                      |
| `content/blog/<slug>.<locale>.mdx`        | Допис у блозі                                               |
