- Tests prove the real behaviour. Strict doubles of Resend and Polar (`src/platform/testing/mocks/resend.ts`, `mocks/polar.ts`) receive every request the app's SDK clients send, in Vitest and in the browser test Worker: they validate it against the SDKs' request models, answer with complete provider objects, and fail the test on a request the provider would refuse; every other host is unreachable, as if offline. The ten Better Auth suites run against the real `auth.server.ts` instead of a hand-copied configuration, and `license-purchase.integration.test.ts` covers checkout creation, the signed `order.paid`, `benefit_grant.created`, `order.refunded` and `benefit_grant.revoked` webhooks in order, out of order, twice and with bad signatures, and the licence activations listing and deactivation. See [Testing and CI](/docs/architecture/testing-architecture).
- Fixed: a docs sidebar link pressed before the page's MDX chunk had loaded could reload the whole document instead of navigating in place, because the sidebar and the content shared one Suspense boundary. The docs pages now render their content in its own boundary, so the sidebar hydrates at once. Component tests no longer wait on real time: timer-driven UI runs on fake timers, route tests keep their loader data fresh, and `userEvent` runs with `delay: null`, so no keystroke waits for a timer.
