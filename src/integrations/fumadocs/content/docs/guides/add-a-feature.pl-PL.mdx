> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

## Checklist

1. **Own it** — pick module (`modules/<name>`) and/or route group
2. **Schema** — Drizzle table + migration if persisted
3. **Validation** — Zod in module `*.zod.ts`
4. **Use-case** — permissioned safe-action
5. **UI** — RSC page + small client islands
6. **i18n** — messages under `integrations/next-intl` catalogs
7. **Tests** — use-case unit + component where needed
8. **Docs** — update the matching Features page

## Anti-patterns

- Business rules in `_components`
- New role strings outside `auth.access.ts`
- Copy-pasting parsers instead of sharing nuqs maps
