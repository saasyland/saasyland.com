- 追加: 出荷済みの[変更履歴](/docs/project/changelog)の各エントリは、それを最初に出荷したリリース（例: `v2026.11.20.15`）にもリンクします。本番デプロイはビルドの前にタグを選ぶため、そのデプロイ自身のエントリには、このあとリリースジョブが作成するタグが表示されます。最初のリリースタグより前にマージされたエントリには表示されません。[リリースとタグ](/docs/tooling/ci-cd#releases-and-tags)を参照してください。
- 変更: 各 GitHub Release は、その日のすべてのエントリではなく、そのリリースが出荷したエントリ、つまり前のリリースタグ以降に `main` に入ったエントリだけを載せます。
