---
title: "Маршрути"
description: "Кожна сторінка та шлях API, їхня константа ROUTES, файл маршруту й guard-функція."
---

Кожен шлях має константу в `ROUTES`, оголошену в `src/routes.ts`, який нічого не імпортує (див. [Шляхи та навігація](/docs/conventions/routes#paths-and-navigation)). Посилання використовують константу, наприклад `<Link to={ROUTES.SIGN_IN}>`, а роутер додає префікс локалі. Кожна сторінка нижче також доступна з префіксом будь-якої нетипової локалі, наприклад `/pl-PL/terms`.

## Публічні сторінки

Ці сторінки розміщені в макеті `_site`, який рендерить заголовок сайту. Усі, крім документації, також розміщені в макеті `_marketing` (рамка сторінки та футер), макет документації сам рендерить той самий футер, а блог і документація мають усередині них власні макети. Усі вони проходять пререндеринг, крім сторінок розсилки.

| Шлях                          | Константа                | Файл маршруту                                                  |
| ----------------------------- | ------------------------ | -------------------------------------------------------------- |
| `/`                           | `HOME`                   | `_site._marketing.index.tsx`                                   |
| `/licence`                    | `LICENCE`                | `_site._marketing.licence.tsx`                                 |
| `/privacy`                    | `PRIVACY`                | `_site._marketing.privacy.tsx`                                 |
| `/terms`                      | `TERMS`                  | `_site._marketing.terms.tsx`                                   |
| `/refunds`                    | `REFUNDS`                | `_site._marketing.refunds.tsx`                                 |
| `/withdrawal`                 | `WITHDRAWAL`             | `_site._marketing.withdrawal.tsx`                              |
| `/affiliates`                 | `AFFILIATES`             | `_site._marketing.affiliates.tsx`                              |
| `/newsletter/confirm`         | `NEWSLETTER_CONFIRM`     | `_site._marketing.newsletter.confirm.tsx`                      |
| `/newsletter/unsubscribe`     | `NEWSLETTER_UNSUBSCRIBE` | `_site._marketing.newsletter.unsubscribe.tsx`                  |
| `/blog`                       | `BLOG`                   | `_site._marketing.blog.tsx`, `_site._marketing.blog.index.tsx` |
| `/blog/rss.xml`               | `BLOG_FEED`              | немає                                                          |
| `/blog/page/*`                | немає                    | `_site._marketing.blog.page.$page.tsx`                         |
| `/blog/*`                     | немає                    | `_site._marketing.blog.$.tsx`                                  |
| `/authors/*`                  | `AUTHORS`                | `_site._marketing.authors.$author.tsx`                         |
| `/docs`                       | `DOCS`                   | `_site.docs.tsx`, `_site.docs.index.tsx`                       |
| `/docs/cli`                   | `DOCS_CLI`               | `_site.docs.$.tsx`                                             |
| `/docs/tooling/test-coverage` | `DOCS_TEST_COVERAGE`     | `_site.docs.$.tsx`                                             |
| `/docs/*`                     | немає                    | `_site.docs.$.tsx`                                             |
| `/*`                          | немає                    | `_site._marketing.$.tsx`                                       |

`/*` — будь-яка адреса, якій не відповідає жоден інший маршрут: `_site._marketing.$.tsx` кидає `notFound()`, тож сервер відповідає 404 сторінкою «не знайдено», яку рендерить на кожен запит (див. [Сторінка не знайдена](/docs/features/landing-page#not-found-page)).

`/blog/rss.xml` не має файлу маршруту: `scripts/generate-seo-files.ts` записує стрічку кожної мови після збірки (див. [Стрічка](/docs/features/blog#feed)).

## Курси

Макет `/courses` (`_site._marketing.courses.tsx`), як і блог, розміщений у макетах `_site` і `_marketing` та не має guard-функції: рівень доступу кожного уроку перевіряє сервер (див. [Курси](/docs/features/courses)). Ці сторінки читають D1 під час кожного запиту й не проходять пререндеринг. `/sitemap-courses.xml` не має файлу маршруту: на нього з D1 відповідає обробник запитів у `src/server.ts` (див. [Карта сайту курсів](/docs/features/seo#course-sitemap)).

| Шлях                         | Константа         | Файл маршруту                                                        |
| ---------------------------- | ----------------- | -------------------------------------------------------------------- |
| `/courses`                   | `COURSES`         | `_site._marketing.courses.tsx`, `_site._marketing.courses.index.tsx` |
| `/courses/<course>`          | немає             | `_site._marketing.courses.$course.index.tsx`                         |
| `/courses/<course>/<lesson>` | немає             | `_site._marketing.courses.$course.$lesson.tsx`                       |
| `/sitemap-courses.xml`       | `COURSES_SITEMAP` | немає                                                                |

## API

Шляхи API ніколи не локалізуються.

| Шлях                                         | Константа       | Файл маршруту                                                                                                                                      |
| -------------------------------------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api`                                       | `API`           | `api/index.ts`                                                                                                                                     |
| `/api/auth/*`                                | `API_AUTH_BASE` | `api/auth.$.ts`                                                                                                                                    |
| <RepositoryFact name="cliApiBasePath" />`/*` | немає           | `api/cli.v1.license.ts`, `api/cli.v1.activations.ts`, `api/cli.v1.activations.$activationId.ts`, `api/cli.v1.activations.$activationId.bundles.ts` |

Шляхи API ліцензій для CLI беруться з його контракту, `API_BASE_PATH` і `API_ROUTE` у `@saasyland/stack/api`, а `src/routes/api/__test__/cli.v1.test.ts` перевіряє, що маршрутизатор передає кожен із них до його файлу маршруту (див. [API ліцензій для CLI](/docs/features/cli-licence-api)).

`ROUTES.API_AUTH` перелічує шляхи власних ендпоінтів Better Auth і ендпоінтів його плагінів admin і двофакторної автентифікації відносно `/api/auth`; `auth.server.ts` використовує їх, щоб звільнити ендпоінти від обмеження частоти запитів, а `INPUT_POLICY` в `auth.hooks.ts` — щоб перевіряти ендпоінти, які приймають пароль, ім'я, адресу пошти чи зображення. `ROUTES.API_AUTH_POLAR` перелічує вебхуки плагіна Polar, які `auth.server.ts` звільняє від обмеження частоти запитів, і зникає разом із розділом Polar, як і `API_AUTH_CUSTOMER_PORTAL`. `API_AUTH_CUSTOMER_PORTAL` і `API_AUTH_VERIFY_EMAIL` — це повні шляхи до ендпоінтів Better Auth, побудовані з `API_AUTH_BASE`. `AUTH` і `NEWSLETTER` не мають власної сторінки; разом з `ADMIN`, `APP`, `API` і `COURSES` вони позначають розділи, які ніколи не проходять пререндеринг (`REQUEST_RENDERED_ROUTES` у `src/routes.ts`, який читає `isRequestRenderedRoute`), а `verify-build.ts` провалює збірку, яка попередньо відрендерила сторінку під будь-яким із них.

## Медіафайли

`/media/<expiry>.<signature>/<videoId>/<file>` віддає підписані відеофайли. Для цього шляху немає константи `ROUTES` і файлу маршруту: `src/server.ts` передає його до `serveMedia` ще до middleware локалі, тож він ніколи не локалізується. Див. [Cloudflare R2](/docs/integrations/cloudflare-r2).

`/media/covers/<courseId>/<file>` віддає публічні обкладинки курсів через `serveCover`, а `/media/downloads/<expiry>.<signature>/<attachmentId>/<fileName>` — підписані матеріали уроків через `serveAttachment`. Туди їх передає обробник `/media/` розділу курсів, тож вони теж ніколи не локалізуються. Див. [Обкладинки курсів](/docs/features/courses#course-covers).

<RepositoryFact name="cliBundleUrlPath" /> так само віддає підписані бандли шаблонів CLI через `serveBundle` і бере свій префікс із
`BUNDLE_PATH_PREFIX` у `license.constants.ts`. Див. [API ліцензій для CLI](/docs/features/cli-licence-api#template-bundles).
