- Added: a [security policy](/docs/project/security-policy) page that says how to report a vulnerability in the site, the CLI or the licensed code, what happens after a report and which versions receive fixes. `SECURITY.md` now covers the CLI releases as well.
- Added: the site serves `/.well-known/security.txt` (RFC 9116) with the contact address, the languages and a link to the policy, and a test renews it before it expires.
- Added: CI writes a CycloneDX SBOM of the production dependencies in every run and fails on a high or critical advisory in them unless a dated, reviewed exception allows it. See [Dependencies](/docs/conventions/dependencies#security-advisories) and [CI/CD](/docs/tooling/ci-cd#checks).
