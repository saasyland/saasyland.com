- Corrigé : le menu des langues du pied de page ouvre aussi la langue choisie dans Safari. Safari ne déplace le focus nulle part quand on appuie sur un lien, si bien que le menu se fermait avant que le lien ne s’ouvre ; appuyer sur une langue garde désormais le menu ouvert jusqu’au changement de page. - Corrigé : une leçon retient l’endroit où un apprenant connecté l’a mise en pause, si bien qu’une courte visite reprend aussi à cet endroit ; jusqu’ici, la position n’était enregistrée que toutes les quelques secondes pendant la lecture. Voir [Cours](/docs/features/courses).
- Modifié : un slug de cours ou de leçon déjà pris est refusé sur le champ **Slug de l’URL**, qui indique qu’un autre cours, ou une autre leçon du cours, l’utilise, au lieu d’un message d’erreur général.
