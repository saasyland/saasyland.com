## Місце розташування

`src/presentation/components/custom/data-table`

## Характеристика шаблону (користувачів)

- `columns.tsx` / `cells.tsx` / `filters.tsx` / `actions.tsx` / `options.tsx`
- Карта DB рядків → таблиці рядків в `_lib` або модуль utils
- Toolbar оновлений → недійсний ключ TanStack Query
- Зберігати запобіжники безкоштовно з таблиці runtime

## Варіанти

Налаштування панелі інструментів (search, filters, import CSV, fetch, налаштування), пагінація, вибір та щільність через `options` — див. UI → DataTable.
