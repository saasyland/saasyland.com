- Geändert: `bun run check:areas` entfernt jetzt, wie die `saasyland`-CLI, auch die Tests, die einen entfernten Bereich nennen. Ein Test, dessen Callback ihn nennt, fällt ganz weg, eine Zeile einer `.each`-Tabelle einzeln, ein Hook verliert die Anweisungen, die ihn nennen, jedes `vi.mock` eines gelöschten Moduls fällt weg, ebenso ein `describe` oder eine Testdatei, in der kein Test mehr steht. Siehe [Testen](/docs/conventions/testing#tests-follow-the-areas).
- Geändert: Es entfernt auch den Code, der aus einem entfernten Bereich gebaut ist. Ein Variablen-Deklarator, dessen Wert nur aus dem Bereich stammt, fällt mit jeder Verwendung der Namen weg, die er bindet, und eine Anweisung, die den Bereich nennt, fällt auf oberster Ebene eines Moduls, eines `describe` oder eines Hooks weg. Ein Wert, der auch auf verbleibenden Code zurückgreift, etwa ein Menülink aus einem verbleibenden Eintrag, sowie Funktionen, Bedingungen und Exporte werden stattdessen gemeldet, denn ändern muss sich der Entwurf, nicht die Bereinigung.
