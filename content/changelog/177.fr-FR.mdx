- La grille de preuves de la page d’accueil ne dit plus que ce qui est vrai. **Langues** remplace **Devises** et affiche le nombre de langues prises en charge, avec une note précisant que chaque page, e-mail et page de documentation est livré traduit et que les dates, les nombres, les devises et les fuseaux horaires sont formatés pour chacune. La note sur React ne promet plus le choix du framework, les chiffres des tests indiquent qu’ils viennent du code source public de ce site, et **Sections d'administration** ne compte que les sections qui fonctionnent. Chaque entrée du menu d’administration déclare un `status`, `FEATURE_STATUS.AVAILABLE` ou `FEATURE_STATUS.ARRIVING` (`src/data/navigation.constants.ts`), et `adminSections` compte les disponibles : le tableau de bord, les utilisateurs, les produits, les cours, les vidéos et les paramètres comptent, mais pas les statistiques, les paiements, les modèles tarifaires, le blog ni l’éditeur de la page d’accueil, qui affichent des données de démonstration. Le manifeste et l’article de lancement citent les mêmes sections. Voir [Page d’accueil](/docs/features/landing-page).
