すべてのパスには、`ROUTES`（`src/routes.ts`）に定数があります。リンクには定数を使い（例：`<Link to={ROUTES.SIGN_IN}>`）、ロケールプレフィックスはルーターが付けます。以下の各ページは、デフォルト以外のすべてのロケールプレフィックスの下でも提供されます（例：`/pl-PL/terms`）。

## 公開ページ

これらのページは `_landing` レイアウト（ナビゲーションとフッター）を使います。ただし、ブログとドキュメントには独自のレイアウトがあります。ニュースレターのページを除き、すべてプリレンダリングされます。

| パス                      | 定数                     | ルートファイル                        |
| ------------------------- | ------------------------ | ------------------------------------- |
| `/`                       | `HOME`                   | `_landing.index.tsx`                  |
| `/premium`                | `PREMIUM`                | `_landing.premium.tsx`                |
| `/licence`                | `LICENCE`                | `_landing.licence.tsx`                |
| `/privacy`                | `PRIVACY`                | `_landing.privacy.tsx`                |
| `/terms`                  | `TERMS`                  | `_landing.terms.tsx`                  |
| `/refunds`                | `REFUNDS`                | `_landing.refunds.tsx`                |
| `/newsletter/confirm`     | `NEWSLETTER_CONFIRM`     | `_landing.newsletter.confirm.tsx`     |
| `/newsletter/unsubscribe` | `NEWSLETTER_UNSUBSCRIBE` | `_landing.newsletter.unsubscribe.tsx` |
| `/blog`                   | `BLOG`                   | `blog.tsx`、`blog.index.tsx`          |
| `/blog/*`                 | なし                     | `blog.$.tsx`                          |
| `/docs`                   | `DOCS`                   | `docs.tsx`、`docs.index.tsx`          |
| `/docs/*`                 | なし                     | `docs.$.tsx`                          |

## 認証

`/auth` レイアウト（`auth.tsx`）にはガードがなく、個々のページがガードを持ちます。

| パス                    | 定数              | ルートファイル             | ガード                                                    |
| ----------------------- | ----------------- | -------------------------- | --------------------------------------------------------- |
| `/auth/sign-in`         | `SIGN_IN`         | `auth.sign-in.tsx`         | `redirectIfSignedIn`                                      |
| `/auth/sign-up`         | `SIGN_UP`         | `auth.sign-up.tsx`         | `redirectIfSignedIn`                                      |
| `/auth/forgot-password` | `FORGOT_PASSWORD` | `auth.forgot-password.tsx` | なし                                                      |
| `/auth/reset-password`  | `RESET_PASSWORD`  | `auth.reset-password.tsx`  | なし                                                      |
| `/auth/two-factor`      | `TWO_FACTOR`      | `auth.two-factor.tsx`      | なし                                                      |
| `/auth/verify-email`    | `VERIFY_EMAIL`    | `auth.verify-email.tsx`    | `token` を Better Auth の検証エンドポイントにリダイレクト |
| `/auth/callback`        | `AUTH_CALLBACK`   | `auth.callback.tsx`        | `redirectAfterAuth`                                       |

## API

API のパスがローカライズされることはありません。

| パス          | 定数            | ルートファイル  |
| ------------- | --------------- | --------------- |
| `/api`        | `API`           | `api/index.ts`  |
| `/api/auth/*` | `API_AUTH_BASE` | `api/auth.$.ts` |
| `/api/search` | なし            | `api/search.ts` |

`ROUTES.API_AUTH` は、Better Auth のエンドポイントのパスを `/api/auth` からの相対パスで列挙します。`auth.server.ts` はこれを使って、エンドポイントをレート制限の対象から除外します。`API_AUTH_CUSTOMER_PORTAL` と `API_AUTH_VERIFY_EMAIL` は、Better Auth のエンドポイントへのフルパスです。`AUTH` と `NEWSLETTER` には独自のページがありません。これらは `ADMIN`、`APP`、`API` とともに、プリレンダリングされないエリアを示します。
