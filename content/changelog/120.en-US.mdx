- Deploys: `deploy:preview` and `deploy:production` write only the secrets that `wrangler.jsonc` declares, from the environment file, to `.wrangler/secrets.<environment>.json`, apply the environment's D1 migrations, deploy `dist/server/wrangler.json` with those secrets and check the live site with `scripts/verify-deployment.ts`. CI does not run that check, because Cloudflare's bot protection answers 403 to requests from CI runners. See [Project scripts](/docs/tooling/scripts).
- `verify-bindings.ts` also requires the `MEDIA` bucket and refuses a production environment that shares its D1 database, KV namespace or R2 bucket with preview. `verify-build.ts` takes the environment and checks that the built Worker config targets it.
- New scripts: `db:reset:test` recreates the local test database and is what Playwright and CI run, and `db:migrations:<environment>` lists the migrations a remote database has not applied yet. Scripts run Wrangler and `drizzle-kit generate` through `vp exec`, and the `package.json` scripts are sorted by name.
- `wrangler.jsonc` lists the environments as development, preview, test and production, each with its D1, R2 and KV bindings in that order and its secrets sorted by name.
