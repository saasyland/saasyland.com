## 管理画面の骨格

`src/routes/admin.tsx` はすべての管理ページを `requireAdmin` で保護し、共通の名前空間をプリロードします。レイアウトは次を表示します。

- `AdminSidebar`、`AdminBreadcrumbs`、`AdminCommandPalette`（⌘K で開く）。いずれも `src/data/navigation.ts` の `ADMIN_NAVIGATION` から構築されます。これは各エリアが追加した項目をアイコンとともにグループにまとめたもので、概要（ダッシュボード、アナリティクス）、商品構成（商品、料金モデル）、コンテンツ（ブログ、コース、動画、ランディングページ）、管理（ユーザー管理、決済、設定）のグループがあります。
- サイドバー下部のユーザーウィジェット。設定へのリンクと `SignOutButton` を含みます。

## ダッシュボード

`/admin`（`src/routes/admin.index.tsx`）はローダーで `getUsersQuery` とダッシュボードの各統計のクエリをプリロードし、`src/presentation/components/custom/admin/dashboard` の 3 つのウィジェットを組み合わせます。

- `DashboardStats`（稼働中）: `ADMIN_DASHBOARD_STATS` の統計を `order` の順に表示します。ユーザー数とメール確認待ちのユーザー数は `src/data/auth.dashboard.ts`、商品数は `src/data/products.dashboard.ts` から来ます。
- `RevenueChart`（デモ）: 軸が固定された静的な SVG で、期間ボタンは何もしません。
- ユーザーカード（稼働中）: 検索とステータスのフィルターを備えた最新ユーザーの一覧で、1 ページ <RepositoryFact name="adminPreviewPageSize" /> 行です。

```tsx
<DataTable
  columns={dashboardUserColumns}
  data={users.rows}
  filters={[
    { columnId: "user", placeholder: t("users.search"), type: "search" },
    {
      columnId: "status",
      label: t("users.filters.status"),
      options: USER_STATUSES.map((status) => ({ label: t(`users.table.status.${status}`), value: status })),
      type: "select",
    },
  ]}
  options={{ initialState: { pagination: ADMIN_DASHBOARD_PREVIEW_PAGINATION }, selectable: true }}
/>
```

このテーブルはブラウザー上で `getUsersQuery` の最初のページ（<RepositoryFact name="defaultPageSize" /> 人）を扱います。ユーザーがそれより多い場合、**すべて表示** は `/admin/users` へリンクします。**商品を追加** は商品エリアが `ADMIN_DASHBOARD_ACTIONS` に追加した項目で、`/admin/products/create` へリンクし、**過去 30 日間** は無効で、**エクスポート** は未接続です。
