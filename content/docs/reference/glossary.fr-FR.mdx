---
title: "Glossaire"
description: "Les termes utilisés dans toute la documentation de SaaSy Land."
---

- **AppError** : l'unique classe d'erreur des fonctions serveur, qui porte l'un des `ERROR_CODES`.
- **Binding** : une ressource Cloudflare transmise au Worker, à savoir `DB` (D1), `CACHE` (KV) ou `ASSETS` (ressources statiques).
- **Guard** : une fonction `beforeLoad`, comme `requireAdmin`, qui redirige avant le chargement d'une route.
- **Intégration** : un dossier de `src/integrations` qui configure un fournisseur, comme Better Auth ou Resend.
- **Route de layout** : une route qui rend un `Outlet` pour ses routes enfants et déclare des `NAMESPACES` partagés, par exemple `admin.tsx`.
- **Préfixe de locale** : le segment de chemin `/<locale>` présent pour toutes les locales sauf en-US, par exemple `/pl-PL`.
- **Middleware** : une fonction qui s'exécute avant le handler d'une fonction serveur, à savoir `withRequest`, `authorized` ou `withRateLimit`.
- **Module** : un dossier de `src/modules` qui possède une table de la base de données et ses cas d'usage.
- **Options de mutation** : l'objet `mutationOptions` exporté à côté d'une fonction serveur qui modifie des données.
- **Namespace** : un fichier de traduction, désigné par son nom de fichier, par exemple `pages.admin.users`.
- **Route de page** : une route qui rend une page et déclare un seul `NAMESPACE`.
- **Prérendu** : le rendu des pages publiques en HTML au moment du build, afin que le Worker puisse les servir comme ressources statiques.
- **Options de query** : l'objet `queryOptions` exporté à côté d'une fonction serveur qui lit des données. Les loaders et les composants le partagent.
- **Namespaces racine** : `common`, `components.*` et `errors*`, préchargés pour chaque page.
- **Fonction serveur** : une opération RPC typée, créée avec `createServerFn`, qui s'exécute toujours sur le serveur.
- **Cas d'usage** : une opération sur la table d'un module, dans `use-cases/<verb>-<noun>.ts`.
- **Environnement Wrangler** : l'un des environnements `development`, `preview`, `production` ou `test` de `wrangler.jsonc`, chacun avec ses propres bindings et secrets.
