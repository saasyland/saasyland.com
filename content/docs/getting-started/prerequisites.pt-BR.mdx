## Ferramentas

| Ferramenta | Versão                              | Motivo                                                                                                                  |
| ---------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Bun        | 1.4.0                               | Gerenciador de pacotes e executor de scripts; `packageManager` no `package.json` e a CI fixam essa versão               |
| Node.js    | 24.11 ou mais recente na linha 24.x | O Vite+ aceita `^22.18.0`, `^24.11.0` ou `>=26.0.0`; a CI usa o Node 24, e o banco de dados de testes usa `node:sqlite` |
| Git        | Qualquer versão recente             | A etapa de instalação configura os hooks do Git                                                                         |

Wrangler, drizzle-kit, Playwright e a CLI do Vite+ são dependências de desenvolvimento; execute-os pelos scripts do pacote ou com `bunx`. Os testes no navegador também precisam dos navegadores do Playwright, instalados com `bun run test:e2e:install`.

## Contas

O preview de testes isolado e todos os testes automatizados não precisam de contas nem de credenciais. O desenvolvimento e o deploy usam serviços reais:

- Uma conta da Cloudflare com D1, KV e Workers. O servidor de desenvolvimento se conecta aos recursos remotos de preview.
- Apps OAuth do GitHub e do Google para o login social.
- Resend com um remetente verificado. O cadastro por e-mail exige um endereço verificado, então o cadastro não funciona sem ele.
- Polar, usando o sandbox no desenvolvimento, com três produtos para os planos Core, Complete e Agency.
