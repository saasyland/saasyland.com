## 環境ファイル

| ファイル           | コミット対象 | 使用箇所                                                                                                                                               |
| ------------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `.env.example`     | はい         | すべてのシークレットを空の値で列挙                                                                                                                     |
| `.env.development` | いいえ       | `bun run dev`、`polar:verify:development`、`db:seed:local`（`LOCAL_ADMIN_PASSWORD`）                                                                   |
| `.env.preview`     | いいえ       | `deploy:preview`（宣言されたシークレット）、`auth:verify:preview`、`polar:verify:preview`、`db:studio:preview`、`db:introspect:preview`                |
| `.env.production`  | いいえ       | `deploy:production`（宣言されたシークレット）、`auth:verify:production`、`polar:verify:production`、`db:studio:production`、`db:introspect:production` |
| `.env.test`        | はい         | Vitest と `test` Wrangler 環境。ダミー値のみ                                                                                                           |

## 変数

| 変数                        | 使用箇所                                                                                                                                                                            |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AUTH_SECRET`               | Better Auth の署名、暗号化、メール認証トークン                                                                                                                                      |
| `AUTH_GITHUB_CLIENT_ID`     | GitHub OAuth。GitHub スター数のリクエストの認証にも使用                                                                                                                             |
| `AUTH_GITHUB_CLIENT_SECRET` | GitHub OAuth。GitHub スター数のリクエストの認証にも使用                                                                                                                             |
| `AUTH_GOOGLE_CLIENT_ID`     | Google OAuth                                                                                                                                                                        |
| `AUTH_GOOGLE_CLIENT_SECRET` | Google OAuth                                                                                                                                                                        |
| `RESEND_API_KEY`            | Resend クライアント                                                                                                                                                                 |
| `RESEND_EMAIL_FROM`         | `sendEmail` のデフォルトの送信元                                                                                                                                                    |
| `POLAR_ACCESS_TOKEN`        | Polar SDK クライアント                                                                                                                                                              |
| `POLAR_SERVER`              | 開発とプレビューでは `sandbox`、本番では `production`                                                                                                                               |
| `POLAR_WEBHOOK_SECRET`      | Polar の Webhook 署名の検証                                                                                                                                                         |
| `POLAR_ORGANIZATION_ID`     | Polar への呼び出しを組織に限定します。ライセンスキーの有効化と無効化（CLI ライセンス API と `/app/license`）、アップグレードの価格のための注文の一覧取得、`polar:verify` の一覧取得 |
| `POLAR_PRODUCT_ID_CORE`     | Core プランのチェックアウト用商品                                                                                                                                                   |
| `POLAR_PRODUCT_ID_COMPLETE` | Complete プランのチェックアウト用商品                                                                                                                                               |
| `POLAR_PRODUCT_ID_AGENCY`   | Agency プランのチェックアウト用商品                                                                                                                                                 |
| `CLOUDFLARE_ACCOUNT_ID`     | Drizzle Kit の D1 HTTP ドライバー                                                                                                                                                   |
| `CLOUDFLARE_DATABASE_ID`    | Drizzle Kit の D1 HTTP ドライバー                                                                                                                                                   |
| `CLOUDFLARE_ACCESS_TOKEN`   | Drizzle Kit の D1 HTTP ドライバー                                                                                                                                                   |
| `AFFONSO_PROGRAM_ID`        | プログラムの開始後にアフィリエイトの紹介トラッキングが使う、公開の Affonso プログラム ID（任意）                                                                                    |
| `LOCAL_ADMIN_PASSWORD`      | `bun run db:seed:local` が作成するローカルの管理者のパスワード（任意）。Worker のシークレットにはなりません                                                                         |
| `FFMPEG`、`FFPROBE`         | `scripts/publish-video.ts` で使う FFmpeg と ffprobe のバイナリ（任意）。デフォルトは `ffmpeg` と `ffprobe`                                                                          |

`wrangler.jsonc` の各環境は、必要なシークレットを `secrets.required` に列挙します。ただし `test` 環境では、3 つの Cloudflare 変数を省略しています。`AFFONSO_PROGRAM_ID` はシークレットではありません。ページの script タグに含まれるため、`vars` の下の Worker 変数として、実際の支払いを受け付ける環境にのみ設定します。`production` は SaaSy Land のプログラム ID を、`test` はブラウザーテスト用のダミー ID を設定しています。トラッキングが動作するのは、Worker にこの ID があり、かつプログラムが開始している場合だけです。現在の `AFFILIATE_PROGRAM` は <RepositoryFact name="affiliateProgram" /> です（[プログラムの開始](/docs/features/affiliates#opening-the-programme)）。`FFMPEG` と `FFPROBE` は `scripts/publish-video.ts` 用の任意のシェル変数で、Worker のシークレットではありません。Worker のコードはこれらの変数を `cloudflare:workers` の `env` から読み取り、その型は `bun run cf-typegen` が `wrangler.jsonc` から生成する `src/types/worker-configuration.d.ts` と、`src/types` にある各機能のファイルで定義されています。`VITE_` 変数はありません。公開 URL とドメインは `src/presentation/branding` の定数です。

## バインディング

| バインディング | 種類         | `development`                        | `preview`    | `production` | `test`                              |
| -------------- | ------------ | ------------------------------------ | ------------ | ------------ | ----------------------------------- |
| `DB`           | D1           | ローカルの `saasyland_local`         | プレビュー用 | 本番用       | ローカルの `saasyland_test`         |
| `CACHE`        | KV           | ローカル                             | プレビュー用 | 本番用       | ローカル                            |
| `MEDIA`        | R2           | ローカルの `saasyland-local`         | プレビュー用 | 本番用       | ローカルの `saasyland-test`         |
| `BUNDLES`      | R2           | ローカルの `saasyland-bundles-local` | プレビュー用 | 本番用       | ローカルの `saasyland-bundles-test` |
| `ASSETS`       | 静的アセット | あり                                 | あり         | あり         | あり                                |

プレビューと本番のデプロイスクリプトは、最初に `scripts/verify-bindings.ts` を実行します。このスクリプトは、環境にバインディングが欠けているか D1 や KV のプレースホルダー ID が残っている場合、また本番がプレビューとリソースを共有している場合に失敗します。R2 バケットは名前（`wrangler.jsonc` の各環境の `r2_buckets` にある各エントリーの `bucket_name`）でバインドされ、デプロイの前に存在している必要があります。`development` と `test` のバケットはローカルにあり、準備は必要ありません。
