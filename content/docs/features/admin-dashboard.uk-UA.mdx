## Каркас адмінпанелі

`src/routes/admin.tsx` захищає кожну сторінку адмінпанелі за допомогою `requireAdmin` і попередньо завантажує спільні простори імен. Макет показує:

- `AdminSidebar`, `AdminBreadcrumbs` і `AdminCommandPalette` (відкривається ⌘K), побудовані з `ADMIN_NAVIGATION` у `src/data/navigation.ts`, який групує пункти, додані розділами, кожен з його іконкою: Огляд (Панель, Аналітика), Пропозиції (Продукти, Цінові моделі), Вміст (Блог, Курси, Відео, Головна сторінка) та Адміністрування (Керування користувачами, Платежі, Налаштування).
- Віджет користувача внизу бічної панелі з посиланням на налаштування та `SignOutButton`.

## Панель

`/admin` (`src/routes/admin.index.tsx`) попередньо завантажує в loader `getUsersQuery`, а через їхній `prefetch` — запит кожної статистики панелі й кожної панелі, що читає дані, та складає віджети з `src/presentation/components/custom/admin/dashboard` із панелями, які додають розділи:

- `DashboardActions`: посилання для кожного пункту з `ADMIN_DASHBOARD_ACTIONS` у порядку його `order`, як-от **Додати продукт** із `src/data/products.navigation.ts` з підписом із `navigation.products.json`.
- `DashboardStats` (робочий): статистика з `ADMIN_DASHBOARD_STATS`, тобто записи `src/data/<area>.dashboard.ts` із розміщенням `DASHBOARD_PLACEMENT.STAT`, у порядку їхнього `order`: кількість користувачів і користувачі, що очікують підтвердження пошти, з `src/data/auth.dashboard.ts` та кількість продуктів із `src/data/products.dashboard.ts`, кожна з підписом із `dashboard.<area>.json` свого розділу.
- Панелі з `ADMIN_DASHBOARD_PANELS`, тобто записи з розміщенням `DASHBOARD_PLACEMENT.PANEL`, у порядку їхнього `order`, кожна зі скелетоном, який для неї показує `AdminDashboardPending`:
  - розділ ліцензій додає в `src/data/license.dashboard.ts` `UnlicensedOrders` (робочий): оплачені замовлення ліцензій, які не мають ліцензії, кожне з посиланням на замовлення в Polar, або рядок про те, що таких немає, з підписами з `dashboard.license.json` (див. [Ліцензії](/docs/features/licences#orders-that-match-no-account));
  - розділ платежів додає в `src/data/payments.dashboard.ts` `RevenueChart` (демонстраційний), статичний SVG із фіксованими осями й підписами з `dashboard.payments.json`; кнопки діапазону нічого не роблять.
- Картка користувачів (робоча): найновіші користувачі з фільтрами пошуку та статусу, кількість рядків на сторінці: <RepositoryFact name="adminPreviewPageSize" />. Кожне ім’я веде на профіль користувача, де розміщено дії.

```tsx
<DataTable
  columns={dashboardUserColumns}
  data={users.rows}
  filters={[
    { columnId: "user", placeholder: t("users.search"), type: "search" },
    {
      columnId: "status",
      label: t("users.filters.status"),
      options: USER_STATUSES.map((status) => ({ label: t(`users.table.status.${status}`), value: status })),
      type: "select",
    },
  ]}
  options={{ initialState: { pagination: ADMIN_DASHBOARD_PREVIEW_PAGINATION }, selectable: true }}
/>
```

Таблиця працює в браузері з першою сторінкою `getUsersQuery` (кількість користувачів: <RepositoryFact name="defaultPageSize" />). **Переглянути всіх** веде на `/admin/users`. **Додати продукт**, пункт розділу продуктів в `ADMIN_DASHBOARD_ACTIONS`, веде на `/admin/products/create`.
