---

Alle Dateien und Ordner verwenden kebab-case.

## Quelldateien

| Muster                                                       | Bedeutung                                                                                                                   |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | Dateiroute; Punkte sind Pfadsegmente, `_` kennzeichnet ein pfadloses Layout, `$` eine Splat-Route, `index` eine Index-Route |
| `src/routes/api/<name>.ts`                                   | HTTP-Handler                                                                                                                |
| `modules/<table>/<table>.schema.ts`                          | Drizzle-Tabelle                                                                                                             |
| `modules/<table>/<table>.zod.ts`                             | Zod-Schemas                                                                                                                 |
| `modules/<table>/<table>.constants.ts`                       | Query-Keys, Mutation-Keys und Enums                                                                                         |
| `modules/<table>/<table>.types.ts`                           | Von der Tabelle abgeleitete Typen                                                                                           |
| `modules/<table>/<table>.utils.ts`                           | Reine Hilfsfunktionen für die Tabelle                                                                                       |
| `modules/<table>/<table>.server.ts`                          | Server-only-Hilfsfunktionen des Moduls                                                                                      |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | Ein Use Case                                                                                                                |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | Anbieterkonfiguration oder Adapter, zum Beispiel `auth.server.ts`                                                           |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | Spalten einer Datentabelle                                                                                                  |
| `presentation/emails/<name>.tsx`                             | E-Mail-Template, das `<NAME>_NAMESPACE` exportiert                                                                          |
| `hooks/use-<name>.ts`                                        | Gemeinsamer React-Hook                                                                                                      |
| `providers/<name>-provider.tsx`                              | Anwendungs-Provider                                                                                                         |

## Tests

| Muster                                | Runner                       |
| ------------------------------------- | ---------------------------- |
| `__test__/<file>.test.ts`             | Vitest-Projekt `node`        |
| `__test__/<file>.integration.test.ts` | Vitest-Projekt `integration` |
| `__test__/<file>.component.test.tsx`  | Vitest-Projekt `component`   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                   |

Testdateien werden nach der Quelldatei benannt, die sie abdecken, zum Beispiel `user.schema.test.ts` für `user.schema.ts`.

## Inhalte und Nachrichten

| Muster                                    | Bedeutung                                                     |
| ----------------------------------------- | ------------------------------------------------------------- |
| `messages/<locale>/<namespace>.json`      | Übersetzungs-Namespace, zum Beispiel `pages.admin.users.json` |
| `content/docs/<path>/<page>.<locale>.mdx` | Dokumentationsseite                                           |
| `content/docs/<path>/meta.<locale>.json`  | Navigation der Dokumentation                                  |
| `content/blog/<slug>.<locale>.mdx`        | Blogbeitrag                                                   |
