> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

## Folders

- `components/shadcn` — primitives (Button, Tabs, …) on React Aria / Base UI
- `components/custom` — DataTable, filters, form builder, locale/theme switches
- `theme` / `branding` / `fonts` / `styles`

## Rules

- Shared visuals belong here; feature-specific screens stay under `app/.../_components`
- Prefer composition over boolean prop sprawl (see Vercel composition skills)
- DataTable options + column defs are feature-owned; the kit stays generic
