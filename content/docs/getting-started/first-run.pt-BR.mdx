## Preview de testes isolado

O preview de testes faz o build da aplicação para o ambiente `test`: D1, KV e R2 locais em `.wrangler/test`, credenciais fictícias de `.env.test`, contas criadas pelo seed e requisições interceptadas ao Resend e à Polar. Ele não precisa de contas.

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

Abra <RepositoryFact name="localServerOrigin" /> e faça login com uma das contas que o seed cria a partir de `e2e/data/accounts.ts`. Todas usam a senha <RepositoryFact name="testPassword" />. Administradores chegam em `/admin` e clientes em `/app`, e as contas licenciadas e suas licenças vêm de `e2e/data/licenses.ts`. A licença Complete abre todas as aulas pagas do curso de exemplo.

<RepositoryTable columns={["E-mail", "Papel", "Licença"]} name="seededAccounts" />

O preview serve um build, então faça um novo build para ver as alterações no código-fonte.

## Desenvolvimento com a Cloudflare

`bun run dev` inicia o servidor de desenvolvimento com hot reload em http://localhost:3000. Seus bindings `DB`, `CACHE`, `MEDIA` e `BUNDLES` são locais, em `.wrangler/state`, então o desenvolvimento nunca lê nem grava os dados de preview ou de produção e não precisa de login na Cloudflare.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

1. Preencha `.env.development` conforme descrito em [Variáveis de ambiente](/docs/getting-started/environment-variables), com `POLAR_SERVER=sandbox`.
2. Crie o banco de dados local e aplique as migrações com `db:reset:local`.
3. Preencha-o com `db:seed:local`: um administrador, o conteúdo programático dos cursos, licenças e um pedido.
4. Inicie o servidor e faça login como <RepositoryFact name="localAdminEmail" /> com `LOCAL_ADMIN_PASSWORD` de `.env.development`, ou <RepositoryFact name="localAdminPassword" /> quando ela não estiver definida.

`bun run db:studio:local` abre os dados locais no Drizzle Studio. O cadastro por e-mail precisa de uma configuração do Resend funcionando: uma conta nova já entra logada, mas a chave de licença e as aulas pagas esperam o link de confirmação, e um novo login exige um endereço confirmado. [Banco de dados](/docs/tooling/database) descreve os três bancos de dados, o seed e como criar o primeiro administrador no preview e na produção.
