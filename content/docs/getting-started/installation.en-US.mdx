---
title: "Installation"
description: "Install dependencies and generate the local files."
---

Clone the repository, then install from its root with the committed lockfile:

```sh
bun install --frozen-lockfile
```

The `prepare` lifecycle script then:

1. Runs `vp config --no-agent`, which installs the Git hook dispatcher for `.vite-hooks/` (pre-commit checks and the commit message hook).
2. Runs `bun run generate:cn`, which builds the class-merging tables in `.source/cn-tables.ts`.
3. Runs `bun run content`, which generates the Fumadocs collections in `.source/`.

If you install with `--ignore-scripts`, as CI does, run `bun run typegen` afterwards. It also regenerates `src/types/worker-configuration.d.ts` from `wrangler.jsonc`.

## Optional extras

```sh
bun run test:e2e:install
bun run skills:sync
```

The first installs Chromium and WebKit for Playwright; the second restores the [agent skills](/docs/tooling/agent-skills).
