## Polices

Geist et Geist Mono sont auto-hébergées dans `public/fonts` sous forme de sous-ensembles WOFF2 variables, servis avec un cache immuable d’un an (`public/_headers`). `src/presentation/styles/fonts.css` déclare un `@font-face` par plage Unicode (latin, latin étendu, cyrillique), des polices de repli aux métriques ajustées et les variables `--font-geist-sans` et `--font-geist-mono`. `globals.css` les associe à `--font-sans`, `--font-heading` et `--font-mono`. Le texte japonais utilise les polices du système. Geist compose tout le texte ; Geist Mono est réservée au code, aux commandes, aux touches et aux identifiants. Voir [Thème](/docs/ui/theme#type-scale).

## Préchargements

`src/presentation/document-assets.ts` exporte `DOCUMENT_STYLESHEET` (`globals.css`) et les préchargements de polices pour une langue :

```ts
export const fontPreloads = (locale: SupportedLocale) => {
  const fonts = [GEIST_LATIN, GEIST_MONO_LATIN]
  if (locale === "pl-PL") {
    fonts.push(GEIST_LATIN_EXT)
  } else if (locale === "uk-UA") {
    fonts.push(GEIST_CYRILLIC)
  }
  return fonts
}
```

La route racine les ajoute sous forme de balises `link`, et le Worker (`src/server.ts`) envoie les mêmes polices dans un en-tête de préchargement `Link` sur chaque réponse HTML, que Cloudflare rejoue sous forme d’Early Hints. Les noms des fichiers de police sont des empreintes de leur contenu : si vous remplacez une police, mettez à jour `fonts.css` et `document-assets.ts`.

## Constantes de marque

`src/presentation/branding/index.ts` est la source unique de la marque :

```ts title="src/presentation/branding/index.ts"
export const APP_NAME = "SaaSy Land"
export const APP_SLUG = "saasyland"
export const APP_LOGO_PATH = "M6 0H15V9H24V18A6 6 0 0 1 18 24H6A6 6 0 0 1 0 18V6A6 6 0 0 1 6 0Z"
export const APP_DOMAIN = "saasyland.com"
export const APP_PREVIEW_DOMAIN = `preview.${APP_DOMAIN}`

export const APP_URL = `https://${APP_DOMAIN}`
export const CONTACT_EMAIL = `hello@${APP_DOMAIN}`
export const NOTIFICATIONS_EMAIL = `notifications@${APP_DOMAIN}`

export const APP_FOUNDED_YEAR = 2023

export const APP_GITHUB_OWNER = "saasyland"
export const APP_GITHUB_REPO = APP_DOMAIN
export const APP_GITHUB_OWNER_URL = `https://github.com/${APP_GITHUB_OWNER}`
export const APP_GITHUB_URL = `${APP_GITHUB_OWNER_URL}/${APP_GITHUB_REPO}`

export const APP_INSTAGRAM_URL = "https://www.instagram.com/saasyland/"
```

Elles alimentent le nom de l’application dans Better Auth et l’émetteur 2FA, les noms des cookies de thème et de langue, les hôtes autorisés, le pied de page, la navigation de la documentation, le nombre d’étoiles GitHub, les données structurées de la page d’accueil et des articles du blog ainsi que les expéditeurs et destinataires des e-mails. `APP_GITHUB_OWNER_URL` et `APP_INSTAGRAM_URL` sont les profils de l’organisation sur d’autres sites : le pied de page renvoie vers le profil Instagram à côté du dépôt, et les données structurées les citent tous deux dans `sameAs` ; voir [Référencement et aperçus sociaux](/docs/features/seo#structured-data).

## Logo et médias

- `Wordmark` (`src/presentation/components/custom/wordmark.tsx`) affiche le logo, `APP_LOGO_PATH`, en SVG intégré à côté de `APP_NAME`. Les cartes de partage dessinent le même tracé avec les mêmes polices ; voir [Référencement et aperçus sociaux](/docs/features/seo). `HomeLink` (`home-link.tsx`) en fait le lien vers l’accueil dans les en-têtes de la page d’accueil, du blog et des cours ; voir [Page d’accueil](/docs/features/landing-page).
- Le favicon est `public/favicon.ico` ; les images du blog se trouvent dans `public/images/blog`.
- Les vidéos de la page d’accueil se trouvent dans `src/presentation/assets/motion` sous forme de fichiers WebM avec des affiches WebP. Une affiche doit conserver les dimensions de sa vidéo. La visite des pages de cours, lue à la demande avec des commandes, a aussi une version MP4 de secours et des affiches AVIF.
