---
title: "Graphify"
description: "An optional knowledge graph of the codebase for agents."
---

Graphify is an optional, external agent skill that turns a folder into a knowledge graph. It is not a project dependency, and `.gitignore` excludes its output folder `graphify-out/`.

With the skill installed in your agent:

- `/graphify .` builds the graph for the repository.
- `/graphify . --update` re-extracts only new or changed files.
- `/graphify query "<question>"` answers a question from the graph.

Read `graphify-out/GRAPH_REPORT.md` for broad questions about structure, then confirm details in the code. The graph is a snapshot; after large changes, update it before relying on it.
