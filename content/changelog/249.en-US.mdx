- Added: **Export all** and **Import** on the course list, and **Export** in the course editor. A course file holds every course with its chapters, lessons, text in every language, access levels, key moments, links and video references, but no uploaded files. Import first checks the file and lists what it will add, update and remove, then applies it in one transaction. Courses and lessons are matched by their slugs, importing the same file twice changes nothing, and nothing is deleted unless you ask for it. See [Courses](/docs/features/courses#import-and-export).
- Added: the SaaSy Land curriculum in every language, as a course file ready to import (`content/courses/saasy-land-courses.json`).
- Changed: a published course whose lessons are still being recorded says so. The catalogue and the landing page show "Being recorded" instead of minutes, the course page offers no start link until a lesson plays, and a lesson being recorded no longer offers a purchase or **Mark as complete**. See [Courses](/docs/features/courses#being-recorded).
