---
title: "Glosario"
description: "Términos que se usan en toda la documentación de SaaSy Land."
---

- **AppError:** la única clase de error de las funciones de servidor, que lleva uno de los `ERROR_CODES`.
- **Binding:** un recurso de Cloudflare que se pasa al Worker: `DB` (D1), `CACHE` (KV) o `ASSETS` (recursos estáticos).
- **Caso de uso:** una operación sobre la tabla de un módulo, en `use-cases/<verb>-<noun>.ts`.
- **Entorno de Wrangler:** uno de `development`, `preview`, `production` o `test` en `wrangler.jsonc`, cada uno con sus propios bindings y secretos.
- **Función de servidor:** una operación RPC tipada, creada con `createServerFn`, que siempre se ejecuta en el servidor.
- **Guard:** una función `beforeLoad`, como `requireAdmin`, que redirige antes de que se cargue una ruta.
- **Integración:** una carpeta de `src/integrations` que configura un proveedor, como Better Auth o Resend.
- **Middleware:** una función que se ejecuta antes del handler de una función de servidor: `withRequest`, `authorized` o `withRateLimit`.
- **Módulo:** una carpeta de `src/modules` que es dueña de una tabla de la base de datos y de sus casos de uso.
- **Namespace:** un archivo de traducción, identificado por su nombre de archivo, por ejemplo `pages.admin.users`.
- **Namespaces raíz:** `common`, `components.*` y `errors*`, que se precargan en todas las páginas.
- **Opciones de consulta:** el objeto `queryOptions` que se exporta junto a una función de servidor que lee datos. Lo comparten los loaders y los componentes.
- **Opciones de mutación:** el objeto `mutationOptions` que se exporta junto a una función de servidor que modifica datos.
- **Prefijo de locale:** el segmento de ruta `/<locale>` de todos los locales excepto en-US, por ejemplo `/pl-PL`.
- **Prerenderizado:** el renderizado de las páginas públicas a HTML en tiempo de build para que el Worker pueda servirlas como recursos estáticos.
- **Ruta de layout:** una ruta que renderiza un `Outlet` para sus rutas hijas y declara `NAMESPACES` compartidos, por ejemplo `admin.tsx`.
- **Ruta de página:** una ruta que renderiza una página y declara un único `NAMESPACE`.
