## テンプレート

テンプレートは `src/presentation/emails` にあります。各ファイルはマークアップだけを含み、名前空間の定数をエクスポートします。

| テンプレート                     | 名前空間                                  | 送信元                                                                                                         |
| -------------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `VerifyEmail`                    | `emails.verify-email`                     | `sendVerifyEmail`（Better Auth のフック）                                                                      |
| `ResetPasswordEmail`             | `emails.reset-password-email`             | `sendResetPasswordEmail`（Better Auth のフック）                                                               |
| `ChangeEmailConfirmationEmail`   | `emails.change-email-confirmation-email`  | `sendChangeEmailConfirmationEmail`（Better Auth のフック）                                                     |
| `ExistingAccountEmail`           | `emails.existing-account-email`           | `sendExistingAccountEmail`（Better Auth の `onExistingUserSignUp`）                                            |
| `PasswordChangedEmail`           | `emails.password-changed-email`           | `sendPasswordChangedEmail`（Better Auth の `onPasswordReset`、`password-change-notice` フック、`setPassword`） |
| `DeleteAccountEmail`             | `emails.delete-account-email`             | `sendDeleteAccountEmail`（Better Auth の `sendDeleteAccountVerification`）                                     |
| `InvitationEmail`                | `emails.invitation-email`                 | `sendInvitationEmail` (`createInvitation`, `resendInvitation`)                                                 |
| `NewsletterConfirmationEmail`    | `emails.newsletter-confirmation-email`    | `subscribeToNewsletter`                                                                                        |
| `NewsletterNotificationEmail`    | `emails.newsletter-notification-email`    | `confirmNewsletterSubscription`、宛先は `CONTACT_EMAIL`                                                        |
| `PurchaseConfirmationEmail`      | `emails.purchase-confirmation-email`      | `sendPurchaseConfirmationEmail`（Polar の `order.paid`）                                                       |
| `UnmatchedOrderAlertEmail`       | `emails.unmatched-order-alert-email`      | `sendUnmatchedOrderAlert`（Polar の `order.paid`）、宛先は `CONTACT_EMAIL`                                     |
| `WithdrawalAcknowledgementEmail` | `emails.withdrawal-acknowledgement-email` | `sendWithdrawalAcknowledgement`（`submitWithdrawal`）                                                          |
| `WithdrawalNotificationEmail`    | `emails.withdrawal-notification-email`    | `sendWithdrawalNotification`（`submitWithdrawal`）、宛先は `CONTACT_EMAIL`                                     |

テンプレートは `locale` と `messages` を受け取り、use-intl の `createTranslator` で翻訳します。

```tsx
const t = createTranslator({ locale, messages: { emails: { "verify-email": messages } }, namespace: "emails.verify-email" })
```

アカウント関連のメールは、アプリケーション名を表示する `EmailBrandHeader` で始まり、ボタンの下に `EmailFallbackLink` を置きます。これは同じリンクをプレーンテキストにしたもので、ボタンを表示しないメールクライアントのためのものです。確認、パスワードリセット、メールアドレス変更、アカウント削除のメールには、Better Auth に設定された値である `EMAIL_LINK_LIFETIME_HOURS` から、リンクの有効期間が記載されます。

## 送信

ユースケースは、Better Auth から渡されるコールバック URL から言語と `redirect` を取り出し、受信者ごとの上限を確認し、メッセージを読み込み、テンプレートをレンダリングして送信します（`src/modules/verification/use-cases/send-verify-email.ts`）。

```ts
if (!(await withinRecipientRateLimit({ kind: EMAIL_PURPOSE.VERIFY_EMAIL, recipient: user.email }))) {
  console.warn("[email] verification email not sent: the recipient reached the hourly limit")
  return
}
const callback = new URL(callbackURL, getRequest().url)
const locale = extractLocaleFromPath(callback.pathname) ?? I18N.DEFAULT_LOCALE
const verifyUrl = new URL(localizePathname({ locale, pathname: ROUTES.VERIFY_EMAIL }), getRequest().url)
verifyUrl.search = callback.search
verifyUrl.searchParams.set("token", token)

const messages = await loadNamespace<typeof verifyEmailMessages>({ locale, namespace: VERIFY_EMAIL_NAMESPACE })
await sendEmail({
  idempotency: { purpose: EMAIL_PURPOSE.VERIFY_EMAIL, token: crypto.randomUUID() },
  react: createElement(VerifyEmail, { locale, messages, name: user.name, verifyUrl: verifyUrl.toString() }),
  subject: createTranslator({ locale, messages })("subject"),
  to: user.email,
})
```

`sendEmail`（`src/integrations/resend/resend.utils.ts`）は、`from` が指定されない限り `RESEND_EMAIL_FROM` から Resend 経由で送信し（オーナーへの通知、アカウントに対応しない注文のアラート、撤回の通知は `NOTIFICATIONS_EMAIL` を使います）、冪等性キーを渡し、失敗時はエラーを投げます。

アカウント関連のメールは、フローを開始したページの言語を使います。この言語はメールのリンクに含まれる `callbackURL` から読み取ります。再登録の場合は、登録リクエストの `callbackURL` から取得します。コールバックを指定しないフロー、つまり未確認のアカウントへのサインインとパスワードリセットは、リクエストを送ったページ（このサイト上にある場合はその `Referer`）から言語と `redirect` を取得します。ニュースレターのメールはフォームと一緒に送られた言語を使い、オーナーへの通知は常に `en-US` です。購入確認メールは、`startCheckout` が注文のメタデータに保存した言語を使い、言語がない場合は英語になります。このメールは、即時提供への購入者の同意を永続的な媒体で確認するものです。[ライセンス](/docs/features/licences#purchase-confirmation)を参照してください。アカウントに対応しない注文のアラートは、顧客がどのアカウントにも対応しない支払い済みのライセンス注文をサイトに知らせるもので、`I18N.DEFAULT_LOCALE` で送られます。[ライセンス](/docs/features/licences#orders-that-match-no-account)を参照してください。撤回の受領確認は意思表示が送信されたページの言語を使い、サイト宛ての撤回の通知は `I18N.DEFAULT_LOCALE` で送られます。[ライセンス](/docs/features/licences#withdrawal-function)を参照してください。招待メールは管理者が選んだ言語を使います。この言語は招待の `locale` に保存されています。

`withinRecipientRateLimit`（`src/lib/rate-limit.ts`）は、種類（確認、パスワードリセット、既存アカウント、アカウント削除、ニュースレターの確認、撤回の受領確認）ごとに、アドレスあたり 1 時間に <RepositoryFact name="recipientEmailsPerHour" /> 通までメールを許可し、アドレスの SHA-256 ハッシュをキーとして `rate_limit` テーブルでカウントします。上限を超えるとメールはスキップされますが、リクエストには通常どおりの応答が返ります。メールアドレス変更の確認メール、パスワード変更の通知、オーナーへの通知、購入確認メール、アカウントに対応しない注文のアラート、撤回の通知には上限はありません。パスワードの変更にはリセットトークンまたは現在のパスワードが必要です。購入確認メールとアカウントに対応しない注文のアラートを送らせるのは訪問者ではなく Polar の Webhook で、送信はどちらも注文ごとに 1 回です。撤回の通知はサイト宛てにだけ送られ、クライアントごとに 1 分あたり <RepositoryFact name="sensitiveRateLimit" /> 通までです。招待メールも同じ上限の対象ですが、上限を超えると `sendInvitationEmail` はメールを省略せず、`TOO_MANY_REQUESTS` で失敗します。
