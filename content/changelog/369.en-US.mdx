- Changed: `bun run check:areas` now prunes, as the `saasyland` CLI does, what the files that stay reference of each removed area: every import of a deleted file, the array element, object property, type member or JSX child that names it, the names an area owns in files that stay, and the imports and local declarations nothing uses afterwards. It lists each reference it cannot prune by file, line and column, then type-checks the rest. The first such names in `scripts/areas.ts` are the team area's paths in `src/areas/auth.shared.ts`. See [Testing](/docs/conventions/testing#tests-follow-the-areas).
