---
title: "Skrypty projektu"
description: "Polecenia używane na co dzień."
---

| Zadanie                                              | Polecenie                |
| ---------------------------------------------------- | ------------------------ |
| Uruchomienie serwera deweloperskiego                 | `bun run dev`            |
| Sprawdzenie formatowania, lintera, typów i tłumaczeń | `bun run check`          |
| Uruchomienie wszystkich projektów Vitest             | `bun run test`           |
| Sprawdzenie wymogu pokrycia                          | `bun run test:coverage`  |
| Uruchomienie przeglądarkowego testu smoke            | `bun run test:e2e:smoke` |
| Wygenerowanie migracji                               | `bun run db:generate`    |
| Zbudowanie Workera preview                           | `bun run build`          |
| Serwowanie ostatniego buildu                         | `bun run start`          |
| Wdrożenie preview                                    | `bun run deploy:preview` |

Przed otwarciem pull requesta uruchom tę samą sekwencję co CI:

```sh
bun run check
bun run test:coverage
bun run test:e2e:smoke
```

Używaj `bun run test`, a nie `bun test`, aby Vitest działał z konfiguracją projektu. Skrypty kończące się nazwą środowiska, takie jak `db:migrate:preview` czy `deploy:production`, działają wyłącznie na tym środowisku.

Pełną listę znajdziesz na stronie [Skrypty projektu](/docs/tooling/scripts).
