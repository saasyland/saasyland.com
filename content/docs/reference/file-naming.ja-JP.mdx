---
title: "ファイル命名規則"
description: "src、messages、content、e2e で使われるファイル名のパターンとサフィックス。"
---

すべてのファイルとフォルダーにはケバブケースを使います。

## ソースファイル

| パターン                                                     | 意味                                                                                                                   |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | ファイルルート。ドットはパスセグメント、`_` はパスなしレイアウト、`$` はスプラット、`index` はインデックスルートを表す |
| `src/routes/api/<name>.ts`                                   | HTTP ハンドラー                                                                                                        |
| `modules/<table>/<table>.schema.ts`                          | Drizzle のテーブル                                                                                                     |
| `modules/<table>/<table>.zod.ts`                             | Zod スキーマ                                                                                                           |
| `modules/<table>/<table>.constants.ts`                       | クエリキー、ミューテーションキー、enum                                                                                 |
| `modules/<table>/<table>.types.ts`                           | テーブルから導出した型                                                                                                 |
| `modules/<table>/<table>.utils.ts`                           | テーブル用の純粋なヘルパー                                                                                             |
| `modules/<table>/<table>.server.ts`                          | モジュール用のサーバー専用ヘルパー                                                                                     |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | 1 つのユースケース                                                                                                     |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | ベンダーの設定またはアダプター（例：`auth.server.ts`）                                                                 |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | データテーブルのカラム                                                                                                 |
| `presentation/emails/<name>.tsx`                             | `<NAME>_NAMESPACE` をエクスポートするメールテンプレート                                                                |
| `hooks/use-<name>.ts`                                        | 共有の React フック                                                                                                    |
| `providers/<name>-provider.tsx`                              | アプリケーションプロバイダー                                                                                           |

## テスト

| パターン                              | ランナー                             |
| ------------------------------------- | ------------------------------------ |
| `__test__/<file>.test.ts`             | Vitest の `node` プロジェクト        |
| `__test__/<file>.integration.test.ts` | Vitest の `integration` プロジェクト |
| `__test__/<file>.component.test.tsx`  | Vitest の `component` プロジェクト   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                           |

テストファイルには、対象のソースファイルに合わせた名前を付けます。たとえば、`user.schema.ts` のテストは `user.schema.test.ts` です。

## コンテンツとメッセージ

| パターン                                  | 意味                                           |
| ----------------------------------------- | ---------------------------------------------- |
| `messages/<locale>/<namespace>.json`      | 翻訳の名前空間（例：`pages.admin.users.json`） |
| `content/docs/<path>/<page>.<locale>.mdx` | ドキュメントページ                             |
| `content/docs/<path>/meta.<locale>.json`  | ドキュメントのナビゲーション                   |
| `content/blog/<slug>.<locale>.mdx`        | ブログ記事                                     |
