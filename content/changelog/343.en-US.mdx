- Changed: the repository's scripts and lint plugins carry no `undefined` or `null` branch and no `return undefined`. The Vite plugins declare hook filters, the lint plugins share one node reader and one class scan, and every script value, such as the script arguments, the exit code, the client build directory and the D1 environments, is declared once. `code-style/no-undefined-branch` now holds for `scripts` and their tests, and the code-style conventions show the shapes that replace an undefined branch. See [Code style](/docs/conventions/code-style).
