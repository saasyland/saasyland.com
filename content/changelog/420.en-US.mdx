- Fixed: the slowest component tests no longer run into the test time limit on a busy machine. The tests that waited for the data grid's search, the command palette's search or the licence key's poll move a fake clock past the component's own delay with `controlTimers()` and `passTime()`, and the form tests paste the values whose keystrokes they do not test with the shared `fill`, instead of typing them a character at a time. See [Testing](/docs/conventions/testing).
- Fixed: the revenue panel's test loads its chart before it renders, so the coverage of the panel no longer depends on how fast the chart loads on a busy machine.
