## 環境ファイル

| ファイル           | コミット対象 | 使用箇所                                                                                                                     |
| ------------------ | ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `.env.example`     | はい         | すべてのシークレットを空の値で列挙                                                                                           |
| `.env.development` | いいえ       | `bun run dev`、`polar:verify:development`、`db:studio:development`、`db:introspect:development`                              |
| `.env.preview`     | いいえ       | `deploy:preview`（宣言されたシークレット）、`polar:verify:preview`、`db:studio:preview`、`db:introspect:preview`             |
| `.env.production`  | いいえ       | `deploy:production`（宣言されたシークレット）、`polar:verify:production`、`db:studio:production`、`db:introspect:production` |
| `.env.test`        | はい         | Vitest と `test` Wrangler 環境。ダミー値のみ                                                                                 |

## 変数

| 変数                        | 使用箇所                                                                                                   |
| --------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `AUTH_SECRET`               | Better Auth の署名、暗号化、メール認証トークン                                                             |
| `AUTH_GITHUB_CLIENT_ID`     | GitHub OAuth。GitHub スター数のリクエストの認証にも使用                                                    |
| `AUTH_GITHUB_CLIENT_SECRET` | GitHub OAuth。GitHub スター数のリクエストの認証にも使用                                                    |
| `AUTH_GOOGLE_CLIENT_ID`     | Google OAuth                                                                                               |
| `AUTH_GOOGLE_CLIENT_SECRET` | Google OAuth                                                                                               |
| `RESEND_API_KEY`            | Resend クライアント                                                                                        |
| `RESEND_EMAIL_FROM`         | `sendEmail` のデフォルトの送信元                                                                           |
| `POLAR_ACCESS_TOKEN`        | Polar SDK クライアント                                                                                     |
| `POLAR_SERVER`              | 開発とプレビューでは `sandbox`、本番では `production`                                                      |
| `POLAR_WEBHOOK_SECRET`      | Polar の Webhook 署名の検証                                                                                |
| `POLAR_ORGANIZATION_ID`     | Polar のライセンスキーの無効化と割引の検索                                                                 |
| `POLAR_PRODUCT_ID_CORE`     | Core プランのチェックアウト用商品                                                                          |
| `POLAR_PRODUCT_ID_COMPLETE` | Complete プランのチェックアウト用商品                                                                      |
| `POLAR_PRODUCT_ID_AGENCY`   | Agency プランのチェックアウト用商品                                                                        |
| `CLOUDFLARE_ACCOUNT_ID`     | Drizzle Kit の D1 HTTP ドライバー                                                                          |
| `CLOUDFLARE_DATABASE_ID`    | Drizzle Kit の D1 HTTP ドライバー                                                                          |
| `CLOUDFLARE_ACCESS_TOKEN`   | Drizzle Kit の D1 HTTP ドライバー                                                                          |
| `AFFONSO_PROGRAM_ID`        | アフィリエイトの紹介トラッキングを有効にする、公開の Affonso プログラム ID（任意）                         |
| `FFMPEG`、`FFPROBE`         | `scripts/publish-video.ts` で使う FFmpeg と ffprobe のバイナリ（任意）。デフォルトは `ffmpeg` と `ffprobe` |

`wrangler.jsonc` の各環境は、必要なシークレットを `secrets.required` に列挙します。ただし `test` 環境では、3 つの Cloudflare 変数を省略しています。`AFFONSO_PROGRAM_ID` はシークレットではありません。ページの script タグに含まれるため、`vars` の下の Worker 変数として、実際の支払いを受け付ける環境にのみ設定します。現在設定しているのは `test` だけで、ブラウザーテスト用のダミー ID です（[アフィリエイトプログラム](/docs/features/affiliates)）。`FFMPEG` と `FFPROBE` は `scripts/publish-video.ts` 用の任意のシェル変数で、Worker のシークレットではありません。Worker のコードはこれらの変数を `cloudflare:workers` の `env` から読み取り、その型は `src/types/bindings.d.ts` で定義されています。`VITE_` 変数はありません。公開 URL とドメインは `src/presentation/branding` の定数です。

## バインディング

| バインディング | 種類         | `development`                        | `preview`    | `production` | `test`                      |
| -------------- | ------------ | ------------------------------------ | ------------ | ------------ | --------------------------- |
| `DB`           | D1           | プレビュー用データベース（リモート） | プレビュー用 | 本番用       | ローカルの `saasyland_test` |
| `CACHE`        | KV           | プレビュー用名前空間（リモート）     | プレビュー用 | 本番用       | ローカル                    |
| `MEDIA`        | R2           | プレビュー用バケット（リモート）     | プレビュー用 | 本番用       | ローカルの `saasyland-test` |
| `ASSETS`       | 静的アセット | あり                                 | あり         | あり         | あり                        |

プレビューと本番のデプロイスクリプトは、最初に `scripts/verify-bindings.ts` を実行します。このスクリプトは、環境にバインディングが欠けているか D1 や KV のプレースホルダー ID が残っている場合、また本番がプレビューとリソースを共有している場合に失敗します。R2 バケットは名前でバインドされ（development と preview では `saasyland-preview`、production では `saasyland`）、デプロイの前に存在している必要があります。
