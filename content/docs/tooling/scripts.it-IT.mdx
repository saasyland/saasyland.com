Esegui gli script dalla radice del repository con `bun run <script>`.

## Sviluppo e build

| Script              | Esegue                                                                                                                                    |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `dev`               | `generate:cn`, `content` e `vp dev` nell'ambiente `development` su http://localhost:3000                                                  |
| `build`             | Come `build:preview`                                                                                                                      |
| `build:preview`     | Pulizia di `dist`, `generate:cn`, `content`, `vp build` per `preview`, `scripts/verify-build.ts` e `scripts/optimize-prerendered-html.ts` |
| `build:production`  | Gli stessi passaggi per `production`                                                                                                      |
| `build:test`        | Gli stessi passaggi per l'ambiente `test`                                                                                                 |
| `start`             | `vp preview` dell'ultima build su http://127.0.0.1:3000                                                                                   |
| `start:test`        | `vp preview` della build di test                                                                                                          |
| `deploy:preview`    | `scripts/verify-bindings.ts preview`, `build:preview` e `wrangler deploy --secrets-file .env.preview`                                     |
| `deploy:production` | `scripts/verify-bindings.ts production`, `build:production` e `wrangler deploy --secrets-file .env.production`                            |

`verify-build.ts` controlla la configurazione di deploy, la lingua del documento, i link canonici e alternativi della home localizzata e delle pagine legali, i font, che le pagine protette e gli alias dei locale non siano stati prerenderizzati e che nessun asset client importi `cloudflare:workers`. `optimize-prerendered-html.ts` rimuove i suggerimenti `modulepreload` delle dipendenze dalle pagine prerenderizzate e mantiene a bassa priorità quello dell'entry.

## Controlli

| Script             | Esegue                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------- |
| `check`            | `generate:cn`, `check:i18n` e `vp check` (formattazione, lint e tipi)                    |
| `check:fix`        | Lo stesso con `vp check --fix`                                                           |
| `check:i18n`       | `scripts/check-i18n.ts`, `scripts/check-message-formats.ts` e `scripts/check-content.ts` |
| `check:pre-commit` | `generate:cn`, `check:i18n` e `vp staged`; eseguito dall'hook di pre-commit              |
| `lint`             | `vp lint`                                                                                |
| `format`           | `vp fmt`                                                                                 |
| `format:check`     | `vp fmt --check`                                                                         |

## Generazione e manutenzione

| Script           | Esegue                                                                                                    |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| `content`        | `fumadocs-mdx`: genera `.source/` da `content/`                                                           |
| `generate:cn`    | Genera le tabelle per l'unione delle classi in `.source/cn-tables.ts` a partire da `src/lib/cn.config.ts` |
| `cf-typegen`     | `wrangler types` per `development`: rigenera `src/types/worker-configuration.d.ts`                        |
| `typegen`        | `cf-typegen`, `generate:cn` e `content`                                                                   |
| `skills:sync`    | `scripts/sync-skills.ts`: ripristina le skill per agenti da `skills-lock.json`                            |
| `clean`          | Rimuove `.source`, `.tanstack`, `.wrangler`, `dist`, `coverage`, l'output di Playwright e `*.tsbuildinfo` |
| `clean:deep`     | `clean` e `node_modules`                                                                                  |
| `clean:hardcore` | `clean:deep`, `bun.lock` e `skills-lock.json`                                                             |
| `prepare`        | Eseguito all'installazione: `vp config --no-agent` (hook Git), `generate:cn` e `content`                  |

`clean` elimina `.wrangler`, compresi i database locali di sviluppo e di test, quindi esporta prima tutti i dati locali che vuoi conservare.
