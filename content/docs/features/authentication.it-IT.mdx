## Proprietario

`integrations/better-auth` — `auth.server.ts`, `auth.client.ts`, validazioni, errori, guardie.

## Capacità

- Email/password
- GitHub + Google OAuth
- Cookie di sessione tramite Better Auth
- Protezione forzata del proxy per `/admin` e `/app`

## Esame

Aggiungere i social provider in configurazione server auth; mantenere i segreti in env; aggiornare i documenti + `.env.example`.
