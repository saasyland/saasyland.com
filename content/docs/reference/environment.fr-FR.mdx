## Fichiers d'environnement

| Fichier            | Versionné | Utilisé par                                                                                                               |
| ------------------ | --------- | ------------------------------------------------------------------------------------------------------------------------- |
| `.env.example`     | Oui       | Liste chaque secret avec une valeur vide                                                                                  |
| `.env.development` | Non       | `bun run dev`, `polar:verify:development`, `db:studio:development`, `db:introspect:development`                           |
| `.env.preview`     | Non       | `deploy:preview` (les secrets déclarés), `polar:verify:preview`, `db:studio:preview`, `db:introspect:preview`             |
| `.env.production`  | Non       | `deploy:production` (les secrets déclarés), `polar:verify:production`, `db:studio:production`, `db:introspect:production` |
| `.env.test`        | Oui       | Vitest et l'environnement Wrangler `test` ; valeurs factices uniquement                                                   |

## Variables

| Variable                    | Utilisée par                                                                                                |
| --------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `AUTH_SECRET`               | La signature, le chiffrement et les jetons de vérification d'e-mail de Better Auth                          |
| `AUTH_GITHUB_CLIENT_ID`     | OAuth GitHub ; authentifie aussi la requête du nombre d'étoiles GitHub                                      |
| `AUTH_GITHUB_CLIENT_SECRET` | OAuth GitHub ; authentifie aussi la requête du nombre d'étoiles GitHub                                      |
| `AUTH_GOOGLE_CLIENT_ID`     | OAuth Google                                                                                                |
| `AUTH_GOOGLE_CLIENT_SECRET` | OAuth Google                                                                                                |
| `RESEND_API_KEY`            | Le client Resend                                                                                            |
| `RESEND_EMAIL_FROM`         | L'expéditeur par défaut de `sendEmail`                                                                      |
| `POLAR_ACCESS_TOKEN`        | Le client du SDK Polar                                                                                      |
| `POLAR_SERVER`              | `sandbox` pour le développement et la preview, `production` pour la production                              |
| `POLAR_WEBHOOK_SECRET`      | La vérification de la signature des webhooks Polar                                                          |
| `POLAR_ORGANIZATION_ID`     | La désactivation des clés de licence Polar et la recherche des réductions                                   |
| `POLAR_PRODUCT_ID_CORE`     | Le produit proposé au paiement pour l'offre Core                                                            |
| `POLAR_PRODUCT_ID_COMPLETE` | Le produit proposé au paiement pour l'offre Complete                                                        |
| `POLAR_PRODUCT_ID_AGENCY`   | Le produit proposé au paiement pour l'offre Agency                                                          |
| `CLOUDFLARE_ACCOUNT_ID`     | Le driver HTTP D1 de Drizzle Kit                                                                            |
| `CLOUDFLARE_DATABASE_ID`    | Le driver HTTP D1 de Drizzle Kit                                                                            |
| `CLOUDFLARE_ACCESS_TOKEN`   | Le driver HTTP D1 de Drizzle Kit                                                                            |
| `AFFONSO_PROGRAM_ID`        | L'identifiant public facultatif du programme Affonso qui active le suivi des recommandations d'affiliation  |
| `FFMPEG`, `FFPROBE`         | Les binaires FFmpeg et ffprobe facultatifs de `scripts/publish-video.ts` ; `ffmpeg` et `ffprobe` par défaut |

Chaque environnement de `wrangler.jsonc` liste les secrets dont il a besoin sous `secrets.required` ; l'environnement `test` omet les trois variables Cloudflare. `AFFONSO_PROGRAM_ID` n'est pas un secret : il apparaît dans la balise script de la page ; c'est donc une variable de Worker sous `vars`, définie uniquement pour l'environnement qui reçoit de vrais paiements. Pour l'instant, seul `test` en définit une, un identifiant factice pour les tests dans le navigateur ([Programme d'affiliation](/docs/features/affiliates)). `FFMPEG` et `FFPROBE` sont des variables shell facultatives pour `scripts/publish-video.ts`, et non des secrets du Worker. Le code du Worker les lit depuis `env` dans `cloudflare:workers`, avec les types fournis par `src/types/bindings.d.ts`. Il n'existe aucune variable `VITE_` : l'URL publique et le domaine sont des constantes dans `src/presentation/branding`.

## Bindings

| Binding  | Type                 | `development`                 | `preview` | `production` | `test`                 |
| -------- | -------------------- | ----------------------------- | --------- | ------------ | ---------------------- |
| `DB`     | D1                   | Base de preview, distante     | Preview   | Production   | `saasyland_test` local |
| `CACHE`  | KV                   | Namespace de preview, distant | Preview   | Production   | Local                  |
| `MEDIA`  | R2                   | Bucket de preview, distant    | Preview   | Production   | `saasyland-test` local |
| `ASSETS` | Ressources statiques | Oui                           | Oui       | Oui          | Oui                    |

Les scripts de déploiement de preview et de production exécutent d'abord `scripts/verify-bindings.ts`, qui échoue tant qu'il manque un binding à un environnement ou que celui-ci contient encore des identifiants D1 ou KV provisoires, ainsi que lorsque la production partage une ressource avec la preview. Les buckets R2 sont liés par leur nom (`saasyland-preview` pour le développement et la preview, `saasyland` pour la production) et doivent exister avant un déploiement.
