---
title: "Skills para agentes"
description: "Skills de fornecedores para agentes de programação, restauradas a partir de skills-lock.json."
---

`skills-lock.json` fixa as skills para agentes usadas com este repositório. As skills instaladas não são versionadas: `.agents/` e `.claude/` são ignorados pelo Git.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` apaga `.agents/skills` e `.claude/skills`, reinstala todas as skills do lockfile com `bunx skills experimental_install`, move cada skill para um grupo de fornecedor em `.agents/skills/<group>/<skill>/SKILL.md` e cria links de cada grupo em `.claude/skills`. Ele falha quando a origem de uma skill não tem mapeamento de grupo.

| Grupo                                                 | Origem                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------ |
| `anthropic`                                           | `anthropics/skills`                                                |
| `better-auth`                                         | `better-auth/skills`                                               |
| `cloudflare`                                          | `cloudflare/skills`                                                |
| `polar`                                               | `polarsource/skills`                                               |
| `resend`                                              | `resend/resend-skills`                                             |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) e `TanStack/table` (`table`) |
| `remotion`                                            | `remotion-dev/skills`                                              |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Skills gerais de engenharia, design e marketing                    |

A sincronização substitui os dois diretórios, então mantenha skills personalizadas em outro lugar. `bun run clean:hardcore` apaga `skills-lock.json`.

## Regra

Antes de alterar código que envolve TanStack Start, Router ou Table, Better Auth, Cloudflare, Polar ou Resend, leia a skill correspondente. As skills descrevem as APIs atuais dos fornecedores; as convenções deste repositório estão documentadas em [Arquitetura](/docs/architecture) e [Convenções](/docs/reference/conventions).
