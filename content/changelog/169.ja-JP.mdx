- コードはどの言語でもコードのままになりました。ランディングページの「すべての主張を検証してください」の一覧は、`coverage/coverage-summary.json` や `bun run test:coverage` など、挙げるファイルとコマンドを `REPOSITORY_FACTS` から ICU 引数として受け取るため、ドイツ語、フランス語、イタリア語、日本語、ブラジルポルトガル語のページに翻訳されたパスや存在しないコマンドが表示されることはなくなりました。サマリーのパスは `vite.config.ts` から、specs のディレクトリは `playwright.config.ts` から取ります。`check-message-formats.ts` は、翻訳が英語のメッセージのファイルパスやコマンドを変えたり Markdown のバッククォートを加えたりすると失敗し、`check-content.ts` は、翻訳したページがインラインコード、コンポーネント、タイトル以外のコンポーネントの props、ほかのページへのリンクを落としたり加えたりしたとき、または表の行数が異なるときに失敗するようになりました。新しいチェックにより、CLI ライセンス API の行がないポーランド語とブラジルポルトガル語の HTTP ハンドラーのページと、変わってしまったいくつかのコードスパンが見つかり、すべて修正しました。ドイツ語のプライバシーポリシーは、ほかの言語と同じくニュースレターの確認トークンと配信停止トークンを明記し、`/admin/pricing-models` のデモの価格、割引額、売上は、言語ごとにドル、ユーロ、ズウォティ、レアルで手入力した金額ではなく、ストアの通貨 `DEFAULT_CURRENCY_CODE` の数値をページの言語で整形したものになりました。[翻訳とコンテンツ](/docs/conventions/translations)を参照してください。
