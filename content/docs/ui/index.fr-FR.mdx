| Chemin                                                  | Contenu                                                                                                                                                                                                           |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/presentation/components/shadcn/`                   | Primitives shadcn générées, variante React Aria                                                                                                                                                                   |
| `src/presentation/components/custom/`                   | Composants de l’application : fichiers partagés à plat (`footer.tsx`, `navigation.tsx`, `data-table.tsx`, `locale-switcher.tsx`, …) et dossiers par domaine `admin/`, `app/`, `auth/`, `blog/` et `landing-page/` |
| `src/presentation/styles/`                              | `globals.css` (Tailwind, jetons, échelle typographique), `fonts.css`, `docs.css`, `typeset.css`                                                                                                                   |
| `src/presentation/theme/`, `src/presentation/branding/` | Constantes de thème et d’identité visuelle                                                                                                                                                                        |
| `src/presentation/document-assets.ts`                   | Feuille de style globale et préchargement des polices                                                                                                                                                             |
| `src/providers/`                                        | `AriaProvider`, `ThemeProvider`, `TranslationsProvider`, `MotionProvider`                                                                                                                                         |

## Dans ce chapitre

- [Composants shadcn](/docs/ui/shadcn-components) : les primitives et la façon dont les écrans les utilisent.
- [DataTable](/docs/ui/data-table) : l’unique composant de tableau.
- [Thème](/docs/ui/theme) : les thèmes clair, sombre et système, et les jetons CSS.
- [Polices et identité visuelle](/docs/ui/fonts-and-branding) : polices auto-hébergées, préchargements et constantes de marque.
- [Modèles de composition](/docs/ui/composition-patterns) : comment routes, pages et composants s’assemblent.
