- Zmieniono: żądanie paczki do API licencji CLI odczytuje nagłówek archiwum wydania w R2 zamiast samego archiwum. Skrót SHA-256 archiwum jest teraz przy nim zapisany jako własne metadane `sha256`, które zapisuje `bundle:upload` z repozytorium CLI, więc Worker nie pobiera, nie dekompresuje i nie haszuje już całej paczki przy każdym żądaniu: przy dzisiejszej paczce o rozmiarze 1,7 MB żądanie zajmowało w lokalnym testowym Workerze około 31 ms CPU, a teraz około 3 ms, niezależnie od rozmiaru paczki. Na obiekt bez skrótu API odpowiada `serviceUnavailable`, a log wskazuje ten obiekt. `bun run db:reset:test` wgrywa lokalną paczkę wraz ze skrótem przez `getPlatformProxy` z Wranglera, bo `wrangler r2 object put` nie potrafi ustawić własnych metadanych. Zobacz [Paczki szablonów](/docs/features/cli-licence-api#template-bundles) i [Publikowanie paczek](/docs/features/cli-licence-api#publishing-bundles).
