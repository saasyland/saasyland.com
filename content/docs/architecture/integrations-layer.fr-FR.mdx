## Ce qui n'est pas une intégration

- Le nombre d'étoiles GitHub est une fonction serveur dans `src/lib/github.ts`, mise en cache dans KV.
- La limitation de débit se trouve dans `src/lib/rate-limit.ts` et s'appuie sur la table `rate_limit`.
- Les bindings Cloudflare ne nécessitent aucun adaptateur. Le code serveur les lit depuis `env` dans `cloudflare:workers`.

## La logique métier reste dans les modules

Une intégration configure un fournisseur. Les décisions concernant les données de l'application appartiennent au module qui possède la table :

- Le plugin Polar, l'un des `plugins` de `src/integrations/better-auth/auth.server.ts`, vérifie les signatures des webhooks avec `POLAR_WEBHOOK_SECRET` et transmet chaque événement à `handlePolarEvent` dans `src/integrations/polar/polar.webhooks.ts`. Celui-ci le passe à chaque élément de `POLAR_EVENT_HANDLERS` qui liste l'événement ; l'élément de la licence appelle `licenseWebhookHandlers` dans `src/modules/license/license.webhooks.ts`, qui appellent les cas d'usage de licence, et les éléments des commandes et des abonnements appellent `recordOrder` et `recordSubscription`. Les identifiants des produits des offres de licence, `POLAR_PRODUCT_IDS`, appartiennent eux aussi à la fonctionnalité des licences, dans `src/modules/license/license.utils.ts`.
- Les hooks e-mail de Better Auth appellent directement `sendVerifyEmail`, `sendExistingAccountEmail`, `sendResetPasswordEmail`, `sendPasswordChangedEmail`, `sendDeleteAccountEmail` et `sendChangeEmailConfirmationEmail`, issus des modules verification, account et user.
- Un cas d'usage envoie un e-mail dans la locale que lui transmet son appelant (l'e-mail de vérification la lit dans l'URL de callback) : il charge le namespace du modèle, effectue le rendu du modèle, puis appelle `sendEmail` :

```ts
const messages = await loadNamespace<typeof verifyEmailMessages>({ locale, namespace: VERIFY_EMAIL_NAMESPACE })
await sendEmail({
  idempotency: { purpose: VERIFICATION_EMAIL_PURPOSE.VERIFY_EMAIL, token: crypto.randomUUID() },
  react: createElement(VerifyEmail, { locale, messages, name: user.name, verifyUrl: verifyUrl.toString() }),
  subject: createTranslator({ locale, messages })("subject"),
  to: user.email,
})
```
