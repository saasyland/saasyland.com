- Changed: CI builds the test Worker once and runs the browser suite on four runners in parallel, each with its share of the specs, instead of building and testing on one runner. One `Build and E2E (chromium)` check still passes only when the build and every shard pass, and when a shard fails its blob report is merged with the others into one HTML report. See [CI/CD](/docs/tooling/ci-cd#checks).
- Changed: a new commit on a pull request cancels the CI run of the commit it replaces. Pushes to `main` now run in `deploy.yml`, which calls `ci.yml` for the same checks before it deploys production and releases, and whose runs queue and never cancel one another, so every push to `main` is still tested, deployed and released.
- Fixed: every CI job restored Bun's install cache twice, once through `setup-vp` and once more through `actions/cache`; it now restores it once.
