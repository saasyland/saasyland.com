## ツール

| ツール  | バージョン                 | 理由                                                                                                                                  |
| ------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Bun     | 1.4.0                      | パッケージマネージャー兼スクリプトランナー。`package.json` の `packageManager` と CI でバージョンを固定しています                     |
| Node.js | 24.x 系の 24.11 以降       | Vite+ が受け付けるのは `^22.18.0`、`^24.11.0`、`>=26.0.0` です。CI は Node 24 を使い、テスト用データベースは `node:sqlite` を使います |
| Git     | 最近のバージョンであれば可 | インストール手順で Git フックをセットアップします                                                                                     |

Wrangler、drizzle-kit、Playwright、Vite+ CLI は開発依存関係です。パッケージのスクリプトまたは `bunx` から実行してください。ブラウザーテストには、`bun run test:e2e:install` でインストールする Playwright のブラウザーも必要です。

## アカウント

隔離されたテストプレビューとすべての自動テストでは、アカウントも認証情報も不要です。開発とデプロイでは実際のサービスを使います。

- D1、KV、Workers を利用できる Cloudflare アカウント。開発サーバーはリモートのプレビュー用リソースに接続します。
- ソーシャルサインイン用の GitHub と Google の OAuth アプリ。
- 認証済みの送信元を持つ Resend。メールによるサインアップには認証済みのアドレスが必要なため、これがないとサインアップできません。
- Polar。開発ではサンドボックスを使い、Core、Complete、Agency の各プランに対応する 3 つの商品を用意します。
