## Scegli un ambiente

| Ambiente          | Comandi                                     | Dati                                                                     | Provider                                |
| ----------------- | ------------------------------------------- | ------------------------------------------------------------------------ | --------------------------------------- |
| Anteprima isolata | `db:reset:test`, `build:test`, `start:test` | D1, KV e R2 locali in `.wrangler/test`, account di prova                 | Intercettati; nessun account necessario |
| Sviluppo          | `db:reset:local`, `db:seed:local`, `dev`    | D1, KV e R2 locali in `.wrangler/state`, amministratore e corsi dal seed | Reali, da `.env.development`            |

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

L'anteprima isolata serve una build su <RepositoryFact name="localServerOrigin" />; ricompilala per vedere le modifiche al codice. Accedi con uno degli account creati dal seed elencati in [Primo avvio](/docs/getting-started/first-run) e la password di `e2e/data/accounts.ts`. Le email vengono intercettate invece di essere inviate: apri `/__test/emails?to=<address>` per leggerle, compresi i link di verifica.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

Il server di sviluppo gira su `http://localhost:3000` con ricaricamento a caldo. I suoi binding `DB`, `CACHE`, `MEDIA` e `BUNDLES` sono locali, quindi nulla di ciò che fai raggiunge i dati dell'anteprima o di produzione. Accedi come l'amministratore creato dal seed descritto in [Il seed locale](/docs/tooling/database#the-local-seed). Usa `POLAR_SERVER=sandbox`.

## Leggi gli errori del server

- Una funzione server che fallisce registra `Server function failed` con l'errore originale nel terminale in cui gira `bun run dev`, oppure in Workers Logs negli ambienti distribuiti. Il browser riceve solo il codice di errore.
- `Rate-limit storage unavailable` indica che D1 non era raggiungibile durante un controllo del limite di richieste; la richiesta è stata rifiutata.
- `[license] <method> <path> failed` indica che una richiesta all'API delle licenze della CLI è fallita sul server, per esempio perché D1 o Polar hanno restituito un errore, e la CLI ha ricevuto `serviceUnavailable`. La voce contiene l'errore con la sua causa e il suo stack, e `[licence key]` al posto della chiave del chiamante.
- `No messages/<locale>/<namespace>.json` indica che una route dichiara un namespace senza file per quella lingua.

## Ispeziona i dati

- Drizzle Studio: `bun run db:studio:local` per il database locale; `:preview` e `:production` richiedono le variabili `CLOUDFLARE_*` nel file di ambiente corrispondente.
- Database di test locale: `bunx wrangler d1 execute DB --env test --local --persist-to .wrangler/test --command "SELECT email, role FROM user"`.

## Correggi i file generati

- Tipi dei binding del Worker, tabelle dei nomi di classe o contenuti della documentazione non aggiornati: `bun run typegen`.
- Le traduzioni non vengono risolte: `bun run check:i18n` elenca le chiavi mancanti per lingua e quelle che non si risolvono nel loro ambito `useTranslations`.
- `bun run clean` rimuove l'output di build, le cache e `.wrangler`, compreso il database di test locale; in seguito esegui `db:reset:test`.

## Debug dei test

- Esegui un solo progetto o solo i test interessati: `bun run test:unit`, `bun run test:component`, `bun run test:changed`, `bun run test:watch`.
- Playwright: `bun run test:e2e:headed` mostra il browser e `bun run test:e2e:ui` apre la modalità UI. Le esecuzioni locali conservano le tracce dei test falliti e aprono il report HTML in caso di errori.
- Esegui la suite nel browser su una porta libera dell'intervallo della build di test quando un altro server occupa <RepositoryFact name="localServerOrigin" /> o un altro worktree esegue la sua suite: `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3027 bun run test:e2e:pr`. [Playwright](/docs/tooling/playwright#running-beside-other-worktrees) spiega come scegliere la porta.
