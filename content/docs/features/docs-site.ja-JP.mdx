## コンテンツ

- ページは、すべての言語について `content/docs/<section>/<page>.<locale>.mdx` として置きます。
- 各フォルダーの `meta.<locale>.json` がセクションのタイトル、アイコン、ページの順序を決めます。
- `src/integrations/fumadocs/fumadocs.i18n.ts` は `dot` パーサー、既定言語かつフォールバックとしての `en-US`、`hideLocale: "always"` を使います。言語プレフィックスはアプリ自身が処理するためです。
- `bun run content` は `fumadocs.config.ts` から `.source` を生成します。

## ルート

- `/docs` レイアウト（`src/routes/docs.tsx`）: サーバー関数が現在の言語のページツリーを返し、レイアウトは Fumadocs の `DocsLayout` を、GitHub へのリンクと、サイドバー下部に同じスタイルのセレクトフィールドとして並ぶ `LocaleSelect`・`ThemeSwitch` 付きで表示します。Fumadocs の目次は見出しへ移動するだけなので `BackToTop` を加えます。`docs.css` を読み込み、読み込み中は `DocsPending` を表示します。
- `/docs/` と `/docs/$` は `loadDocsPage`（`fumadocs.docs.ts`）を呼び出し、ページを解決してからレンダリング前にコンパイル済み MDX（`docsContent`）をプリロードします。
- `/api/search` はすべての言語を対象とした Fumadocs の検索を提供します（`fumadocs.search.ts`）。

MDX ページでは `src/presentation/components/custom/mdx.tsx` の `mdxComponents` を使えます。Fumadocs の既定コンポーネント、Fumadocs の `Accordions`・`Steps`・`Tabs`、shadcn の `Alert`・`Badge`・`Button`・カードの各パーツ・`Separator`・テーブルの各パーツ、そして値を手入力する代わりにコードから表示する `RepositoryFact`・`RepositoryTable`・`TierPrice`（[翻訳とコンテンツ](/docs/conventions/translations)）が含まれます。リンクは自動的にローカライズされます。

## アクセシビリティ

ドキュメントページは両方のテーマで WCAG 2.2 AA を満たします。コードブロックは Shiki の GitHub Light と GitHub Dark のテーマを使い、2 つのトークンの色を置き換えて（`fumadocs.config.ts` の `colorReplacements`）すべてのトークンが 4.5:1 を満たすようにしています。コードブロックのスクロール領域はフォーカスできますが、ランドマークになるのはブロックにタイトルがある場合だけです。タスクリストのチェックボックスには項目のテキストで名前が付きます。`e2e/specs/accessibility.spec.ts` はドキュメントのトップページ、規約のすべてのページ、それ以外の各セクションから 1 ページずつをスキャンします。[アクセシビリティ](/docs/conventions/accessibility)を参照してください。

## ページの追加

1. `title` と `description` を付けて `<page>.en-US.mdx` を書きます。
2. スラッグを `meta.en-US.json` と、ほかのすべての `meta.<locale>.json` に同じ順序で追加します。
3. コードブロックをバイト単位で同一に保ったまま、ほかのすべての言語の翻訳を追加します。
4. `bun scripts/check-content.ts`（`bun run check:i18n` にも含まれます）と `bun run content` を実行します。

`bun run build` はすべてのドキュメントページを全言語でプリレンダリングします。
