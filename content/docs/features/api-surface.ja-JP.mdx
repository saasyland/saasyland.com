アプリは 3 つの HTTP ルートを公開しており、`src/routes/api` で `createFileRoute` の `server.handlers` を使って宣言しています。

| ルート        | メソッド  | ハンドラー                                                                                                                                                          |
| ------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api`        | GET       | `{ "runtime": "cloudflare-workers" }` を返します。                                                                                                                  |
| `/api/auth/$` | GET、POST | Better Auth: サインイン、OAuth コールバック、`/api/auth/verify-email`、Polar プラグインのエンドポイント `/api/auth/polar/webhooks` と `/api/auth/customer/portal`。 |
| `/api/search` | GET       | Fumadocs の検索（`fumadocs.search.ts`）。                                                                                                                           |

```ts
import { createFileRoute } from "@tanstack/react-router"

import { auth } from "~/src/integrations/better-auth/auth.server"

export const Route = createFileRoute("/api/auth/$")({
  server: { handlers: { GET: ({ request }) => auth.handler(request), POST: ({ request }) => auth.handler(request) } },
})
```

## REST の代わりにサーバー関数

アプリの操作は `src/modules/<table>/use-cases`（またはそれを使う唯一のルート内）にある `createServerFn` 関数です。TanStack Start はセッション、権限、レート制限のミドルウェアを通して、`/_serverFn` 配下の RPC でこれらを呼び出します。このアプリだけが呼び出す操作に REST エンドポイントを追加しないでください。HTTP ルートは Webhook のような外部の呼び出し元のためだけに追加し、署名はプロバイダーの統合で検証します。

## 動作

- Worker は `/api` と `/_serverFn` に言語のリダイレクトを適用せず、これらのリクエストは Cookie から言語を取得します。
- ビルドは `/api` をプリレンダリングしません。
- ハンドラーのテストは `src/routes/api/__test__/handlers.test.ts` にあります。
