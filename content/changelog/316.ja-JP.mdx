- 追加：`bun run deps:update` は、範囲指定のすべての依存関係を最新リリースに、Vite+ を `vp migrate` で、エージェントスキルも合わせて 1 つのコマンドで更新し、新しいリリースがある固定パッケージを表示します。[依存関係](/docs/conventions/dependencies#upgrading)を参照してください。
- 追加：エージェントスキルが説明するパッケージ（`resend`、`better-auth`、`wrangler` など）が `bun run skills:update` なしで動いた場合や、インストール済みのスキルが `skills-lock.json` と異なる場合に、`bun run check` が失敗するようになりました。`src/data/skills.ts` の `SKILL_SOURCES` が、スキルの各ソースと説明対象のパッケージを対応付けます。[エージェントスキル](/docs/tooling/agent-skills#drift-checks)を参照してください。
- 追加：毎週実行する `updates.yml` ワークフローが、利用できる依存関係とスキルの更新を 1 つの GitHub Issue にまとめ、その Issue を作成、書き直し、クローズします。[CI/CD](/docs/tooling/ci-cd#updates) を参照してください。
- 変更：`skills` CLI を開発依存関係にしたため、スキルをインストールしてハッシュを計算するバージョンを `bun.lock` が固定します。
