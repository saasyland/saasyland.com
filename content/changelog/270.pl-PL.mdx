- Naprawiono: każdy punkt [historii zmian](/docs/project/changelog) kończy się pull requestem, z którego pochodzi, i wydaniem, które go dostarczyło, a nie tylko ostatni punkt każdego wpisu, a każdy punkt GitHub Release kończy się swoim `(#<number>)`. Wpis historii zmian, który nie jest listą jednowierszowych punktów, powoduje teraz błąd `bun run check`. Zobacz [Wpisy historii zmian](/docs/conventions/git-workflow#changelog-entries).
