`src/modules/account` は Better Auth の `account` テーブル（`account.schema.ts`）を所有します。ユーザーに紐づく認証情報または OAuth プロバイダーごとに 1 行あり、その中の OAuth トークンは暗号化されています。

## ユースケース

| ユースケース                       | ミドルウェア               | 利用箇所                               |
| ---------------------------------- | -------------------------- | -------------------------------------- |
| `signUpWithPassword`               | レート制限                 | `SignUpForm`                           |
| `signOutUser`                      | サインイン必須             | `useSignOut`                           |
| `changePassword`                   | サインイン必須、レート制限 | `SettingsPasswordForm`                 |
| `changeEmail`                      | サインイン必須、レート制限 | 画面からは未使用                       |
| `updateUser`                       | サインイン必須             | 画面からは未使用                       |
| `sendChangeEmailConfirmationEmail` | Better Auth のフック       | `auth.server.ts` の `user.changeEmail` |

`sendChangeEmailConfirmationEmail` は、Better Auth が発行した確認リンクを含む `ChangeEmailConfirmationEmail` を現在のアドレスへ送信します。

## サインアウト

`useSignOut`（`src/hooks/use-sign-out.ts`）は `signOutUserMutation` を実行し、クエリキャッシュをクリアして `/auth/sign-in` へ移動し、トーストを表示します。管理画面のユーザーウィジェットと `/app` のサイドバーには、それぞれこのフックを使う `SignOutButton` があります。
