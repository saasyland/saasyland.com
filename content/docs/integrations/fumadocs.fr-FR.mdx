---
title: "Fumadocs"
description: "Collections MDX pour la documentation et le blog, sources localisées et recherche."
---

Fumadocs transforme `content/docs` et `content/blog` en arborescences de pages localisées. `bun run content` exécute `fumadocs-mdx` et écrit `.source/` ; `dev`, `typegen` et chaque script de build l'exécutent en premier.

| Fichier              | Rôle                                                                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `fumadocs.config.ts` | La collection `docs` et la collection `blog` avec son schéma de frontmatter                                                                    |
| `fumadocs.i18n.ts`   | Les neuf langues de `I18N`, `en-US` par défaut et comme langue de repli, le parseur `dot` pour `<slug>.<locale>.mdx`, préfixe de langue masqué |
| `fumadocs.source.ts` | `source` sur `/docs` avec le plugin d'icônes Lucide, `blogSource` sur `/blog`, `getPublishedBlogPosts` avec le temps de lecture                |
| `fumadocs.docs.ts`   | Fonction serveur `getDocsPage`, `loadDocsPage` et `docsHead` pour la route `docs.$`                                                            |
| `fumadocs.search.ts` | L'index de recherche servi par `/api/search`                                                                                                   |

Le préfixe de langue est masqué dans les URL Fumadocs, car c'est le routeur qui l'ajoute. Le frontmatter du blog exige `title`, `authorName` et `date`, et accepte `description`, `excerpt`, `faq`, `featured`, `image`, `published`, `tags`, `updated` et `authorImage`.

## Composants

`src/presentation/components/custom/mdx.tsx` associe les composants MDX : les composants Fumadocs par défaut (dont `Cards` et `Callout`), `Accordions`, `Steps` et `Tabs`, ainsi que `Alert`, `Badge`, `Button`, les éléments de carte, `Separator` et `Table` de shadcn. Les liens internes sont localisés avec `localizePathname`. `docs-content.tsx` et `blog-content.tsx` rendent les pages.

## Règles de contenu

Chaque page existe une fois par langue sous la forme `<slug>.<locale>.mdx`, et chaque dossier possède un `meta.<locale>.json` avec le même tableau `pages` dans toutes les langues. Dans un fichier meta, `icon` accepte un nom d'icône Lucide. `scripts/check-content.ts`, qui fait partie de `bun run check:i18n`, échoue lorsqu'une traduction manque, qu'un bloc de code diffère, que la navigation diffère ou qu'un paragraphe en anglais subsiste dans une autre langue.
