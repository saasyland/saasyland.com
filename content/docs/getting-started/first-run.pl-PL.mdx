## Izolowany podgląd testowy

Podgląd testowy buduje aplikację dla środowiska `test`: lokalne D1, KV i R2 w `.wrangler/test`, fikcyjne dane uwierzytelniające z `.env.test`, wstępnie utworzone konta oraz przechwytywane żądania do Resend i Polara. Nie wymaga żadnych kont.

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

Otwórz <RepositoryFact name="localServerOrigin" /> i zaloguj się na jedno z kont, które tworzy `e2e/data/accounts.ts`. Wszystkie mają hasło <RepositoryFact name="testPassword" />. Administratorzy trafiają do `/admin`, klienci do `/app`, a konta z licencjami i ich licencje pochodzą z `e2e/data/licenses.ts`. Licencja Komplet otwiera każdą płatną lekcję przykładowego kursu.

<RepositoryTable columns={["E-mail", "Rola", "Licencja"]} name="seededAccounts" />

Podgląd serwuje gotowy build, więc aby zobaczyć zmiany w kodzie źródłowym, zbuduj go ponownie.

## Tryb deweloperski z Cloudflare

`bun run dev` uruchamia serwer deweloperski z hot reloadem pod adresem http://localhost:3000. Jego bindingi `DB`, `CACHE`, `MEDIA` i `BUNDLES` są lokalne, w `.wrangler/state`, więc tryb deweloperski nigdy nie odczytuje ani nie zapisuje danych preview ani produkcji i nie wymaga logowania do Cloudflare.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

1. Uzupełnij `.env.development` zgodnie z opisem w [Zmiennych środowiskowych](/docs/getting-started/environment-variables), ustawiając `POLAR_SERVER=sandbox`.
2. Utwórz lokalną bazę danych i zastosuj migracje za pomocą `db:reset:local`.
3. Wypełnij ją danymi poleceniem `db:seed:local`: konto administratora, program kursu, licencje i zamówienie.
4. Uruchom serwer i zaloguj się jako <RepositoryFact name="localAdminEmail" /> z hasłem z `LOCAL_ADMIN_PASSWORD` w `.env.development` albo – jeśli ta zmienna nie jest ustawiona – z hasłem <RepositoryFact name="localAdminPassword" />.

`bun run db:studio:local` otwiera lokalne dane w Drizzle Studio. Rejestracja e-mailem wymaga działającej konfiguracji Resend: nowe konto jest zalogowane od razu, ale jego klucz licencyjny i płatne lekcje czekają na link potwierdzający, a ponowne logowanie wymaga potwierdzonego adresu. [Baza danych](/docs/tooling/database) opisuje trzy bazy danych, dane początkowe i sposób utworzenia pierwszego administratora w środowiskach podglądowym i produkcyjnym.
