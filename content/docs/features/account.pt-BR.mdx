`src/modules/account` é dono da tabela `account` do Better Auth (`account.schema.ts`): uma linha por credencial ou provedor OAuth vinculado a um usuário. Os tokens OAuth nela ficam criptografados.

## Casos de uso

| Caso de uso                        | Middleware          | Usado por                                                                     |
| ---------------------------------- | ------------------- | ----------------------------------------------------------------------------- |
| `signUpWithPassword`               | limitado            | `SignUpForm`                                                                  |
| `signOutUser`                      | logado              | `useSignOut`                                                                  |
| `changePassword`                   | logado, limitado    | `PasswordCard`                                                                |
| `setPassword`                      | logado, limitado    | `PasswordCard`                                                                |
| `changeEmail`                      | logado, limitado    | `ChangeEmailForm`                                                             |
| `listAccounts`                     | logado              | `PasswordCard`, `TwoFactorCard`, `ConnectedAccountsCard`, `DeleteAccountCard` |
| `unlinkAccount`                    | logado, limitado    | `ConnectedAccountsCard`                                                       |
| `updateUser`                       | logado              | nenhuma tela                                                                  |
| `sendChangeEmailConfirmationEmail` | hook do Better Auth | `user.changeEmail` em `auth.server.ts`                                        |

`sendChangeEmailConfirmationEmail` envia `ChangeEmailConfirmationEmail` para o endereço atual com o link de confirmação fornecido pelo Better Auth. `changePassword` sempre revoga as outras sessões. `setPassword` adiciona uma senha a uma conta que entra apenas com GitHub ou Google, por meio do `setPassword` do Better Auth, que só roda no servidor, revoga as outras sessões e envia `PasswordChangedEmail`. `listAccounts` retorna o ID da linha, o provedor e a data de criação de cada método de login, sem tokens, e `unlinkAccount` passa um ID de linha para o `unlinkAccount` do Better Auth, que se recusa a desvincular o último.

## Excluir uma conta

A exclusão remove o usuário, então os casos de uso dela ficam no módulo de usuário: `requestAccountDeletion` (logado e limitado) pede ao `deleteUser` do Better Auth que confira a senha e envie por e-mail um link de confirmação, e `confirmAccountDeletion` (logado e limitado como um token) exclui a conta com o token do link. `sendDeleteAccountEmail` (`src/modules/user/use-cases/send-delete-account-email.ts`) é o hook `sendDeleteAccountVerification`. Veja [Configurações](/docs/features/settings#delete-account).

## Preferências

O fuso horário que um usuário escolhe em [Configurações](/docs/features/settings) é uma coluna da tabela `user`, então o caso de uso dele fica no módulo de usuário: `updatePreferences` (`src/modules/user/use-cases/update-preferences.ts`) exige um usuário logado, valida a entrada com `userZodSchemas.updatePreferences` e a salva por meio do `updateUser` do Better Auth, o mesmo caminho da atualização de perfil acima. `PreferencesCard` o chama em `/app/settings` e `/admin/settings`. O idioma é o locale da URL e não fica armazenado.

## Sair

`useSignOut` (`src/hooks/use-sign-out.ts`) executa `signOutUserMutation`, remove os dados da conta do cache de consultas, navega para `/auth/sign-in` e mostra uma notificação. O widget de usuário da administração e a barra lateral de `/app` mostram cada um um `SignOutButton` que o utiliza.
