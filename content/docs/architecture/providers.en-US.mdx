title: "Providers"
description: "The four application providers in src/providers, where each one is mounted and why."
---

`src/providers` contains four providers. Each is mounted as close to its consumers as possible.

| Provider               | Wraps                                                                                                               | Mounted in                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `TranslationsProvider` | use-intl `IntlProvider` with the root and matched route namespaces, the named date formats and the user's time zone | The root shell, around the document body                                    |
| `AriaProvider`         | React Aria `I18nProvider` and `RouterProvider`                                                                      | The root component, around every route                                      |
| `ThemeProvider`        | The `@wrksz/themes` provider, stored in a cookie                                                                    | Around the `Toaster` in the root and the theme switch in the docs sidebar   |
| `MotionProvider`       | Motion `LazyMotion` (strict) and `MotionConfig` with `reducedMotion="user"`                                         | The landing page, the blog index, the blog share buttons and `LicenseOffer` |

## Root composition

`src/routes/__root.tsx` renders the document in `shellComponent` and the application in `component`:

```tsx
const RootComponent = () => (
  <AriaProvider>
    <OfflineBanner />
    {ROOT_COMPONENTS.map(({ component: Component, key }) => (
      <Component key={key} />
    ))}
    <Outlet />
    <ThemeProvider>
      <Toaster />
    </ThemeProvider>
  </AriaProvider>
)
```

- **TranslationsProvider** sits in the shell's `<body>`, so every screen is translated, including the default error and not-found components and the route skeletons. It reads the namespaces from the root namespaces plus each matched route's `staticData.namespaces`, loads them with `useSuspenseQueries` and builds one message tree. It also passes `I18N.FORMATS` and the time zone of the first time zone source an area declares (`TIME_ZONE_SOURCES`), `UTC` without one. The auth area's source reads the session that the route guards loaded, `UTC` without one, and never fetches it; see [Internationalization and locales](/docs/features/internationalization).
- **AriaProvider** passes the current locale to React Aria and connects React Aria links to TanStack Router. Its `useHref` localizes paths, so an `href` on a React Aria component gets the locale prefix.
- **ThemeProvider** does not wrap the route outlet. A provider that updates after hydration would re-render every page, so it wraps only the components that need it. The initial theme is applied before hydration by `ThemeScript` in the document head.
- **MotionProvider** loads the `domMax` feature bundle on demand and is mounted only where animations run: `_site._marketing.index.tsx`, `_site._marketing.blog.index.tsx`, `post-share.tsx` and `license-offer.tsx`, the tier cards on `/app` and `/app/license`. A Bun patch to `framer-motion` 14.14.0 makes `LazyMotion` ignore a bundle that fails to load, as when Safari cancels it because the visitor is leaving, so the components render without animation instead of the page reporting an unhandled rejection.
- **ROOT_COMPONENTS** are not providers. They are the components the areas mount beside the outlet, declared in `src/data/<area>.root.ts` (see [What the areas add](/docs/architecture/platform-layer#what-the-areas-add)). The affiliates area adds `AffiliateReferral`, which renders Affonso's script only on a visit with a referral parameter ([Affiliate programme](/docs/features/affiliates)).

## Not a provider component

- **QueryClient.** `src/router.tsx` creates it per request, puts it in the router context and connects it with `setupRouterSsrQueryIntegration`.
- **Fumadocs.** The `/docs` layout mounts Fumadocs' `RootProvider` with its own theme handling disabled.
