`/admin/pricing-models` は、`src/data/admin.ts` の `ADMIN_PRICING_STATS` と `ADMIN_PRICING_MODELS` から `PricingModelStats` と `PricingModelsGrid` を表示します。フィルターと **モデルを作成** のボタンは未接続で、何も保存されません。

## 価格の出どころ

- **ランディングページ**: `src/data/marketing.ts` の `TIER_PRICES`。`core` <TierPrice tier="core" />、`complete` <TierPrice tier="complete" />、`agency` <TierPrice tier="agency" /> で、`Price` がページの言語で書式設定します。ランディングページの説明文は Core の価格を `{price}` として受け取り、ブログ記事とドキュメントのページは `<TierPrice tier="core" />` でプランの価格を表示するため、価格を手入力する文章はありません。コンサルティングカードの時間単価は同じファイルの `CONSULTING_HOURLY_RATE` です。通話はメールで予約するもので Polar では販売しないため、地域別価格はありません。
- **購入**: `POLAR_PRODUCT_ID_CORE`、`POLAR_PRODUCT_ID_COMPLETE`、`POLAR_PRODUCT_ID_AGENCY` が参照する Polar の商品。
- **地域割引**: `src/modules/_core/constants/pricing.ts` の `PPP_TIERS`。国のグループごとの価格の倍率で、購入時に Polar で設定した自動のパーセント割引と照合されます。倍率は次のとおりです。

`bun run polar:verify:<environment>` は Polar の商品価格を `TIER_PRICES` と、Polar の割引を `PPP_TIERS` と比較し、デプロイスクリプトは手動デプロイのたびに事前にこれを実行します。コードを先に変更し、その後で Polar を変更してください。[Polar の設定](/docs/getting-started/polar-setup)を参照してください。
