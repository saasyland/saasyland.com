| `/affiliates` | `src/routes/_site._marketing.affiliates.tsx` | `pages.legal.affiliates` |

Кожен файл маршруту визначає власний компонент сторінки, статичний `NAMESPACE` і константу модуля з ключами розділів у порядку відображення:

```tsx
const SECTIONS = ["operator", "accounts", "purchases", "payments", "licence", "conduct", "refunds", "responsibility", "law"] as const
```

Сторінка показує `title` і `description` через `ContentPage`, потім `lastUpdated`, а далі `sections.<key>.title` і `sections.<key>.body` для кожного ключа. Спільного компонента для юридичних сторінок немає. Політика конфіденційності та умови партнерської програми передають у свої повідомлення значення з `AFFILIATE_TERMS` (`src/data/affiliates.ts`), тож комісію, тривалість cookie, строк утримання й мінімальну виплату ніколи не вписують у тексти вручну.

## Редагування

- Змінюйте тексти в `messages/<locale>/pages.legal.<doc>.json` для кожної мови й запускайте `bun run check:i18n`.
- Щоб додати розділ, додайте його ключ до `SECTIONS` і повідомлення кожною мовою.
- Посилання у футері — це пункти футера з `LEGAL_NAVIGATION` у `src/data/legal.navigation.ts` з підписами з `navigation.legal.json`: юридична колонка, а в колонці продукту — умови партнерської програми; юридичний розділ додає під формою реєстрації рядок згоди, `SignUpConsent` зі скелетоном у `custom/sign-up-consent.tsx`, до `SIGN_UP_NOTICES` у `src/data/legal.sign-up-notices.ts`, тож проєкт без юридичних сторінок має форму реєстрації без посилань на них. `LegalPending` (`custom/legal-pending.tsx`) — скелетон усіх п’яти сторінок, оголошений у `src/data/legal.skeletons.ts`.

Сторінка ліцензії відокремлює ліцензію MIT публічного репозиторію від окремо наданих платних матеріалів. Політика повернень зберігає обов’язкові права споживачів. Узгоджуйте кожен документ із фактичним оператором, процесом оплати, постачальниками й обробкою даних.
