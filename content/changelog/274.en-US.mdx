- Added: the lint rules `code-style/no-comments`, `code-style/no-multiline-ternary` and `code-style/no-undefined-fallback`, and `bun run check:comments`, which parses every TypeScript, JavaScript and CSS file outside the linter, so `bun run check` now fails on any comment, a disable comment included, on a ternary that spans lines and on `?? undefined`. See [Code style](/docs/conventions/code-style).
- Changed: `typescript/ban-ts-comment` rejects `@ts-expect-error`, `@ts-ignore` and `@ts-nocheck` even with a description, `typescript/consistent-type-assertions` rejects every type assertion except `as const`, and an `eslint-disable` comment no longer switches a rule off. See [Lint and format](/docs/tooling/lint-format).
- Added: a `commit-msg` hook that rejects a commit message whose trailer names an AI tool or that has a "Generated with" line. See [Conventional commits](/docs/tooling/conventional-commits).
