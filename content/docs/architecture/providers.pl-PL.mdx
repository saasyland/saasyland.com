---

`src/providers` zawiera cztery providery. Każdy jest montowany jak najbliżej komponentów, które z niego korzystają.

| Provider               | Opakowuje                                                                                                                                         | Miejsce montowania                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `TranslationsProvider` | `IntlProvider` z use-intl z głównymi przestrzeniami nazw i przestrzeniami dopasowanych tras, nazwanymi formatami dat i strefą czasową użytkownika | Główny shell, wokół body dokumentu                                                  |
| `AriaProvider`         | `I18nProvider` i `RouterProvider` z React Aria                                                                                                    | Główny komponent, wokół każdej trasy                                                |
| `ThemeProvider`        | Provider `@wrksz/themes`, zapisywany w cookie                                                                                                     | Wokół `Toaster` w trasie głównej i przełącznika motywu w pasku bocznym dokumentacji |
| `MotionProvider`       | `LazyMotion` (strict) i `MotionConfig` z `reducedMotion="user"` z Motion                                                                          | Landing, indeks bloga, przyciski udostępniania na blogu i `LicenseOffer`            |

## Kompozycja w trasie głównej

`src/routes/__root.tsx` renderuje dokument w `shellComponent`, a aplikację w `component`:

```tsx
const RootComponent = () => (
  <AriaProvider>
    <OfflineBanner />
    {ROOT_COMPONENTS.map(({ component: Component, key }) => (
      <Component key={key} />
    ))}
    <Outlet />
    <ThemeProvider>
      <Toaster />
    </ThemeProvider>
  </AriaProvider>
)
```

- **TranslationsProvider** znajduje się w `<body>` shella, więc przetłumaczony jest każdy ekran, łącznie z domyślnymi komponentami błędu i nieznalezionej strony oraz szkieletami tras. Zbiera główne przestrzenie nazw oraz `staticData.namespaces` każdej dopasowanej trasy, ładuje je przez `useSuspenseQueries` i buduje jedno drzewo komunikatów. Przekazuje też `I18N.FORMATS` oraz strefę czasową pierwszego źródła strefy czasowej, które deklaruje obszar (`TIME_ZONE_SOURCES`), a bez źródła `UTC`. Źródło obszaru uwierzytelniania odczytuje sesję wczytaną przez guardy tras, a bez sesji `UTC`, i nigdy jej nie pobiera; zobacz [Internacjonalizacja i języki](/docs/features/internationalization).
- **AriaProvider** przekazuje bieżące locale do React Aria i łączy linki React Aria z TanStack Router. Jego `useHref` lokalizuje ścieżki, więc `href` w komponencie React Aria dostaje prefiks locale.
- **ThemeProvider** nie opakowuje outletu trasy. Provider aktualizowany po hydratacji powodowałby ponowne renderowanie każdej strony, dlatego opakowuje tylko komponenty, które go potrzebują. Początkowy motyw jest stosowany przed hydratacją przez `ThemeScript` w sekcji head dokumentu.
- **MotionProvider** ładuje pakiet funkcji `domMax` na żądanie i jest montowany tylko tam, gdzie działają animacje: `_landing.index.tsx`, `blog.index.tsx`, `post-share.tsx` i `license-offer.tsx`, czyli karty planów na `/app` i `/app/license`. Patch Bun dla `framer-motion` 14.14.0 sprawia, że `LazyMotion` pomija pakiet, którego nie udało się załadować, na przykład gdy Safari go przerywa, bo odwiedzający opuszcza stronę, więc komponenty renderują się bez animacji, zamiast żeby strona zgłaszała nieobsłużone odrzucenie.
- **ROOT_COMPONENTS** nie są providerami, tylko komponentami, które obszary montują obok outletu, zadeklarowanymi w `src/data/<area>.root.ts` (zobacz [Co dodają obszary](/docs/architecture/platform-layer#what-the-areas-add)). Obszar partnerski dodaje `AffiliateReferral`, który renderuje skrypt Affonso tylko podczas wizyty z parametrem polecenia ([Program partnerski](/docs/features/affiliates)).

## Elementy, które nie są komponentami providerów

- **QueryClient.** `src/router.tsx` tworzy go dla każdego żądania, umieszcza w kontekście routera i podłącza przez `setupRouterSsrQueryIntegration`.
- **Fumadocs.** Layout `/docs` montuje `RootProvider` z Fumadocs z wyłączoną własną obsługą motywu.
