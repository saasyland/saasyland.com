description: "Коди помилок, константи HTTP, поля Zod і вхідні дані сценаріїв використання в src/modules/_core, на яких побудовано кожен модуль."

`src/modules/_core` — єдина папка модуля, яка не володіє таблицею. Вона містить лише основу, на якій побудовано схеми, схеми Zod і сценарії використання модулів, щоб жоден модуль не визначав її заново: коди помилок, константи HTTP і середовищ, спільні поля Zod і локалізовані тексти, а також вхідні дані пагінації, порядку й пошуку.

## Константи

| Файл                    | Вміст                                                                                                                             |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `constants/errors.ts`   | `ERROR_CODES`, тип `ErrorCode` і клас `AppError`                                                                                  |
| `constants/api.ts`      | `HTTP_STATUS`, назви заголовків `cf-ipcountry` і `cf-connecting-ip`, заголовки безпеки, дозволені хости для кожного режиму збірки |
| `constants/ordering.ts` | `FIRST_POSITION`, місце першого елемента у впорядкованому списку                                                                  |

Дані та допоміжні функції, якими модулі користуються, але на яких не будуються, лежать поза `_core`: каталоги країн, валют, локалей і часових поясів у `src/data/countries.ts`, `src/data/currencies.ts`, `src/data/locales.ts` і `src/data/timezones.ts`, валюта магазину й формат цін у `src/data/pricing.ts`, а також періоди й інтервали графіків адміністративної панелі в `src/lib/time-series.ts`. Каталог локалей містить усі відомі локалі; локалі, які застосунок обслуговує, задає `I18N.SUPPORTED_LOCALES` у `src/integrations/use-intl/i18n.config.ts`. Тест у `src/__test__/module-tables.test.ts` не проходить, коли файл у `_core` не описано на цій сторінці, тож кожен новий файл — свідоме рішення.

## Утиліти

- `utils/localized-text.ts`: `LocalizedText`, текст для кожної локалі, що зберігається як JSON, `localizedTextSchema`, який вимагає `en-US` і обмежує довжину кожного тексту (максимальна кількість символів: <RepositoryFact name="localizedTextMaxLength" />), і `localize`, який повертається до `en-US`
- `utils/ordering.ts`: `nextPosition`, найбільша `position` плюс один, і `reorder`, яка переміщує елемент на вказане місце серед сусідніх, місце за будь-яким краєм списку вважає цим краєм, нумерує список від `FIRST_POSITION` і повертає лише елементи, чия `position` змінюється; сценарії використання курсів, розділів, уроків і матеріалів тримають `position` без пропусків за їхньою допомогою
- `utils/pagination.ts`: `paginationSchema` (`pageIndex`, `pageSize`) і `DEFAULT_PAGE_SIZE`
- `utils/search.ts`: `searchSchema` і `localizedSearchSchema`, вхідні дані сценаріїв використання пошуку в адміністративній панелі, їхні обмеження довжини та `SearchHit`, який вони повертають
- `utils/zod-fields.ts`: повторно використовувані поля Zod, як-от `idField`, `localeField`, `positionField` (ціле число від `FIRST_POSITION`) і `slugField`

## Помилки

Є один клас помилок і один список кодів:

```ts
export const ERROR_CODES = {
  AUTH_API_ERROR: "AUTH_API_ERROR",
  CONFLICT: "CONFLICT",
  FORBIDDEN: "FORBIDDEN",
  INTERNAL_ERROR: "INTERNAL_ERROR",
  NOT_FOUND: "NOT_FOUND",
  TOO_MANY_REQUESTS: "TOO_MANY_REQUESTS",
  UNAUTHORIZED: "UNAUTHORIZED",
  VALIDATION: "VALIDATION",
} as const

export type ErrorCode = (typeof ERROR_CODES)[keyof typeof ERROR_CODES]

export class AppError extends Error {
  readonly code: ErrorCode

  constructor(code: ErrorCode, message: string = code) {
    super(message)
    this.name = "AppError"
    this.code = code
  }
}
```

Серверні функції викидають `AppError`. Middleware `withRequest` нормалізує все інше: помилки API Better Auth стають `AUTH_API_ERROR` із ключем помилки Better Auth як повідомленням, помилки Zod стають `VALIDATION`, а невідомі помилки логуються й стають `INTERNAL_ERROR`. У браузері `useErrorMessage()` із `src/hooks/use-error-message.ts` зіставляє повідомлення з перекладами `auth.errors.*` або `errors.codes.*`.
