## Denominazione

- Moduli d'uso: `verb-noun.ts`
- Test: colocated `__test__`
- Percorso privato: `_components`, `_lib`

## Impegni

Impegni convenzionali (`feat`, `fix`, `refactor`, ...) con prefisso emoji via `scripts/commit-msg.ts`.

## PR

Piombo con tipo di interfaccia utente (`feat` quando il comportamento cambia). Osserva i refattori nel corpo.
