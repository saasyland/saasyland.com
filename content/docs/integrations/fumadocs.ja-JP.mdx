title: "Fumadocs"

---

Fumadocs は `content/docs` と `content/blog` を、ローカライズされたページツリーに変換します。`bun run content` は `fumadocs-mdx` を実行して `.source/` を書き出します。`dev`、`typegen`、すべてのビルドスクリプトは、最初にこれを実行します。

| ファイル             | 目的                                                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fumadocs.config.ts` | `docs` コレクションと、フロントマターのスキーマを持つ `blog` コレクション                                                                         |
| `fumadocs.i18n.ts`   | `I18N` の 9 つのロケール、デフォルトかつフォールバックとしての `en-US`、`<slug>.<locale>.mdx` 用の `dot` パーサー、非表示のロケールプレフィックス |
| `fumadocs.source.ts` | Lucide アイコンプラグイン付きで `/docs` に配置する `source`、`/blog` に配置する `blogSource`、読了時間付きの `getPublishedBlogPosts`              |
| `fumadocs.docs.ts`   | `docs.$` ルート用の `getDocsPage` サーバー関数、`loadDocsPage`、`docsHead`                                                                        |
| `fumadocs.search.ts` | `/api/search` から提供される検索インデックス                                                                                                      |

ロケールプレフィックスはルーターが付与するため、Fumadocs の URL では非表示になっています。ブログのフロントマターでは `title`、`authorName`、`date` が必須で、`description`、`excerpt`、`faq`、`featured`、`image`、`published`、`tags`、`updated`、`authorImage` も指定できます。

## コンポーネント

`src/presentation/components/custom/mdx.tsx` が MDX コンポーネントをマッピングします。Fumadocs のデフォルト（`Cards` と `Callout` を含む）、`Accordions`、`Steps`、`Tabs`、そして shadcn の `Alert`、`Badge`、`Button`、カードの各パーツ、`Separator`、`Table` です。内部リンクは `localizePathname` でローカライズされます。ページの描画は `docs-content.tsx` と `blog-content.tsx` が担当します。

## コンテンツのルール

すべてのページは、ロケールごとに `<slug>.<locale>.mdx` として 1 つずつ存在します。各フォルダーには `meta.<locale>.json` があり、どのロケールでも同じ `pages` 配列を持ちます。meta ファイルの `icon` には Lucide のアイコン名を指定します。`bun run check:i18n` の一部である `scripts/check-content.ts` は、翻訳の欠落、コードブロックの差異、ナビゲーションの差異、他のロケールに英語の段落が残っている場合に失敗します。
