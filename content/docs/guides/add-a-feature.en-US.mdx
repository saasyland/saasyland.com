description: "Add a feature — SaaSy Land"
---

Create or extend the owning module’s schema, validation, constants and use cases. Add a flat route under `src/routes` with its permission guard, validated search parameters, metadata and namespace preload. Place feature UI under `presentation/components/custom/{feature}` with nearby components, hooks and constants.

Preload independent data queries together in the loader, render from the same QueryClient cache, and submit through native mutation options. Add keys for all nine configured languages together. Retain the existing layout and accessible primitives, then verify the use case, component and browser behavior at the appropriate level.
