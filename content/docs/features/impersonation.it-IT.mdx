title: Impersonazione
description: Impersonazione di Admin degli utenti (Better Auth plugin di amministrazione).
---

## Stato

Esposta tramite le azioni di amministratore degli utenti / casi di utilizzo con i controlli di autorizzazione.

## Regole

- Admin-solo
- Cancella indicazione dell'interfaccia utente quando si impersona
- Preferisci la registrazione dell'audit quando indurisci le operazioni
- Non permettere mai l'escalation del privilegio oltre i flussi di lavoro di supporto previsti
