title: "Umiejętności agentów"
description: "Umiejętności dostawców dla agentów kodujących, przywracane ze skills-lock.json."
---

`skills-lock.json` przypina wersje umiejętności (skills) agentów używanych w tym repozytorium. Zainstalowane umiejętności nie są commitowane: `.agents/` i `.claude/` są ignorowane przez Git.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` usuwa `.agents/skills` i `.claude/skills`, ponownie instaluje każdą umiejętność zapisaną w pliku blokady za pomocą `bunx skills experimental_install`, przenosi każdą z nich do grupy dostawcy w `.agents/skills/<group>/<skill>/SKILL.md` i linkuje każdą grupę do `.claude/skills`. Skrypt kończy się błędem, gdy źródło umiejętności nie ma przypisanej grupy.

Każdy wpis zapisuje `commit` Git, z którego pochodzi umiejętność, oraz `computedHash` jej plików, więc `skills:sync` przywraca te same pliki na każdym komputerze. Aby przenieść każdą umiejętność na najnowszy commit jej źródła:

```sh
bun run skills:update
```

Aktualizacja przywraca przypięte umiejętności, uruchamia `bunx skills update --project --yes`, które przesuwa każdy `commit` i `computedHash` w `skills-lock.json`, a potem grupuje i linkuje umiejętności tak jak `skills:sync`. Umiejętność usunięta w źródle zachowuje swój wpis i jest zgłaszana jako usunięta; usuń ten wpis z `skills-lock.json`.

| Grupa                                                 | Źródło                                                               |
| ----------------------------------------------------- | -------------------------------------------------------------------- |
| `anthropic`                                           | `anthropics/skills`                                                  |
| `better-auth`                                         | `better-auth/skills`                                                 |
| `cloudflare`                                          | `cloudflare/skills`                                                  |
| `polar`                                               | `polarsource/skills`                                                 |
| `resend`                                              | `resend/resend-skills`                                               |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) i `TanStack/table` (`table`)   |
| `remotion`                                            | `remotion-dev/skills`                                                |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Ogólne umiejętności z zakresu inżynierii, projektowania i marketingu |

Synchronizacja zastępuje oba katalogi, więc własne umiejętności przechowuj gdzie indziej. `bun run clean:hardcore` usuwa `skills-lock.json`.

## Zasada

Zanim zmienisz kod związany z TanStack Start, Router lub Table, Better Auth, Cloudflare, Polar lub Resend, przeczytaj odpowiednią umiejętność. Umiejętności opisują aktualne API dostawców, a konwencje tego repozytorium są udokumentowane w rozdziałach [Architektura](/docs/architecture) i [Konwencje](/docs/conventions).
