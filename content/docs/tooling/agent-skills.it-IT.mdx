---
title: "Skill per agenti"
description: "Skill dei fornitori per gli agenti di programmazione, ripristinate da skills-lock.json."
---

`skills-lock.json` fissa le versioni delle skill per agenti usate con questo repository. Le skill installate non vengono versionate: `.agents/` e `.claude/` sono ignorate da Git.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` elimina `.agents/skills` e `.claude/skills`, reinstalla ogni skill bloccata con `bunx skills experimental_install`, sposta ogni skill in un gruppo per fornitore in `.agents/skills/<group>/<skill>/SKILL.md` e collega ogni gruppo in `.claude/skills`. Fallisce quando la sorgente di una skill non ha una mappatura verso un gruppo.

| Gruppo                                                | Sorgente                                                           |
| ----------------------------------------------------- | ------------------------------------------------------------------ |
| `anthropic`                                           | `anthropics/skills`                                                |
| `better-auth`                                         | `better-auth/skills`                                               |
| `cloudflare`                                          | `cloudflare/skills`                                                |
| `polar`                                               | `polarsource/skills`                                               |
| `resend`                                              | `resend/resend-skills`                                             |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) e `TanStack/table` (`table`) |
| `remotion`                                            | `remotion-dev/skills`                                              |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Skill generali di ingegneria, design e marketing                   |

La sincronizzazione sostituisce entrambe le directory, quindi conserva altrove le skill personalizzate. `bun run clean:hardcore` elimina `skills-lock.json`.

## Regola

Prima di modificare codice che riguarda TanStack Start, Router o Table, Better Auth, Cloudflare, Polar o Resend, leggi la skill corrispondente. Le skill descrivono le API attuali dei fornitori; le convenzioni di questo repository sono documentate in [Architettura](/docs/architecture) e [Convenzioni](/docs/reference/conventions).
