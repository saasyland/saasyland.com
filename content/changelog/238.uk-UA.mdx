- Виправлено: сторінка, відкрита до розгортання, більше не показує «Something went wrong», коли відвідувач натискає посилання, код якого розгортання замінило, наприклад **Blog**. TanStack Start виносить loader кожного маршруту в окремий чанк, і loader, чанка якого вже не було, ламав маршрут без перезавантаження, яке TanStack Router дає відсутньому компоненту. Типовий компонент помилки роутера тепер розпізнає чанк, який браузер не зміг імпортувати, або файл, який Vite не зміг для нього попередньо завантажити, і завантажує натиснуту сторінку як нову сторінку з нового розгортання. Він робить це один раз для кожної сторінки й збірки, тож файл, якого справді бракує, показує сторінку помилки замість безкінечного перезавантаження, а посилання, чиє попереднє завантаження під час наведення не вдалося, однаково перезавантажується після натискання.
