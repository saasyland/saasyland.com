## Schriften

Geist und Geist Mono werden als variable WOFF2-Subsets in `public/fonts` selbst gehostet und mit einem einjährigen, unveränderlichen Cache ausgeliefert (`public/_headers`). `src/presentation/styles/fonts.css` deklariert ein `@font-face` pro Unicode-Bereich (Latin, Latin Extended, Cyrillic), metrisch angepasste Fallback-Schriften sowie die Variablen `--font-geist-sans` und `--font-geist-mono`. `globals.css` ordnet sie `--font-sans`, `--font-heading` und `--font-mono` zu. Japanischer Text fällt auf den System-Font-Stack zurück.

## Preloads

`src/presentation/document-assets.ts` exportiert `DOCUMENT_STYLESHEET` (`globals.css`) und die Schrift-Preloads für eine Locale:

```ts
export const fontPreloads = (locale: SupportedLocale) => {
  const fonts = [GEIST_LATIN, GEIST_MONO_LATIN]
  if (locale === "pl-PL") {
    fonts.push(GEIST_LATIN_EXT)
  } else if (locale === "uk-UA") {
    fonts.push(GEIST_CYRILLIC)
  }
  return fonts
}
```

Die Root-Route fügt sie als `link`-Tags hinzu, und der Worker (`src/server.ts`) sendet dieselben Schriften bei jeder HTML-Antwort in einem `Link`-Preload-Header, den Cloudflare als Early Hints wiederholt. Die Dateinamen der Schriften sind Inhalts-Hashes: Wenn Sie eine Schrift ersetzen, aktualisieren Sie sowohl `fonts.css` als auch `document-assets.ts`.

## Markenkonstanten

`src/presentation/branding/index.ts` ist die einzige Quelle der Marke:

```ts title="src/presentation/branding/index.ts"
export const APP_NAME = "SaaSy Land"
export const APP_SLUG = "saasyland"
export const APP_LOGO_PATH = "M6 0H15V9H24V18A6 6 0 0 1 18 24H6A6 6 0 0 1 0 18V6A6 6 0 0 1 6 0Z"
export const APP_DOMAIN = "saasyland.com"
export const APP_PREVIEW_DOMAIN = `preview.${APP_DOMAIN}`

export const APP_URL = `https://${APP_DOMAIN}`
export const CONTACT_EMAIL = `hello@${APP_DOMAIN}`
export const NOTIFICATIONS_EMAIL = `notifications@${APP_DOMAIN}`

export const APP_FOUNDED_YEAR = 2023

export const APP_GITHUB_OWNER = "saasyland"
export const APP_GITHUB_REPO = APP_DOMAIN
export const APP_GITHUB_OWNER_URL = `https://github.com/${APP_GITHUB_OWNER}`
export const APP_GITHUB_URL = `${APP_GITHUB_OWNER_URL}/${APP_GITHUB_REPO}`

export const APP_INSTAGRAM_URL = "https://www.instagram.com/saasyland/"
```

Sie speisen den App-Namen und den 2FA-Aussteller in Better Auth, die Cookie-Namen für Theme und Locale, die erlaubten Hosts, den Footer, die Navigation der Dokumentation, die Anzahl der GitHub-Sterne, die strukturierten Daten der Startseite und der Blogbeiträge sowie Absender und Empfänger der E-Mails. `APP_GITHUB_OWNER_URL` und `APP_INSTAGRAM_URL` sind die Profile der Organisation auf anderen Websites: Der Footer verlinkt das Instagram-Profil neben dem Repository, und die strukturierten Daten führen beide in `sameAs` auf; siehe [Suche und Social-Media-Vorschauen](/docs/features/seo#structured-data).

## Logo und Medien

- `Wordmark` (`src/presentation/components/custom/wordmark.tsx`) rendert das Logo, `APP_LOGO_PATH`, als Inline-SVG neben `APP_NAME`. Die Social Cards zeichnen denselben Pfad mit denselben Schriften; siehe [Suche und Social-Media-Vorschauen](/docs/features/seo). `HomeLink` (`home-link.tsx`) macht es in den Headern der Landingpage, des Blogs und der Kurse zum Link auf die Startseite; siehe [Landingpage](/docs/features/landing-page).
- Das Favicon ist `public/favicon.ico`; Blogbilder liegen in `public/images/blog`.
- Die Videos der Landingpage liegen in `src/presentation/assets/motion` als WebM-Dateien mit WebP-Postern. Ein Poster muss die Abmessungen seines Videos beibehalten. Die Tour durch die Kursseiten, die auf Anforderung mit Bedienelementen abgespielt wird, hat zusätzlich einen MP4-Fallback und AVIF-Poster.
