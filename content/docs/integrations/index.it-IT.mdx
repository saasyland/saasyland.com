---
title: "Introduzione"
description: "Adattatori dei fornitori in src/integrations."
---

Ogni cartella in `src/integrations/<vendor>/` incapsula un fornitore in file `<vendor>.<concern>.ts`: configurazione, client e adattatori leggeri. Le regole di business e le operazioni sul database restano in `src/modules`, e i componenti non importano mai direttamente il client di un fornitore.

| Cartella        | File                                                                                                            | Scopo                                                                       |
| --------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `better-auth`   | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.session.ts` | Sessioni, OAuth, guard delle route, middleware delle funzioni server, ruoli |
| `drizzle-orm`   | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `migrations/`                                 | Client D1, barrel degli schemi, configurazione di drizzle-kit               |
| `fumadocs`      | `fumadocs.config.ts`, `fumadocs.i18n.ts`, `fumadocs.source.ts`, `fumadocs.docs.ts`, `fumadocs.search.ts`        | Collezioni di documentazione e blog, sorgenti localizzate, ricerca          |
| `motion`        | `motion.features.ts`, `motion.tokens.ts`                                                                        | Funzionalità di Motion caricate in modo lazy e transizioni condivise        |
| `polar`         | `polar.config.ts`, `polar.constants.ts`                                                                         | Client dell'SDK Polar e prodotti del checkout                               |
| `resend`        | `resend.config.ts`, `resend.utils.ts`                                                                           | Client Resend e `sendEmail`                                                 |
| `tanstack-form` | `form.fields.ts`                                                                                                | `fieldErrorMessage` per gli errori dei campi dei form                       |
| `use-intl`      | `i18n.config.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                    | Locale, namespace dei messaggi, middleware del locale, helper per gli URL   |
