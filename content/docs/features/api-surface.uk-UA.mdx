Застосунок надає три HTTP-маршрути, оголошені через `server.handlers` у `createFileRoute` в `src/routes/api`:

| Маршрут       | Методи    | Обробник                                                                                                                                                     |
| ------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `/api`        | GET       | Повертає `{ "runtime": "cloudflare-workers" }`.                                                                                                              |
| `/api/auth/$` | GET, POST | Better Auth: вхід, повернення OAuth, `/api/auth/verify-email`, а також кінцеві точки плагіна Polar `/api/auth/polar/webhooks` і `/api/auth/customer/portal`. |
| `/api/search` | GET       | Пошук Fumadocs (`fumadocs.search.ts`).                                                                                                                       |

```ts
import { createFileRoute } from "@tanstack/react-router"

import { auth } from "~/src/integrations/better-auth/auth.server"

export const Route = createFileRoute("/api/auth/$")({
  server: { handlers: { GET: ({ request }) => auth.handler(request), POST: ({ request }) => auth.handler(request) } },
})
```

## Серверні функції замість REST

Операції застосунку — це функції `createServerFn` у `src/modules/<table>/use-cases` (або в єдиному маршруті, який їх використовує). TanStack Start викликає їх через RPC під `/_serverFn` з middleware для сесій, дозволів і обмеження частоти запитів. Не додавайте REST-ендпоінт для операції, яку викликає лише цей застосунок; HTTP-маршрут додавайте тільки для зовнішніх викликачів, як-от вебхуки, і перевіряйте їхні підписи в інтеграції провайдера.

## Поведінка

- Worker не застосовує мовні перенаправлення до `/api` і `/_serverFn`; ці запити беруть мову з cookie.
- Збирання не рендерить `/api` заздалегідь.
- Тести обробників розташовані в `src/routes/api/__test__/handlers.test.ts`.
