---

- **Ruta:** una ruta nativa de TanStack que utiliza un componente, una protección, un cargador o un manejador HTTP.
- **Función del servidor:** una operación RPC con tipo, creada con `createServerFn`.
- **Query:** datos de lectura en caché con una clave estable, compartidos entre el loader y React.
- **Mutación:** una operación enviada a través de TanStack Query y respaldada por una función del servidor.
- **Espacio de nombres:** un archivo de traducción con una estructura de puntos, ubicado dentro de un directorio de localización.
- **Vinculación:** un recurso de Cloudflare proporcionado al Worker como `env.DB`, `env.CACHE` o `env.ASSETS`.
- **Prerender:** HTML generado en tiempo de compilación para una ruta pública.
