## Корінь контенту

`content/docs`

- MDX сторінки: `*.{locale}.mdx` для всіх дев'яти налаштованих мов (dot parser)
- Склад `meta.<locale>.json` заголовки / замовити / кремнію
- `fallbackLanguage: en-US` для відсутніх перекладів

## Електропроводка

`fumadocs.source.ts`, docs макет, пошук API. Додавання сторінок → оновлення мета `pages` масиви → rebuild.
