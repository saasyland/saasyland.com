- Corregido: registrarte con una dirección de correo que ya tiene una cuenta ya no te deja esperando un correo que nunca llega. Ahora recibes «Ya tienes una cuenta en SaaSy Land», con las formas en que puedes iniciar sesión, un enlace para iniciar sesión y otro para restablecer la contraseña. La pantalla tras el registro es la misma para cualquier dirección, así que nunca revela quién tiene una cuenta. Consulta [Autenticación](/docs/features/authentication#signing-up-with-a-known-address).
- Cambiado: iniciar sesión en una cuenta cuyo correo aún no está verificado envía un nuevo enlace de verificación, y la página lo indica.
- Nuevo: después de restablecer la contraseña, un correo te avisa de que se ha cambiado, con una forma de restablecerla de nuevo y escribirnos si no has sido tú.
- Cambiado: los correos de la cuenta muestran SaaSy Land arriba, repiten el enlace como texto bajo el botón e indican cuánto tiempo funciona.
- Cambiado: `bun run dev` usa su propia base de datos, espacio de nombres KV y buckets R2 locales en lugar de los de preview. `bun run db:seed:local` llena la base de datos local con un administrador, el plan de cursos, licencias y un pedido, `bun run db:studio:local` la abre en Drizzle Studio, y `bun run admin:grant:preview` y `bun run admin:grant:production` convierten una cuenta verificada en el primer administrador de un sitio desplegado. Consulta [Base de datos](/docs/tooling/database).
- Eliminados: los scripts `db:migrate:development`, `db:migrations:development`, `db:studio:development` y `db:introspect:development`, que trabajaban sobre la base de datos de preview.
- Nuevo: hooks de Git que reinstalan las dependencias cuando `bun.lock` cambia tras un pull, un rebase o un cambio de rama.
