- Added: `bun run skills:update` moves every agent skill in `skills-lock.json` to the latest commit of its source, and `bun run skills:sync` now restores each skill at the commit the lock records, so every machine gets the same files. See [Agent skills](/docs/tooling/agent-skills).
- Added: four Cloudflare agent skills, `workers-profiling`, `workers-development`, `frameworks-on-cloudflare` and `cf-cli`, for profiling deployed Workers, debugging them locally, running TanStack Start on Workers and using the `cf` CLI.
- Changed: every agent skill is on its latest upstream version, among them the Polar and Resend skills, and the lock no longer lists the 33 skills that their sources have removed, such as the TanStack Table v9 skills now folded into `table-features` and `table-state`.
- Fixed: `bun run skills:sync` no longer stops with `EEXIST` when the skills CLI has already linked a skill into `.claude/skills` under the name of a vendor group, such as `cloudflare`.
