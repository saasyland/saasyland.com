- Fixed: the options that are coming in a later release in the landing page's command builder are no longer faded out, and a dashed border marks them instead.
- Fixed: the admin's curriculum editor gives each lesson's title its own line and its tags and buttons a row of their own, the course form shows every language tab, the admin breadcrumb keeps its parent pages whole, and long file paths in the docs wrap on phones. See [Courses](/docs/features/courses).
