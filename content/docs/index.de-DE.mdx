Willkommen zur Dokumentation von **SaaSy Land 2.0**, einem modularen, Full-Stack-SaaS-Starter-Kit, basierend auf TanStack Start.

<Callout title={"Wie man diese Dokumentation verwendet."}>
  Bevorzugen Sie **Guides** für Anleitungen und Aufgabenbeschreibungen und **Architecture** für Bereiche, in denen Code gespeichert ist.
  **Features** und **Integrations** beschreiben die Produktfunktionalität und die Anbindung an Drittanbieter – einschließlich geplanter
  Bereiche wie Zahlungsabwicklung.
</Callout>

## Lokale Bearbeitung.

Inhaltdateien: `content/docs`.

MDX kann Fumadocs-Komponenten (`<Cards>`, `<Callout>`, `<Steps>`, `<Tabs>`, `<Accordions>`) und ausgewählte Shadcn-Elemente (`<Button>`, `<Badge>`, `<Alert>`, `<Table>`, …) verwenden.

Nachdem Sie Seiten hinzugefügt haben, aktualisieren Sie das `meta.<locale>.json` Array `pages` (das Scaffolding-Skript erledigt dies für Sie). Seiten im Ordner `index` sind **Ordnerindizes** – listen Sie `index` nicht erneut in `pages` auf.
