title: Autenticación
description: Configuración de Better Auth, credenciales y OAuth.
---

## Propiedad.

`integrations/better-auth` — `auth.server.ts`, `auth.client.ts`, validaciones, errores, protecciones.

## Capacidades.

- Correo electrónico / contraseña
- GitHub + Google OAuth
- Cookies de sesión a través de Better Auth.
- Protección reforzada por proxy para `/admin` y `/app`.

## Extender.

Añadir proveedores de redes sociales en la configuración del servidor de autenticación; mantener las claves en las variables de entorno; actualizar la documentación y el archivo `.env.example`.
