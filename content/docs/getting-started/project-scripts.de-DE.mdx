---
title: "Projektskripte"
description: "Die Befehle, die Sie täglich verwenden."
---

| Aufgabe                                               | Befehl                   |
| ----------------------------------------------------- | ------------------------ |
| Dev-Server starten                                    | `bun run dev`            |
| Formatierung, Linting, Typen und Übersetzungen prüfen | `bun run check`          |
| Alle Vitest-Projekte ausführen                        | `bun run test`           |
| Prüfung der Testabdeckung ausführen                   | `bun run test:coverage`  |
| Browser-Smoke-Test ausführen                          | `bun run test:e2e:smoke` |
| Migration erzeugen                                    | `bun run db:generate`    |
| Preview-Worker bauen                                  | `bun run build`          |
| Letzten Build ausliefern                              | `bun run start`          |
| Preview deployen                                      | `bun run deploy:preview` |

Führen Sie vor dem Öffnen eines Pull Requests dieselbe Abfolge wie die CI aus:

```sh
bun run check
bun run test:coverage
bun run test:e2e:smoke
```

Verwenden Sie `bun run test`, nicht `bun test`, damit Vitest mit dem Projekt-Setup läuft. Skripte, die auf einen Umgebungsnamen enden, etwa `db:migrate:preview` oder `deploy:production`, wirken nur auf diese Umgebung.

Die vollständige Liste finden Sie unter [Projektskripte](/docs/tooling/scripts).
