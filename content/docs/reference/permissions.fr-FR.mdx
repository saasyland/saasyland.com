`src/integrations/better-auth/auth.access.ts` définit les déclarations de permissions dans `APP_STATEMENTS`, les accorde aux rôles et construit à partir d'elles le contrôle d'accès de Better Auth (voir [Rôles et permissions](/docs/guides/roles-and-permissions)). Les mêmes définitions sont utilisées par le serveur (`authorized`, guards de route) et par le client Better Auth.

## Rôles

| Rôle           | Code       | Permissions                                                                                                                         |
| -------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Administrateur | `admin`    | Toutes les déclarations de l'application ci-dessous, plus les déclarations d'administration de Better Auth pour `user` et `session` |
| Client         | `customer` | Aucune. Les clients peuvent appeler les fonctions serveur qui n'exigent qu'une session.                                             |

Les nouveaux utilisateurs reçoivent le rôle `customer` (`DEFAULT_ROLE_CODE` dans `auth.roles.ts`).

Hors des cas d'usage, `requireAdmin` sur le layout `/admin` et la redirection après la connexion vérifient `admin: ["access"]` avec `hasPermission`, et `resolveViewer` (`lesson.viewer.ts`) permet aux détenteurs de `course: ["read"]` de regarder chaque leçon et de télécharger ses ressources, quel que soit son niveau d'accès.

## Vérifier une permission

Les fonctions serveur utilisent le middleware, par exemple `authorized({ category: ["read"] })`. Le reste du code appelle `hasPermission`, comme le font les guards de route :

```ts
const isAdmin = (role: string | null | undefined): boolean => hasPermission({ permission: { admin: ["access"] }, role })

export const requireAdmin = async (context: ProtectedRouteContext) => {
  const result = await requireSignedIn(context)
  if (!isAdmin(result.session.user.role)) {
    throw redirect({ replace: true, to: ROUTES.APP })
  }
  return result
}
```
