---
title: "Introducción"
description: "Adaptadores de proveedores en src/integrations."
---

Cada carpeta de `src/integrations/<vendor>/` encapsula un proveedor en archivos `<vendor>.<concern>.ts`: configuración, clientes y adaptadores ligeros. Las reglas de negocio y las operaciones de base de datos permanecen en `src/modules`, y los componentes nunca importan directamente un cliente de un proveedor.

| Carpeta         | Archivos                                                                                                        | Propósito                                                                         |
| --------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `better-auth`   | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.session.ts` | Sesiones, OAuth, guardas de ruta, middleware de funciones de servidor, roles      |
| `drizzle-orm`   | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `migrations/`                                 | Cliente de D1, barrel de esquemas, configuración de drizzle-kit                   |
| `fumadocs`      | `fumadocs.config.ts`, `fumadocs.i18n.ts`, `fumadocs.source.ts`, `fumadocs.docs.ts`, `fumadocs.search.ts`        | Colecciones de documentación y blog, fuentes localizadas, búsqueda                |
| `motion`        | `motion.features.ts`, `motion.tokens.ts`                                                                        | Funcionalidades de Motion cargadas de forma diferida y transiciones compartidas   |
| `polar`         | `polar.config.ts`, `polar.constants.ts`                                                                         | Cliente del SDK de Polar y productos de checkout                                  |
| `resend`        | `resend.config.ts`, `resend.utils.ts`                                                                           | Cliente de Resend y `sendEmail`                                                   |
| `tanstack-form` | `form.fields.ts`                                                                                                | `fieldErrorMessage` para los errores de los campos de formulario                  |
| `use-intl`      | `i18n.config.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                    | Idiomas, espacios de nombres de mensajes, middleware de idioma, utilidades de URL |
