---
title: "Fumadocs"
description: "MDX collections for the docs and blog, localized sources and search."
---

Fumadocs turns `content/docs` and `content/blog` into localized page trees. `bun run content` runs `fumadocs-mdx` and writes `.source/`; `dev`, `typegen` and every build script run it first.

| File                 | Purpose                                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `fumadocs.config.ts` | The `docs` collection and the `blog` collection with its frontmatter schema                                                     |
| `fumadocs.i18n.ts`   | The nine locales from `I18N`, `en-US` as default and fallback, the `dot` parser for `<slug>.<locale>.mdx`, hidden locale prefix |
| `fumadocs.source.ts` | `source` at `/docs` with the Lucide icons plugin, `blogSource` at `/blog`, `getPublishedBlogPosts` with reading time            |
| `fumadocs.docs.ts`   | `getDocsPage` server function, `loadDocsPage` and `docsHead` for the `docs.$` route                                             |
| `fumadocs.search.ts` | The search index served by `/api/search`                                                                                        |

The locale prefix is hidden in Fumadocs URLs because the router adds it. Blog frontmatter requires `title`, `authorName` and `date` and accepts `description`, `excerpt`, `faq`, `featured`, `image`, `published`, `tags`, `updated` and `authorImage`.

## Components

`src/presentation/components/custom/mdx.tsx` maps the MDX components: the Fumadocs defaults (including `Cards` and `Callout`), `Accordions`, `Steps` and `Tabs`, and the shadcn `Alert`, `Badge`, `Button`, card parts, `Separator` and `Table`. Internal links are localized with `localizePathname`. `docs-content.tsx` and `blog-content.tsx` render the pages.

## Content rules

Every page exists once per locale as `<slug>.<locale>.mdx`, and each folder has a `meta.<locale>.json` with the same `pages` array in every locale. `icon` in a meta file takes a Lucide icon name. `scripts/check-content.ts`, part of `bun run check:i18n`, fails when a translation is missing, a code block differs, the navigation differs or an English paragraph remains in another locale.
