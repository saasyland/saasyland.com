- **Itinéraire:** une route de fichier TanStack native avec un composant, un garde, un chargeur ou un gestionnaire HTTP.
- **Fonction serveur & #160;:** une opération RPC dactylographiée créée avec `createServerFn`.
- **Demande :** cached read data avec une clé stable, partagée entre le chargeur et React.
- **Mutation:** une opération soumise par TanStack Query et soutenue par une fonction serveur.
- **Espace de noms :** un fichier de traduction pointillé dans un répertoire local.
- **Reliure :** une ressource Cloudflare fournie au travailleur comme `env.DB`, `env.CACHE` ou `env.ASSETS`.
- **Avant-dernière échéance :** build-time HTML pour un itinéraire public.
