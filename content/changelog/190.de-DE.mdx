- Jede Seite führt nur die Skripte aus, mit denen sie ausgeliefert wurde, unter einer Content Security Policy, die der Strict CSP von Google folgt. Eine Seite, die der Worker rendert, erhält mit jeder Antwort eine neue Nonce in ihrem Header, und `src/server.ts` übergibt sie an TanStack Start, das sie auf die Skripte des Routers, von React und des Themes setzt. Eine vorgerenderte Seite ist für alle dieselbe Datei und kann keine Nonce tragen, deshalb hasht `scripts/secure-prerendered-html.ts` beim Build ihre Inline-Skripte, lädt das Entry-Modul aus einem gehashten Inline-Loader, der den Entry-Hinweis mit niedriger Priorität beibehält, und schreibt die Richtlinie in ein Meta-Tag. `'strict-dynamic'` erlaubt diesen Skripten, Routen-Chunks und das Empfehlungspixel von Affonso zu laden. `base-uri` ist jetzt `'none'`, zod parst, ohne zu prüfen, ob `eval` verfügbar ist, und jede Browser-Spec schlägt fehl, wenn eine Seite einen Verstoß meldet.
