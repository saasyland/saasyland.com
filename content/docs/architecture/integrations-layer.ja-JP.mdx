title: "インテグレーションの責務"
description: "src/integrations 配下のベンダーフォルダー、それぞれが設定する内容、そこに含めないもの。"
---

セットアップが必要なサードパーティのライブラリやサービスは、それぞれ `src/integrations` 配下に 1 つのフォルダーを持ちます。ファイル名は `<prefix>.<concern>.ts` の形式で、プレフィックスにはベンダーの短縮名を使います。

| フォルダー       | ファイル                                                                                                                                                                                   | 責務                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `affonso`        | `affonso.constants`、`affonso.program`、`affonso.referral`                                                                                                                                 | 紹介パラメーター、ピクセルの URL、プログラム ID、チェックアウトのメタデータとして Polar に渡す紹介情報                            |
| `better-auth`    | `auth.server`、`auth.client`、`auth.access`、`auth.roles`、`auth.middleware`、`auth.routes`、`auth.session`、`auth.errors`、`auth.hooks`、`auth.zod`、`auth.constraints`、`auth.constants` | 認証の設定、ロール、サーバー関数のミドルウェア、ルートガード、セッションクエリ、プロバイダー ID                                   |
| `drizzle-orm`    | `drizzle.config`、`drizzle.database`、`drizzle.schemas`、`drizzle.errors`、`drizzle.columns`、`migrations/`                                                                                | D1 クライアント、スキーマのレジストリ、SQL マイグレーション、一意制約エラー用の `rethrowAsConflict`、共通の `timestamps()` カラム |
| `fumadocs`       | `fumadocs.config`、`fumadocs.source`、`fumadocs.docs`、`fumadocs.search`、`fumadocs.i18n`                                                                                                  | ドキュメントとブログの MDX コレクション、ページの読み込み、検索                                                                   |
| `motion`         | `motion.features`、`motion.tokens`                                                                                                                                                         | 遅延読み込みされる Motion の機能バンドルと、共有のトランジション                                                                  |
| `polar`          | `polar.config`、`polar.constants`、`polar.discounts`                                                                                                                                       | Polar SDK クライアント、SDK と照合した Polar 固有の値、チェックアウトと `polar:verify` が共有する地域割引のルール                 |
| `resend`         | `resend.config`、`resend.utils`、`resend.constants`                                                                                                                                        | Resend クライアント、`sendEmail`、`EMAIL_PURPOSE` の名前                                                                          |
| `tanstack-form`  | `form.fields`                                                                                                                                                                              | TanStack Form 用のフィールド型と `fieldErrorMessage`                                                                              |
| `tanstack-query` | `query.cache`                                                                                                                                                                              | `src/router.tsx` がリクエストごとに作成する `QueryClient` のデフォルトのキャッシュ時間                                            |
| `use-intl`       | `i18n.config`、`i18n.messages`、`i18n.middleware`、`i18n.paths`、`i18n.utils`                                                                                                              | ロケール、メッセージの読み込み、ロケール付きの URL、クッキー                                                                      |

## インテグレーションではないもの

- GitHub のスター数は、`src/lib/github.ts` のサーバー関数で取得し、KV にキャッシュします。
- レート制限は `src/lib/rate-limit.ts` が担い、`rate_limit` テーブルに保存します。
- Cloudflare のバインディングにアダプターは不要です。サーバーコードは `cloudflare:workers` の `env` からバインディングを読み取ります。

## ビジネスロジックはモジュールに置く

インテグレーションは、ベンダーを設定するためのものです。アプリケーションのデータに関する判断は、そのテーブルを所有するモジュールが担います。

- Polar のエリアが `src/data/polar.auth-plugins.ts` で Better Auth に追加する Polar プラグインは、`POLAR_WEBHOOK_SECRET` で Webhook の署名を検証し、各イベントを `src/data/polar-events.ts` の `handlePolarEvent` に渡します。`handlePolarEvent` は、そのイベントを自分の `<area>.polar-events.ts` に列挙しているすべてのエリアに渡します。ライセンスのエリアの `src/data/license.polar-events.ts` は `src/modules/license/license.webhooks.ts` の `licenseWebhookHandlers` を呼び出し、このハンドラーがライセンスのユースケースを呼び出します。ライセンスのプランの商品 ID である `POLAR_PRODUCT_IDS` もライセンスのエリアに属し、`src/modules/license/license.utils.ts` にあります。
- Better Auth のメールフックは、verification モジュールと account モジュールの `sendVerifyEmail`、`sendResetPasswordEmail`、`sendChangeEmailConfirmationEmail` を呼び出します。これらは Resend が `src/data/resend.auth-emails.ts` で追加します。
- ユースケースは、呼び出し元から渡されたロケールでメールを送信します（確認メールはコールバック URL からロケールを読み取ります）。テンプレートの名前空間を読み込み、テンプレートをレンダリングしてから `sendEmail` を呼び出します。

```ts
const messages = await loadNamespace<typeof verifyEmailMessages>({ locale, namespace: VERIFY_EMAIL_NAMESPACE })
await sendEmail({
  idempotency: { purpose: EMAIL_PURPOSE.VERIFY_EMAIL, token },
  react: createElement(VerifyEmail, { locale, messages, name: user.name, verifyUrl: verifyUrl.toString() }),
  subject: createTranslator({ locale, messages })("subject"),
  to: user.email,
})
```
