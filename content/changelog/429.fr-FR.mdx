- Modifié : la page d'accueil ne bloque plus le fil principal d'un téléphone juste après son chargement : avec le preset mobile de Lighthouse, son Total Blocking Time est passé de 2 458 ms à 41 ms. L'en-tête précharge le code de la documentation sur chaque page, et la documentation affichait les termes polonais que la vérification du glossaire laisse au lecteur à partir de `glossary-terms.ts`, qui compile au chargement un motif pour chaque terme du glossaire. Le plugin `repositoryFacts` construit désormais ces termes et les tableaux des glossaires au moment du build, et les tableaux que seule la documentation affiche viennent de leur propre module, `virtual:repository-tables`, au lieu du script d'entrée de chaque page, plus léger de 26,0 Kio avec gzip. `scripts/verify-build.ts` fait échouer le build si le script d'entrée les atteint de nouveau.
