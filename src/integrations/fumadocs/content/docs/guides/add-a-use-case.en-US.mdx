---
title: "Add a use-case"
description: "Create a permissioned server action in a module."
---

## Steps

1. Add `modules/<domain>/use-cases/<verb>-<noun>.use-case.ts`
2. Build mutations with `actionClient.use(withAuth({ resource: ["action"] }))`; reads are plain guarded functions
3. Validate input with module Zod schemas
4. Call auth/DB; throw `AppError` for expected failures
5. Add `__test__` covering happy path + forbidden
6. Export and call from the page/action UI

## Naming

`get-users.use-case.ts`, `ban-user.use-case.ts` — verb-first, kebab-case.
