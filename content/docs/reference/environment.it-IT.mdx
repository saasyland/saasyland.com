## File di ambiente

| File               | Versionato | Usato da                                                                                      |
| ------------------ | ---------- | --------------------------------------------------------------------------------------------- |
| `.env.example`     | Sì         | Elenca ogni secret con un valore vuoto                                                        |
| `.env.development` | No         | `bun run dev`, `db:studio:development`, `db:introspect:development`                           |
| `.env.preview`     | No         | `deploy:preview` (i secret dichiarati), `db:studio:preview`, `db:introspect:preview`          |
| `.env.production`  | No         | `deploy:production` (i secret dichiarati), `db:studio:production`, `db:introspect:production` |
| `.env.test`        | Sì         | Vitest e l'ambiente Wrangler `test`; solo valori fittizi                                      |

## Variabili

| Variabile                   | Usata da                                                                                                              |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `AUTH_SECRET`               | Firma, cifratura e token di verifica email di Better Auth                                                             |
| `AUTH_GITHUB_CLIENT_ID`     | OAuth GitHub; autentica anche la richiesta del numero di stelle GitHub                                                |
| `AUTH_GITHUB_CLIENT_SECRET` | OAuth GitHub; autentica anche la richiesta del numero di stelle GitHub                                                |
| `AUTH_GOOGLE_CLIENT_ID`     | OAuth Google                                                                                                          |
| `AUTH_GOOGLE_CLIENT_SECRET` | OAuth Google                                                                                                          |
| `RESEND_API_KEY`            | Il client Resend                                                                                                      |
| `RESEND_EMAIL_FROM`         | Il mittente predefinito di `sendEmail`                                                                                |
| `POLAR_ACCESS_TOKEN`        | Il client dell'SDK di Polar                                                                                           |
| `POLAR_SERVER`              | `sandbox` o `production`                                                                                              |
| `POLAR_WEBHOOK_SECRET`      | La verifica della firma dei webhook di Polar                                                                          |
| `POLAR_ORGANIZATION_ID`     | La disattivazione delle chiavi di licenza Polar e la ricerca degli sconti                                             |
| `POLAR_PRODUCT_ID_CORE`     | Il prodotto di checkout per il piano Core                                                                             |
| `POLAR_PRODUCT_ID_COMPLETE` | Il prodotto di checkout per il piano Complete                                                                         |
| `POLAR_PRODUCT_ID_AGENCY`   | Il prodotto di checkout per il piano Agency                                                                           |
| `CLOUDFLARE_ACCOUNT_ID`     | Il driver HTTP D1 di Drizzle Kit                                                                                      |
| `CLOUDFLARE_DATABASE_ID`    | Il driver HTTP D1 di Drizzle Kit                                                                                      |
| `CLOUDFLARE_ACCESS_TOKEN`   | Il driver HTTP D1 di Drizzle Kit                                                                                      |
| `AFFONSO_PROGRAM_ID`        | L'ID pubblico facoltativo del programma Affonso, che attiva il tracciamento dei referral degli affiliati              |
| `FFMPEG`, `FFPROBE`         | Binari FFmpeg e ffprobe facoltativi per `scripts/publish-video.ts`; per impostazione predefinita `ffmpeg` e `ffprobe` |

Ogni ambiente in `wrangler.jsonc` elenca i secret di cui ha bisogno in `secrets.required`; l'ambiente `test` omette le tre variabili Cloudflare. `AFFONSO_PROGRAM_ID` non è un secret: compare nel tag script della pagina, quindi è una variabile del Worker sotto `vars`, da impostare solo per l'ambiente che riceve pagamenti reali. Per ora solo `test` ne imposta uno, un ID fittizio per i test nel browser ([Programma di affiliazione](/docs/features/affiliates)). `FFMPEG` e `FFPROBE` sono variabili di shell facoltative per `scripts/publish-video.ts`, non secret del Worker. Il codice del Worker le legge da `env` in `cloudflare:workers`, tipizzate da `src/types/bindings.d.ts`. Non esistono variabili `VITE_`: l'URL pubblico e il dominio sono costanti in `src/presentation/branding`.

## Binding

| Binding  | Tipo          | `development`                | `preview` | `production` | `test`                  |
| -------- | ------------- | ---------------------------- | --------- | ------------ | ----------------------- |
| `DB`     | D1            | Database di preview, remoto  | Preview   | Produzione   | `saasyland_test` locale |
| `CACHE`  | KV            | Namespace di preview, remoto | Preview   | Produzione   | Locale                  |
| `MEDIA`  | R2            | Bucket di preview, remoto    | Preview   | Produzione   | `saasyland-test` locale |
| `ASSETS` | Asset statici | Sì                           | Sì        | Sì           | Sì                      |

Gli script di deploy di preview e di produzione eseguono prima `scripts/verify-bindings.ts`, che fallisce finché a un ambiente manca un binding o restano ID D1 o KV segnaposto, e quando la produzione condivide una risorsa con la preview. I bucket R2 sono collegati per nome (`saasyland-preview` per sviluppo e preview, `saasyland` per la produzione) e devono esistere prima di un deploy.
