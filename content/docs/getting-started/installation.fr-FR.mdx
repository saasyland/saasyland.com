title: "Installation"

---

Clonez le dépôt, puis lancez l'installation depuis sa racine avec le lockfile versionné :

```sh
bun install --frozen-lockfile
```

Le script de cycle de vie `prepare` effectue ensuite les opérations suivantes :

1. Il exécute `vp config --no-agent`, qui installe le répartiteur de hooks Git pour `.vite-hooks/` (vérifications de pre-commit et hook de message de commit).
2. Il exécute `bun run generate:cn`, qui construit les tables de fusion des classes dans `.source/cn-tables.ts`.
3. Il exécute `bun run content`, qui génère les collections Fumadocs dans `.source/`.

Si vous installez avec `--ignore-scripts`, comme le fait la CI, exécutez ensuite `bun run typegen`. Cette commande régénère aussi `src/types/worker-configuration.d.ts` à partir de `wrangler.jsonc`.

## Compléments facultatifs

```sh
bun run test:e2e:install
bun run skills:sync
```

La première commande installe Chromium et WebKit pour Playwright ; la seconde restaure les [skills pour agents](/docs/tooling/agent-skills).
