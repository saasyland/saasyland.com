| ------------- | -------------------------------------------- | ------------------------ |
| `/privacy`    | `src/routes/_site._marketing.privacy.tsx`    | `pages.legal.privacy`    |
| `/terms`      | `src/routes/_site._marketing.terms.tsx`      | `pages.legal.terms`      |
| `/refunds`    | `src/routes/_site._marketing.refunds.tsx`    | `pages.legal.refunds`    |
| `/licence`    | `src/routes/_site._marketing.licence.tsx`    | `pages.legal.licence`    |
| `/affiliates` | `src/routes/_site._marketing.affiliates.tsx` | `pages.legal.affiliates` |

各ルートファイルは独自のページコンポーネント、静的な `NAMESPACE`、表示順にセクションキーを並べたモジュール定数を定義します。

```tsx
const SECTIONS = ["operator", "accounts", "purchases", "payments", "licence", "conduct", "refunds", "responsibility", "law"] as const
```

ページは `ContentPage` で `title` と `description` を表示し、続いて `lastUpdated`、各キーの `sections.<key>.title` と `sections.<key>.body` を表示します。法務ページ共通のコンポーネントはありません。プライバシーポリシーとアフィリエイト規約は `AFFILIATE_TERMS`（`src/data/affiliates.ts`）の値をメッセージに渡すため、報酬率、Cookie の有効期間、保留期間、最低支払額を文言に直接書くことはありません。どちらも `AFFILIATE_PROGRAM` を `{program}` として渡すため、プログラムが提供予定のあいだ、プライバシーポリシーは Affonso が何も受け取らず、そのスクリプトも読み込まれないと述べます。また、プライバシーポリシーは `SIDEBAR_COOKIE.DAYS`（`src/data/sidebar.ts`）を `{sidebarDays}` として渡し、サイドバーが設定する `sidebar_state` Cookie の有効期間を表示します。アフィリエイト規約は本文を `t.rich` でレンダリングするため、「参加方法」セクションから `AFFILIATE_PORTAL_URL` のパートナーポータルにリンクできます。返金ポリシーと利用規約は `REFUND_TERMS.WITHDRAWAL_DAYS`（`src/data/refunds.ts`）を `{days}` としてメッセージに渡します。これは `refundEligibility` が数える期間と同じです。また、本文を `t.rich` でレンダリングするため、撤回についてのセクションから `/withdrawal` の撤回機能にリンクできます。

## 編集

- 文言はすべての言語の `messages/<locale>/pages.legal.<doc>.json` で変更し、`bun run check:i18n` を実行します。
- セクションを追加するには、`SECTIONS` にキーを追加し、各言語にメッセージを追加します。
- フッターのリンクは、`navigation.legal.json` でラベルが付く、`src/data/legal.navigation.ts` の `LEGAL_NAVIGATION` のフッター項目で、「法的情報」の列と、「プロダクト」の列に置くアフィリエイト規約です。法的情報エリアは、登録フォームの下に置く同意の一文を、スケルトンとともに `custom/sign-up-consent.tsx` の `SignUpConsent` として、`src/data/legal.sign-up-notices.ts` で `SIGN_UP_NOTICES` に追加します。そのため、法的ページのないプロジェクトの登録フォームには、それらへのリンクがありません。`LegalPending`（`custom/legal-pending.tsx`）は 5 つのページすべてのスケルトンで、`src/data/legal.skeletons.ts` で宣言されています。

ライセンスページは、公開リポジトリの MIT ライセンスと別途提供される有料素材を区別し、返金またはチャージバックがあった購入のライセンスを、そのライセンスで生成したアプリケーションに関する権利も含めて終了させます。返金ポリシーは、初回利用（CLI でのプロジェクト生成、または有料レッスンの閲覧）の前であれば <RepositoryFact name="refundWithdrawalDays" unit="day" />以内の全額返金を認めます。ライセンスには最初のテンプレートのダウンロードと最初に開いた有料レッスンが記録されます（[ライセンス](/docs/features/licences#records-and-refunds)を参照）。また、デジタルコンテンツの撤回権がいつ消滅するかを説明し、消費者の強行法規上の権利を維持します。アフィリエイト規約は各報酬を <RepositoryFact name="affiliateHoldDays" unit="day" />保留し、支払い後に返金またはチャージバックされた注文の報酬を差し引きます。返金ポリシーの「オンラインでの撤回」セクションと利用規約は、撤回機能がどこにあるか、その受領確認がメールで届くことを説明します。これは消費者権利指令の第 6 条第 1 項 (h) が求める情報です。プライバシーポリシーは、撤回の意思表示で保存される内容と保存期間を記載します。撤回ページ自体とフッターのリンクはライセンスのエリアに属します。[ライセンス](/docs/features/licences#withdrawal-function)を参照してください。各文書を、実際の運営者、購入手続き、提供事業者、データの取り扱いに合わせてください。
