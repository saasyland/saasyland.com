Définir un schéma de recherche de route avec `validateSearch`, lisez avec `Route.useSearch`, et le mettre à jour via TanStack Router navigation. Gardez les filtres bookmarkables, les onglets, le tri et la pagination dans l'URL le cas échéant. L'état du composant reste dans React.

Les réécritures d'URL locales s'appliquent aux liens routeurs natifs. Utilisation `localizePathname` pour les URL construites manuellement, y compris les callbacks OAuth et les liens de courriel. Ne prépendez pas une locale vers des liens externes ou des chemins API. Préservez la requête et le fragment lors du changement de langage.
