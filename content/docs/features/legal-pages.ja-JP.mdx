| ---------- | --------------------------------- | --------------------- |
| `/privacy` | `src/routes/_landing.privacy.tsx` | `pages.legal.privacy` |
| `/terms`   | `src/routes/_landing.terms.tsx`   | `pages.legal.terms`   |
| `/refunds` | `src/routes/_landing.refunds.tsx` | `pages.legal.refunds` |
| `/licence` | `src/routes/_landing.licence.tsx` | `pages.legal.licence` |

各ルートファイルは独自のページコンポーネント、静的な `NAMESPACE`、表示順にセクションキーを並べたモジュール定数を定義します。

```tsx
const SECTIONS = ["operator", "accounts", "purchases", "payments", "licence", "conduct", "refunds", "responsibility", "law"] as const
```

ページは `lastUpdated`、`title`、`description` を表示し、続いて各キーの `sections.<key>.title` と `sections.<key>.body` を表示します。法務ページ共通のコンポーネントはありません。

## 編集

- 文言は 9 言語すべての `messages/<locale>/pages.legal.<doc>.json` で変更し、`bun run check:i18n` を実行します。
- セクションを追加するには、`SECTIONS` にキーを追加し、各言語にメッセージを追加します。
- フッターのリンクは `src/presentation/components/custom/footer.tsx` の定数 `LEGAL_LINKS` です。登録ページは利用規約とプライバシーポリシーへリンクします。
