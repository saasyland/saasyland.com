description: Колокація суфіксів і конвенцій папок.

| Візерунок      | Зручності                                            |
| -------------- | ---------------------------------------------------- |
| `_components/` | Маршрут-локал React компоненти                       |
| `_lib/`        | Маршрут-локальні помічники, пошук-парами, картоппери |
| `_types/`      | Маршрутні види                                       |
| `use-cases/`   | Послуги з експлуатації модуля                        |
| `*.server.ts`  | Статус на сервери                                    |
| `__test__/`    | Змішані тести                                        |

Письмові імена преференцій`search-params.ts`) над язиком `utils.ts` пельмені.
