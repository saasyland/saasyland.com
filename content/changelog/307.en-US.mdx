- Changed: the admin command palette opens with ⌘K or Ctrl+K in a wider dialog whose list scrolls inside it, so no result is cut off. It groups recent items, quick actions such as **New course**, every admin page and, from two letters, a search of users by name or email, orders by ID or customer, and courses and lessons by title in any language, run on the server with your role's permissions. Each row has its icon and a line of detail, a footer names the keys (↑ ↓ to move, ↵ to open, esc to close), and screen readers hear when it searches and how many results it found. See [Admin dashboard](/docs/features/admin-dashboard#command-palette).
- Changed: the admin sidebar collapses to its icons, each named in a tooltip, and marks the page you are on with an accent bar. See [Admin dashboard](/docs/features/admin-dashboard#admin-shell).
- Changed: each counter on the admin dashboard shows its icon and opens the page that lists what it counts, sits two to a row on a phone, and the **Orders** and **Customers** buttons above them are quieter outline buttons. See [Admin dashboard](/docs/features/admin-dashboard#dashboard).
- Changed: every admin page opens with the same header: its title, a short description, its actions on the right, a link back to the parent page where there is one, and its tabs underneath on Products, Users and Settings, separated from the content by a rule, with a loading placeholder of the same shape. See [Admin dashboard](/docs/features/admin-dashboard#admin-shell).
