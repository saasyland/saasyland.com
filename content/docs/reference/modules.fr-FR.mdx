---
title: Catalogue des modules
description: Inventaire des domaines de src/modules et propriété.
---

| Module         | Possède                                                     |
| -------------- | ----------------------------------------------------------- |
| `_core`        | Erreurs, catalogues local/monnaie/timezone, outils partagés |
| `account`      | Profil / courriel / mot de passe / signature                |
| `user`         | Gestion de l'utilisateur Admin + aide à l'image             |
| `session`      | Lister / révoquer les séances                               |
| `two-factor`   | TOTP active / vérifie / désactive                           |
| `verification` | Email vérifier + mot de passe réinitialiser orchestration   |
| `product`      | Cas d'utilisation du catalogue de produits                  |
| `category`     | Cas d'utilisation par catégorie                             |

Ajoutez une ligne lorsque vous introduisez un nouveau dossier de domaine.
