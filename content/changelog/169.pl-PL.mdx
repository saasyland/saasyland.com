- Kod pozostaje kodem w każdym języku. Lista „Sprawdź każdą deklarację” na stronie głównej bierze przytaczane pliki i polecenia, takie jak `coverage/coverage-summary.json` i `bun run test:coverage`, z `REPOSITORY_FACTS` jako argumenty ICU, więc strony w języku niemieckim, francuskim, włoskim, japońskim i brazylijskim portugalskim nie pokazują już przetłumaczonych ścieżek ani polecenia, które nie istnieje; ścieżka podsumowania pochodzi z `vite.config.ts`, a katalog specyfikacji z `playwright.config.ts`. `check-message-formats.ts` kończy się teraz błędem, gdy tłumaczenie zmienia ścieżkę pliku lub polecenie z angielskiego komunikatu albo dodaje grawisy Markdown, a `check-content.ts`, gdy przetłumaczona strona pomija lub dodaje kod w linii, komponent, prop komponentu inny niż tytuł albo link do innej strony lub ma inną liczbę wierszy tabel. Nowe sprawdzenia znalazły polską i brazylijsko-portugalską stronę o handlerach HTTP bez wiersza API licencji CLI oraz kilka zmienionych fragmentów kodu; wszystko jest poprawione. Niemiecka polityka prywatności wymienia, tak jak pozostałe języki, tokeny potwierdzenia i rezygnacji z newslettera, a demonstracyjne ceny, oszczędność i przychód na `/admin/pricing-models` są liczbami w walucie sklepu, `DEFAULT_CURRENCY_CODE`, sformatowanymi dla języka strony, zamiast kwot wpisanych ręcznie w dolarach, euro, złotych lub realach. Zobacz [Tłumaczenia i treści](/docs/conventions/translations).
