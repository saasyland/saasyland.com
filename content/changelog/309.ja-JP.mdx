- 追加：`bun run skills:update` は `skills-lock.json` のすべてのエージェントスキルを取得元の最新コミットに更新し、`bun run skills:sync` はロックファイルに記録されたコミットで各スキルを復元するようになったため、どのマシンでも同じファイルが入ります。[エージェントスキル](/docs/tooling/agent-skills)を参照してください。
- 追加：Cloudflare のエージェントスキル `workers-profiling`、`workers-development`、`frameworks-on-cloudflare`、`cf-cli` の 4 つを追加しました。デプロイ済み Workers のプロファイリング、ローカルでのデバッグ、Workers 上の TanStack Start、`cf` CLI の利用に使います。
- 変更：Polar と Resend のスキルを含むすべてのエージェントスキルを上流の最新版にしました。ロックファイルからは、取得元で削除された 33 個のスキルを外しました。たとえば TanStack Table v9 のスキルは `table-features` と `table-state` に統合されています。
- 修正：スキル CLI が `cloudflare` などのベンダーグループと同じ名前でスキルを `.claude/skills` にリンク済みの場合でも、`bun run skills:sync` が `EEXIST` で止まらなくなりました。
