SaaSy Land — це вихідний код вебсайту saasyland.com, робочого простору клієнтів і адміністративної консолі: один застосунок TanStack Start на Cloudflare Workers із D1, KV, Better Auth, Polar, Resend, use-intl і Fumadocs. SaaSy Land CLI та шаблони його генератора зберігаються в окремому приватному репозиторії.

<Callout title="Як користуватися документацією">
  Почніть із розділу **Початок роботи**, щоб запустити застосунок. **Архітектура** пояснює, де розміщено код, **Посібники** містять рецепти
  для типових завдань, **Можливості** описують поведінку продукту, а **Інтеграції** документують кожен адаптер постачальника в
  `src/integrations`.
</Callout>

## Редагування документації

Сторінки зберігаються в `content/docs` як `<slug>.<locale>.mdx`, по одному файлу для кожної з дев'яти локалей, а кожна папка перелічує свої сторінки в `meta.<locale>.json`. Усі локалі містять однаковий набір slug-ів, а блоки коду в них ідентичні до байта; це забезпечує `bun run check:i18n` через `scripts/check-content.ts`. `bun run content` перегенеровує `.source/`, а `dev` і кожен скрипт збірки запускають його автоматично.

Сторінки MDX можуть використовувати компоненти Fumadocs (`<Cards>`, `<Callout>`, `<Steps>`, `<Tabs>`, `<Accordions>`) і вибрані примітиви shadcn (`<Button>`, `<Badge>`, `<Alert>`, `<Table>`). Внутрішні посилання на кшталт `/docs/tooling/testing` автоматично отримують префікс локалі читача.
