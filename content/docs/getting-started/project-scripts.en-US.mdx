| Task                                       | Command                  |
| ------------------------------------------ | ------------------------ |
| Start the dev server                       | `bun run dev`            |
| Check format, lint, types and translations | `bun run check`          |
| Run all Vitest projects                    | `bun run test`           |
| Run the coverage gate                      | `bun run test:coverage`  |
| Run the browser smoke test                 | `bun run test:e2e:smoke` |
| Run the Chromium browser suite CI runs     | `bun run test:e2e:pr`    |
| Generate a migration                       | `bun run db:generate`    |
| Build the preview Worker                   | `bun run build`          |
| Serve the latest build                     | `bun run start`          |
| Deploy the preview                         | `bun run deploy:preview` |

Before opening a pull request, run the same sequence as CI:

```sh
bun run check
bun run test:coverage
bun run test:e2e:pr
```

Locally, Playwright migrates and seeds the test database, builds the test Worker and starts it, unless a server is already running on port 3000.

Use `bun run test`, not `bun test`, so Vitest runs with the project setup. Scripts that end in an environment name, such as `db:migrate:preview` or `deploy:production`, act on that environment only.

See [Project scripts](/docs/tooling/scripts) for the complete list.
