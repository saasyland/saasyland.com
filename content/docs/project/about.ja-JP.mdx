SaaSy Land 2.0 は、saasyland.com の Web サイト、その顧客ワークスペース、管理コンソールのソースコードです。Cloudflare Workers 上の 1 つの TanStack Start アプリケーションが、多言語のマーケティングサイト、ドキュメントとブログ、認証、ニュースレターの購読、動画ストリーミングとコース、ライセンスキー管理を伴う Polar のチェックアウトをまとめて提供します。

コードは実際のプロダクトとして書かれています。データベースのテーブルごとのモジュール、独自の認可を持つ型付きのサーバー関数、ページごとに 1 つの翻訳名前空間、<RepositoryFact name="coverageThreshold" unit="percent" /> のコードカバレッジ、ユーザーと管理者のフローを CI で検証するブラウザーテストを備えています。認証、管理画面、国際化、Cloudflare まわりの本番環境の構成を学びたい、あるいは再利用したい開発者に向けたものです。

ユーザー、セッション、商品、カテゴリー、動画、コース、レッスンの進捗、ニュースレターの購読者、ライセンス、Polar の注文とサブスクリプションのコピーは D1 のデータを使い、動画ファイルは R2 に保存されています。管理画面はすべてこれらを読み取ります。管理画面にデモ画面はなく、lint ルールが管理画面のコードからデモデータを締め出します。

SaaSy Land CLI とその非公開のジェネレーターテンプレートは、別のプロプライエタリな製品であり、このコードベースには含まれていません。[ライセンス](/docs/project/license)を参照してください。
