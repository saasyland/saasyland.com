title: "Маршрути"
description: "Кожна сторінка та шлях API, їхня константа ROUTES, файл маршруту й guard-функція."
---

Кожен шлях має константу в `ROUTES` (`src/routes.ts`). Посилання використовують константу, наприклад `<Link to={ROUTES.SIGN_IN}>`, а роутер додає префікс локалі. Кожна сторінка нижче також доступна з префіксом будь-якої нетипової локалі, наприклад `/pl-PL/terms`.

## Публічні сторінки

Ці сторінки використовують макет `_landing` (навігація та футер), крім блогу й документації, які мають власні макети. Усі вони проходять пререндеринг, крім сторінок розсилки.

| Шлях                      | Константа                | Файл маршруту                         |
| ------------------------- | ------------------------ | ------------------------------------- |
| `/`                       | `HOME`                   | `_landing.index.tsx`                  |
| `/premium`                | `PREMIUM`                | `_landing.premium.tsx`                |
| `/licence`                | `LICENCE`                | `_landing.licence.tsx`                |
| `/privacy`                | `PRIVACY`                | `_landing.privacy.tsx`                |
| `/terms`                  | `TERMS`                  | `_landing.terms.tsx`                  |
| `/refunds`                | `REFUNDS`                | `_landing.refunds.tsx`                |
| `/newsletter/confirm`     | `NEWSLETTER_CONFIRM`     | `_landing.newsletter.confirm.tsx`     |
| `/newsletter/unsubscribe` | `NEWSLETTER_UNSUBSCRIBE` | `_landing.newsletter.unsubscribe.tsx` |
| `/blog`                   | `BLOG`                   | `blog.tsx`, `blog.index.tsx`          |
| `/blog/*`                 | немає                    | `blog.$.tsx`                          |
| `/docs`                   | `DOCS`                   | `docs.tsx`, `docs.index.tsx`          |
| `/docs/*`                 | немає                    | `docs.$.tsx`                          |

## Автентифікація

Макет `/auth` (`auth.tsx`) не має guard-функції; їх мають окремі сторінки.

| Шлях                    | Константа         | Файл маршруту              | Guard-функція                                             |
| ----------------------- | ----------------- | -------------------------- | --------------------------------------------------------- |
| `/auth/sign-in`         | `SIGN_IN`         | `auth.sign-in.tsx`         | `redirectIfSignedIn`                                      |
| `/auth/sign-up`         | `SIGN_UP`         | `auth.sign-up.tsx`         | `redirectIfSignedIn`                                      |
| `/auth/forgot-password` | `FORGOT_PASSWORD` | `auth.forgot-password.tsx` | немає                                                     |
| `/auth/reset-password`  | `RESET_PASSWORD`  | `auth.reset-password.tsx`  | немає                                                     |
| `/auth/two-factor`      | `TWO_FACTOR`      | `auth.two-factor.tsx`      | немає                                                     |
| `/auth/verify-email`    | `VERIFY_EMAIL`    | `auth.verify-email.tsx`    | Перенаправляє `token` на ендпоінт верифікації Better Auth |
| `/auth/callback`        | `AUTH_CALLBACK`   | `auth.callback.tsx`        | `redirectAfterAuth`                                       |

## API

Шляхи API ніколи не локалізуються.

| Шлях          | Константа       | Файл маршруту   |
| ------------- | --------------- | --------------- |
| `/api`        | `API`           | `api/index.ts`  |
| `/api/auth/*` | `API_AUTH_BASE` | `api/auth.$.ts` |
| `/api/search` | немає           | `api/search.ts` |

`ROUTES.API_AUTH` перелічує шляхи ендпоінтів Better Auth відносно `/api/auth`; `auth.server.ts` використовує їх, щоб звільнити ендпоінти від обмеження частоти запитів. `API_AUTH_CUSTOMER_PORTAL` і `API_AUTH_VERIFY_EMAIL` — це повні шляхи до ендпоінтів Better Auth. `AUTH` і `NEWSLETTER` не мають власної сторінки; разом з `ADMIN`, `APP` і `API` вони позначають розділи, які ніколи не проходять пререндеринг.
