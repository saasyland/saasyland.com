---
title: "Organisations"
description: "Non implémenté : il n’y a ni organisations, ni équipes, ni cloisonnement par locataire."
---

L’application n’a pas de modèle d’organisations, d’équipes ou d’adhésions :

- Le plugin d’organisations de Better Auth n’est pas installé.
- Aucun module ni aucune table ne stocke d’organisations ou d’adhésions.
- Les requêtes se limitent à l’utilisateur connecté ou sont protégées par des permissions d’administration.
- Les rôles sont globaux : `admin` et `customer` dans `auth.access.ts`.

Les champs d’espace de travail de **Paramètres → Général** sont des champs de démo statiques, pas une organisation.

Pour ajouter des organisations, partez du plugin Better Auth ; la skill d’agent `organization-best-practices` dans `.agents/skills/better-auth` le décrit. Les nouvelles tables appartiennent à leur propre module sous `src/modules`.
