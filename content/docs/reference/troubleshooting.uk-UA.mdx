## База даних

**`no such table` у `bun run dev`.** Середовище `development` використовує віддалену базу даних D1 середовища preview. Застосуйте там міграції командою `bun run db:migrate:development`. Для локальної бази даних розробки використовуйте `bun run db:migrate:local`.

**`no such table` у Playwright.** Браузерні тести використовують власну локальну базу даних. Виконайте `bun run db:migrate:test` і `bun run db:seed:test` або дайте Playwright самому запустити застосунок: він виконає обидві команди.

**Таблиці у Vitest застаріли.** Мок D1 під час запуску застосовує кожен SQL-файл із `src/integrations/drizzle-orm/migrations`. Після зміни схеми згенеруйте міграцію командою `bun run db:generate`.

## Сервер розробки

**Сервер розробки не запускається.** Він використовує порт 3000 зі `strictPort`, тож завершується помилкою, коли порт зайнятий. Зупиніть інший процес.

**Не працює вхід або OAuth.** Перевірте `AUTH_SECRET` та облікові дані OAuth-клієнта у файлі середовища, а також те, що URL зворотного виклику провайдера вказує на `/api/auth/callback/<provider>` на хості, який ви використовуєте. Better Auth приймає лише хости, налаштовані для режиму збірки: локально це `localhost:3000` і `127.0.0.1:3000`.

**У типах Worker бракує прив'язки або секрету.** Після зміни `wrangler.jsonc` запустіть `bun run cf-typegen` і додайте змінну в `src/types/bindings.d.ts`.

**Власні класи `text-*` зникають після об'єднання.** `cn` залежить від таблиць, згенерованих із `src/lib/cn.config.ts`. `bun run dev`, `bun run check` і збірки генерують їх заново; якщо `.source/cn-tables.ts` відсутній, запустіть `bun run generate:cn`.

## Переклади

**`No messages/<locale>/<namespace>.json`.** Маршрут оголошує простір імен, для якого в цій локалі немає файлу. Створіть файл у кожній локалі.

**Ключ відображається як його шлях, або `check:i18n` повідомляє про відсутній ключ.** Ключа немає в одній із локалей, або компонент читає його поза областю свого виклику `useTranslations`. Використовуйте один `useTranslations` на компонент і запустіть `bun run check:i18n`.

## Документація

**Сторінка документації повертає 404.** Файл має називатися `<page>.<locale>.mdx` і бути вказаним у `pages` файлу `meta.<locale>.json` відповідної папки. Запустіть `bun run content`, щоб заново згенерувати `.source`.

**`check-content.ts` завершується помилкою.** Скрипт порівнює кожну локаль з en-US. `Changed code examples` означає, що блок коду відрізняється від англійського; блоки коду мають бути ідентичними. `Untranslated English paragraph` означає, що абзац скопійовано без перекладу. `Missing <file>` означає, що файлу локалі не існує.

## Тести й розгортання

**`test:coverage` не проходить.** Покриття рядків, інструкцій, функцій і гілок має становити 100%. Звіт у `coverage/` показує непокриті рядки.

**Розгортання зупиняється на `verify-bindings.ts`.** Цільове середовище у `wrangler.jsonc` досі має заглушкові ідентифікатори D1 або KV. Створіть ресурси в Cloudflare і замініть ідентифікатори.

**Збірка з пререндерингом завершується помилкою.** Вивід збірки називає першу URL-адресу, на якій стався збій. Відкрийте цю сторінку через `bun run dev`, щоб побачити помилку.
