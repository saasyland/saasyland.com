Ejecute los scripts desde la raíz del repositorio con `bun run <script>`.

## Desarrollo y compilación

| Script              | Ejecuta                                                                                                                                |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `dev`               | `generate:cn`, `content` y `vp dev` en el entorno `development` en http://localhost:3000                                               |
| `build`             | Lo mismo que `build:preview`                                                                                                           |
| `build:preview`     | Limpia `dist`, `generate:cn`, `content`, `vp build` para `preview`, `scripts/verify-build.ts` y `scripts/optimize-prerendered-html.ts` |
| `build:production`  | Los mismos pasos para `production`                                                                                                     |
| `build:test`        | Los mismos pasos para el entorno `test`                                                                                                |
| `start`             | `vp preview` de la última compilación en http://127.0.0.1:3000                                                                         |
| `start:test`        | `vp preview` de la compilación de pruebas                                                                                              |
| `deploy:preview`    | `scripts/verify-bindings.ts preview`, `build:preview` y `wrangler deploy --secrets-file .env.preview`                                  |
| `deploy:production` | `scripts/verify-bindings.ts production`, `build:production` y `wrangler deploy --secrets-file .env.production`                         |

`verify-build.ts` comprueba la configuración de despliegue, el idioma del documento, los enlaces canónicos y alternativos de la página de inicio y de las páginas legales localizadas, las fuentes, que las páginas protegidas y los alias de idioma no se hayan prerenderizado y que ningún recurso del cliente importe `cloudflare:workers`. `optimize-prerendered-html.ts` elimina de las páginas prerenderizadas las indicaciones `modulepreload` de las dependencias y mantiene la indicación del punto de entrada con prioridad baja.

## Comprobaciones

| Script             | Ejecuta                                                                                  |
| ------------------ | ---------------------------------------------------------------------------------------- |
| `check`            | `generate:cn`, `check:i18n` y `vp check` (formato, lint y tipos)                         |
| `check:fix`        | Lo mismo con `vp check --fix`                                                            |
| `check:i18n`       | `scripts/check-i18n.ts`, `scripts/check-message-formats.ts` y `scripts/check-content.ts` |
| `check:pre-commit` | `generate:cn`, `check:i18n` y `vp staged`; lo ejecuta el hook de pre-commit              |
| `lint`             | `vp lint`                                                                                |
| `format`           | `vp fmt`                                                                                 |
| `format:check`     | `vp fmt --check`                                                                         |

## Generación y mantenimiento

| Script           | Ejecuta                                                                                                    |
| ---------------- | ---------------------------------------------------------------------------------------------------------- |
| `content`        | `fumadocs-mdx`: genera `.source/` a partir de `content/`                                                   |
| `generate:cn`    | Genera las tablas de fusión de clases en `.source/cn-tables.ts` a partir de `src/lib/cn.config.ts`         |
| `cf-typegen`     | `wrangler types` para `development`: regenera `src/types/worker-configuration.d.ts`                        |
| `typegen`        | `cf-typegen`, `generate:cn` y `content`                                                                    |
| `skills:sync`    | `scripts/sync-skills.ts`: restaura las skills para agentes a partir de `skills-lock.json`                  |
| `clean`          | Elimina `.source`, `.tanstack`, `.wrangler`, `dist`, `coverage`, la salida de Playwright y `*.tsbuildinfo` |
| `clean:deep`     | `clean` y `node_modules`                                                                                   |
| `clean:hardcore` | `clean:deep`, `bun.lock` y `skills-lock.json`                                                              |
| `prepare`        | Se ejecuta durante la instalación: `vp config --no-agent` (hooks de Git), `generate:cn` y `content`        |

`clean` elimina `.wrangler`, incluidas las bases de datos locales de desarrollo y de pruebas, así que exporte antes los datos locales que quiera conservar.
