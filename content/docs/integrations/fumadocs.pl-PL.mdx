title: "Fumadocs"
description: "Kolekcje MDX dla dokumentacji i bloga, zlokalizowane źródła i wyszukiwanie."
---

Fumadocs zamienia `content/docs` i `content/blog` w zlokalizowane drzewa stron. `bun run content` uruchamia `fumadocs-mdx` i zapisuje `.source/`; `dev`, `typegen` i każdy skrypt budowania uruchamiają go jako pierwszy krok.

| Plik                 | Przeznaczenie                                                                                                                    |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `fumadocs.config.ts` | Kolekcja `docs`, kolekcja `blog` z własnym schematem frontmattera oraz motywy i zamienniki kolorów podświetlania kodu            |
| `fumadocs.i18n.ts`   | Dziewięć języków z `I18N`, `en-US` jako język domyślny i zapasowy, parser `dot` dla `<slug>.<locale>.mdx`, ukryty prefiks języka |
| `fumadocs.source.ts` | `source` pod `/docs` z pluginem ikon Lucide, `blogSource` pod `/blog`, `getPublishedBlogPosts` z czasem czytania                 |
| `fumadocs.docs.ts`   | Funkcja serwerowa `getDocsPage`, `loadDocsPage` i `docsHead` dla trasy `docs.$`                                                  |
| `fumadocs.search.ts` | Indeks wyszukiwania udostępniany przez `/api/search`                                                                             |

Prefiks języka jest ukryty w URL-ach Fumadocs, ponieważ dodaje go router. Frontmatter bloga wymaga pól `title`, `authorName` i `date` oraz akceptuje `description`, `excerpt`, `faq`, `featured`, `image`, `published`, `tags`, `updated` i `authorImage`.

## Komponenty

`src/presentation/components/custom/mdx.tsx` mapuje komponenty MDX: domyślne komponenty Fumadocs (w tym `Cards` i `Callout`), `Accordions`, `Steps` i `Tabs` oraz komponenty shadcn `Alert`, `Badge`, `Button`, części karty, `Separator` i `Table`, a także `RepositoryCount`, który renderuje liczbę zmierzoną w repozytorium podczas budowania, np. `<RepositoryFact name="testFiles" />`. `TierPrice` wyświetla cenę katalogową planu z `TIER_PRICES` w języku strony, np. `<TierPrice tier="core" />`, więc żaden wpis nie wpisuje ceny ręcznie. Linki wewnętrzne są lokalizowane za pomocą `localizePathname`, a element listy zadań obejmuje swoje pole wyboru i tekst elementem `label`. Strony renderują `docs-content.tsx` i `blog-content.tsx`.

`@fumadocs/base-ui` jest przypięty do wersji 16.19.0 z patchem Bun: jego `CodeBlock` nadawał obszarowi przewijania każdego bloku kodu rolę `region` bez nazwy, więc strona z dwoma blokami kodu miała zduplikowane nienazwane punkty orientacyjne. Z patchem obszar przewijania jest regionem nazwanym tytułem bloku, jeśli blok go ma, a w przeciwnym razie pozostaje elementem bez roli, który może otrzymać fokus. Zobacz [Zależności](/docs/conventions/dependencies).

## Zasady treści

Każda strona istnieje raz dla każdego języka jako `<slug>.<locale>.mdx`, a każdy folder ma plik `meta.<locale>.json` z tą samą tablicą `pages` we wszystkich językach. Pole `icon` w pliku meta przyjmuje nazwę ikony Lucide. `scripts/check-content.ts`, będący częścią `bun run check:i18n`, zgłasza błąd, gdy brakuje tłumaczenia, blok kodu lub nawigacja się różni albo w innym języku pozostał angielski akapit.
