---
title: Catalogo dei moduli
description: Inventario di domini e proprietà src/modules.
---

| Modulo         | Ows                                                       |
| -------------- | --------------------------------------------------------- |
| `_core`        | Errori, cataloghi locali/valuta/timezone, utils condivisi |
| `account`      | Profilo / email / password / sign-out                     |
| `user`         | Admin gestione utente + helper di impersonazione          |
| `session`      | Elenco / sessioni di revoca                               |
| `two-factor`   | TOTP abilita / verifica / disabilita                      |
| `verification` | Verifica e-mail + password reset orchestration            |
| `product`      | Libreria per uso catalogo prodotto                        |
| `category`     | Casi di utilizzo della categoria                          |

Aggiungere una riga quando si introduce una nuova cartella di dominio.
