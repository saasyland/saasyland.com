title: "Réinitialisation du mot de passe"
description: "Parcours de mot de passe oublié et de réinitialisation reposant sur Better Auth."
---

## Demander un lien

`/auth/forgot-password` affiche `ForgotPasswordForm`. Il appelle `requestPasswordReset` (`src/modules/verification/use-cases/request-password-reset.ts`, limitée par `RATE_LIMITS.SENSITIVE`) avec `redirectTo` pointant vers `/auth/reset-password` dans la langue courante. Better Auth appelle ensuite `sendResetPasswordEmail`, qui envoie le modèle `ResetPasswordEmail`.

## Définir un nouveau mot de passe

Le lien reçu par e-mail ouvre `/auth/reset-password?token=…`. Sans jeton, ou avec `?error=`, la page affiche le message de lien invalide et un lien de retour vers `/auth/forgot-password`. Avec un jeton, `ResetPasswordForm` appelle `resetPassword` (limitée par `RATE_LIMITS.TOKEN`) puis navigue vers `/auth/sign-in`. Comme `revokeSessionsOnPasswordReset` est activé, toutes les sessions existantes de cet utilisateur prennent fin.

## Autres changements de mot de passe

- Les utilisateurs connectés changent leur mot de passe dans **Paramètres → Sécurité** ([Paramètres](/docs/features/settings)).
- Les administrateurs définissent le mot de passe d’un autre utilisateur depuis le tableau des utilisateurs ([Utilisateurs (admin)](/docs/features/users-admin)).
