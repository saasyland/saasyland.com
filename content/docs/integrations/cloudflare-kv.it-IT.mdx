Ogni ambiente collega un namespace KV come `CACHE`. Contiene una voce.

## Conteggio delle stelle GitHub

Il conteggio delle stelle mostrato sul sito, implementato in `src/lib/github.ts`:

- `getStarCount` legge la voce `github:<owner>/<repo>:stars`.
- Se la voce non esiste, recupera il repository dall'API di GitHub con un timeout di <RepositoryFact name="starCountFetchTimeoutSeconds" unit="second" />, restituisce il conteggio e scrive `count` e `fetchedAt` in KV con `waitUntil`.
- Quando la voce ha più di <RepositoryFact name="starCountRefreshHours" unit="hour" /> (`STAR_COUNT_REFRESH_AFTER_MS`), restituisce il conteggio in cache e lo aggiorna in background.
- `starCountQuery` mantiene il risultato nella cache delle query per lo stesso tempo: `STAR_COUNT_REFRESH_AFTER_MS` è anche il suo `staleTime` e il suo `gcTime`.

Le voci non hanno una scadenza KV; è `fetchedAt` a decidere quando aggiornarle. La richiesta a GitHub si autentica con le credenziali dell'app OAuth di GitHub `AUTH_GITHUB_CLIENT_ID` e `AUTH_GITHUB_CLIENT_SECRET`.

## Coerenza e test

KV è eventualmente consistente. Le sessioni, i rate limit e tutto ciò che serve per l'autorizzazione si trovano in D1.

In Vitest, `cloudflare:workers` si risolve in `src/platform/testing/mocks/cloudflare.ts`, che fornisce una `CACHE` in memoria. L'ambiente Wrangler `test` usa un namespace locale in `.wrangler/test`.
