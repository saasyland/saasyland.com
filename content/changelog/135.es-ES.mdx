- Versiones: cuando un despliegue a producción termina con éxito, CI etiqueta el commit desplegado como `vYYYY.MM.DD` con la fecha UTC (`.2`, `.3` y así sucesivamente para los despliegues posteriores de ese día) y publica una GitHub Release cuyas notas son la sección de ese día de este registro de cambios. Los despliegues a preview no se etiquetan. Consulte [Versiones y etiquetas](/docs/tooling/ci-cd#releases-and-tags).
