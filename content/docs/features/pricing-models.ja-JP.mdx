プランの価格は、以下のとおりコードと Polar で設定します。管理画面に価格の画面はありません。管理画面からの商品と価格の管理は[ロードマップ](/docs/project/roadmap)にあります。

## 価格の出どころ

- **ランディングページ**: `src/data/marketing.ts` の `TIER_PRICES`。`core` <TierPrice tier="core" />、`complete` <TierPrice tier="complete" />、`agency` <TierPrice tier="agency" /> で、`Price` がページの言語で書式設定します。ランディングページの説明文は Core の価格を `{price}` として受け取り、ブログ記事とドキュメントのページは `<TierPrice tier="core" />` でプランの価格を表示するため、価格を手入力する文章はありません。コンサルティングカードの時間単価は同じファイルの `CONSULTING_HOURLY_RATE` です。通話はメールで予約するもので Polar では販売しないため、地域別価格はありません。
- **購入**: `POLAR_PRODUCT_ID_CORE`、`POLAR_PRODUCT_ID_COMPLETE`、`POLAR_PRODUCT_ID_AGENCY` が参照する Polar の商品。地域価格やアップグレードの価格は、チェックアウト独自の価格として渡されます（[ライセンス](/docs/features/licences#starting-the-checkout)を参照）。
- **地域価格**: `src/modules/license/license.pricing.ts` の `PPP_TIERS`。国のグループごとの価格の倍率です。`regionalPrice` はプランの価格に倍率を掛けてドル未満を切り捨て、その価格をプランのカードにもチェックアウトにも同じように使います。倍率は次のとおりです。

`bun run polar:verify:<environment>` は Polar の商品価格を `TIER_PRICES` と比較し、デプロイスクリプトは手動デプロイのたびに事前にこれを実行します。地域価格のために Polar で設定するものはありません。コードを先に変更し、その後で Polar を変更してください。[Polar の設定](/docs/getting-started/polar-setup)を参照してください。

## 通貨と価格

- **ストアの通貨**: `src/data/pricing.ts` の `DEFAULT_CURRENCY_CODE`。別の通貨で課金するには、ここを変更します。ほかの場所では定義されていません。`currency.ts` ではなく価格の定数と並べて置いているのは、ランディングページが `CURRENCIES` カタログを読み込まずに済むようにするためです。
- **変わるもの**: `CURRENCY_FORMAT` と、それに伴うランディングページのすべての価格、プランのカード、ブログの `<TierPrice>`、コンサルティングの時間単価。新しい商品のデフォルトの `currency`（`product.schema.ts`、`createProduct`）。管理ダッシュボードは、ストアの通貨に関係なく、各注文が支払われた通貨で売上を表示します。価格は `Intl.NumberFormat` によって通貨の最小単位に丸められます。`Intl.NumberFormat` は ISO 4217 の各通貨の小数桁数を把握しています。地域別価格は `regionalPrice` が切り捨てるため、もともと整数の単位になっています。
- **変わらないもの**: Polar は Polar の商品価格の通貨で課金するため、商品も同じ通貨と `TIER_PRICES` の金額に設定してください。価格を管理画面から管理して Polar から読み取るようになるまでは、`TIER_PRICES` が Polar の価格をそのまま写します。アフィリエイトへの支払いは、Affonso が支払いに使う米ドル、つまり `AFFILIATE_TERMS.PAYOUT_CURRENCY` のままです。
