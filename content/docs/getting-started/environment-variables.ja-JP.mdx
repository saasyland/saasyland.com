作業する環境用にテンプレートをコピーします。`.env.development`、`.env.preview`、`.env.production` は Git の管理対象外です。`.env.test` は、テストと隔離されたプレビュー用のダミー値とともにコミットされています。

```sh
cp .env.example .env.development
openssl rand -base64 48
```

生成された値を `AUTH_SECRET` に使います。デプロイする環境ごとに別のシークレットを使ってください。

| 変数                                                                            | 目的                                                                                                                 |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `AUTH_SECRET`                                                                   | Better Auth の署名と暗号化に使うシークレット                                                                         |
| `AUTH_GITHUB_CLIENT_ID`, `AUTH_GITHUB_CLIENT_SECRET`                            | GitHub OAuth アプリ。GitHub のスター数を取得するリクエストの認証にも使います                                         |
| `AUTH_GOOGLE_CLIENT_ID`, `AUTH_GOOGLE_CLIENT_SECRET`                            | Google OAuth アプリ                                                                                                  |
| `RESEND_API_KEY`, `RESEND_EMAIL_FROM`                                           | Resend の API キーとデフォルトの送信元アドレス                                                                       |
| `POLAR_SERVER`                                                                  | 開発では `sandbox`、実際の決済では `production`                                                                      |
| `POLAR_ACCESS_TOKEN`, `POLAR_ORGANIZATION_ID`                                   | Polar API へのアクセスと、割引およびライセンスキーに使う組織                                                         |
| `POLAR_WEBHOOK_SECRET`                                                          | `/api/auth/polar/webhooks` で Polar の Webhook を検証します                                                          |
| `POLAR_PRODUCT_ID_CORE`, `POLAR_PRODUCT_ID_COMPLETE`, `POLAR_PRODUCT_ID_AGENCY` | 3 つのチェックアウトプランに対応する Polar の商品                                                                    |
| `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_DATABASE_ID`, `CLOUDFLARE_ACCESS_TOKEN`    | Drizzle Studio とイントロスペクション用の D1 HTTP API へのアクセス。アプリケーションは `DB` バインディングを使います |

`wrangler.jsonc` の `development`、`preview`、`production` の各環境では、上記のすべてのキーが必須です。サーバーのコードは `import { env } from "cloudflare:workers"` でこれらを読み込みます。Vite は `VITE_` プレフィックスの付いた値をブラウザーに公開するため、どのキーにもこのプレフィックスは付いていません。

## コード内の値

一部の設定は環境変数ではなく、コードで定義されています。

- `src/presentation/branding/index.ts`: アプリケーション名、`APP_DOMAIN`（正規 URL は `https://` にこのドメインを付けたもの）、連絡先アドレス、GitHub リポジトリ。
- `src/modules/_core/constants/api.ts`: Better Auth がモードごとに受け付けるホスト（`appHostsForMode`）。
- `wrangler.jsonc`: Worker 名、カスタムドメイン、D1 と KV の ID。

## プロバイダーのコールバック

- GitHub と Google: `https://<host>/api/auth/callback/github` と `https://<host>/api/auth/callback/google`。
- Polar の Webhook: `https://<host>/api/auth/polar/webhooks`。`POLAR_WEBHOOK_SECRET` で署名されます。
