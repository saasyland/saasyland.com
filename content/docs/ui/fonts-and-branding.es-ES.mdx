## Fuentes

Geist y Geist Mono se alojan en `public/fonts` como subconjuntos WOFF2 variables, servidos con una caché inmutable de un año (`public/_headers`). `src/presentation/styles/fonts.css` declara un `@font-face` por rango Unicode (latino, latino extendido, cirílico), caras de reserva con métricas ajustadas y las variables `--font-geist-sans` y `--font-geist-mono`. `globals.css` las asocia a `--font-sans`, `--font-heading` y `--font-mono`. El texto japonés recurre a las fuentes del sistema.

## Precargas

`src/presentation/document-assets.ts` exporta `DOCUMENT_STYLESHEET` (`globals.css`) y las precargas de fuentes de un idioma:

```ts
export const fontPreloads = (locale: SupportedLocale) => {
  const fonts = [GEIST_LATIN, GEIST_MONO_LATIN]
  if (locale === "pl-PL") {
    fonts.push(GEIST_LATIN_EXT)
  } else if (locale === "uk-UA") {
    fonts.push(GEIST_CYRILLIC)
  }
  return fonts
}
```

La ruta raíz las añade como etiquetas `link`, y el Worker (`src/server.ts`) envía la hoja de estilos y las mismas fuentes en una cabecera de precarga `Link` en cada respuesta HTML. Los nombres de los archivos de fuente son hashes de su contenido: si sustituyes una fuente, actualiza tanto `fonts.css` como `document-assets.ts`.

## Constantes de marca

`src/presentation/branding/index.ts` es la única fuente de la marca:

```ts
export const APP_NAME = "SaaSy Land"
export const APP_DOMAIN = "saasyland.com"

export const APP_URL = `https://${APP_DOMAIN}`
export const CONTACT_EMAIL = `hello@${APP_DOMAIN}`
export const NOTIFICATIONS_EMAIL = `notifications@${APP_DOMAIN}`

export const APP_FOUNDED_YEAR = 2023

export const APP_GITHUB_OWNER = "saasyland"
export const APP_GITHUB_REPO = APP_DOMAIN
export const APP_GITHUB_URL = `https://github.com/${APP_GITHUB_OWNER}/${APP_GITHUB_REPO}`
```

Alimentan el nombre de la aplicación en Better Auth y el emisor de la 2FA, los nombres de las cookies de tema e idioma, los hosts permitidos, el pie de página, la navegación de la documentación, el número de estrellas de GitHub, los datos estructurados del blog y los remitentes y destinatarios de los correos.

## Logotipo y medios

- `Wordmark` (`src/presentation/components/custom/wordmark.tsx`) muestra el logotipo como SVG en línea junto a `APP_NAME`.
- El favicon es `public/favicon.ico`; las imágenes del blog están en `public/images/blog`.
- Los vídeos de la página de inicio están en `src/presentation/assets/motion` como archivos WebM con pósteres WebP. Un póster debe conservar las dimensiones de su vídeo.
