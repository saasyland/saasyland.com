Jeder Abschnitt listet die Änderungen, die an diesem Tag (UTC) in `main` angekommen sind, die neuesten zuerst, und jede Änderung endet mit einem Link auf den Pull Request, aus dem sie stammt, und nach dem Deployment auf das Release, das sie als erstes ausgeliefert hat. Jedes Deployment in Produktion erhält einen Tag und wird als GitHub Release mit den Einträgen, die es ausgeliefert hat, als Notes veröffentlicht; siehe [Releases und Tags](/docs/tooling/ci-cd#releases-and-tags). Die Versionen der CLI selbst stehen in den [Release Notes der CLI](/docs/cli/releases). Jede Änderung bringt ihren eigenen Eintrag mit; siehe [Changelog-Einträge](/docs/conventions/git-workflow#changelog-entries).
