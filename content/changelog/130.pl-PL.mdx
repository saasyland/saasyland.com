- Dokumentacja i blog: każda strona spełnia WCAG 2.2 AA w obu motywach. Pomarańczowy z GitHub Light i szary kolor komentarzy z GitHub Dark są zastąpione w `fumadocs.config.ts`, więc każdy token kodu osiąga 4,5:1, pola wyboru list zadań otrzymują nazwę ze swojego elementu, a łatka Buna do `@fumadocs/base-ui` 16.19.0 sprawia, że blok kodu jest punktem orientacyjnym typu region tylko wtedy, gdy nazywa go jego tytuł, więc strony z kilkoma blokami kodu nie mają już zduplikowanych nienazwanych punktów orientacyjnych. `accessibility.spec.ts` skanuje też każdą stronę sekcji Konwencje, po jednej stronie z każdej sekcji dokumentacji i jeden wpis na blogu w obu motywach oraz kończy się niepowodzeniem, gdy skanowana strona się nie wczyta.
