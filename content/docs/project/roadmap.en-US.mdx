## CLI

Available now: `activate`, `whoami` and `deactivate` manage a licence key on a machine and in CI (see the [CLI guide](/docs/cli)).

Arriving:

- Project generation with `init`, starting with the options the landing page's [configurator](/#cli) lets you pick
- The other UI libraries and frameworks: Next.js and React Router on React, Angular with Analog and Angular SSR, Vue with Nuxt, Svelte with SvelteKit, and Solid with SolidStart and TanStack Start, and the Deno runtime
- The other options and extras, which the configurator shows disabled until the templates generate them
- `change`, to change the answers of a generated project, `update`, to bring it to a newer release, and `status`
- The stable release on npm's default tag

## Tiers

Each tier card on the [pricing section](/#pricing) lists what is available now and what is arriving. `TIER_FEATURES` in `src/data/marketing.ts` holds that split. Arriving:

- Core: the generated application source with only the chosen modules, Better Auth and Resend wired in, billing wired in with the chosen provider, the test suite with its <RepositoryFact name="coverageThreshold" />% gate, and unlimited projects under the commercial licence
- Complete: free lifetime access to reactprojects.com and angularprojects.com, which open after their waitlists, the video course from an empty folder to production, and the code walkthrough module by module
- Agency: unlimited client projects, team seats for the course, reactprojects.com and angularprojects.com, the private Discord channel, and the Figma files for the page designer
