| Шлях                                                    | Вміст                                                                                                                                                                                                         |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/presentation/components/shadcn/`                   | Згенеровані примітиви shadcn у варіанті React Aria                                                                                                                                                            |
| `src/presentation/components/custom/`                   | Компоненти застосунку: спільні файли без вкладених тек (`footer.tsx`, `navigation.tsx`, `data-table.tsx`, `locale-switcher.tsx`, …) і теки за областями `admin/`, `app/`, `auth/`, `blog/` та `landing-page/` |
| `src/presentation/styles/`                              | `globals.css` (Tailwind, токени, типографічна шкала), `fonts.css`, `docs.css`, `typeset.css`                                                                                                                  |
| `src/presentation/theme/`, `src/presentation/branding/` | Константи теми та бренду                                                                                                                                                                                      |
| `src/presentation/document-assets.ts`                   | Глобальна таблиця стилів і попереднє завантаження шрифтів                                                                                                                                                     |
| `src/providers/`                                        | `AriaProvider`, `ThemeProvider`, `TranslationsProvider`, `MotionProvider`                                                                                                                                     |

## У цьому розділі

- [Компоненти shadcn](/docs/ui/shadcn-components): примітиви та те, як їх використовують екрани.
- [DataTable](/docs/ui/data-table): єдиний компонент таблиці.
- [Тема](/docs/ui/theme): світла, темна й системна теми та токени CSS.
- [Шрифти та брендинг](/docs/ui/fonts-and-branding): шрифти, розміщені в проєкті, попереднє завантаження та константи бренду.
- [Шаблони композиції](/docs/ui/composition-patterns): як поєднуються маршрути, сторінки й компоненти.
