---
title: "Glossario"
description: "I termini usati in tutta la documentazione di SaaSy Land."
---

- **AppError:** l'unica classe di errore delle server function, che trasporta uno dei codici di `ERROR_CODES`.
- **Binding:** una risorsa Cloudflare passata al Worker: `DB` (D1), `CACHE` (KV) o `ASSETS` (asset statici).
- **Guard:** una funzione `beforeLoad`, come `requireAdmin`, che reindirizza prima che una route venga caricata.
- **Integrazione:** una cartella in `src/integrations` che configura un singolo fornitore, come Better Auth o Resend.
- **Route di layout:** una route che renderizza un `Outlet` per le proprie route figlie e dichiara `NAMESPACES` condivisi, ad esempio `admin.tsx`.
- **Prefisso del locale:** il segmento di percorso `/<locale>` presente per ogni locale tranne en-US, ad esempio `/pl-PL`.
- **Middleware:** una funzione eseguita prima dell'handler di una server function: `withRequest`, `authorized` o `withRateLimit`.
- **Modulo:** una cartella in `src/modules` che possiede una tabella del database e i relativi casi d'uso.
- **Opzioni di mutazione:** l'oggetto `mutationOptions` esportato accanto a una server function che modifica dati.
- **Namespace:** un file di traduzione, identificato dal nome del file, ad esempio `pages.admin.users`.
- **Route di pagina:** una route che renderizza una pagina e dichiara un `NAMESPACE`.
- **Prerendering:** il rendering delle pagine pubbliche in HTML in fase di build, così che il Worker possa servirle come asset statici.
- **Opzioni di query:** l'oggetto `queryOptions` esportato accanto a una server function che legge dati. Loader e componenti lo condividono.
- **Namespace radice:** `common`, `components.*` e `errors*`, precaricati per ogni pagina.
- **Server function:** un'operazione RPC tipizzata, creata con `createServerFn`, che viene sempre eseguita sul server.
- **Caso d'uso:** un'operazione sulla tabella di un modulo, in `use-cases/<verb>-<noun>.ts`.
- **Ambiente Wrangler:** uno tra `development`, `preview`, `production` e `test` in `wrangler.jsonc`, ciascuno con i propri binding e secret.
