- **Percorso:** un percorso di file TanStack nativo con un componente, una guardia, un caricatore o un handler HTTP.
- **Funzione del server:** un funzionamento RPC digitato creato con `createServerFn`.
- **Query:** dati di lettura memorizzati nella cache con una chiave stabile, condivisi tra il caricatore e React.
- **Mutazione:** un'operazione presentata tramite TanStack Query e supportata da una funzione server.
- **Nomespazio:** un file di traduzione punteggiato sotto una directory locale.
- **Bilance:** una risorsa Cloudflare fornita al lavoratore come `env.DB`, `env.CACHE` o `env.ASSETS`.
- **Prerender:** build-time HTML per un percorso pubblico.
