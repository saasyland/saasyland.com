> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

## Shipped foundations

Authentication, sessions, 2FA, verification, admin users (live data), products/categories use-cases, settings/account, docs, blog, landing.

## In progress / UI shells

Płatności, kursy, modele cenowe, pulpity analityczne, interfejs kreatora strony startowej — ścieżki administracyjne już istnieją; podłączaj prawdziwe moduły w miarę produktyzacji.

## Planned

Organizacje / zespoły, rozliczenia Stripe, sprzedaż w sklepie, zaawansowany dostęp do treści — udokumentowane, aby mapa startera pozostała kompletna.

Przejrzyj strony w tym rozdziale, aby poznać właścicieli poszczególnych obszarów i punkty rozszerzeń.
