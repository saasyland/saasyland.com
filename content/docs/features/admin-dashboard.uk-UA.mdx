## Каркас адмінпанелі

`src/routes/admin.tsx` захищає кожну сторінку адмінпанелі за допомогою `requireAdmin` і попередньо завантажує спільні простори імен. Макет показує:

- `AdminSidebar`, `AdminBreadcrumbs` і `AdminCommandPalette` (відкривається ⌘K), побудовані з `ADMIN_SIDEBAR_GROUPS` у `src/data/admin.ts`, який надає кожному пункту `ADMIN_NAVIGATION` (`src/data/admin-navigation.ts`) його іконку: Огляд (Панель, Аналітика), Пропозиції (Продукти, Цінові моделі), Вміст (Блог, Курси, Відео, Головна сторінка) та Адміністрування (Керування користувачами, Платежі, Налаштування).
- Віджет користувача внизу бічної панелі з посиланням на налаштування та `SignOutButton`.

## Панель

`/admin` (`src/routes/admin.index.tsx`) попередньо завантажує в loader `getProductsQuery` і `getUsersQuery` та складає три віджети з `src/presentation/components/custom/admin/dashboard`:

- `DashboardStats` (робочий): кількість користувачів, кількість продуктів і користувачі, що очікують підтвердження пошти.
- `RevenueChart` (демонстраційний): статичний SVG із фіксованими осями; кнопки діапазону нічого не роблять.
- Картка користувачів (робоча): найновіші користувачі з фільтрами пошуку та статусу, кількість рядків на сторінці: <RepositoryFact name="adminPreviewPageSize" />.

```tsx
<DataTable
  columns={dashboardUserColumns}
  data={users.rows}
  filters={[
    { columnId: "user", placeholder: t("users.search"), type: "search" },
    {
      columnId: "status",
      label: t("users.filters.status"),
      options: USER_STATUSES.map((status) => ({ label: t(`users.table.status.${status}`), value: status })),
      type: "select",
    },
  ]}
  options={{ initialState: { pagination: ADMIN_DASHBOARD_PREVIEW_PAGINATION }, selectable: true }}
/>
```

Таблиця працює в браузері з першою сторінкою `getUsersQuery` (кількість користувачів: <RepositoryFact name="defaultPageSize" />). **Переглянути всіх** веде на `/admin/users`, коли користувачів більше. **Додати продукт** веде на `/admin/products/create`; **Останні 30 днів** вимкнено, а **Експорт** не підключено.
