- Changed: CI runs the unit, integration and component tests with coverage on parallel shards, beside `bun run check`, so the `Format, lint, types, i18n, tests` check finishes sooner. That check now merges the shards' coverage and holds it to the same thresholds as `bun run test:coverage`, and fails when the checks, any shard or the merged coverage fails. See [CI/CD](/docs/tooling/ci-cd#checks).
- Fixed: a Vitest option given on the command line no longer changes the repository facts that the docs and the landing page print.
