---
title: "Installazione"
description: "Installa le dipendenze e genera i file locali."
---

Clona il repository, poi esegui l'installazione dalla sua radice con il lockfile versionato:

```sh
bun install --frozen-lockfile
```

Lo script di ciclo di vita `prepare` poi:

1. Esegue `vp config --no-agent`, che installa il dispatcher degli hook Git per `.vite-hooks/` (i controlli di pre-commit e l'hook del messaggio di commit).
2. Esegue `bun run generate:cn`, che genera le tabelle per l'unione delle classi in `.source/cn-tables.ts`.
3. Esegue `bun run content`, che genera le collezioni Fumadocs in `.source/`.

Se installi con `--ignore-scripts`, come fa la CI, esegui poi `bun run typegen`. Questo rigenera anche `src/types/worker-configuration.d.ts` a partire da `wrangler.jsonc`.

## Extra facoltativi

```sh
bun run test:e2e:install
bun run skills:sync
```

Il primo installa Chromium e WebKit per Playwright; il secondo ripristina le [skill per agenti](/docs/tooling/agent-skills).

## Passo successivo

Configura le tue [variabili d'ambiente](/docs/getting-started/environment-variables), oppure passa direttamente alla preview isolata in [Primo avvio](/docs/getting-started/first-run).
