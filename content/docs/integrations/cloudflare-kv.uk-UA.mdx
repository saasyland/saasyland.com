title: "Cloudflare KV"

---

Кожне середовище прив'язує простір імен KV як `CACHE`. Його єдине призначення — кількість зірок на GitHub, яку показує сайт; реалізацію розміщено в `src/lib/github.ts`:

- `getStarCount` зчитує запис `github:<owner>/<repo>:stars`.
- Якщо запису немає, функція отримує репозиторій через GitHub API з тайм-аутом у три секунди, повертає кількість і записує `count` та `fetchedAt` у KV за допомогою `waitUntil`.
- Коли запис старший за одну годину, функція повертає кешовану кількість і оновлює її у фоні.
- `starCountQuery` зберігає результат у кеші запитів протягом однієї години.

Записи не мають терміну дії в KV; момент оновлення визначає `fetchedAt`. Запит до GitHub автентифікується обліковими даними OAuth-застосунку GitHub `AUTH_GITHUB_CLIENT_ID` і `AUTH_GITHUB_CLIENT_SECRET`.

KV має узгодженість у кінцевому підсумку (eventual consistency). Сесії, ліміти частоти запитів і все, що використовується для авторизації, зберігаються в D1.

У Vitest `cloudflare:workers` розв'язується в `src/platform/testing/mocks/cloudflare.ts`, який надає `CACHE` у пам'яті. Середовище Wrangler `test` використовує локальний простір імен у `.wrangler/test`.
