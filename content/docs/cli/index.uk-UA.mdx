Ліцензія SaaSy Land — це ліцензія на інструмент командного рядка `saasyland`. Ця сторінка описує випуск із тегу <RepositoryFact name="cliReleaseChannel" /> в npm, <RepositoryFact name="cliPackageSpec" />, а [нотатки до випусків](/docs/cli/releases) перелічують, що змінив кожен випуск.

## Що працює сьогодні

- `activate`, `whoami` і `deactivate` керують вашим ліцензійним ключем на пристрої.
- `--help` і `--version` працюють повністю, а кожна команда приймає `--json` і `--locale`.
- Генерація проєктів з’явиться в одному з наступних випусків. Доти <RepositoryFact name="cliInit" /> перевіряє свої прапорці й завершується з кодом <RepositoryFact name="cliExitNotAvailable" />, як і `change`, `update` та `status`. [Конфігуратор](/#cli) на головній сторінці позначає стек за замовчуванням, який запише перший випуск із генерацією проєктів, а [дорожня карта](/docs/project/roadmap) перелічує, що буде далі.

## Запуск

Запускайте CLI з тегу <RepositoryFact name="cliReleaseChannel" /> своїм менеджером пакетів. Глобально нічого встановлювати не потрібно:

<RepositoryTable columns={["Менеджер пакетів", "Команда"]} name="cliRunners" />

Без тегу менеджер пакетів запускає тег `latest` в npm, де досі лежить випуск-заглушка, що зарезервував назву, і жодна з його команд не працює. CLI потребує Node.js <RepositoryFact name="cliNodeEngine" /> або Bun.

## Активація ключа

1. Увійдіть і скопіюйте ключ зі [сторінки ліцензії](/app/license).
2. Запустіть <RepositoryFact name="cliActivate" />. У терміналі CLI попросить ключ і приховає його під час введення.
3. Замість введення можна передати ключ як аргумент, який залишиться в історії оболонки, або задати змінну <RepositoryFact name="cliLicenseKeyVariable" />, яка там не залишається. Без ключа `activate` використовує ключ, уже активований на цьому пристрої.

`--label` дає пристрою назву на сторінці ліцензії; за замовчуванням це ім’я хоста. Повторна активація пристрою зберігає місце, яке він уже займає.

## Пристрої

Кожен пристрій, який ви активуєте, займає одне з місць активації вашої ліцензії: <ActivationLimit tier="core" /> на Core, <ActivationLimit tier="complete" /> на Complete і <ActivationLimit tier="agency" /> на Agency.

- <RepositoryFact name="cliWhoami" /> показує ваш план, зайняті місця та назву цього пристрою.
- <RepositoryFact name="cliDeactivate" /> звільняє місце цього пристрою й видаляє з нього ліцензію.
- Щоб звільнити місце пристрою, яким ви більше не користуєтеся, видаліть його в розділі **Пристрої** на [сторінці ліцензії](/app/license). Наступний виклик `whoami` або `deactivate` на тому пристрої це помітить.

Коли всі місця зайняті, `activate` перелічує пристрої, що їх займають, і відправляє вас на сторінку ліцензії, щоб звільнити одне.

## CI

Збережіть ключ як секрет у <RepositoryFact name="cliLicenseKeyVariable" />. У системах <RepositoryFact name="cliCiProviders" /> кожен запуск одного репозиторію виводить той самий ідентифікатор пристрою, тож репозиторій займає одне місце, скільки б разів він не запускався, з назвою провайдера та репозиторію. У будь-якій іншій системі CI або в контейнері без ідентифікатора пристрою задайте <RepositoryFact name="cliCiRepositoryVariable" /> з назвою репозиторію.

## Де зберігається ліцензія

CLI зберігає ліцензію у файлі <RepositoryFact name="cliCredentialsFile" />, який може прочитати лише ваш користувач (режим <RepositoryFact name="cliCredentialsFileMode" />), у вашому каталозі конфігурації:

<RepositoryTable columns={["Система", "Каталог"]} name="cliCredentialDirectories" />

Якщо `XDG_CONFIG_HOME` не задано, Linux використовує <RepositoryFact name="cliCredentialsLinuxFallback" />. CLI надсилає saasyland.com ключований хеш ідентифікатора цього пристрою, а не сам ідентифікатор. Коли saasyland.com повідомляє, що ліцензію повернено або відкликано, CLI видаляє її з пристрою та спрямовує вас на сторінку ліцензії й до підтримки.

## Змінні середовища

| Змінна                                            | Що задає                                                                                                          |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| <RepositoryFact name="cliLicenseKeyVariable" />   | Ліцензійний ключ, для CI і для сеансів, які не можуть його запитати                                               |
| <RepositoryFact name="cliCiRepositoryVariable" /> | Назву репозиторію в системі CI, яку CLI не розпізнає                                                              |
| <RepositoryFact name="cliLocaleVariable" />       | Мову виводу: спершу `--locale`, потім ця змінна, потім мова вашої системи                                         |
| <RepositoryFact name="cliApiUrlVariable" />       | Інше розгортання saasyland.com, наприклад preview: адресу `https` або адресу `http` на вашому власному комп’ютері |

## Скрипти та агенти для програмування

`--json` виводить результат або помилку як один JSON-документ. У CI, в агенті для програмування або без термінала CLI ніколи не чекає на введення: `activate` без ключа завершується з кодом виходу <RepositoryFact name="cliExitUsage" /> і пояснює, як його передати.

| Код виходу                                        | Коли                                                                                                                                 |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| <RepositoryFact name="cliExitSuccess" />          | Команда зробила те, що обіцяє                                                                                                        |
| <RepositoryFact name="cliExitFailure" />          | Усередині CLI щось пішло не так                                                                                                      |
| <RepositoryFact name="cliExitUsage" />            | Прапорець або <RepositoryFact name="cliApiUrlVariable" /> недійсні, або ключа бракує в сеансі, який не може його запитати            |
| <RepositoryFact name="cliExitNotAvailable" />     | Команда ще недоступна, ідентифікатор цього пристрою не вдається прочитати, або система не Linux, macOS чи Windows                    |
| <RepositoryFact name="cliExitTemporaryFailure" /> | saasyland.com недоступний або просить спробувати пізніше                                                                             |
| <RepositoryFact name="cliExitProtocol" />         | saasyland.com і ця версія CLI не можуть порозумітися; оновіть CLI                                                                    |
| <RepositoryFact name="cliExitNoPermission" />     | Тут не активовано жодної ліцензії, місце цього пристрою звільнено, ключ недійсний, відкликаний або повернений, або всі місця зайняті |
| <RepositoryFact name="cliExitCancelled" />        | Ви скасували запитання клавішами Ctrl+C                                                                                              |
