- 変更: CI はユニットテスト、統合テスト、コンポーネントテストをカバレッジ付きで、`bun run check` と並行して複数のシャードで実行するようになり、`Format, lint, types, i18n, tests` チェックが早く終わります。このチェックはシャードのカバレッジを統合し、`bun run test:coverage` と同じしきい値と照合し、チェック、いずれかのシャード、統合したカバレッジのどれかが失敗すると失敗します。[CI/CD](/docs/tooling/ci-cd#checks) を参照してください。
- 修正: コマンドラインで指定した Vitest のオプションが、ドキュメントとランディングページに表示されるリポジトリの値を変えなくなりました。
