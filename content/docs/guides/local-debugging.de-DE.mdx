## Umgebung wählen

| Umgebung          | Befehle                                     | Daten                                                                    | Provider                       |
| ----------------- | ------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------ |
| Isolierte Preview | `db:reset:test`, `build:test`, `start:test` | Lokales D1, KV und R2 in `.wrangler/test`, vorbefüllte Konten            | Abgefangen; keine Konten nötig |
| Entwicklung       | `db:reset:local`, `db:seed:local`, `dev`    | Lokales D1, KV und R2 in `.wrangler/state`, vorbefüllter Admin und Kurse | Echt, aus `.env.development`   |

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

Die isolierte Preview liefert einen Build unter <RepositoryFact name="localServerOrigin" /> aus; um Änderungen am Quellcode zu sehen, neu bauen. Mit einem der angelegten Konten aus [Erster Start](/docs/getting-started/first-run) und dem Passwort aus `e2e/data/accounts.ts` anmelden. E-Mails werden abgefangen statt versendet: `/__test/emails?to=<address>` öffnen, um sie zu lesen, einschließlich der Verifizierungslinks.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

Der Entwicklungsserver läuft unter `http://localhost:3000` mit Hot Reload. Seine Bindings `DB`, `CACHE`, `MEDIA` und `BUNDLES` sind lokal, sodass nichts, was du tust, die Daten von Preview oder Produktion erreicht. Mit dem vorbefüllten Admin aus [Der lokale Seed](/docs/tooling/database#the-local-seed) anmelden. `POLAR_SERVER=sandbox` verwenden.

## Serverfehler lesen

- Eine fehlschlagende Server-Funktion protokolliert `Server function failed` mit dem ursprünglichen Fehler im Terminal, in dem `bun run dev` läuft, bzw. in den Workers Logs für deployte Umgebungen. Der Browser erhält nur den Fehlercode.
- `Rate-limit storage unavailable` bedeutet, dass D1 während einer Rate-Limit-Prüfung nicht erreichbar war; die Anfrage wurde abgelehnt.
- `[license] <method> <path> failed` bedeutet, dass ein Request an die CLI-Lizenz-API auf dem Server fehlgeschlagen ist, etwa weil D1 oder Polar fehlgeschlagen ist, und die CLI `serviceUnavailable` erhalten hat. Der Eintrag enthält den Fehler mit seiner Ursache und seinem Stack und `[licence key]` an der Stelle des Schlüssels des Aufrufers.
- `No messages/<locale>/<namespace>.json` bedeutet, dass eine Route einen Namespace deklariert, für den es in dieser Locale keine Datei gibt.

## Daten untersuchen

- Drizzle Studio: `bun run db:studio:local` für die lokale Datenbank; `:preview` und `:production` benötigen die `CLOUDFLARE_*`-Variablen in der passenden Umgebungsdatei.
- Lokale Testdatenbank: `bunx wrangler d1 execute DB --env test --local --persist-to .wrangler/test --command "SELECT email, role FROM user"`.

## Generierte Dateien reparieren

- Typen für Worker-Bindings, Klassennamen-Tabellen oder Docs-Inhalte sind veraltet: `bun run typegen`.
- Übersetzungen werden nicht aufgelöst: `bun run check:i18n` listet fehlende Schlüssel pro Locale sowie Schlüssel auf, die in ihrem `useTranslations`-Scope nicht aufgelöst werden.
- `bun run clean` entfernt Build-Ausgaben, Caches und `.wrangler`, einschließlich der lokalen Testdatenbank; danach `db:reset:test` ausführen.

## Tests debuggen

- Ein einzelnes Projekt oder nur betroffene Tests ausführen: `bun run test:unit`, `bun run test:component`, `bun run test:changed`, `bun run test:watch`.
- Playwright: `bun run test:e2e:headed` zeigt den Browser, und `bun run test:e2e:ui` öffnet den UI-Modus. Lokale Läufe behalten Traces fehlgeschlagener Tests und öffnen bei einem Fehlschlag den HTML-Bericht.
- Die Browser-Suite auf einem freien Port aus dem Bereich des Test-Builds ausführen, wenn ein anderer Server <RepositoryFact name="localServerOrigin" /> belegt oder ein anderer Worktree seine Suite ausführt: `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3027 bun run test:e2e:pr`. Wie du den Port wählst, erklärt [Playwright](/docs/tooling/playwright#running-beside-other-worktrees).
