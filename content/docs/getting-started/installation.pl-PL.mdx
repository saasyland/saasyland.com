Sklonuj repozytorium, a następnie zainstaluj zależności z jego katalogu głównego, używając pliku blokady zapisanego w repozytorium:

```sh
bun install --frozen-lockfile
```

Skrypt cyklu życia `prepare` następnie:

1. Uruchamia `vp config --no-agent`, który instaluje dyspozytor hooków Git dla `.vite-hooks/` (kontrole pre-commit i hook komunikatu commita).
2. Uruchamia `bun run generate:cn`, który buduje tablice scalania klas w `.source/cn-tables.ts`.
3. Uruchamia `bun run content`, który generuje kolekcje Fumadocs w `.source/`.

Jeśli instalujesz z `--ignore-scripts`, tak jak CI, uruchom potem `bun run typegen`. To polecenie dodatkowo generuje ponownie `src/types/worker-configuration.d.ts` na podstawie `wrangler.jsonc`.

## Opcjonalne dodatki

```sh
bun run test:e2e:install
bun run skills:sync
```

Pierwsze polecenie instaluje Chromium i WebKit dla Playwright, a drugie przywraca [umiejętności agentów](/docs/tooling/agent-skills).
