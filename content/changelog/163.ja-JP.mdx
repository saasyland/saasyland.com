- ジャーニースイート: `bun run test:journey` は、プルリクエストでは実行されない `e2e/journey/` の独自の Playwright 設定で、顧客と同じ手順でプレビューデプロイ上の各プランを購入します。Resend のテスト用受信箱のアドレスで登録して Resend API で認証メールを読み、ランナーの国の価格を確認し、Polar サンドボックスのチェックアウトで Stripe のテストカードを使って支払い、Polar の注文と `/app/license` のキーを確認します。続いて公開済みの CLI `npx saasyland@beta` をプレビューに対して実行します。対象は `activate`、2 回目のアクティベートでも同じ枠のままであること、`whoami`、プランの上限までの CI 端末と拒否されるもう 1 台、`/app/license` で解放した枠、`deactivate`、そして Polar サンドボックスの API による返金で、`whoami` はこれを `licenseRefunded` と報告します。`playwright.config.ts` は今後 `e2e/specs/` だけを実行します。[ジャーニースイート](/docs/tooling/playwright#journey-suite)を参照してください。
