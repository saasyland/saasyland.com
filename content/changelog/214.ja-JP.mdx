- 修正: Chrome が Topics API を廃止したため、Chromium はすべてのページで `Error with Permissions-Policy header: Unrecognized feature: 'browsing-topics'` を記録していました。`SECURITY_HEADERS` と `public/_headers` の `Permissions-Policy` は、Chromium が引き続き適用するカメラ・位置情報・マイクだけを無効にするようになり、ページが Permissions-Policy のエラーを記録するとブラウザーのスペックが失敗します。[セキュリティと堅牢化](/docs/features/security)を参照してください。
- 修正: デプロイ直後、Early Hints によってブラウザーが前のビルドのスタイルシートを取得し、404 になっていました。Cloudflare はページの直前の `Link` ヘッダーをデプロイ後も `103 Early Hints` として送り直し、スタイルシートの名前は内容とともに変わります。そのため Worker の `Link` ヘッダーには、名前が変わらないロケールのフォントだけを並べるようにしました。フォントは Early Hints によって First Contentful Paint を 20–48 ms 短縮したままです。測定は[パフォーマンス](/docs/conventions/performance)、ゾーンの Early Hints と Speed Brain の設定は [Cloudflare Workers](/docs/integrations/cloudflare-workers) を参照してください。
- 修正: ローカライズした記事にある `/#pricing` のようなホームページのセクションへのリンクが `/pl-PL/#pricing` を指し、リダイレクトを経由していました。`localizeHref` はリンクのパスだけをローカライズしてクエリとフラグメントを残すので、MDX と React Aria のリンクは `/pl-PL#pricing` を開くようになりました。`check-content.ts` は、スラッシュ、`/index`、`.html` で終わる内部リンクや、ロケールで始まる内部リンクで失敗します。[翻訳とコンテンツ](/docs/conventions/translations)を参照してください。
