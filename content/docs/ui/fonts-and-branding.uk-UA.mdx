## Шрифти

Geist і Geist Mono розміщено в `public/fonts` як змінні підмножини WOFF2, що віддаються з незмінним кешем на рік (`public/_headers`). `src/presentation/styles/fonts.css` оголошує `@font-face` для кожного діапазону Unicode (латиниця, розширена латиниця, кирилиця), резервні шрифти з підігнаними метриками та змінні `--font-geist-sans` і `--font-geist-mono`. `globals.css` зіставляє їх із `--font-sans`, `--font-heading` і `--font-mono`. Японський текст використовує системні шрифти.

## Попереднє завантаження

`src/presentation/document-assets.ts` експортує `DOCUMENT_STYLESHEET` (`globals.css`) і шрифти для попереднього завантаження для певної мови:

```ts
export const fontPreloads = (locale: SupportedLocale) => {
  const fonts = [GEIST_LATIN, GEIST_MONO_LATIN]
  if (locale === "pl-PL") {
    fonts.push(GEIST_LATIN_EXT)
  } else if (locale === "uk-UA") {
    fonts.push(GEIST_CYRILLIC)
  }
  return fonts
}
```

Кореневий маршрут додає їх як теги `link`, а Worker (`src/server.ts`) надсилає таблицю стилів і ті самі шрифти в заголовку попереднього завантаження `Link` у кожній HTML-відповіді. Назви файлів шрифтів — це хеші їхнього вмісту: замінивши шрифт, оновіть і `fonts.css`, і `document-assets.ts`.

## Константи бренду

`src/presentation/branding/index.ts` — єдине джерело даних про бренд:

```ts
export const APP_NAME = "SaaSy Land"
export const APP_DOMAIN = "saasyland.com"

export const APP_URL = `https://${APP_DOMAIN}`
export const CONTACT_EMAIL = `hello@${APP_DOMAIN}`
export const NOTIFICATIONS_EMAIL = `notifications@${APP_DOMAIN}`

export const APP_FOUNDED_YEAR = 2023

export const APP_GITHUB_OWNER = "saasyland"
export const APP_GITHUB_REPO = APP_DOMAIN
export const APP_GITHUB_URL = `https://github.com/${APP_GITHUB_OWNER}/${APP_GITHUB_REPO}`
```

Вони задають назву застосунку в Better Auth і видавця 2FA, назви cookie теми та мови, дозволені хости, футер, навігацію документації, кількість зірок GitHub, структуровані дані блогу, а також відправників і отримувачів листів.

## Логотип і медіа

- `Wordmark` (`src/presentation/components/custom/wordmark.tsx`) рендерить логотип як вбудований SVG поруч з `APP_NAME`.
- Фавікон — `public/favicon.ico`; зображення блогу розташовано в `public/images/blog`.
- Відео головної сторінки розташовано в `src/presentation/assets/motion` як файли WebM з постерами WebP. Постер має зберігати розміри свого відео.
