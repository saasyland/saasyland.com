---

## In the admin

There is no analytics screen. The [admin dashboard](/docs/features/admin-dashboard) reports what D1 holds: revenue from the copies of Polar's orders, new accounts, course progress and newsletter subscribers. Page views, visitors, retention and churn need an analytics source that the app does not have, so no screen shows them.

## What is collected

No analytics script is installed, and no events are stored. The only third-party script is Affonso's referral pixel, which loads only on a visit whose URL carries a referral parameter and only when `AFFONSO_PROGRAM_ID` is set and `AFFILIATE_PROGRAM` says the programme is open ([Affiliate programme](/docs/features/affiliates)). `wrangler.jsonc` enables Workers `observability`, so Worker logs, including the `console.error` output of failed server functions, appear in the Cloudflare dashboard.
