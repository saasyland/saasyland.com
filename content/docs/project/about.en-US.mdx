SaaSy Land 2.0 is the source code of the saasyland.com website, its customer workspace and its admin console. One TanStack Start application on Cloudflare Workers combines a multilingual marketing site, documentation and blog, authentication, newsletter subscriptions, video streaming and courses, and Polar checkout with licence-key management.

The code is written as a real product: modules per database table, typed server functions with their own authorization, one translation namespace per page, <RepositoryFact name="coverageThreshold" unit="percent" /> test coverage and browser tests in CI. It is for developers who want to study or reuse a production setup of authentication, admin, internationalization and Cloudflare plumbing.

Users, sessions, products, categories, videos, courses and lesson progress are backed by D1, and video files by R2. The analytics, payments, pricing models, blog administration, landing page builder, invitations and roles screens, and the revenue chart on the dashboard, show demo data from `src/data/`.

The SaaSy Land CLI and its private generator templates are a separate, proprietary product and are not part of this codebase. See [Licence](/docs/project/license).
