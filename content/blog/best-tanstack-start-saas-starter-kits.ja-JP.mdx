## 結論から

チーム、シート課金、管理画面を初日から備えた TanStack Start の SaaS を今週始める必要があるなら、成熟した有料の選択肢は **MakerKit** と **supastarter** です。同じライセンスで Supabase や Next.js も使いたいなら MakerKit が、5 つの決済プロバイダーと、アプリとは別にデプロイするマーケティングサイトが欲しいなら supastarter が合っています。

**Cloudflare Workers** にデプロイするなら、現在それ向けに作られている有料キットの中で定価が最も安いのは **TanStarter**（tanstarter.dev）です。

無料で小さなものが欲しいなら、以前 TanStarter と呼ばれていたテンプレートである **Cove Stack** が、TanStack Start、Better Auth、Drizzle をつなぎ合わせてくれます。削除しなければならないものは何もありません。

**Open SaaS** は無料で機能も揃っていますが、TanStack Start ではなく Wasp で作られています。

**SaaSy Land** は、Cloudflare Workers 上で動き、<RepositoryFact name="coverageThreshold" />% のカバレッジゲートを満たし、<RepositoryFact name="languages" /> 言語に翻訳された本番の TanStack Start アプリを、決める前に隅々まで読みたい場合の選択肢です。CLI はベータ版で、コンフィギュレーターで選択できるオプションからプロジェクトを生成し、課金とその他のオプションは提供予定なので、購入する前に SaaSy Land の現状を説明したセクションを読んでください。

## 検索結果を紛らわしくしている 2 つの名前

**TanStarter は今では 2 つの別々の製品を指します。** 多くの TanStack Start プロジェクトの出発点になった、無料でパブリックドメインのテンプレートは、TanStarter として公開されていました。2026年9月、作者はこれを **Cove Stack** に改名しました。古い名前が「is now shared with a growing, unaffiliated product that is commercially offered as a SaaS boilerplate」（SaaS ボイラープレートとして商用提供されている、成長中の無関係な製品と共有されるようになった）からです。その製品が tanstarter.dev の **TanStarter** で、Cloudflare Workers 向けの有料キットです。ここでは両方を現在の名前で比較しており、古い GitHub のリンクは Cove Stack にリダイレクトされます。

**Open SaaS は TanStack Start のキットではありません。** 無料の SaaS ボイラープレートの一覧には必ず登場するので、この比較にも含めていますが、Wasp フレームワークで動いています。ブラウザ側は React と React Router、サーバー側は Node.js で、その下に Prisma と PostgreSQL があります。Wasp は TanStack Query を独自の `useQuery` でラップしており、混乱の原因はそこにあります。TanStack Start を選んだのであれば、Open SaaS は別のキットというより、別の決断です。

**MakerKit と supastarter は、Next.js と並べて TanStack Start を販売しています。** MakerKit のライセンスは Supabase、Drizzle、Prisma というデータレイヤーごとに販売され、そのキットの Next.js 版と TanStack Start 版の両方が含まれます。Supabase のライセンスには React Router 版も加わります。supastarter の購入は 1 つのフレームワークが対象なので、TanStack Start 版は Next.js 版や Nuxt 版とは別に購入します。

## スターターキットは必要か、それとも公式の CLI で十分か

TanStack 自身の CLI もプロジェクトを作成します。クイックスタートのページには `npx @tanstack/cli@latest create` が載っており、このコマンドはパッケージマネージャーと「optional add-ons like Tailwind CSS and ESLint」（Tailwind CSS や ESLint などの任意のアドオン）を尋ねます。ドキュメントには、Clerk や Supabase などのインテグレーションのサンプルプロジェクトへのリンクもあります。すべてのレイヤーを自分で選んでつなぎたいなら、これが正しい出発点です。Cove Stack は同じ考え方をもう一歩進めたもので、認証とデータベースがすでに接続されています。

SaaS スターターキットが担うのは、その後に続くレイヤーです。メールアドレスの確認と二要素認証を備えたサインイン、課金とその Webhook、管理画面、トランザクションメール、翻訳、そしてそれらすべてが動き続けるよう守るテストです。この比較の残りで扱うのは、そうしたレイヤーです。

重要な分かれ目は**アプリがどこで動くか**です。MakerKit と supastarter の TanStack Start キットは Nitro で Node サーバーをビルドし、Node ホストをドキュメントに記載しています。MakerKit の Drizzle 版と Prisma 版では Railway と Docker、supastarter では 7 つのホストです。MakerKit の Supabase 版には Vercel、Cloudflare、VPS のガイドが加わり、MakerKit は Drizzle キットとは別に販売する Cloudflare キットを発表していますが、確認した日には「Coming soon」（近日公開）と表示されていました。

TanStarter と SaaSy Land は最初から Cloudflare Workers 向けに作られており、データベースに D1、その隣に KV と R2 を使います。これはデプロイのプリセット以上の意味を持ちます。用意したりパッチを当てたりするサーバーがなく、D1 は SQLite なので、データモデルは後から Postgres から移植されるのではなく、最初のマイグレーションから SQLite 向けに書かれます。このサイトでの使い方は、SaaSy Land の [Cloudflare Workers のドキュメント](/docs/integrations/cloudflare-workers)で説明しています。

**認証ライブラリは 1 つに収束しています。** ここで取り上げる TanStack Start キットはすべて Better Auth を使っており、例外は行レベルセキュリティ付きの Supabase Auth を使う MakerKit の Supabase 版だけです。購入者にとっては良い知らせです。ユーザーとセッションは自分のデータベースに保存され、アクティブユーザー単位で課金してくる認証ベンダーはいません。

**認証。** 最も充実しているのは MakerKit と supastarter で、パスワード、マジックリンク、パスキー、OAuth、二要素認証に加え、組織、招待、ロール、スーパー管理者、なりすましを備えています。TanStarter はメールとパスワード、Google サインイン、管理者とユーザーのロールを搭載しています。Cove Stack はメールとパスワードで、GitHub と Google をオプションで使えます。Open SaaS は Wasp 独自の認証を使い、メールでのサインインが有効で、Google、GitHub、Discord はすぐに有効化できる状態です。SaaSy Land のサイトは Better Auth で、メールアドレスの確認、パスワードのリセット、メールアドレスの変更、GitHub と Google のサインイン、ロール、バックアップコード付きの二要素認証を動かしています。組織はまだなく、マルチテナンシーは提供予定です。

**課金。** 最も多くのプロバイダーに対応しているのは supastarter で、マーチャント・オブ・レコードの Creem と Dodo Payments も含まれます。MakerKit の TanStack Start キットは、Drizzle 版と Prisma 版で Stripe または Polar、Supabase 版で Stripe に対応し、シート課金と従量課金のプランを扱えます。TanStarter は Stripe、Creem、Waffo Pancake に、Open SaaS は Stripe、Lemon Squeezy、Polar、Paddle に対応しています。Cove Stack は課金を利用者に任せています。SaaSy Land 自身のサイトは、チェックアウトと Webhook を含めて Polar で決済を受け付けており、そのコードは公開されています。生成されるプロジェクトの課金は提供予定です。現在の CLI は、課金なしでプロジェクトを書き出します。

**対応言語。** TanStarter は Paraglide JS で英語と中国語を搭載し、supastarter は翻訳と言語スイッチャーを含み、MakerKit の TanStack Start キットは use-intl を使い、デフォルトで英語が有効になっています。SaaSy Land は use-intl で <RepositoryFact name="languages" /> 言語に対応し、ドキュメントもそのすべての言語で書かれており、キーが欠けていたり翻訳が壊れていたりすると、チェックが CI を失敗させます。Cove Stack と Open SaaS には翻訳がありません。

**テスト。** ここで取り上げる有料キットにはどれも、Playwright の E2E テストと Vitest があります。違うのは、テストされていないコードのマージを止めるものがあるかどうかです。MakerKit のテストガイドには「no repo-wide (root) test:unit:coverage script」（リポジトリ全体で使うルートの test:unit:coverage スクリプトはない）とあります。supastarter は Playwright のスイートを、プルリクエストの CI ではなくローカルで実行します。TanStarter はユニット、ブラウザ、Worker のスモーク、実際の決済サンドボックスのスイートを記載しており、これはほとんどのキットより多いものの、カバレッジのしきい値は示していません。Cove Stack のエージェントガイドには「there is no coverage target」（カバレッジの目標はない）とあり、Open SaaS はユニットテストのない Playwright のスイートを提供しています。SaaSy Land の `vite.config.ts` はステートメント、分岐、関数、行に <RepositoryFact name="coverageThreshold" />% を設定しており、それを下回るとマージが失敗します。その仕組みは[テストのドキュメント](/docs/tooling/testing)で説明しています。

**管理画面。** Cove Stack 以外のキットにはすべて管理画面があります。MakerKit と supastarter の管理画面はユーザーと組織を管理し、MakerKit のものにはサブスクリプションとなりすましも加わります。TanStarter の管理画面はユーザー、ロール、アカウント停止を管理し、Open SaaS にはユーザーとアナリティクスのダッシュボードがあります。SaaSy Land の管理画面には、ダッシュボード、操作付きのユーザーテーブル、設定があります。

## ドキュメントとコーディングエージェント

6 つすべてが、サインインなしでドキュメントを公開しています。最も大規模なのは MakerKit で、ホームページには Next.js Supabase キットについて「alone has more than 170 pages」（それだけで 170 ページを超える）と書かれており、TanStack Start の各版にもそれぞれのドキュメントがあります。supastarter の TanStack Start 版のドキュメントは、セットアップ、決済、組織、デプロイ、エージェントスキルを扱い、zip でダウンロードできます。TanStarter には Cloudflare のセットアップ、インテグレーション、CLI のためのドキュメントサイトがあり、Open SaaS には Astro Starlight で作られたドキュメントサイトがあります。Cove Stack は README と一連のエージェントガイドで自らを説明しています。SaaSy Land の[ドキュメント](/docs)は <RepositoryFact name="languages" /> 言語で公開されており、値をコードから出力しているので、ドキュメントのページにある数値が、説明しているコードとずれることはありません。

コーディングエージェント向けには、MakerKit、supastarter、Open SaaS、Cove Stack のすべてがエージェントスキル付きの `AGENTS.md` を同梱しており、MakerKit はさらに MCP サーバーを提供しています。SaaSy Land は `AGENTS.md` を同梱し、TanStack、Better Auth、Cloudflare、Polar、Resend のベンダースキルのバージョンを固定しています。指示よりもチェックのほうが重要な理由は、[AI コーディングエージェントに向けたリポジトリの準備](/blog/ai-coding-agents-repository-readiness)で書きました。

## SaaSy Land の現状を正確に

これは私たち自身の製品なので、手に入るものと手に入らないものを正確に説明します。

**このサイト自身のコード。** saasyland.com のソースは MIT ライセンスで公開されています。Cloudflare Worker 上の完成した TanStack Start アプリケーションで、Drizzle 経由の D1、KV と R2、Better Auth、Polar のチェックアウトと Webhook、Resend、<RepositoryFact name="languages" /> 言語の use-intl、Fumadocs を備え、上で述べたカバレッジゲートを満たしています。お金を使う前にその全行を読めます。ここで取り上げるほかの有料キットで、自社のコードについてそれを提供しているものはありません。

**購入する CLI。** ライセンスで購入するのはプロプライエタリな `saasyland` CLI で、npm の <RepositoryFact name="cliReleaseChannel" /> タグから実行します。キーを使う端末の有効化、表示、解放ができ、`init` は[コンフィギュレーター](/#cli)で選択できるオプションからプロジェクトを書き出します。現時点では、Cloudflare Workers 上のモノリス構成で React を使う TanStack Start、Drizzle を使う D1 上の SQLite、Better Auth または認証なし、Resend、MDX のコンテンツです。それ以外のオプションは、ライセンスが確認される前にコード <RepositoryFact name="cliExitNotAvailable" /> で終了します。課金、Postgres、マルチテナンシー、ほかのフレームワーク、ほかのホストは提供予定です。現在動作するものは [CLI のドキュメント](/docs/cli)に記載しています。

**プラン。** <TierPrice tier="core" /> の Core は、基本コードの無期限アップデートが付いた CLI です。<TierPrice tier="complete" /> の Complete は、優先サポートを今すぐ追加し、reactprojects.com と angularprojects.com への無期限の無料アクセス、収録中の動画コース、モジュールごとのコード解説を提供され次第追加します。<TierPrice tier="agency" /> の Agency は、60 分のアーキテクチャ相談とクライアントプロジェクトを今すぐ追加し、チーム席、プライベートな Discord チャンネル、Figma ファイルを提供され次第追加します。各料金カードには、今すぐ使えるものと提供予定のものが示されています。購入後に使っていなければ、<RepositoryFact name="refundWithdrawalDays" unit="day" />以内に全額返金を受けられます。何が利用にあたるかは[返金条件](/refunds)に記載しています。

## どの TanStack Start スターターキットを選ぶべきか

**MakerKit を選ぶ**のは、最初のリリースでチーム、ロール、シート課金が必要な B2B SaaS を作る場合、行レベルセキュリティ付きの Supabase と pgTAP によるデータベーステストが欲しい場合、あるいは 1 つのライセンスで Next.js と TanStack Start を使いたい場合です。2022年からフルタイムでメンテナンスされており、MCP サーバーとエージェントスキルを同梱し、ドキュメントはここで取り上げる中で最も充実しています。ほかの誰かがコードに触れる場合や、クライアント向けに開発する場合は、Teams の予算を見込んでください。[MakerKit の代替](/blog/makerkit-alternative-for-engineers)では、SaaSy Land と詳しく比較しています。

**supastarter を選ぶ**のは、決済プロバイダーの選択肢を最も広く持ちたい場合、マーケティングサイトとプロダクトのアプリを別々にデプロイしたい場合、あるいは OpenAPI ドキュメント付きの Hono と oRPC の API が欲しい場合です。シート単位のプランは開発者 10 人まであり、ホームページによれば 1,520 人の開発者に信頼されています。

**TanStarter を選ぶ**のは、Cloudflare Workers にデプロイする場合、有料キットの中で最も安い定価を求める場合、Workers AI や fal.ai との AI 連携が欲しい場合、あるいは初日から英語と中国語が必要な場合です。条件が公開されていないので、クライアントワークに使う前に作者に確認してください。

**Cove Stack を選ぶ**のは、TanStack Start、Better Auth、Drizzle、shadcn/ui がつながっていてそれ以外は何もない状態を、パブリックドメインのライセンスで手に入れたく、課金、メール、管理画面を自分で作ることに抵抗がない場合です。

**Open SaaS を選ぶ**のは、決済、管理ダッシュボード、1 コマンドでのデプロイを備えた無料の MIT ライセンスのキットのほうがフレームワークよりも重要で、Wasp の README がベータ版と説明している Wasp を採用することに抵抗がない場合です。

**SaaSy Land を選ぶ**のは、決める前に完成した本番アプリを読みたい場合、D1 を使う Cloudflare Workers がターゲットである場合、<RepositoryFact name="coverageThreshold" />% のカバレッジゲートと <RepositoryFact name="languages" /> 言語を、いつか到達したい目標ではなく出発点にしたい場合、そして開発者ではなく端末を数えるライセンスがチームに合っている場合です。今週生成するプロジェクトに課金、チーム、または別のホストが必要なら、選ばないでください。それらのオプションは提供予定で、上のキットは今日からそれらを提供しています。
