## Happy path (admin page)

1. `proxy.ts` ensures locale + authenticated admin
2. Layout renders shell (sidebar, header); `children` remain RSC
3. Page starts data promises (use-cases) and wraps sections in `Suspense`
4. Read checks its `Permission` via `hasPermission` and loads cached data
5. Client islands (DataTable, tabs) hydrate; URL-driven tabs soft-navigate through the App Shell

## Mutations

Client → server action (safe-action) → use-case → `updateTag` / auth API → UI refresh.
