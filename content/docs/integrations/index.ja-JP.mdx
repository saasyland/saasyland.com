---
title: "概要"
description: "src/integrations 配下のベンダーアダプターです。"
---

`src/integrations/<vendor>/` の各フォルダーは、1 つのベンダーを `<prefix>.<concern>.ts` ファイル群でラップします。プレフィックスはベンダーの短い名前（`auth`、`drizzle`、`i18n`、`form`）です。内容は設定、クライアント、薄いアダプターです。ビジネスルールとデータベース操作は `src/modules` に置き、コンポーネントがベンダーのクライアントを直接インポートすることはありません。

| フォルダー       | ファイル                                                                                                                                                                                                                                                               | 目的                                                                                                                                                                          |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `affonso`        | `affonso.constants.ts`, `affonso.program.ts`, `affonso.referral.ts`                                                                                                                                                                                                    | アフィリエイトの紹介パラメーター、プログラム ID、チェックアウトのメタデータ                                                                                                   |
| `better-auth`    | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.roles.ts`, `auth.session.ts`, `auth.hooks.ts`, `auth.callbacks.ts`, `auth.constants.ts`, `auth.constraints.ts`, `auth.errors.ts`, `auth.zod.ts`, `auth.types.d.ts` | セッション、OAuth、プラグイン、ルートガード、サーバー関数のミドルウェア、ロールと権限、リクエストのフック、コールバック URL、定数、フィールドの上限、エラーキー、Zod スキーマ |
| `drizzle-orm`    | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `drizzle.local.config.ts`, `drizzle.errors.ts`, `drizzle.columns.ts`, `drizzle.time-series.ts`, `drizzle.search.ts`, `migrations/`                                                                   | D1 クライアント、スキーマのバレル、drizzle-kit の設定、`rethrowAsConflict`、`timestamps()`、`bucketOf`、検索とフィルターの条件                                                |
| `fumadocs`       | `fumadocs.config.ts`, `fumadocs.schema.ts`, `fumadocs.i18n.ts`, `fumadocs.indexes.ts`, `fumadocs.docs.ts`, `fumadocs.blog.ts`, `fumadocs.changelog.ts`, `fumadocs.icons.ts`, `fumadocs.vite.ts`                                                                        | ドキュメントとブログのコレクション、ビルド時に作るインデックス、検索、変更履歴のエントリ、サイドバーのアイコン                                                                |
| `motion`         | `motion.features.ts`, `motion.tokens.ts`                                                                                                                                                                                                                               | 遅延読み込みされる Motion の機能と共通のトランジション                                                                                                                        |
| `polar`          | `polar.config.ts`, `polar.constants.ts`, `polar.customers.ts`, `polar.webhooks.ts`, `polar.vite.ts`                                                                                                                                                                    | Polar SDK クライアント、Polar 固有の値、顧客のアカウント、各 Webhook イベントが届くコード、SDK のビルド設定                                                                   |
| `resend`         | `resend.config.ts`, `resend.constants.ts`, `resend.utils.ts`                                                                                                                                                                                                           | Resend クライアント、`sendEmail`、`sendBatchEmails`、バッチの上限、配信停止ヘッダー、`EMAIL_PURPOSE`                                                                          |
| `takumi`         | `takumi.fonts.ts`, `takumi.render.tsx`                                                                                                                                                                                                                                 | ソーシャルカードと組織のロゴを、サイト自身のフォントでビルド時に描画します                                                                                                    |
| `tanstack-form`  | `form.fields.ts`, `form.submit.ts`                                                                                                                                                                                                                                     | フォームフィールドのエラー用の `fieldErrorMessage`。`submitForm` と `showFieldError` は無効なフィールドを示し、そこにフォーカスを移します                                     |
| `tanstack-query` | `query.cache.ts`                                                                                                                                                                                                                                                       | リクエストごとの `QueryClient` のデフォルトのキャッシュ時間                                                                                                                   |
| `tanstack-table` | `table.columns.ts`, `table.features.ts`                                                                                                                                                                                                                                | `DataGrid` のテーブル機能、フィルターの種類、固定列                                                                                                                           |
| `use-intl`       | `i18n.config.ts`, `i18n.loaders.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                                                                                                                                                        | ロケール、メッセージの名前空間、ロケールミドルウェア、URL ヘルパー                                                                                                            |
| `zod`            | `zod.config.ts`, `zod.vite.ts`                                                                                                                                                                                                                                         | ブラウザで Zod を `jitless` で動かし、Content Security Policy のもとで `eval` を試さないようにします                                                                          |
