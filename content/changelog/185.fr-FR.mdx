- Le navigateur ne télécharge plus Drizzle. Chaque `<table>.zod.ts` construisait des schémas `insert`, `select` et `update` à partir de sa table avec `drizzle-zod`, que seuls les tests lisaient, et plusieurs tuples d’enum se trouvaient dans les fichiers `.schema.ts` : les formulaires, les options de query et les squelettes de chargement de `/admin` et `/app` apportaient donc à chaque page les tables, `drizzle-orm` et, via `drizzle-zod`, toutes les locales de zod. Chaque tuple d’enum, y compris `TIMEZONE_CODES` et `LICENSE_STATUSES`, se trouve désormais dans le `<table>.constants.ts` de son module, les schémas dérivés et la dépendance `drizzle-zod` ont disparu, et chaque page charge environ 75 Kio de JavaScript compressé avec gzip en moins : la page d’accueil est passée de 526,2 Kio à 450,7 Kio. La protection des imports de TanStack Start interdit `drizzle-orm` dans le build client, si bien qu’un import qui le ramènerait fait échouer le build et affiche sa chaîne d’imports. Voir [Gardez l’ORM hors du navigateur](/docs/conventions/performance#keep-the-orm-out-of-the-browser).
