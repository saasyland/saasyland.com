- Nuevo: `bun run deps:update` actualiza en un solo comando cada dependencia con rango a su versión más reciente, Vite+ mediante `vp migrate` y las skills para agentes, y después nombra los paquetes fijados que tienen una versión más reciente. Consulta [Dependencias](/docs/conventions/dependencies#upgrading).
- Nuevo: `bun run check` falla cuando un paquete que documenta una skill para agentes, como `resend`, `better-auth` o `wrangler`, se movió sin `bun run skills:update`, y cuando las skills instaladas difieren de `skills-lock.json`. `SKILL_SOURCES` en `src/data/skills.ts` asigna a cada origen de skills los paquetes que documenta. Consulta [Skills para agentes](/docs/tooling/agent-skills#drift-checks).
- Nuevo: el flujo de trabajo semanal `updates.yml` enumera las actualizaciones disponibles de dependencias y skills en una sola issue de GitHub, que abre, reescribe y cierra. Consulta [CI/CD](/docs/tooling/ci-cd#updates).
- Cambiado: la CLI `skills` es una dependencia de desarrollo, así que `bun.lock` fija la versión que instala las skills y calcula sus hashes.
