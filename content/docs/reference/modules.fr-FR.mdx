Un module n'existe que pour une vraie table de la base de données. Chaque table est enregistrée dans `src/integrations/drizzle-orm/drizzle.schemas.ts`.

`_core` ne possède aucune table. Il contient les codes d'erreur, les catalogues et les utilitaires partagés décrits dans [Noyau partagé](/docs/architecture/core).

## Fichiers en plus de l'ensemble standard

La plupart des modules ne contiennent que `<table>.schema.ts`, `.zod.ts`, `.constants.ts`, `.types.ts`, `.utils.ts` et `use-cases/`. Quelques-uns en comptent davantage :

- `license/license.webhooks.ts` : les handlers de webhooks Polar transmis à Better Auth
- `license/license.ppp.ts` : les réductions de tarification régionale appliquées au paiement
- `newsletter-subscriber/newsletter-subscriber.server.ts` : la vérification de l'origine des requêtes pour les liens de la newsletter

## Cas d'usage serveur simples

Ces cas d'usage sont des fonctions asynchrones sans endpoint RPC. Ce sont les hooks Better Auth, les handlers de webhooks Polar ou d'autres cas d'usage qui les appellent : `send-verify-email`, `send-reset-password-email`, `send-change-email-confirmation-email`, `grant-license`, `revoke-license`, `attach-license-key` et `get-license`.
