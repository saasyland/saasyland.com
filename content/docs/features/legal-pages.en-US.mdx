| Route      | Route file                        | Namespace             |
| ---------- | --------------------------------- | --------------------- |
| `/privacy` | `src/routes/_landing.privacy.tsx` | `pages.legal.privacy` |
| `/terms`   | `src/routes/_landing.terms.tsx`   | `pages.legal.terms`   |
| `/refunds` | `src/routes/_landing.refunds.tsx` | `pages.legal.refunds` |
| `/licence` | `src/routes/_landing.licence.tsx` | `pages.legal.licence` |

Each route file defines its own page component, a static `NAMESPACE`, and a module constant with the section keys in display order:

```tsx
const SECTIONS = ["operator", "accounts", "purchases", "payments", "licence", "conduct", "refunds", "responsibility", "law"] as const
```

The page renders `lastUpdated`, `title` and `description`, then `sections.<key>.title` and `sections.<key>.body` for every key. There is no shared legal component.

## Editing

- Change copy in `messages/<locale>/pages.legal.<doc>.json` for all nine locales and run `bun run check:i18n`.
- To add a section, add its key to `SECTIONS` and its messages in every locale.
- Footer links are the `LEGAL_LINKS` constant in `src/presentation/components/custom/footer.tsx`; the sign-up page links to the terms and privacy policy.

The licence page separates the public repository's MIT licence from separately supplied paid material. The refund policy keeps mandatory consumer rights. Keep every document aligned with the real operator, checkout, providers and data handling.
