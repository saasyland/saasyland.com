---
title: "Вступ"
description: "Адаптери постачальників у src/integrations."
---

Кожна папка в `src/integrations/<vendor>/` обгортає одного постачальника у файли `<vendor>.<concern>.ts`: конфігурацію, клієнти й тонкі адаптери. Бізнес-правила та операції з базою даних залишаються в `src/modules`, а компоненти ніколи не імпортують клієнт постачальника напряму.

| Папка           | Файли                                                                                                           | Призначення                                                         |
| --------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `better-auth`   | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.session.ts` | Сесії, OAuth, гарди маршрутів, middleware серверних функцій, ролі   |
| `drizzle-orm`   | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `migrations/`                                 | Клієнт D1, barrel-файл схем, конфігурація drizzle-kit               |
| `fumadocs`      | `fumadocs.config.ts`, `fumadocs.i18n.ts`, `fumadocs.source.ts`, `fumadocs.docs.ts`, `fumadocs.search.ts`        | Колекції документації та блогу, локалізовані джерела, пошук         |
| `motion`        | `motion.features.ts`, `motion.tokens.ts`                                                                        | Ліниво завантажувані можливості Motion і спільні переходи           |
| `polar`         | `polar.config.ts`, `polar.constants.ts`                                                                         | Клієнт Polar SDK і продукти для оформлення замовлення               |
| `resend`        | `resend.config.ts`, `resend.utils.ts`                                                                           | Клієнт Resend і `sendEmail`                                         |
| `tanstack-form` | `form.fields.ts`                                                                                                | `fieldErrorMessage` для помилок полів форми                         |
| `use-intl`      | `i18n.config.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                    | Локалі, простори імен повідомлень, middleware локалі, помічники URL |
