Defina el esquema de búsqueda para una ruta. `validateSearch`, lee `Route.useSearch`, y se actualiza a través de la navegación de TanStack Router. Mantener filtros, pestañas, ordenación y paginación marcables en la URL cuando sea apropiado. El estado de los componentes permanece en React.

Las redirecciones de URL de localización se aplican a los enlaces nativos de Router. `localizePathname` Para URLs construidas manualmente, incluyendo callbacks de OAuth y enlaces de correo electrónico. No añadir prefijos a los enlaces o rutas de API externas. Conservar la consulta y el fragmento al cambiar de idioma.
