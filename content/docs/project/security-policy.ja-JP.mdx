このポリシーの対象は、顧客エリアと管理コンソールを含む saasyland.com、このリポジトリのコード、そして有料の CLI とそのパッケージ `saasyland`、`create-saasyland`、`@saasyland/stack` です。リポジトリのルートにある `SECURITY.md` にも同じ内容を記載しています。

## 脆弱性を報告する [#report]

脆弱性を公開の Issue、プルリクエスト、コメントで報告しないでください。次のいずれかの方法で非公開で報告してください。

- GitHub の[非公開の脆弱性報告](https://github.com/saasyland/saasyland.com/security/advisories/new)
- hello@saasyland.com へのメール

影響を受ける対象（URL、ルート、サーバー関数、ファイル、CLI のコマンド）、再現手順または概念実証、影響（攻撃者が何を読み取り、変更し、実行できるか）、テストしたコミットまたはリリースを記載してください。英語またはポーランド語で書いてください。

サイトは同じ連絡先を <RepositoryFact name="securityTxtPath" /> で RFC 9116 の形式で公開しており、言語 <RepositoryFact name="securityTxtLanguages" /> とこのページへのリンクを記載しています。ビルドが `src/lib/security-txt.ts` からこのファイルを書き出し、`Expires` の日付が過ぎたとき、または 1 年より先になったときは `security-txt.test.ts` が失敗するため、古くなる前に更新されます。

## 報告後の流れ [#after-you-report]

以下は目標であり、保証ではありません。

1. **受領の連絡。** <RepositoryFact name="securityAcknowledgeWorkingDays" /> 営業日以内に返信します。
2. **評価。** <RepositoryFact name="securityAssessWorkingDays" /> 営業日以内に問題を確認または却下し、深刻度を評価し、確認できた場合は修正を計画します。
3. **修正。** 修正は下の表のサポート対象のすべてのバージョンに入り、公開されるまで進捗をお知らせします。
4. **公開。** 修正が利用可能になったら、修正済みのバージョンを示す GitHub のセキュリティアドバイザリを公開し、報告者としてお名前を記載します。記載を望まない場合は記載しません。

確認された問題を公開する前に、修正のための十分な時間をください。

## サポート対象のバージョン [#supported-versions]

| バージョン                                                                                                                       | サポート |
| -------------------------------------------------------------------------------------------------------------------------------- | -------- |
| saasyland.com と `main`                                                                                                          | 対象     |
| サイトの最新の日付付きリリース                                                                                                   | 対象     |
| npm の <RepositoryFact name="cliReleaseChannel" /> タグにある `saasyland`、`create-saasyland`、`@saasyland/stack` の最新リリース | 対象     |
| それ以前のリリースとコミット                                                                                                     | 対象外   |

`main` へのマージは CI に通ると saasyland.com にデプロイされるため、修正はまずサイトに届きます（[CI/CD](/docs/tooling/ci-cd)）。CLI とそのパッケージは 1 つのバージョンでまとめてリリースされ、修正は npm の新しいリリースとして公開されます。どのリリースかは[リリースノート](/docs/cli/releases)に記載します。以前のリリースを使っている場合は、最新のリリースに更新して修正を受け取ってください。

## 対象範囲 [#scope]

対象: 顧客エリアと管理コンソールを含む saasyland.com、このリポジトリのコード、有料の CLI、ライセンスキーとアクティベーション、CLI が生成するコード。

対象外: Cloudflare、Polar、Resend などのサードパーティサービスの脆弱性（当方の設定が原因の場合を除く）、および影響が実証されていないスキャナーの出力。

## EU サイバーレジリエンス法 [#cyber-resilience-act]

SaaSy Land は、自社製品に影響する積極的に悪用されている脆弱性と重大なインシデントを、サイバーレジリエンス法（規則 (EU) 2024/2847）の定めに従い、EU の単一報告プラットフォーム（Single Reporting Platform）を通じて報告します。
