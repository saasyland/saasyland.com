---
title: "プロジェクトのスクリプト"
description: "日常的に使うコマンドです。"
---

| 作業                                                  | コマンド                 |
| ----------------------------------------------------- | ------------------------ |
| 開発サーバーを起動する                                | `bun run dev`            |
| フォーマット、リント、型、翻訳をチェックする          | `bun run check`          |
| すべての Vitest プロジェクトを実行する                | `bun run test`           |
| カバレッジのゲートを実行する                          | `bun run test:coverage`  |
| ブラウザーのスモークテストを実行する                  | `bun run test:e2e:smoke` |
| CI が実行する Chromium のブラウザースイートを実行する | `bun run test:e2e:pr`    |
| マイグレーションを生成する                            | `bun run db:generate`    |
| プレビュー用 Worker をビルドする                      | `bun run build`          |
| 最新のビルドを配信する                                | `bun run start`          |
| プレビューをデプロイする                              | `bun run deploy:preview` |

プルリクエストを作成する前に、[コントリビューション](/docs/project/contributing)の手順を実行してください。

```sh
bun run check
bun run test:coverage
bun run build:test
bun run test:e2e:pr
```

ローカルでは、`127.0.0.1:3000` ですでにサーバーが応答していない限り、Playwright が `db:reset:test` でテスト用データベースを作り直し、テスト用 Worker をビルドして起動します。

Vitest がプロジェクトのセットアップ込みで実行されるよう、`bun test` ではなく `bun run test` を使ってください。`db:migrate:preview` や `deploy:production` のように環境名で終わるスクリプトは、その環境だけに作用します。

完全な一覧は[プロジェクトのスクリプト](/docs/tooling/scripts)を参照してください。
