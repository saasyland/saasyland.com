## No admin

Não há tela de análise de dados. O [painel administrativo](/docs/features/admin-dashboard) mostra o que o D1 guarda: a receita das cópias dos pedidos do Polar, as novas contas, o progresso dos cursos e os assinantes da newsletter. Visualizações de página, visitantes, retenção e churn precisam de uma fonte de analytics que o app não tem, então nenhuma tela os mostra.

## O que é coletado

Nenhum script de analytics está instalado e nenhum evento é armazenado. O único script de terceiros é o pixel de indicação do Affonso, que só é carregado em uma visita cuja URL traz um parâmetro de indicação e só quando `AFFONSO_PROGRAM_ID` está definido e `AFFILIATE_PROGRAM` marca o programa como aberto ([Programa de afiliados](/docs/features/affiliates)). `wrangler.jsonc` ativa a `observability` dos Workers, então os logs do Worker, incluindo a saída de `console.error` das funções de servidor que falham, aparecem no painel da Cloudflare.
