- Додано: `bun run skills:update` переводить кожну навичку агентів із `skills-lock.json` на найновіший коміт її джерела, а `bun run skills:sync` тепер відновлює кожну навичку з коміту, записаного у файлі блокування, тож кожен комп'ютер отримує ті самі файли. Див. [Навички агентів](/docs/tooling/agent-skills).
- Додано: чотири навички агентів від Cloudflare, `workers-profiling`, `workers-development`, `frameworks-on-cloudflare` і `cf-cli`, для профілювання розгорнутих Workers, локального налагодження, запуску TanStack Start на Workers і роботи з CLI `cf`.
- Змінено: кожна навичка агентів має найновішу версію з джерела, зокрема навички Polar і Resend, а файл блокування більше не містить 33 навичок, які їхні джерела видалили, як-от навичок TanStack Table v9, що тепер увійшли до `table-features` і `table-state`.
- Виправлено: `bun run skills:sync` більше не зупиняється з `EEXIST`, коли CLI навичок уже зв'язала навичку в `.claude/skills` під назвою групи постачальника, як-от `cloudflare`.
