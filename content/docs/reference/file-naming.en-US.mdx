title: "File naming"

---

All files and folders use kebab-case.

## Source files

| Pattern                                                      | Meaning                                                                                              |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | File route; dots are path segments, `_` marks a pathless layout, `$` a splat, `index` an index route |
| `src/routes/api/<name>.ts`                                   | HTTP handler                                                                                         |
| `modules/<table>/<table>.schema.ts`                          | Drizzle table                                                                                        |
| `modules/<table>/<table>.zod.ts`                             | Zod schemas                                                                                          |
| `modules/<table>/<table>.constants.ts`                       | Query keys, mutation keys and enums                                                                  |
| `modules/<table>/<table>.types.ts`                           | Types derived from the table                                                                         |
| `modules/<table>/<table>.utils.ts`                           | Pure helpers for the table                                                                           |
| `modules/<table>/<table>.server.ts`                          | Server-only helpers for the module                                                                   |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | One use case                                                                                         |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | Vendor configuration or adapter, for example `auth.server.ts`                                        |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | Data table columns                                                                                   |
| `presentation/emails/<name>.tsx`                             | Email template exporting `<NAME>_NAMESPACE`                                                          |
| `hooks/use-<name>.ts`                                        | Shared React hook                                                                                    |
| `providers/<name>-provider.tsx`                              | Application provider                                                                                 |

## Tests

| Pattern                               | Runner                       |
| ------------------------------------- | ---------------------------- |
| `__test__/<file>.test.ts`             | Vitest `node` project        |
| `__test__/<file>.integration.test.ts` | Vitest `integration` project |
| `__test__/<file>.component.test.tsx`  | Vitest `component` project   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                   |

Test files are named after the source file they cover, for example `user.schema.test.ts` for `user.schema.ts`.

## Content and messages

| Pattern                                   | Meaning                                                     |
| ----------------------------------------- | ----------------------------------------------------------- |
| `messages/<locale>/<namespace>.json`      | Translation namespace, for example `pages.admin.users.json` |
| `content/docs/<path>/<page>.<locale>.mdx` | Documentation page                                          |
| `content/docs/<path>/meta.<locale>.json`  | Documentation navigation                                    |
| `content/blog/<slug>.<locale>.mdx`        | Blog post                                                   |
