`DataGrid`（`src/presentation/components/custom/data-grid.tsx`）はテーブルコンポーネントです。`src/integrations/tanstack-table/table.features.ts` の機能から TanStack Table v9 のインスタンスを作り、shadcn のテーブルプリミティブと React Aria のコントロールで描画します。ページが渡すのは列と、行またはクエリのどちらかだけです。ツールバーからページネーションのバーまで、それ以外はすべて内部にあります。

```tsx
<DataGrid
  columns={columns}
  empty={t("empty")}
  id={ORDER_GRID_ID}
  label={t("title")}
  query={(request) => getOrdersPageQuery(orderZodSchemas.getOrders.parse(request))}
  search={t("filters.search")}
  selectable
/>
```

## Props

| Prop               | 役割                                                                                                                      |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| `columns`          | ページの `<entity>-columns.tsx` の列セット。各行には行 ID として使う文字列の `id` が必要です                              |
| `id`               | グリッドの名前。ブラウザに保存するレイアウトのキーと、CSV ファイル名の先頭になります                                      |
| `label`            | テーブルのアクセシブルな名前。通常はページのタイトルです                                                                  |
| `data`             | メモリ上の行。クライアントで検索、絞り込み、並べ替え、ページ分割を行うグリッド用です                                      |
| `query`            | サーバーモード。グリッドのリクエストを受け取り、`{ rows, total }` に解決されるクエリオプションを返す関数です              |
| `search`           | 検索ボックスのラベルとプレースホルダー。指定しないとグリッドに検索はありません                                            |
| `empty`            | 行がなく、検索も絞り込みも設定されていない間にグリッドが表示する内容                                                      |
| `emptyDescription` | そのタイトルの下に表示する、最初の行がどう追加されるかを説明する一文                                                      |
| `selectable`       | チェックボックスの列と選択バーを追加します                                                                                |
| `bulkActions`      | 選択した行を受け取り、選択バーにボタンを追加で描画する関数                                                                |
| `rowActions`       | 各 `row` を受け取り、右に固定した列でその行の最後に ⋯ メニューを描画するコンポーネント                                    |
| `onReorder`        | 各行にハンドルを追加します。移動した行とその新しい位置を受け取って呼ばれます。[行の並び順](#row-order) を参照してください |

## 列

列セットは `custom/<area>/<entity>-columns.tsx` にあるフックで、`useOrderColumns` などです。自分の翻訳と、絞り込みが選択肢として示すデータを読み込み、列をメモ化して返します。そのため、どのラベルもただの文字列になり、グリッドはそれをメニュー、読み上げ、CSV のヘッダーに使えます。各セルは同じファイル内の小さなコンポーネントで、自分の翻訳を読み込みます。

```tsx
columnHelper.accessor("status", {
  cell: StatusCell,
  header: t("pages.admin.orders.table.headers.status"),
  meta: {
    export: ({ status }) => t(`pages.admin.orders.status.${status}`),
    filter: {
      kind: DATA_GRID_FILTER.MULTI_SELECT,
      options: ORDER_STATUSES.map((value) => ({ label: t(`pages.admin.orders.status.${value}`), value })),
    },
  },
  size: ORDER_COLUMN_SIZES.status,
})
```

グリッドが列から読み取るのは `meta` です。

| キー     | 効果                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `filter` | 列の絞り込み。その `kind` と、選択式の場合は `{ label, value }` 形式の `options` です                                                  |
| `hidden` | 管理者が「列」メニューから表示するまで非表示になります                                                                                 |
| `pinned` | 管理者が固定を解除するまで `start` または `end` に固定されます                                                                         |
| `export` | 行ごとに CSV が受け取るテキスト。指定しない場合、CSV は文字列と数値をそのまま、日付を ISO 形式の時刻として出力し、それ以外は空にします |
| `align`  | `end` はヘッダーとセルを右寄せにし、等幅の数字で表示します。金額や件数に使います                                                       |

`size` は列の初期幅（ピクセル）です。`enableSorting: false` を指定しない限り列は並べ替えられます。サーバーモードでは、モジュールの Zod スキーマが並べ替えに対応している列だけを並べ替え可能にしてください。

## 絞り込み [#filters]

絞り込みの種類は <RepositoryFact name="dataGridFilterKinds" /> です。それぞれに専用のエディターがあり、ツールバーの「絞り込み」ボタンか、絞り込みのチップから開きます。

| 種類          | エディター                                                                                         | 値                         |
| ------------- | -------------------------------------------------------------------------------------------------- | -------------------------- |
| `text`        | テキストフィールド。入力が <RepositoryFact name="dataGridTypingDelayMs" /> ms 止まると適用されます | 前後の空白を除いたテキスト |
| `select`      | 選択肢のリスト。選択中のものをもう一度選ぶと解除されます                                           | 1 つの `value`             |
| `multiSelect` | 選択肢のリストで、複数を同時に選べます。長いリストには検索フィールドが付きます                     | `value` の配列             |
| `numberRange` | 最小と最大の 2 つの数値フィールド。どちらも空のままにできます                                      | `{ min?, max? }`           |
| `dateRange`   | 過去7日間、過去30日間、過去12か月、またはカレンダー上の任意の日                                    | ms 単位の `{ from?, to? }` |

日は管理者のタイムゾーンで時刻に変換され、最初の日の始まりから最後の日の最後のミリ秒までになります。そのため、サーバーは単純な時刻どうしを比較します。有効な絞り込みはそれぞれ、設定した時点でツールバーの「絞り込み」ボタンの横にチップとして表示されるため、絞り込みを開いたままでもチップと結果が変わります。チップには、40以上、支払い済みまたは返金済み、3件を選択のような短い要約が付きます。チップの × でその絞り込みを外し、「絞り込みを解除」ですべてを外します。検索、絞り込み、並べ替えを変更すると最初のページに戻り、選択は解除されます。

## サーバーモード

`query` を指定すると、グリッドはページ分割、並べ替え、検索、絞り込みをサーバーで行います。`query` は次の引数で呼ばれます。

```ts
interface DataGridRequest {
  readonly filters: Readonly<Record<string, unknown>>
  readonly pageIndex: number
  readonly pageSize: number
  readonly search: string
  readonly sorting: SortingState
}
```

`filters` には、絞り込んだ各列の id とその値が入ります。ルートはサーバー関数に届く前にモジュールの Zod スキーマでリクエストを検証します。`/admin/orders` では `orderZodSchemas.getOrders.parse(request)` がそれにあたります。最初のページが届くまで、グリッドはスケルトン行を表示します。2 ページ目以降の読み込み中は前の行を薄く表示したまま残し、テーブルを処理中としてマークし、ページ送りを無効にします。クエリのエラーはルートのエラーバウンダリへ渡されます。

## レイアウト

管理者がグリッドを並べ替えると、ブラウザはグリッドの `id` をキーにして `localStorage`（`src/hooks/use-data-grid-preferences.ts`）に保存します。保存するのは、表示する列、その順序、固定する列、列の幅、行の密度、ページサイズです。検索、絞り込み、並べ替え、選択は保存しません。「レイアウトをリセット」で既定値に戻ります。ブラウザがストレージを拒否した場合、レイアウトはその訪問の間だけ保たれます。

- **「列」メニュー。** 非表示にできるすべての列の表示と非表示を切り替えます。
- **列メニュー。** 各ヘッダーの ⋮ ボタンで、昇順または降順に並べ替える、並べ替えを解除する、列を左または右に固定する、固定を解除する、同じ側の中で 1 つ左または右へ移動する、非表示にする、の操作ができます。
- **ドラッグ。** ヘッダーを同じ側の別のヘッダーにドラッグすると、その位置に入ります。
- **サイズ変更。** ヘッダーの端をドラッグすると幅が変わります。端は区切りでもあり、矢印キーで広げたり狭めたりでき、ダブルクリックで初期幅に戻ります。
- **並べ替え。** ヘッダーを押すとその列で並べ替えます。Shift を押しながらだと、その列を並べ替えに追加します。最大 <RepositoryFact name="dataGridMaxSortedColumns" /> 列まで追加でき、ヘッダーに番号が付きます。
- **密度。** ゆったりした行か詰めた行です。
- **ページサイズ。** 1 ページあたり <RepositoryFact name="dataGridPageSizes" /> 行です。

グリッドは 1 枚のカードです。上にツールバー、次にテーブル、下にページネーションがあり、細い線で区切られています。ツールバーは 2 行で、1 行目に検索と表示の操作、その下の 2 行目に絞り込みボタンと有効なフィルターのチップが並びます。ツールバーのコントロールと絞り込みのチップはすべて同じ高さです。ヘッダーは文頭だけを大文字にし、控えめな色の帯の上に spec サイズで表示します。セルは body サイズです。最後のデータ列は残りの幅をすべて使い、アクション列は自分の幅を保ちます。グリッドのどのリストでも、ポインターの下にある選択肢は、キーボードで選んでいる選択肢と同じように強調表示されます。検索欄はツールバーの空き幅いっぱいに広がるため、プレースホルダーが途切れることはありません。ヘッダーは 1 行に収まり、単語の途中で改行されることはありません。各列の初期幅は、どのロケールでも並べ替えの矢印と列メニューを含めてヘッダーが収まる幅になっており、管理画面のどのグリッドでもヘッダーのラベルがセルからはみ出すと `e2e/specs/text-layout.spec.ts` が失敗します。グリッドの幅が 64rem 未満のときは、「列」「CSVを書き出す」「レイアウトをリセット」をアイコンだけで表示し、検索欄の幅を確保します。

行がグリッド内でスクロールしてもヘッダー行は表示されたままで、グリッドが横にスクロールしても固定した列は表示されたままです。スマートフォンでは幅の広いテーブルをこのように表示します。見えていない列がある側と、ほかの列が下を通り過ぎ始めた固定列の端に影が付き、グリッドがスクロールできることを示します（`globals.css` の `.grid-scroller`）。

行アクションの列は幅 <RepositoryFact name="dataGridActionsSize" /> ピクセルで、⋯ ボタンを 1 つだけ持ちます。このボタン `RowMenu`（`src/presentation/components/custom/row-menu.tsx`）は、行のアクションをメニューとして開きます。日常的な操作が先に並び、区切り線の後に破壊的な操作が続きます。破壊的な操作はアラートダイアログで確認を求めます。管理画面のすべてのグリッドと、カリキュラムのように並び順を変更できるすべてのリストは、行の末尾をこのボタンで終え、アイコンを並べることはありません。この列には列メニューがありません。並べ替え、非表示、移動、サイズ変更はできず、CSV にも含まれず、常に右端の最後の列になります。

## 行の並び順 [#row-order]

`onReorder` を指定すると、グリッドの先頭に細いハンドルの列が加わります。チェックボックスがある場合は、その後ろに置かれます。ハンドルは控えめな色のグリップアイコンです。

- **ドラッグ。** ハンドルでドラッグした行は、ポインターが通過するほかの行の間を移動し、ドロップすると新しい位置が保存されます。Escape を押すか、行の外にドロップすると元に戻ります。
- **キーボード。** ハンドルにフォーカスがあるとき、上下の矢印キーで行を 1 つずつ移動します。ページの最初または最後の行を越えて移動すると、行の移動先のページが開き、そこで行のハンドルにフォーカスが移ります。
- **保存。** `onReorder` は、行と、保存された並び順全体での新しい位置を受け取ります。位置はページをまたいで 1 から数えるため、サーバーは行をどこにでも置けます。新しい並び順はすぐに表示され、移動が 1 つずつ保存されている間も、更新された行が届くまでそのまま保たれます。`onReorder` が返す Promise が拒否されると、行は元に戻ります。`/admin/courses` は `moveCourse` を、`scope` を指定したミューテーションで渡すため、移動は行われた順に保存されます。
- **無効になるとき。** 行を並べ替え、絞り込み、検索している間は、画面上の行の位置が保存された並び順での位置と一致しないため、ハンドルは無効になります。

移動するたびに、ライブリージョンで「12件中3番目に移動しました。」のように読み上げられます。

## 選択と書き出し

`selectable` を指定すると、チェックボックスで行を選択でき、ヘッダーのチェックボックスでページ全体を選択できます。するとウィンドウの下部にバーが浮かび、選択数、「選択した行を書き出す」、ページの `bulkActions`、「選択を解除」が表示されます。レコードを一覧表示する管理画面のグリッドは、コース、商品、カテゴリーとコレクション、注文、顧客、ユーザー、招待、ライセンスのない注文のすべてで選択できます。選択できないのはダッシュボードの集計表だけです。`/admin/courses` には、選択したコースに対する **削除** が加わります。ほかのグリッドでは選択した行を書き出せます。それらのレコードには、複数件にまとめて適用できる操作がないためです。

「CSVを書き出す」は、画面上のページだけでなく、検索と絞り込みに一致するすべての行をダウンロードします。サーバーでは、すべての行がそろうまで <RepositoryFact name="dataGridExportPageSize" /> 行ずつページを要求します。ファイルには表示中の列がその順序で入り、スプレッドシートが UTF-8 として読めるようにバイトオーダーマークで始まり、数式として始まってしまうセルの前には `'` を付けます。書き出すのは `src/lib/csv.ts` です。

## アクセシビリティ

- テーブルは `label` を名前として持ち、`aria-rowcount` を持ちます。各行は、ページをまたいで数えた `aria-rowindex` を持ちます。
- 並べ替え可能なヘッダーはボタンで、`aria-sort` を持ちます。
- すべてのコントロールはキーボードで操作できます。メニューとリストは React Aria の矢印キーとタイプアヘッドに従い、Escape で閉じます。サイズ変更はヘッダーの区切りで矢印キーを使い、行はそのハンドルで上下の矢印キーを押して移動します。ハンドルの名前は「ドラッグするか矢印キーで順番を変更」です。
- 列や行の移動、固定、非表示、メニューからの並べ替え、レイアウトのリセットは polite なライブリージョンで読み上げられます。結果の件数と選択数もライブで読み上げられます。

## 翻訳

グリッド自身の文言は `messages/<locale>/components.custom.data-grid.json` にあります。ページが渡すのは、列のラベル、絞り込みの選択肢、検索のラベル、空のときのメッセージだけです。
