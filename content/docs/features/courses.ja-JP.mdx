コース、チュートリアル、プロジェクトは D1 に保存され、`/courses` で視聴します。各レッスンは[動画](/docs/features/videos)のライブラリにある動画を再生し、レッスンのアクセスレベルによって誰が視聴できるかが決まります。

## データモデル

各テーブルは `src/modules` に専用のモジュールを持ち、マイグレーション `20261113004409_salty_slipstream.sql` で作成されます。

| テーブル          | 列                                                                                                                                                  |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `course`          | `slug`（一意）、`kind`（`course`、`tutorial`、`project`）、`status`（`draft`、`published`）、`position`、`title`、`summary`                         |
| `chapter`         | `course_id`、`position`、`title`                                                                                                                    |
| `lesson`          | `course_id`、`chapter_id`、`slug`（コース内で一意）、`access`（`preview`、`account`、`paid`）、`status`、`position`、`title`、`summary`、`video_id` |
| `lesson_progress` | `user_id` と `lesson_id`（主キー）、`position_ms`、`completed_at`                                                                                   |

- `title` と `summary` は、`{"en-US": "Billing", "pl-PL": "Płatności"}` のようにロケールをキーとする JSON を保持します（`src/modules/_core/utils/localized-text.ts` の `LocalizedText`）。`localize()` は訪問者のロケールの値を返し、ない場合は `en-US` にフォールバックするため、`en-US` は必ず入力してください。管理画面では入力が必須ですが、D1 に直接挿入した行はチェックされません。
- 新しい行は `draft`、新しいレッスンは `paid` になります。一覧表示や配信の対象になるのは `published` のコースとレッスンだけで、それ以外のスラッグでは Not Found ページが表示されます。
- コースは `position` 順、チャプターはコース内の `position` 順、レッスンはチャプター内の `position` 順に並びます。レッスン番号はコース全体を通して振られます。
- `video_id` は `video` テーブルを参照し、動画が削除されると `NULL` になります。コースやチャプターを削除するとそのレッスンが削除され、レッスンやユーザーを削除するとその進捗が削除されます。

## アクセスレベル

| `access`  | 視聴できる人                                                                                       |
| --------- | -------------------------------------------------------------------------------------------------- |
| `preview` | サインインの有無を問わず全員                                                                       |
| `account` | サインインしているすべてのユーザー                                                                 |
| `paid`    | ティア `complete` または `agency` の `active` なライセンスを持つユーザー（`COURSE_LICENCE_TIERS`） |

`course: ["read"]` を持つロール（管理者が該当）は、すべてのレッスンを視聴できます。判定は `hasLessonAccess`（`src/modules/lesson/lesson.access.ts`）が行い、その対象となる視聴者は `resolveViewer`（`lesson.viewer.ts`）がセッション、ロール、`getLicense` から組み立てます。この判定はページだけでなく、コースのコンテンツを返すすべてのサーバー関数で行われます。

- `getCatalogue`（公開）は、公開済みのコースを、レッスン数、動画の合計時間、無料プレビューの数とともに返します。
- `getCourseShowcase`（公開）は、ランディングページ用に、公開済みの最初の 2 つのコース（`COURSE_SHOWCASE`）をレッスン数、動画の合計時間、無料プレビューの数、公開済みの最初の 6 レッスンとともに返し、動画のある最初の無料プレビューも返します。返すのは各レッスンのアクセスレベルで、視聴者ごとのロック状態ではありません。
- `getCourse`（公開）は、公開済みのコースを、そのチャプターと公開済みのレッスンとともに訪問者のロケールで返します。各レッスンには視聴者ごとの `locked`、`completed`、`positionMs` が付きます。
- `getLessonPlayback`（公開）は、`createPlayback` による署名付きの再生パスを返します。レッスンを視聴できない場合、ゲストには `UNAUTHORIZED`、サインイン済みのユーザーには `FORBIDDEN` を返し、未公開のレッスンや動画のないレッスンには `NOT_FOUND` を返します。
- `saveLessonProgress` はセッションを必要とし、書き込む前に同じアクセス判定を行います。

## ページ

`/courses` レイアウト（`courses.tsx`）は独自のナビゲーションを持ち、ラベルは `pages.courses` 名前空間にあります。これらのページは視聴者ごとに D1 を読むため、プリレンダリングされません。`ROUTES.COURSES` は `vite.config.ts` の `UNLISTED_ROUTES` に含まれています。

- `/courses`: 公開済みのコースごとに 1 枚のカードを表示し、種類、レッスン数、分数、無料レッスンの数を示します。
- `/courses/<course>`: 概要、サインイン済みの視聴者向けの進捗バー、次に視聴するレッスンへの **講座を始める** または **…の続きから** のリンク、チャプターごとのカリキュラムを表示します。カリキュラムには **無料プレビュー** バッジ、再生時間、鍵と完了のアイコンが付きます。ロックされたレッスンがある場合は、**すべてのレッスンがCompleteに含まれます** パネルが料金セクションに、サインイン済みの視聴者には Complete があらかじめ選択された `/app/license?tier=complete` にリンクします。
- `/courses/<course>/<lesson>`: プレーヤー、またはロックのパネルを表示します。パネルには、サインイン後に `redirect` でレッスンに戻る **サインインして視聴** か、**Completeを入手** が表示されます。動画のないレッスンでは、録画が近日公開であることを示します。その下にアクセスレベル、サインイン済みの視聴者向けの **完了にする**、前後のレッスンへのリンクが並び、広い画面ではコースの内容が横に表示され続けます。

## ランディングページ

ランディングページの **ツールキット** セクションにあるコースブロック（`src/presentation/components/custom/landing-page/components/` の `course-showcase.tsx`）は D1 の内容を表示するため、存在しないコースやレッスンを載せることはありません。

- ランディングページはプリレンダリングされるため、HTML に含まれるのはブロックの見出し、講座ページの紹介動画、プレースホルダーです。ブロックが表示領域まで画面 1 つ分以内に近づくと、ブラウザが `courseShowcaseQuery` を通じて `getCourseShowcase` を一度だけ呼び出し、ブロックを埋めます。そこまでスクロールしない訪問者はリクエストを送りません。
- 各コースには種類、レッスン数、分数、無料レッスンの数が表示され、その下に最初のレッスンがアクセスレベルとともに並びます。どのコースとレッスンもそれぞれのページにリンクし、レッスンがさらにあるコースの最後にはすべてのレッスンへのリンクがあります。
- **無料レッスンを見る** は、動画のある最初の無料プレビューを開きます。該当するレッスンがなければ、このリンクは表示されません。
- 公開済みのコースがない場合はその旨を表示し、リクエストが失敗した場合は講座一覧へ案内します。**すべての講座を見る** はどの場合も `/courses` にリンクします。
- 講座ページの紹介動画は、`remotion/` プロジェクトの `course-tour` コンポジションです。AVIF と WebP のポスターを持つ静的ファイルとして `src/presentation/assets/motion/` に置かれ、押すとその場でブラウザのコントロール付きで再生されます。動画ライブラリは使いません。

## 進捗

サインイン済みの視聴者の場合、プレーヤーは保存された `position_ms` から再生を始め、`useLessonProgress`（`src/hooks/use-lesson-progress.ts`）が再生中に最大 15 秒ごとに位置を保存します。これには `VideoPlayer` の `startAt` と `onProgress` プロパティを使います。動画が最後まで再生されたとき（`onEnded`）や、視聴者が **完了にする** を押したときは、`completed_at` が設定され、保存された位置が先頭に戻り、コースページの進捗が更新されます。一度設定された `completed_at` は保持されます。ゲストも無料プレビューを視聴できますが、何も保存されません。

## レッスンと動画

レッスンは自身の動画ファイルを持ちません。録画は `bun run video:publish:<environment>` で公開し（[動画](/docs/features/videos)を参照）、管理画面のレッスンの **動画** フィールドで選択すると `video_id` が設定されます。複数のレッスンで同じ動画を使えます。カタログとカリキュラムの再生時間は `video.duration_ms` から取得します。

## コースを管理する

管理画面のサイドバーの **コンテンツ → コース** からコースの画面を開きます。そのレイアウト `admin.courses.tsx` は `course.validations` と `pages.admin.courses` の名前空間をプリロードし、`/admin` 配下のすべてのページと同じく `admin: ["access"]` を必要とします。コンポーネントは `src/presentation/components/custom/admin/courses/` にあります。

- `/admin/courses`（`admin.courses.index.tsx`）は、下書きを含むすべてのコースを `position` 順に一覧表示します。表示するのは、タイトルと `/courses/<slug>` のパス、種類、状態、レッスン数、最終更新日です。各行には、コースを上下に移動する矢印、編集リンク、削除ボタンがあります。**新しいコース** でフォームを開きます。
- `/admin/courses/create`（`admin.courses.create.tsx`）は空のコースフォームを表示します。**コースを作成** でコースを保存し、そのエディターを開きます。
- `/admin/courses/<courseId>`（`admin.courses.$courseId.tsx`）は、**詳細を保存** を備えたコースフォーム、**カリキュラム**、**コースを表示** を表示します。**コースを表示** は `/courses/<slug>` を新しいタブで開きます。下書きは公開されないため、**コースを表示** はコースを公開してから表示されます。

新しいコースはほかのコースの後ろに追加されます。一覧の矢印で公開カタログの並び順を決めます（`moveCourse`）。

### コースの詳細

コースフォーム（`course-form.tsx`）には次のフィールドがあります。

- **タイトル** と **概要**。ロケールごとにタブがあります。`en-US` のタブは必須で、空のままのロケールは英語にフォールバックします。
- **URLスラッグ**: 小文字、数字、単独のハイフンのみ、最大 96 文字で、コース全体で一意です。
- **種類**: **コース**、**チュートリアル**、**プロジェクト** のいずれか。
- **状態**: 既定の **下書き** または **公開**。`/courses` に表示されるのは公開済みのコースだけです。

### カリキュラム

カリキュラムエディター（`curriculum-editor.tsx`）は、チャプターを順に表示し、それぞれのレッスンを並べます。

- **章を追加** は `chapter-dialog.tsx` を開き、ロケールごとに **章のタイトル** を入力します。各チャプターには、上下に移動する、タイトルを編集する、削除するためのボタンがあります。
- チャプターのレッスンの下にある **レッスンを追加** は `lesson-dialog.tsx` を開きます。レッスンの編集にも同じダイアログを使います。
- 各レッスンには、スラッグ、動画と再生時間（ない場合は **動画なし**）、アクセスレベル、状態が表示され、チャプター内で上下に移動する、編集する、削除するためのボタンがあります。レッスンを別のチャプターに移動することはできません。

レッスンのダイアログには次のフィールドがあります。

- **レッスンのタイトル** と **概要**。ロケールごとにタブがあり、`en-US` は必須です。
- **URLスラッグ**。コース内で一意です。
- **視聴できる人**: **誰でも（無料プレビュー）**（`preview`）、**サインイン済みの訪問者**（`account`）、または既定の **CompleteとAgencyのライセンス**（`paid`）。
- **状態**: 既定の **下書き** または **公開**。
- **動画**: ライブラリで最近公開された 100 本の動画と、その再生時間。**動画はまだありません** を選ぶと、レッスンに動画を設定しないか、設定済みの動画を外します。

### 削除

削除はどれも、実行前に確認を求めます。

- コースを削除すると、そのチャプター、レッスン、およびそれらに対する全ユーザーの進捗が削除されます。
- チャプターを削除すると、そのレッスンとその進捗が削除されます。
- レッスンを削除すると、その進捗が削除されます。

これは外部キーの `ON DELETE CASCADE` によって行われます。コース、チャプター、レッスンと一緒に動画が削除されることはなく、動画はライブラリに残ります。

### サーバー関数

| モジュール | ユースケース                                                     | 権限                 |
| ---------- | ---------------------------------------------------------------- | -------------------- |
| `course`   | `getCourses`, `getCourseEditor`                                  | `course: ["read"]`   |
| `course`   | `createCourse`                                                   | `course: ["create"]` |
| `course`   | `updateCourse`, `moveCourse`                                     | `course: ["update"]` |
| `course`   | `deleteCourse`                                                   | `course: ["delete"]` |
| `chapter`  | `createChapter`, `updateChapter`, `deleteChapter`, `moveChapter` | `course: ["update"]` |
| `lesson`   | `createLesson`, `updateLesson`, `deleteLesson`, `moveLesson`     | `course: ["update"]` |

- レッスンのダイアログの動画一覧は `getVideos` から取得し、これには `video: ["read"]` が必要です。
- すでに使われているスラッグには `CONFLICT` を返します。`rethrowAsConflict`（`src/integrations/drizzle-orm/drizzle.errors.ts`）が D1 の一意制約エラーを `AppError` に変換します。どの行にも一致しない ID には `NOT_FOUND` を返します。
- 新しいコース、チャプター、レッスンは、同じ階層の行の中で最大の `position` に 1 を足した値を取ります（`nextPosition`）。移動では行を隣の行と入れ替え、同じ階層の行を 1 から番号付けし直します（`reorder`）。これは 1 回の `db.batch` で行います。どちらの関数も `src/modules/_core/utils/ordering.ts` にあり、方向は `src/modules/_core/constants/ordering.ts` の `MOVE_DIRECTION` です。
- すべての書き込みで、タイトルと概要を `localizedTextSchema` で検証します。`en-US` は必須で、各テキストは最大 2,000 文字です。スラッグは最大 96 文字です。フォームのメッセージは `course.validations` の `defaultLocaleRequired`、`textTooLong`、`slugInvalid`、`slugTooLong` で、上限値は `COURSE_VALIDATION_PARAMS`（`course.constants.ts`）が渡します。
- `courseEditorQuery` は公開側のコースのクエリと同じく `staleTime: COURSE_STALE_MS` を保ち、変更のたびに `course` のクエリが無効化されるため、一覧とエディターが再取得されます。

## テスト

`scripts/seed-test.ts` は、`e2e/specs/courses.spec.ts` のブラウザテスト用に、1 つのチャプターと 4 つのレッスンを持つ公開済みのコースを投入します。`e2e/specs/course-admin.spec.ts` では、管理者がコース、チャプター、シード済みの動画を使う無料レッスンを作成し、別のブラウザページの訪問者がそのレッスンを視聴し、最後に管理者がコースを削除します。`e2e/specs/landing.spec.ts` は、ランディングページがシード済みのコースとそのレッスンにリンクし、無料レッスンを開き、講座ページの紹介動画を再生できることを確認します。
