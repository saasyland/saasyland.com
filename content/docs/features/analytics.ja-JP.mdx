## 管理画面（デモ）

`/admin/analytics` は 5 つのタブ（`overview`、`revenue`、`audience`、`retention`、`reports`）を表示しますが、内容があるのは **概要** だけです。

- `AnalyticsKpis` と `AnalyticsRevenueChart` はそれぞれのファイル内の定数を表示します。
- `RegionsAndUpgrades` は `src/data/admin.ts` の `ADMIN_ANALYTICS_REGION_ROWS` と `ADMIN_ANALYTICS_UPGRADE_ROWS` を表示します。
- 日付選択ボタンは未接続です。

ダッシュボードの売上グラフも静的な SVG です。

## 収集されるもの

アナリティクスやトラッキングのスクリプトはインストールされておらず、イベントも保存されません。`wrangler.jsonc` で Workers の `observability` が有効になっているため、失敗したサーバー関数の `console.error` 出力を含む Worker のログを Cloudflare ダッシュボードで確認できます。
