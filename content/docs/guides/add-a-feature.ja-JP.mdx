独自のモジュールのスキーマ、バリデーション、定数、使用例を作成または拡張します。 下のフラットなルートを追加します。 `src/routes` パーミッションガード、検証済みの検索パラメータ、メタデータ、ネームスペースのプリロード。 機能 UI を配置します。 `presentation/components/custom/{feature}` 近くのコンポーネント、ホックおよび定数を使って。

独立したデータクエリを loader で読み込み、同じ QueryClient キャッシュからレンダーし、ネイティブのミューテーションオプションで送信します。 すべての9つの構成された言語のキーを一緒に加えて下さい。 既存のレイアウトとアクセス可能なプリミティブを保持し、使用例、コンポーネント、ブラウザの動作を適切なレベルで確認します。
