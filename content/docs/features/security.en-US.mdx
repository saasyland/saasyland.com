## Implemented

- **Sessions**: Better Auth sessions in D1, cookie prefix `saasyland`, secure cookies outside local modes, allowed hosts per mode, and `cf-connecting-ip` as the client address. The client session never contains the token.
- **Accounts**: required email verification, sessions revoked on password reset, optional TOTP with backup codes, verification identifiers stored hashed and OAuth tokens encrypted.
- **Authorization**: `requireSignedIn` and `requireAdmin` on routes; `authorized(permission)` on server functions with the roles from `auth.access.ts`.
- **Rate limits**: the Better Auth limiter and the `withRateLimit` middleware share the D1 `rate_limit` table. `RATE_LIMITS.SENSITIVE` allows 3 calls and `RATE_LIMITS.TOKEN` 5 calls per 60 seconds per client and action.
- **Errors**: the request middleware turns failures into `AppError` codes (`src/modules/_core/constants/errors.ts`), so clients never receive raw server messages; components show them with `useErrorMessage`.
- **Webhooks and forms**: Polar webhooks are verified with `POLAR_WEBHOOK_SECRET`; newsletter requests are accepted only from known hosts over HTTPS (`newsletterRequestOrigin`).
- **Headers**: every response carries `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`, `Cross-Origin-Opener-Policy: same-origin`, a `Permissions-Policy` that turns off camera, microphone, geolocation and topics, and a Content Security Policy that blocks framing, `<base>` changes and plugins. HTTPS responses add `Strict-Transport-Security`. The Worker sets them in `src/server.ts` unless the response already has its own, and `public/_headers` gives static files the same.

## Not implemented

- A Content Security Policy that restricts scripts and styles: prerendered pages would need a hash for every inline script on every page.
- An audit log, including for bans, deletions and impersonation.
- Bot protection or CAPTCHA on public forms.
- An impersonation screen ([Impersonation](/docs/features/impersonation)).
