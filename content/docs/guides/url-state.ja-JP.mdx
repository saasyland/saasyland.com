title: URL の状態
description: URL の状態 — SaaSy Land
---

ルートの検索スキーマを定義する `validateSearch`, それを読んで下さい `Route.useSearch`TanStack Router ナビゲーションで更新します。 必要に応じてURLにブックマーク可能なフィルタ、タブ、ソート、ペジネーションを保存します。 コンポーネントのみの state は React にとどまります。

ローカル URL は、ネイティブ ルーターのリンクに適用します。 利用条件 `localizePathname` OAuth のコールバックとメールリンクを含む手動で URL を生成します。 外部リンクやAPIパスにロケールを送らないでください。 言語切り替え時にクエリとフラグメントを保存します。
