## レイアウト

`src/routes/app.tsx` は `requireSignedIn` でこの領域を保護し、名前空間をプリロードします。

```tsx
const NAMESPACES = ["auth.errors", "pages.app", "pages.license"] as const

export const Route = createFileRoute("/app")({
  beforeLoad: requireSignedIn,
  component: AppLayout,
  loader: ({ context }) => preloadNamespaces({ locale: getCurrentLocale(), namespaces: NAMESPACES, queryClient: context.queryClient }),
  staticData: { namespaces: NAMESPACES },
})
```

`AppLayout` は shadcn の `SidebarProvider` の中に、`src/presentation/components/custom/app` の `AppSidebar` と `AppHeader` を表示します。サイドバーは `src/data/app.ts` の `APP_NAVIGATION` からリンクを作り、ルートコンテキスト（`getRouteApi("/app")`）からユーザーを読み取り、最後に `SignOutButton` を置きます。ヘッダーは現在のページとサイトへ戻るリンクを表示します。サインイン後、管理者は `/admin` に、それ以外のユーザーは `/app` に移動します。

## ページ

| ルート         | 内容                                                                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/app`         | ライセンスがなければ `CheckoutOptions`、あれば `LicenseStatusCard`（プラン、ステータス、ライセンスページへのリンク）。ドキュメントとメールサポートへのリンク。                |
| `/app/license` | ライセンスがなければ `CheckoutOptions`、あれば `LicenseCard`（キー、インストールコマンド、カスタマーポータルへのリンク）と、Polar がキーを発行した後は `LicenseActivations`。 |

どちらのローダーも `currentLicenseQuery` をプリロードし、`/app/license` は `licenseActivationsQuery` もプリロードします。購入、Webhook、ライセンスの状態は[決済とライセンス](/docs/features/payments)で説明しています。

`/app` には請求履歴、アカウント設定、コースの画面はありません。
