## Layout

`src/routes/app.tsx` chroni obszar za pomocą `requireSignedIn` i wstępnie ładuje jego przestrzenie nazw:

```tsx
const NAMESPACES = ["auth.errors", "pages.app", "pages.license"] as const

export const Route = createFileRoute("/app")({
  beforeLoad: requireSignedIn,
  component: AppLayout,
  loader: ({ context }) => preloadNamespaces({ locale: getCurrentLocale(), namespaces: NAMESPACES, queryClient: context.queryClient }),
  staticData: { namespaces: NAMESPACES },
})
```

`AppLayout` wyświetla `AppSidebar` i `AppHeader` z `src/presentation/components/custom/app` wewnątrz `SidebarProvider` z shadcn. Pasek boczny buduje linki z `APP_NAVIGATION` w `src/data/app.ts`, odczytuje użytkownika z kontekstu trasy (`getRouteApi("/app")`) i kończy się przyciskiem `SignOutButton`. Nagłówek pokazuje bieżącą stronę i link powrotny do witryny. Po zalogowaniu administratorzy trafiają do `/admin`, a pozostali do `/app`.

## Strony

| Trasa          | Zawartość                                                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/app`         | `CheckoutOptions` bez licencji, w przeciwnym razie `LicenseStatusCard` (plan, status i link do strony licencji); linki do dokumentacji i do pomocy przez e-mail.          |
| `/app/license` | `CheckoutOptions` bez licencji, w przeciwnym razie `LicenseCard` (klucz, polecenie instalacji, link do portalu klienta) oraz, gdy Polar wyda klucz, `LicenseActivations`. |

Oba loadery wstępnie ładują `currentLicenseQuery`; `/app/license` ładuje też `licenseActivationsQuery`. Płatności, webhooki i stany licencji opisuje strona [Płatności i licencje](/docs/features/payments).

W `/app` nie ma historii rozliczeń, ustawień konta ani ekranów kursów.
