新しいテーブルはすべて、`src/presentation/components/custom/data-grid.tsx` の `DataGrid` で描画されます（[データグリッド](/docs/ui/data-grid)）。その土台となる TanStack Table v9 の設定は `src/integrations/tanstack-table/` にあります。

| ファイル            | 内容                                                                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `table.features.ts` | `tableFeatures` のレジストリである `dataGridFeatures`、絞り込みの種類とその絞り込み関数、密度と固定の値、グリッドが読み取る `ColumnMeta` |
| `table.columns.ts`  | カラムのヘルパー。`meta` からの既定の表示状態と固定、カラムのラベル、固定したカラムの sticky オフセット、並べ替え、CSV の値              |

## 機能

`dataGridFeatures` は、カラムの絞り込み、順序、固定、サイズ、サイズ変更、表示状態、グローバルフィルター、ページネーション、行選択、ソートを、絞り込み済み、ソート済み、ページ分割済みの行モデルとともに登録します。`query` を持つグリッドは `manualFiltering`、`manualPagination`、`manualSorting` を設定するため、これらの行モデルが動くのは `data` を持つグリッドだけです。

## 絞り込み関数

絞り込みの種類はそれぞれ `DATA_GRID_FILTER_FNS` に登録された 1 つの関数に対応し、グリッドは `meta.filter` を宣言したすべてのカラムにその関数を割り当てます。

| 種類          | 関数             |
| ------------- | ---------------- |
| `text`        | `includesString` |
| `select`      | `equalsString`   |
| `multiSelect` | `arrHas`         |
| `numberRange` | `numberInRange`  |
| `dateRange`   | `dateInRange`    |

`numberInRange` と `dateInRange` は、グリッドのエディターが書き込む `{ min?, max? }` と `{ from?, to? }` の値のために `constructFilterFn` で作られており、どちらの境界も持たない範囲は無視します。同じ形が `src/modules/_core/utils/zod-fields.ts` の `numberRangeField` と `dateRangeField` で、モジュールの Zod スキーマはこれを使ってグリッドのリクエストを読み取ります。

## 状態

グリッドは、使う状態のすべてを自分で制御します。ページネーション、ソート、カラムの絞り込み、検索、選択はコンポーネントの state に置かれ、検索、絞り込み、ソート、ページのいずれかが変わると最初のページと空の選択に戻ります。カラムの表示状態、順序、固定、サイズは、密度とページサイズとともに `useDataGridPreferences`（`src/hooks/use-data-grid-preferences.ts`）から取得されます。このフックは `useSyncExternalStore` を通じて `localStorage` に読み書きし、サーバーでは既定値をレンダリングします。
