title: "Acerca de"
description: "Qué es el código base de SaaSy Land y a quién va dirigido."
---

SaaSy Land 2.0 es el código fuente del sitio web saasyland.com, de su espacio de trabajo para clientes y de su consola de administración. Una única aplicación TanStack Start en Cloudflare Workers reúne un sitio de marketing multilingüe, documentación y blog, autenticación, suscripciones a la newsletter y checkout de Polar con gestión de claves de licencia.

El código está escrito como un producto real: módulos por tabla de la base de datos, funciones de servidor tipadas con su propia autorización, un espacio de nombres de traducción por página, un 100 % de cobertura de pruebas y pruebas en el navegador en la CI. Está pensado para desarrolladores que quieran estudiar o reutilizar una configuración de producción de autenticación, administración, internacionalización e infraestructura de Cloudflare.

Los usuarios, las sesiones, los productos y las categorías se almacenan en D1. Las pantallas de analítica, pagos, administración del blog, invitaciones y roles todavía muestran datos de demostración de `src/data/`.

La CLI de SaaSy Land y sus plantillas de generación privadas son un producto propietario independiente y no forman parte de este código base. Consulte [Licencia](/docs/project/license).
