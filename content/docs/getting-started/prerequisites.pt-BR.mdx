## Ferramentas

| Ferramenta | Versão                                                | Motivo                                                                                                    |
| ---------- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Bun        | <RepositoryFact name="bunVersion" />                  | Gerenciador de pacotes e executor de scripts; `packageManager` no `package.json` e a CI fixam essa versão |
| Node.js    | <RepositoryFact name="nodeVersion" /> ou mais recente | A versão em `.nvmrc`, lida pelo `nvm use` e pela CI. O banco de dados de testes usa `node:sqlite`         |
| Git        | Qualquer versão recente                               | A etapa de instalação configura os hooks do Git                                                           |

Wrangler, drizzle-kit, Playwright e a CLI do Vite+ são dependências de desenvolvimento; execute-os pelos scripts do pacote ou com `bunx`. Os testes no navegador também precisam dos navegadores do Playwright, instalados com `bun run test:e2e:install`.

## Contas

O preview de testes isolado e todos os testes automatizados não precisam de contas nem de credenciais. O desenvolvimento e o deploy usam serviços reais:

- Uma conta da Cloudflare com D1, KV, R2 e Workers para os deploys de preview e de produção. O servidor de desenvolvimento usa recursos locais e não precisa de conta.
- Apps OAuth do GitHub e do Google para o login social.
- Resend com um remetente verificado. Uma conta nova por e-mail já entra logada, mas sem o Resend nenhum link de confirmação chega, então a chave de licença, o portal do cliente, as aulas pagas e um novo login continuam bloqueados.
- Polar, usando o sandbox no desenvolvimento, com três produtos para os planos Core, Complete e Agency.
