# SaaSy Land 2.0

SaaSy Land 2.0 is here! 🎉

**The ultimate SaaS starter kit for building modern full-stack web applications.**

Smarter, cleaner, more robust and more powerful than ever. This release brings world-class engineering and design standards to your next SaaS project. Every detail has been thoughtfully crafted so you can move fast without compromising on quality.

## Feature highlights

- Modern package ecosystem (latest versions as of 2025-05-01)
- Advanced authentication and authorization (2FA, multi-tenancy, RBAC, subdomains)
- Stripe + Stripe Connect (one-time payments, subscriptions, marketplaces)
- Ready-to-use ecommerce (digital & physical products, subscriptions, courses)
- Fully featured dashboard with account and billing settings
- Centralized, scalable global config — one file to rule them all
- i18n out of the box (8+ languages, easy to extend)
- Lightning-fast API with Hono and TypeScript
- Auto-generated OpenAPI docs with Scalar
- S3 file uploads via AWS SDK
- SEO-friendly MDX blog and content pages
- Customizable UI
- Strict TypeScript throughout
- 100% test coverage (unit, integration, e2e)
- Enterprise-ready documentation with Fumadocs
- Ongoing bug fixes and security improvements

## What’s new in 2.0

- **Modern package ecosystem** — upgraded core dependencies for performance, security, and longevity
- **Global configuration** — flexible, scalable config across environments
- **Dashboard** — responsive UI with locale, time zone, notifications, theming, account, security, billing, and more
- **Authentication** — [Better Auth](https://better-auth.com) replaces NextAuth: multi-tenancy, subdomains, organizations, roles, RBAC
- **API** — Hono: type-safe, modular, fast
- **S3** — Amazon S3 for file uploads
- **Stripe** — Stripe + Connect for payments and marketplaces
- **E-commerce** — digital and physical products, subscriptions, example course setup
- **OpenAPI** — Hono OpenAPI + Scalar
- **MDX** — blog, legal, and marketing content, SEO-oriented
- **i18n** — English, Spanish, French, Italian, German, Polish, Ukrainian, Chinese (extensible)
- **Documentation** — Fumadocs + Content Collections
- **UI** — refreshed design system with swappable components and simple customization
- **Type safety** — strict TypeScript, no `any` by design
- **Stability & security** — hardening and fixes across the stack
- **Testing** — 100% coverage with unit, integration, and E2E setups

## Philosophy

Clean, scalable architecture and best practices at every layer — industrial-grade quality with open-source agility.

SaaSy Land 2.0 is built for startups, production apps, and everything in between: a robust, scalable, developer-friendly SaaS starter that can save months of work.
