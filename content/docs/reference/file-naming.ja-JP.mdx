---
title: ファイルネーミング
description: コロケーションサフィックスとフォルダの慣習。
---

| パターン       | 意味する                                         |
| -------------- | ------------------------------------------------ |
| `_components/` | ルートローカル React コンポーネント              |
| `_lib/`        | ルートローカルヘルパー、検索パラメータ、マッパー |
| `_types/`      | ルートローカルタイプ                             |
| `use-cases/`   | モジュールアプリケーションサービス               |
| `*.server.ts`  | サーバーのみの統合エントリ                       |
| `__test__/`    | 凝集テスト                                       |

プリファーの明示的な名前 (`search-params.ts`) ヴァグに `utils.ts` ダンプ。
