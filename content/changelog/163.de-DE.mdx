- Journey-Suite: `bun run test:journey` kauft jedes Paket auf dem Preview-Deployment so wie ein Kunde, mit einer eigenen Playwright-Konfiguration in `e2e/journey/`, die Pull-Requests nicht ausführen. Sie registriert sich mit einer Adresse des Test-Postfachs von Resend und liest die Verifizierungs-E-Mail über die Resend-API, prüft den Preis für das Land des Runners, bezahlt im Checkout der Polar-Sandbox mit der Testkarte von Stripe und prüft die Bestellung in Polar und den Schlüssel auf `/app/license`. Danach führt sie die veröffentlichte CLI, `npx saasyland@beta`, gegen Preview aus: `activate`, denselben Aktivierungsplatz bei einer zweiten Aktivierung, `whoami`, CI-Geräte bis zum Limit des Pakets und ein weiteres, das abgewiesen wird, einen auf `/app/license` freigegebenen Platz, `deactivate` und eine Erstattung über die API der Polar-Sandbox, die `whoami` als `licenseRefunded` meldet. `playwright.config.ts` führt jetzt nur noch `e2e/specs/` aus. Siehe [Journey-Suite](/docs/tooling/playwright#journey-suite).
