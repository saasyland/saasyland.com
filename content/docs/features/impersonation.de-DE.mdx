## Status

Über die administrativen Aktionen bzw. Nutzungsszenarien der Benutzer zugänglich gemacht, wobei Berechtigungsprüfungen durchgeführt werden.

## Regeln.

- Nur für Administratoren.
- Deutliche Benachrichtigung in der Benutzeroberfläche, wenn eine Benutzerimpersonierung stattfindet.
- Bevorzugen Sie die Protokollierung von Aktivitäten, wenn Sie die Betriebsabläufe absichern.
- Ermöglichen Sie keine Erhöhung der Berechtigungen außerhalb der vorgesehenen Support-Prozesse.
