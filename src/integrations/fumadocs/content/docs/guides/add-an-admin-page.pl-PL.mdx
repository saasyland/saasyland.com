> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

## Steps

1. Add path to `ROUTES`
2. Add sidebar entry in `admin/_lib/sidebar.ts` (+ i18n labels)
3. Create `app/[locale]/(admin)/admin/<feature>/page.tsx`
4. Colocate `_components` / `_lib`
5. Gate data with use-cases + Suspense
6. Document under Features
