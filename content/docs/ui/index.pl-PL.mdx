| Ścieżka                                                 | Zawartość                                                                                                                                                                                                        |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/presentation/components/shadcn/`                   | Wygenerowane prymitywy shadcn w wariancie React Aria                                                                                                                                                             |
| `src/presentation/components/custom/`                   | Komponenty aplikacji: płasko ułożone pliki współdzielone (`footer.tsx`, `navigation.tsx`, `data-table.tsx`, `locale-switcher.tsx`, …) oraz foldery obszarów `admin/`, `app/`, `auth/`, `blog/` i `landing-page/` |
| `src/presentation/styles/`                              | `globals.css` (Tailwind, tokeny, skala typograficzna), `fonts.css`, `docs.css`, `typeset.css`                                                                                                                    |
| `src/presentation/theme/`, `src/presentation/branding/` | Stałe motywu i marki                                                                                                                                                                                             |
| `src/presentation/document-assets.ts`                   | Globalny arkusz stylów i wstępne ładowanie czcionek                                                                                                                                                              |
| `src/providers/`                                        | `AriaProvider`, `ThemeProvider`, `TranslationsProvider`, `MotionProvider`                                                                                                                                        |

- [Czcionki i branding](/docs/ui/fonts-and-branding): czcionki hostowane w projekcie, wstępne ładowanie i stałe marki.
