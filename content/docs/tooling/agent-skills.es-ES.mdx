---
title: "Skills para agentes"
description: "Skills de proveedores para agentes de programación, restauradas a partir de skills-lock.json."
---

`skills-lock.json` fija las skills para agentes que se usan con este repositorio. Las skills instaladas no se incluyen en el repositorio: Git ignora `.agents/` y `.claude/`.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` elimina `.agents/skills` y `.claude/skills`, reinstala cada skill fijada con `bunx skills experimental_install`, mueve cada skill a un grupo de proveedor en `.agents/skills/<group>/<skill>/SKILL.md` y enlaza cada grupo en `.claude/skills`. Falla cuando el origen de una skill no tiene asignado ningún grupo.

| Grupo                                                 | Origen                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------ |
| `anthropic`                                           | `anthropics/skills`                                                |
| `better-auth`                                         | `better-auth/skills`                                               |
| `cloudflare`                                          | `cloudflare/skills`                                                |
| `polar`                                               | `polarsource/skills`                                               |
| `resend`                                              | `resend/resend-skills`                                             |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) y `TanStack/table` (`table`) |
| `remotion`                                            | `remotion-dev/skills`                                              |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Skills generales de ingeniería, diseño y marketing                 |

La sincronización sustituye ambos directorios, así que guarde las skills personalizadas en otro lugar. `bun run clean:hardcore` elimina `skills-lock.json`.

## Regla

Antes de modificar código relacionado con TanStack Start, Router o Table, Better Auth, Cloudflare, Polar o Resend, lea la skill correspondiente. Las skills describen las API actuales de los proveedores; las convenciones de este repositorio se documentan en [Arquitectura](/docs/architecture) y [Convenciones](/docs/reference/conventions).
