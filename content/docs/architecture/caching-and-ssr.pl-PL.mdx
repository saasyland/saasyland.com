## Cache zapytań

`getRouter` tworzy nowy `QueryClient` dla każdego żądania, dzięki czemu na serwerze dane nie wyciekają między użytkownikami. Wartości domyślne:

| Ustawienie                 | Wartość       |
| -------------------------- | ------------- |
| `staleTime` zapytań        | 1 minuta      |
| `gcTime` zapytań           | 5 minut       |
| `defaultStaleTime` routera | 1 minuta      |
| Wstępne ładowanie          | Przy intencji |

Loadery wypełniają cache przez `queryClient.query({ ...options, staleTime: "static" })`, a komponenty odczytują te same klucze za pomocą `useSuspenseQuery`. Wyjątkiem są strony kursów i edytor kursów w administracji: ich zapytania mają `staleTime: COURSE_STALE_MS` (minuta), bo `invalidateQueries` nigdy nie pobiera ponownie zapytania `static`, a ukończenie lekcji albo zapisanie zmiany w edytorze musi odświeżyć program. `setupRouterSsrQueryIntegration` serializuje serwerowy cache do HTML i hydratuje go w przeglądarce.

- **Komunikaty tłumaczeń** są przechowywane w cache osobno dla każdego locale i przestrzeni nazw, z nieskończonymi wartościami `staleTime` i `gcTime`.
- **Zapytanie o sesję** (`getCurrentSessionQuery`) ma `staleTime` równy jednej minucie. Guardy tras pobierają je ponownie przy rzeczywistych nawigacjach i czyszczą cały cache, gdy zmienia się zalogowany użytkownik.
- **Mutacje** po pomyślnym wykonaniu unieważniają klucze zapytań swojego modułu, na przykład `USER_QUERY_KEYS.ALL`.

## Prerendering

`bun run build` prerenderuje strony publiczne, przechodząc po linkach: landing, strony prawne, blog i dokumentację we wszystkich dziewięciu wersjach językowych. Pomijane są ścieżki pod `/admin`, `/app`, `/auth`, `/courses`, `/newsletter` i `/api` (z prefiksem locale lub bez niego) oraz linki z query stringiem lub hashem. Strony kursów są pomijane, bo pokazują blokady i postępy każdego widza.

Worker serwuje prerenderowany HTML z bindingu `ASSETS`, zanim załaduje aplikację. Prerenderowana strona nie zawiera danych użytkownika, więc można ją bezpiecznie serwować wszystkim. Gdy odwiedzającemu przysługują ceny regionalne, Worker przepisuje HTML i oznacza odpowiedź jako `Cache-Control: private, no-cache`.

## KV i D1

- **KV (`CACHE`)** przechowuje liczbę gwiazdek na GitHubie dla `src/lib/github.ts` i rabaty regionalne w checkoucie dla `src/modules/license/license.ppp.ts`. Liczba gwiazdek starsza niż godzina jest zwracana od razu i odświeżana w tle przez `waitUntil`; rabaty starsze niż pięć minut są ponownie pobierane z Polar.
- **D1 (`DB`)** przechowuje sesje i liczniki limitów żądań. Sprawdzanie sesji w funkcjach serwerowych omija cookie cache Better Auth, a wynik jest memoizowany do końca żądania.
- **Cache Workers** przechowuje pliki wideo, które `serveMedia` odczytuje z R2, pod `/media/_/<videoId>/<file>`, bez podpisu, dzięki czemu widzowie w jednej lokalizacji brzegowej współdzielą jedną kopię w cache. Zobacz [Cloudflare R2](/docs/integrations/cloudflare-r2).
- Funkcje serwerowe nigdy nie podejmują decyzji o uprawnieniach na podstawie danych z cache.
