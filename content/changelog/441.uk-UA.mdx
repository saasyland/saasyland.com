- Виправлено: `bun run check:features` очищає скрипти `package.json` за тим самим правилом, що й код: зникає крок, який запускає видалений файл або скрипт, що зникає, а також скрипт, у якому не лишилося кроків, тож сайт без контенту більше не зберігає `check:content`, що вказує на видалений файл. Кожен сценарій також провалюється, коли скрипт досі називає видалений файл або запускає скрипт, якого вже немає. Див. [Тестування](/docs/conventions/testing#tests-follow-the-features).
