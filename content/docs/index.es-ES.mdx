## Edición local.

Archivos de contenido: `content/docs`.

MDX puede utilizar componentes de Fumadocs (`<Cards>`, `<Callout>`, `<Steps>`, `<Tabs>`, `<Accordions>`) y elementos seleccionados de shadcn primitives (`<Button>`, `<Badge>`, `<Alert>`, `<Table>`, …).

Después de añadir páginas, actualice el archivo `meta.<locale>.json`, el array `pages` (el script de scaffolding lo hace por usted). Las páginas de la carpeta `index` son **índices de carpetas** — no incluya `index` de nuevo en `pages`.
