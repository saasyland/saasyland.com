Each section lists the changes that reached `main` on that day in UTC, newest first, and each change ends with a link to the pull request it came from and, once deployed, to the release that first shipped it. Every production deploy is tagged and published as a GitHub Release whose notes are the entries it shipped; see [Releases and tags](/docs/tooling/ci-cd#releases-and-tags). The CLI's own releases are in the [CLI release notes](/docs/cli/releases). Each change adds its own entry, as [Changelog entries](/docs/conventions/git-workflow#changelog-entries) describes.
