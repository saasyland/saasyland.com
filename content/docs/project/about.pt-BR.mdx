title: Sobre
description: O quê? SaaSy Land é e para quem é.
---

SaaSy Land 2.0 é um código aberto. **SaaS Kit de arranque.** Mantido como uma base de código de produto real: modular, digitado e opinado sobre limites.

É para equipes que querem meses de autenticação, administração, i18n, e encanamento de plataforma sem herdar um labirinto de caldeiras intolerável.
