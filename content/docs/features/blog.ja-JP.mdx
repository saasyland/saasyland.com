## コンテンツ

記事は言語ごとに 1 ファイルずつ `content/blog/<slug>.<locale>.mdx` に置きます。`src/integrations/fumadocs/fumadocs.config.ts` のフロントマタースキーマでは `title`、`authorName`、`date` が必須で、`description`、`authorImage`、`excerpt`、`faq`、`featured`、`image`、`published`（既定値 `true`）、`tags`、`updated` を指定できます。

## ソース

`fumadocs.source.ts` の `blogSource` は、ドキュメントと同じ i18n 設定でコレクションを `/blog` 配下に読み込みます。`getPublishedBlogPosts(locale)` は公開済みの記事を新しい順に、その言語向けに `Intl.Segmenter` で計算した読了時間付きの概要として返します。

## ルート

- `/blog` レイアウト（`blog.tsx`）はブログのヘッダー、`PageFrame`、`Footer` を表示し、記事のタイポグラフィ用に `docs.css` を読み込みます。
- `/blog`（`blog.index.tsx`）は `PostRow` で記事を一覧表示します。一覧はルートファイル内で定義したサーバー関数から取得します。
- `/blog/$`（`blog.$.tsx`）は記事を 1 件読み込み（未公開なら 404）、`blogContent` でコンパイル済みの MDX をプリロードし、`src/presentation/components/custom/blog` の `PostMeta`、`PostToc`（小さい画面では `InlineTOC`）、`PostCta`、`PostShare` を組み合わせます。`buildBlogPostStructuredDataHtml` の JSON-LD と `buildPageHead` の記事メタデータを追加します。

ランディングページの Notes セクションには最新の 3 記事が表示されます。

## 管理画面のブログ（デモ）

`/admin/blog` と `/admin/blog/create` は、`src/data/admin-blog.ts` のデモ記事と統計、および静的なエディターを表示します。`content/blog` の読み書きは行いません。

## チェック

記事を追加したら `bun run content` を実行します。`bun scripts/check-content.ts` は、すべての言語のファイルがあること、タイトル・説明・抜粋が翻訳されていること、コードブロックが同一であることを確認します。
