## CLI

Disponible maintenant, comme le décrit le [guide de la CLI](/docs/cli) :

- `init` génère un projet à partir des options que le [configurateur](/#cli) de la page d’accueil permet de choisir : React avec TanStack Start sur un Cloudflare Worker avec D1, avec la connexion Better Auth ou sans elle
- `activate`, `whoami` et `deactivate` gèrent une clé de licence sur un appareil et en CI

À venir :

- La facturation, ainsi que les autres options et extras, que le configurateur affiche désactivés jusqu’à ce que les modèles les génèrent
- Les autres bibliothèques UI et frameworks : Next.js et React Router sur React, Angular avec Analog et Angular SSR, Vue avec Nuxt, Svelte avec SvelteKit et Solid avec SolidStart et TanStack Start, ainsi que le runtime Deno
- `change`, pour modifier les réponses d’un projet généré, `update`, pour le passer à une version plus récente, et `status`
- La version stable sur le tag par défaut de npm

## Offres

Chaque carte d’offre de la [section des tarifs](/#pricing) indique ce qui est disponible maintenant et ce qui est à venir. `TIER_FEATURES` dans `src/data/marketing.ts` contient ce partage. À venir :

- Core : la facturation déjà branchée avec le prestataire choisi ; le code source généré de l’application avec uniquement les modules choisis, Better Auth et Resend déjà branchés, la suite de tests avec son seuil de <RepositoryFact name="coverageThreshold" /> % et les projets illimités sous licence commerciale sont disponibles maintenant
- Complete : l’accès gratuit à vie à reactprojects.com et angularprojects.com, qui ouvrent après leurs listes d’attente, la formation vidéo du dossier vide à la production, et l’explication du code module par module
- Agency : les places d’équipe pour le cours, reactprojects.com et angularprojects.com, la chaîne Discord privée et les fichiers Figma pour le concepteur de pages ; les projets clients illimités sont disponibles maintenant
