- Suite del recorrido del cliente: `bun run test:journey` compra cada nivel en el despliegue de preview como lo hace un cliente, con una configuración propia de Playwright en `e2e/journey/` que las pull requests no ejecutan. Se registra con una dirección de la bandeja de pruebas de Resend y lee el correo de verificación mediante la API de Resend, comprueba el precio para el país del runner, paga en el checkout del sandbox de Polar con la tarjeta de prueba de Stripe y comprueba el pedido en Polar y la clave en `/app/license`. Después ejecuta la CLI publicada, `npx saasyland@beta`, contra preview: `activate`, la misma activación en una segunda activación, `whoami`, dispositivos de CI hasta el límite del nivel y uno más que se rechaza, una activación liberada en `/app/license`, `deactivate` y un reembolso mediante la API del sandbox de Polar que `whoami` notifica como `licenseRefunded`. `playwright.config.ts` ahora solo ejecuta `e2e/specs/`. Consulta [Suite del recorrido del cliente](/docs/tooling/playwright#journey-suite).
