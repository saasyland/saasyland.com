- Neu: `bun run deps:update` bringt jede Abhängigkeit mit Bereich auf ihr neuestes Release, Vite+ über `vp migrate`, und die Agent-Skills in einem Befehl auf den neuesten Stand und nennt danach die fixierten Pakete, für die es ein neueres Release gibt. Siehe [Abhängigkeiten](/docs/conventions/dependencies#upgrading).
- Neu: `bun run check` schlägt fehl, wenn sich ein Paket, das ein Agent-Skill beschreibt, etwa `resend`, `better-auth` oder `wrangler`, ohne `bun run skills:update` bewegt hat, und wenn die installierten Skills von `skills-lock.json` abweichen. `SKILL_SOURCES` in `src/data/skills.ts` ordnet jeder Skill-Quelle die Pakete zu, die sie beschreibt. Siehe [Agent-Skills](/docs/tooling/agent-skills#drift-checks).
- Neu: Der wöchentliche Workflow `updates.yml` listet die verfügbaren Updates für Abhängigkeiten und Skills in einem GitHub-Issue auf, das er öffnet, neu schreibt und schließt. Siehe [CI/CD](/docs/tooling/ci-cd#updates).
- Geändert: Die `skills`-CLI ist eine Entwicklungsabhängigkeit, daher fixiert `bun.lock` die Version, die die Skills installiert und ihre Hashes berechnet.
