Примітиви в `src/presentation/components/shadcn/` — це компоненти shadcn/ui, побудовані на React Aria Components. `input-otp`, `carousel`, `resizable`, `chart`, `message-scroller` і `sonner` обгортають інші бібліотеки, `drawer` використовує Base UI, а решта працює за правилами React Aria. `components.json` спрямовує псевдонім `ui` на цю теку, а `utils` — на `~/src/lib/cn`. Екрани імпортують примітиви напряму; обгорток навколо них немає.

## Властивості React Aria

| Звичка з DOM або Radix   | Тут використовуйте                     |
| ------------------------ | -------------------------------------- |
| `onClick`                | `onPress`                              |
| `disabled`               | `isDisabled`                           |
| `open` у діалозі         | `isOpen` з `onOpenChange`              |
| `checked`                | `isSelected`                           |
| `value` у вкладках       | `selectedKey` або `defaultSelectedKey` |
| `onSelect` у пункті меню | `onAction`                             |

`Input` зберігає нативну подію `onChange`. `Select` приймає `fieldLabel`, який рендерить його мітку.

## Правила

- **Кнопки в очікуванні**: передавайте стан мутації в `Button`: `<Button isPending={mutation.isPending} type="submit">`.
- **Посилання**: `LinkButton` і `SidebarMenuLink` — це посилання TanStack Router, створені через `createLink` із `Link` з React Aria: вони приймають `to` з `params` і `search`, які дерево маршрутів перевіряє типами, і попередньо завантажують свою сторінку за наміром, як `<Link>`. `AnchorButton`, `TabsTrigger` і `SidebarMenuButton` приймають `href` для адрес поза деревом маршрутів, як-от завантаження, `mailto:` та інші сайти, а `AriaProvider` спрямовує `href` того самого сайту через TanStack Router із префіксом мови. Щоб надати іншим елементам вигляду кнопки, використовуйте `buttonVariants`.
- **Форми**: `Field`, `FieldGroup`, `FieldLabel`, `Input` і `ValidationFieldError` з TanStack Form, як у цьому полі з `ResetPasswordDialog`:

```tsx
<Field data-invalid={isInvalid}>
  <FieldLabel htmlFor={passwordId}>{t("resetPasswordDialog.password")}</FieldLabel>
  <Input
    aria-invalid={isInvalid}
    autoComplete="new-password"
    id={passwordId}
    name={field.name}
    onBlur={field.handleBlur}
    onChange={(event) => {
      field.handleChange(event.target.value)
    }}
    type="password"
    value={field.state.value}
  />
  {isInvalid && (
    <ValidationFieldError
      message={fieldErrorMessage(field.state.meta.errors)}
      namespace="auth.validations"
      params={AUTH_VALIDATION_PARAMS}
    />
  )}
</Field>
```

- **Діалоги**: `Dialog` і `AlertDialog` керуються через `isOpen` і `onOpenChange`; кожен діалог має власний файл, наприклад `admin/users/delete-user-dialog.tsx`.
- **Меню**: `DropdownMenuTrigger` обгортає `Button`, що його відкриває, і `DropdownMenu`; пункти виконують `onAction`, а для небезпечних дій використовують `variant="destructive"`.
- **Сповіщення**: викликайте `toast.success` або `toast.error` з `sonner`; кореневий маршрут рендерить `Toaster` усередині `ThemeProvider`. Його область сповіщень має назву з `components.shadcn.sonner`, за якою йде клавіатурне скорочення Sonner.
- **Рамки фокуса**: стилізуйте тригери React Aria варіантами `data-focus-visible:`, як це роблять `checkbox`, `select`, `switch` і `radio-group`.
- **Назви класів**: використовуйте `cn` з `~/src/lib/cn` з об’єктним синтаксисом для умовних класів.

## Розмір CSS

`globals.css` не містить жодного списку примітивів. Vite-плагін `unused-primitives` у `scripts/unused-primitives.ts` працює перед Tailwind: записує в `.source/unused-primitives.css` рядок `@source not` для кожного примітива, якого не імпортує жодне джерело застосунку ні напряму, ні через інший примітив (тести й `src/platform/testing` не враховуються), та імпортує цей файл у таблицю стилів, яку передає Tailwind. CSS проєкту містить класи тих примітивів, які використовує його власний код, і жодних інших. Tailwind стежить за імпортованим файлом, а плагін переписує його лише тоді, коли список змінюється, тож коли екран починає імпортувати примітив, сервер розробки перебудовує CSS з його класами без перезапуску.
