Кожна таблиця рендериться через один універсальний `DataTable` у `src/presentation/components/custom/data-table.tsx`. Він створює екземпляр TanStack Table v9 із `tableFeatures` (фільтрація за стовпцями, сортування, пагінація та вибір рядків) і `useTable`, а також рендерить примітиви таблиці shadcn, рядки-скелетони під час завантаження та локалізований порожній стан.

```tsx
<DataTable columns={userColumns} options={{ query: getUsersPageQuery, selectable: true }} />
```

## Пропси

| Проп                   | Призначення                                                                                                                                           |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `columns`              | Визначення стовпців для типу рядка; кожен рядок потребує `id`                                                                                         |
| `data`                 | Рядки для таблиці, яка сортує, фільтрує та розбиває на сторінки на клієнті                                                                            |
| `options.initialState` | Початкові `pagination` і `sorting`                                                                                                                    |
| `options.query`        | Серверна пагінація та сортування: функція від `pageIndex`, `pageSize` і `sorting`, що повертає параметри запиту, які розв'язуються в `rows` і `total` |
| `options.selectable`   | Додає стовпець із прапорцями для вибору рядків                                                                                                        |
| `filters`              | Фільтри пошуку (`type: "search"`, `columnId`, `placeholder`) або фільтри вибору (`type: "select"`, `columnId`, `label`, `options`)                    |

З `options.query` таблиця перемикається на ручну пагінацію та сортування, показує попередню сторінку, доки завантажується наступна, і повертається на першу сторінку, коли змінюється сортування.

## Стовпці

Стовпці зберігаються у файлі `<entity>-columns.tsx` поруч із віджетами сторінки й використовують `createColumnHelper<DataTableFeatures, Row>()`. Комірки та заголовки — це невеликі компоненти, які самі зчитують свої переклади, тож маршрут не передає жодних підписів:

```tsx
const columnHelper = createColumnHelper<DataTableFeatures, AdminUser>()

export const userColumns = columnHelper.columns([
  columnHelper.accessor("role", { cell: RoleCell, header: () => <ColumnHeader id="role" /> }),
  columnHelper.accessor("createdAt", { cell: DateCell, header: () => <ColumnHeader id="createdAt" />, sortFn: "datetime" }),
])
```

Повний приклад — `src/presentation/components/custom/admin/users/user-columns.tsx`, який рендерить `src/routes/admin.users.all.tsx`.
