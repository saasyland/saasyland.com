Aplikacja udostępnia następujące trasy HTTP, zadeklarowane przez `server.handlers` w `createFileRoute` w `src/routes/api`:

| Trasa                                        | Metody            | Handler                                                                                                                                                                           |
| -------------------------------------------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api`                                       | GET               | Zwraca `{ "runtime": "cloudflare-workers" }`.                                                                                                                                     |
| `/api/auth/$`                                | GET, POST         | Better Auth: logowanie, powroty OAuth, `/api/auth/verify-email` oraz endpointy wtyczki Polar `/api/auth/polar/webhooks` i `/api/auth/customer/portal`.                            |
| `/api/search`                                | GET               | Wyszukiwarka Fumadocs (`fumadocs.search.ts`).                                                                                                                                     |
| <RepositoryFact name="cliApiBasePath" />`/*` | GET, POST, DELETE | [API licencji CLI](/docs/features/cli-licence-api): `licenseApiHandlers` (`license.api.ts`) odczytują licencję oraz aktywują, sprawdzają i zwalniają maszyny dla CLI `saasyland`. |

```ts
import { createFileRoute } from "@tanstack/react-router"

import { auth } from "~/src/integrations/better-auth/auth.server"

export const Route = createFileRoute("/api/auth/$")({
  server: { handlers: { GET: ({ request }) => auth.handler(request), POST: ({ request }) => auth.handler(request) } },
})
```

## Funkcje serwerowe zamiast REST

Operacje aplikacji to funkcje `createServerFn` w `src/modules/<table>/use-cases`. Pozostałe znajdują się w `src/lib` (`getStarCount` w `github.ts`), w integracji (`getCurrentSession` w `auth.session.ts`, `getDocsPage` w `fumadocs.docs.ts`) albo bezpośrednio w jedynej trasie, która ich używa (`getBlogPosts` w `_site._marketing.blog.index.tsx`). TanStack Start wywołuje je przez RPC pod `/_serverFn`, z middleware dla sesji, uprawnień i limitów żądań. Nie dodawaj endpointu REST dla operacji, którą wywołuje tylko ta aplikacja; trasę HTTP dodawaj wyłącznie dla zewnętrznych wywołujących, takich jak webhooki i CLI, a podpisy webhooków weryfikuj w integracji dostawcy.

## Zachowanie

- Worker nie stosuje przekierowań językowych dla `/api` i `/_serverFn`. Ich adresy URL nie zawierają języka, więc `getCurrentLocale()` zwraca dla nich na serwerze `en-US`; kod, który potrzebuje języka, otrzymuje go jako dane wejściowe albo odczytuje z `callbackURL`.
- Build nie prerenderuje `/api`.
- `/media/*` nie jest trasą TanStack Start: Worker przekazuje tę ścieżkę do `serveMedia` przed obsługą języka. Zobacz [Cloudflare R2](/docs/integrations/cloudflare-r2). Nie jest nią też `/bundles/*`, którą Worker przekazuje do `serveBundle`; zobacz [API licencji CLI](/docs/features/cli-licence-api#template-bundles).
- Testy handlerów znajdują się w `src/routes/api/__test__/`, po jednym pliku na handler: `auth.test.ts`, `search.test.ts` i `index.test.ts`. `cli.v1.test.ts` obejmuje pliki tras API licencji CLI, którego działanie testuje `src/modules/license/__test__/license.api.integration.test.ts`, a w przypadku paczek `license.bundles.integration.test.ts`.
