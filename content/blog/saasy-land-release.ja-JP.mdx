## SaaSy Land とは？

SaaSy Land は、商用の React SaaS スターターキットです。その CLI は、回答したモジュールだけを書き出します。自分のデータベースで動く認証、課金、トランザクションメール、管理画面、国際化です。CLI はお使いの端末でライセンスキーを有効化し（`activate`、`whoami`、`deactivate`）、`init` が[コンフィギュレーター](/#cli)で選択できるオプションからプロジェクトを書き出します。課金は今後提供予定です。CLI が書き出すのはこのサイト自身のコードで、<RepositoryFact name="testFiles" /> 個のテストファイルと、それらを最初から強制するカバレッジゲートが付いているため、受け取るものはただ存在するだけでなく、検証済みです。

公開 Web サイトのソースコードは MIT ライセンスです。一方、別途提供する CLI と非公開テンプレートはプロプライエタリです。ライセンスを購入して saasyland.com にサインインし、CLI のインストールと利用に必要なキーを取得してください。オンラインでのライセンス認証は CLI に適用されます。生成したアプリケーションは商用ライセンスの下で編集・デプロイでき、実行時のキーは不要です。Web サイトのライセンスによって SaaSy Land の商標権が付与されることはありません。

### カバレッジゲートがリリース時よりも今重要になっている理由

2.0 をリリースした当時、カバレッジの数値は品質を示す論拠でした。その後、それはスループットを示す論拠になりました。いまや SaaS のコードベースに追加されるコードのかなりの割合を、エージェントが書いているからです。

[2025 Stack Overflow Developer Survey](https://survey.stackoverflow.co/2025/ai) では、開発者の 84% が AI ツールを使用している、または使用する予定だと回答しました。一方で、最も多く挙げられた不満は、66% が指摘した「ほぼ正しいが、完全ではない」AI の出力でした。[2026 年の調査](https://survey.stackoverflow.co/2026/ai) では、48% が、答えを簡単に検証できるときには AI を信頼すると回答しています。マージを止めるしきい値は、この両方に対して取れる最も安価な答えです。エージェントはテストを追加しない限り振る舞いを追加できず、何かを壊せば、それは顧客のもとではなくプルリクエストの段階で表に出ます。

この点については、[リポジトリがエージェントの出力品質を左右する理由](/blog/ai-coding-agents-repository-readiness) と [AI コーディングエージェントのためのスタックの選び方](/blog/choosing-a-saas-stack-for-ai-coding-agents) で詳しく書いています。要点だけ言えば、このリポジトリは私たち自身の準備度スコアカードで 20 点中 17 点を獲得しており、それは努力ではなく構造によるものです。

| ローカライズ         | 8 言語                   | <RepositoryFact name="languages" /> ロケール                                        | さらに <RepositoryFact name="timezones" /> のタイムゾーン、<RepositoryFact name="currencies" /> の通貨、CI を失敗させるパリティチェック |

ページデザイナーを除き、これらはすべて現在このサイトのリポジトリに入っています。コアの無期限アップデートが含まれているため、次の改良もあなたのリポジトリに届きます。

## 一度の支払いで手に入るもの

あなたが買うのはコードではありません。カレンダーを買い戻すのです。

時給 <RepositoryFact name="illustrativeHourlyRate" unit="currency" /> なら、<TierPrice tier="core" /> はあなたの作業時間の <RepositoryFact name="corePriceInHours" unit="hour" />未満です。それで置き換えられる作業は、<RepositoryFact name="corePriceInHours" unit="hour" />では済みません。二要素認証と OAuth を備えた認証、型付きデータレイヤー、トランザクションメール、管理画面、<RepositoryFact name="languages" /> ロケールのカタログ、マーケティングサイト、そして次の変更後もすべてが動き続けることを証明するテストスイートです。

| プラン       | 価格                                   | 対象                                         | 含まれるもの                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------ | -------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Core**     | <TierPrice tier="core" /> 買い切り     | ひとりで出荷し、すべての行を読む創業者       | いま使えるもの：ライセンスキー付きの CLI（init、activate、whoami、deactivate）を同時に <ActivationLimit tier="core" /> 台の端末で、コアの無期限アップデート、選んだモジュールだけを含む生成済みアプリのソース、統合済みの Better Auth・Resend、完全なテストスイートとその <RepositoryFact name="coverageThreshold" />% ゲート、商用ライセンスでの無制限のプロジェクト。提供予定：選んだプロバイダーで統合済みの課金 |
| **Complete** | <TierPrice tier="complete" /> 買い切り | 結果だけでなく、その理由も知りたいエンジニア | いま使えるもの：Core のすべて、1 営業日以内に回答する優先サポート、<ActivationLimit tier="complete" /> 台の端末で使える CLI。提供予定：reactprojects.com と angularprojects.com への無期限の無料アクセス、空のフォルダーから本番環境までを構築するビデオコース、モジュールごとのコード解説                                                                                                                          |

米ドルでの一回払いで、サブスクリプションも、席数に応じた料金も、月間アクティブユーザーによる従量課金もありません。各プランのカードには、そのキーを同時に有効化できる端末の台数が表示されます。Core は <ActivationLimit tier="core" /> 台、Complete は <ActivationLimit tier="complete" /> 台、Agency は <ActivationLimit tier="agency" /> 台です。CI リポジトリは 1 台として数えます。

合わなければ、使用していない限り、購入から <RepositoryFact name="refundWithdrawalDays" unit="day" />以内であれば全額返金を受けられます。ここでの使用とは、プロジェクトの生成または有料レッスンの閲覧を指します。サインインと、端末でのキーの有効化は使用に含まれません。返金またはチャージバックによってライセンスは終了します。詳しくは [返金ポリシー](/refunds) をご覧ください。

## 支払う前に、すべての主張を確認する

お客様の声は載せていません。引用文には検証できるものが何もないからです。このページにあるコードベースの数字はすべて公開 Web サイトのリポジトリで計測しており、各主張を確認できる場所は以下のとおりです。

| 主張                                                                                      | 確認する場所                                                                                                                   |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| <RepositoryFact name="coverageThreshold" />% のテストカバレッジ                           | `bun run test:coverage` が生成する `coverage/coverage-summary.json`                                                            |
| 報告ではなく強制                                                                          | すべてのプルリクエストと main への push で実行される `.github/workflows/ci.yml`                                                |
| jsdom ではなく実際のブラウザ                                                              | `e2e/specs`、<RepositoryFact name="e2eSpecs" /> 個の Playwright スイート。Chromium はプルリクエストごと、WebKit は main で実行 |
| <RepositoryFact name="languages" /> ロケール、<RepositoryFact name="currencies" /> の通貨 | `messages/` と `src/modules/_core/constants`。`bun run check:i18n` で検証                                                      |
| 厳格な型、`any` はゼロ                                                                    | 厳格な型チェックを含む `bun run check`                                                                                         |
| <RepositoryFact name="uiComponents" /> 個のコンポーネントがリポジトリ内に                 | 編集可能なソースとしての `src/presentation/components/shadcn`                                                                  |

## 向いていない人

無料で学べるものが欲しいなら、テンプレートをクローンして楽しんでください。認証をホスティング型のベンダーに任せ、その特権の対価として月間アクティブユーザーごとに請求されることを望むなら、そちらを購入してください。

これは、5 万人のユーザーを抱えても自分の利益率を手放さないつもりの人、そして本番環境ではなくプルリクエストの段階で問題に気づきたい人のためのものです。
