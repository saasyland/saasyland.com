SaaSy Land は、Cloudflare Worker として動作する 1 つの TanStack Start アプリケーションです。コードは責務ごとに分かれています。

- **ルート**（`src/routes`）はページを組み立てます。ルートファイルは翻訳の名前空間、ガード、ローダー、head タグを宣言し、そのうえでコンポーネントを描画します。
- **モジュール**（`src/modules/<table>`）は、実在するデータベーステーブルのためだけに存在します。モジュールは、テーブルの Drizzle スキーマ、Zod スキーマ、定数、型、そしてテーブルを読み取り・変更するユースケースを所有します。
- **インテグレーション**（`src/integrations/<vendor>`）は、サードパーティのライブラリやサービスを設定します。
- **プレゼンテーション**（`src/presentation`）には、shadcn のプリミティブ、アプリケーションのコンポーネント、React Email のテンプレート、スタイル、テーマ、ブランディングが入ります。
- **共有コード**は、`src/data`（複数のファイルで使うデータ）、`src/lib`（小さなユーティリティ）、`src/hooks`、`src/providers` に置きます。

```text
src/
├── routes/          Flat file routes that compose pages
├── modules/         One folder per database table, plus _core
├── integrations/    One folder per vendor
├── presentation/    Components, emails, styles, theme, branding
├── data/            Data shared by several files
├── lib/             Small shared utilities
├── hooks/           Shared React hooks
├── providers/       Application providers
├── platform/        Test runtime wiring
├── types/           Global type declarations
├── router.tsx       Router and per-request QueryClient
├── routes.ts        ROUTES path constants
└── server.ts        Cloudflare Worker entry
```

## コードを形づくるルール

- ルートファイルは組み立てるだけです。ウィジェット、ダイアログ、フォーム、テーブルのカラムは、`src/presentation/components/custom` に 1 ファイルずつ置きます。
- コンポーネントは、`useTranslations`、`useSuspenseQuery`、またはルートのローダーデータを使って、自分の翻訳とデータを読み取ります。ルートがラベルやデータを props として渡すことはありません。
- テーブルを扱うサーバー関数は、そのテーブルのモジュール内のユースケースにします。1 つのルートだけが使うサーバー関数は、そのルートファイルに定義できます。それ以外はすべて `src/lib` に置きます。
- 依存性注入コンテナーもラッパー層もありません。具体的な関数を、それを所有するフォルダーから直接インポートします。
- 1 つのファイルだけが使う定数は、そのファイルに置いたままにします。複数のファイルで共有するデータだけを `src/data` に移します。
