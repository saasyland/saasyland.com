---
title: "Stan w adresie URL"
description: "Przechowuj zakładki, widoki i jednorazowe tokeny w walidowanych parametrach wyszukiwania."
---

Parametry wyszukiwania przechowują stan, który ma przetrwać przeładowanie lub udostępnienie linku: wybraną zakładkę lub widok, adres e-mail przekazywany między stronami uwierzytelniania, token weryfikacyjny. Wszystko inne zostaje w stanie Reacta. `DataTable` trzyma paginację, sortowanie, zaznaczenie i filtry w stanie komponentu.

## Zadeklaruj parametry

`validateSearch` zamienia surowe parametry zapytania w typowany obiekt. Nieznane lub niepoprawne wartości przyjmują wartość domyślną zamiast rzucać błąd. Z `src/routes/admin.blog.index.tsx`:

```tsx
validateSearch: (search: SearchSchemaInput & { view?: unknown }): { view: "grid" | "table" } => ({
  view: search.view === "table" ? "table" : "grid",
}),
search: { middlewares: [stripSearchParams({ view: "grid" })] },
```

`stripSearchParams` usuwa wartość domyślną z adresu, więc `/admin/blog` pozostaje kanonicznym adresem widoku siatki.

## Odczytaj je

- W komponencie trasy: `const { view } = Route.useSearch()`.
- Z selektorem komponent renderuje się ponownie tylko wtedy, gdy zmieni się wybrana wartość: `Route.useSearch({ select: (search) => search.error !== "" })`.
- W komponencie poza plikiem trasy: `getRouteApi("/auth/reset-password").useSearch()`, jak w `reset-password-form.tsx`.

## Zmień je

- Linki: `<Link search={{ view: id }} to={ROUTES.ADMIN_BLOG}>`.
- Komponenty React Aria z atrybutem `href`, np. `TabsTrigger` w `src/routes/admin.products.index.tsx`, nawigują przez router, ponieważ `AriaProvider` łączy React Aria z TanStack Router.
- Kod: `router.navigate({ search: { email }, to: ROUTES.VERIFY_EMAIL })`.
- Strażnicy i loadery: `throw redirect({ replace: true, search: { status: "success" }, to: ROUTES.NEWSLETTER_UNSUBSCRIBE })`.

## Wczytuj na ich podstawie dane

Loader zależny od parametru wyszukiwania deklaruje go w `loaderDeps` i odczytuje z `deps`. Trasa potwierdzenia newslettera w ten sposób zużywa token i ustawia `preload: false`, aby najechanie kursorem na link nigdy go nie zużyło:

```tsx
loaderDeps: ({ search: { token } }) => ({ token: token ?? "" }),
```

## Języki i adresy URL

- Linki routera (`<Link to={ROUTES.X}>`) dostają prefiks języka z `rewrite` routera. Angielski nie ma prefiksu (`/docs`), pozostałe języki go mają (`/pl-PL/docs`).
- Surowe adresy buduj przez `localizePathname({ locale, pathname })`: `callbackURL` i `errorCallbackURL` w Better Auth, linki w e-mailach i ręcznie budowane `<a href>`. Ścieżki `/api` i zewnętrzne adresy pozostają bez zmian.
- Przełącznik języka prowadzi do tej samej ścieżki w innym języku z pełnym przeładowaniem strony; parametry zapytania i fragment nie są przenoszone.
