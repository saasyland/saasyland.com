- Added: each licence records when the buyer consented to immediate delivery, when its key was first activated and when the CLI first downloaded templates with it. `order.paid` stores the consent from the order's `withdrawal_consent` checkout field, the CLI licence API records the first activation and the first template download once and before it answers, and a new purchase on the same account starts the records again. A migration adds the nullable columns `withdrawal_consent_at`, `activated_at` and `delivered_at` to `license`. See [Licences](/docs/features/licences#records-and-refunds) and [CLI licence API](/docs/features/cli-licence-api#records-of-use).
- Added: a user's profile in the admin shows their licence: the tier, the status, the purchase time, the consent, the first activation, the first template download and, for an active licence, whether it can still be refunded, which `refundEligibility` works out on the server. Other areas add cards to the profile in `src/data/<area>.user-profile.ts`. See [Users (admin)](/docs/features/users-admin#profile).
