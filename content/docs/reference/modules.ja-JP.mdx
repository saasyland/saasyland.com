モジュールは、実在するデータベーステーブルのためだけに存在します。各テーブルは `src/integrations/drizzle-orm/drizzle.schemas.ts` に登録されます。

<RepositoryTable name="moduleUseCases" columns={["モジュール", "テーブル", "ユースケース"]} />

`_core` はテーブルを所有しません。[Core 共有カーネル](/docs/architecture/core)で説明している、エラーコード、HTTP 定数、カタログ、Zod フィールド、ユースケースの入力を保持します。

## 標準セット以外のファイル

ほとんどのモジュールには、`<table>.schema.ts`、`.zod.ts`、`.constants.ts`、`.types.ts`、`.utils.ts`、`use-cases/` しかありません。いくつかのモジュールには、追加のファイルがあります。

- `course/course.outline.ts`：視聴者向けの公開済みコースのチャプターとレッスンを返す `readCourseOutline`。`get-course` と `get-lesson` が共有する
- `course/course.curriculum.ts`: カリキュラムを章とレッスンの行からなる 1 つのリストとして扱い、ドラッグした章やレッスンを置ける場所と、移動後の順序を求めます（`curriculumRows`、`canDropInCurriculum`、`moveInCurriculum`、`curriculumOrder`）。純粋な関数です
- `lesson/lesson.access.ts`：`hasLessonAccess`、`Viewer` 型、そして有料レッスンを開けるユーザーを決める `COURSE_ACCESS_GRANTS`（ライセンスの付与を直接含む）、`holdsCourseAccess`、`recordCourseAccessUse`
- `lesson/lesson.playable.ts`: 動画のレッスンをその動画と結合する `playableVideo` と、動画のない動画レッスンとテキストのレッスンを区別する `isBeingRecorded`
- `lesson-attachment/lesson-attachment.files.ts`：アップロードされたファイルの R2 のオブジェクトキー、安全な名前、アップロードと配信ができるコンテンツタイプ
- `lesson-attachment/lesson-attachment.download.ts`：署名済みのダウンロードパス（`signDownload`、`verifyDownload`）
- `lesson-attachment/lesson-attachment.delivery.ts`：`/media/downloads/` リクエストに R2 から応答する `serveAttachment`
- `lesson-attachment/lesson-attachment.objects.ts`：削除されるレッスンのアップロード済みファイルと、R2 からのその削除
- `lesson/lesson.viewer.ts`：セッション、ロール、`COURSE_ACCESS_GRANTS` のコースアクセスから視聴者を組み立てる `resolveViewer` と、コースアクセスで開いた有料レッスンを記録する `recordPaidLessonOpened`
- `license/license.webhooks.ts`：`POLAR_EVENT_HANDLERS` (`src/integrations/polar/polar.webhooks.ts`) から呼び出される、ライセンスの Polar イベントハンドラー
- `license/license.api.ts`：`src/routes/api/cli.v1.*.ts` が提供する CLI ライセンス API である `licenseApiHandlers`
- `license/license.bundles.ts`：リリースのテンプレートバンドルの R2 のキーと署名済み URL（`bundleObjectKey`、`signBundle`、`verifyBundle`）
- `license/license.delivery.ts`：`/bundles/` リクエストに R2 から応答する `serveBundle`
- `license/license.ppp.ts`：チェックアウトで購入者にプランに対して請求する価格（地域価格を含む）である `buyerTierPrice`
- `license/license.pricing.ts`：地域別価格の区分（`PPP_TIERS`）、その倍率と割合、適用を外すクッキー
- `license/license.upgrade-price.ts`：上位プランの価格から、顧客がライセンスに支払った額を差し引く `upgradePrice`
- `license/license.refunds.ts`：同意と最初の使用（最初のテンプレートのダウンロードまたは最初の有料レッスン）から、購入を現時点で返金できるかどうかを求める `refundEligibility`
- `withdrawal/withdrawal.contracts.ts`：撤回の意思表示が指定する有効なライセンスと、その時点での返金条件を求める `matchContract` と `accountContract`
- `video/video.files.ts`：R2 のオブジェクトキーと、保存・配信できるファイルとそのメディアタイプ
- `video/video.playback.ts`：署名済みの再生パス（`createPlayback`、`verifyPlayback`）
- `video/video.delivery.ts`：`/media/` リクエストに Workers のキャッシュまたは R2 から応答する `serveMedia`
- `video/video.encoding.ts`: `scripts/publish-video.ts` と `scripts/encode-videos.ts` が実行する FFmpeg の計画（レンディション、引数、ストーリーボード）
- `video/video.objects.ts`: 動画のすべてのファイルを R2 から削除する `removeVideoObjects`
- `video-upload/video-upload.files.ts`: アップロード元ファイルの R2 キー、受け付ける録画の種類、パートとそのフォームデータ
- `video-upload/video-upload.objects.ts`: 削除されるレッスンのアップロードと、その R2 からの削除（未完了のマルチパートアップロードは中止）
- `video-upload/video-upload.encoder.ts`: エンコーダーがアップロードに対して実行するクエリ（`queuedUploadsQuery`、`startEncodingQuery`、`failEncodingQuery`、`finishEncodingQueries`）。`scripts/encode-videos.ts` とブラウザテストのテスト用 Worker が共有します
- `account/account.links.ts`: `accountEmailLinks`。アカウントメールのコールバックのロケールで作る、サインインとパスワード再設定のリンク
- `business-profile/business-profile.logo.ts`: ロゴの R2 キー、縮小後の長辺の上限、アップロードと保存に使える形式、アップロードフォーム。純粋な関数です
- `business-profile/business-profile.delivery.ts`: `serveBusinessLogo`。`/media/logos/` へのリクエストにエッジキャッシュまたは R2 から応答します
- `course/course.cover.ts`: カバーの R2 キー、サイズと幅、アップロードフォーム、コースページが表示して共有する画像（`courseCoverImage`、`courseShareImage`）
- `course/course.delivery.ts`: `/media/covers/` へのリクエストにエッジキャッシュまたは R2 から応答する `serveCover` と、D1 から `/sitemap-courses.xml` を書き出す `serveCourseSitemap`
- `course/course.objects.ts`: `removeCoverObjects`。差し替えた、または削除したカバーを R2 から消します
- `course/course.transfer.ts`: エクスポートが書き出してインポートが読み込むコースドキュメント、そのドライランとインポート（`exportCourseDocument`、`planCourseImport`、`applyCourseImport`）
- `license/license.upgrades.ts`: ライセンスの階層より上の階層と、アップグレードのチェックアウトのメタデータ（`higherTiers`、`upgradeMetadata`）
- `order/order.checkout.ts`: サイトが開始するすべての Polar チェックアウトを作成する `createCheckout` と、機能が独自のチェックアウトで商品を販売するかどうかを返す `hasOwnCheckout`
- `order/order.polar.ts`: Polar の注文の割引と請求先の国を返す `polarOrderTerms` と、その小計、純額、返金された税を返す `polarOrderAmounts`
- `newsletter-issue/newsletter-issue.audience.ts`: `issueAudience` と `afterRecipient`。号の送信先となる確認済みの購読者と、最後に届いた購読者より後の購読者
- `session/session.rewrite.ts`: セッションクッキーを持つリクエストに対して `<html>` に `data-session`（`SESSION_ATTRIBUTE`）を設定するドキュメントの書き換え `markSession`、データベースを読まずにクッキーの有無を調べる `carriesSessionCookie`、Better Auth が設定するとおりのクッキー名（`SESSION_COOKIE_NAMES`）
- `invitation/invitation.plugin.ts`: `invitationPlugin`。招待されたアカウントを作成し、招待を使用済みにしてセッションを開始する、サーバー専用の Better Auth エンドポイント

## サーバー側で実行されるプレーンなユースケース

次のユースケースは、RPC エンドポイントを持たない async 関数です。Better Auth のフック、Polar の Webhook ハンドラー、または他のユースケースから呼び出されます。対象は <RepositoryFact name="plainUseCases" /> です。
