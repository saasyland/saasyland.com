- 修正: スクロールバーが現れたり消えたりしても、コンテンツが横にずれなくなりました。`html` が `scrollbar-gutter: stable` でスクロールバーの場所を確保するため、ページはスクロールするかどうかに関係なく、伸びている間も、ダイアログ、ポップオーバー、メニューがスクロールを止めている間も同じ位置にとどまります。ウィンドウの代わりにコンテンツ領域をスクロールする `/app` と `/admin` は、その領域に `data-page-scroller` を付けて場所をそこで確保し、ウィンドウいっぱいに広がります。透明なトラックを持つ細いページのスクロールバーは、`body` から、ブラウザーがウィンドウのスクロールバーのスタイルを読む唯一の要素である `html` に移りました。ランディング、認証、ブログ、コースのページの背後では `html` がダークのトークンを使うため、ライトテーマでも確保した場所には明るい帯ではなくダークな背景が見えます。React Aria と Base UI はすでに `scrollbar-gutter` でスクロールを止めるため、二重に補うことはありません。`e2e/specs/scrollbars.spec.ts` がクラシックなスクロールバーの Chromium ですべてを確認します。[スクロールバー](/docs/ui/theme#scrollbars)を参照してください。
