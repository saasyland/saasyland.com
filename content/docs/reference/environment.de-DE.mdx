## Umgebungsdateien

| Datei              | Eingecheckt | Verwendet von                                                                                                                 |
| ------------------ | ----------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `.env.example`     | Ja          | Führt jedes Secret mit leerem Wert auf                                                                                        |
| `.env.development` | Nein        | `bun run dev`, `polar:verify:development`, `db:studio:development`, `db:introspect:development`                               |
| `.env.preview`     | Nein        | `deploy:preview` (die deklarierten Secrets), `polar:verify:preview`, `db:studio:preview`, `db:introspect:preview`             |
| `.env.production`  | Nein        | `deploy:production` (die deklarierten Secrets), `polar:verify:production`, `db:studio:production`, `db:introspect:production` |
| `.env.test`        | Ja          | Vitest und die Wrangler-Umgebung `test`; nur Dummy-Werte                                                                      |

## Variablen

| Variable                    | Verwendet von                                                                                                   |
| --------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `AUTH_SECRET`               | Signierung, Verschlüsselung und E-Mail-Verifizierungstokens von Better Auth                                     |
| `AUTH_GITHUB_CLIENT_ID`     | GitHub-OAuth; authentifiziert außerdem die Abfrage der GitHub-Sterne                                            |
| `AUTH_GITHUB_CLIENT_SECRET` | GitHub-OAuth; authentifiziert außerdem die Abfrage der GitHub-Sterne                                            |
| `AUTH_GOOGLE_CLIENT_ID`     | Google-OAuth                                                                                                    |
| `AUTH_GOOGLE_CLIENT_SECRET` | Google-OAuth                                                                                                    |
| `RESEND_API_KEY`            | Der Resend-Client                                                                                               |
| `RESEND_EMAIL_FROM`         | Der Standardabsender für `sendEmail`                                                                            |
| `POLAR_ACCESS_TOKEN`        | Der Polar-SDK-Client                                                                                            |
| `POLAR_SERVER`              | `sandbox` für Entwicklung und Preview, `production` für die Produktion                                          |
| `POLAR_WEBHOOK_SECRET`      | Prüfung der Signaturen von Polar-Webhooks                                                                       |
| `POLAR_ORGANIZATION_ID`     | Deaktivierung von Polar-Lizenzschlüsseln und Abfrage von Rabatten                                               |
| `POLAR_PRODUCT_ID_CORE`     | Checkout-Produkt für den Core-Tarif                                                                             |
| `POLAR_PRODUCT_ID_COMPLETE` | Checkout-Produkt für den Complete-Tarif                                                                         |
| `POLAR_PRODUCT_ID_AGENCY`   | Checkout-Produkt für den Agency-Tarif                                                                           |
| `CLOUDFLARE_ACCOUNT_ID`     | D1-HTTP-Treiber von Drizzle Kit                                                                                 |
| `CLOUDFLARE_DATABASE_ID`    | D1-HTTP-Treiber von Drizzle Kit                                                                                 |
| `CLOUDFLARE_ACCESS_TOKEN`   | D1-HTTP-Treiber von Drizzle Kit                                                                                 |
| `AFFONSO_PROGRAM_ID`        | Optionale öffentliche Programm-ID von Affonso, die das Tracking von Partnerempfehlungen einschaltet             |
| `FFMPEG`, `FFPROBE`         | Optionale FFmpeg- und ffprobe-Binärdateien für `scripts/publish-video.ts`; standardmäßig `ffmpeg` und `ffprobe` |

Jede Umgebung in `wrangler.jsonc` listet die Secrets, die sie braucht, unter `secrets.required` auf; die Umgebung `test` lässt die drei Cloudflare-Variablen weg. `AFFONSO_PROGRAM_ID` ist kein Secret: Die ID steht im Script-Tag der Seite und ist deshalb eine Worker-Variable unter `vars`, die nur für die Umgebung gesetzt wird, die echte Zahlungen annimmt. Derzeit setzt nur `test` eine, eine Dummy-ID für die Browsertests ([Partnerprogramm](/docs/features/affiliates)). `FFMPEG` und `FFPROBE` sind optionale Shell-Variablen für `scripts/publish-video.ts`, keine Worker-Secrets. Worker-Code liest sie aus `env` in `cloudflare:workers`, typisiert durch `src/types/bindings.d.ts`. Es gibt keine `VITE_`-Variablen: Die öffentliche URL und die Domain sind Konstanten in `src/presentation/branding`.

## Bindings

| Binding  | Typ              | `development`             | `preview` | `production` | `test`                 |
| -------- | ---------------- | ------------------------- | --------- | ------------ | ---------------------- |
| `DB`     | D1               | Preview-Datenbank, remote | Preview   | Produktion   | Lokal `saasyland_test` |
| `CACHE`  | KV               | Preview-Namespace, remote | Preview   | Produktion   | Lokal                  |
| `MEDIA`  | R2               | Preview-Bucket, remote    | Preview   | Produktion   | Lokal `saasyland-test` |
| `ASSETS` | Statische Assets | Ja                        | Ja        | Ja           | Ja                     |

Die Deploy-Skripte für Preview und Produktion führen zuerst `scripts/verify-bindings.ts` aus. Das Skript schlägt fehl, solange einer Umgebung ein Binding fehlt oder sie noch Platzhalter-IDs für D1 oder KV enthält, und wenn die Produktion eine Ressource mit Preview teilt. R2-Buckets sind über ihren Namen gebunden (`saasyland-preview` für Entwicklung und Preview, `saasyland` für Produktion) und müssen vor einem Deployment existieren.
