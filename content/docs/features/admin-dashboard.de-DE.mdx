## Route

`/admin` — erstellt ein Statistik-Raster, ein Diagramm und eine Benutzerübersicht mit Suspense.

Bevorzugen Sie echte Aggregationen über Module, während Sie Metriken weiterentwickeln; halten Sie die Grundstrukturen frei von Imports, die ausschließlich auf Server-seitiger Logik basieren.
