Each section lists the changes that reached `main` on that day in UTC, newest first, and each change ends with a link to the pull request it came from. Every production deploy is tagged and published as a GitHub Release with its day's section as the notes; see [Releases and tags](/docs/tooling/ci-cd#releases-and-tags). The CLI's own releases are in the [CLI release notes](/docs/cli/releases). Each change adds its own entry, as [Changelog entries](/docs/conventions/git-workflow#changelog-entries) describes.
