---

`src/providers` zawiera cztery providery. Każdy jest montowany jak najbliżej komponentów, które z niego korzystają.

| Provider               | Opakowuje                                                                                                                                         | Miejsce montowania                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `TranslationsProvider` | `IntlProvider` z use-intl z głównymi przestrzeniami nazw i przestrzeniami dopasowanych tras, nazwanymi formatami dat i strefą czasową użytkownika | Rama dokumentu w trasie głównej, wokół body dokumentu                               |
| `AriaProvider`         | `I18nProvider` i `RouterProvider` z React Aria                                                                                                    | Główny komponent, wokół każdej trasy                                                |
| `ThemeProvider`        | Provider `@wrksz/themes`, zapisywany w cookie                                                                                                     | Wokół `Toaster` w trasie głównej i przełącznika motywu w pasku bocznym dokumentacji |
| `MotionProvider`       | `LazyMotion` (strict) i `MotionConfig` z `reducedMotion="user"` z Motion                                                                          | Strona główna, lista wpisów bloga, strony archiwum bloga i `LicenseOffer`           |

## Kompozycja w trasie głównej

`src/routes/__root.tsx` renderuje dokument w `shellComponent`, a aplikację w `component`:

```tsx
const RootComponent = () => (
  <AriaProvider>
    <OfflineBanner />
    {ROOT_COMPONENTS.map(({ component: Component, key }) => (
      <Component key={key} />
    ))}
    <Outlet />
    <ThemeProvider>
      <Toaster />
    </ThemeProvider>
  </AriaProvider>
)
```

- **TranslationsProvider** znajduje się w `<body>` ramy dokumentu, więc przetłumaczony jest każdy ekran, łącznie z domyślnymi komponentami błędu i nieznalezionej strony oraz szkieletami tras. Zbiera główne przestrzenie nazw oraz `staticData.namespaces` każdej dopasowanej trasy, ładuje je przez `useSuspenseQueries` i buduje jedno drzewo komunikatów. Przekazuje też `I18N.FORMATS` oraz strefę czasową pierwszego źródła strefy czasowej, które deklaruje obszar (`TIME_ZONE_HOOKS`), a gdy żadnego nie ma – `UTC`. Źródło z obszaru uwierzytelniania odczytuje sesję wczytaną przez guardy tras (bez sesji daje `UTC`) i nigdy sam jej nie pobiera; zobacz [Internacjonalizacja i języki](/docs/features/internationalization).
- **AriaProvider** przekazuje bieżący język do React Aria i łączy linki React Aria z TanStack Router. Jego `useHref` lokalizuje ścieżki, więc `href` w komponencie React Aria dostaje prefiks języka.
- **ThemeProvider** nie opakowuje outletu trasy. Provider aktualizowany po hydratacji powodowałby ponowne renderowanie każdej strony, dlatego opakowuje tylko komponenty, które go potrzebują. Początkowy motyw jest stosowany przed hydratacją przez `ThemeScript` w sekcji head dokumentu.
- **MotionProvider** ładuje zestaw funkcji `domMax` na żądanie i jest montowany tylko tam, gdzie działają animacje: `_site._marketing.index.tsx`, `_site._marketing.blog.index.tsx`, `_site._marketing.blog.page.$page.tsx` i `license-offer.tsx`, czyli karty pakietów na `/app` i `/app/license`. Łatka Bun dla `framer-motion` 14.14.0 sprawia, że `LazyMotion` pomija zestaw, którego nie udało się załadować, na przykład gdy Safari go przerywa, bo odwiedzający opuszcza stronę, więc komponenty renderują się bez animacji, zamiast żeby strona zgłaszała nieobsłużone odrzucenie obietnicy.
- **ROOT_COMPONENTS** nie są providerami, tylko komponentami, które obszary montują obok outletu, zadeklarowanymi w `src/areas/<area>.ts` (zobacz [Co dodają obszary](/docs/architecture/platform-layer#what-the-areas-add)). Gdy program partnerski jest otwarty (`AFFILIATE_PROGRAM`), obszar partnerski dodaje `AffiliateReferral`, który renderuje skrypt Affonso tylko podczas wizyty z parametrem polecenia ([Program partnerski](/docs/features/affiliates)).

## Co nie jest komponentem providera

- **QueryClient.** `src/router.tsx` tworzy go dla każdego żądania, umieszcza w kontekście routera i podłącza przez `setupRouterSsrQueryIntegration`.
- **Fumadocs.** Layout `/docs` montuje `RootProvider` z Fumadocs z wyłączoną własną obsługą motywu.
- **Naciśnięcia po przeciągnięciu.** Po każdym przeciągnięciu i upuszczeniu Safari zgłasza kolejne naciśnięcie przycisku myszy jako `pointermove` zamiast `pointerdown` ([błąd WebKit 202287](https://bugs.webkit.org/show_bug.cgi?id=202287)), więc React Aria, które zaczyna naciśnięcie od `pointerdown`, ignorowało pierwsze kliknięcie po przeciągnięciu. Komponent główny uruchamia w efekcie `restoreLostPointerDowns` z `src/lib/lost-pointer-down.ts`: dla `pointermove`, który zgłasza naciśnięcie głównego przycisku myszy bez żadnego innego wciśniętego przycisku, czego żadna przeglądarka poza tym nie wysyła, wywołuje brakujące `pointerdown` w tym samym miejscu.
