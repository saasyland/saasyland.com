- Release: quando un deploy di produzione va a buon fine, la CI assegna al commit distribuito il tag `vYYYY.MM.DD` con la data UTC (`.2`, `.3` e così via per i deploy successivi dello stesso giorno) e pubblica una GitHub Release le cui note sono la sezione di quel giorno di questo changelog. I deploy di preview non ricevono tag. Vedi [Release e tag](/docs/tooling/ci-cd#releases-and-tags).
