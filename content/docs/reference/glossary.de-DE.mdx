- **Route:** Eine native TanStack-Route mit einer Komponente, einer Sicherheitsprüfung (Guard), einem Loader oder einem HTTP-Handler.
- **Serverfunktion:** Eine typisierte RPC-Operation, die mit `createServerFn` erstellt wurde.
- **Query:** zwischengespeicherte Lesedaten mit einem stabilen Schlüssel, die Loader und React gemeinsam nutzen.
- **Mutation:** Eine Operation, die über TanStack Query übermittelt und durch eine serverseitige Funktion unterstützt wird.
- **Namespace:** Eine durch Punkte getrennte Übersetzungsdatei innerhalb eines Ländercode-Verzeichnisses.
- **Binding:** Eine Cloudflare-Ressource, die dem Worker als `env.DB`, `env.CACHE` oder `env.ASSETS` zur Verfügung gestellt wird.
- **Prerender:** Erstellung von HTML im Build-Zeitpunkt für eine öffentlich zugängliche Route.
