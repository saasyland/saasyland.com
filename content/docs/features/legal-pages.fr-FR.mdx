| Route         | Fichier de route                     | Espace de noms           |
| ------------- | ------------------------------------ | ------------------------ |
| `/privacy`    | `src/routes/_landing.privacy.tsx`    | `pages.legal.privacy`    |
| `/terms`      | `src/routes/_landing.terms.tsx`      | `pages.legal.terms`      |
| `/refunds`    | `src/routes/_landing.refunds.tsx`    | `pages.legal.refunds`    |
| `/licence`    | `src/routes/_landing.licence.tsx`    | `pages.legal.licence`    |
| `/affiliates` | `src/routes/_landing.affiliates.tsx` | `pages.legal.affiliates` |

Chaque fichier de route définit son propre composant de page, un `NAMESPACE` statique et une constante de module contenant les clés de section dans l’ordre d’affichage :

```tsx
const SECTIONS = ["operator", "accounts", "purchases", "payments", "licence", "conduct", "refunds", "responsibility", "law"] as const
```

La page affiche `lastUpdated`, `title` et `description`, puis `sections.<key>.title` et `sections.<key>.body` pour chaque clé. Il n’existe pas de composant légal partagé. La politique de confidentialité et les conditions d’affiliation transmettent à leurs messages les valeurs de `AFFILIATE_TERMS` (`src/data/affiliates.ts`), si bien que la commission, la durée du cookie, la période de rétention et le seuil de versement ne sont jamais saisis en dur dans les textes.

## Modification

- Modifiez les textes dans `messages/<locale>/pages.legal.<doc>.json` pour toutes les langues et lancez `bun run check:i18n`.
- Pour ajouter une section, ajoutez sa clé à `SECTIONS` et ses messages dans chaque langue.
- Les liens du pied de page sont la constante `LEGAL_LINKS` dans `src/presentation/components/custom/footer.tsx`, et les conditions d’affiliation figurent dans `PAGE_LINKS` du même fichier ; la page d’inscription renvoie vers les conditions et la politique de confidentialité.

La page de licence distingue la licence MIT du dépôt public du matériel payant fourni séparément. La politique de remboursement préserve les droits impératifs des consommateurs. Alignez chaque document sur l’exploitant, le paiement, les prestataires et le traitement des données réels.
