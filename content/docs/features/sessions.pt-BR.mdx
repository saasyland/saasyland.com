---
title: "Sessões"
description: "Sessões do Better Auth no D1, com revogação em autoatendimento nas configurações administrativas e revogação das sessões de qualquer usuário a partir do perfil administrativo dele."
---

As sessões ficam na tabela `session` do D1 (`src/modules/session/session.schema.ts`). `auth.session.ts` as lê com `getRequestSession`, memorizada por requisição, e expõe `getCurrentSessionQuery` para rotas e componentes. A cópia do cliente nunca inclui o token de sessão.

## Casos de uso

| Caso de uso                               | Middleware                          | Usado por          |
| ----------------------------------------- | ----------------------------------- | ------------------ |
| `getActiveSessions`                       | logado                              | `SettingsSessions` |
| `revokeSession`                           | logado; somente as próprias sessões | `SessionRow`       |
| `revokeOtherSessions`                     | logado                              | `SettingsSessions` |
| `listUserSessions`                        | `session: ["list"]`                 | `UserSessions`     |
| `revokeUserSession`, `revokeUserSessions` | `session: ["revoke"]`               | `UserSessions`     |

`getActiveSessions` retorna as sessões não expiradas do usuário atual, das mais recentes para as mais antigas, e deixa de fora as sessões de personificação. `listUserSessions` retorna as sessões não expiradas de outro usuário a partir do `listUserSessions` do Better Auth, das mais recentes para as mais antigas e sem os tokens, incluindo as de personificação. `revokeUserSession` recebe um ID de sessão e procura o token dela no servidor, então nenhum token chega ao navegador.

## Interface

**Configurações → Segurança** em `/admin/settings` mostra `SettingsSessions` (`src/presentation/components/custom/admin/settings/sessions.tsx`). Cada `SessionRow` mostra o dispositivo (user agent ou endereço IP), a última atividade e um selo na sessão atual, e pode revogar essa sessão. Um botão no cabeçalho revoga todas as outras sessões. Trocar a senha também atualiza a lista de sessões.

O perfil de um usuário em `/admin/users` mostra `UserSessions` (`src/presentation/components/custom/admin/users/user-sessions.tsx`): o dispositivo de cada sessão e quando ela começou e teve atividade pela última vez, um botão que a revoga e, após uma confirmação, um botão que desconecta o usuário em todos os lugares. Veja [Usuários (admin)](/docs/features/users-admin).
