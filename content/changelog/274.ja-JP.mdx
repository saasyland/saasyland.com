- 追加：lint ルール `code-style/no-comments`, `code-style/no-multiline-ternary`、`code-style/no-undefined-fallback` と、linter の外で TypeScript、JavaScript、CSS のすべてのファイルを解析する `bun run check:comments` を追加しました。これにより `bun run check` は、無効化コメントを含むあらゆるコメント、複数行にわたる三項演算子、`?? undefined` で失敗します。[コードスタイル](/docs/conventions/code-style)を参照してください。
- 変更：`typescript/ban-ts-comment` は説明付きでも `@ts-expect-error`, `@ts-ignore`、`@ts-nocheck` を拒否し、`typescript/consistent-type-assertions` は `as const` 以外のすべての型アサーションを拒否します。また、`eslint-disable` コメントはもうルールを無効にしません。[リントとフォーマット](/docs/tooling/lint-format)を参照してください。
- 追加：トレーラーで AI ツールの名前を挙げるコミットメッセージや、「Generated with」の行を含むコミットメッセージを拒否する `commit-msg` フックを追加しました。[Conventional Commits](/docs/tooling/conventional-commits)を参照してください。
