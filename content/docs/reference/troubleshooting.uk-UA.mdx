Якщо локальні запити повідомляють про відсутні таблиці, запустіть `bun run db:migrate:local`; використання веб-переглядачів `db:migrate:test` і окрема D1 обов'язкова. Якщо автентифікація не вдається, перевірте URL-адресу середовища, `AUTH_SECRET`, облікові дані провайдера та URL-адреси зворотного зв’язку.

Помилки перекладу, як правило, вказують на простір імен, що складається з маршруту або ключа, відсутній в одному локальному режимі. Зареєструватися `check:i18n`. . Для документації 404-х, перевірте локалізацію файлу MDX, посилання на сторінку метаданих та відносне джерело. Для хибних збоїв перевірте першу відмову URL у виході з збірки.

Відхилено для адресних обов’язків, які потребують реальних D1 та KV ID у цільовому середовищі. Побудувати і тестувати операції не створювати віддалені ресурси автоматично.
