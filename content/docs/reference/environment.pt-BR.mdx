## Arquivos de ambiente

| Arquivo            | Versionado | Usado por                                                                                                                  |
| ------------------ | ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| `.env.example`     | Sim        | Lista todos os secrets com valor vazio                                                                                     |
| `.env.development` | Não        | `bun run dev`, `polar:verify:development`, `db:studio:development`, `db:introspect:development`                            |
| `.env.preview`     | Não        | `deploy:preview` (os secrets declarados), `polar:verify:preview`, `db:studio:preview`, `db:introspect:preview`             |
| `.env.production`  | Não        | `deploy:production` (os secrets declarados), `polar:verify:production`, `db:studio:production`, `db:introspect:production` |
| `.env.test`        | Sim        | O Vitest e o ambiente Wrangler `test`; apenas valores fictícios                                                            |

## Variáveis

| Variável                    | Usada por                                                                                                   |
| --------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `AUTH_SECRET`               | Assinatura, criptografia e tokens de verificação de e-mail do Better Auth                                   |
| `AUTH_GITHUB_CLIENT_ID`     | OAuth do GitHub; também autentica a requisição da contagem de estrelas do GitHub                            |
| `AUTH_GITHUB_CLIENT_SECRET` | OAuth do GitHub; também autentica a requisição da contagem de estrelas do GitHub                            |
| `AUTH_GOOGLE_CLIENT_ID`     | OAuth do Google                                                                                             |
| `AUTH_GOOGLE_CLIENT_SECRET` | OAuth do Google                                                                                             |
| `RESEND_API_KEY`            | O cliente do Resend                                                                                         |
| `RESEND_EMAIL_FROM`         | O remetente padrão de `sendEmail`                                                                           |
| `POLAR_ACCESS_TOKEN`        | O cliente do SDK do Polar                                                                                   |
| `POLAR_SERVER`              | `sandbox` para desenvolvimento e preview, `production` para produção                                        |
| `POLAR_WEBHOOK_SECRET`      | Verificação da assinatura dos webhooks do Polar                                                             |
| `POLAR_ORGANIZATION_ID`     | Desativação de chaves de licença e consulta de descontos no Polar                                           |
| `POLAR_PRODUCT_ID_CORE`     | Produto de checkout do plano Core                                                                           |
| `POLAR_PRODUCT_ID_COMPLETE` | Produto de checkout do plano Complete                                                                       |
| `POLAR_PRODUCT_ID_AGENCY`   | Produto de checkout do plano Agency                                                                         |
| `CLOUDFLARE_ACCOUNT_ID`     | O driver HTTP do D1 usado pelo Drizzle Kit                                                                  |
| `CLOUDFLARE_DATABASE_ID`    | O driver HTTP do D1 usado pelo Drizzle Kit                                                                  |
| `CLOUDFLARE_ACCESS_TOKEN`   | O driver HTTP do D1 usado pelo Drizzle Kit                                                                  |
| `AFFONSO_PROGRAM_ID`        | ID público opcional do programa no Affonso que ativa o rastreamento de indicações de afiliados              |
| `FFMPEG`, `FFPROBE`         | Binários opcionais do FFmpeg e do ffprobe para `scripts/publish-video.ts`; por padrão, `ffmpeg` e `ffprobe` |

Cada ambiente em `wrangler.jsonc` lista os secrets de que precisa em `secrets.required`; o ambiente `test` omite as três variáveis do Cloudflare. `AFFONSO_PROGRAM_ID` não é um secret: ele aparece na tag de script da página, então é uma variável do Worker em `vars`, definida apenas para o ambiente que recebe pagamentos reais. Hoje só `test` define uma, um ID fictício para os testes no navegador ([Programa de afiliados](/docs/features/affiliates)). `FFMPEG` e `FFPROBE` são variáveis de shell opcionais para `scripts/publish-video.ts`, e não secrets do Worker. O código do Worker as lê de `env` em `cloudflare:workers`, com os tipos definidos em `src/types/bindings.d.ts`. Não existem variáveis `VITE_`: a URL pública e o domínio são constantes em `src/presentation/branding`.

## Bindings

| Binding  | Tipo             | `development`                | `preview` | `production` | `test`                 |
| -------- | ---------------- | ---------------------------- | --------- | ------------ | ---------------------- |
| `DB`     | D1               | Banco de preview, remoto     | Preview   | Produção     | `saasyland_test` local |
| `CACHE`  | KV               | Namespace de preview, remoto | Preview   | Produção     | Local                  |
| `MEDIA`  | R2               | Bucket de preview, remoto    | Preview   | Produção     | `saasyland-test` local |
| `ASSETS` | Assets estáticos | Sim                          | Sim       | Sim          | Sim                    |

Os scripts de deploy de preview e de produção executam primeiro `scripts/verify-bindings.ts`, que falha enquanto um ambiente não tiver um binding ou ainda tiver IDs provisórios de D1 ou KV, e quando a produção compartilha um recurso com o preview. Os buckets do R2 são vinculados pelo nome (`saasyland-preview` para desenvolvimento e preview, `saasyland` para produção) e precisam existir antes de um deploy.
