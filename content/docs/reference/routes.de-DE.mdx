---

Jeder Pfad hat eine Konstante in `ROUTES` (`src/routes.ts`). Links verwenden die Konstante, zum Beispiel `<Link to={ROUTES.SIGN_IN}>`, und der Router fügt das Locale-Präfix hinzu. Jede der unten aufgeführten Seiten wird außerdem unter dem Präfix jeder Nicht-Standard-Locale ausgeliefert, zum Beispiel `/pl-PL/terms`.

## Authentifizierung

Das `/auth`-Layout (`auth.tsx`) hat keinen Guard; die einzelnen Seiten schon.

| Pfad                    | Konstante         | Routendatei                | Guard                                                                     |
| ----------------------- | ----------------- | -------------------------- | ------------------------------------------------------------------------- |
| `/auth/sign-in`         | `SIGN_IN`         | `auth.sign-in.tsx`         | `redirectIfSignedIn`                                                      |
| `/auth/sign-up`         | `SIGN_UP`         | `auth.sign-up.tsx`         | `redirectIfSignedIn`                                                      |
| `/auth/forgot-password` | `FORGOT_PASSWORD` | `auth.forgot-password.tsx` | keiner                                                                    |
| `/auth/reset-password`  | `RESET_PASSWORD`  | `auth.reset-password.tsx`  | keiner                                                                    |

## API

API-Pfade werden nie lokalisiert.

| Pfad          | Konstante       | Routendatei     |
| ------------- | --------------- | --------------- |
| `/api`        | `API`           | `api/index.ts`  |
| `/api/auth/*` | `API_AUTH_BASE` | `api/auth.$.ts` |
| `/api/search` | keine           | `api/search.ts` |

`ROUTES.API_AUTH` listet die Pfade der Better-Auth-Endpunkte relativ zu `/api/auth` auf; `auth.server.ts` nutzt sie, um Endpunkte vom Rate Limiting auszunehmen. `API_AUTH_CUSTOMER_PORTAL` und `API_AUTH_VERIFY_EMAIL` sind vollständige Pfade zu Better-Auth-Endpunkten. `AUTH` und `NEWSLETTER` haben keine eigene Seite; zusammen mit `ADMIN`, `APP` und `API` markieren sie die Bereiche, die nie vorgerendert werden.
