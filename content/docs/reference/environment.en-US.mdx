## Environment files

| File               | Committed | Used by                                                                                        |
| ------------------ | --------- | ---------------------------------------------------------------------------------------------- |
| `.env.example`     | Yes       | Lists every secret with an empty value                                                         |
| `.env.development` | No        | `bun run dev`, `db:studio:development`, `db:introspect:development`                            |
| `.env.preview`     | No        | `deploy:preview` (the declared secrets), `db:studio:preview`, `db:introspect:preview`          |
| `.env.production`  | No        | `deploy:production` (the declared secrets), `db:studio:production`, `db:introspect:production` |
| `.env.test`        | Yes       | Vitest and the `test` Wrangler environment; dummy values only                                  |

## Variables

| Variable                    | Used by                                                                                                |
| --------------------------- | ------------------------------------------------------------------------------------------------------ |
| `AUTH_SECRET`               | Better Auth signing, encryption and email verification tokens                                          |
| `AUTH_GITHUB_CLIENT_ID`     | GitHub OAuth; also authenticates the GitHub star count request                                         |
| `AUTH_GITHUB_CLIENT_SECRET` | GitHub OAuth; also authenticates the GitHub star count request                                         |
| `AUTH_GOOGLE_CLIENT_ID`     | Google OAuth                                                                                           |
| `AUTH_GOOGLE_CLIENT_SECRET` | Google OAuth                                                                                           |
| `RESEND_API_KEY`            | The Resend client                                                                                      |
| `RESEND_EMAIL_FROM`         | The default sender for `sendEmail`                                                                     |
| `POLAR_ACCESS_TOKEN`        | The Polar SDK client                                                                                   |
| `POLAR_SERVER`              | `sandbox` or `production`                                                                              |
| `POLAR_WEBHOOK_SECRET`      | Polar webhook signature verification                                                                   |
| `POLAR_ORGANIZATION_ID`     | Polar licence key deactivation and discount lookup                                                     |
| `POLAR_PRODUCT_ID_CORE`     | Checkout product for the Core tier                                                                     |
| `POLAR_PRODUCT_ID_COMPLETE` | Checkout product for the Complete tier                                                                 |
| `POLAR_PRODUCT_ID_AGENCY`   | Checkout product for the Agency tier                                                                   |
| `CLOUDFLARE_ACCOUNT_ID`     | Drizzle Kit's D1 HTTP driver                                                                           |
| `CLOUDFLARE_DATABASE_ID`    | Drizzle Kit's D1 HTTP driver                                                                           |
| `CLOUDFLARE_ACCESS_TOKEN`   | Drizzle Kit's D1 HTTP driver                                                                           |
| `AFFONSO_PROGRAM_ID`        | Optional public Affonso program ID that turns on affiliate referral tracking                           |
| `FFMPEG`, `FFPROBE`         | Optional FFmpeg and ffprobe binaries for `scripts/publish-video.ts`; `ffmpeg` and `ffprobe` by default |

Every environment in `wrangler.jsonc` lists the secrets it needs under `secrets.required`; the `test` environment omits the three Cloudflare variables. `AFFONSO_PROGRAM_ID` is not a secret: it appears in the page's script tag, so it is a Worker variable under `vars`, set only for the environment that takes real payments. Only `test` sets one now, a dummy ID for the browser tests ([Affiliate programme](/docs/features/affiliates)). `FFMPEG` and `FFPROBE` are optional shell variables for `scripts/publish-video.ts`, not Worker secrets. Worker code reads them from `env` in `cloudflare:workers`, typed by `src/types/bindings.d.ts`. There are no `VITE_` variables: the public URL and domain are constants in `src/presentation/branding`.

## Bindings

| Binding  | Type          | `development`             | `preview` | `production` | `test`                 |
| -------- | ------------- | ------------------------- | --------- | ------------ | ---------------------- |
| `DB`     | D1            | Preview database, remote  | Preview   | Production   | Local `saasyland_test` |
| `CACHE`  | KV            | Preview namespace, remote | Preview   | Production   | Local                  |
| `MEDIA`  | R2            | Preview bucket, remote    | Preview   | Production   | Local `saasyland-test` |
| `ASSETS` | Static assets | Yes                       | Yes       | Yes          | Yes                    |

Preview and production deploy scripts run `scripts/verify-bindings.ts` first, which fails while an environment lacks a binding or still has placeholder D1 or KV IDs, and when production shares a resource with preview. R2 buckets are bound by name (`saasyland-preview` for development and preview, `saasyland` for production) and must exist before a deploy.
