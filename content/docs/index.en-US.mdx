SaaSy Land is the source of the saasyland.com website, customer workspace and admin console: one TanStack Start application on Cloudflare Workers with D1, KV, R2, Better Auth, Polar, Resend, use-intl and Fumadocs. The SaaSy Land CLI and its generator templates live in a separate, private repository.

<Callout title="How to use these docs">
  Start with **Getting started** to run the application. **Architecture** explains where code lives, **Conventions** are the rules every
  change follows, **Guides** are task recipes, **Features** describe product behaviour and **Integrations** document the vendor adapters
  under `src/integrations`.
</Callout>

## Editing the docs

Pages live in `content/docs` as `<slug>.<locale>.mdx`, one file for each of the nine locales, and every folder lists its pages in `meta.<locale>.json`. All locales list the same slugs and keep code blocks byte-identical; `bun run check:i18n` enforces this through `scripts/check-content.ts`. `bun run content` regenerates `.source/`, and `dev` and every build script run it for you.

MDX pages can use Fumadocs components (`<Cards>`, `<Callout>`, `<Steps>`, `<Tabs>`, `<Accordions>`) and selected shadcn primitives (`<Button>`, `<Badge>`, `<Alert>`, `<Table>`). Internal links such as `/docs/tooling/testing` receive the reader's locale prefix automatically.
