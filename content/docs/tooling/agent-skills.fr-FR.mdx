---
title: "Skills pour agents"
description: "Skills des fournisseurs pour les agents de codage, restaurées à partir de skills-lock.json."
---

`skills-lock.json` fixe les versions des skills pour agents utilisées avec ce dépôt. Les skills installées ne sont pas versionnées : `.agents/` et `.claude/` sont ignorés par Git.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` supprime `.agents/skills` et `.claude/skills`, réinstalle chaque skill verrouillée avec `bunx skills experimental_install`, déplace chaque skill dans un groupe de fournisseur sous `.agents/skills/<group>/<skill>/SKILL.md` et crée un lien vers chaque groupe dans `.claude/skills`. Il échoue lorsqu'une source de skill n'est associée à aucun groupe.

| Groupe                                                | Source                                                              |
| ----------------------------------------------------- | ------------------------------------------------------------------- |
| `anthropic`                                           | `anthropics/skills`                                                 |
| `better-auth`                                         | `better-auth/skills`                                                |
| `cloudflare`                                          | `cloudflare/skills`                                                 |
| `polar`                                               | `polarsource/skills`                                                |
| `resend`                                              | `resend/resend-skills`                                              |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) et `TanStack/table` (`table`) |
| `remotion`                                            | `remotion-dev/skills`                                               |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Skills généralistes d'ingénierie, de design et de marketing         |

La synchronisation remplace les deux répertoires : conservez donc vos skills personnalisées ailleurs. `bun run clean:hardcore` supprime `skills-lock.json`.

## Règle

Avant de modifier du code qui touche à TanStack Start, Router ou Table, Better Auth, Cloudflare, Polar ou Resend, lisez la skill correspondante. Les skills décrivent les API actuelles des fournisseurs ; les conventions de ce dépôt sont documentées dans [Architecture](/docs/architecture) et [Conventions](/docs/reference/conventions).
