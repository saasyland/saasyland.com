> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

## Naming

- Use-cases: `verb-noun.use-case.ts`
- Tests: colocated `__test__`
- Route privates: `_components`, `_lib`

## Commits

Conventional commits (`feat`, `fix`, `refactor`, …) with emoji prefix via `scripts/commit-msg.ts`.

## PRs

Lead with user-facing type (`feat` when behavior changes). Note refactors in the body.
