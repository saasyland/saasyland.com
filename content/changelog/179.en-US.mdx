- Fixed: two browser tests that WebKit failed now and then. The locales spec waits for each client-side navigation to render before it leaves the page, because WebKit reports a request that a page starts after it has begun to leave as a page error (`Fetch API cannot load … due to access control checks.`), even when the app handles the failed request. The logo test on the landing page loads the course block before it scrolls: the block filled in while the page scrolled back to the top, its height changed above the viewport, and WebKit stops a smooth scroll when scroll anchoring makes up for such a change. The [Testing](/docs/conventions/testing) page describes both.
