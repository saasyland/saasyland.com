title: "TanStack Table"
description: "TanStack Table v9 derrière un DataTable générique unique."
---

Chaque tableau est rendu par un seul `DataTable` générique dans `src/presentation/components/custom/data-table.tsx`. Il crée une instance TanStack Table v9 avec `tableFeatures` (filtrage des colonnes, tri, pagination et sélection des lignes) et `useTable`, puis rend les primitives de tableau shadcn, des lignes squelettes pendant le chargement et un état vide localisé.

```tsx
<DataTable columns={userColumns} options={{ query: getUsersPageQuery, selectable: true }} />
```

## Props

| Prop                   | Rôle                                                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `columns`              | Définitions des colonnes pour le type de ligne ; chaque ligne a besoin d'un `id`                                                                       |
| `data`                 | Lignes d'un tableau qui trie, filtre et pagine côté client                                                                                             |
| `options.initialState` | `pagination` et `sorting` initiaux                                                                                                                     |
| `options.query`        | Pagination et tri côté serveur : une fonction de `pageIndex`, `pageSize` et `sorting` qui renvoie des options de requête résolues en `rows` et `total` |
| `options.selectable`   | Ajoute une colonne de cases à cocher pour sélectionner les lignes                                                                                      |
| `filters`              | Filtres de recherche (`type: "search"`, `columnId`, `placeholder`) ou filtres de sélection (`type: "select"`, `columnId`, `label`, `options`)          |

Avec `options.query`, le tableau passe en pagination et en tri manuels, garde la page précédente visible pendant le chargement de la suivante et revient à la première page lorsque le tri change.

## Colonnes

Les colonnes se trouvent dans un fichier `<entity>-columns.tsx` à côté des widgets de la page et utilisent `createColumnHelper<DataTableFeatures, Row>()`. Les cellules et les en-têtes sont de petits composants qui lisent leurs propres traductions, si bien que la route ne transmet aucun libellé :

```tsx
const columnHelper = createColumnHelper<DataTableFeatures, AdminUser>()

export const userColumns = columnHelper.columns([
  columnHelper.accessor("role", { cell: RoleCell, header: () => <ColumnHeader id="role" /> }),
  columnHelper.accessor("createdAt", { cell: DateCell, header: () => <ColumnHeader id="createdAt" />, sortFn: "datetime" }),
])
```

L'exemple complet est `src/presentation/components/custom/admin/users/user-columns.tsx`, rendu par `src/routes/admin.users.all.tsx`.
