## Narzędzia

| Narzędzie | Wersja                                           | Do czego                                                                                                            |
| --------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| Bun       | <RepositoryFact name="bunVersion" />             | Menedżer pakietów i narzędzie do uruchamiania skryptów; wersję przypinają `packageManager` w `package.json` oraz CI |
| Node.js   | <RepositoryFact name="nodeVersion" /> lub nowszy | Wersja z `.nvmrc`, którą czytają `nvm use` i CI. Testowa baza danych korzysta z `node:sqlite`                       |
| Git       | Dowolna aktualna wersja                          | Krok instalacji konfiguruje hooki Git                                                                               |

Wrangler, drizzle-kit, Playwright i CLI Vite+ są zależnościami deweloperskimi; uruchamiaj je przez skrypty pakietu lub `bunx`. Testy przeglądarkowe wymagają też przeglądarek Playwright instalowanych poleceniem `bun run test:e2e:install`.

## Konta

Izolowany podgląd testowy i wszystkie testy automatyczne nie wymagają kont ani danych uwierzytelniających. Tryb deweloperski i wdrożenie korzystają z prawdziwych usług:

- Konto Cloudflare z D1, KV, R2 i Workers. Serwer deweloperski łączy się ze zdalnymi zasobami preview.
- Aplikacje OAuth w GitHubie i Google do logowania przez konta zewnętrzne.
- Resend ze zweryfikowanym nadawcą. Rejestracja e-mailem wymaga zweryfikowanego adresu, więc bez tego rejestracja nie działa.
- Polar, w trybie sandbox podczas pracy deweloperskiej, z trzema produktami dla planów Core, Complete i Agency.
