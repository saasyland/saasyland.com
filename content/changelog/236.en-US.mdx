- Fixed: the first click on **Docs**, on the logo from the docs or on **Blog** no longer waits a second or more on a new Worker isolate. Every server request first loads the route tree, and `/api/search` had put the Fumadocs source into it: the compiled MDX of every docs page and blog post in every locale, with their search text, and the whole Lucide icon set. The docs and blog collections are now `async`, so the Worker keeps each page's frontmatter and loads a page's MDX only when a request needs it; `/api/search` loads its index on its first request, and the docs import only the icons their meta files name. The route tree went from 1,635 modules and 21.7 MiB to 296 modules and 4.9 MiB, and each docs server function from 1,402 modules to 41. `scripts/verify-build.ts` fails the build when the route tree or a server function imports a compiled docs or blog page. See [Performance](/docs/conventions/performance#keep-the-route-tree-light).
- Changed: a navigation that has not finished after <RepositoryFact name="navigationPendingMs" unit="millisecond" /> shows its route's skeleton instead of showing nothing for a second, and the skeleton goes the moment the page is ready, because `defaultPendingMinMs` is <RepositoryFact name="navigationPendingMinMs" unit="millisecond" />. A navigation between docs pages shows the next page's skeleton beside the sidebar instead of keeping the previous page until the next one has loaded. See [Performance](/docs/conventions/performance#a-slow-navigation-shows-its-skeleton-at-once).
