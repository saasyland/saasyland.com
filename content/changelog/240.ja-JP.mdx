- 追加: ランディングページの実在のプロダクトに angularprojects.com が加わりました。本番品質の Angular アプリケーションを学べるコースプラットフォームで、SaaSy Land の Cloudflare、D1、Better Auth、Polar、Resend のスタックで動き、React と TanStack Start の代わりに Angular と Analog を使っています。セクションの見出しは「架空のお客様の声ではなく、本物のプロダクト。」です。カードは `src/data/marketing.ts` の `PRODUCT_CASES` から作られ、各プロダクトのホストと URL もここにあります。reactprojects.com と angularprojects.com はウェイトリストの登録を受け付けているため **ウェイトリスト受付中** と表示し、新しいタブでサイトを開きます。まだ公開されていない marte-bizuteria.pl は **リリース時に公開** のままで、リンクはありません。`lg` 以上では 3 枚のカードが 3 列に並びます。詳しくは [ランディングページ](/docs/features/landing-page#real-products) をご覧ください。
- 追加: Complete には reactprojects.com に加えて angularprojects.com への無料の生涯アクセスが含まれ、Agency のチーム席はコースと両方のプラットフォームに使えます。
- 修正: Complete のカードは reactprojects.com へのアクセスを **提供中** に表示しなくなりました。どちらのプラットフォームもまだウェイトリストの登録を受け付けている段階のため、アクセスは **提供予定** に表示されます。`REACTPROJECTS_ACCESS` と `ANGULARPROJECTS_ACCESS` が各プラットフォームのステータスを持ち、Complete についての FAQ の回答もこれに合わせて変わります。どちらかを `FEATURE_STATUS.AVAILABLE` にすると、そのプラットフォームは **提供中** に移ります。リリース記事、Supastarter の記事、[ロードマップ](/docs/project/roadmap) も同じ内容に更新しました。詳しくは [ランディングページ](/docs/features/landing-page) をご覧ください。
