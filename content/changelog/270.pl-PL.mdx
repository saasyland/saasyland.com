- Naprawiono: każdy punkt [listy zmian](/docs/project/changelog) kończy się pull requestem, z którego pochodzi, i wydaniem, które go dostarczyło, a nie tylko ostatni punkt każdego wpisu, a każdy punkt GitHub Release kończy się swoim `(#<number>)`. Wpis na liście zmian, który nie jest listą jednowierszowych punktów, powoduje teraz błąd `bun run check`. Zobacz [Wpisy na liście zmian](/docs/conventions/git-workflow#changelog-entries).
