Aplikacja udostępnia te trasy HTTP, zadeklarowane przez `server.handlers` w `createFileRoute` w `src/routes/api`:

| Trasa                                        | Metody            | Handler                                                                                                                                                                                                                                          |
| -------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `/api`                                       | GET               | Zwraca `{ "runtime": "cloudflare-workers" }`.                                                                                                                                                                                                    |
| `/api/auth/$`                                | GET, POST         | Better Auth: logowanie, adresy zwrotne OAuth, `/api/auth/verify-email` oraz endpointy wtyczki Polara `/api/auth/polar/webhooks` i `/api/auth/customer/portal`.                                                                                   |
| <RepositoryFact name="cliApiBasePath" />`/*` | GET, POST, DELETE | [API licencji CLI](/docs/features/cli-licence-api): `licenseApiHandlers` (`license.api.ts`) odczytują licencję, aktywują, sprawdzają i zwalniają urządzenia oraz podpisują adres pobierania paczki szablonów danego wydania dla CLI `saasyland`. |

```ts
import { createFileRoute } from "@tanstack/react-router"

import { auth } from "~/src/integrations/better-auth/auth.server"

export const Route = createFileRoute("/api/auth/$")({
  server: { handlers: { GET: ({ request }) => auth.handler(request), POST: ({ request }) => auth.handler(request) } },
})
```

## Funkcje serwerowe zamiast REST

Operacje aplikacji to funkcje `createServerFn` w `src/modules/<table>/use-cases`. Pozostałe leżą w `src/lib` (`getStarCount` w `github.ts`), w integracji (`getCurrentSession` w `auth.session.ts`) albo bezpośrednio w jedynej trasie, która ich używa. TanStack Start wywołuje je przez RPC pod `/_serverFn`, z middleware do sesji, uprawnień i limitów żądań. Nie dodawaj endpointu REST dla operacji, którą wywołuje tylko ta aplikacja; trasę HTTP dodawaj wyłącznie dla wywołań z zewnątrz, takich jak webhooki i CLI, a podpisy webhooków weryfikuj w integracji dostawcy.

## Zachowanie

- Worker pomija przekierowania językowe dla `/api` i `/_serverFn`. Ich adresy URL nie zawierają języka, więc `getCurrentLocale()` zwraca dla nich na serwerze `en-US`; kod, który potrzebuje języka, dostaje go w danych wejściowych albo odczytuje z `callbackURL`.
- Build nie prerenderuje `/api`.
- `/media/*` nie jest trasą TanStack Start: Worker kieruje tę ścieżkę do `serveMedia`, zanim zajmie się językiem. Zobacz [Cloudflare R2](/docs/integrations/cloudflare-r2). Nie jest nią też `/bundles/*`, którą Worker kieruje do `serveBundle`; zobacz [API licencji CLI](/docs/features/cli-licence-api#template-bundles).
- Testy handlerów leżą w `src/routes/api/__test__/`, po jednym pliku na handler: `auth.test.ts` i `index.test.ts`. `cli.v1.test.ts` obejmuje pliki tras API licencji CLI, którego działanie testuje `src/modules/license/__test__/license.api.integration.test.ts`, a paczki – `license.bundles.integration.test.ts`.
