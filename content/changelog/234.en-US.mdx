- Changed: every dependency is on its latest release. Vite+ moved to 1.7.0 through `vp migrate`, and its core now carries the version of the Vite release it bundles (8.3.8000 for Vite 8.3.8). `@polar-sh/sdk` moved to 1.3.0 with no code change, and its `overrides` entry follows to `^1.3.0`, because `@polar-sh/adapter-utils` still pins 1.0.2. Fumadocs, Video.js, TanStack Query, Lucide, React Email, React Resizable Panels, Testing Library's `user-event` and Wrangler took their patch releases. The patch to `@videojs/utils` is gone, because 10.5.0 ships the fix, and `@videojs/react` is no longer pinned. See [Dependencies](/docs/conventions/dependencies).
- Changed: the Fumadocs patch is gone, so `@fumadocs/base-ui` is no longer patched or pinned. Fumadocs declined the slot that let the docs layout leave out its own invisible skip link, so `globals.css` hides that link with `display: none`. The site's skip link, still the first stop of the Tab key in the one site header, now jumps on docs pages to the article under its Fumadocs id, `nd-page`. See [Docs site](/docs/features/docs-site).
