title: "インストール"
description: "依存関係をインストールし、ローカルのファイルを生成します。"
---

リポジトリをクローンし、ルートでコミット済みのロックファイルを使ってインストールします。

```sh
bun install --frozen-lockfile
```

その後、`prepare` ライフサイクルスクリプトが次の処理を行います。

1. `vp config --no-agent` を実行し、`.vite-hooks/` 用の Git フックディスパッチャー（pre-commit のチェックとコミットメッセージのフック）をインストールします。
2. `bun run generate:cn` を実行し、`.source/cn-tables.ts` にクラスマージ用のテーブルを生成します。
3. `bun run content` を実行し、`.source/` に Fumadocs のコレクションを生成します。

CI と同じように `--ignore-scripts` を付けてインストールした場合は、その後に `bun run typegen` を実行してください。このコマンドは `wrangler.jsonc` から `src/types/worker-configuration.d.ts` も再生成します。

## 任意の追加手順

```sh
bun run test:e2e:install
bun run skills:sync
```

1 つ目は Playwright 用に Chromium と WebKit をインストールし、2 つ目は[エージェントスキル](/docs/tooling/agent-skills)を復元します。
