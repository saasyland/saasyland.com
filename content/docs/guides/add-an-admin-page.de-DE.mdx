---
title: Fügen Sie eine Admin-Seite hinzu.
description: Registrieren Sie Routen, die Seitenleiste und die Seitenvorlage.
---

## Schritte.

1. Fügen Sie den Pfad zu `ROUTES` hinzu.
2. Fügen Sie einen Seiteneintrag in `admin/constants/sidebar.ts` hinzu (+ i18n-Beschriftungen).
3. Erstellen Sie `app/[locale]/(admin)/admin/<feature>/page.tsx`.
4. `_components` / `_lib` direkt beim jeweiligen Funktionsbereich ablegen
5. Sensordaten mit Anwendungsfällen + Spannung.
6. Funktionen (oder: Eigenschaften)
