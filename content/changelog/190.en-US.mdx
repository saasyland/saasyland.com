- Every page runs only the scripts it was served with, under a Content Security Policy that follows Google's strict CSP. A page the Worker renders gets a new nonce in its header with every response, and `src/server.ts` passes it to TanStack Start, which puts it on the router's, React's and the theme's scripts. A prerendered page is the same file for everyone and cannot carry a nonce, so `scripts/secure-prerendered-html.ts` hashes its inline scripts at build time, loads the entry module from a hashed inline loader that keeps the low-priority entry hint, and writes the policy into a meta tag. `'strict-dynamic'` lets those scripts load route chunks and the Affonso pixel. `base-uri` is now `'none'`, zod parses without probing for `eval`, and every browser spec fails when a page reports a violation.
