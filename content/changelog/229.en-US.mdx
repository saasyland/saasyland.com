- Added: a paid licence order whose Polar customer matches no account now emails the site's contact address an alert with the Polar order ID, the date, the tier, the amount, the buyer's email and name, a link to the order in the Polar dashboard and the steps that recover it. Before, the order was only logged. When the alert cannot be sent, the webhook fails, so Polar delivers it again. See [Licences](/docs/features/licences#orders-that-match-no-account).
- Added: the admin dashboard lists the paid licence orders that have no licence, from the D1 copies of Polar's orders, each linked to the order in Polar, and says so when there are none. See [Admin dashboard](/docs/features/admin-dashboard).
- Fixed: once the Polar customer of such an order is linked to an account, redelivering the order's `order.paid` and `benefit_grant.created` events grants the licence and stores its key. A redelivered event carries the customer as it was when Polar created the event, so when that customer matches no account the licence webhooks now read the order's current customer from Polar. See [Licences](/docs/features/licences#recovering-an-order).
