---
title: "Estado en la URL"
description: "Guarda pestañas, vistas y tokens de un solo uso en parámetros de búsqueda validados."
---

Los parámetros de búsqueda guardan el estado que debe sobrevivir a una recarga o a un enlace compartido: la pestaña o vista seleccionada, una dirección de correo que pasa entre páginas de autenticación o un token de verificación. Todo lo demás se queda en el estado de React. `DataTable` guarda su paginación, ordenación, selección y filtros en el estado del componente.

## Declara los parámetros

`validateSearch` convierte la query en bruto en un objeto tipado. Los valores desconocidos o no válidos vuelven a un valor por defecto en lugar de lanzar un error. De `src/routes/admin.blog.index.tsx`:

```tsx
validateSearch: (search: SearchSchemaInput & { view?: unknown }): { view: "grid" | "table" } => ({
  view: search.view === "table" ? "table" : "grid",
}),
search: { middlewares: [stripSearchParams({ view: "grid" })] },
```

`stripSearchParams` elimina el valor por defecto de la URL, así que `/admin/blog` sigue siendo la dirección canónica de la vista de cuadrícula.

## Léelos

- En el componente de la ruta: `const { view } = Route.useSearch()`.
- Con un selector, el componente solo se vuelve a renderizar cuando cambia el valor seleccionado: `Route.useSearch({ select: (search) => search.error !== "" })`.
- En un componente fuera del archivo de ruta: `getRouteApi("/auth/reset-password").useSearch()`, como en `reset-password-form.tsx`.

## Cámbialos

- Enlaces: `<Link search={{ view: id }} to={ROUTES.ADMIN_BLOG}>`.
- Los componentes de React Aria con `href`, como `TabsTrigger` en `src/routes/admin.products.index.tsx`, navegan a través del router porque `AriaProvider` conecta React Aria con TanStack Router.
- Código: `router.navigate({ search: { email }, to: ROUTES.VERIFY_EMAIL })`.
- Guards y loaders: `throw redirect({ replace: true, search: { status: "success" }, to: ROUTES.NEWSLETTER_UNSUBSCRIBE })`.

## Carga datos a partir de ellos

Un loader que depende de un parámetro de búsqueda lo declara en `loaderDeps` y lo lee de `deps`. La ruta de confirmación del boletín consume así un token y establece `preload: false`, para que pasar el ratón por encima de un enlace nunca gaste el token:

```tsx
loaderDeps: ({ search: { token } }) => ({ token: token ?? "" }),
```

## Idiomas y URL

- Los enlaces del router (`<Link to={ROUTES.X}>`) reciben el prefijo de idioma del `rewrite` del router. El inglés no tiene prefijo (`/docs`); los demás idiomas sí (`/pl-PL/docs`).
- Construye las URL en bruto con `localizePathname({ locale, pathname })`: `callbackURL` y `errorCallbackURL` de Better Auth, enlaces en correos y `<a href>` hechos a mano. Las rutas `/api` y las URL externas no cambian.
- El selector de idioma enlaza a la misma ruta en el otro idioma con una carga completa de la página; la query y el fragmento no se conservan.
