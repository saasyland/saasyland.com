Run scripts from the repository root with `bun run <script>`.

## Development and build

| Script              | Runs                                                                                                                                   |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `dev`               | `generate:cn`, `content` and `vp dev` in the `development` environment at http://localhost:3000                                        |
| `build`             | Same as `build:preview`                                                                                                                |
| `build:preview`     | Clean `dist`, `generate:cn`, `content`, `vp build` for `preview`, `scripts/verify-build.ts` and `scripts/optimize-prerendered-html.ts` |
| `build:production`  | The same steps for `production`                                                                                                        |
| `build:test`        | The same steps for the `test` environment                                                                                              |
| `start`             | `vp preview` of the latest build at http://127.0.0.1:3000                                                                              |
| `start:test`        | `vp preview` of the test build                                                                                                         |
| `deploy:preview`    | `scripts/verify-bindings.ts preview`, `build:preview` and `wrangler deploy --secrets-file .env.preview`                                |
| `deploy:production` | `scripts/verify-bindings.ts production`, `build:production` and `wrangler deploy --secrets-file .env.production`                       |

`verify-build.ts` checks the deployment config, the document language, canonical and alternate links of the localized home and legal pages, the fonts, that protected pages and locale aliases were not prerendered and that no client asset imports `cloudflare:workers`. `optimize-prerendered-html.ts` removes dependency `modulepreload` hints from prerendered pages and keeps the entry hint at low priority.

## Checks

| Script             | Runs                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------ |
| `check`            | `generate:cn`, `check:i18n` and `vp check` (format, lint and types)                        |
| `check:fix`        | The same with `vp check --fix`                                                             |
| `check:i18n`       | `scripts/check-i18n.ts`, `scripts/check-message-formats.ts` and `scripts/check-content.ts` |
| `check:pre-commit` | `generate:cn`, `check:i18n` and `vp staged`; run by the pre-commit hook                    |
| `lint`             | `vp lint`                                                                                  |
| `format`           | `vp fmt`                                                                                   |
| `format:check`     | `vp fmt --check`                                                                           |

| `test:coverage`                                                                                   | All projects with the coverage gate                     |
| `test:all`                                                                                        | `test`, then `test:e2e:smoke`                           |

## Generation and maintenance

| Script           | Runs                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| `content`        | `fumadocs-mdx`: generates `.source/` from `content/`                                                   |
| `generate:cn`    | Builds the class-merging tables in `.source/cn-tables.ts` from `src/lib/cn.config.ts`                  |
| `cf-typegen`     | `wrangler types` for `development`: regenerates `src/types/worker-configuration.d.ts`                  |
| `typegen`        | `cf-typegen`, `generate:cn` and `content`                                                              |
| `skills:sync`    | `scripts/sync-skills.ts`: restores agent skills from `skills-lock.json`                                |
| `clean`          | Removes `.source`, `.tanstack`, `.wrangler`, `dist`, `coverage`, Playwright output and `*.tsbuildinfo` |
| `clean:deep`     | `clean` and `node_modules`                                                                             |
| `clean:hardcore` | `clean:deep`, `bun.lock` and `skills-lock.json`                                                        |
| `prepare`        | Runs on install: `vp config --no-agent` (Git hooks), `generate:cn` and `content`                       |

`clean` deletes `.wrangler`, including the local development and test databases, so export any local data you want to keep first.
