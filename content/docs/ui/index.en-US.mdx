| Path                                                    | Contents                                                                                                                                                                                   |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/presentation/components/shadcn/`                   | Generated shadcn primitives, React Aria variant                                                                                                                                            |
| `src/presentation/components/custom/`                   | App components: flat shared files (`footer.tsx`, `navigation.tsx`, `data-table.tsx`, `locale-switcher.tsx`, …) and the area folders `admin/`, `app/`, `auth/`, `blog/` and `landing-page/` |
| `src/presentation/styles/`                              | `globals.css` (Tailwind, tokens, type scale), `fonts.css`, `docs.css`, `typeset.css`                                                                                                       |
| `src/presentation/theme/`, `src/presentation/branding/` | Theme constants and brand constants                                                                                                                                                        |
| `src/presentation/document-assets.ts`                   | Global stylesheet and font preloads                                                                                                                                                        |
| `src/providers/`                                        | `AriaProvider`, `ThemeProvider`, `TranslationsProvider`, `MotionProvider`                                                                                                                  |
