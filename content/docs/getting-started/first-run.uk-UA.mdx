## Ізольований тестовий preview

Тестовий preview збирає застосунок для середовища `test`: локальні D1, KV і R2 у `.wrangler/test`, фіктивні облікові дані з `.env.test`, засіяні облікові записи та перехоплені запити до Resend і Polar. Він не потребує облікових записів у сервісах.

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

Відкрийте <RepositoryFact name="localServerOrigin" /> і ввійдіть з одним з облікових записів, які засіває `e2e/data/accounts.ts`. Кожен використовує пароль <RepositoryFact name="testPassword" />. Адміністратори потрапляють на `/admin`, клієнти — на `/app`, а облікові записи з ліцензіями та їхні ліцензії — з `e2e/data/licenses.ts`. Ліцензія Complete відкриває кожен платний урок демонстраційного курсу.

<RepositoryTable columns={["Електронна пошта", "Роль", "Ліцензія"]} name="seededAccounts" />

Preview обслуговує збірку, тож щоб побачити зміни у вихідному коді, перезберіть його.

## Розробка з Cloudflare

`bun run dev` запускає dev-сервер із гарячим перезавантаженням за адресою http://localhost:3000. Його прив'язки `DB`, `CACHE`, `MEDIA` і `BUNDLES` локальні, у `.wrangler/state`, тож розробка ніколи не читає й не записує дані preview чи продакшну і не потребує входу в Cloudflare.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

1. Заповніть `.env.development`, як описано в розділі [Змінні середовища](/docs/getting-started/environment-variables), з `POLAR_SERVER=sandbox`.
2. Створіть локальну базу даних і застосуйте міграції командою `db:reset:local`.
3. Заповніть її командою `db:seed:local`: адміністратор, програма курсів, ліцензії та замовлення.
4. Запустіть сервер і ввійдіть як <RepositoryFact name="localAdminEmail" /> з паролем `LOCAL_ADMIN_PASSWORD` з `.env.development` або <RepositoryFact name="localAdminPassword" />, якщо його не задано.

`bun run db:studio:local` відкриває локальні дані в Drizzle Studio. Реєстрація за електронною поштою потребує робочої конфігурації Resend: новий обліковий запис одразу входить у систему, але його ліцензійний ключ і платні уроки чекають на посилання для підтвердження, а повторний вхід потребує підтвердженої адреси. [База даних](/docs/tooling/database) описує три бази даних, початкові дані та створення першого адміністратора на preview і в продакшні.
