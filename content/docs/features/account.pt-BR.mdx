`src/modules/account` é dono da tabela `account` do Better Auth (`account.schema.ts`): uma linha por credencial ou provedor OAuth vinculado a um usuário. Os tokens OAuth nela ficam criptografados.

## Casos de uso

| Caso de uso                        | Middleware          | Usado por                              |
| ---------------------------------- | ------------------- | -------------------------------------- |
| `signUpWithPassword`               | limitado            | `SignUpForm`                           |
| `signOutUser`                      | logado              | `useSignOut`                           |
| `changePassword`                   | logado, limitado    | `SettingsPasswordForm`                 |
| `changeEmail`                      | logado, limitado    | nenhuma tela                           |
| `updateUser`                       | logado              | nenhuma tela                           |
| `sendChangeEmailConfirmationEmail` | hook do Better Auth | `user.changeEmail` em `auth.server.ts` |

`sendChangeEmailConfirmationEmail` envia `ChangeEmailConfirmationEmail` para o endereço atual com o link de confirmação fornecido pelo Better Auth.

## Preferências

O fuso horário que um usuário escolhe em [Configurações](/docs/features/settings) é uma coluna da tabela `user`, então o caso de uso dele fica no módulo de usuário: `updatePreferences` (`src/modules/user/use-cases/update-preferences.ts`) exige um usuário logado, valida a entrada com `userZodSchemas.updatePreferences` e a salva por meio do `updateUser` do Better Auth, o mesmo caminho da atualização de perfil acima. `PreferencesCard` o chama em `/app/settings` e `/admin/settings`. O idioma é o locale da URL e não fica armazenado.

## Sair

`useSignOut` (`src/hooks/use-sign-out.ts`) executa `signOutUserMutation`, limpa o cache de consultas, navega para `/auth/sign-in` e mostra uma notificação. O widget de usuário da administração e a barra lateral de `/app` mostram cada um um `SignOutButton` que o utiliza.
