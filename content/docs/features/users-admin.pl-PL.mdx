> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

## Routes

`/admin/users` z parametrem wyszukiwania `tab` z TanStack Router (`allUsers` | `invitations` | `roles` | `security`).

## Module

`modules/user/use-cases` — list/create/update/delete, ban/unban, set role/password, impersonate, refresh table.

## UI

DataTable under `admin/users/components/all-users-tab`. Status is **derived** (`getUserStatus`: active / pending / banned), not a DB enum column.

## URL state

`admin/users/constants/search-params.ts` — shared parsers + `searchParamsCache`.
