このリポジトリでは、パッケージマネージャー兼スクリプトランナーとして Bun を、開発サーバー、ビルド、テスト、リント、フォーマットには Vite+（`vp`）を使います。Cloudflare の環境とマイグレーションは Wrangler が管理し、ブラウザーテストは Playwright が実行します。

## この章の内容

- [環境とバインディング](/docs/tooling/environment): Wrangler の環境、シークレット、環境ファイル
- [データベースのマイグレーション](/docs/tooling/database): D1 マイグレーションの生成、適用、確認
- [テスト](/docs/tooling/testing): Vitest のプロジェクト、ヘルパー、100% カバレッジのゲート
- [リントとフォーマット](/docs/tooling/lint-format): oxlint、oxfmt、チェック用スクリプト
- [Vite+](/docs/tooling/vite-plus): `vp` ツールチェーンとプラグイン
- [Playwright](/docs/tooling/playwright): 隔離されたテスト用 Worker に対するブラウザーテスト
- [エージェントスキル](/docs/tooling/agent-skills): コーディングエージェント向けのベンダー製スキル
- [CI/CD](/docs/tooling/ci-cd): GitHub Actions によるチェックとデプロイ
- [プロジェクトのスクリプト](/docs/tooling/scripts): `package.json` のすべてのスクリプト
- [Graphify](/docs/tooling/graphify): コードベースのナレッジグラフ（任意）
- [Conventional Commits](/docs/tooling/conventional-commits): コミットの形式と絵文字フック
