## CLI

提供中（[CLI ガイド](/docs/cli)で説明しています）：

- `init` は、ランディングページの[構成ツール](/#cli)で選択できるオプションからプロジェクトを生成します。D1 を使う Cloudflare Worker 上の React と TanStack Start で、Better Auth のサインイン付きかサインインなしです
- `activate`、`whoami`、`deactivate` で、端末と CI のライセンスキーを管理できます

提供予定：

- 課金、そしてテンプレートが生成するまで構成ツールで無効として表示される、その他のオプションと追加機能
- ほかの UI ライブラリとフレームワーク。React の Next.js と React Router、Angular の Analog と Angular SSR、Vue の Nuxt、Svelte の SvelteKit、Solid の SolidStart と TanStack Start、そしてランタイムの Deno
- 生成したプロジェクトの回答を変更する `change`、新しいリリースに更新する `update`、そして `status`
- npm の既定タグでの安定版リリース

## プラン

[料金セクション](/#pricing)の各プランのカードには、提供中のものと提供予定のものが並んでいます。この区分は `src/data/marketing.ts` の `TIER_FEATURES` が持っています。提供予定：

- Core：選んだプロバイダーで接続済みの課金。選んだモジュールだけを含む生成されたアプリケーションのソースコード、接続済みの Better Auth・Resend、<RepositoryFact name="coverageThreshold" />% のしきい値付きのテストスイート、商用ライセンスでの無制限のプロジェクトは提供中です
- Complete：ウェイトリストの後に公開される reactprojects.com と angularprojects.com への無料の生涯アクセス、空のフォルダから本番運用までの動画コース、モジュールごとのコード解説
- Agency：コース、reactprojects.com、angularprojects.com のチーム席、プライベートな Discord チャンネル、ページデザイナー向けの Figma ファイル。無制限の顧客案件は提供中です

## アプリケーション

- Polar から読み取った返金を管理画面に表示する
- 管理画面から商品と料金モデルを管理する
- 管理画面からブログとドキュメントを編集する
- ビジュアルなページデザイナーと、投稿エディター
- 管理画面から商品を作成、編集、削除する
- ロールの編集
- 組織とチーム

## 長期

- 高度なアナリティクスのパイプライン
- プレミアムコンテンツのより細かなアクセス制御
