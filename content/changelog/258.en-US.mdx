- Fixed: signing up with an email address that already has an account no longer leaves you waiting for an email that never comes. You now get "You already have a SaaSy Land account", with the ways you can sign in, a sign-in link and a link to reset your password. The screen after signing up is the same for every address, so it never reveals who has an account. See [Authentication](/docs/features/authentication#signing-up-with-a-known-address).
- Changed: signing in to an account whose email address is not verified yet sends a fresh verification link, and the page says so.
- Added: after a password reset, an email tells you that your password was changed, with a way to reset it again and contact us if it was not you.
- Changed: account emails show SaaSy Land at the top, repeat the link as text under the button, and say how long the link works.
- Changed: `bun run dev` uses its own local database, KV namespace and R2 buckets instead of the preview ones. `bun run db:seed:local` fills the local database with an admin, the course curriculum, licences and an order, `bun run db:studio:local` opens it in Drizzle Studio, and `bun run admin:grant:preview` and `bun run admin:grant:production` make a verified account the first admin of a deployed site. See [Database](/docs/tooling/database).
- Removed: the `db:migrate:development`, `db:migrations:development`, `db:studio:development` and `db:introspect:development` scripts, which worked on the preview database.
- Added: Git hooks that reinstall the dependencies when `bun.lock` changes after a pull, a rebase or a branch switch.
