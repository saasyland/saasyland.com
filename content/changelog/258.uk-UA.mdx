- Виправлено: реєстрація з адресою електронної пошти, для якої вже є обліковий запис, більше не залишає вас чекати листа, який ніколи не прийде. Тепер ви отримуєте «У вас уже є обліковий запис SaaSy Land» зі способами, якими можна увійти, посиланням для входу й посиланням для скидання пароля. Екран після реєстрації однаковий для будь-якої адреси, тож він ніколи не розкриває, хто має обліковий запис. Див. [Автентифікація](/docs/features/authentication#signing-up-with-a-known-address).
- Змінено: вхід в обліковий запис, електронну адресу якого ще не підтверджено, надсилає нове посилання для підтвердження, і сторінка про це повідомляє.
- Додано: після скидання пароля лист повідомляє, що ваш пароль змінено, і пропонує скинути його знову та написати нам, якщо це були не ви.
- Змінено: листи облікового запису показують SaaSy Land угорі, повторюють посилання текстом під кнопкою й повідомляють, скільки часу воно дійсне.
- Змінено: `bun run dev` використовує власну локальну базу даних, простір імен KV і бакети R2 замість ресурсів preview. `bun run db:seed:local` заповнює локальну базу адміністратором, програмою курсів, ліцензіями й замовленням, `bun run db:studio:local` відкриває її в Drizzle Studio, а `bun run admin:grant:preview` і `bun run admin:grant:production` роблять підтверджений обліковий запис першим адміністратором розгорнутого сайту. Див. [База даних](/docs/tooling/database).
- Вилучено: скрипти `db:migrate:development`, `db:migrations:development`, `db:studio:development` і `db:introspect:development`, які працювали з базою даних preview.
- Додано: хуки Git, які перевстановлюють залежності, коли `bun.lock` змінюється після pull, rebase або перемикання гілки.
