`/admin/pricing-models` は、`src/data/admin.ts` の `ADMIN_PRICING_STATS` と `ADMIN_PRICING_MODELS` から `PricingModelStats` と `PricingModelsGrid` を表示します。フィルターと **モデルを作成** のボタンは未接続で、何も保存されません。

## 価格の出どころ

- **ランディングページ**: `src/data/marketing.ts` の `TIER_PRICES`（米ドル）。`core` 249、`complete` 399、`agency` 899 で、`Price` がページの言語で書式設定します。ランディングページの説明文は Core の価格を `{price}` として受け取り、ブログ記事は `<TierPrice tier="core" />` でプランの価格を表示するため、価格を手入力する文章はありません。コンサルティングカードの時間単価は同じファイルの `CONSULTING_HOURLY_RATE` です。通話はメールで予約するもので Polar では販売しないため、地域別価格はありません。
- **購入**: `POLAR_PRODUCT_ID_CORE`、`POLAR_PRODUCT_ID_COMPLETE`、`POLAR_PRODUCT_ID_AGENCY` が参照する Polar の商品。
- **地域割引**: `src/modules/_core/constants/pricing.ts` の `PPP_TIERS`（国に応じた倍率 0.8、0.7、0.6、0.5）。購入時に Polar で設定した自動のパーセント割引と照合されます。

`TIER_PRICES`、Polar の商品価格、Polar の割引は手動で一致させてください。コードはこれらを比較しません。

## 通貨と価格

- **ストアの通貨**: `src/modules/_core/constants/pricing.ts` の `DEFAULT_CURRENCY_CODE`。別の通貨で課金するには、ここを変更します。ほかの場所では定義されていません。`currency.ts` ではなく価格の定数と並べて置いているのは、ランディングページが `CURRENCIES` カタログを読み込まずに済むようにするためです。
- **変わるもの**: `CURRENCY_FORMAT` と、それに伴うランディングページのすべての価格、プランのカード、ブログの `<TierPrice>`、コンサルティングの時間単価。新しい商品のデフォルトの `currency`（`product.schema.ts`、`createProduct`）。管理画面の売上グラフと返金テーブルの金額。価格は `Intl.NumberFormat` によって通貨の最小単位に丸められます。`Intl.NumberFormat` は ISO 4217 の各通貨の小数桁数を把握しているため、地域別価格に専用の丸め用の定数は必要ありません。
- **変わらないもの**: Polar は Polar の商品価格の通貨で課金するため、商品も同じ通貨と `TIER_PRICES` の金額に設定してください。価格を管理画面から管理して Polar から読み取るようになるまでは、`TIER_PRICES` が Polar の価格をそのまま写します。アフィリエイトへの支払いは、Affonso が支払いに使う米ドル、つまり `AFFILIATE_TERMS.PAYOUT_CURRENCY` のままです。
