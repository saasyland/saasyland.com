- Changed: the landing page no longer blocks a phone's main thread right after it loads: on Lighthouse's mobile preset its Total Blocking Time went from 2,458 ms to 41 ms. The header preloads the docs' code on every page, and the docs printed the Polish terms that the glossary check leaves to the reader from `glossary-terms.ts`, which compiles a pattern for every glossary term when it loads. The `repositoryFacts` plugin now builds those terms and the glossary tables at build time, and the tables that only the docs print come from their own module, `virtual:repository-tables`, instead of every page's entry script, which is 26.0 KiB lighter gzipped. `scripts/verify-build.ts` fails the build when the entry script reaches them again.
