---
title: "Скрипти проєкту"
description: "Команди, якими ви користуєтеся щодня."
---

| Завдання                                            | Команда                  |
| --------------------------------------------------- | ------------------------ |
| Запустити dev-сервер                                | `bun run dev`            |
| Перевірити форматування, лінтинг, типи та переклади | `bun run check`          |
| Запустити всі проєкти Vitest                        | `bun run test`           |
| Запустити перевірку покриття                        | `bun run test:coverage`  |
| Запустити браузерний smoke-тест                     | `bun run test:e2e:smoke` |
| Згенерувати міграцію                                | `bun run db:generate`    |
| Зібрати Worker для preview                          | `bun run build`          |
| Запустити останню збірку                            | `bun run start`          |
| Розгорнути preview                                  | `bun run deploy:preview` |

Перш ніж відкрити pull request, виконайте ту саму послідовність, що й CI:

```sh
bun run check
bun run test:coverage
bun run test:e2e:smoke
```

Використовуйте `bun run test`, а не `bun test`, щоб Vitest запускався з налаштуваннями проєкту. Скрипти, назва яких закінчується назвою середовища, як-от `db:migrate:preview` чи `deploy:production`, діють лише на це середовище.

Повний список наведено в розділі [Скрипти проєкту](/docs/tooling/scripts).
