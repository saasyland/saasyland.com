---
title: "Organizations"
description: "Not implemented: there are no organizations, teams or tenant scoping."
---

The app has no organization, team or membership model:

- The Better Auth organization plugin is not installed.
- No module or table stores organizations or memberships.
- Queries are scoped to the signed-in user or guarded by admin permissions.
- Roles are global: `admin` and `customer` in `auth.access.ts`.

The workspace fields in **Settings → General** are static demo inputs, not an organization.

To add organizations, start from the Better Auth plugin; the `organization-best-practices` agent skill in `.agents/skills/better-auth` covers it. New tables belong in their own module under `src/modules`.
