Każda ścieżka ma stałą w `ROUTES` (`src/routes.ts`). Linki używają tej stałej, na przykład `<Link to={ROUTES.SIGN_IN}>`, a router dodaje prefiks locale. Każda z poniższych stron jest też serwowana pod prefiksem każdego niedomyślnego locale, na przykład `/pl-PL/terms`.

## Strony publiczne

Te strony używają layoutu `_landing` (nawigacja i stopka), z wyjątkiem bloga i dokumentacji, które mają własne layouty. Wszystkie poza stronami newslettera są prerenderowane.

| Ścieżka                   | Stała                    | Plik trasy                            |
| ------------------------- | ------------------------ | ------------------------------------- |
| `/`                       | `HOME`                   | `_landing.index.tsx`                  |
| `/premium`                | `PREMIUM`                | `_landing.premium.tsx`                |
| `/licence`                | `LICENCE`                | `_landing.licence.tsx`                |
| `/privacy`                | `PRIVACY`                | `_landing.privacy.tsx`                |
| `/terms`                  | `TERMS`                  | `_landing.terms.tsx`                  |
| `/refunds`                | `REFUNDS`                | `_landing.refunds.tsx`                |
| `/affiliates`             | `AFFILIATES`             | `_landing.affiliates.tsx`             |
| `/newsletter/confirm`     | `NEWSLETTER_CONFIRM`     | `_landing.newsletter.confirm.tsx`     |
| `/newsletter/unsubscribe` | `NEWSLETTER_UNSUBSCRIBE` | `_landing.newsletter.unsubscribe.tsx` |

## Kursy

Layout `/courses` (`courses.tsx`) wyświetla `ContentNavigation` bloga i nie ma guarda: poziom dostępu każdej lekcji sprawdza serwer (zobacz [Kursy](/docs/features/courses)). Te strony czytają D1 przy każdym żądaniu i nie są prerenderowane.

| Ścieżka                      | Stała     | Plik trasy                         |
| ---------------------------- | --------- | ---------------------------------- |
| `/courses`                   | `COURSES` | `courses.tsx`, `courses.index.tsx` |
| `/courses/<course>`          | brak      | `courses.$course.index.tsx`        |
| `/courses/<course>/<lesson>` | brak      | `courses.$course.$lesson.tsx`      |

## API

Ścieżki API nigdy nie są lokalizowane.

| Ścieżka       | Stała           | Plik trasy      |
| ------------- | --------------- | --------------- |
| `/api`        | `API`           | `api/index.ts`  |
| `/api/auth/*` | `API_AUTH_BASE` | `api/auth.$.ts` |
| `/api/search` | brak            | `api/search.ts` |

`ROUTES.API_AUTH` zawiera ścieżki endpointów Better Auth względem `/api/auth`; `auth.server.ts` używa ich, aby wyłączyć te endpointy z limitowania żądań i dezaktywować `/checkout` wtyczki Polar (`disabledPaths`), a `INPUT_POLICY` w `auth.hooks.ts`, aby walidować endpointy przyjmujące hasło, imię, adres e-mail lub obraz. `API_AUTH_CUSTOMER_PORTAL` i `API_AUTH_VERIFY_EMAIL` to pełne ścieżki do endpointów Better Auth. `AUTH` i `NEWSLETTER` nie mają własnych stron; razem z `ADMIN`, `APP`, `API` i `COURSES` oznaczają obszary, które nigdy nie są prerenderowane (`UNLISTED_ROUTES` w `vite.config.ts`).

## Media

`/media/<expiry>.<signature>/<videoId>/<file>` serwuje podpisane pliki wideo. Ta ścieżka nie ma stałej w `ROUTES` ani pliku trasy: `src/server.ts` przekazuje ją do `serveMedia` przed middleware języka, więc nigdy nie jest lokalizowana. Zobacz [Cloudflare R2](/docs/integrations/cloudflare-r2).
