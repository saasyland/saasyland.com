| Percorso                                                | Contenuto                                                                                                                                                                                                    |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/presentation/components/shadcn/`                   | Primitive shadcn generate, variante React Aria                                                                                                                                                               |
| `src/presentation/components/custom/`                   | Componenti dell’app: file condivisi in forma piatta (`footer.tsx`, `navigation.tsx`, `data-table.tsx`, `locale-switcher.tsx`, …) e le cartelle per area `admin/`, `app/`, `auth/`, `blog/` e `landing-page/` |
| `src/presentation/styles/`                              | `globals.css` (Tailwind, token, scala tipografica), `fonts.css`, `docs.css`, `typeset.css`                                                                                                                   |
| `src/presentation/theme/`, `src/presentation/branding/` | Costanti del tema e del brand                                                                                                                                                                                |
| `src/presentation/document-assets.ts`                   | Foglio di stile globale e precaricamento dei font                                                                                                                                                            |
| `src/providers/`                                        | `AriaProvider`, `ThemeProvider`, `TranslationsProvider`, `MotionProvider`                                                                                                                                    |

## In questo capitolo

- [Componenti shadcn](/docs/ui/shadcn-components): le primitive e come le usano le schermate.
- [DataTable](/docs/ui/data-table): l’unico componente tabella.
- [Tema](/docs/ui/theme): i temi chiaro, scuro e di sistema e i token CSS.
- [Font e branding](/docs/ui/fonts-and-branding): font self-hosted, precaricamenti e costanti del brand.
- [Pattern di composizione](/docs/ui/composition-patterns): come si combinano rotte, pagine e componenti.
