Ogni sezione elenca le modifiche arrivate su `main` in quel giorno (UTC), dalle più recenti. Ogni deploy di produzione riceve un tag e viene pubblicato come GitHub Release con la sezione del suo giorno come note; vedi [Release e tag](/docs/tooling/ci-cd#releases-and-tags). Le versioni della CLI stessa sono nelle [note di rilascio della CLI](/docs/cli/releases). Ogni modifica aggiunge la propria voce; vedi [Voci del changelog](/docs/conventions/git-workflow#changelog-entries).
