## データ

`src/modules/product/product.schema.ts` は `product` テーブルを定義します。列は `name`、`description`、`priceCents`、`currency`、`type`（`one_time`、`subscription`、`course`）、`status`（`draft`、`published`、`archived`）、`billingCycle`、タイムスタンプです。

`src/modules/product/use-cases` のユースケースは、それぞれ対応する `product` 権限で保護されています。

- `getProducts` — ページ分割に対応し、`type` と `status` のフィルターを任意で指定できます。`getProductsPageQuery` と `getProductsQuery` をエクスポートします。
- `getProduct`、`createProduct`、`updateProduct`、`deleteProduct`。

## 管理画面

`/admin/products` は選択中のタブを検索パラメーター `?tab=` に保持します。値は `all`、`onetime`、`subscriptions`、`categories`、`collections`、`drafts` です。商品タブはサーバー側でページ分割します。

```tsx
<DataTable
  columns={productColumns}
  key={tab}
  options={{ query: ({ pageIndex, pageSize }) => getProductsPageQuery({ pageIndex, pageSize, ...FILTERS[tab] }) }}
/>
```

`categories` と `collections` は `getCategoriesPageQuery` とともに `categoryColumns` を表示し（[カテゴリー](/docs/features/categories)を参照）。コースには専用の画面 `/admin/courses` があります（[コース](/docs/features/courses)を参照）。ダッシュボードのカウンターも `getProductsQuery` を読み取ります。

一覧は読み取り専用です。列は商品、種類、価格、ステータスです。作成フォームと行のメニューはありません。`createProduct`、`updateProduct`、`deleteProduct`、`getProduct` に接続された画面がまだないためです。また、売上の列を設けるにはこれらの行と Polar の商品との対応付けが必要ですが、このテーブルにはそれがありません。

購入処理はこのテーブルを使いません。購入できるプランは Polar の商品です（[ライセンス](/docs/features/licences)を参照）。
