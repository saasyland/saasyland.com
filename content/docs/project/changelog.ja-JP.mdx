## 2026-11-13

- 動画: `bun run video:publish:<environment>` は、FFmpeg で録画をアダプティブ HLS（最大 1440p の H.264 レンディション、共有の AAC トラック 1 つ、ポスター、ストーリーボードのサムネイル、字幕）にエンコードし、新しい `MEDIA` R2 バケットにアップロードして、新しい `video` テーブルに行を追加します。[動画](/docs/features/videos)を参照してください。
- `/admin/videos` で動画の一覧表示、プレビュー、削除ができます。新しい `video` 権限ステートメント（`read`、`delete`）で保護されています。
- Worker は、ロケールミドルウェアより前に、署名済みで期限付きの `/media/` パスで動画ファイルを配信します。`Range` に対応し、Workers のキャッシュを使います。[Cloudflare R2](/docs/integrations/cloudflare-r2) を参照してください。
- `VideoPlayer` は Video.js 10 で動画を再生し、画質、再生速度、字幕、ピクチャー・イン・ピクチャー、シークプレビューに対応します。メディア要素がアダプターの場合にストーリーボードのサムネイル URL が正しくなるよう、`@videojs/utils` 10.3.0 に Bun のパッチを当てています。
- コース: 新しい `course`、`chapter`、`lesson`、`lesson_progress` テーブルが、`/courses`（カタログ）、`/courses/<course>`（カリキュラムと進捗）、`/courses/<course>/<lesson>`（視聴者が止めた位置から再開し、進捗を保存するプレーヤー）を支えます。レッスンは動画ライブラリの動画を再生します。[コース](/docs/features/courses)を参照してください。
- 各レッスンは、無料プレビュー、アカウントがあれば無料、Complete または Agency のライセンスに含まれる、のいずれかで、サーバー関数がこれを強制します。管理者は新しい `course` 権限ステートメントによってすべてのレッスンを視聴できます。レッスンからサインインした訪問者は、そのレッスンに戻ります。
- `VideoPlayer` は `startAt`、`onProgress`、`onEnded` を受け取ります。管理画面でのコース作成はまだデモのため、当面は D1 でコースを作成してください。

## 2026-11-12

- Worker のすべてのレスポンスにセキュリティヘッダーが付くようになりました。`X-Content-Type-Options`、`Referrer-Policy`、`X-Frame-Options`、`Cross-Origin-Opener-Policy`、`Permissions-Policy`、フレームへの埋め込み・`<base>` の変更・プラグインを禁止する Content Security Policy に加え、HTTPS では `Strict-Transport-Security` が付きます。Worker を経由せずに配信される静的ファイルには、`public/_headers` がそのサブセットを付けます。
- 確認メール、パスワードリセットメール、ニュースレターの確認メールを、アドレスごとに 1 時間あたり 3 通までに制限しました（`withinRecipientRateLimit`）。
- Better Auth 独自のエンドポイントでも、フォームのパスワード、名前、メールアドレス、画像のルールを適用するようになりました（`auth.hooks.ts` の `enforceInputPolicy`）。
- 修正: Resend の冪等性キーを `<purpose>/<SHA-256 of the token>` にしたため、長いアドレスへの確認メールとメールアドレス変更のメールが拒否されなくなりました。
- 修正: 一部返金でライセンスが取り消されなくなりました。また、決して成功しない Polar の Webhook イベントは、再送させずに受領するようになりました。
- 修正: ニュースレターの確認リンクと配信停止リンクは、訪問者がボタンを押したときにだけ処理を行うようになりました。また、ニュースレターのリンクは `appHostsForMode` のホストだけを受け付けるようになりました。
- ルートの検索パラメーターは、`src/lib/search-params.ts` の `searchText`、`searchFlag`、`searchChoice` で組み立てた Zod スキーマになりました。
- 各モジュールの `<module>.types.ts` は 1 つのインターフェースをエクスポートし、サーバー関数は入力を `Module["operation"]` として型付けするようになりました。ニュースレターのステータスとソースは名前付きの定数になりました。
- 修正: デプロイで Worker のソースマップをアップロードしなくなりました（`upload_source_maps: false`）。ソースマップのせいでアップロードが大きくなりすぎていました。
- 依存関係を更新しました: `@polar-sh/sdk` 1.x、`@polar-sh/better-auth` 2.x、Vite+ 1.6.0、Vitest 5.1.0、`fumadocs-mdx` 15.6.1。

## 2026-09-26

- 国際化を use-intl の名前空間を中心に再構築しました。`messages/<locale>/` に名前空間ごとに 1 つの JSON ファイルを置き、ページルートごとに `NAMESPACE`、レイアウトルートごとに `NAMESPACES` を宣言し、すべての画面で使うルート名前空間を用意し、すべての静的キーを `useTranslations` のスコープ内で解決する `check:i18n` ステップを追加しました。
- メールを、React Email テンプレート（マークアップと名前空間のみ）と、メッセージを読み込んで `sendEmail` で送信するユースケースに分割しました。
- コンポーネントを再編成しました。ルートファイルがページを組み立て、コンポーネントのフォルダーはフラットにし、ウィジェット、ダイアログ、フォーム、テーブルのカラムセットはそれぞれ専用のファイルを持つようにしました。
- すべてのフォームが、`Field`、`FieldLabel`、`Input` とモジュールの Zod スキーマを使う shadcn の TanStack Form パターンに従うようになりました。
- 個別のテーブル実装を、TanStack Table v9 ベースの 1 つの汎用 `DataTable` に置き換えました。
- ニュースレターのフォームを簡素化しました。
- 修正: ホームページ以外のページでも、ナビゲーションとセクションへのリンクがロケールを保持するようになりました。
- 修正: 管理ダッシュボードのグラフのラベルがローカライズされるようになりました。
- Vitest のカバレッジのゲートを、行、ステートメント、関数、分岐のすべてで 100% に設定しました。
