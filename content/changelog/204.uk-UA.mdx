- Кожен pull request додає власний запис журналу змін, `content/changelog/<number>.<locale>.mdx`, замість редагувати цю сторінку, тож pull request, відкриті паралельно, більше не конфліктують у дев’яти файлах журналу змін. Жоден запис не має дати: сторінка й нотатки до релізу беруть день кожного запису (UTC) із squash-коміту, тема якого закінчується на `(#<number>)`, а записи, що ще не потрапили в `main`, показують у розділі **Ще не випущено**. Наявні записи перейшли до власних файлів із днями, які фіксує Git: #160 переходить на 2026-11-14, #104, #111 і #115 — на 2026-11-12, а дванадцять записів — з 2026-11-15 на 2026-11-16; колишні пункти з розділу **Раніше** датовано 2026-09-24. У pull request `bun run check` завершується помилкою, доки бракує його запису. Див. [Записи журналу змін](/docs/conventions/git-workflow#changelog-entries).
