Le dépôt utilise Bun comme gestionnaire de paquets et lanceur de scripts, et Vite+ (`vp`) pour le serveur de développement, les builds, les tests, le lint et le formatage. Wrangler gère les environnements Cloudflare et les migrations, et Playwright exécute les tests dans le navigateur.

## Dans ce chapitre

- [Environnement et bindings](/docs/tooling/environment) : environnements Wrangler, secrets et fichiers d'environnement
- [Migrations de base de données](/docs/tooling/database) : générer, appliquer et inspecter les migrations D1
- [Tests](/docs/tooling/testing) : projets Vitest, utilitaires et seuil de couverture à 100 %
- [Lint et formatage](/docs/tooling/lint-format) : oxlint, oxfmt et les scripts de vérification
- [Vite+](/docs/tooling/vite-plus) : la chaîne d'outils `vp` et ses plugins
- [Playwright](/docs/tooling/playwright) : tests dans le navigateur contre le Worker de test isolé
- [Skills pour agents](/docs/tooling/agent-skills) : skills des fournisseurs pour les agents de codage
- [CI/CD](/docs/tooling/ci-cd) : vérifications et déploiements avec GitHub Actions
- [Scripts du projet](/docs/tooling/scripts) : chaque script de `package.json`
- [Graphify](/docs/tooling/graphify) : un graphe de connaissances facultatif de la base de code
- [Commits conventionnels](/docs/tooling/conventional-commits) : format des commits et hook d'emoji
