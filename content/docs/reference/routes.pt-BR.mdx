title: "Rotas"
description: "Todas as páginas e caminhos de API, com a constante em ROUTES, o arquivo de rota e o guard de cada um."
---

Todo caminho tem uma constante em `ROUTES` (`src/routes.ts`). Os links usam a constante, por exemplo `<Link to={ROUTES.SIGN_IN}>`, e o router adiciona o prefixo de locale. Cada página abaixo também é servida sob todos os prefixos de locale que não são o padrão, por exemplo `/pl-PL/terms`.

## Páginas públicas

Estas páginas usam o layout `_landing` (navegação e rodapé), exceto o blog e a documentação, que têm layouts próprios. Todas são pré-renderizadas, exceto as páginas da newsletter.

| Caminho                   | Constante                | Arquivo de rota                       |
| ------------------------- | ------------------------ | ------------------------------------- |
| `/`                       | `HOME`                   | `_landing.index.tsx`                  |
| `/premium`                | `PREMIUM`                | `_landing.premium.tsx`                |
| `/licence`                | `LICENCE`                | `_landing.licence.tsx`                |
| `/privacy`                | `PRIVACY`                | `_landing.privacy.tsx`                |
| `/terms`                  | `TERMS`                  | `_landing.terms.tsx`                  |
| `/refunds`                | `REFUNDS`                | `_landing.refunds.tsx`                |
| `/newsletter/confirm`     | `NEWSLETTER_CONFIRM`     | `_landing.newsletter.confirm.tsx`     |
| `/newsletter/unsubscribe` | `NEWSLETTER_UNSUBSCRIBE` | `_landing.newsletter.unsubscribe.tsx` |
| `/blog`                   | `BLOG`                   | `blog.tsx`, `blog.index.tsx`          |
| `/blog/*`                 | nenhuma                  | `blog.$.tsx`                          |
| `/docs`                   | `DOCS`                   | `docs.tsx`, `docs.index.tsx`          |
| `/docs/*`                 | nenhuma                  | `docs.$.tsx`                          |

## Autenticação

O layout de `/auth` (`auth.tsx`) não tem guard; as páginas individuais têm.

| Caminho                 | Constante         | Arquivo de rota            | Guard                                                                |
| ----------------------- | ----------------- | -------------------------- | -------------------------------------------------------------------- |
| `/auth/sign-in`         | `SIGN_IN`         | `auth.sign-in.tsx`         | `redirectIfSignedIn`                                                 |
| `/auth/sign-up`         | `SIGN_UP`         | `auth.sign-up.tsx`         | `redirectIfSignedIn`                                                 |
| `/auth/forgot-password` | `FORGOT_PASSWORD` | `auth.forgot-password.tsx` | nenhum                                                               |
| `/auth/reset-password`  | `RESET_PASSWORD`  | `auth.reset-password.tsx`  | nenhum                                                               |
| `/auth/two-factor`      | `TWO_FACTOR`      | `auth.two-factor.tsx`      | nenhum                                                               |
| `/auth/verify-email`    | `VERIFY_EMAIL`    | `auth.verify-email.tsx`    | Redireciona um `token` para o endpoint de verificação do Better Auth |
| `/auth/callback`        | `AUTH_CALLBACK`   | `auth.callback.tsx`        | `redirectAfterAuth`                                                  |

## API

Os caminhos de API nunca são localizados.

| Caminho       | Constante       | Arquivo de rota |
| ------------- | --------------- | --------------- |
| `/api`        | `API`           | `api/index.ts`  |
| `/api/auth/*` | `API_AUTH_BASE` | `api/auth.$.ts` |
| `/api/search` | nenhuma         | `api/search.ts` |

`ROUTES.API_AUTH` lista os caminhos dos endpoints do Better Auth relativos a `/api/auth`; `auth.server.ts` os usa para isentar endpoints do rate limiting. `API_AUTH_CUSTOMER_PORTAL` e `API_AUTH_VERIFY_EMAIL` são caminhos completos para endpoints do Better Auth. `AUTH` e `NEWSLETTER` não têm página própria; junto com `ADMIN`, `APP` e `API`, elas marcam as áreas que nunca são pré-renderizadas.
