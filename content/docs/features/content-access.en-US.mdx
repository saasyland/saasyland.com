---
title: "Content access"
description: "What controls access today: route guards, permissions and the licence record. There is no premium content gating."
---

There is no gated premium content. Access is controlled by:

- **Route guards**: `/app` requires a session (`requireSignedIn`); `/admin` requires the `admin: ["access"]` permission (`requireAdmin`).
- **Server functions**: `authorized(permission)` checks the role permissions from `auth.access.ts`.
- **Licence**: the `license` table holds at most one licence per user with a `tier` (`core`, `complete`, `agency`) and a `status` (`active`, `revoked`), written by Polar webhooks. `/app` and `/app/license` read it through `currentLicenseQuery` to show either checkout options or the licence key.

`/premium` (`src/routes/_landing.premium.tsx`) is a placeholder page that renders only its title from `pages.premium`.

To gate something by purchase, read the licence on the server with `getLicense(userId)` from `src/modules/license/use-cases/get-license.ts` and check `status` and `tier`.
