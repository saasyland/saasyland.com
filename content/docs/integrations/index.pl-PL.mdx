---
title: "Wprowadzenie"
description: "Adaptery dostawców w src/integrations."
---

Każdy folder w `src/integrations/<vendor>/` opakowuje jednego dostawcę w plikach `<prefix>.<concern>.ts`, gdzie prefiks to krótka nazwa dostawcy (`auth`, `drizzle`, `i18n`, `form`): konfigurację, klientów i cienkie adaptery. Reguły biznesowe i operacje na bazie danych pozostają w `src/modules`, a komponenty nigdy nie importują klienta dostawcy bezpośrednio.

| Folder           | Pliki                                                                                                                                                                           | Przeznaczenie                                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `affonso`        | `affonso.constants.ts`, `affonso.program.ts`, `affonso.referral.ts`                                                                                                             | Parametry poleceń partnerskich, ID programu i metadane sesji płatności                                                                          |
| `better-auth`    | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.roles.ts`, `auth.session.ts`                                                | Sesje, OAuth, strażnicy tras, middleware funkcji serwerowych, role                                                                              |
| `drizzle-orm`    | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `drizzle.local.config.ts`, `drizzle.errors.ts`, `drizzle.columns.ts`, `drizzle.time-series.ts`, `migrations/` | Klient D1, zbiorczy eksport schematów, konfiguracja drizzle-kit, `rethrowAsConflict`, `timestamps()`, `bucketOf`                                |
| `fumadocs`       | `fumadocs.config.ts`, `fumadocs.schema.ts`, `fumadocs.i18n.ts`, `fumadocs.indexes.ts`, `fumadocs.docs.ts`, `fumadocs.blog.ts`, `fumadocs.changelog.ts`, `fumadocs.icons.ts`     | Kolekcje dokumentacji i bloga, indeksy generowane podczas budowania, wyszukiwanie, wpisy changeloga i ikony paska bocznego                      |
| `motion`         | `motion.features.ts`, `motion.tokens.ts`                                                                                                                                        | Leniwie ładowane funkcje Motion i wspólne przejścia                                                                                             |
| `polar`          | `polar.config.ts`, `polar.constants.ts`, `polar.customers.ts`                                                                                                                   | Klient SDK Polar, własne wartości Polar i konta klientów                                                                                        |
| `resend`         | `resend.config.ts`, `resend.utils.ts`, `resend.constants.ts`                                                                                                                    | Klient Resend, `sendEmail` i `EMAIL_PURPOSE`                                                                                                    |
| `takumi`         | `takumi.fonts.ts`, `takumi.render.tsx`                                                                                                                                          | Renderuje karty społecznościowe i logo organizacji podczas builda, czcionkami samej witryny                                                     |
| `tanstack-form`  | `form.fields.ts`, `form.submit.ts`                                                                                                                                              | `fieldErrorMessage` dla błędów pól formularza oraz `submitForm` i `showFieldError`, które oznaczają nieprawidłowe pole i przenoszą na nie fokus |
| `tanstack-query` | `query.cache.ts`                                                                                                                                                                | Domyślne czasy cache `QueryClient` tworzonego dla każdego żądania                                                                               |
| `use-intl`       | `i18n.config.ts`, `i18n.loaders.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                                                                 | Języki, przestrzenie nazw komunikatów, middleware języka, obsługa URL-i                                                                         |
| `zod`            | `zod.config.ts`                                                                                                                                                                 | Uruchamia Zod w przeglądarce w trybie `jitless`, więc pod Content Security Policy nigdy nie sprawdza `eval`                                     |
