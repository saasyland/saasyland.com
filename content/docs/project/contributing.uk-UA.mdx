---
title: "Участь у розробці"
description: "Як запропонувати зміни до SaaSy Land."
---

1. Спершу обговоріть великі зміни в issue, відкритому через форму звіту про помилку або запиту на функцію.
2. Створіть гілку від `main`.
3. Дотримуйтеся [конвенцій](/docs/conventions) та [архітектури](/docs/architecture), а перед зміною інтеграції з постачальником прочитайте відповідну [навичку агента](/docs/tooling/agent-skills). Агенти програмування починають з `AGENTS.md` у корені репозиторію.
4. Розміщуйте тести поруч із їхнім власником і підтримуйте поріг покриття 100%.
5. Запустіть наведені нижче перевірки.
6. Зробіть коміт із повідомленням у форматі [conventional commits](/docs/tooling/conventional-commits), відкрийте pull request із заголовком у тому самому форматі та заповніть його шаблон.

```sh
bun run check
bun run test:coverage
bun run build:test
bun run test:e2e:install
bun run test:e2e:pr
```

`build:test` запускає повну збірку Cloudflare, яку не перевіряють ні `check`, ні модульні тести. `test:e2e:pr` збирає й запускає тестовий Worker, якщо сервер ще не працює, і виконує всі специфікації в Chromium, як це робить CI для pull request. Для змін, які можуть поводитися інакше у WebKit, також запускайте повний набір браузерних тестів (`bun run test:e2e`). Коли змінюєте конфігурацію реальних інтеграцій із провайдерами, перевіряйте їх окремо.

Коли змінюється поведінка, оновіть `content/docs` в усіх дев'яти локалях; `bun run check:i18n` відхиляє відсутні переклади, а також відмінності в блоках коду та навігації. Шаблон pull request містить підсумок, план тестування з наведеними вище перевірками та список оновленої документації; опишіть у ньому підсумкову поведінку, як ви її перевірили, а також демонстраційні чи незавершені сценарії, які залишаються.

`CONTRIBUTING.md` у корені репозиторію — це стисла версія цієї сторінки, а `SUPPORT.md` пояснює, де отримати допомогу. Усі учасники дотримуються `CODE_OF_CONDUCT.md`, тобто Contributor Covenant 2.1. Повідомляйте про вразливості безпеки конфіденційно, як описано в `SECURITY.md`, а не в публічному issue.
