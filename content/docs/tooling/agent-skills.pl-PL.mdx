`skills-lock.json` przypina wersje umiejętności (skills) agentów używanych w tym repozytorium. Zainstalowane umiejętności nie są commitowane: `.agents/` i `.claude/` są ignorowane przez Git.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` usuwa `.agents/skills` i `.claude/skills`, ponownie instaluje każdą umiejętność zapisaną w pliku blokady za pomocą `bunx skills experimental_install`, przenosi każdą z nich do grupy dostawcy w `.agents/skills/<group>/<skill>/SKILL.md` i linkuje każdą grupę do `.claude/skills`. Skrypt kończy się błędem, gdy źródło umiejętności nie ma przypisanej grupy.

| Grupa                                                 | Źródło                                                               |
| ----------------------------------------------------- | -------------------------------------------------------------------- |
| `anthropic`                                           | `anthropics/skills`                                                  |
| `better-auth`                                         | `better-auth/skills`                                                 |
| `cloudflare`                                          | `cloudflare/skills`                                                  |
| `polar`                                               | `polarsource/skills`                                                 |
| `resend`                                              | `resend/resend-skills`                                               |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) i `TanStack/table` (`table`)   |
| `remotion`                                            | `remotion-dev/skills`                                                |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Ogólne umiejętności z zakresu inżynierii, projektowania i marketingu |

Synchronizacja zastępuje oba katalogi, więc własne umiejętności przechowuj gdzie indziej. `bun run clean:hardcore` usuwa `skills-lock.json`.

## Zasada

Zanim zmienisz kod związany z TanStack Start, Router lub Table, Better Auth, Cloudflare, Polar lub Resend, przeczytaj odpowiednią umiejętność. Umiejętności opisują aktualne API dostawców, a konwencje tego repozytorium są udokumentowane w rozdziałach [Architektura](/docs/architecture) i [Konwencje](/docs/reference/conventions).
