`src/modules/account` verwaltet die Better-Auth-Tabelle `account` (`account.schema.ts`): eine Zeile pro Zugangsdatum oder OAuth-Anbieter, der mit einem Benutzer verknüpft ist. Die darin gespeicherten OAuth-Tokens sind verschlüsselt.

## Anwendungsfälle

| Anwendungsfall                     | Middleware             | Verwendet von                          |
| ---------------------------------- | ---------------------- | -------------------------------------- |
| `signUpWithPassword`               | Rate-Limit             | `SignUpForm`                           |
| `signOutUser`                      | angemeldet             | `useSignOut`                           |
| `changePassword`                   | angemeldet, Rate-Limit | `SettingsPasswordForm`                 |
| `changeEmail`                      | angemeldet, Rate-Limit | von keiner Ansicht verwendet           |
| `updateUser`                       | angemeldet             | von keiner Ansicht verwendet           |
| `sendChangeEmailConfirmationEmail` | Better-Auth-Hook       | `user.changeEmail` in `auth.server.ts` |

`sendChangeEmailConfirmationEmail` sendet `ChangeEmailConfirmationEmail` mit dem Bestätigungslink von Better Auth an die aktuelle Adresse.

## Abmelden

`useSignOut` (`src/hooks/use-sign-out.ts`) führt `signOutUserMutation` aus, leert den Query-Cache, navigiert zu `/auth/sign-in` und zeigt einen Toast an. Das Benutzer-Widget im Adminbereich und die Seitenleiste von `/app` rendern jeweils einen `SignOutButton`, der diesen Hook verwendet.
