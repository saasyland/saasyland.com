## クエリキャッシュ

`getRouter` はリクエストごとに新しい `QueryClient` を作成するため、サーバー上でユーザー間にデータが漏れることはありません。デフォルト値は次のとおりです。

| 設定                          | 値           |
| ----------------------------- | ------------ |
| クエリの `staleTime`          | 1 分         |
| クエリの `gcTime`             | 5 分         |
| ルーターの `defaultStaleTime` | 1 分         |
| プリロード                    | インテント時 |

ローダーは `queryClient.query({ ...options, staleTime: "static" })` でキャッシュを埋め、コンポーネントは `useSuspenseQuery` で同じキーを読み取ります。例外はコースのページと管理画面のコースエディターです。`invalidateQueries` は `static` のクエリを再取得しないため、レッスンの完了後やエディターで変更を保存した後にカリキュラムを更新できるよう、これらのクエリは `staleTime: COURSE_STALE_MS`（1 分）を使います。`setupRouterSsrQueryIntegration` はサーバーのキャッシュを HTML にシリアライズし、ブラウザでハイドレートします。

- **翻訳メッセージ**は、ロケールと名前空間ごとに、`staleTime` と `gcTime` を無限に設定してキャッシュされます。
- **セッションクエリ**（`getCurrentSessionQuery`）の `staleTime` は 1 分です。ルートガードは実際のナビゲーション時にこれを再取得し、サインイン中のユーザーが変わるとキャッシュ全体をクリアします。
- **ミューテーション**は成功後、そのモジュールのクエリキー（例：`USER_QUERY_KEYS.ALL`）を無効化します。

## プリレンダリング

`bun run build` はリンクをクロールして公開ページをプリレンダリングします。対象は、9 つすべてのロケールのランディング、法務、ブログ、ドキュメントの各ページです。`/admin`、`/app`、`/auth`、`/courses`、`/newsletter`、`/api` 配下のパス（ロケールプレフィックスの有無を問わない）と、クエリ文字列やハッシュを含むリンクは除外されます。コースのページは、視聴者ごとのロックと進捗を表示するため除外されます。

Worker は、アプリケーションを読み込む前に、`ASSETS` バインディングからプリレンダリング済みの HTML を返します。プリレンダリングされたページにはユーザーデータが含まれないため、誰に返しても安全です。訪問者が地域別価格の対象になる場合、Worker は HTML を書き換え、レスポンスに `Cache-Control: private, no-cache` を設定します。

## KV と D1

- **KV（`CACHE`）** には、`src/lib/github.ts` 用の GitHub スター数と、`src/modules/license/license.ppp.ts` 用のチェックアウトの地域割引を保存します。1 時間より古いスター数はそのまま即座に返され、`waitUntil` によってバックグラウンドで更新されます。5 分より古い割引は Polar から取得し直します。
- **D1（`DB`）** にはセッションとレート制限のカウンターを保存します。サーバー関数のセッションチェックは Better Auth のクッキーキャッシュを経由せず、結果はリクエストの残りの処理の間メモ化されます。
- **Workers のキャッシュ** には、`serveMedia` が R2 から読み取った動画ファイルを、署名を除いた `/media/_/<videoId>/<file>` の下に保持します。そのため、同じエッジロケーションの視聴者は、キャッシュされた 1 つのコピーを共有します。[Cloudflare R2](/docs/integrations/cloudflare-r2) を参照してください。
- サーバー関数が、キャッシュされたデータをもとに権限を判断することはありません。
