`src/modules/account` possède la table `account` de Better Auth (`account.schema.ts`) : une ligne par identifiant ou fournisseur OAuth lié à un utilisateur. Les jetons OAuth qu’elle contient sont chiffrés.

## Cas d’usage

| Cas d’usage                        | Middleware       | Utilisé par                              |
| ---------------------------------- | ---------------- | ---------------------------------------- |
| `signUpWithPassword`               | limité           | `SignUpForm`                             |
| `signOutUser`                      | connecté         | `useSignOut`                             |
| `changePassword`                   | connecté, limité | `SettingsPasswordForm`                   |
| `changeEmail`                      | connecté, limité | aucun écran                              |
| `updateUser`                       | connecté         | aucun écran                              |
| `sendChangeEmailConfirmationEmail` | hook Better Auth | `user.changeEmail` dans `auth.server.ts` |

`sendChangeEmailConfirmationEmail` envoie `ChangeEmailConfirmationEmail` à l’adresse actuelle avec le lien de confirmation fourni par Better Auth.

## Déconnexion

`useSignOut` (`src/hooks/use-sign-out.ts`) exécute `signOutUserMutation`, vide le cache des requêtes, navigue vers `/auth/sign-in` et affiche une notification. Le widget utilisateur de l’administration et la barre latérale de `/app` affichent chacun un `SignOutButton` qui l’utilise.
