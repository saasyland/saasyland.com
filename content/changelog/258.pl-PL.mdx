- Naprawiono: rejestracja adresem e-mail, do którego istnieje już konto, nie zostawia Cię już w oczekiwaniu na wiadomość, która nigdy nie przychodzi. Dostajesz teraz „Masz już konto w SaaSy Land”, ze sposobami, w jakie możesz się zalogować, linkiem do logowania i linkiem do zresetowania hasła. Ekran po rejestracji jest taki sam dla każdego adresu, więc nigdy nie zdradza, kto ma konto. Zobacz [Uwierzytelnianie](/docs/features/authentication#signing-up-with-a-known-address).
- Zmieniono: logowanie na konto, którego adres e-mail nie jest jeszcze potwierdzony, wysyła nowy link weryfikacyjny, a strona o tym informuje.
- Dodano: po zresetowaniu hasła wiadomość informuje, że Twoje hasło zostało zmienione, i podaje sposób, by zresetować je ponownie i napisać do nas, jeśli to nie była Twoja zmiana.
- Zmieniono: wiadomości dotyczące konta pokazują SaaSy Land na górze, powtarzają link jako tekst pod przyciskiem i podają, jak długo link działa.
- Zmieniono: `bun run dev` korzysta z własnej lokalnej bazy danych, przestrzeni nazw KV i bucketów R2 zamiast zasobów preview. `bun run db:seed:local` wypełnia lokalną bazę administratorem, programem kursów, licencjami i zamówieniem, `bun run db:studio:local` otwiera ją w Drizzle Studio, a `bun run admin:grant:preview` i `bun run admin:grant:production` czynią potwierdzone konto pierwszym administratorem wdrożonej strony. Zobacz [Baza danych](/docs/tooling/database).
- Usunięto: skrypty `db:migrate:development`, `db:migrations:development`, `db:studio:development` i `db:introspect:development`, które działały na bazie danych preview.
- Dodano: hooki Git, które ponownie instalują zależności, gdy `bun.lock` zmieni się po pullu, rebase lub zmianie gałęzi.
