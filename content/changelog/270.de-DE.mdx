- Behoben: Jeder Aufzählungspunkt im [Changelog](/docs/project/changelog) endet mit dem Pull Request, aus dem er stammt, und dem Release, das ihn ausgeliefert hat, nicht nur der letzte Punkt jedes Eintrags, und jeder Punkt eines GitHub Release endet mit seinem `(#<number>)`. Ein Changelog-Eintrag, der keine Liste einzeiliger Aufzählungspunkte ist, lässt `bun run check` jetzt scheitern. Siehe [Changelog-Einträge](/docs/conventions/git-workflow#changelog-entries).
