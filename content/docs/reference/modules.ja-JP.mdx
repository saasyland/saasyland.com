## 標準セット以外のファイル

ほとんどのモジュールには、`<table>.schema.ts`、`.zod.ts`、`.constants.ts`、`.types.ts`、`.utils.ts`、`use-cases/` しかありません。いくつかのモジュールには、追加のファイルがあります。

- `course/course.outline.ts`：視聴者向けの公開済みコースのチャプターとレッスンを返す `readCourseOutline`。`get-course` と `get-lesson` が共有する
- `lesson/lesson.access.ts`：`hasLessonAccess`、`Viewer` 型
- `lesson/lesson.playable.ts`：レッスンの動画との結合からプレースホルダーを除外する `playableVideo`。再生できる動画のないレッスンは収録中になる
- `lesson-attachment/lesson-attachment.files.ts`：アップロードされたファイルの R2 のオブジェクトキー、安全な名前、アップロードと配信ができるコンテンツタイプ
- `lesson-attachment/lesson-attachment.download.ts`：署名済みのダウンロードパス（`signDownload`、`verifyDownload`）
- `lesson-attachment/lesson-attachment.delivery.ts`：`/media/downloads/` リクエストに R2 から応答する `serveAttachment`
- `lesson-attachment/lesson-attachment.objects.ts`：削除されるレッスンのアップロード済みファイルと、R2 からのその削除
- `lesson/lesson.viewer.ts`：セッション、ロール、ほかのエリアが与えるコースアクセスから視聴者を組み立てる `resolveViewer`
- `license/license.webhooks.ts`：Better Auth に渡される Polar の Webhook ハンドラー
- `license/license.api.ts`：`src/routes/api/cli.v1.*.ts` が提供する CLI ライセンス API である `licenseApiHandlers`
- `license/license.bundles.ts`：リリースのテンプレートバンドルの R2 のキーと署名済み URL（`bundleObjectKey`、`signBundle`、`verifyBundle`）
- `license/license.delivery.ts`：`/bundles/` リクエストに R2 から応答する `serveBundle`
- `license/license.ppp.ts`：チェックアウトで購入者にプランに対して請求する価格（地域価格を含む）である `buyerTierPrice`
- `license/license.pricing.ts`：地域別価格の区分（`PPP_TIERS`）、その倍率と割合、適用を外すクッキー
- `license/license.upgrade-price.ts`：上位プランの価格から、顧客がライセンスに支払った額を差し引く `upgradePrice`
- `license/license.refunds.ts`：同意と最初のダウンロードから、購入を現時点で返金できるかどうかを求める `refundEligibility`
- `withdrawal/withdrawal.contracts.ts`：撤回の意思表示が指定する有効なライセンスと、その時点での返金条件を求める `matchContract` と `accountContract`
- `video/video.files.ts`：R2 のオブジェクトキーと、保存・配信できるファイルとそのメディアタイプ
- `video/video.playback.ts`：署名済みの再生パス（`createPlayback`、`verifyPlayback`）
- `video/video.delivery.ts`：`/media/` リクエストに Workers のキャッシュまたは R2 から応答する `serveMedia`
- `video/video.encoding.ts`：`scripts/publish-video.ts` が実行する FFmpeg の計画（レンディション、引数、ストーリーボード）

## サーバー側で実行されるプレーンなユースケース

次のユースケースは、RPC エンドポイントを持たない async 関数です。Better Auth のフック、Polar の Webhook ハンドラー、または他のユースケースから呼び出されます。対象は `send-verify-email`、`send-reset-password-email`、`send-change-email-confirmation-email`、`grant-license`、`upgrade-license`、`revert-license-upgrade`、`send-purchase-confirmation-email`、`send-unmatched-order-alert`、`revoke-license`、`attach-license-key`、`get-license` です。
