## Preview di test isolata

La preview di test compila l'applicazione per l'ambiente `test`: D1, KV e R2 locali in `.wrangler/test`, credenziali fittizie da `.env.test`, account creati dal seed e richieste a Resend e Polar intercettate. Non richiede alcun account.

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

Apri <RepositoryFact name="localServerOrigin" /> e accedi con uno degli account che il seed crea da `e2e/data/accounts.ts`. Tutti usano la password <RepositoryFact name="testPassword" />. Gli amministratori arrivano su `/admin` e i clienti su `/app`, e gli account con licenza e le loro licenze vengono da `e2e/data/licenses.ts`. La licenza Complete apre tutte le lezioni a pagamento del corso di esempio.

<RepositoryTable columns={["Email", "Ruolo", "Licenza"]} name="seededAccounts" />

La preview serve una build, quindi ricompilala per vedere le modifiche al codice sorgente.

## Sviluppo con Cloudflare

`bun run dev` avvia il server di sviluppo con hot reload su http://localhost:3000. I suoi binding `DB`, `CACHE`, `MEDIA` e `BUNDLES` sono locali, in `.wrangler/state`, quindi lo sviluppo non legge né scrive mai i dati di preview o di produzione e non richiede un accesso a Cloudflare.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

1. Compila `.env.development` come descritto in [Variabili d'ambiente](/docs/getting-started/environment-variables), con `POLAR_SERVER=sandbox`.
2. Crea il database locale e applica le migrazioni con `db:reset:local`.
3. Popolalo con `db:seed:local`: un amministratore, il programma dei corsi, delle licenze e un ordine.
4. Avvia il server e accedi come <RepositoryFact name="localAdminEmail" /> con `LOCAL_ADMIN_PASSWORD` di `.env.development`, oppure con <RepositoryFact name="localAdminPassword" /> quando non è impostata.

`bun run db:studio:local` apre i dati locali in Drizzle Studio. La registrazione con email richiede una configurazione di Resend funzionante: un nuovo account ha subito effettuato l'accesso, ma la sua chiave di licenza e le lezioni a pagamento attendono il link di conferma, e per accedere di nuovo serve un indirizzo confermato. [Database](/docs/tooling/database) descrive i tre database, il seed e come creare il primo amministratore su preview e in produzione.
