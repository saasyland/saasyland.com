## Werkzeuge

| Werkzeug | Version                             | Wozu                                                                                                                         |
| -------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Bun      | 1.4.0                               | Paketmanager und Skript-Runner; `packageManager` in `package.json` und die CI fixieren die Version                           |
| Node.js  | 24.11 oder neuer aus der Reihe 24.x | Vite+ akzeptiert `^22.18.0`, `^24.11.0` oder `>=26.0.0`; die CI verwendet Node 24, und die Testdatenbank nutzt `node:sqlite` |
| Git      | Jede aktuelle Version               | Der Installationsschritt richtet Git-Hooks ein                                                                               |

Wrangler, drizzle-kit, Playwright und die Vite+ CLI sind Dev-Abhängigkeiten; führen Sie sie über die Paketskripte oder `bunx` aus. Browsertests benötigen außerdem die Playwright-Browser aus `bun run test:e2e:install`.

## Konten

Die isolierte Test-Preview und alle automatisierten Tests benötigen weder Konten noch Zugangsdaten. Entwicklung und Deployment verwenden echte Dienste:

- Ein Cloudflare-Konto mit D1, KV und Workers. Der Dev-Server verbindet sich mit entfernten Preview-Ressourcen.
- OAuth-Apps bei GitHub und Google für die Anmeldung über soziale Konten.
- Resend mit einem verifizierten Absender. Die Registrierung per E-Mail erfordert eine verifizierte Adresse, ohne ihn funktioniert die Registrierung daher nicht.
- Polar, für die Entwicklung mit der Sandbox, mit drei Produkten für die Stufen Core, Complete und Agency.
