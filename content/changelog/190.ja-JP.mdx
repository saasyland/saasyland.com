- すべてのページが、Google の strict CSP に従う Content Security Policy のもとで、配信時に含まれていたスクリプトだけを実行するようになりました。Worker がレンダリングするページは、レスポンスごとに新しい nonce をヘッダーで受け取り、`src/server.ts` がそれを TanStack Start に渡します。TanStack Start はその nonce をルーター、React、テーマのスクリプトに付けます。プリレンダリングされたページは誰にとっても同じファイルで nonce を持てないため、`scripts/secure-prerendered-html.ts` がビルド時にインラインスクリプトのハッシュを計算し、低優先度のエントリーのヒントを保つ、ハッシュで許可されたインラインのローダーからエントリーモジュールを読み込み、ポリシーを meta タグに書き込みます。`'strict-dynamic'` によって、それらのスクリプトはルートのチャンクと Affonso のピクセルを読み込めます。`base-uri` は `'none'` になり、zod は `eval` が使えるかどうかを調べずに解析するようになり、ページが違反を報告するとブラウザーテストのすべてのスペックが失敗します。
