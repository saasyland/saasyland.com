- 追加: 顧客ワークスペースと管理コンソールにセキュリティ設定を追加しました。**設定** には「一般」と「セキュリティ」のタブがあり、メールアドレスの変更（旧アドレスで確認し、新アドレスを検証）、パスワードの変更、または GitHub や Google でサインインするアカウントへのパスワードの設定、認証アプリによる二要素認証の有効化（QR コード、セットアップキー、コピーまたはダウンロードできるバックアップコード、必要に応じた新しいコード）、最後のサインイン方法を外すことなく行える GitHub と Google の連携と連携解除、ブラウザー、システム、国、IP アドレス付きでのサインイン中の各デバイスの確認とサインアウトができます。[設定](/docs/features/settings)を参照してください。
- 追加: 顧客の設定に **アカウントを削除** を追加しました。パスワードの入力後、メールで届くリンクから、削除されるものと保存されるものを示すページが開き、**アカウントを削除する** を押したときにだけアカウントを削除します。
- 変更: 本人または管理者がアカウントを削除しても、ライセンスとその提供記録は、アカウントとの紐付けを外した決済記録として保存され、有効なライセンスは先に取り消されるため、そのキーは CLI で使えなくなります。プライバシーポリシー、削除の案内、管理者の削除ダイアログにもそのように記載しました。
- 変更: パスワードが変更または設定されると、アカウントにメールで通知します。
