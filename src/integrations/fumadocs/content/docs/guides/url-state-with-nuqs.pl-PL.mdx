## Rules of thumb

1. Define parsers once (e.g. `search-params.ts`) with `nuqs/server` imports
2. `createSearchParamsCache` in the same map for RSC
3. Client: `useQueryState` / `useQueryStates` + `startTransition` when `shallow: false`
4. App defaults on `NuqsProvider` (`history`, `shallow`, `scroll`)
5. Enum/literal parsers for constrained tabs/filters

## Example

Admin users tabs: `admin/users/_lib/search-params.ts` + `TabsList` + `ActiveTab`.
