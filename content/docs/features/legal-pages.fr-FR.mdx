| Route         | Fichier de route                             | Espace de noms           |
| ------------- | -------------------------------------------- | ------------------------ |
| `/privacy`    | `src/routes/_site._marketing.privacy.tsx`    | `pages.legal.privacy`    |
| `/terms`      | `src/routes/_site._marketing.terms.tsx`      | `pages.legal.terms`      |
| `/refunds`    | `src/routes/_site._marketing.refunds.tsx`    | `pages.legal.refunds`    |
| `/licence`    | `src/routes/_site._marketing.licence.tsx`    | `pages.legal.licence`    |
| `/affiliates` | `src/routes/_site._marketing.affiliates.tsx` | `pages.legal.affiliates` |

Chaque fichier de route définit son propre composant de page, un `NAMESPACE` statique et une constante de module contenant les clés de section dans l’ordre d’affichage :

```tsx
const SECTIONS = ["operator", "accounts", "purchases", "payments", "licence", "conduct", "refunds", "responsibility", "law"] as const
```

La page affiche `title` et `description` avec `ContentPage`, puis `lastUpdated`, puis `sections.<key>.title` et `sections.<key>.body` pour chaque clé. Il n’existe pas de composant légal partagé. La politique de confidentialité et les conditions d’affiliation transmettent à leurs messages les valeurs de `AFFILIATE_TERMS` (`src/data/affiliates.ts`), si bien que la commission, la durée du cookie, la période de rétention et le seuil de versement ne sont jamais saisis en dur dans les textes.

## Modification

- Modifiez les textes dans `messages/<locale>/pages.legal.<doc>.json` pour toutes les langues et lancez `bun run check:i18n`.
- Pour ajouter une section, ajoutez sa clé à `SECTIONS` et ses messages dans chaque langue.
- Les liens du pied de page sont les entrées de pied de page de `LEGAL_NAVIGATION` dans `src/data/legal.navigation.ts`, avec les libellés de `navigation.legal.json` : la colonne juridique et, dans la colonne produit, les conditions d’affiliation ; la zone juridique ajoute la ligne de consentement sous le formulaire d’inscription, `SignUpConsent` avec son squelette dans `custom/sign-up-consent.tsx`, à `SIGN_UP_NOTICES` dans `src/data/legal.sign-up-notices.ts`, de sorte qu’un projet sans pages juridiques a un formulaire d’inscription sans liens vers elles. `LegalPending` (`custom/legal-pending.tsx`) est le squelette des cinq pages, déclaré dans `src/data/legal.skeletons.ts`.

La page de licence distingue la licence MIT du dépôt public du matériel payant fourni séparément. La politique de remboursement préserve les droits impératifs des consommateurs. Alignez chaque document sur l’exploitant, le paiement, les prestataires et le traitement des données réels.
