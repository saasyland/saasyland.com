> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

## Required locally

- **Bun** (package manager + scripts)
- **Node-compatible OS** (macOS / Linux / WSL recommended)
- **Git**
- A code editor (Cursor / VS Code)

## Accounts (free tiers are fine)

| Service                                                                                             | Used for            |
| --------------------------------------------------------------------------------------------------- | ------------------- |
| [Neon](https://neon.tech)                                                                           | Postgres            |
| [Upstash](https://upstash.com)                                                                      | Redis               |
| [Resend](https://resend.com)                                                                        | Transactional email |
| [GitHub](https://github.com/settings/developers) / [Google Cloud](https://console.cloud.google.com) | OAuth apps          |
| [Vercel](https://vercel.com) (optional)                                                             | Deploy + env pull   |

## Knowledge assumptions

You should be comfortable with TypeScript, React, and the Next.js App Router. Domain modules use **use-cases** + **next-safe-action**; you do not need a DI framework.
