## Passos

1. Adicionar caminho para `ROUTES`
2. Adicionar entrada na barra lateral. `admin/constants/sidebar.ts` (+ I18n rótulos)
3. Criar `app/[locale]/(admin)/admin/<feature>/page.tsx`
4. Colocate `_components` / `_lib`
5. Dados do portal com casos de uso + suspense
6. Documento sob recursos.
