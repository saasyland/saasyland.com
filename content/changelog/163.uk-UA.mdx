- Набір тестів шляху клієнта: `bun run test:journey` купує кожен план на preview-розгортанні так, як це робить клієнт, із власною конфігурацією Playwright в `e2e/journey/`, яку pull request не запускають. Він реєструється з адресою тестової скриньки Resend і читає лист підтвердження через API Resend, перевіряє ціну для країни runner, платить у checkout пісочниці Polar тестовою карткою Stripe і перевіряє замовлення в Polar і ключ на `/app/license`. Потім запускає опублікований CLI, `npx saasyland@beta`, на preview: `activate`, те саме місце при другій активації, `whoami`, CI-пристрої до ліміту плану й ще один, якому відмовлено, місце, звільнене на `/app/license`, `deactivate` і повернення коштів через API пісочниці Polar, яке `whoami` повідомляє як `licenseRefunded`. `playwright.config.ts` тепер запускає лише `e2e/specs/`. Див. [Набір тестів шляху клієнта](/docs/tooling/playwright#journey-suite).
