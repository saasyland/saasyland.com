SaaSy Land 2.0 — це вихідний код вебсайту saasyland.com, його робочого простору для клієнтів і адміністративної консолі. Один застосунок TanStack Start на Cloudflare Workers поєднує багатомовний маркетинговий сайт, документацію та блог, автентифікацію, підписку на розсилку й оформлення замовлення через Polar з керуванням ліцензійними ключами.

Код написано як справжній продукт: модулі для кожної таблиці бази даних, типізовані серверні функції з власною авторизацією, один простір імен перекладів на сторінку, 100% покриття тестами та браузерні тести в CI. Він призначений для розробників, які хочуть вивчити або повторно використати продакшн-налаштування автентифікації, адмінки, інтернаціоналізації та інфраструктури Cloudflare.

Користувачі, сесії, продукти та категорії зберігаються в D1. Екрани аналітики, платежів, адміністрування блогу, запрошень і ролей поки що показують демонстраційні дані з `src/data/`.

SaaSy Land CLI та його приватні шаблони генератора — це окремий пропрієтарний продукт, який не входить до цієї кодової бази. Див. [Ліцензія](/docs/project/license).
