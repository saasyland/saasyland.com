## Link anfordern

`/auth/forgot-password` rendert `ForgotPasswordForm`. Das Formular ruft `requestPasswordReset` auf (`src/modules/verification/use-cases/request-password-reset.ts`, begrenzt mit `RATE_LIMITS.SENSITIVE`), wobei `redirectTo` auf `/auth/reset-password` in der aktuellen Locale gesetzt ist. Better Auth ruft anschließend `sendResetPasswordEmail` auf, das die Vorlage `ResetPasswordEmail` versendet.

## Neues Passwort festlegen

Der per E-Mail versendete Link öffnet `/auth/reset-password?token=…`. Ohne Token oder mit `?error=` zeigt die Seite die Meldung für einen ungültigen Link und einen Link zurück zu `/auth/forgot-password`. Mit Token ruft `ResetPasswordForm` die Funktion `resetPassword` auf (begrenzt mit `RATE_LIMITS.TOKEN`) und navigiert zu `/auth/sign-in`. Da `revokeSessionsOnPasswordReset` aktiviert ist, werden alle bestehenden Sitzungen dieses Benutzers beendet.

## Weitere Passwortänderungen

- Angemeldete Benutzer ändern ihr Passwort unter **Einstellungen → Sicherheit** ([Einstellungen](/docs/features/settings)).
- Admins legen in der Benutzertabelle ein Passwort für einen anderen Benutzer fest ([Benutzer (Admin)](/docs/features/users-admin)).
