title: "このプロジェクトについて"
description: "SaaSy Land のコードベースとは何か、誰のためのものかを説明します。"
---

SaaSy Land 2.0 は、saasyland.com の Web サイト、その顧客ワークスペース、管理コンソールのソースコードです。Cloudflare Workers 上の 1 つの TanStack Start アプリケーションが、多言語のマーケティングサイト、ドキュメントとブログ、認証、ニュースレターの購読、動画ストリーミングとコース、ライセンスキー管理を伴う Polar のチェックアウトをまとめて提供します。

コードは実際のプロダクトとして書かれています。データベースのテーブルごとのモジュール、独自の認可を持つ型付きのサーバー関数、ページごとに 1 つの翻訳名前空間、100% のテストカバレッジ、CI でのブラウザーテストを備えています。認証、管理画面、国際化、Cloudflare まわりの本番環境の構成を学びたい、あるいは再利用したい開発者に向けたものです。

ユーザー、セッション、商品、カテゴリー、動画、コース、レッスンの進捗は D1 のデータを使い、動画ファイルは R2 に保存されています。アナリティクス、決済、料金モデル、ブログ管理、ランディングページビルダー、招待、ロールの各画面と、ダッシュボードの売上グラフは、`src/data/` のデモデータを表示しています。

SaaSy Land CLI とその非公開のジェネレーターテンプレートは、別のプロプライエタリな製品であり、このコードベースには含まれていません。[ライセンス](/docs/project/license)を参照してください。
