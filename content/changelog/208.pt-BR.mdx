- Alterado: uma requisição de pacote à API de licenças da CLI lê o cabeçalho do arquivo compactado da versão no R2 em vez do arquivo. O SHA-256 do arquivo agora fica junto dele como o metadado personalizado `sha256`, que o `bundle:upload` do repositório da CLI grava, então o Worker não baixa, descompacta nem calcula mais o hash do pacote inteiro a cada requisição: com o pacote atual de 1,7 MB, uma requisição levava cerca de 31 ms de CPU no Worker de testes local e agora leva cerca de 3 ms, por maior que o pacote fique. Um objeto sem o digest responde `serviceUnavailable`, e o log informa qual é. O `bun run db:reset:test` preenche o pacote local com o digest dele por meio do `getPlatformProxy` do Wrangler, porque o `wrangler r2 object put` não consegue definir metadados personalizados. Veja [Pacotes de templates](/docs/features/cli-licence-api#template-bundles) e [Publicação dos pacotes](/docs/features/cli-licence-api#publishing-bundles).
