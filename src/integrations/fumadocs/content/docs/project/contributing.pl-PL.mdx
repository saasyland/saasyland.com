> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

1. Discuss large changes in an issue
2. Branch from mainline
3. Follow conventions + skills
4. `bun run check` · tests · build
5. Open a PR with `feat`/`fix`/`docs` title

Keep docs pages in sync when you add modules or routes.
