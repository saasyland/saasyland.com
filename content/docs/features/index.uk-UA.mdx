## Змішані фундаменти

Ауттентифікація, сеанси, 2FA, перевірка, користувачів адміністратора (живі дані), товари/категорії використання-кейси, налаштування/рахунок, docs, блог, посадка.

## В прогресі / оболонки UI

Платежі, курси, моделі ціноутворення, аналітичні прилади, лендінг-стабілдер UI — маршрути адміністратора; дротові реальні модулі, як ви виріб.

## Планування

Організація / команди, Stripe вексельна, роздрібна торгівля, розширений доступ контенту — документований таким чином, що стартова карта залишається повним.

Перегляд сторінок в цьому розділі для точок власності та розширення.
