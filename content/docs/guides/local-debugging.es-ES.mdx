## Elige un entorno

| Entorno              | Comandos                                    | Datos                                                                      | Proveedores                           |
| -------------------- | ------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------- |
| Vista previa aislada | `db:reset:test`, `build:test`, `start:test` | D1, KV y R2 locales en `.wrangler/test`, cuentas sembradas                 | Interceptados; no hacen falta cuentas |
| Desarrollo           | `db:reset:local`, `db:seed:local`, `dev`    | D1, KV y R2 locales en `.wrangler/state`, administrador y cursos sembrados | Reales, desde `.env.development`      |

```sh
bun run db:reset:test
bun run build:test
bun run start:test
```

La vista previa aislada sirve una compilación en `http://127.0.0.1:3000`; vuelve a compilarla para ver los cambios del código. Inicia sesión con una de las cuentas precargadas que enumera [Primera ejecución](/docs/getting-started/first-run) y la contraseña de `e2e/data/accounts.ts`. Los correos se capturan en lugar de enviarse: abre `/__test/emails?to=<address>` para leerlos, incluidos los enlaces de verificación.

```sh
cp .env.example .env.development
bun run db:reset:local
bun run db:seed:local
bun run dev
```

El servidor de desarrollo funciona en `http://localhost:3000` con recarga en caliente. Sus bindings `DB`, `CACHE`, `MEDIA` y `BUNDLES` son locales, así que nada de lo que hagas llega a los datos de la vista previa ni de producción. Inicia sesión como el administrador sembrado de [El seed local](/docs/tooling/database#the-local-seed). Usa `POLAR_SERVER=sandbox`.

## Lee los errores del servidor

- Una función de servidor que falla registra `Server function failed` con el error original en el terminal donde se ejecuta `bun run dev`, o en Workers Logs en los entornos desplegados. El navegador solo recibe el código de error.
- `Rate-limit storage unavailable` significa que D1 no estaba disponible durante una comprobación del límite de peticiones; la petición se rechazó.
- `[license] <method> <path> failed` significa que una petición a la API de licencias de la CLI falló en el servidor, por ejemplo porque falló D1 o Polar, y la CLI recibió `serviceUnavailable`. La entrada contiene el error con su causa y su traza, y `[licence key]` en lugar de la clave de quien llama.
- `No messages/<locale>/<namespace>.json` significa que una ruta declara un espacio de nombres sin archivo para ese idioma.

## Inspecciona los datos

- Drizzle Studio: `bun run db:studio:local` para la base de datos local; `:preview` y `:production` necesitan las variables `CLOUDFLARE_*` en el archivo de entorno correspondiente.
- Base de datos local de pruebas: `bunx wrangler d1 execute DB --env test --local --persist-to .wrangler/test --command "SELECT email, role FROM user"`.

## Arregla los archivos generados

- Tipos de bindings del Worker, tablas de nombres de clase o contenido de la documentación desactualizados: `bun run typegen`.
- Las traducciones no se resuelven: `bun run check:i18n` enumera las claves que faltan en cada idioma y las que no se resuelven en su ámbito de `useTranslations`.
- `bun run clean` elimina la salida de compilación, las cachés y `.wrangler`, incluida la base de datos local de pruebas; después ejecuta `db:reset:test`.

## Depura los tests

- Ejecuta un solo proyecto o solo los tests afectados: `bun run test:unit`, `bun run test:component`, `bun run test:changed`, `bun run test:watch`.
- Playwright: `bun run test:e2e:headed` muestra el navegador y `bun run test:e2e:ui` abre el modo UI. Las ejecuciones locales conservan las trazas de los tests fallidos y abren el informe HTML cuando hay fallos.
- Ejecuta la suite del navegador en un puerto libre del rango de la build de pruebas cuando otro servidor ocupa `127.0.0.1:3000` u otro worktree ejecuta su suite: `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3027 bun run test:e2e:pr`. [Playwright](/docs/tooling/playwright#running-beside-other-worktrees) explica cómo elegir el puerto.
