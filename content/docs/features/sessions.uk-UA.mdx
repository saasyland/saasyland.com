Сесії зберігаються в таблиці `session` у D1 (`src/modules/session/session.schema.ts`). `auth.session.ts` читає їх через `getRequestSession`, що кешується в межах запиту, і надає `getCurrentSessionQuery` маршрутам і компонентам. Клієнтська копія ніколи не містить токена сесії.

## Сценарії використання

| Сценарій                                  | Middleware                  | Використовує       |
| ----------------------------------------- | --------------------------- | ------------------ |
| `getActiveSessions`                       | з сесією                    | `SettingsSessions` |
| `revokeSession`                           | з сесією; лише власні сесії | `SessionRow`       |
| `revokeOtherSessions`                     | з сесією                    | `SettingsSessions` |
| `listUserSessions`                        | `session: ["list"]`         | `UserSessions`     |
| `revokeUserSession`, `revokeUserSessions` | `session: ["revoke"]`       | `UserSessions`     |

`getActiveSessions` повертає непрострочені сесії поточного користувача, від найновішої, і пропускає сесії входу від імені іншого користувача. `listUserSessions` повертає непрострочені сесії іншого користувача з `listUserSessions` від Better Auth, від найновішої та без їхніх токенів, разом із сесіями входу від імені. `revokeUserSession` приймає ID сесії й знаходить її токен на сервері, тож жоден токен не потрапляє в браузер.

## Інтерфейс

**Налаштування → Безпека** в `/admin/settings` показує `SettingsSessions` (`src/presentation/components/custom/admin/settings/sessions.tsx`). Кожен `SessionRow` показує пристрій (user agent або IP-адресу), останню активність і позначку поточної сесії та дає змогу відкликати цю сесію. Кнопка в заголовку відкликає всі інші сесії. Зміна пароля також оновлює список сесій.

Профіль користувача в `/admin/users` показує `UserSessions` (`src/presentation/components/custom/admin/users/user-sessions.tsx`): пристрій кожної сесії, час входу й останньої активності, кнопку, що її відкликає, а після підтвердження — кнопку, що виводить користувача з усіх пристроїв. Див. [Користувачі (адмін)](/docs/features/users-admin).
