title: Ajouter une table de données
description: Utilisez le kit TanStack DataTable partagé dans les écrans d'administration.

## Emplacement de la trousse

`src/presentation/components/custom/data-table`

## Caractéristiques (utilisateurs)

- `columns.tsx` / `cells.tsx` / `filters.tsx` / `actions.tsx` / `options.tsx`
- Carte des lignes DB → lignes de table dans `_lib` ou des outils de module
- Barre d'outils rafraîchir → invalider la touche TanStack Query pertinente
- Gardez les retombées de suspense libre de l'exécution de la table

## Options

Configurer la barre d'outils (recherche, filtres, exportation CSV, récupérer, paramètres), pagination, sélection et densité via `options` — voir UI → DataTable.
