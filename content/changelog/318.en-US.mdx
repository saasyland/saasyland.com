- Added: `/admin/orders` is a data grid. It filters by the day an order was placed, the customer, several products, a range of totals in each order's own currency, the discount, several billing countries and several statuses, each filter shown as a chip with a summary; sorts by several columns with Shift; and lets the admin show, hide, pin, move and resize columns and pick the row density and page size, which the browser keeps until Reset layout. See [Data grid](/docs/ui/data-grid) and [Orders and customers](/docs/features/orders).
- Added: Export CSV on `/admin/orders` downloads every order the search and filters find, across pages, with the visible columns; selected rows can be exported on their own.
- Added: a Refunded column on `/admin/orders`, hidden until the admin shows it, that sorts by the amount refunded.
- Changed: the period filter of `/admin/orders` is a range of days, from Last 7 days, Last 30 days, Last 12 months or the calendar, instead of a fixed choice.
- Changed: new tables use `DataGrid`, with a columns hook that declares each column's filter, default visibility and pinning. The other admin tables keep `DataTable` until each moves. See [Add a data grid](/docs/guides/add-a-data-table).
