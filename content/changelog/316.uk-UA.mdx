- Додано: `bun run deps:update` однією командою оновлює кожну залежність із діапазоном до найновішого релізу, Vite+ через `vp migrate` і навички агентів, а потім називає зафіксовані пакети, що мають новіший реліз. Див. [Залежності](/docs/conventions/dependencies#upgrading).
- Додано: `bun run check` завершується помилкою, коли пакет, який описує навичка агентів, як-от `resend`, `better-auth` або `wrangler`, змінився без `bun run skills:update`, і коли встановлені навички відрізняються від `skills-lock.json`. `SKILL_SOURCES` у `src/data/skills.ts` зіставляє кожне джерело навичок із пакетами, які воно описує. Див. [Навички агентів](/docs/tooling/agent-skills#drift-checks).
- Додано: щотижневий workflow `updates.yml` перелічує доступні оновлення залежностей і навичок в одному issue на GitHub, яке він відкриває, переписує й закриває. Див. [CI/CD](/docs/tooling/ci-cd#updates).
- Змінено: CLI `skills` є залежністю для розробки, тож `bun.lock` фіксує версію, яка встановлює навички й обчислює їхні хеші.
