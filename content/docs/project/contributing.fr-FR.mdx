---
title: Contribution
description: Comment proposer des changements au démarreur.
---

1. Discuter des changements importants dans un problème
2. Branche de la ligne principale
3. Suivre les conventions + compétences
4. `bun run check` · tests · construction
5. Ouvrir un PR avec `feat`/`fix`/`docs` titre

Conservez les pages docs en synchronisation lorsque vous ajoutez des modules ou des itinéraires.
