- Fixed: Chromium logged `Error with Permissions-Policy header: Unrecognized feature: 'browsing-topics'` on every page, because Chrome withdrew the Topics API. The `Permissions-Policy` in `SECURITY_HEADERS` and `public/_headers` now turns off only camera, geolocation and microphone, which Chromium still enforces, and a browser spec fails when a page logs a Permissions-Policy error. See [Security and hardening](/docs/features/security).
- Fixed: right after a deploy, Early Hints made the browser fetch the previous build's stylesheet, a 404. Cloudflare replays a page's last `Link` header as `103 Early Hints`, also after a deploy, and the stylesheet's name changes with its content, so the Worker's `Link` header now names only the locale's fonts, whose names stay the same. The fonts keep 20–48 ms of First Contentful Paint from Early Hints. See [Performance](/docs/conventions/performance) for the measurements and [Cloudflare Workers](/docs/integrations/cloudflare-workers) for the zone's Early Hints and Speed Brain settings.
- Fixed: a link to a section of the home page in a localized post, such as `/#pricing`, went to `/pl-PL/#pricing` and through a redirect. `localizeHref` localizes only the path of a link and keeps its query and fragment, so MDX and React Aria links now open `/pl-PL#pricing`. `check-content.ts` fails an internal link that ends in a slash, `/index` or `.html` or starts with a locale. See [Translations and content](/docs/conventions/translations).
