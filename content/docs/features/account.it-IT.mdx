`src/modules/account` possiede la tabella `account` di Better Auth (`account.schema.ts`): una riga per ogni credenziale o provider OAuth collegato a un utente. I token OAuth al suo interno sono cifrati.

## Casi d’uso

| Caso d’uso                         | Middleware            | Usato da                               |
| ---------------------------------- | --------------------- | -------------------------------------- |
| `signUpWithPassword`               | limitato              | `SignUpForm`                           |
| `signOutUser`                      | autenticato           | `useSignOut`                           |
| `changePassword`                   | autenticato, limitato | `SettingsPasswordForm`                 |
| `changeEmail`                      | autenticato, limitato | nessuna schermata                      |
| `updateUser`                       | autenticato           | nessuna schermata                      |
| `sendChangeEmailConfirmationEmail` | hook di Better Auth   | `user.changeEmail` in `auth.server.ts` |

`sendChangeEmailConfirmationEmail` invia `ChangeEmailConfirmationEmail` all’indirizzo attuale con il link di conferma fornito da Better Auth.

## Disconnessione

`useSignOut` (`src/hooks/use-sign-out.ts`) esegue `signOutUserMutation`, svuota la cache delle query, naviga verso `/auth/sign-in` e mostra una notifica. Il widget utente dell’amministrazione e la barra laterale di `/app` mostrano ciascuno un `SignOutButton` che lo usa.
