O aplicativo expõe três rotas HTTP, declaradas com `server.handlers` em `createFileRoute` dentro de `src/routes/api`:

| Rota          | Métodos   | Handler                                                                                                                                                   |
| ------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api`        | GET       | Retorna `{ "runtime": "cloudflare-workers" }`.                                                                                                            |
| `/api/auth/$` | GET, POST | Better Auth: login, callbacks OAuth, `/api/auth/verify-email` e os endpoints do plugin do Polar `/api/auth/polar/webhooks` e `/api/auth/customer/portal`. |
| `/api/search` | GET       | Busca do Fumadocs (`fumadocs.search.ts`).                                                                                                                 |

```ts
import { createFileRoute } from "@tanstack/react-router"

import { auth } from "~/src/integrations/better-auth/auth.server"

export const Route = createFileRoute("/api/auth/$")({
  server: { handlers: { GET: ({ request }) => auth.handler(request), POST: ({ request }) => auth.handler(request) } },
})
```

## Funções de servidor em vez de REST

As operações do aplicativo são funções `createServerFn` em `src/modules/<table>/use-cases` (ou dentro da única rota que as usa). O TanStack Start as chama via RPC sob `/_serverFn`, com middleware para sessões, permissões e limites de taxa. Não adicione um endpoint REST para uma operação que só este aplicativo chama; adicione uma rota HTTP apenas para chamadores externos, como webhooks, e verifique as assinaturas na integração do provedor.

## Comportamento

- O Worker não aplica redirecionamentos de idioma a `/api` nem a `/_serverFn`; essas requisições pegam o idioma do cookie.
- O build não pré-renderiza `/api`.
- Os testes dos handlers ficam em `src/routes/api/__test__/handlers.test.ts`.
