Sklonuj repozytorium, a następnie zainstaluj zależności z jego katalogu głównego, używając pliku blokady zapisanego w repozytorium:

```sh
bun install --frozen-lockfile
```

Skrypt cyklu życia `prepare` następnie:

1. Uruchamia `vp config --no-agent`, który instaluje program uruchamiający hooki Git z `.vite-hooks/` (kontrole pre-commit, hook komunikatu commita i hook `post-checkout`, który instaluje ten program w nowych worktree).
2. Uruchamia `scripts/verify-git-hooks.ts`, który przerywa instalację błędem, gdy Git nie uruchomiłby tego programu, i wypisuje polecenie, które to naprawia.
3. Uruchamia `bun run generate:cn`, który buduje tablice scalania klas w `.source/cn-tables.ts`.
4. Uruchamia `bun run content`, który generuje kolekcje Fumadocs w `.source/`.

Jeśli instalujesz z `--ignore-scripts`, tak jak CI, uruchom potem `bun run typegen`. To polecenie dodatkowo generuje ponownie `src/types/worker-configuration.d.ts` na podstawie `wrangler.jsonc`.

## Opcjonalne dodatki

```sh
bun run test:e2e:install
bun run skills:sync
```

Pierwsze polecenie instaluje Chromium i WebKit dla Playwrighta, a drugie przywraca [umiejętności agentów](/docs/tooling/agent-skills).
