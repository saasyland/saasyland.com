---
title: "Zugriff auf Inhalte"
description: "Was den Zugriff derzeit steuert: Route Guards, Berechtigungen und der Lizenzdatensatz. Premium-Inhalte werden nicht geschützt."
---

Es gibt keine geschützten Premium-Inhalte. Der Zugriff wird gesteuert durch:

- **Route Guards**: `/app` verlangt eine Sitzung (`requireSignedIn`); `/admin` verlangt die Berechtigung `admin: ["access"]` (`requireAdmin`).
- **Serverfunktionen**: `authorized(permission)` prüft die Rollenberechtigungen aus `auth.access.ts`.
- **Lizenz**: Die Tabelle `license` enthält höchstens eine Lizenz pro Benutzer mit einer Stufe `tier` (`core`, `complete`, `agency`) und einem Status `status` (`active`, `revoked`) und wird von Polar-Webhooks geschrieben. `/app` und `/app/license` lesen sie über `currentLicenseQuery`, um entweder die Checkout-Optionen oder den Lizenzschlüssel anzuzeigen.

`/premium` (`src/routes/_landing.premium.tsx`) ist eine Platzhalterseite, die nur ihren Titel aus `pages.premium` rendert.

Um etwas an einen Kauf zu knüpfen, lesen Sie die Lizenz auf dem Server mit `getLicense(userId)` aus `src/modules/license/use-cases/get-license.ts` und prüfen Sie `status` und `tier`.
