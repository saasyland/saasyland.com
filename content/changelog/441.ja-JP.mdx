- 修正: `bun run check:features` は、コードと同じルールで `package.json` のスクリプトも刈り込みます。削除したファイルや削除されるスクリプトを実行するステップを取り除き、ステップが残らないスクリプトも取り除くため、コンテンツを外したサイトに削除済みのファイルを指す `check:content` が残らなくなりました。スクリプトが削除したファイルを指すか、なくなったスクリプトを実行するときも、各シナリオは失敗します。[テスト](/docs/conventions/testing#tests-follow-the-features) を参照してください。
- 修正: テストビルドの GitHub のスター数は古くなりません。その GitHub API は固定のスター数を返すテストダブルだからです。そのため、`build:test` からしばらくたってから始めたブラウザーのテストでもスター数を取得し直さず、データセーバーと保留したサーバー関数のテストが失敗しなくなりました。[Cloudflare KV](/docs/integrations/cloudflare-kv) を参照してください。
