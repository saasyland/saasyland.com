- ブラウザーが Drizzle をダウンロードしなくなりました。各 `<table>.zod.ts` は `drizzle-zod` を使ってテーブルから `insert`、`select`、`update` のスキーマを組み立てていましたが、それを読むのはテストだけでした。また、いくつかの enum のタプルが `.schema.ts` のファイルにあったため、フォーム、クエリオプション、`/admin` と `/app` の読み込み中のスケルトンが、テーブルと `drizzle-orm`、さらに `drizzle-zod` を通じて zod のすべてのロケールを、すべてのページに持ち込んでいました。`TIMEZONE_CODES` と `LICENSE_STATUSES` を含むすべての enum のタプルは、それぞれのモジュールの `<table>.constants.ts` に置かれるようになり、導出したスキーマと `drizzle-zod` への依存はなくなりました。各ページが読み込む JavaScript は gzip 圧縮後で約 75 KiB 減り、ランディングページは 526.2 KiB から 450.7 KiB になりました。TanStack Start のインポート保護がクライアントのビルドで `drizzle-orm` を禁止するため、これを再び持ち込むインポートはビルドを失敗させ、そのインポートの連鎖を出力します。[ORM をブラウザーに入れない](/docs/conventions/performance#keep-the-orm-out-of-the-browser)を参照してください。
