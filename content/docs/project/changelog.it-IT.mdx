Ogni sezione elenca le modifiche arrivate su `main` in quel giorno (UTC), dalle più recenti, e ogni modifica termina con un link alla pull request da cui proviene e, una volta distribuita, alla release che l'ha rilasciata per prima. Ogni deploy di produzione riceve un tag e viene pubblicato come GitHub Release con le voci che ha rilasciato come note; vedi [Release e tag](/docs/tooling/ci-cd#releases-and-tags). Le versioni della CLI stessa sono nelle [note di rilascio della CLI](/docs/cli/releases). Ogni modifica aggiunge la propria voce; vedi [Voci del changelog](/docs/conventions/git-workflow#changelog-entries).
