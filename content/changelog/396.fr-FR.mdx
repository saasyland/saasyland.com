- Modifié : un commentaire reste l’exception, mais quand il est vraiment nécessaire, il peut tenir en une seule ligne qui renvoie, après quelques mots, à l’endroit où se trouve la raison : une page `https://` ou un chemin `/docs/`. `code-style/no-comments` et `bun run check:comments` acceptent cette forme et rien d’autre. Voir [Style de code](/docs/conventions/code-style#comments).
- Ajouté : `bun run check:comments` lit aussi les fichiers YAML, et n’y accepte que l’étiquette de version qui suit une action épinglée à un SHA de commit, comme `# v4`.
