- Fixed: several worktrees can run the browser suite at the same time. The test build now trusts `127.0.0.1` and `localhost` on ports <RepositoryFact name="testServerFirstPort" /> to <RepositoryFact name="testServerLastPort" /> besides `127.0.0.1:3000`, so each worktree runs the suite on a port of its own with `PLAYWRIGHT_BASE_URL`. Until now it trusted only `127.0.0.1:3000` and `127.0.0.1:3020`, and on any other port the sign-in and course pages failed. Production, preview and development trust the same hosts as before. See [Playwright](/docs/tooling/playwright#running-beside-other-worktrees).
- Added: `playwright.config.ts` stops before it builds anything when `PLAYWRIGHT_BASE_URL` names a host the test build does not trust, and `e2e/global-setup.ts` stops the run before the first test when the server on the suite's port runs from another worktree, so Playwright can no longer test another worktree's build and database.
