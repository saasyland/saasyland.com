---
title: "Einführung"
description: "Anbieter-Adapter unter src/integrations."
---

Jeder Ordner in `src/integrations/<vendor>/` kapselt einen Anbieter in `<prefix>.<concern>.ts`-Dateien, wobei das Präfix der Kurzname des Anbieters ist (`auth`, `drizzle`, `i18n`, `form`): Konfiguration, Clients und schlanke Adapter. Geschäftsregeln und Datenbankoperationen bleiben in `src/modules`, und Komponenten importieren nie direkt einen Anbieter-Client.

| Ordner           | Dateien                                                                                                                                                                         | Zweck                                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `affonso`        | `affonso.constants.ts`, `affonso.program.ts`, `affonso.referral.ts`                                                                                                             | Parameter für Partnerempfehlungen, die Programm-ID und die Checkout-Metadaten                                                                |
| `better-auth`    | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.roles.ts`, `auth.session.ts`                                                | Sitzungen, OAuth, Plugins, Routen-Guards, Middleware für Serverfunktionen, Rollen und Berechtigungen                                         |
| `drizzle-orm`    | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `drizzle.local.config.ts`, `drizzle.errors.ts`, `drizzle.columns.ts`, `drizzle.time-series.ts`, `migrations/` | D1-Client, Schema-Barrel, drizzle-kit-Konfiguration, `rethrowAsConflict`, `timestamps()`, `bucketOf`                                         |
| `fumadocs`       | `fumadocs.config.ts`, `fumadocs.schema.ts`, `fumadocs.i18n.ts`, `fumadocs.indexes.ts`, `fumadocs.docs.ts`, `fumadocs.blog.ts`, `fumadocs.changelog.ts`, `fumadocs.icons.ts`     | Docs- und Blog-Collections, beim Build erzeugte Indizes, Suche, die Changelog-Einträge und die Icons der Seitenleiste                        |
| `motion`         | `motion.features.ts`, `motion.tokens.ts`                                                                                                                                        | Verzögert geladene Motion-Features und gemeinsame Übergänge                                                                                  |
| `polar`          | `polar.config.ts`, `polar.constants.ts`, `polar.customers.ts`, `polar.webhooks.ts`, `polar.vite.ts`                                                                             | Polar-SDK-Client, eigene Werte von Polar, Kundenkonten, der Code, den jedes Webhook-Ereignis erreicht, und die Build-Einstellung für das SDK |
| `resend`         | `resend.config.ts`, `resend.utils.ts`                                                                                                                                           | Resend-Client, `sendEmail` und `EMAIL_PURPOSE`                                                                                               |
| `takumi`         | `takumi.fonts.ts`, `takumi.render.tsx`                                                                                                                                          | Rendert die Social Cards und das Logo der Organisation beim Build mit den Schriften der Website                                              |
| `tanstack-form`  | `form.fields.ts`, `form.submit.ts`                                                                                                                                              | `fieldErrorMessage` für Fehler in Formularfeldern sowie `submitForm` und `showFieldError`, die das ungültige Feld markieren und fokussieren  |
| `tanstack-query` | `query.cache.ts`                                                                                                                                                                | Standard-Cache-Zeiten des `QueryClient` pro Request                                                                                          |
| `use-intl`       | `i18n.config.ts`, `i18n.loaders.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                                                                 | Sprachen, Nachrichten-Namespaces, Sprach-Middleware, URL-Hilfsfunktionen                                                                     |
| `zod`            | `zod.config.ts`                                                                                                                                                                 | Lässt Zod im Browser `jitless` laufen, sodass es unter der Content Security Policy nie nach `eval` sucht                                     |
