---
title: モジュールカタログ
description: src/modules ドメインおよび所有権の在庫。
---

| モジュール     | オーナーズ                                                         |
| -------------- | ------------------------------------------------------------------ |
| `_core`        | エラー、locale/currency/タイムゾーンのカタログ、共有ユーティリティ |
| `account`      | プロフィール / メール / パスワード / サインアウト                  |
| `user`         | 管理者ユーザー管理 + 偽装ヘルパー                                  |
| `session`      | リスト/リデュークセッション                                        |
| `two-factor`   | TOTPが有効/検証/無効化                                             |
| `verification` | メール認証 + パスワードリセットオーケストレーション                |
| `product`      | 製品カタログのユースケース                                         |
| `category`     | カテゴリー ユースケース                                            |

新しいドメインフォルダーを導入する際に行を追加します。
