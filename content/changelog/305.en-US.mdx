- Fixed: in Safari, leaving a page while it still loads its code, for example a lesson whose video player is on its way, takes you to the page you asked for. The page took the files Safari cancelled for code a new deploy had removed and loaded itself again, which sent you back. See [Delivery layer](/docs/architecture/delivery-layer#after-a-deploy).
- Changed: the browser suite runs in WebKit again. A patch to `playwright-core` 1.65.1 lets its WebKit driver follow the return from Polar's hosted checkout, and the clipboard specs ask each browser only for the permissions it knows. See [Dependencies](/docs/conventions/dependencies) and [Testing](/docs/conventions/testing).
