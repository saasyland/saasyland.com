- 修正: 負荷の高いマシンでのビルドが、`connect ETIMEDOUT ::1` と `connect ECONNREFUSED 127.0.0.1` でプリレンダリングを止めることがありました。プリレンダリングが起動するプレビューサーバーは `localhost` で待ち受け、Node はこの名前をまず `::1` に解決します。クローラーは名前で接続し、`::1`、次に `127.0.0.1` をそれぞれ短いタイマーで試していたため、ビルドがそれより長く止まると `::1` をあきらめ、`127.0.0.1` では何も見つけられませんでした。`vp preview` は `src/data/local-server.ts` の `LOCAL_SERVER` のアドレスである `127.0.0.1` で待ち受けるようになり（`start` と `start:test` では `127.0.0.1:3000`、プリレンダリングでは空いているポート）、ローカルのクライアントは名前を解決せずにサーバーのアドレスへ接続します。Playwright の既定の URL と `appHostsForMode` が信頼するローカルホストも同じ定数から取ります。
