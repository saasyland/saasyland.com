---
title: "Навички агентів"
description: "Навички від постачальників для агентів програмування, відновлювані з skills-lock.json."
---

`skills-lock.json` фіксує навички агентів, які використовуються з цим репозиторієм. Встановлені навички не комітяться: `.agents/` і `.claude/` ігноруються Git.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` видаляє `.agents/skills` і `.claude/skills`, повторно встановлює кожну зафіксовану навичку через `bunx skills experimental_install`, переміщує кожну навичку в групу постачальника за шляхом `.agents/skills/<group>/<skill>/SKILL.md` і створює посилання на кожну групу в `.claude/skills`. Скрипт завершується помилкою, коли для джерела навички немає зіставлення з групою.

| Група                                                 | Джерело                                                            |
| ----------------------------------------------------- | ------------------------------------------------------------------ |
| `anthropic`                                           | `anthropics/skills`                                                |
| `better-auth`                                         | `better-auth/skills`                                               |
| `cloudflare`                                          | `cloudflare/skills`                                                |
| `polar`                                               | `polarsource/skills`                                               |
| `resend`                                              | `resend/resend-skills`                                             |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) і `TanStack/table` (`table`) |
| `remotion`                                            | `remotion-dev/skills`                                              |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Загальні навички з інженерії, дизайну та маркетингу                |

Синхронізація замінює обидві папки, тож зберігайте власні навички деінде. `bun run clean:hardcore` видаляє `skills-lock.json`.

## Правило

Перш ніж змінювати код, пов'язаний із TanStack Start, Router чи Table, Better Auth, Cloudflare, Polar або Resend, прочитайте відповідну навичку. Навички описують актуальні API постачальників; конвенції цього репозиторію задокументовано в розділах [Архітектура](/docs/architecture) і [Конвенції](/docs/reference/conventions).
