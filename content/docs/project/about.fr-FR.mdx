description: "Ce qu'est la base de code SaaSy Land et à qui elle s'adresse."
---

SaaSy Land 2.0 est le code source du site saasyland.com, de son espace client et de sa console d'administration. Une seule application TanStack Start sur Cloudflare Workers réunit un site marketing multilingue, une documentation et un blog, l'authentification, les abonnements à la newsletter et le paiement Polar avec gestion des clés de licence.

Le code est écrit comme un vrai produit : un module par table de base de données, des fonctions serveur typées avec leur propre autorisation, un espace de noms de traduction par page, une couverture de tests à 100 % et des tests dans le navigateur en CI. Il s'adresse aux développeurs qui souhaitent étudier ou réutiliser une mise en place de production de l'authentification, de l'administration, de l'internationalisation et de l'infrastructure Cloudflare.

Les utilisateurs, les sessions, les produits et les catégories reposent sur D1. Les écrans d'analytique, de paiements, d'administration du blog, d'invitations et de rôles affichent encore des données de démonstration issues de `src/data/`.

La CLI SaaSy Land et ses modèles de génération privés constituent un produit propriétaire distinct et ne font pas partie de cette base de code. Voir [Licence](/docs/project/license).
