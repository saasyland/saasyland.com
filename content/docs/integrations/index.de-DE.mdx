---
title: "Einführung"
description: "Anbieter-Adapter unter src/integrations."
---

Jeder Ordner in `src/integrations/<vendor>/` kapselt einen Anbieter in `<vendor>.<concern>.ts`-Dateien: Konfiguration, Clients und schlanke Adapter. Geschäftsregeln und Datenbankoperationen bleiben in `src/modules`, und Komponenten importieren nie direkt einen Anbieter-Client.

| Ordner          | Dateien                                                                                                         | Zweck                                                                    |
| --------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `better-auth`   | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.session.ts` | Sitzungen, OAuth, Routen-Guards, Middleware für Serverfunktionen, Rollen |
| `drizzle-orm`   | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `migrations/`                                 | D1-Client, Schema-Barrel, drizzle-kit-Konfiguration                      |
| `fumadocs`      | `fumadocs.config.ts`, `fumadocs.i18n.ts`, `fumadocs.source.ts`, `fumadocs.docs.ts`, `fumadocs.search.ts`        | Docs- und Blog-Collections, lokalisierte Quellen, Suche                  |
| `motion`        | `motion.features.ts`, `motion.tokens.ts`                                                                        | Verzögert geladene Motion-Features und gemeinsame Übergänge              |
| `polar`         | `polar.config.ts`, `polar.constants.ts`                                                                         | Polar-SDK-Client und Checkout-Produkte                                   |
| `resend`        | `resend.config.ts`, `resend.utils.ts`                                                                           | Resend-Client und `sendEmail`                                            |
| `tanstack-form` | `form.fields.ts`                                                                                                | `fieldErrorMessage` für Fehler in Formularfeldern                        |
| `use-intl`      | `i18n.config.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                    | Sprachen, Nachrichten-Namespaces, Sprach-Middleware, URL-Hilfsfunktionen |
