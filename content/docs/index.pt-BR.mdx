SaaSy Land é o código-fonte do site saasyland.com, do workspace do cliente e do console de administração: uma única aplicação TanStack Start no Cloudflare Workers com D1, KV, Better Auth, Polar, Resend, use-intl e Fumadocs. A CLI do SaaSy Land e seus templates de geração ficam em um repositório separado e privado.

<Callout title="Como usar esta documentação">
  Comece por **Primeiros passos** para executar a aplicação. **Arquitetura** explica onde o código fica, **Guias** são receitas para
  tarefas, **Recursos** descrevem o comportamento do produto e **Integrações** documentam cada adaptador de fornecedor em
  `src/integrations`.
</Callout>

## Editando a documentação

As páginas ficam em `content/docs` como `<slug>.<locale>.mdx`, um arquivo para cada um dos nove locales, e cada pasta lista suas páginas em `meta.<locale>.json`. Todos os locales listam os mesmos slugs e mantêm os blocos de código idênticos byte a byte; `bun run check:i18n` garante isso por meio de `scripts/check-content.ts`. `bun run content` gera novamente `.source/`, e `dev` e todos os scripts de build o executam para você.

Páginas MDX podem usar componentes do Fumadocs (`<Cards>`, `<Callout>`, `<Steps>`, `<Tabs>`, `<Accordions>`) e alguns primitivos do shadcn (`<Button>`, `<Badge>`, `<Alert>`, `<Table>`). Links internos como `/docs/tooling/testing` recebem automaticamente o prefixo do locale do leitor.
