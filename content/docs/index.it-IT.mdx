## Elaborazione locale

File di contenuto: `content/docs`.

MDX può usare componenti Fumadocs (`<Cards>`, `<Callout>`, `<Steps>`, `<Tabs>`, `<Accordions>`) e primitivi shadcn selezionati (`<Button>`, `<Badge>`, `<Alert>`, `<Table>`, …).

Dopo l'aggiunta di pagine, aggiornare la cartella `meta.<locale>.json` `pages` array (lo script ponteggio fa questo per voi). Cartella `index` pagine sono sidebar **indici delle cartelle** — non elencare `index` di nuovo in `pages`.
