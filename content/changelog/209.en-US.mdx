- Fixed: the course block on the landing page moved the page when its courses loaded. Its placeholder assumed two courses of six lessons, so once the courses arrived the block shrank or grew and everything below it jumped, by 103 pixels on a desktop and 331 on a phone with the test data, and by more when no course is published. Each course is now a column of three lines that never wrap: its title, its kind, lesson count and minutes, and its first free preview with a video. The placeholder draws the same lines, and the messages for no published course and for a failed request sit in a frame the size of a column, so the block has the same height in every state at every width. The block no longer lists each course's first lessons, and each course's own free preview replaces the separate **Watch a free lesson** link; `getCourseShowcase` returns that preview instead of the lessons. `landing.spec.ts` holds the request on a desktop and a phone, lets it succeed or fail, and checks that the block keeps its height and that no layout shift is reported. See [Courses](/docs/features/courses) and [Performance](/docs/conventions/performance).
