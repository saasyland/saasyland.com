---
title: Aggiungi una pagina di amministrazione
description: Registra le rotte, la barra laterale e la shell della pagina.
---

## Passi

1. Aggiungi il percorso per `ROUTES`
2. Aggiungere la barra laterale `admin/constants/sidebar.ts` (+ etichette i18n)
3. Creare `app/[locale]/(admin)/admin/<feature>/page.tsx`
4. Colocate `_components` / `_lib`
5. Dati della porta con casi d'uso + Suspense
6. Documento sotto Caratteristiche
