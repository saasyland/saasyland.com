- **ルート:** コンポーネント、ガード、ローダー、HTTP ハンドラを持つネイティブな TanStack ファイルルートです。
- **サーバー機能:** 組まれた RPC 操作 `createServerFn`.
- **クエリ:** loader と React 間で共有された、安定したキーでデータを読み込みます。
- **ミュテーション:** TanStack Query で送信された操作と、サーバ関数でバックアップされた操作。
- **名前空間:** locale ディレクトリの下のドット化された翻訳ファイルです。
- **結合:** Worker に供給される Cloudflare リソース `env.DB`, `env.CACHE` または `env.ASSETS`.
- **プレンダー:** パブリックルート用のビルドタイムHTML。
