Todos os arquivos e pastas usam kebab-case.

## Arquivos de código-fonte

| Padrão                                                       | Significado                                                                                                                        |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | Rota de arquivo; os pontos são segmentos de caminho, `_` marca um layout sem caminho, `$` uma rota splat e `index` uma rota índice |
| `src/routes/api/<name>.ts`                                   | Handler HTTP                                                                                                                       |
| `modules/<table>/<table>.schema.ts`                          | Tabela Drizzle                                                                                                                     |
| `modules/<table>/<table>.zod.ts`                             | Schemas Zod                                                                                                                        |
| `modules/<table>/<table>.constants.ts`                       | Chaves de query, chaves de mutation e enums                                                                                        |
| `modules/<table>/<table>.types.ts`                           | Tipos derivados da tabela                                                                                                          |
| `modules/<table>/<table>.utils.ts`                           | Helpers puros da tabela                                                                                                            |
| `modules/<table>/<table>.server.ts`                          | Helpers do módulo exclusivos do servidor                                                                                           |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | Um caso de uso                                                                                                                     |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | Configuração ou adaptador de um fornecedor, por exemplo `auth.server.ts`                                                           |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | Colunas de uma tabela de dados                                                                                                     |
| `presentation/emails/<name>.tsx`                             | Template de e-mail que exporta `<NAME>_NAMESPACE`                                                                                  |
| `hooks/use-<name>.ts`                                        | Hook React compartilhado                                                                                                           |
| `providers/<name>-provider.tsx`                              | Provider da aplicação                                                                                                              |

## Testes

| Padrão                                | Executado por                   |
| ------------------------------------- | ------------------------------- |
| `__test__/<file>.test.ts`             | Projeto `node` do Vitest        |
| `__test__/<file>.integration.test.ts` | Projeto `integration` do Vitest |
| `__test__/<file>.component.test.tsx`  | Projeto `component` do Vitest   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                      |

Os arquivos de teste levam o nome do arquivo de código que cobrem, por exemplo `user.schema.test.ts` para `user.schema.ts`.

## Conteúdo e mensagens

| Padrão                                    | Significado                                                 |
| ----------------------------------------- | ----------------------------------------------------------- |
| `messages/<locale>/<namespace>.json`      | Namespace de tradução, por exemplo `pages.admin.users.json` |
| `content/docs/<path>/<page>.<locale>.mdx` | Página da documentação                                      |
| `content/docs/<path>/meta.<locale>.json`  | Navegação da documentação                                   |
| `content/blog/<slug>.<locale>.mdx`        | Post do blog                                                |
