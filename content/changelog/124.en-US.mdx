- Domain values are named once as constants instead of repeated strings: product statuses and types (`PRODUCT_STATUS`, `PRODUCT_TYPE`), category icons, kinds and visibilities (`CATEGORY_ICON`, `CATEGORY_KIND`, `CATEGORY_VISIBILITY`), derived user statuses (`USER_STATUS`), the credential and OAuth provider ids (`AUTH_PROVIDER`), email purposes (`EMAIL_PURPOSE`) and the admin blog's demo post statuses. Tests, e2e data and the seed script import them and the role, tier, status and `ERROR_CODES` constants. See [Add a module](/docs/guides/add-a-module).
