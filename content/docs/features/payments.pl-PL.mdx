Interfejs `/admin/payments` korzysta dziś z atrap wierszy. Deklaracje `order` w `APP_STATEMENTS` szkicują już odczyt, aktualizację i zwrot środków.

- `modules/billing` or `modules/order` use-cases

- Webhooks route handler
- Customer invoices under `/app`
- Map Better Auth user ↔ customer id
