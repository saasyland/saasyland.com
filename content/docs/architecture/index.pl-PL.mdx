SaaSy Land to jedna aplikacja TanStack Start działająca jako Cloudflare Worker. Kod jest podzielony według odpowiedzialności:

- **Trasy** (`src/routes`) komponują strony. Plik trasy deklaruje swoje przestrzenie nazw tłumaczeń, guard, loader i tagi head, a następnie renderuje komponenty.
- **Moduły** (`src/modules/<table>`) istnieją wyłącznie dla rzeczywistych tabel bazy danych. Do modułu należą schemat Drizzle tabeli, schematy Zod, stałe, typy oraz przypadki użycia, które ją odczytują lub modyfikują.
- **Integracje** (`src/integrations/<vendor>`) konfigurują zewnętrzne biblioteki i usługi.
- **Warstwa prezentacji** (`src/presentation`) zawiera prymitywy shadcn, komponenty aplikacji, szablony React Email, style, motyw i branding.
- **Kod współdzielony** znajduje się w `src/data` (dane używane przez kilka plików), `src/lib` (małe narzędzia), `src/hooks` i `src/providers`.

```text
src/
├── routes/          Flat file routes that compose pages
├── modules/         One folder per database table, plus _core
├── integrations/    One folder per vendor
├── presentation/    Components, emails, styles, theme, branding
├── data/            Data shared by several files
├── lib/             Small shared utilities
├── hooks/           Shared React hooks
├── providers/       Application providers
├── platform/        Test runtime wiring
├── types/           Global type declarations
├── router.tsx       Router and per-request QueryClient
├── routes.ts        ROUTES path constants
└── server.ts        Cloudflare Worker entry
```

## Zasady kształtujące kod

- Pliki tras tylko komponują. Widżety, dialogi, formularze i kolumny tabel znajdują się w `src/presentation/components/custom`, po jednym na plik.
- Komponenty same odczytują swoje tłumaczenia i dane przez `useTranslations`, `useSuspenseQuery` lub dane loadera trasy. Trasy nie przekazują etykiet ani danych w dół przez propsy.
- Funkcja serwerowa operująca na tabeli jest przypadkiem użycia w module tej tabeli. Funkcję serwerową używaną przez jedną trasę można zdefiniować w pliku tej trasy. Wszystko inne należy do `src/lib`.
- Nie ma kontenera wstrzykiwania zależności ani warstwy wrapperów. Importuj konkretną funkcję z folderu, do którego należy.
- Stała używana przez jeden plik pozostaje w tym pliku. Do `src/data` trafiają tylko dane współdzielone przez kilka plików.
