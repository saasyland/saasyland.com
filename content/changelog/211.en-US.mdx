- CLI licence API: a request reaches D1 once before the Worker asks Polar. The address and licence-key rate limits and the licence lookup took three D1 round trips, one after another; they now run in one D1 batch, which D1 runs as one transaction. `rateLimitBatch` in `src/lib/rate-limit.ts` returns the statements that count a request, and the API adds its licence lookup to them. A request that the address limit refuses still writes nothing and still does not count against the key, an unknown key still counts against both limits, and `retry-after` is still the seconds left in the window that refused the request. The key comes from the `authorization` header, so the Worker refuses a request over either limit before it reads the body; a request that carries a key now counts against that key even when its body or machine header cannot be read. Expired counters are removed once per request instead of once per limit. See [Rate limits](/docs/features/cli-licence-api#rate-limits).
