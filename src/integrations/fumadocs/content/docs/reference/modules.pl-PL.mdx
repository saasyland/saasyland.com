> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

| Module         | Owns                                                    |
| -------------- | ------------------------------------------------------- |
| `_core`        | Errors, locale/currency/timezone catalogs, shared utils |
| `account`      | Profile / email / password / sign-out                   |
| `user`         | Admin user management + impersonation helpers           |
| `session`      | List / revoke sessions                                  |
| `two-factor`   | TOTP enable / verify / disable                          |
| `verification` | Email verify + password reset orchestration             |
| `product`      | Product catalog use-cases                               |
| `category`     | Category use-cases                                      |

Add a row when you introduce a new domain folder.
