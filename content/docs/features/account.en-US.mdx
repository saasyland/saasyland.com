`src/modules/account` owns the Better Auth `account` table (`account.schema.ts`): one row per credential or OAuth provider linked to a user. OAuth tokens in it are encrypted.

## Use cases

| Use case                           | Middleware              | Used by                                                                       |
| ---------------------------------- | ----------------------- | ----------------------------------------------------------------------------- |
| `signUpWithPassword`               | rate limited            | `SignUpForm`                                                                  |
| `signOutUser`                      | signed in               | `useSignOut`                                                                  |
| `changePassword`                   | signed in, rate limited | `PasswordCard`                                                                |
| `setPassword`                      | signed in, rate limited | `PasswordCard`                                                                |
| `changeEmail`                      | signed in, rate limited | `ChangeEmailForm`                                                             |
| `listAccounts`                     | signed in               | `PasswordCard`, `TwoFactorCard`, `ConnectedAccountsCard`, `DeleteAccountCard` |
| `unlinkAccount`                    | signed in, rate limited | `ConnectedAccountsCard`                                                       |
| `updateUser`                       | signed in               | not used by a screen                                                          |
| `sendChangeEmailConfirmationEmail` | Better Auth hook        | `user.changeEmail` in `auth.server.ts`                                        |

`sendChangeEmailConfirmationEmail` sends `ChangeEmailConfirmationEmail` to the current address with the confirmation link from Better Auth. `changePassword` always revokes the other sessions. `setPassword` adds a password to an account that signs in only with GitHub or Google, through Better Auth's server-only `setPassword`, revokes the other sessions and sends `PasswordChangedEmail`. `listAccounts` returns each sign-in method's row ID, provider and creation date, without tokens, and `unlinkAccount` passes a row ID to Better Auth's `unlinkAccount`, which refuses the last one.

## Deleting an account

Deleting removes the user, so its use cases live in the user module: `requestAccountDeletion` (signed in, rate limited) asks Better Auth's `deleteUser` to check the password and email a confirmation link, and `confirmAccountDeletion` (signed in, rate limited as a token) deletes the account with the link's token. `sendDeleteAccountEmail` (`src/modules/user/use-cases/send-delete-account-email.ts`) is the `sendDeleteAccountVerification` hook. See [Settings](/docs/features/settings#delete-account).

## Preferences

The time zone a user chooses in [Settings](/docs/features/settings) is a column of the `user` table, so its use case lives in the user module: `updatePreferences` (`src/modules/user/use-cases/update-preferences.ts`) requires a signed-in user, validates the input with `userZodSchemas.updatePreferences` and saves it through Better Auth's `updateUser`, the same path as the profile update above. `PreferencesCard` calls it on `/app/settings` and `/admin/settings`. The language is the locale in the URL and is not stored.

## Signing out

`useSignOut` (`src/hooks/use-sign-out.ts`) runs `signOutUserMutation`, removes the account's data from the query cache, navigates to `/auth/sign-in` and shows a toast. The admin user widget and the `/app` sidebar each render a `SignOutButton` that uses it.
