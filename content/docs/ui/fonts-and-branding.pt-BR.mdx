## Fontes

Geist e Geist Mono são auto-hospedadas em `public/fonts` como subconjuntos WOFF2 variáveis, servidas com cache imutável de um ano (`public/_headers`). `src/presentation/styles/fonts.css` declara um `@font-face` por faixa Unicode (latino, latino estendido, cirílico), fontes de fallback com métricas ajustadas e as variáveis `--font-geist-sans` e `--font-geist-mono`. `globals.css` as associa a `--font-sans`, `--font-heading` e `--font-mono`. O texto em japonês usa as fontes do sistema.

## Pré-carregamentos

`src/presentation/document-assets.ts` exporta `DOCUMENT_STYLESHEET` (`globals.css`) e os pré-carregamentos de fontes de um idioma:

```ts
export const fontPreloads = (locale: SupportedLocale) => {
  const fonts = [GEIST_LATIN, GEIST_MONO_LATIN]
  if (locale === "pl-PL") {
    fonts.push(GEIST_LATIN_EXT)
  } else if (locale === "uk-UA") {
    fonts.push(GEIST_CYRILLIC)
  }
  return fonts
}
```

A rota raiz os adiciona como tags `link`, e o Worker (`src/server.ts`) envia a folha de estilo e as mesmas fontes em um cabeçalho de pré-carregamento `Link` em toda resposta HTML. Os nomes dos arquivos de fonte são hashes do conteúdo: se você trocar uma fonte, atualize `fonts.css` e `document-assets.ts`.

## Constantes da marca

`src/presentation/branding/index.ts` é a única fonte da marca:

```ts
export const APP_NAME = "SaaSy Land"
export const APP_DOMAIN = "saasyland.com"

export const APP_URL = `https://${APP_DOMAIN}`
export const CONTACT_EMAIL = `hello@${APP_DOMAIN}`
export const NOTIFICATIONS_EMAIL = `notifications@${APP_DOMAIN}`

export const APP_FOUNDED_YEAR = 2023

export const APP_GITHUB_OWNER = "saasyland"
export const APP_GITHUB_REPO = APP_DOMAIN
export const APP_GITHUB_URL = `https://github.com/${APP_GITHUB_OWNER}/${APP_GITHUB_REPO}`
```

Elas alimentam o nome do aplicativo no Better Auth e o emissor da 2FA, os nomes dos cookies de tema e de idioma, os hosts permitidos, o rodapé, a navegação da documentação, o número de estrelas do GitHub, os dados estruturados do blog e os remetentes e destinatários dos e-mails.

## Logo e mídia

- `Wordmark` (`src/presentation/components/custom/wordmark.tsx`) renderiza o logo como SVG inline ao lado de `APP_NAME`.
- O favicon é `public/favicon.ico`; as imagens do blog ficam em `public/images/blog`.
- Os vídeos da landing page ficam em `src/presentation/assets/motion` como arquivos WebM com pôsteres WebP. Um pôster deve manter as dimensões do seu vídeo.
