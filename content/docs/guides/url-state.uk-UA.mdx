Визначте пошукову схему маршруту з `validateSearch`, читати його з `Route.useSearch`Навігація та оновлення за допомогою навігації TanStack Router. Зберігайте закладені фільтри, вкладки, сортування та піхви в URL при необхідності. Складно-тільки стан залишається в React.

Місцеві перезаписи URL застосовуються на рідні посилання маршрутизатора. Зареєструватися `localizePathname` для ручних сконструйованих URL-адрес, включаючи OAuth зворотний зв'язок і посилання на електронну пошту. Не препендуйте локалізацію на зовнішні посилання або API доріжки. Збереження запиту та фрагмента при переході мов.
