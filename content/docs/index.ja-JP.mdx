SaaSy Land は、saasyland.com の Web サイト、顧客ワークスペース、管理コンソールのソースコードです。D1、KV、Better Auth、Polar、Resend、use-intl、Fumadocs を利用し、Cloudflare Workers 上で動作する 1 つの TanStack Start アプリケーションとして構成されています。SaaSy Land CLI とそのジェネレーターテンプレートは、別の非公開リポジトリで管理されています。

<Callout title="このドキュメントの使い方">
  まずは **はじめに** でアプリケーションを起動してください。**アーキテクチャ** ではコードの配置場所を、**ガイド** では作業ごとの手順を、
  **機能** ではプロダクトの振る舞いを説明しています。**連携** では `src/integrations` 配下にある各ベンダーアダプターを解説しています。
</Callout>

## ドキュメントの編集

ページは `content/docs` に `<slug>.<locale>.mdx` として置かれ、9 つのロケールごとに 1 ファイルずつ存在します。各フォルダーは `meta.<locale>.json` でページを列挙します。すべてのロケールで同じスラッグを列挙し、コードブロックはバイト単位で同一に保ちます。これは `bun run check:i18n` が `scripts/check-content.ts` を通じて検証します。`bun run content` は `.source/` を再生成します。`dev` とすべてのビルドスクリプトがこれを自動で実行します。

MDX ページでは Fumadocs のコンポーネント（`<Cards>`、`<Callout>`、`<Steps>`、`<Tabs>`、`<Accordions>`）と、一部の shadcn プリミティブ（`<Button>`、`<Badge>`、`<Alert>`、`<Table>`）を使用できます。`/docs/tooling/testing` のような内部リンクには、読者のロケールのプレフィックスが自動的に付与されます。
