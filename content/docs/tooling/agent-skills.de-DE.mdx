---
title: "Agent-Skills"
description: "Skills der Anbieter für Coding-Agenten, wiederhergestellt aus skills-lock.json."
---

`skills-lock.json` fixiert die Agent-Skills, die mit diesem Repository verwendet werden. Die installierten Skills werden nicht eingecheckt: `.agents/` und `.claude/` werden von Git ignoriert.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` löscht `.agents/skills` und `.claude/skills`, installiert jeden fixierten Skill mit `bunx skills experimental_install` neu, verschiebt jeden Skill in eine Anbietergruppe unter `.agents/skills/<group>/<skill>/SKILL.md` und verlinkt jede Gruppe in `.claude/skills`. Das Skript schlägt fehl, wenn für eine Skill-Quelle keine Gruppenzuordnung existiert.

| Gruppe                                                | Quelle                                                               |
| ----------------------------------------------------- | -------------------------------------------------------------------- |
| `anthropic`                                           | `anthropics/skills`                                                  |
| `better-auth`                                         | `better-auth/skills`                                                 |
| `cloudflare`                                          | `cloudflare/skills`                                                  |
| `polar`                                               | `polarsource/skills`                                                 |
| `resend`                                              | `resend/resend-skills`                                               |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) und `TanStack/table` (`table`) |
| `remotion`                                            | `remotion-dev/skills`                                                |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Allgemeine Skills für Engineering, Design und Marketing              |

Die Synchronisierung ersetzt beide Verzeichnisse; bewahren Sie eigene Skills daher an anderer Stelle auf. `bun run clean:hardcore` löscht `skills-lock.json`.

## Regel

Bevor Sie Code ändern, der TanStack Start, Router oder Table, Better Auth, Cloudflare, Polar oder Resend betrifft, lesen Sie den passenden Skill. Skills beschreiben die aktuellen APIs der Anbieter; die Konventionen dieses Repositorys sind unter [Architektur](/docs/architecture) und [Konventionen](/docs/reference/conventions) dokumentiert.
