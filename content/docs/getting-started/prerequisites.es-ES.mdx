## Herramientas

| Herramienta | Versión                                           | Motivo                                                                                            |
| ----------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Bun         | <RepositoryFact name="bunVersion" />              | Gestor de paquetes y ejecutor de scripts; lo fijan `packageManager` en `package.json` y la CI     |
| Node.js     | <RepositoryFact name="nodeVersion" /> o posterior | La versión de `.nvmrc`, que leen `nvm use` y la CI. La base de datos de pruebas usa `node:sqlite` |
| Git         | Cualquier versión reciente                        | El paso de instalación configura los hooks de Git                                                 |

Wrangler, drizzle-kit, Playwright y la CLI de Vite+ son dependencias de desarrollo; ejecútalos mediante los scripts del paquete o con `bunx`. Las pruebas en el navegador también necesitan los navegadores de Playwright que instala `bun run test:e2e:install`.

## Cuentas

La preview de pruebas aislada y todas las pruebas automatizadas no necesitan cuentas ni credenciales. El desarrollo y el despliegue usan servicios reales:

- Una cuenta de Cloudflare con D1, KV, R2 y Workers para los despliegues de preview y producción. El servidor de desarrollo usa recursos locales y no necesita cuenta.
- Aplicaciones OAuth de GitHub y Google para el inicio de sesión social.
- Resend con un remitente verificado. Una cuenta nueva por correo electrónico inicia sesión al momento, pero sin Resend no llega ningún enlace de confirmación, así que la clave de licencia, el portal de clientes, las lecciones de pago y volver a iniciar sesión siguen bloqueados.
- Polar, con el entorno sandbox para desarrollo, con tres productos para los niveles Core, Complete y Agency.
