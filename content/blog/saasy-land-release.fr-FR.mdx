## Qu'est-ce que SaaSy Land ?

SaaSy Land est un kit de démarrage SaaS React commercial. Sa CLI n'écrit que les modules correspondant à vos réponses : authentification sur votre propre base de données, e-mails transactionnels, console d'administration et internationalisation dès aujourd'hui, et facturation une fois ses modèles arrivés. La CLI active votre clé de licence sur vos appareils (`activate`, `whoami`, `deactivate`), et `init` écrit le projet à partir des options que vous pouvez choisir dans le [configurateur](/#cli), qui signale les options encore à venir. Le code qu'elle écrit provient du code source de ce site, où <RepositoryFact name="testFiles" /> fichiers de tests et un seuil de couverture le vérifient déjà, de sorte que ce que vous recevez est vérifié, et pas seulement présent.

Le code source du site web public est sous licence MIT ; la CLI et les modèles privés, distincts, sont propriétaires. Tout le monde peut installer la CLI depuis npm ; achetez une licence, connectez-vous sur saasyland.com et obtenez la clé nécessaire pour l'utiliser. La validation de licence en ligne s'applique à la CLI. Les applications générées peuvent être modifiées et déployées sous la licence commerciale et ne nécessitent aucune clé à l'exécution. La licence du site web n'accorde aucun droit sur la marque SaaSy Land.

### Pourquoi le seuil de couverture compte davantage aujourd'hui qu'au lancement

À la sortie de la 2.0, le chiffre de couverture était un argument de qualité. C'est depuis devenu un argument de débit, car une grande partie du code ajouté aux bases de code SaaS est désormais écrite par un agent.

Dans l'[enquête Stack Overflow 2025 auprès des développeurs](https://survey.stackoverflow.co/2025/ai), 84 % des développeurs déclaraient utiliser ou prévoir d'utiliser des outils d'IA, tandis que la frustration la plus citée, mentionnée par 66 % d'entre eux, était une production d'IA « presque juste, mais pas tout à fait ». Dans l'[enquête 2026](https://survey.stackoverflow.co/2026/ai), 48 % déclaraient faire confiance à l'IA quand ils peuvent facilement en valider les réponses. Un seuil qui bloque la fusion est la réponse la moins coûteuse aux deux : un agent ne peut pas ajouter de comportement sans ajouter de test, et tout ce qu'il casse apparaît dans la pull request plutôt que chez un client.

Nous l'avons expliqué en détail dans [pourquoi votre dépôt détermine la qualité du travail de l'agent](/blog/ai-coding-agents-repository-readiness) et dans [comment choisir une stack pour les agents de programmation IA](/blog/choosing-a-saas-stack-for-ai-coding-agents). En bref, ce dépôt se classe « Prêt pour les agents » sur notre propre grille d'évaluation de préparation, par construction plutôt qu'à force d'efforts.

## À qui ce produit ne s'adresse pas

Si vous voulez quelque chose de gratuit pour apprendre, clonez un modèle et faites-vous plaisir. Si vous préférez qu'un fournisseur hébergé gère votre authentification et vous facture ce privilège par utilisateur actif mensuel, achetez plutôt cela.

Ce produit s'adresse à celles et ceux qui comptent bien rester maîtres de leurs marges à cinquante mille utilisateurs, et qui préfèrent découvrir les problèmes dans la pull request plutôt qu'en production.
