---

Define a route’s search schema with `validateSearch`, read it with `Route.useSearch`, and update it through TanStack Router navigation. Keep bookmarkable filters, tabs, sorting and pagination in the URL when appropriate. Component-only state stays in React.

Locale URL rewrites apply to native Router links. Use `localizePathname` for manually constructed URLs, including OAuth callbacks and email links. Do not prepend a locale to external links or API paths. Preserve the query and fragment when switching languages.
