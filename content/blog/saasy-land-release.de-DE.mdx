## Was ist SaaSy Land?

SaaSy Land ist ein kommerzielles Starter-Kit für SaaS-Anwendungen, basierend auf Next.js. Eine Kommandozeilenanwendung (CLI) stellt fünf Fragen und erstellt ausschließlich die Module, die Sie in Ihren Antworten angegeben haben: Authentifizierung für Ihre eigene Datenbank, Abrechnung, Transaktions-E-Mails, ein Administrationsbereich, Internationalisierung und ein visueller Seitendesigner. Es wird mit 141 Testdateien ausgeliefert, und ein Coverage-Check ist bereits implementiert, um diese zu überprüfen. Der Code, den Sie erhalten, ist somit verifiziert und nicht nur vorhanden.

Der Code ist unter der MIT-Lizenz veröffentlicht und öffentlich zugänglich, sodass Sie ihn einsehen können, bevor Sie eine Entscheidung treffen. Sie zahlen einmalig für die Befehlszeilenschnittstelle, die Vorlagen und lebenslange Updates des Kernsystems. Es gibt keine Laufzeitprüfung, keine Anbindung an Drittanbieter und kein Abonnement.

## Wählen Sie Ihre Umgebung und führen Sie einen Befehl.

Die CLI ist kein Template, das man herunterlädt und dann damit kämpft. Sie fragt, was man erstellen möchte, und generiert genau das. Das gleiche Tool kann daher sowohl ein Single-Tenant-Projekt für den privaten Gebrauch als auch ein Multi-Tenant-Produkt mit einem Zahlungsanbieter erstellen.

```bash
bunx saasyland@latest init my-app \
  --framework tanstack \
  --tenancy multi \
  --billing polar \
  --content mdx \
  --email resend
```

Fünf Fragen, wobei die verwendeten Symbole bewusst unspektakulär sind, damit der Befehl problemlos in ein Skript eingefügt werden kann, anstatt in eine direkte Eingabeaufforderung.

| Frage.             | Optionen.                                         | Warum es eine Frage ist.                                                                                                                                                                             |
| ------------------ | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Framework          | `next`, `tanstack`                                | Beide Optionen werden unterstützt; wählen Sie die, mit der Ihr Team bereits vertraut ist.                                                                                                            |
| Mandantenfähigkeit | `multi`, `single`                                 | Die nachträgliche Anpassung von Organisationen kann später jede Frage betreffen, die Sie gestellt haben.                                                                                             |
| Abrechnung         | `stripe`, `polar`, `lemonsqueezy`, `--no-billing` | Polar und Lemon Squeezy sind ordentliche Händler und übernehmen für Sie die EU-Umsatzsteuer sowie die US-Verkaufssteuer. Dies gilt nicht für Stripe. Diese Entscheidung trifft der Gründer einmalig. |
| Inhalt             | `mdx`, `--no-content`                             | Ein Blog und eine Dokumentation, oder auch nichts.                                                                                                                                                   |
| E-Mail             | `resend`, `--no-email`                            | Transaktions-E-Mails, die in die Authentifizierungsabläufe integriert sind, oder eben keine.                                                                                                         |

Ändern Sie eine Antwort, und der Befehl ändert sich entsprechend. Führen Sie es erneut für das nächste Projekt aus: Die Antworten ändern sich, die Befehlszeilenschnittstelle und die lebenslangen Updates jedoch nicht.

### Warum die Berichterstattung um diesen Fall heute wichtiger ist als zum Zeitpunkt der Veröffentlichung.

Mit der Veröffentlichung von Version 2.0 war die Abdeckung ein Qualitätsmerkmal. Mittlerweile ist sie zu einem Argument für die Leistung geworden, da ein großer Teil des Codes, der nun zu SaaS-Architekturen hinzugefügt wird, von einem Agenten erstellt wird.

In der [2025 Stack Overflow Developer Survey](https://survey.stackoverflow.co/2025/ai) gaben 84 % der Entwickler an, KI-Tools zu verwenden oder die Verwendung zu planen. Die am häufigsten genannte Herausforderung, von 45 % der Befragten genannt, war KI-Ausgabe, die „fast richtig, aber nicht ganz“ ist. Ein Fehler, der zu einem Build-Fehler führt, ist die günstigste verfügbare Lösung: Ein Agent kann kein Verhalten hinzufügen, ohne gleichzeitig einen Test hinzuzufügen, und alle Probleme, die dadurch entstehen, werden erst im Pull Request und nicht beim Kunden entdeckt.

Wir haben dies ausführlich in [warum unser Repository die Qualität der Agentenausgaben bewertet](/blog/ai-coding-agents-repository-readiness) und in [wie man den richtigen Stack für KI-Coding-Agenten auswählt](/blog/choosing-a-saas-stack-for-ai-coding-agents) beschrieben. Kurz gesagt: Dieses Repository erzielt 20 von 20 Punkten auf unserer eigenen Bewertungsskala, und das nicht durch Anstrengung, sondern aufgrund seiner Konzeption.

## Überprüfen Sie jede Aussage, bevor Sie bezahlen.

Es gibt keine Erfahrungsberichte, da es in einem Preisangebot nichts zu überprüfen gibt. Jede Zahl auf dieser Seite wird vom Repository generiert, das Sie erwerben würden, und hier finden Sie es.

| Aussage                                 | Wo kann man das überprüfen?                                                              |
| --------------------------------------- | ---------------------------------------------------------------------------------------- |
| 100-prozentige Testabdeckung            | `coverage/coverage-summary.json`, generiert durch `bun run test:coverage`.               |
| Verbindlich geprüft, nicht nur gemeldet | `.github/workflows/ci.yml`, bei jedem Pull Request und jedem Push auf den Branch "main". |
| Echte Browser, kein jsdom               | `e2e/specs`, 5 Playwright-Testsuiten für Chromium und WebKit.                            |

## Für wen dies nicht geeignet ist

Wenn Sie etwas Kostenloses zum Lernen suchen, können Sie eine Vorlage klonen und diese nutzen. Wenn Sie es vorziehen, dass ein externer Anbieter Ihre Authentifizierung verwaltet und Sie dafür pro monatlich aktivem Nutzer eine Gebühr zahlen, erwerben Sie stattdessen dieses Angebot.

Dies ist für diejenigen, die beabsichtigen, ihre Gewinnspannen auch bei fünfzigtausend Nutzern zu behalten, und die es vorzugsweise durch die Überprüfung von Pull Requests und nicht erst in der Produktionsumgebung herausfinden möchten.

Das "Agency"-Paket zum Preis von 899 € beinhaltet eine unbegrenzte kommerzielle Client-Lizenz, sodass Sie es an beliebig viele Kunden senden können, die Sie fakturieren. Die "Codebase"- und "Masterclass"-Pakete decken Ihre eigenen Produkte ab. Alle drei Optionen sind einmalige Zahlungen, die lebenslange Updates der Kernfunktionen beinhalten.

<Accordion title={"Muss ich wirklich jeden Teil davon verwenden?"}>

Nein. Die Befehlszeilenschnittstelle (CLI) stellt fünf Fragen und schreibt lediglich die von Ihnen eingegebenen Antworten. Daher können Sie die Abrechnung, Inhalte und E-Mail-Funktionen jeweils überspringen, indem Sie die Flags `--no-billing`, `--no-content` oder `--no-email` verwenden. Sieben Module werden immer geschrieben, während drei Module nur dann geschrieben werden, wenn Sie diese explizit angefordert haben.

</Accordion>

Es wird funktionieren, und das Ergebnis wird korrekt sein. Was es Ihnen jedoch nicht mitteilen wird, ist, welche Autorisierungsfälle es übersprungen hat, welcher Webhook nicht idempotent ist oder dass eine Paritätsprüfung der Übersetzungen, die es nie durchgeführt hat, die fehlenden Schlüssel hätte erkennen können. Die Qualität der Ergebnisse eines Agenten hängt lediglich von den Prüfungen ab, die sie überprüft haben, und in einem leeren Repository gibt es keine solchen Prüfungen.
