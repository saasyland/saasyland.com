## データ

`src/modules/category/category.schema.ts` は `category` テーブルを定義します。列は `name`、`description`、`kind`（`category` または `collection`）、`visibility`（`public` または `hidden`）、`icon`（`Archive`、`FolderOpen`、`Puzzle`）、タイムスタンプです。

`src/modules/category/use-cases` のユースケースは、それぞれ対応する `category` 権限で保護されています。`getCategories`（ページ分割、`kind` は任意）、`getCategory`、`createCategory`、`updateCategory`、`deleteCategory` です。`createCategory` は更新系ユースケースの基準となる構成です。

```ts
export const createCategory = createServerFn({ method: "POST" })
  .middleware([authorized({ category: ["create"] })])
  .validator((input: Category["createCategory"]) => categoryZodSchemas.createCategory.parse(input))
  .handler(({ data }) =>
    db
      .insert(category)
      .values({
        description: data.description ?? "",
        icon: data.icon ?? CATEGORY_ICON.FOLDER_OPEN,
        id: v7(),
        kind: data.kind,
        name: data.name,
        visibility: data.visibility ?? CATEGORY_VISIBILITY.PUBLIC,
      })
      .returning()
      .get(),
  )

export const createCategoryMutation = mutationOptions({
  mutationFn: (data: Category["createCategory"]) => createCategory({ data }),
  mutationKey: CATEGORY_MUTATION_KEYS.CREATE,
})
```

エラーメッセージは `category.errors` 名前空間にあります。カテゴリを編集するフォームはまだないため、Zod のメッセージはそれを表示する最初のフォームとともに `category.validations` 名前空間を持ちます。

## 管理画面

`/admin/products` の **カテゴリー** と **コレクション** タブは、`useCategoryColumns` を使った `DataGrid` である `CategoryGrid` を、タブの `kind` を渡した `getCategoriesPageQuery` で表示します。サーバーは名前と説明を検索し、名前、公開状態、作成日と更新日で絞り込み、各列で並べ替えます。接続されているのは一覧だけで、カテゴリーを作成、編集、削除する画面はありません。商品にはまだカテゴリーとの関連がないため、テーブルには項目数が表示されません。
