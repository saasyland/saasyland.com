- 修正: なりすまし中の顧客のセッション読み取り（メール確認のチェックなど）がまだ処理中のときになりすましを終了しても、管理者がサインアウトされなくなりました。なりすましの開始と終了は、セッションが切り替わる前に取得中のクエリがなくなるまで待つようになりました。[なりすまし](/docs/features/impersonation)を参照してください。
- 変更: 顧客とサインアウトした訪問者がユーザー管理のすべてのサーバー関数で拒否されることを確かめるブラウザテストは、Better Auth の管理 API でアカウントを作成し、検査用アカウントをブラウザなしでサインインさせるようになったため、WebKit でテストのタイムアウトに達しなくなりました。セッションの読み取りが処理中のままなりすましを終了する新しいブラウザテストを追加しました。[テスト](/docs/conventions/testing)を参照してください。
