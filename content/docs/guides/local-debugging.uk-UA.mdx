---
title: Місцевий розвиток
description: Місцевий розвиток — SaaSy Land
---

Встановити Bun 1.4 і Node 24 або новіший, потім встановити залежності. Зареєструватися `.env.example` до `.env.development` і настроювання довгої випадковості `AUTH_SECRET`громадськість `VITE_APP_URL`, і будь-які зовнішні інтеграції, які ви будете здійснювати.

Місцевий розвиток використовує Cloudflare’ локальний D1 і KV обов'язки. Застосувати зареєстровані SQLite Міграції перед початком. Команда розвитку генерує Fumadocs зміст і ходи Vite+ з Cloudflare плагін. Місцеве державне життя під `.wrangler/`.

OAuth, електронна пошта та вексельна обробка вимагає облікових даних провайдера; використовувати тестові облікові дані та Polar пісочниця при розробці. Тести використовують химерні значення і мокс замість відправки реальних повідомлень або зарядки замовника.

```sh
bun install
cp .env.example .env.development
bun run db:migrate:development
bun run dev
```
