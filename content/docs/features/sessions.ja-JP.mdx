セッションは D1 の `session` テーブル（`src/modules/session/session.schema.ts`）に保存されます。`auth.session.ts` はリクエスト単位でメモ化される `getRequestSession` で読み取り、ルートとコンポーネントに `getCurrentSessionQuery` を提供します。クライアント側のコピーにセッショントークンが含まれることはありません。

## ユースケース

| ユースケース                              | ミドルウェア                         | 利用箇所           |
| ----------------------------------------- | ------------------------------------ | ------------------ |
| `getActiveSessions`                       | サインイン必須                       | `SettingsSessions` |
| `revokeSession`                           | サインイン必須、自分のセッションのみ | `SessionRow`       |
| `revokeOtherSessions`                     | サインイン必須                       | `SettingsSessions` |
| `listUserSessions`                        | `session: ["list"]`                  | `UserSessions`     |
| `revokeUserSession`、`revokeUserSessions` | `session: ["revoke"]`                | `UserSessions`     |

`getActiveSessions` は現在のユーザーの有効期限内のセッションを新しい順に返し、なりすましセッションは除外します。`listUserSessions` は Better Auth の `listUserSessions` を使って、別のユーザーの有効期限内のセッションを新しい順に、トークンを除いて返します。なりすましセッションも含まれます。`revokeUserSession` はセッション ID を受け取り、サーバー側でそのトークンを調べるため、トークンがブラウザーに届くことはありません。

## UI

`/admin/settings` の **設定 → セキュリティ** は `SettingsSessions`（`src/presentation/components/custom/admin/settings/sessions.tsx`）を表示します。各 `SessionRow` はデバイス（ユーザーエージェントまたは IP アドレス）、最終アクティビティ、現在のセッションを示すバッジを表示し、そのセッションを失効できます。ヘッダーのボタンで他のすべてのセッションを失効できます。パスワードを変更したときもセッション一覧が更新されます。

`/admin/users` のユーザーのプロフィールは `UserSessions`（`src/presentation/components/custom/admin/users/user-sessions.tsx`）を表示します。各セッションのデバイス、サインインした日時と最後にアクティブだった日時、そのセッションを失効させるボタン、そして確認のうえでユーザーをすべての場所からサインアウトさせるボタンがあります。[ユーザー（管理）](/docs/features/users-admin)を参照してください。
