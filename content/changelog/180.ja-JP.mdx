- CLI ライセンス API: Worker が、`saasyland init` がプロジェクトの生成に必要とする各リリースのテンプレートバンドルを配信するようになりました。`POST /api/cli/v1/activations/:activationId/bundles` は、ライセンスと、アクティベーションが呼び出し元の端末のものであることを確認してから、ライセンスのエリアの新しい `BUNDLES` R2 バケットにあるリリースのアーカイブへの HTTPS URL、アーカイブの JSON の内容の SHA-256（CLI がリリースごとに固定するダイジェスト）、アーカイブのサイズ、発行から `API_LIMIT.BUNDLE_URL_TTL_SECONDS` 後となる URL の有効期限を返します。アーカイブのないリリースには `versionNotFound` を、読み取れないバケットには `serviceUnavailable` を返します。ライセンスのエリアの Worker ハンドラーは、有効期限と HMAC が正しいことを確かめたうえで `/bundles/<expiry>.<signature>/<version>.json.gz` を R2 から配信します。鍵は HKDF が `AUTH_SECRET` からバンドル専用に導出するため、S3 の認証情報は必要ありません。動画の再生が使っていた鍵の導出は、両者が共有する `src/lib/hmac.ts` に移りました。CLI のリポジトリのリリースが各アーカイブをプレビューと本番のバケットにアップロードし、[バンドルの公開](/docs/features/cli-licence-api#publishing-bundles)にキー、コンテンツタイプ、バケットが記載されています。プライバシーポリシーには、バンドルのリクエストがリリースとスタックの回答を送信し、API はそれらを保存しないことを記載しました。
