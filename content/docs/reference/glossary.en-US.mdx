- **Route:** a native TanStack file route with a component, guard, loader or HTTP handler.
- **Server function:** a typed RPC operation created with `createServerFn`.
- **Query:** cached read data with a stable key, shared between the loader and React.
- **Mutation:** an operation submitted through TanStack Query and backed by a server function.
- **Namespace:** a dotted translation file under a locale directory.
- **Binding:** a Cloudflare resource supplied to the Worker as `env.DB`, `env.CACHE` or `env.ASSETS`.
- **Prerender:** build-time HTML for a public route.
