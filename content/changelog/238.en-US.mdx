- Fixed: a page opened before a deploy no longer shows "Something went wrong" when a visitor clicks a link whose code the deploy replaced, such as **Blog**. TanStack Start puts each route's loader in a chunk of its own, and a loader whose chunk was gone failed the route without the reload TanStack Router gives a missing component. The router's default error component now recognises a chunk the browser could not import, or a file Vite could not preload for it, and loads the page the visitor clicked as a new page, from the new deploy. It does this once for each page and build, so a file that is really missing shows the error page instead of reloading forever, and a link that failed to preload on hover still reloads when it is clicked. See [Routes and delivery](/docs/architecture/delivery-layer#after-a-deploy).
