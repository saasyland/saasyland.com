La CLI `saasyland`, `create-saasyland` et `@saasyland/stack` sont publiés ensemble sous un même numéro de version, et chaque préversion ci-dessous a été publiée sur le tag `beta` de npm. Le [guide de la CLI](/docs/cli) décrit la version actuelle, et le [journal des modifications](/docs/project/changelog) liste les changements de ce site.

## 0.1.0-beta.1

### saasyland

- `saasyland activate` active votre clé de licence sur cet appareil : passez la clé en argument ou dans <RepositoryFact name="cliLicenseKeyVariable" />, ou saisissez-la quand elle est demandée, masquée pendant la saisie. `saasyland whoami` affiche votre offre, les activations utilisées et le nom de cet appareil, et `saasyland deactivate` libère l’activation de cet appareil.
- La licence est conservée dans un fichier de votre répertoire de configuration que seul votre utilisateur peut lire, toutes les exécutions d’un même dépôt de CI partagent une activation, et une licence remboursée ou révoquée est supprimée de l’appareil.
- Les trois commandes affichent leur résultat sous la forme d’un seul document JSON avec `--json` et n’acceptent plus `--cwd` ni `--dry-run`, qui ne s’y sont jamais appliqués.

### create-saasyland

Aucun changement dans cette version.

### @saasyland/stack

- `@saasyland/stack/api` limite une version de la CLI et une release à `API_LIMIT.VERSION_MAX_LENGTH` caractères, si bien que l’API de licence répond à une valeur plus longue par `invalidRequest`, comme pour tout autre champ mal formé.

## 0.1.0-beta.0

### saasyland

- Première préversion de la CLI `saasyland`. `saasyland --help` liste toutes les commandes, et `saasyland init --help` liste chaque choix de stack sous forme d’option.
- Les options sont vérifiées avant toute exécution : une valeur inconnue ou une combinaison qui ne peut pas fonctionner, comme `--provider neon` sans `--db postgres`, est refusée avec la raison et le code de sortie <RepositoryFact name="cliExitUsage" />.
- La sortie est disponible en anglais, allemand, espagnol, français, italien, japonais, polonais, portugais du Brésil et ukrainien, selon `--locale` ou la langue de votre système, et `--json` affiche un seul document JSON pour les scripts et les agents de code.
- La génération d’un projet et l’activation d’une licence arrivent dans les préversions suivantes ; d’ici là, ces commandes le signalent et se terminent avec le code <RepositoryFact name="cliExitNotAvailable" />.

### create-saasyland

- Première préversion de `create-saasyland` : `npm create saasyland`, `bun create saasyland`, `pnpm create saasyland` et `yarn create saasyland` lancent `saasyland init` avec les mêmes options.

### @saasyland/stack

- Nouveau point d’entrée : `@saasyland/stack/api`, le contrat de l’API de licence de saasyland.com qu’appelle la CLI `saasyland`. Il définit les routes de <RepositoryFact name="cliApiBasePath" />, les en-têtes, les schémas des requêtes et des réponses, les codes d’erreur et les limites, et construit et lit chaque requête et chaque réponse. Importer `@saasyland/stack` seul n’en charge rien.
