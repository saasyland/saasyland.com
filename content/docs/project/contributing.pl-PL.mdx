> Pełna treść jest utrzymywana po angielsku i może być uzupełniana sukcesywnie. Poniżej znajduje się lokalna wersja / mapa tej strony.

1. Omów duże zmiany w zgłoszeniu
2. Odbij gałąź od głównej linii
3. Trzymaj się konwencji i umiejętności
4. `bun run check` · testy · build
5. Otwórz PR z tytułem `feat`/`fix`/`docs`

Dodając moduły lub ścieżki, aktualizuj odpowiednie strony dokumentacji.
