---

SaaSy Land es una única aplicación TanStack Start que se ejecuta como un Cloudflare Worker. El código se divide por responsabilidades:

- Las **rutas** (`src/routes`) componen páginas. Un archivo de ruta declara sus namespaces de traducción, su guard, su loader y sus etiquetas del head, y después renderiza componentes.
- Los **módulos** (`src/modules/<table>`) existen solo para tablas reales de la base de datos. Un módulo contiene el esquema Drizzle de su tabla, los esquemas Zod, las constantes, los tipos y los casos de uso que la leen o la modifican.
- Las **integraciones** (`src/integrations/<vendor>`) configuran librerías y servicios de terceros.
- La **presentación** (`src/presentation`) reúne las primitivas de shadcn, los componentes de la aplicación, las plantillas de React Email, los estilos, el tema y la marca.
- El **código compartido** vive en `src/data` (datos que usan varios archivos), `src/lib` (utilidades pequeñas), `src/hooks` y `src/providers`.

```text
src/
├── routes/          Flat file routes that compose pages
├── modules/         One folder per database table, plus _core
├── integrations/    One folder per vendor
├── presentation/    Components, emails, styles, theme, branding
├── data/            Data shared by several files
├── lib/             Small shared utilities
├── hooks/           Shared React hooks
├── providers/       Application providers
├── platform/        Test runtime wiring
├── types/           Global type declarations
├── router.tsx       Router and per-request QueryClient
├── routes.ts        ROUTES path constants
└── server.ts        Cloudflare Worker entry
```

## Reglas que dan forma al código

- Los archivos de ruta solo componen. Los widgets, diálogos, formularios y columnas de tabla viven en `src/presentation/components/custom`, uno por archivo.
- Los componentes leen sus propias traducciones y datos con `useTranslations`, `useSuspenseQuery` o los datos del loader de la ruta. Las rutas no pasan etiquetas ni datos hacia abajo como props.
- Una función de servidor que trabaja sobre una tabla es un caso de uso del módulo de esa tabla. Una función de servidor que usa una sola ruta puede definirse en el propio archivo de ruta. Todo lo demás va en `src/lib`.
- No hay contenedor de inyección de dependencias ni capa de wrappers. Importa la función concreta desde la carpeta a la que pertenece.
- Una constante que usa un solo archivo se queda en ese archivo. Solo los datos que comparten varios archivos pasan a `src/data`.
