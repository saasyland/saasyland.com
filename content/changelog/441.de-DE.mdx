- Behoben: `bun run check:features` bereinigt die Skripte der `package.json` mit derselben Regel wie den Code: Ein Schritt, der eine gelöschte Datei oder ein wegfallendes Skript aufruft, wird entfernt, ebenso ein Skript ohne verbleibende Schritte, sodass eine Website ohne die Inhalte kein `check:content` mehr behält, das auf eine gelöschte Datei zeigt. Jedes Szenario scheitert außerdem, wenn ein Skript noch eine gelöschte Datei nennt oder ein weggefallenes Skript aufruft. Siehe [Testen](/docs/conventions/testing#tests-follow-the-features).
- Behoben: Die Anzahl der GitHub-Sterne im Test-Build veraltet nie, weil dessen GitHub-API ein Test-Double mit fester Anzahl ist; eine Browser-Testsuite, die lange nach `build:test` startet, ruft die Anzahl deshalb nicht erneut ab und lässt die Tests zum Datensparmodus und zu angehaltenen Serverfunktionen nicht mehr scheitern. Siehe [Cloudflare KV](/docs/integrations/cloudflare-kv).
