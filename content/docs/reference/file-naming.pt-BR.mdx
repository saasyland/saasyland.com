| Padrão         | Significando...                                |
| -------------- | ---------------------------------------------- |
| `_components/` | Rota-local React Componentes                   |
| `_lib/`        | Ajudantes locais, params de busca, mapeadores. |
| `_types/`      | Tipos de rotas locais                          |
| `use-cases/`   | Serviços de aplicação de módulos               |
| `*.server.ts`  | Entrada de integração só para servidores.      |
| `__test__/`    | Testes Colocados.                              |

Preferir nomes explícitos (`search-params.ts`) sobre vago `utils.ts` Pombas.
