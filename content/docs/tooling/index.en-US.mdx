The repository uses Bun as package manager and script runner and Vite+ (`vp`) for the dev server, builds, tests, linting and formatting. Wrangler manages Cloudflare environments and migrations, and Playwright runs browser tests.

## In this chapter

- [Environment and bindings](/docs/tooling/environment): Wrangler environments, secrets and environment files
- [Database migrations](/docs/tooling/database): generate, apply and inspect D1 migrations
- [Testing](/docs/tooling/testing): Vitest projects, helpers and the 100% coverage gate
- [Lint and format](/docs/tooling/lint-format): oxlint, oxfmt and the check scripts
- [Vite+](/docs/tooling/vite-plus): the `vp` toolchain and plugins
- [Playwright](/docs/tooling/playwright): browser tests against the isolated test Worker
- [Agent skills](/docs/tooling/agent-skills): vendor skills for coding agents
- [CI/CD](/docs/tooling/ci-cd): GitHub Actions checks and deployments
- [Project scripts](/docs/tooling/scripts): every `package.json` script
- [Graphify](/docs/tooling/graphify): an optional knowledge graph of the codebase
- [Conventional commits](/docs/tooling/conventional-commits): commit format and the emoji hook
