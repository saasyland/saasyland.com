title: "Introduction"
description: "Vendor adapters under src/integrations."
---

Each folder in `src/integrations/<vendor>/` wraps one vendor in `<vendor>.<concern>.ts` files: configuration, clients and thin adapters. Business rules and database operations stay in `src/modules`, and components never import a vendor client directly.

| Folder          | Files                                                                                                           | Purpose                                                          |
| --------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `better-auth`   | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.session.ts` | Sessions, OAuth, route guards, server-function middleware, roles |
| `drizzle-orm`   | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `migrations/`                                 | D1 client, schema barrel, drizzle-kit configuration              |
| `fumadocs`      | `fumadocs.config.ts`, `fumadocs.i18n.ts`, `fumadocs.source.ts`, `fumadocs.docs.ts`, `fumadocs.search.ts`        | Docs and blog collections, localized sources, search             |
| `motion`        | `motion.features.ts`, `motion.tokens.ts`                                                                        | Lazily loaded Motion features and shared transitions             |
| `polar`         | `polar.config.ts`, `polar.constants.ts`                                                                         | Polar SDK client and checkout products                           |
| `resend`        | `resend.config.ts`, `resend.utils.ts`                                                                           | Resend client and `sendEmail`                                    |
| `tanstack-form` | `form.fields.ts`                                                                                                | `fieldErrorMessage` for form field errors                        |
| `use-intl`      | `i18n.config.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                    | Locales, message namespaces, locale middleware, URL helpers      |
