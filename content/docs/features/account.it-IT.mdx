`src/modules/account` possiede la tabella `account` di Better Auth (`account.schema.ts`): una riga per ogni credenziale o provider OAuth collegato a un utente. I token OAuth al suo interno sono cifrati.

## Casi d’uso

| Caso d’uso                         | Middleware            | Usato da                                                                      |
| ---------------------------------- | --------------------- | ----------------------------------------------------------------------------- |
| `signUpWithPassword`               | limitato              | `SignUpForm`                                                                  |
| `signOutUser`                      | autenticato           | `useSignOut`                                                                  |
| `changePassword`                   | autenticato, limitato | `PasswordCard`                                                                |
| `setPassword`                      | autenticato, limitato | `PasswordCard`                                                                |
| `changeEmail`                      | autenticato, limitato | `ChangeEmailForm`                                                             |
| `listAccounts`                     | autenticato           | `PasswordCard`, `TwoFactorCard`, `ConnectedAccountsCard`, `DeleteAccountCard` |
| `unlinkAccount`                    | autenticato, limitato | `ConnectedAccountsCard`                                                       |
| `updateUser`                       | autenticato           | nessuna schermata                                                             |
| `sendChangeEmailConfirmationEmail` | hook di Better Auth   | `user.changeEmail` in `auth.server.ts`                                        |

`sendChangeEmailConfirmationEmail` invia `ChangeEmailConfirmationEmail` all’indirizzo attuale con il link di conferma fornito da Better Auth. `changePassword` revoca sempre le altre sessioni. `setPassword` aggiunge una password a un account che accede solo con GitHub o Google, tramite il `setPassword` di Better Auth riservato al server, revoca le altre sessioni e invia `PasswordChangedEmail`. `listAccounts` restituisce per ogni metodo di accesso l’ID della riga, il provider e la data di creazione, senza token, e `unlinkAccount` passa l’ID di una riga a `unlinkAccount` di Better Auth, che si rifiuta di scollegare l’ultimo.

## Eliminare un account

L’eliminazione rimuove l’utente, quindi i suoi casi d’uso si trovano nel modulo utente: `requestAccountDeletion` (autenticato, limitato) chiede a `deleteUser` di Better Auth di verificare la password e di inviare via email un link di conferma, e `confirmAccountDeletion` (autenticato, limitato come un token) elimina l’account con il token del link. `sendDeleteAccountEmail` (`src/modules/user/use-cases/send-delete-account-email.ts`) è l’hook `sendDeleteAccountVerification`. Vedi [Impostazioni](/docs/features/settings#delete-account).

## Preferenze

Il fuso orario che un utente sceglie in [Impostazioni](/docs/features/settings) è una colonna della tabella `user`, quindi il suo caso d’uso si trova nel modulo utente: `updatePreferences` (`src/modules/user/use-cases/update-preferences.ts`) richiede un utente autenticato, convalida l’input con `userZodSchemas.updatePreferences` e lo salva tramite `updateUser` di Better Auth, lo stesso percorso dell’aggiornamento del profilo descritto sopra. `PreferencesCard` lo chiama su `/app/settings` e `/admin/settings`. La lingua è il locale nell’URL e non viene salvata.

## Disconnessione

`useSignOut` (`src/hooks/use-sign-out.ts`) esegue `signOutUserMutation`, rimuove dalla cache delle query i dati dell’account, naviga verso `/auth/sign-in` e mostra una notifica. Il widget utente dell’amministrazione e la barra laterale di `/app` mostrano ciascuno un `SignOutButton` che lo usa.
