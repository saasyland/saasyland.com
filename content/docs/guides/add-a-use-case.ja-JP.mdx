description: "1 つの操作を追加します。サーバー関数と、そのクエリオプションまたはミューテーションオプション、キャッシュの無効化、エラー処理です。"
---

ユースケースは、1 つのテーブルに対する 1 つの操作です。`src/modules/<table>/use-cases/<operation>.ts` に置き、サーバー関数と、コンポーネントが使うオプションを一緒にエクスポートします。構成要素については [サーバー関数](/docs/guides/server-functions) で説明しています。

## ミューテーションを書く

`src/modules/category/use-cases/create-category.ts`：

```ts
import { mutationOptions } from "@tanstack/react-query"
import { createServerFn } from "@tanstack/react-start"
import { v7 } from "uuid"
import type * as zod from "zod"

import { authorized } from "~/src/integrations/better-auth/auth.middleware"
import { db } from "~/src/integrations/drizzle-orm/drizzle.database"

import { CATEGORY_MUTATION_KEYS } from "~/src/modules/category/category.constants"
import { category } from "~/src/modules/category/category.schema"
import { categoryZodSchemas } from "~/src/modules/category/category.zod"

export const createCategory = createServerFn({ method: "POST" })
  .middleware([authorized({ category: ["create"] })])
  .validator((input: zod.input<typeof categoryZodSchemas.createCategory>) => categoryZodSchemas.createCategory.parse(input))
  .handler(({ data }) =>
    db
      .insert(category)
      .values({
        description: data.description ?? "",
        icon: data.icon ?? "FolderOpen",
        id: v7(),
        kind: data.kind,
        name: data.name,
        visibility: data.visibility ?? "public",
      })
      .returning()
      .get(),
  )

export const createCategoryMutation = mutationOptions({
  mutationFn: (data: Parameters<typeof createCategory>[0]["data"]) => createCategory({ data }),
  mutationKey: CATEGORY_MUTATION_KEYS.CREATE,
})
```

- 書き込みには `method: "POST"`、読み取りには `method: "GET"` を使います。
- ミドルウェアが呼び出しを保護します。権限を持つサインイン済みユーザーには `authorized(permission)`、任意のサインイン済みユーザーには `authorized()`、公開された操作には `withRateLimit(kind, RATE_LIMITS.SENSITIVE)` を使います。
- バリデーターはモジュールのスキーマで入力をパースし、ハンドラーはパース済みの `data` を受け取ります。
- ハンドラーは結果をそのまま返します。呼び出し元自身のデータに対する操作では、ユーザーを入力からではなく、必ず `context.auth.user.id` から読み取ります。

## クエリを書く

クエリは、パース済みの入力をキーに含むクエリオプションをエクスポートします。これにより、ページやフィルターごとに独自のキャッシュエントリが作られます（`src/modules/category/use-cases/get-categories.ts`）。

```ts
export const getCategoriesPageQuery = (input: zod.input<typeof listCategoriesSchema> = {}) =>
  queryOptions<Awaited<ReturnType<typeof getCategories>>>({
    queryFn: () => getCategories({ data: input }),
    queryKey: [...CATEGORY_QUERY_KEYS.LIST, listCategoriesSchema.parse(input)],
  })

export const getCategoriesQuery = getCategoriesPageQuery()
```

ルートのローダーの `Promise.all` 内で `context.queryClient.query({ ...getCategoriesQuery, staleTime: "static" })` を使ってクエリをプリロードし、コンポーネントでは `useSuspenseQuery(getCategoriesQuery)` で読み取ります。

## 失敗を処理する

想定される失敗には、`src/modules/_core/constants/errors.ts` のコードを指定して `AppError` をスローします。

```ts
if (row === undefined) {
  throw new AppError(ERROR_CODES.NOT_FOUND)
}
```

コードは `AUTH_API_ERROR`、`CONFLICT`、`FORBIDDEN`、`INTERNAL_ERROR`、`NOT_FOUND`、`TOO_MANY_REQUESTS`、`UNAUTHORIZED`、`VALIDATION` です。`authorized` と `withRateLimit` に含まれる `withRequest` ミドルウェアは、`AppError` についてはコードだけを転送し、Better Auth の API エラーは認証エラーキー付きの `AUTH_API_ERROR` に、Zod のエラーは `VALIDATION` に変換します。それ以外のエラーはログに記録したうえで `INTERNAL_ERROR` に置き換えます。

## コンポーネントで使う

エクスポートされたオプションを `useMutation` に展開し、`useErrorMessage` でエラーを翻訳し、成功時にモジュールのクエリを無効化します（`src/presentation/components/custom/admin/users/delete-user-dialog.tsx`）。

```tsx
const queryClient = useQueryClient()
const errorMessage = useErrorMessage()

const deleteUser = useMutation({
  ...deleteUserMutation,
  onError: (error) => {
    toast.error(errorMessage(error))
  },
  onSuccess: async () => {
    await queryClient.invalidateQueries({ queryKey: USER_QUERY_KEYS.ALL })
    toast.success(t("feedback.deleteSuccess"))
  },
})
```

`useErrorMessage` は、認証エラーキーを `auth.errors.<key>` に、エラーコードを `errors.codes.<CODE>` に、未知のものを `errors.codes.INTERNAL_ERROR` に対応付けます。無効化するのは、ミューテーションがデータを変更するモジュールだけにしてください。

## テストする

`use-cases/__test__/<operation>.test.ts` を追加します。`~/src/platform/testing/lib/query` の `executeMutation` と `executeQuery` は、実際の `QueryClient` を通してオプションを実行し、テストのセットアップはサーバー関数を実際のミドルウェアとバリデーターを経由して呼び出します。成功、スローされるすべてのコード、権限チェックをカバーします。[テストを書く](/docs/guides/writing-tests) を参照してください。
