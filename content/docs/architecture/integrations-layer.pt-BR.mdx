Cada biblioteca externa ou provedor possui um diretório sob `src/integrations`: Better Auth, Drizzle, Fumadocs, use-intl, Polar, Resend e... GitHub Arquivos de configuração inicializam clientes, adaptadores compartilhados normalizam os resultados do provedor e mantêm credenciais atrás dos limites do servidor.

Decisões de negócios permanecem em módulos de recursos, por exemplo, Polar Os manipuladores de webhook atualizam os registros de licenças através de casos de uso de módulos; a integração em si configura o SDK e verifica os webhooks que chegam.
