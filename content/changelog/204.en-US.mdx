- Each pull request adds its own changelog entry, `content/changelog/<number>.<locale>.mdx`, instead of editing this page, so pull requests open side by side no longer collide in the nine changelog files. No entry carries a date: the page and the release notes take each entry's day, in UTC, from the squash commit whose subject ends with `(#<number>)`, and list the entries that have not reached `main` yet under **Unreleased**. The existing entries moved into their own files under the days Git records: #160 moves to 2026-11-14, #104, #111 and #115 to 2026-11-12, and twelve entries from 2026-11-15 to 2026-11-16; the former **Earlier** items are dated 2026-09-24. In a pull request, `bun run check` fails while its entry is missing. See [Changelog entries](/docs/conventions/git-workflow#changelog-entries).
