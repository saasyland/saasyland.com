---
title: "Wprowadzenie"
description: "Adaptery dostawców w src/integrations."
---

Każdy folder w `src/integrations/<vendor>/` opakowuje jednego dostawcę w plikach `<vendor>.<concern>.ts`: konfigurację, klientów i cienkie adaptery. Reguły biznesowe i operacje na bazie danych pozostają w `src/modules`, a komponenty nigdy nie importują klienta dostawcy bezpośrednio.

| Folder          | Pliki                                                                                                           | Przeznaczenie                                                           |
| --------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `better-auth`   | `auth.server.ts`, `auth.client.ts`, `auth.routes.ts`, `auth.middleware.ts`, `auth.access.ts`, `auth.session.ts` | Sesje, OAuth, strażnicy tras, middleware funkcji serwerowych, role      |
| `drizzle-orm`   | `drizzle.database.ts`, `drizzle.schemas.ts`, `drizzle.config.ts`, `migrations/`                                 | Klient D1, zbiorczy eksport schematów, konfiguracja drizzle-kit         |
| `fumadocs`      | `fumadocs.config.ts`, `fumadocs.i18n.ts`, `fumadocs.source.ts`, `fumadocs.docs.ts`, `fumadocs.search.ts`        | Kolekcje dokumentacji i bloga, zlokalizowane źródła, wyszukiwanie       |
| `motion`        | `motion.features.ts`, `motion.tokens.ts`                                                                        | Leniwie ładowane funkcje Motion i wspólne przejścia                     |
| `polar`         | `polar.config.ts`, `polar.constants.ts`                                                                         | Klient SDK Polar i produkty dostępne w procesie zakupu                  |
| `resend`        | `resend.config.ts`, `resend.utils.ts`                                                                           | Klient Resend i `sendEmail`                                             |
| `tanstack-form` | `form.fields.ts`                                                                                                | `fieldErrorMessage` dla błędów pól formularza                           |
| `use-intl`      | `i18n.config.ts`, `i18n.messages.ts`, `i18n.middleware.ts`, `i18n.paths.ts`, `i18n.utils.ts`                    | Języki, przestrzenie nazw komunikatów, middleware języka, obsługa URL-i |
