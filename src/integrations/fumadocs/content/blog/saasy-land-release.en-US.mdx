## ✨ What’s New in 2.0?

### 📦 Modern Package Ecosystem

Upgraded to the latest versions of all core dependencies for performance, security, and future-proofing

### ⚙️ Global Configuration

A flexible, scalable configuration system that’s easy to manage and extend across environments

### 🧭 Fully Featured Dashboard

Beautiful, responsive dashboard with full settings suite (locale, timeZone, notifications, theming, account preferences, security control, billing management, and more)

### 🔐 Authentication, Reimagined

Moved away from [NextAuth](https://next-auth.js.org) to [BetterAuth](https://better-auth.com). Full support for multi-tenancy, subdomain routing, organizations & user roles, role-based access control (RBAC)

### ⚡ High-Performance API

Powered by Hono. Type-safe, modular, and lightning fast

### ☁️ S3 File Uploads

Seamless integration with Amazon S3 for secure file management

### 💳 Full Stripe Integration

Stripe + Stripe Connect included. One-time payments, subscriptions, marketplaces — ready out of the box

### 🛒 E-commerce Ready

Complete ecommerce system, set up both digital and physical products, but also subscriptions. Includes example course setup for SaaS + content

### 📚 OpenAPI Documentation

API docs auto-generated with Hono OpenAPI + Scalar. Easy to explore, easy to maintain

### ✍️ MDX Content System

Blog posts, legal pages, marketing content — all written in MDX. SEO-optimized and developer-friendly

### 🌍 Internationalization (i18n)

Out of the box translations included for: English, Spanish, French, Italian, German, Polish, Ukrainian, Chinese. Easily extend with your own locales

### 📘 Modern Documentation

Built with Fumadocs and Content Collections. Clean, intuitive, and easy to maintain

### 🎨 Beautiful, Flexible UI

A refreshed design system with swappable components, multiple variants, and simple customization with just a single line toggle

### 🧠 Type Safety First

Strict TypeScript everywhere. No any, no magic — just fully typed, predictable code

### 🔧 Stability & Security

Bug fixes, hardening, and optimizations across the board

### ✅ Test Coverage You Can Trust

100% coverage. Preconfigured for unit, integration, and E2E testing
