- Added: visual tests compare screenshots of the landing page, its header and footer, a blog post's author card and call to action, a docs page, the admin dashboard and settings and the billing page with approved ones, in English, German and Polish on desktop and on a phone, and fail the Chromium check of a pull request when a layout changes by accident. The browser runs in Playwright's Docker image locally and in CI, and `bun run test:visual:update` retakes the screenshots after an intended change. See [Playwright](/docs/tooling/playwright#visual-tests).
