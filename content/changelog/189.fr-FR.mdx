- Une seule constante indique si la génération de projets est livrée : `CLI_GENERATION` dans `src/data/cli.ts`. Chaque message qui annonce la génération comme à venir, sur la page d’accueil, dans l’appel à l’action du blog, sur la carte Core et sur la carte de documentation de `/app`, est un `select` ICU qui contient aussi la phrase pour la sortie de `init`, et les fonctionnalités de Core qu’apporte la génération prennent leur statut à la même constante : un seul changement les bascule dans toutes les langues. Le configurateur signale les options que liste `CLI_TEMPLATE_SUPPORT` : la stack par défaut et `--no-auth`. Les articles du blog affichent depuis le code le seuil de couverture, la version majeure de React, le taux horaire indicatif et les heures que représente le prix de Core, et leurs titres et questions de FAQ sont formatés comme leurs réponses. Voir [Page d’accueil](/docs/features/landing-page) et [Blog](/docs/features/blog).
