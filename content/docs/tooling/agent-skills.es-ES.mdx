title: "Skills para agentes"
description: "Skills de proveedores para agentes de programación, restauradas a partir de skills-lock.json."
---

`skills-lock.json` fija las skills para agentes que se usan con este repositorio. Las skills instaladas no se incluyen en el repositorio: Git ignora `.agents/` y `.claude/`.

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` elimina `.agents/skills` y `.claude/skills`, reinstala cada skill fijada con `bunx skills experimental_install`, mueve cada skill a un grupo de proveedor en `.agents/skills/<group>/<skill>/SKILL.md` y enlaza cada grupo en `.claude/skills`. Falla cuando el origen de una skill no tiene asignado ningún grupo.

Cada entrada registra el `commit` de Git del que procede su skill y un `computedHash` de sus archivos, de modo que `skills:sync` restaura los mismos archivos en todas las máquinas. Para llevar cada skill al último commit de su origen:

```sh
bun run skills:update
```

La actualización restaura las skills fijadas, ejecuta `bunx skills update --project --yes`, que avanza cada `commit` y `computedHash` en `skills-lock.json`, y después agrupa y enlaza las skills igual que `skills:sync`. Una skill eliminada en el origen conserva su entrada y se informa como eliminada; quita esa entrada de `skills-lock.json`.

| Grupo                                                 | Origen                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------ |
| `anthropic`                                           | `anthropics/skills`                                                |
| `better-auth`                                         | `better-auth/skills`                                               |
| `cloudflare`                                          | `cloudflare/skills`                                                |
| `polar`                                               | `polarsource/skills`                                               |
| `resend`                                              | `resend/resend-skills`                                             |
| `tanstack`                                            | `TanStack/router` (`router`, `start`) y `TanStack/table` (`table`) |
| `remotion`                                            | `remotion-dev/skills`                                              |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | Skills generales de ingeniería, diseño y marketing                 |

La sincronización sustituye ambos directorios, así que guarda las skills personalizadas en otro lugar. `bun run clean:hardcore` elimina `skills-lock.json`.

## Regla

Antes de modificar código relacionado con TanStack Start, Router o Table, Better Auth, Cloudflare, Polar o Resend, lee la skill correspondiente. Las skills describen las API actuales de los proveedores; las convenciones de este repositorio se documentan en [Arquitectura](/docs/architecture) y [Convenciones](/docs/conventions).
