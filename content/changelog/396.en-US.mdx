- Changed: a comment is still the exception, but when one is really needed it may be a single line that links to where the reason lives, an `https://` page or a `/docs/` path, after a few words. `code-style/no-comments` and `bun run check:comments` accept that shape and nothing else. See [Code style](/docs/conventions/code-style#comments).
- Added: `bun run check:comments` reads YAML files too, and accepts only the version tag after an action pinned to a commit SHA, such as `# v4`.
