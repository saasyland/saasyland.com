---
title: "Журнал змін"
description: "Помітні зміни з часом."
---

Кожен розділ перелічує зміни, що потрапили в `main` того дня (UTC), від найновіших, і кожна зміна завершується посиланням на pull request, з якого вона походить. Кожне розгортання production отримує тег і публікується як GitHub Release з розділом свого дня як нотатками; див. [Релізи й теги](/docs/tooling/ci-cd#releases-and-tags). Випуски самого CLI описано в [нотатках до випусків CLI](/docs/cli/releases). Кожна зміна додає власний запис; див. [Записи журналу змін](/docs/conventions/git-workflow#changelog-entries).
