---
title: Catálogo de módulos.
description: Inventario de `src/modules`, dominios y titularidad.
---

| Módulo.        | Posee.                                                                                         |
| -------------- | ---------------------------------------------------------------------------------------------- |
| `_core`        | Errores, catálogos de localización/moneda/zona horaria, utilidades compartidas.                |
| `account`      | Perfil / correo electrónico / contraseña / cerrar sesión                                       |
| `user`         | Administración de usuarios (para administradores) + herramientas de suplantación de identidad. |
| `session`      | Lista / revocar sesiones.                                                                      |
| `two-factor`   | Habilitar / Verificar / Deshabilitar TOTP                                                      |
| `verification` | Verificación de correo electrónico + gestión de restablecimiento de contraseña.                |
| `product`      | Catálogos de productos: casos de uso.                                                          |
| `category`     | Categorías de casos de uso.                                                                    |

Añade una fila cuando introduzcas una nueva carpeta de dominio.
