---
title: "Scripts du projet"
description: "Les commandes que vous utilisez au quotidien."
---

| Tâche                                                        | Commande                 |
| ------------------------------------------------------------ | ------------------------ |
| Démarrer le serveur de développement                         | `bun run dev`            |
| Vérifier le formatage, le lint, les types et les traductions | `bun run check`          |
| Exécuter tous les projets Vitest                             | `bun run test`           |
| Exécuter le contrôle de couverture                           | `bun run test:coverage`  |
| Exécuter le test de fumée dans le navigateur                 | `bun run test:e2e:smoke` |
| Générer une migration                                        | `bun run db:generate`    |
| Construire le Worker de préversion                           | `bun run build`          |
| Servir le dernier build                                      | `bun run start`          |
| Déployer la préversion                                       | `bun run deploy:preview` |

Avant d'ouvrir une pull request, exécutez la même séquence que la CI :

```sh
bun run check
bun run test:coverage
bun run test:e2e:smoke
```

Utilisez `bun run test`, et non `bun test`, pour que Vitest s'exécute avec la configuration du projet. Les scripts qui se terminent par un nom d'environnement, comme `db:migrate:preview` ou `deploy:production`, n'agissent que sur cet environnement.

Voir [Scripts du projet](/docs/tooling/scripts) pour la liste complète.
