---

El plugin `twoFactor` de Better Auth usa `APP_NAME` como emisor. Sus funciones de servidor están en `src/modules/two-factor/use-cases`:

| Caso de uso        | Middleware           | Lo usa                                 |
| ------------------ | -------------------- | -------------------------------------- |
| `enableTwoFactor`  | con sesión, limitada | `TwoFactorPasswordStep`                |
| `disableTwoFactor` | con sesión, limitada | `TwoFactorPasswordStep`                |
| `verifyTotp`       | limitada             | `TwoFactorVerifyStep`, `TwoFactorForm` |
| `verifyBackupCode` | limitada             | `TwoFactorForm`                        |

## Configuración

**Ajustes → Seguridad** en `/admin/settings` muestra `TwoFactorDialog` (`src/presentation/components/custom/admin/settings`):

1. El paso de contraseña llama a `enableTwoFactor` y recibe la URI TOTP y los códigos de respaldo.
2. El paso de verificación muestra el secreto de la URI (`extractTotpSecret`) para introducirlo a mano en una aplicación de autenticación y confirma un código de <RepositoryFact name="twoFactorCodeLength" /> dígitos con `verifyTotp`.
3. El último paso muestra los códigos de respaldo.

Con la 2FA activada, el mismo botón abre el paso de contraseña con `disableTwoFactor`. El botón lee `twoFactorEnabled` de la sesión actual.

## Desafío al iniciar sesión

Para una cuenta con 2FA, Better Auth responde al inicio de sesión con `twoFactorRedirect`, y `SignInForm` abre `/auth/two-factor`, conservando `redirect`. `TwoFactorForm` acepta un código de <RepositoryFact name="twoFactorCodeLength" /> dígitos (`InputOTP`) o, tras cambiar de modo, un código de respaldo, y envía `trustDevice: true`. Si tiene éxito, `finishSignIn` de `useAuthRedirect` continúa a `/auth/callback`.

Las longitudes de los códigos están en `auth.constraints.ts`: `TWO_FACTOR_CODE_LENGTH` es <RepositoryFact name="twoFactorCodeLength" /> y los códigos de respaldo tienen de <RepositoryFact name="backupCodeMinLength" /> a <RepositoryFact name="backupCodeMaxLength" /> caracteres.
