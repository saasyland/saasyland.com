- Змінено: запит бандла до API ліцензій для CLI читає заголовок архіву випуску в R2 замість самого архіву. SHA-256 архіву тепер зберігається разом із ним як користувацькі метадані `sha256`, які записує `bundle:upload` з репозиторію CLI, тож Worker більше не завантажує, не розпаковує й не гешує весь бандл під час кожного запиту: з нинішнім бандлом на 1,7 МБ запит займав у локальному тестовому Worker близько 31 мс процесорного часу, а тепер близько 3 мс, хоч яким великим стане бандл. На об’єкт без дайджесту API відповідає `serviceUnavailable`, а журнал називає цей об’єкт. `bun run db:reset:test` заповнює локальний бандл разом із дайджестом через `getPlatformProxy` з Wrangler, бо `wrangler r2 object put` не вміє задавати користувацькі метадані. Див. [Бандли шаблонів](/docs/features/cli-licence-api#template-bundles) і [Публікація бандлів](/docs/features/cli-licence-api#publishing-bundles).
