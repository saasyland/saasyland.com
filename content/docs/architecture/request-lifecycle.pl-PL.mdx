description: Cykl żądania — SaaSy Land
---

`src/server.ts` kanonizuje adresy językowe i synchronizuje cookie języka. `src/router.tsx` tworzy osobny QueryClient dla routera i łączy go z SSR. Natywne pliki tras deklarują komponenty, strażników, loadery, walidację parametrów i metadane.

Układy panelu i aplikacji klienta używają strażników `beforeLoad`. Każda chroniona funkcja serwerowa również sprawdza użytkownika, ponieważ RPC można wywołać niezależnie od strony. Odpowiedzi uwierzytelnionych nie umieszczaj we wspólnej pamięci statycznej.

```text
Request → Worker locale middleware → TanStack Router
        → beforeLoad session/permission guard
        → loader: messages + authorized query data
        → SSR + hydrated React presentation
Mutation → validated server function → auth/rate limit → D1 or provider
         → result/error → scoped query invalidation
```
