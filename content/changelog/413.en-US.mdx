- Fixed: stopping an impersonation no longer signs the admin out when a session read of the impersonated customer, such as the email verification check, is still on its way. Starting and stopping an impersonation now wait until no query is fetching before the session changes. See [Impersonation](/docs/features/impersonation).
- Changed: the browser test that a customer and a signed-out visitor are refused by every user-management server function creates its accounts through Better Auth's admin API and signs the probe account in without a browser, so it no longer runs into the test timeout in WebKit. A new browser test stops an impersonation while a session read is in flight. See [Testing](/docs/conventions/testing).
