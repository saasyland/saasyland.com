---
title: "Glossar"
description: "Begriffe, die in der gesamten Dokumentation von SaaSy Land verwendet werden."
---

- **AppError:** die einzige Fehlerklasse für Server Functions; sie trägt einen der `ERROR_CODES`.
- **Binding:** eine Cloudflare-Ressource, die an den Worker übergeben wird: `DB` (D1), `CACHE` (KV) oder `ASSETS` (statische Assets).
- **Guard:** eine `beforeLoad`-Funktion wie `requireAdmin`, die umleitet, bevor eine Route geladen wird.
- **Integration:** ein Ordner in `src/integrations`, der genau einen Anbieter konfiguriert, etwa Better Auth oder Resend.
- **Layout-Route:** eine Route, die ein `Outlet` für ihre Kindrouten rendert und gemeinsame `NAMESPACES` deklariert, zum Beispiel `admin.tsx`.
- **Locale-Präfix:** das Pfadsegment `/<locale>` für jede Locale außer en-US, zum Beispiel `/pl-PL`.
- **Middleware:** eine Funktion, die vor dem Handler einer Server Function läuft: `withRequest`, `authorized` oder `withRateLimit`.
- **Modul:** ein Ordner in `src/modules`, der genau eine Datenbanktabelle und ihre Use Cases besitzt.
- **Mutation-Optionen:** das `mutationOptions`-Objekt, das neben einer Server Function exportiert wird, die Daten ändert.
- **Namespace:** eine Übersetzungsdatei, deren Dateiname zugleich ihr Name ist, zum Beispiel `pages.admin.users`.
- **Prerendering:** das Rendern öffentlicher Seiten zu HTML zur Build-Zeit, damit der Worker sie als statische Assets ausliefern kann.
- **Query-Optionen:** das `queryOptions`-Objekt, das neben einer Server Function exportiert wird, die Daten liest. Loader und Komponenten nutzen es gemeinsam.
- **Root-Namespaces:** `common`, `components.*` und `errors*`, die für jede Seite vorgeladen werden.
- **Seitenroute:** eine Route, die eine Seite rendert und genau einen `NAMESPACE` deklariert.
- **Server Function:** eine typisierte RPC-Operation, die mit `createServerFn` erstellt wird und immer auf dem Server läuft.
- **Use Case:** eine Operation auf der Tabelle eines Moduls, abgelegt in `use-cases/<verb>-<noun>.ts`.
- **Wrangler-Umgebung:** eine der Umgebungen `development`, `preview`, `production` oder `test` in `wrangler.jsonc`, jede mit eigenen Bindings und Secrets.
