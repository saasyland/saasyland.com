SaaSy Land es el código fuente del sitio web saasyland.com, del espacio de trabajo del cliente y de la consola de administración: una única aplicación TanStack Start en Cloudflare Workers con D1, KV, Better Auth, Polar, Resend, use-intl y Fumadocs. La CLI de SaaSy Land y sus plantillas de generación se encuentran en un repositorio privado independiente.

<Callout title="Cómo usar esta documentación">
  Empiece por **Primeros pasos** para ejecutar la aplicación. **Arquitectura** explica dónde reside el código, **Guías** reúne recetas para
  tareas concretas, **Funcionalidades** describe el comportamiento del producto e **Integraciones** documenta cada adaptador de proveedor en
  `src/integrations`.
</Callout>

## Editar la documentación

Las páginas se encuentran en `content/docs` como `<slug>.<locale>.mdx`, un archivo por cada uno de los nueve idiomas, y cada carpeta enumera sus páginas en `meta.<locale>.json`. Todos los idiomas enumeran los mismos slugs y mantienen los bloques de código idénticos byte a byte; `bun run check:i18n` lo comprueba mediante `scripts/check-content.ts`. `bun run content` regenera `.source/`, y tanto `dev` como todos los scripts de compilación lo ejecutan automáticamente.

Las páginas MDX pueden usar componentes de Fumadocs (`<Cards>`, `<Callout>`, `<Steps>`, `<Tabs>`, `<Accordions>`) y una selección de primitivas de shadcn (`<Button>`, `<Badge>`, `<Alert>`, `<Table>`). Los enlaces internos como `/docs/tooling/testing` reciben automáticamente el prefijo del idioma del lector.
