- Документація й блог: кожна сторінка відповідає WCAG 2.2 AA в обох темах. Помаранчевий з GitHub Light і сірий колір коментарів з GitHub Dark замінено в `fumadocs.config.ts`, тож кожен токен коду досягає 4,5:1, прапорці у списках завдань отримують назву зі свого пункту, а патч Bun для `@fumadocs/base-ui` 16.19.0 робить блок коду орієнтиром-регіоном лише тоді, коли його називає заголовок, тож сторінки з кількома блоками коду більше не мають дубльованих безіменних орієнтирів. `accessibility.spec.ts` також сканує кожну сторінку розділу «Конвенції», одну сторінку з кожного розділу документації та один допис блогу в обох темах і завершується помилкою, коли сканована сторінка не завантажується.
