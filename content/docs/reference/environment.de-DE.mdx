## Umgebungsdateien

| Datei              | Eingecheckt | Verwendet von                                                                              |
| ------------------ | ----------- | ------------------------------------------------------------------------------------------ |
| `.env.example`     | Ja          | Führt jede Variable mit leerem Wert auf                                                    |
| `.env.development` | Nein        | `bun run dev`, `db:studio:development`, `db:introspect:development`                        |
| `.env.preview`     | Nein        | `deploy:preview` (`--secrets-file`), `db:studio:preview`, `db:introspect:preview`          |
| `.env.production`  | Nein        | `deploy:production` (`--secrets-file`), `db:studio:production`, `db:introspect:production` |
| `.env.test`        | Ja          | Vitest und die Wrangler-Umgebung `test`; nur Dummy-Werte                                   |

## Variablen

| Variable                    | Verwendet von                                                               |
| --------------------------- | --------------------------------------------------------------------------- |
| `AUTH_SECRET`               | Signierung, Verschlüsselung und E-Mail-Verifizierungstokens von Better Auth |
| `AUTH_GITHUB_CLIENT_ID`     | GitHub-OAuth; authentifiziert außerdem die Abfrage der GitHub-Sterne        |
| `AUTH_GITHUB_CLIENT_SECRET` | GitHub-OAuth; authentifiziert außerdem die Abfrage der GitHub-Sterne        |
| `AUTH_GOOGLE_CLIENT_ID`     | Google-OAuth                                                                |
| `AUTH_GOOGLE_CLIENT_SECRET` | Google-OAuth                                                                |
| `RESEND_API_KEY`            | Der Resend-Client                                                           |
| `RESEND_EMAIL_FROM`         | Der Standardabsender für `sendEmail`                                        |
| `POLAR_ACCESS_TOKEN`        | Der Polar-SDK-Client                                                        |
| `POLAR_SERVER`              | `sandbox` oder `production`                                                 |
| `POLAR_WEBHOOK_SECRET`      | Prüfung der Signaturen von Polar-Webhooks                                   |
| `POLAR_ORGANIZATION_ID`     | Deaktivierung von Polar-Lizenzschlüsseln und Abfrage von Rabatten           |
| `POLAR_PRODUCT_ID_CORE`     | Checkout-Produkt für den Core-Tarif                                         |
| `POLAR_PRODUCT_ID_COMPLETE` | Checkout-Produkt für den Complete-Tarif                                     |
| `POLAR_PRODUCT_ID_AGENCY`   | Checkout-Produkt für den Agency-Tarif                                       |
| `CLOUDFLARE_ACCOUNT_ID`     | D1-HTTP-Treiber von Drizzle Kit                                             |
| `CLOUDFLARE_DATABASE_ID`    | D1-HTTP-Treiber von Drizzle Kit                                             |
| `CLOUDFLARE_ACCESS_TOKEN`   | D1-HTTP-Treiber von Drizzle Kit                                             |

Jede Umgebung in `wrangler.jsonc` listet die Variablen, die sie braucht, unter `secrets.required` auf; die Umgebung `test` lässt die drei Cloudflare-Variablen weg. Worker-Code liest sie aus `env` in `cloudflare:workers`, typisiert durch `src/types/bindings.d.ts`. Es gibt keine `VITE_`-Variablen: Die öffentliche URL und die Domain sind Konstanten in `src/presentation/branding`.

## Bindings

| Binding  | Typ              | `development`             | `preview` | `production` | `test`                 |
| -------- | ---------------- | ------------------------- | --------- | ------------ | ---------------------- |
| `DB`     | D1               | Preview-Datenbank, remote | Preview   | Produktion   | Lokal `saasyland_test` |
| `CACHE`  | KV               | Preview-Namespace, remote | Preview   | Produktion   | Lokal                  |
| `ASSETS` | Statische Assets | Ja                        | Ja        | Ja           | Ja                     |

Die Deploy-Skripte für Preview und Produktion führen zuerst `scripts/verify-bindings.ts` aus. Das Skript schlägt fehl, solange eine Umgebung noch Platzhalter-IDs für D1 oder KV enthält.
