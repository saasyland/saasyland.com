- CLI ライセンス API: Worker が `saasyland` CLI に応答するようになりました。ライセンスの読み取りと、端末のアクティベート、確認、解放は、CLI もインポートする `@saasyland/stack/api` のコントラクトに従います。`readApiRequest` がすべてのリクエストを読み取り、`apiResponse` と `apiErrorResponse` がすべてのレスポンスを書き出します。キーは D1 で検索します。端末は Polar 上のキーのアクティベーションで、CLI が HMAC で導出する端末 ID で識別されるため、生のマシン ID が端末の外に出ることはありません。同じ端末から再びアクティベートするとその枠を再利用し、枠が埋まったライセンスは使用中の端末とともに `activationLimitReached` を返します。リクエストは IP アドレスごととライセンスキーごとにレート制限され、Polar の障害時は `retry-after` 付きの `serviceUnavailable` を返します。[CLI ライセンス API](/docs/features/cli-licence-api) を参照してください。
- ライセンスに 3 つ目のステータス `refunded` が加わり、`order.refunded` がこれを設定します。`benefit_grant.revoked` は引き続き `revoked` を設定しますが、`refunded` を置き換えることはありません。Polar は返金された注文の特典も取り消し、2 つのイベントはどちらの順序でも届く可能性があるためです。`/app` と `/app/license` は、返金されたライセンスを返金済みとして表示します。D1 はステータスをテキストとして保存するため、マイグレーションは不要でした。
- プランとキーの長さの定義元を 1 つにしました。`LICENSE_TIER` と `LICENSE_ACTIVATION_LIMITS` は、コンパイル時とテストでコントラクトのプランと照合され、`license.key` 列はコントラクトから長さを取得します。ドキュメントは、サイトのビルド時に API のパス、ヘッダー、上限、エンドポイント、エラーコードをコントラクトから出力し、`<RepositoryTable>` は任意の数の列を受け付けます。
- 修正: Polar がもう保持していない端末を解放すると `INTERNAL_ERROR` を返していました。現在は `deactivateLicense` が `NOT_FOUND` を返します。
- プライバシーポリシーに、CLI が端末をアクティベートするときに送信する情報、Polar がアクティベーションとともに保存する情報、ライセンス API のレート制限の仕組みを記載しました。
