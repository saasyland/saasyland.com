## SaaSy Landとは?

SaaSy Land は商用 Next.js SaaS のスターターキットです。 CLI は 5 つの質問をし、回答したモジュールのみを記述します: 独自のデータベース、課金、トランザクションメール、管理者コンソール、国際化、ビジュアルページデザイナーの認証。 141個のテストファイルとカバレッジゲートが既に配置されているので、受け取ったコードは単なる存在ではなく検証されます。

コードは MIT ライセンス済みで公開されているので、決定する前に読み込むことができます。 CLI、テンプレートとライフタイムコアの更新のために一度支払い、ランタイムライセンスチェック、ベンダーコールバックなし、サブスクリプションなしはありません。

## スタックを選択し、1つのコマンドを実行

CLI は、ダウンロードしたテンプレートではなく、戦います。 建物と書いているものを正確に尋ねるので、同じツールは、単一のテナントサイドプロジェクトとレコードの商人とマルチテナント製品に足場します。

```bash
bunx saasyland@latest init my-app \
  --framework tanstack \
  --tenancy multi \
  --billing polar \
  --content mdx \
  --email resend
```

5つの質問は、意図的に退屈するフラグで、コマンドはプロンプトではなくスクリプトに貼り付けられるようにします。

| よくある質問   | オプション                                        | なぜそれが疑問であるのか                                                                                                                                                |
| -------------- | ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| フレームワーク | `next`, `tanstack`                                | どちらもサポートされます。 既に知っているチームを選んでください。                                                                                                       |
| テナンシー     | `multi`, `single`                                 | 修正組織は、後であなたが書いたすべてのクエリに触れる                                                                                                                    |
| 請求する       | `stripe`, `polar`, `lemonsqueezy`, `--no-billing` | Polar と Lemon Squeezy はレコードの商人であり、EU の付加価値税と米国の消費税をあなたのために運ぶ。 Stripe はそうではありません。 創業者は、一度にその呼び出しをします。 |
| コンテンツ     | `mdx`, `--no-content`                             | ブログとドキュメント、または両方                                                                                                                                        |
| 電子メール     | `resend`, `--no-email`                            | トランザクションメールは、auth フローにワイヤーで縛られたり、またはどれも                                                                                               |

回答を変更し、コマンドが変更されます。 次のプロジェクトで再び実行してください: 回答の変更、CLI と生涯の更新は行いません。

### なぜカバレッジゲートが起動時にしたよりも今重要であるのか

2.0 が出荷されたとき、カバレッジ番号は品質引数でした。 これまでは、SaaS のコードベースに追加されたコードの大きなシェアがエージェントによって書かれているため、スループットの引数になります。

ふりがな [2025 Stack Overflow 開発者アンケート](https://survey.stackoverflow.co/2025/ai), 開発者の84%は、AIツールを使用して報告しました, 最も引用された不満にもかかわらず、, 45%によって命名, 「ほとんど右ではありません, しかし、かなりではありません」AI出力でした. ビルドに失敗するしきい値は、それに最も安い利用可能な答えです: エージェントは、テストを追加せずに行動を追加することはできません, そして、それは、顧客ではなく、プルリクエストで表面を破壊します.

ここまで書いています。 [あなたのリポジトリがエージェントの出力品質を決定する理由](/blog/ai-coding-agents-repository-readiness) そして、 [AIコーディングエージェントのスタックを選択する方法](/blog/choosing-a-saas-stack-for-ai-coding-agents). . 短いバージョンは、このリポジトリが20のうち20点のうち20点のスコアカードで、作業ではなく、構造によって得られます。
