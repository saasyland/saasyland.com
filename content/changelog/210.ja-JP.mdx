- 修正: Cloudflare の Bot Fight Mode は JavaScript Detections のスクリプトをすべてのページに挿入しますが、そのスクリプトに付ける nonce は `Content-Security-Policy` ヘッダーからしか取得できません。そのため、プリレンダリングされたページが meta タグで持っていたハッシュベースのポリシーが、ホームページ、ドキュメント、ブログでこのスクリプトをブロックしていました。現在は、プリレンダリングされたものもレンダリングされたものも、すべての HTML レスポンスがそのレスポンス専用の nonce を受け取り、ヘッダーに `documentPolicy(nonce)` が付きます。Worker はプリレンダリングされたページを `withNonce` に通してストリーミングします。この `HTMLRewriter` は、ページのスクリプトとモジュールのプリロードヒントに nonce を付け、プリレンダリングによってページに残った nonce を置き換えます。そのため、ビルドはスクリプトのハッシュを計算することも、meta タグにポリシーを書き込むことも、エントリースクリプトをローダーに置き換えることもなくなりました。HTML レスポンスは `private, no-cache` になり、`ETag` も `Last-Modified` も付かないため、ブラウザーが別のレスポンスの nonce を持つページを再利用することはありません。[セキュリティと堅牢化](/docs/features/security) を参照してください。
