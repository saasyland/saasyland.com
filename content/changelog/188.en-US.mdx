- Fixed: a build on a busy machine could stop prerendering with `connect ETIMEDOUT ::1` and `connect ECONNREFUSED 127.0.0.1`. The preview server that prerendering starts listened on `localhost`, which Node resolves to `::1` first, and the crawler connected by name, trying `::1` and then `127.0.0.1` with a short timer for each; when the build stalled for longer than that, the crawler gave up on `::1` and found nothing on `127.0.0.1`. `vp preview` now listens on `127.0.0.1`, the `LOCAL_SERVER` address in `src/data/local-server.ts` (at `127.0.0.1:3000` for `start` and `start:test`, on a free port for prerendering), so every local client connects to the address the server binds, without resolving a name. Playwright's default URL and the local hosts that `appHostsForMode` trusts come from the same constant.
