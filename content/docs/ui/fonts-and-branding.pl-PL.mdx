## Czcionki

Geist i Geist Mono są hostowane w `public/fonts` jako zmienne podzbiory WOFF2 serwowane z niezmienną roczną pamięcią podręczną (`public/_headers`). `src/presentation/styles/fonts.css` deklaruje `@font-face` dla każdego zakresu Unicode (łaciński, łaciński rozszerzony, cyrylica), zapasowe kroje z dopasowaną metryką oraz zmienne `--font-geist-sans` i `--font-geist-mono`. `globals.css` mapuje je na `--font-sans`, `--font-heading` i `--font-mono`. Tekst japoński korzysta z czcionek systemowych.

## Wstępne ładowanie

`src/presentation/document-assets.ts` eksportuje `DOCUMENT_STYLESHEET` (`globals.css`) i czcionki do wstępnego ładowania dla danego języka:

```ts
export const fontPreloads = (locale: SupportedLocale) => {
  const fonts = [GEIST_LATIN, GEIST_MONO_LATIN]
  if (locale === "pl-PL") {
    fonts.push(GEIST_LATIN_EXT)
  } else if (locale === "uk-UA") {
    fonts.push(GEIST_CYRILLIC)
  }
  return fonts
}
```

Trasa główna dodaje je jako znaczniki `link`, a Worker (`src/server.ts`) wysyła arkusz stylów i te same czcionki w nagłówku `Link` przy każdej odpowiedzi HTML. Nazwy plików czcionek to skróty ich zawartości: po podmianie czcionki zaktualizuj zarówno `fonts.css`, jak i `document-assets.ts`.

## Stałe marki

`src/presentation/branding/index.ts` to jedyne źródło danych o marce:

```ts
export const APP_NAME = "SaaSy Land"
export const APP_LOGO_PATH = "M6 0H15V9H24V18A6 6 0 0 1 18 24H6A6 6 0 0 1 0 18V6A6 6 0 0 1 6 0Z"
export const APP_DOMAIN = "saasyland.com"

export const APP_URL = `https://${APP_DOMAIN}`
export const CONTACT_EMAIL = `hello@${APP_DOMAIN}`
export const NOTIFICATIONS_EMAIL = `notifications@${APP_DOMAIN}`

export const APP_FOUNDED_YEAR = 2023

export const APP_GITHUB_OWNER = "saasyland"
export const APP_GITHUB_REPO = APP_DOMAIN
export const APP_GITHUB_URL = `https://github.com/${APP_GITHUB_OWNER}/${APP_GITHUB_REPO}`
```

Zasilają one nazwę aplikacji w Better Auth i wystawcę 2FA, nazwy ciasteczek motywu i języka, dozwolone hosty, stopkę, nawigację dokumentacji, liczbę gwiazdek GitHuba, dane strukturalne bloga oraz nadawców i odbiorców e-maili.

## Logo i multimedia

- `Wordmark` (`src/presentation/components/custom/wordmark.tsx`) renderuje logo, `APP_LOGO_PATH`, jako osadzony SVG obok `APP_NAME`. Karty podglądu rysują tę samą ścieżkę tymi samymi czcionkami; zobacz [Podglądy w wyszukiwarkach i mediach społecznościowych](/docs/features/seo). `HomeLink` (`home-link.tsx`) zamienia je w link do strony głównej w nagłówkach strony głównej, bloga i kursów; zobacz [Strona główna](/docs/features/landing-page).
- Favicon to `public/favicon.ico`; obrazy bloga znajdują się w `public/images/blog`.
- Filmy strony głównej znajdują się w `src/presentation/assets/motion` jako pliki WebM z plakatami WebP. Plakat musi mieć takie same wymiary jak jego film. Przegląd stron kursu, odtwarzany na żądanie z kontrolkami, ma też zapasowy plik MP4 i plakaty AVIF.
