- Changed: the docs, the blog and the landing page read their content from indexes that every build writes as static files, one per language, so a client navigation through the docs or the blog requests nothing from the Worker and never waits for a new Worker isolate. The deployed Worker holds no docs or blog content any more: its upload went from 30,115 KiB to 13,465 KiB, and from 3,021 files to 1,590. See [Performance](/docs/conventions/performance#the-worker-holds-no-docs-or-blog-content).
- Changed: the docs search runs in the browser. The first search downloads the search index of the page's language once, and every result after that comes from memory; `/api/search`, which took 9 to 18 seconds on saasyland.com, is gone. Results no longer show the tags of components such as `<RepositoryFact>`. See [Docs site](/docs/features/docs-site#search).
- Changed: a blog post's reading time no longer counts the markup of components as words, so a few posts read a minute shorter in some languages.
- `scripts/verify-build.ts` fails the build when any file of the deployed Worker holds a docs or blog page, or when the search index of a language is missing or does not hold exactly the docs pages of that language.
