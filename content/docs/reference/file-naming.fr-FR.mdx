---
title: Nom du fichier
description: Les suffixes de colocation et les conventions de dossiers.
---

| Motif          | Signification                                        |
| -------------- | ---------------------------------------------------- |
| `_components/` | Composants locaux de la route React                  |
| `_lib/`        | Aides routières locales, params de recherche, cartes |
| `_types/`      | Types d'itinéraires locaux                           |
| `use-cases/`   | Services d'application de modules                    |
| `*.server.ts`  | Entrée d'intégration uniquement pour le serveur      |
| `__test__/`    | Essais communs                                       |

Préférez des noms explicites (`search-params.ts`) sur vague `utils.ts` Des ordures.
