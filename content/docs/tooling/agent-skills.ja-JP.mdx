---
title: "エージェントスキル"
description: "skills-lock.json から復元する、コーディングエージェント向けのベンダー製スキルです。"
---

`skills-lock.json` は、このリポジトリで使うエージェントスキルのバージョンを固定します。インストールされたスキルはコミットしません。`.agents/` と `.claude/` は Git の管理対象外です。

```sh
bun run skills:sync
```

`scripts/sync-skills.ts` は `.agents/skills` と `.claude/skills` を削除し、ロックされているすべてのスキルを `bunx skills experimental_install` で再インストールします。そのうえで各スキルを `.agents/skills/<group>/<skill>/SKILL.md` のベンダーグループに移動し、すべてのグループを `.claude/skills` にリンクします。グループの対応付けがないスキルのソースがあると失敗します。

| グループ                                              | ソース                                                               |
| ----------------------------------------------------- | -------------------------------------------------------------------- |
| `anthropic`                                           | `anthropics/skills`                                                  |
| `better-auth`                                         | `better-auth/skills`                                                 |
| `cloudflare`                                          | `cloudflare/skills`                                                  |
| `polar`                                               | `polarsource/skills`                                                 |
| `resend`                                              | `resend/resend-skills`                                               |
| `tanstack`                                            | `TanStack/router`（`router`、`start`）と `TanStack/table`（`table`） |
| `remotion`                                            | `remotion-dev/skills`                                                |
| `matt-pocock`, `impeccable`, `taste`, `coreyhaines31` | エンジニアリング、デザイン、マーケティング全般のスキル               |

同期は両方のディレクトリを置き換えるため、独自のスキルは別の場所に置いてください。`bun run clean:hardcore` は `skills-lock.json` を削除します。

## ルール

TanStack Start、Router、Table、Better Auth、Cloudflare、Polar、Resend に関わるコードを変更する前に、対応するスキルを読んでください。スキルはベンダーの最新の API を説明しています。このリポジトリの規約は[アーキテクチャ](/docs/architecture)と[規約](/docs/reference/conventions)にまとめられています。
