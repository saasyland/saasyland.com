La aplicación se ejecuta como un único Cloudflare Worker. `@cloudflare/vite-plugin` lo compila y `CLOUDFLARE_ENV` selecciona el entorno de Wrangler. `wrangler.jsonc` establece `main` en `./src/server.ts`, activa `nodejs_compat` y la observabilidad, y sirve los archivos estáticos mediante el binding `ASSETS`. El Worker se ejecuta primero en todas las rutas excepto `/assets/*`, `/fonts/*`, `/robots.txt` y `/llms.txt`.

| Entorno       | Worker                  | D1 y KV                              | Dominio                 |
| ------------- | ----------------------- | ------------------------------------ | ----------------------- |
| `development` | `saasyland-development` | Recursos remotos de preview          | `localhost:3000`        |
| `preview`     | `saasyland-preview`     | Recursos de preview                  | `preview.saasyland.com` |
| `production`  | `saasyland`             | Recursos de producción               | `saasyland.com`         |
| `test`        | `saasyland-test`        | Recursos locales en `.wrangler/test` | `127.0.0.1:3000`        |

Todos los entornos vinculan D1 como `DB` y KV como `CACHE` y enumeran sus secretos obligatorios. El entorno `test` usa `src/platform/testing/worker.ts` como punto de entrada; intercepta las solicitudes a Resend y a Polar y expone endpoints exclusivos de pruebas para Playwright.

## Flujo de una solicitud

`src/server.ts` gestiona todas las solicitudes:

1. `resolveLocale` de `i18n.middleware.ts` examina las solicitudes de documentos `GET` y `HEAD` fuera de `/api` y `/_serverFn`. Redirige los alias de idioma y las rutas de idioma no canónicas con el estado 308 e indica cuándo la cookie de idioma no coincide con el idioma de la URL.
2. Las solicitudes `GET` y `HEAD` fuera de `/api` y `/_serverFn` se sirven primero desde `ASSETS`, lo que cubre las páginas prerenderizadas. Un 404 pasa al handler de TanStack Start.
3. Cuando hay que actualizar la cookie de idioma, el Worker la añade a la respuesta. Las respuestas HTML reciben además cabeceras `Link` de precarga para la hoja de estilos y las fuentes del idioma.
4. Las respuestas HTML reciben precios regionales: cuando el país de `cf-ipcountry` cumple los requisitos para un descuento por paridad de poder adquisitivo, un `HTMLRewriter` añade los atributos del descuento a `<html>` y la respuesta pasa a ser `private, no-cache`.

## Despliegue

`bun run deploy:preview` y `bun run deploy:production` ejecutan `scripts/verify-bindings.ts`, que rechaza los ID de D1 y KV de marcador de posición, y después la compilación correspondiente y `wrangler deploy --secrets-file .env.<environment>`. Las compilaciones prerenderizan las páginas públicas y ejecutan `scripts/verify-build.ts` y `scripts/optimize-prerendered-html.ts`. Las migraciones son comandos independientes; consulte [Desplegar una preview](/docs/getting-started/deploy-preview) y [CI/CD](/docs/tooling/ci-cd).
