- 変更: 2つの Polar パッケージを除くすべての依存関係が最新リリースになり、Bun は 1.4.5 になりました。TanStack Start は、同じパッチ済みの TanStack Router に依存する 1.169.7 に移行しました。`@testing-library/jest-dom` は、コードを変更せずに Vitest 5 が必要な 8.0.0 に移行しました。Fumadocs、Lucide、TanStack Query、Video.js、React Email、React Resizable Panels、Recharts、Resend、Takumi、Wrangler、Cloudflare の Vite プラグイン、Testing Library の `user-event`、Bun の型定義は最新リリースになりました。Vitest とそのカバレッジプロバイダーは、Vite+ 1.7.0 が同梱する 5.1.0 のままです。[依存関係](/docs/conventions/dependencies)を参照してください。
- 修正: Fumadocs 16.19.5 が Fumadocs 自身のスキップリンクにボタンのクラスを付け、それがリンクを隠すルールより優先されたため、ドキュメントのページでそのリンクが再び Tab の順序に入っていました。ルールを Tailwind のレイヤーの外に移したので、サイトのリンクだけが残ります。[ドキュメントサイト](/docs/features/docs-site)を参照してください。
- 変更: ランディングページの動画プロジェクトは Remotion 4.0.545 と、サイトが受け入れる最も低いバージョンである Lucide 1.77.0 に移行しました。[依存関係](/docs/conventions/dependencies)を参照してください。
- 変更: `@polar-sh/sdk` は当面 1.3.0、`@polar-sh/better-auth` は 2.1.4 のままです。SDK 1.3.2 はサブスクリプションのステータス `trial_ended` を追加しており、先に Polar 連携のステータスにこれを加える必要があります。その変更はレビュー待ちです。
- 変更: TanStack Router、Motion、Better Auth のパッチは、修正を含むリリースがまだないため残しています。ドキュメントには、それぞれのアップストリームの Issue または Pull Request へのリンクを載せました。Motion は次のリリースに向けて `LazyMotion` の修正を取り込み済みです。GitHub が `deepmerge` のアドバイザリーを取り下げたため、`bun audit` が報告するアドバイザリーは1件になりました。[依存関係](/docs/conventions/dependencies)を参照してください。
