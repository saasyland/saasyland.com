## Herramientas

| Herramienta | Versión                    | Motivo                                                                                                                                                                            |
| ----------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bun         | 1.4.4                      | Gestor de paquetes y ejecutor de scripts; lo fijan `packageManager` en `package.json` y la CI                                                                                     |
| Node.js     | 26.13.1 o posterior        | La versión de `.nvmrc`, que leen `nvm use` y la CI; 26.13.1 es la versión de seguridad de noviembre de 2026 de la rama LTS Node 26. La base de datos de pruebas usa `node:sqlite` |
| Git         | Cualquier versión reciente | El paso de instalación configura los hooks de Git                                                                                                                                 |

Wrangler, drizzle-kit, Playwright y la CLI de Vite+ son dependencias de desarrollo; ejecútelos mediante los scripts del paquete o con `bunx`. Las pruebas en el navegador también necesitan los navegadores de Playwright que instala `bun run test:e2e:install`.

## Cuentas

La preview de pruebas aislada y todas las pruebas automatizadas no necesitan cuentas ni credenciales. El desarrollo y el despliegue usan servicios reales:

- Una cuenta de Cloudflare con D1, KV, R2 y Workers. El servidor de desarrollo se conecta a los recursos remotos de preview.
- Aplicaciones OAuth de GitHub y Google para el inicio de sesión social.
- Resend con un remitente verificado. El registro por correo electrónico exige una dirección verificada, por lo que sin él el registro no funciona.
- Polar, con el entorno sandbox para desarrollo, con tres productos para los niveles Core, Complete y Agency.
