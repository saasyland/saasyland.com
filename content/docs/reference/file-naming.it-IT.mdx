---
title: Nome del file
description: Suffissi di colocation e convenzioni di cartelle.
---

| Modello        | Significato                                  |
| -------------- | -------------------------------------------- |
| `_components/` | Componenti Route-local React                 |
| `_lib/`        | Assistenti locali, ricerca-parami, mappatori |
| `_types/`      | Tipologie locali                             |
| `use-cases/`   | Servizi applicativi del modulo               |
| `*.server.ts`  | Ingresso di integrazione solo server         |
| `__test__/`    | Test Colocati                                |

Preferire nomi espliciti (`search-params.ts`) su vago `utils.ts` Le discariche.
