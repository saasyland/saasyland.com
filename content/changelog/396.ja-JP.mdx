- 変更：コメントは引き続き例外ですが、本当に必要な場合に限り、理由が書かれている場所へのリンクを 1 行で置けます。リンクは `https://` のページか `/docs/` のパスで、前に添えられるのは数語までです。`code-style/no-comments` と `bun run check:comments` はこの形だけを受け入れます。[コードスタイル](/docs/conventions/code-style#comments)を参照してください。
- 追加：`bun run check:comments` は YAML ファイルも読み、コミット SHA に固定したアクションの後ろに付くバージョンタグ（`# v4` など）だけを受け入れます。
