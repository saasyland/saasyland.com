- 変更: オプション機能は `scripts/features.ts` に並び、`bun run check:features` はシナリオごとにその機能を取り除き、変更したファイルを整形し、残ったサイトの型と翻訳を検査します。5 つのシナリオはすべて、取り除けない参照を残さずに通り、失敗したシナリオは CI の実行を失敗させるようになりました。[テスト](/docs/conventions/testing)を参照してください。
- 変更: `*.entries.ts` のバレルはなくなりました。フロー、ページ、シード、プロバイダーのダブル、テストのフィクスチャの各リストは、要素を宣言するファイルから直接インポートします。[テストと CI](/docs/architecture/testing-architecture)を参照してください。
- 変更: `bun run check:content` がドキュメント、ブログ、変更履歴の内容を検査し、`bun run check:i18n` はメッセージだけを検査します。[プロジェクトのスクリプト](/docs/tooling/scripts)を参照してください。
