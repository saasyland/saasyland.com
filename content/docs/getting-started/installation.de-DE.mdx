Klone das Repository und installiere anschließend im Stammverzeichnis mit der eingecheckten Lockfile:

```sh
bun install --frozen-lockfile
```

Das Lifecycle-Skript `prepare` führt danach Folgendes aus:

1. `vp config --no-agent`, das den Git-Hook-Dispatcher für `.vite-hooks/` installiert (Pre-Commit-Prüfungen, den Hook für Commit-Nachrichten und den Hook `post-checkout`, der den Dispatcher in neuen Worktrees installiert).
2. `scripts/verify-git-hooks.ts`, das die Installation scheitern lässt, wenn Git diesen Dispatcher nicht ausführen würde, und den Befehl ausgibt, der das behebt.
3. `bun run generate:cn`, das die Tabellen für das Zusammenführen von Klassen in `.source/cn-tables.ts` erzeugt.
4. `bun run content`, das die Fumadocs-Collections in `.source/` erzeugt.

Wenn du wie die CI mit `--ignore-scripts` installierst, führe anschließend `bun run typegen` aus. Dieses Skript erzeugt außerdem `src/types/worker-configuration.d.ts` aus `wrangler.jsonc` neu.

## Optionale Extras

```sh
bun run test:e2e:install
bun run skills:sync
```

Der erste Befehl installiert Chromium und WebKit für Playwright; der zweite stellt die [Agent-Skills](/docs/tooling/agent-skills) wieder her.
