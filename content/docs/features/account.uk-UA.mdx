`src/modules/account` володіє таблицею `account` з Better Auth (`account.schema.ts`): один рядок на кожні облікові дані або провайдера OAuth, пов’язаного з користувачем. Токени OAuth у ній зашифровані.

## Сценарії використання

| Сценарій                           | Middleware             | Використовує                          |
| ---------------------------------- | ---------------------- | ------------------------------------- |
| `signUpWithPassword`               | з обмеженням           | `SignUpForm`                          |
| `signOutUser`                      | з сесією               | `useSignOut`                          |
| `changePassword`                   | з сесією, з обмеженням | `SettingsPasswordForm`                |
| `changeEmail`                      | з сесією, з обмеженням | жоден екран                           |
| `updateUser`                       | з сесією               | жоден екран                           |
| `sendChangeEmailConfirmationEmail` | хук Better Auth        | `user.changeEmail` в `auth.server.ts` |

`sendChangeEmailConfirmationEmail` надсилає `ChangeEmailConfirmationEmail` на поточну адресу з посиланням для підтвердження від Better Auth.

## Параметри

Часовий пояс, який користувач вибирає на екрані [Налаштування](/docs/features/settings), — це стовпець таблиці `user`, тому його сценарій використання розташовано в модулі користувача: `updatePreferences` (`src/modules/user/use-cases/update-preferences.ts`) вимагає користувача, який увійшов, перевіряє вхідні дані за допомогою `userZodSchemas.updatePreferences` і зберігає їх через `updateUser` з Better Auth — тим самим шляхом, що й оновлення профілю вище. `PreferencesCard` викликає його на `/app/settings` і `/admin/settings`. Мова — це локаль в URL, і вона не зберігається.

## Вихід

`useSignOut` (`src/hooks/use-sign-out.ts`) запускає `signOutUserMutation`, очищує кеш запитів, переходить на `/auth/sign-in` і показує сповіщення. Віджет користувача в адмінпанелі та бічна панель `/app` мають власний `SignOutButton`, що його використовує.
