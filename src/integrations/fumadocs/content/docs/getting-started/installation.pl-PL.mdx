## Clone and install

```bash
git clone https://github.com/pjborowiecki/saasyland.com.git
cd saasyland.com
bun install
```

Nie ma kroku `postinstall`. Źródła MDX (`.source/`) generuje wtyczka `createMDX` podczas `next dev` i `next build`, a migracje bazy uruchamiasz sam poleceniem `bun run db:migrate` po uzupełnieniu `.env.local`.

## Verify tooling

```bash
bun run check
bun run test:unit
```

## Monorepo note

This repository is a **single Next.js app**, not an npm workspaces monorepo.
