title: "プロバイダー"
description: "src/providers にある 4 つのアプリケーションプロバイダーと、それぞれのマウント位置およびその理由。"
---

`src/providers` には 4 つのプロバイダーがあります。各プロバイダーは、それを利用するコンポーネントにできるだけ近い位置にマウントします。

| プロバイダー           | ラップするもの                                                                                                            | マウント位置                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `TranslationsProvider` | root とマッチしたルートの名前空間、名前付きの日付フォーマット、ユーザーのタイムゾーンを渡した、use-intl の `IntlProvider` | root シェル内で、ドキュメントの body を囲む                                  |
| `AriaProvider`         | React Aria の `I18nProvider` と `RouterProvider`                                                                          | root コンポーネント内で、すべてのルートを囲む                                |
| `ThemeProvider`        | クッキーに保存する `@wrksz/themes` のプロバイダー                                                                         | root の `Toaster` と、ドキュメントサイドバーのテーマ切り替えを囲む           |
| `MotionProvider`       | Motion の `LazyMotion`（strict）と、`reducedMotion="user"` を指定した `MotionConfig`                                      | ランディングページ、ブログのインデックス、ブログの共有ボタン、`LicenseOffer` |

## root の構成

`src/routes/__root.tsx` は、`shellComponent` でドキュメントを、`component` でアプリケーションを描画します。

```tsx
const RootComponent = () => (
  <AriaProvider>
    <OfflineBanner />
    <AffiliateReferral />
    <Outlet />
    <ThemeProvider>
      <Toaster />
    </ThemeProvider>
  </AriaProvider>
)
```

- **TranslationsProvider** はシェルの `<body>` 内にあるため、デフォルトのエラーと not-found の各コンポーネントやルートのスケルトンを含め、すべての画面が翻訳されます。root 名前空間と、マッチした各ルートの `staticData.namespaces` から名前空間を集め、`useSuspenseQueries` で読み込んで 1 つのメッセージツリーを構築します。また、`I18N.FORMATS` と、ルートガードが読み込んだセッションのタイムゾーン（セッションがなければ `UTC`）も渡します。セッションを自分で取得することはありません。[国際化とロケール](/docs/features/internationalization)を参照してください。
- **AriaProvider** は、現在のロケールを React Aria に渡し、React Aria のリンクを TanStack Router に接続します。`useHref` がパスをローカライズするため、React Aria コンポーネントの `href` にはロケールプレフィックスが付きます。
- **ThemeProvider** はルートのアウトレットをラップしません。ハイドレーション後に更新されるプロバイダーはすべてのページを再レンダリングしてしまうため、必要なコンポーネントだけをラップします。初期テーマは、ドキュメントの head にある `ThemeScript` がハイドレーションの前に適用します。
- **MotionProvider** は `domMax` の機能バンドルをオンデマンドで読み込み、アニメーションを実行する場所にだけマウントされます。対象は `_landing.index.tsx`、`blog.index.tsx`、`post-share.tsx`、そして `/app` と `/app/license` のプランのカードである `license-offer.tsx` です。
- **AffiliateReferral** はプロバイダーではありません。アウトレットの隣に置かれ、紹介パラメーター付きの訪問でのみ Affonso のスクリプトをレンダリングします（[アフィリエイトプログラム](/docs/features/affiliates)）。

## プロバイダーコンポーネントではないもの

- **QueryClient。** `src/router.tsx` がリクエストごとに作成し、ルーターのコンテキストに入れて、`setupRouterSsrQueryIntegration` で接続します。
- **Fumadocs。** `/docs` レイアウトは、Fumadocs 独自のテーマ処理を無効にした状態で、Fumadocs の `RootProvider` をマウントします。
