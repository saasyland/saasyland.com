- Zmieniono: opcjonalne funkcje są wymienione w `scripts/features.ts`, a `bun run check:features` usuwa funkcje każdego scenariusza, formatuje zmienione pliki i sprawdza typy oraz tłumaczenia strony, która zostaje. Wszystkie pięć scenariuszy przechodzi bez odwołania, którego nie da się usunąć, a nieudany scenariusz kończy teraz przebieg CI błędem. Zobacz [Testy](/docs/conventions/testing).
- Zmieniono: nie ma już żadnego pliku zbiorczego `*.entries.ts`. Każda lista przepływów, stron, danych początkowych, atrap dostawców i fixture’ów testowych importuje elementy z plików, które je deklarują. Zobacz [Testy i CI](/docs/architecture/testing-architecture).
- Zmieniono: `bun run check:content` sprawdza treść dokumentacji, bloga i dziennika zmian, a `bun run check:i18n` już tylko komunikaty. Zobacz [Skrypty projektu](/docs/tooling/scripts).
