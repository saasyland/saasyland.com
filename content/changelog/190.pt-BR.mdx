- Toda página executa apenas os scripts com que foi servida, sob uma Content Security Policy que segue a strict CSP do Google. Uma página que o Worker renderiza recebe um nonce novo no cabeçalho a cada resposta, e `src/server.ts` o passa ao TanStack Start, que o coloca nos scripts do router, do React e do tema. Uma página pré-renderizada é o mesmo arquivo para todos e não pode levar um nonce, então `scripts/secure-prerendered-html.ts` calcula os hashes dos seus scripts inline durante o build, carrega o módulo de entrada a partir de um loader inline com hash que mantém o hint de entrada de baixa prioridade e grava a política em uma tag meta. `'strict-dynamic'` permite que esses scripts carreguem os chunks de rota e o pixel do Affonso. `base-uri` agora é `'none'`, o zod faz o parsing sem verificar se pode usar `eval`, e toda spec de navegador falha quando uma página relata uma violação.
