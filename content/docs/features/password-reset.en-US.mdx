## Requesting a link

`/auth/forgot-password` renders `ForgotPasswordForm`. It calls `requestPasswordReset` (`src/modules/verification/use-cases/request-password-reset.ts`, rate limited with `RATE_LIMITS.SENSITIVE`) with `redirectTo` set to `/auth/reset-password` in the current locale. Better Auth then calls `sendResetPasswordEmail`, which sends the `ResetPasswordEmail` template.

## Setting a new password

The emailed link opens `/auth/reset-password?token=…`. Without a token, or with `?error=`, the page shows the invalid-link message and a link back to `/auth/forgot-password`. With a token, `ResetPasswordForm` calls `resetPassword` (rate limited with `RATE_LIMITS.TOKEN`) and navigates to `/auth/sign-in`. Because `revokeSessionsOnPasswordReset` is enabled, every existing session of that user ends.

## Other password changes

- Signed-in users change their password in **Settings → Security** ([Settings](/docs/features/settings)).
- Admins set a password for another user from the users table ([Users (admin)](/docs/features/users-admin)).
