Ci sono due modi per eseguire SaaSy Land in locale. La preview di test isolata non richiede alcun account: usa D1 e KV locali, account di test creati dal seed e richieste ai provider intercettate. Lo sviluppo con hot reload si collega a Cloudflare e ai provider reali.

<Steps>
  <Step>[Prerequisiti](/docs/getting-started/prerequisites): Bun, Node.js e gli account necessari per ciascuna modalità.</Step>
  <Step>[Installazione](/docs/getting-started/installation): installa le dipendenze e i file generati.</Step>
  <Step>[Variabili d'ambiente](/docs/getting-started/environment-variables): compila il file di ambiente.</Step>
  <Step>[Primo avvio](/docs/getting-started/first-run): avvia la preview di test o il server di sviluppo.</Step>
  <Step>[Script del progetto](/docs/getting-started/project-scripts): i comandi che usi ogni giorno.</Step>
  <Step>[Deploy di una preview](/docs/getting-started/deploy-preview): crea le risorse Cloudflare ed esegui il deploy.</Step>
</Steps>
