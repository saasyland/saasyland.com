## インポートの方向

| フォルダー                | インポートしてよいもの                                                                                                            | インポートしてはいけないもの                                 |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `src/routes`              | presentation、モジュールのクエリ／ミューテーションオプション、インテグレーション（ガード、i18n、Fumadocs）、`src/data`、`src/lib` | サーバー関数の外でのデータベースやプロバイダーのクライアント |
| `src/presentation`        | モジュールのオプション、Zod スキーマ、定数と型、フック、`src/data`、`src/lib`、ブラウザで安全に使えるインテグレーション           | `db`、`auth.server.ts` の `auth`、Polar、Resend              |
| `src/modules/*/use-cases` | インテグレーション（`db`、`auth`、`sendEmail`、`polar`）、`_core`、モジュールのスキーマ、メールテンプレート                       | コンポーネント                                               |
| `src/integrations`        | `_core`、ベンダーからコールバックされるモジュールのスキーマとユースケース                                                         | コンポーネント                                               |
| `src/server.ts`           | ロケールのヘルパー、クッキー、`_core` の定数、`MEDIA_PATH_PREFIX`、ドキュメントアセット                                           | データベース、Better Auth、Polar SDK                         |

ブラウザで安全に使えるインテグレーションには、`i18n.paths.ts`、`i18n.utils.ts`、`auth.client.ts`、`auth.access.ts`、`form.fields.ts` があります。

## サーバー専用の境界

- **サーバー関数。** TanStack Start は、すべての `createServerFn` ハンドラーをコンパイル時にブラウザバンドルから取り除き、呼び出しを RPC リクエストに置き換えます。そのため、コンポーネントは、`db` をインポートしているファイルと同じファイルから `createCategoryMutation` をインポートできます。
- **サーバー専用モジュール。** シークレットやバインディングを読み取るファイルは `import "@tanstack/react-start/server-only"` で始まり、これによってクライアントビルドから除外されます。例：`drizzle.database.ts`、`auth.server.ts`、`polar.config.ts`、`resend.utils.ts`、`src/lib/rate-limit.ts`、`i18n.middleware.ts`。例外は、`src/lib/github.ts` や `deactivate-license.ts` のようにサーバー関数をエクスポートするファイルです。コンポーネントが RPC 呼び出しのためにインポートするため、`env` はハンドラーとそこから呼ばれるヘルパーの中でだけ読み取ります。ビルドはこれらをクライアントバンドルから除外します。
- **環境ごとの関数。** `createServerOnlyFn` は、サーバーでのみ実行されるコード（`getRequestSession`）をラップします。`createIsomorphicFn` は、サーバーとブラウザで別々の実装を提供します（`getCurrentLocale`、`getCookie`）。
- **バインディングとシークレット**は `cloudflare:workers` の `env` から取得し、サーバーコード、つまりサーバー専用モジュール、サーバー関数のハンドラー、およびそれらだけがインポートするヘルパーでのみ読み取ります。クライアントアセットが `cloudflare:workers` をインポートしている場合、`scripts/verify-build.ts` がビルドを失敗させます。
- **Worker のエントリー。** `src/server.ts` は、`/assets/*`、`/fonts/*`、`/robots.txt`、`/llms.txt` を除くすべてのリクエストで実行されます。これらは `wrangler.jsonc` の `run_worker_first` によって静的アセットから直接配信されます。そのため静的インポートを最小限に抑えています。動的 `import()` で読み込むのは、`/media/` パスの場合の `serveMedia` と、一致する静的アセットがない場合の TanStack Start のハンドラーだけです。

```ts
import "@tanstack/react-start/server-only"

import { env } from "cloudflare:workers"

import { drizzle } from "drizzle-orm/d1"

import * as schema from "~/src/integrations/drizzle-orm/drizzle.schemas"

export const db = drizzle(env.DB, { schema })
```
