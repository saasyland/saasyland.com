Кожна стороння бібліотека чи сервіс, які потребують налаштування, володіють однією папкою в `src/integrations`. Файли називаються `<prefix>.<concern>.ts`, де префікс — коротка назва вендора.

## Що не є інтеграцією

- Кількість зірок на GitHub — це серверна функція в `src/lib/github.ts`, кешована в KV.
- Обмеження частоти запитів — це `src/lib/rate-limit.ts` на основі таблиці `rate_limit`.
- Прив'язкам Cloudflare не потрібен адаптер. Серверний код читає їх з `env` у `cloudflare:workers`.

## Бізнес-логіка залишається в модулях

Інтеграція налаштовує вендора. Рішення щодо даних застосунку належать модулю, який володіє таблицею:

- Плагін Polar, який розділ Polar додає до Better Auth у `src/data/polar.auth-plugins.ts`, перевіряє підписи вебхуків за допомогою `POLAR_WEBHOOK_SECRET` і передає кожну подію в `handlePolarEvent` у `src/data/polar-events.ts`. Звідти подія потрапляє до кожного розділу, який перелічує її у своєму `<area>.polar-events.ts`; `src/data/license.polar-events.ts` розділу ліцензій викликає `licenseWebhookHandlers` у `src/modules/license/license.webhooks.ts`, які викликають сценарії використання ліцензій. Ідентифікатори продуктів планів ліцензій, `POLAR_PRODUCT_IDS`, теж належать розділу ліцензій і лежать у `src/modules/license/license.utils.ts`.
- Email-хуки Better Auth викликають `sendVerifyEmail`, `sendResetPasswordEmail` і `sendChangeEmailConfirmationEmail` з модулів verification та account, які додає Resend у `src/data/resend.auth-emails.ts`.
- Сценарій використання надсилає лист мовою, яку передає його викликач (лист підтвердження читає її з callback-URL): завантажує простір імен шаблону, рендерить шаблон і викликає `sendEmail`:

```ts
const messages = await loadNamespace<typeof verifyEmailMessages>({ locale, namespace: VERIFY_EMAIL_NAMESPACE })
await sendEmail({
  idempotency: { purpose: EMAIL_PURPOSE.VERIFY_EMAIL, token: crypto.randomUUID() },
  react: createElement(VerifyEmail, { locale, messages, name: user.name, verifyUrl: verifyUrl.toString() }),
  subject: createTranslator({ locale, messages })("subject"),
  to: user.email,
})
```
