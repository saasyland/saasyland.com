## AIコーディングエージェントとは?

AIコーディングエージェントは、コードベースを読み取り、変更を計画し、ファイルを編集し、コマンドを実行し、各ステップを運転することなく結果に反応するプログラムです。 これは、オートコンプリートアシスタントから分離するものです。エージェントは、テスト、タイプチェッカー、ビルドを実行することで、独自のループを閉じて、それらが返すものから修正します。

最後の句は、この記事の主題全体です。 エージェントの天井は、観察できる信号の品質と遅延によって設定されます。 ベンチマークやスコアの悪いモデルでよく評価するモデルは、両方とも自信を持って作ります, 聖書的, バック言うことのないリポジトリの間違ったコード.

### 3つの失敗モード

各研究は、同じ欠落信号の異なる症状を測定しています。 それらを浪費すると、それらをハントしやすくなります。

**可塑性漂流。** エージェントは、正しく読み込まれるコードを生成し、あなたの命名規則を使用し、間違ったことをします。 これは、開発者の45%が最上位の不満と名付けられた「最も右」カテゴリです。 リポジトリがそれに同意しないので、それは生き残ります。 変更を書くよりもコストがかかる見直しは、誤った答えが誤った答えよりも拒否するのが難しいためです。

**無声複製。** エージェントはヘルパーを必要とし、すでに持っているものを見つけることができません。 すべての機能でマルチプライし、GitClearの81%が2023上の重複したブロックで上昇します。 重複したブロックはスタイルの苦情ではありません:研究は、クローンされたコードをと関連付けます **15% から 50% 以上の欠陥**. . エージェントは重複することを選択しませんでした。 元の存在は観察できませんでした。

**秘密の回帰。** 変更は、チェックが存在したり、マージしたり、チェックを隠さないものを破ったりします。 DORA の 7.2% の安定性は 1 つの事件として表現されます。 出力バラ、ゲートが動かなかったので、テストされていない変更は時間の単位ごとの生産に達しました。

3つすべて同じルートを持っています。 エージェントは、「いいえ」に十分な速さ、またはまったく言うことができません。

## いいえまでの時間:エージェントの出力品質を予測するメトリック

**リポジトリが変更が間違っているAIコーディングエージェントに伝える時間がかかりません。** エージェントが指示する自動信号の瞬間に書き込みを停止する瞬間からそれを測定します。 厳密なタイプ、カバレッジゲートおよび1つの検証コマンドを持つリポジトリは秒単位で応答します。 コードレビューや制作、あるいは決して答えないリポジトリ。

エージェントのループが構造化されているため、問題ありません。 エージェントが提案し、観察し、修正します。 観察に対してのみ補正が可能です。 **独自の実行中**. . エージェントのフィードバックではないよりも遅くなります。 あなたのためのクリーンアップです。

<Step>

</Step>

<Step>

</Step>

### コンテキスト: エージェントは真実を見つけることができますか?

**1。 1。 エージェントの指示ファイルが存在し、現在の状態です。**

`AGENTS.md` OpenAI、Google、Cursor、Factoryから参加して2025年8月にオープン仕様として正式化し、Linux Foundationの有能AI財団に12月2025日に寄贈し、現在、6万以上の公共リポジトリに出荷され、30以上のエージェントが読み込まれています。

- **0**: 指示ファイルはありません。 エージェントはゼロから始まり、どのファイルからでも開いているかを調べます。
- **1**: ファイルが存在しますが、エージェントが解釈しなければならないか、現実から漂流しているかを推測します。
- **2**: コマンド、境界線、慣行を200行以下で記述し、腐敗することはできません。 CI 名前と同じコマンドを実行します。

**2。 タイプは、装飾ではなく契約です。**

- **0**: `any` 共通です。 外部データは、システムが無効化されていない状態で入力します。
- **1**: Strict TypeScript, しかし、境界線 (HTTP ボディ, 環境変数, webhook ペイロード, データベース行) は解析ではなく信頼されます。
- **2**: なしの厳密な TypeScript `any`、およびあらゆる外部境界の回路図検証。 間違った形状は、フィールドを命名するメッセージで、2秒以内にエッジで失敗します。

**3。 各パターンの1つのcanonical例は正確にあります。**

エージェントは、最も近い隣接する模造によって動作します。 彼らが見つけることができる最も近いものをコピーします。 リポジトリにデータを取得するための3つの方法が含まれている場合、エージェントはランダムで1つを選び、必要なものの3つのチャンスがあります。

- **0**: 同じ仕事のための複数の競争パターン、すべての活動的な使用。
- **1**: 何も強制しない文書化された優先順位。
- **2**: 1パターンあたりの例を実装するので、最も近い隣人は常に正しい隣人です。

### 検証:リポジトリはノーと言うことができますか?

**4。 1つのコマンドはすべてを実行します。**

- **0**: 特定の順序でステップを記述するREADME段落。
- **1**: 複数のスクリプトで、いつ実行するかを知る必要があります。
- **2**: 型チェック、整列、テスト、レポート、 0 または 1 を終了する単一のコマンド。 エージェントは、どのように言うことなく、それを実行することができます。

**5。 5。 カバレッジは、報告ではなく、ゲートです。**

- **0**:カバレッジ測定なし。
- **1**: カバレッジが測定され、誰もマージをブロックしないバッジに表示されます。
- **2**: ビルドに失敗するしきい値。 テストのない新しい動作はマージできません。つまり、エージェントが望まれる場合でも、未テストの動作を追加することはできません。

**6。 。 重要なパスは、実際のブラウザで実行されます。**

- **0**: エンドツーエンドのテストはありません。
- **1**: jsdom または mocked 環境のみ、実際のものが壊れている間に渡します。
- **2**: 実際のブラウザエンジンは、サインアップ、チェックアウト、およびWebhookパスを促進します。

**7。 7。 型チェックはゼロ許容です。**

- **0**: タイプのエラーは通常のバックグラウンドノイズです。
- **1**: エラーはバックログに追跡されます。
- **2**: 1つのエラーは、非ゼロを終了し、マージをブロックします。 エージェントはバイナリ信号に応答します。 「ビットをあきらめる」というカウントは信号ではありません。

### ターミナルネイティブエージェント

**例:Claudeコード、OpenAI Codex CLI、OpenCode、Aider。**

シェルのシェルの許可を得て、シェルのプロセスとして実行します。 コンテキストアセンブリは、周囲ではなく有効です。エージェントは実行します `grep`ファイルを開き、テストコマンドを実行し、戻ってくるものを読み込みます。 ツーリングがどこに住んでいるかは、検証ループを最も直接閉じるからです。 ワンコンマンド認証があれば、ターミナルエージェントは2回も尋ねずに使います。

### IDEネイティブエージェント

### 実際に属するもの

## Verify before you claim done

Run `bun run verify`. It type-checks, lints, tests and enforces
100% coverage. Exit code 0 means done. Nothing else does.

## Architecture

Dependencies flow one way: presentation -> application -> domain.
The domain layer imports nothing from the other two. This is
enforced by an import boundary rule, so a violation fails the build.

## Conventions

- Strict TypeScript. No `any`, no non-null assertions.
- Validate every external boundary with a Zod schema: HTTP bodies,
  environment variables, webhook payloads.
- New behaviour needs a test in the same commit. The coverage
  gate will reject it otherwise.
- Copy the nearest existing module. There is exactly one example
  of each pattern and it is the correct one.

## よくある質問

<Accordions>

<Accordion title={"2026年にAIのコーディングエージェントが最適ですか?"}>

ひとつのベストエージェントはありませんし、正直な答えは、問題が聞こえるよりも重要ではないことです。 2026年1月現在、GitHub Copilotは29%の職場採用を率い、18%で結ばれるカーサールとクロードコードを率いています。 ハーネスフィット:マルチファイルワークのターミナルネイティブ、インクリメンタルワークのIDEネイティブ、上記のスコアカードで17以上のレポジトリが得た場合にのみ委任されます。

</Accordion>

<Accordion title={"AI のコーディングエージェントは、実際に開発者がより速くなりますか?"}>

信頼性はなく、条件ではほとんどのチームが作業しています。 METRのランダム化された制御試験は、16人の経験豊富な開発者が、自分の成熟したリポジトリ内の実際のタスクで19%遅く、彼らは20%高速だったと信じていました。 リポジトリが誤った変更を自動的に拒否できるときの速度が現れます。 それなしで、出力が上昇し、スループットはしません。

</Accordion>

<Accordion title={"なぜAIコーディングエージェントは、ほぼ正しいコードを生成し続けるのですか?"}>

あなたのリポジトリに矛盾しないので、それを矛盾させます。 エージェントは、それが観察できるものを最適化し、利用可能な信号が「これは周囲のコードのように見える」場合、それは周囲のコードのようなコードを生成し、間違ったことを行います。 調査した開発者の45%の最上位の不満です。 時間の短縮とカテゴリーの縮小。

</Accordion>

<Accordion title={"AGENTS.md とは何ですか?"}>

`AGENTS.md` コマンド、境界、慣行のコーディングエージェントを指示するリポジトリのルートでマークダウンファイルです。 2025年12月、Linux FoundationのAgentic AI Foundationに寄贈され、6万を超える公共リポジトリに出荷され、30以上のエージェントが読み込まれました。 はい、あなたは1つが必要で、真に滞在するのに十分短くなければなりません。

</Accordion>

<Accordion title={"AGENTS.mdとCLAUDE.mdを持っている必要がありますか?"}>

1つのファイルをリアルに保ち、他の人がそれを指摘させます。 1ヶ月以内に重複した命令ファイルと、その翌々のストールファイルに従うエージェントが自信をもってフォローします。 すべて入れる `AGENTS.md`, ツール固有のファイルのみを本物ツール固有の動作に使用する.

</Accordion>

<Accordion title={"AI支援開発に100%の試験カバレッジが問題ですか?"}>

エージェントの前でやったことよりも、通常の議論に関係しない理由で重要である。 ビルドに失敗するカバレッジのしきい値は、エージェントがルーティングできないルールです。テストを追加せずに動作を追加することはできません。 バッジとしてのカバレッジは何もしません。 ゲートとしてのカバレッジは、レビューの負担をゼロにコストするビルド失敗に変換します。

</Accordion>

<Accordion title={"AI エージェントが SaaS のボイラープレートをビルドできますか?"}>

すると、結果が右に見えます。 Webhook が重要でない、または i18n のパーリティチェックをしないと、それがスキップしたエッジのケースは、それが欠けている翻訳をキャッチしているかどうかをお伝えしません。 エージェントの出力は、それをレビューしたチェックと空のリポジトリには、どれも信頼できるものだけです。

</Accordion>

<Accordion title={"どのエージェントが大きなコードベースを最もよく扱うか?"}>

質問は、主にエージェントではなくコンテキストアセンブリに解決します。 積極的に検索するエージェント(実行) `grep`, ファイルの開き, インポートの次の) あなたの既存のヘルパーを見つけます. 周囲のエディタのコンテキストに依存するエージェントは、開いているものを見つけます。 大規模なリポジトリでは、差が重複として表示され、スコアカードで3つをチェックする理由は、パターンごとに1つの正当な例で、コードベースが成長するにつれてより重要になります。

</Accordion>

<Accordion title={"エージェントがマイグレーションやシークレットに触れないようにするにはどうすればよいですか?"}>

パスの名前 `AGENTS.md` 人間のみとして、信頼ではなく CI でそれを返します。 指示ファイルは、意図的に設定します。ブランチ保護、それらのパスの必要なレビュー、および失敗するビルドは、それを強制します。 間違いが不可逆であるか、または高価なが両方の場所で属するあらゆる表面。

</Accordion>

<Accordion title={"より良い結果を得るためにエージェントを切り替える価値はありますか?"}>

スイッチングは、次のモデルが出荷されるたびにリセットする提案品質で一回変化します。 間違った提案が何に達しているか変更無しにあなたの時間を下げることはあなたが使用するすべての代理店および混合物に適用します。 第2回目は行います。 その後、選択について間違っているコストが低いため、好きなようにエージェントを頻繁に切り替えます。

</Accordion>
