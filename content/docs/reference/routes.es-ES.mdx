title: "Rutas"
description: "Todas las rutas de páginas y de la API, con su constante de ROUTES, su archivo de ruta y su guard."
---

Cada ruta tiene una constante en `ROUTES` (`src/routes.ts`). Los enlaces usan la constante, por ejemplo `<Link to={ROUTES.SIGN_IN}>`, y el router añade el prefijo de locale. Cada una de las páginas siguientes se sirve también bajo todos los prefijos de locale distintos del predeterminado, por ejemplo `/pl-PL/terms`.

## Páginas públicas

Estas páginas usan el layout `_landing` (navegación y pie de página), excepto el blog y la documentación, que tienen sus propios layouts. Todas se prerenderizan salvo las páginas de la newsletter.

| Ruta                      | Constante                | Archivo de ruta                       |
| ------------------------- | ------------------------ | ------------------------------------- |
| `/`                       | `HOME`                   | `_landing.index.tsx`                  |
| `/premium`                | `PREMIUM`                | `_landing.premium.tsx`                |
| `/licence`                | `LICENCE`                | `_landing.licence.tsx`                |
| `/privacy`                | `PRIVACY`                | `_landing.privacy.tsx`                |
| `/terms`                  | `TERMS`                  | `_landing.terms.tsx`                  |
| `/refunds`                | `REFUNDS`                | `_landing.refunds.tsx`                |
| `/newsletter/confirm`     | `NEWSLETTER_CONFIRM`     | `_landing.newsletter.confirm.tsx`     |
| `/newsletter/unsubscribe` | `NEWSLETTER_UNSUBSCRIBE` | `_landing.newsletter.unsubscribe.tsx` |
| `/blog`                   | `BLOG`                   | `blog.tsx`, `blog.index.tsx`          |
| `/blog/*`                 | ninguna                  | `blog.$.tsx`                          |
| `/docs`                   | `DOCS`                   | `docs.tsx`, `docs.index.tsx`          |
| `/docs/*`                 | ninguna                  | `docs.$.tsx`                          |

## API

Las rutas de la API nunca se localizan.

| Ruta          | Constante       | Archivo de ruta |
| ------------- | --------------- | --------------- |
| `/api`        | `API`           | `api/index.ts`  |
| `/api/auth/*` | `API_AUTH_BASE` | `api/auth.$.ts` |
| `/api/search` | ninguna         | `api/search.ts` |

`ROUTES.API_AUTH` enumera las rutas de los endpoints de Better Auth relativas a `/api/auth`; `auth.server.ts` las usa para eximir endpoints de la limitación de peticiones. `API_AUTH_CUSTOMER_PORTAL` y `API_AUTH_VERIFY_EMAIL` son rutas completas a endpoints de Better Auth. `AUTH` y `NEWSLETTER` no tienen página propia; junto con `ADMIN`, `APP` y `API`, marcan las áreas que nunca se prerenderizan.
