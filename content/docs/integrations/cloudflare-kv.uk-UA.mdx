`env.CACHE` зберігає громадськість, одноразові записи кешу. GitHub інтеграція кеш-повідомлень з ТТЛ і використання `waitUntil` для запису кешу. Якщо GitHub або KV є недоступним.

KV в кінцевому підсумку послідовно. Ауттентифікаційні сесії та ліміти ставок, що живуть в D1. Лімітатор дії використовує один анатомічний SQL upsert на ключ і часове вікно, тому запити, які керуються окремими екземплярами Worker, поділяють той же ліміт. Не використовуйте KV лічильники для авторизації або чутливих обмежень.
