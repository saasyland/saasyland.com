---
title: Sobre mí
description: ¿Qué es SaaSy Land y para quién es?
---

SaaSy Land 2.0 es un **kit de inicio para SaaS** de código abierto, mantenido como un código base de un producto real: modular, con tipado y con criterios definidos en cuanto a límites.

Es ideal para equipos que buscan meses de autenticación, administración, i18n y tareas básicas de la plataforma, sin tener que lidiar con una estructura de código inicial (boilerplate) difícil de mantener.
