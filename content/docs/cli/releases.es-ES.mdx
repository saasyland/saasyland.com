La CLI `saasyland`, `create-saasyland` y `@saasyland/stack` se publican juntos con un mismo número de versión, y cada versión preliminar de abajo se publicó en la etiqueta `beta` de npm. La [guía de la CLI](/docs/cli) describe la versión actual, y el [registro de cambios](/docs/project/changelog) recoge los cambios de este sitio web.

## 0.1.0-beta.1

### saasyland

- `saasyland activate` activa su clave de licencia en este dispositivo: pase la clave como argumento o en <RepositoryFact name="cliLicenseKeyVariable" />, o escríbala cuando se le pida; queda oculta mientras escribe. `saasyland whoami` muestra su nivel, las activaciones en uso y el nombre de este dispositivo, y `saasyland deactivate` libera la activación de este dispositivo.
- La licencia se guarda en un archivo de su directorio de configuración que solo puede leer su usuario, todas las ejecuciones de un mismo repositorio de CI comparten una activación, y una licencia reembolsada o revocada se elimina del dispositivo.
- Los tres imprimen su resultado como un único documento JSON con `--json` y ya no aceptan `--cwd` ni `--dry-run`, que nunca se aplicaban a ellos.

### create-saasyland

Sin cambios en esta versión.

### @saasyland/stack

- `@saasyland/stack/api` limita una versión de la CLI y una release a `API_LIMIT.VERSION_MAX_LENGTH` caracteres, de modo que la API de licencias responde a una más larga con `invalidRequest`, como a cualquier otro campo mal formado.

## 0.1.0-beta.0

### saasyland

- Primera versión preliminar de la CLI `saasyland`. `saasyland --help` enumera todos los comandos, y `saasyland init --help` enumera cada opción del stack como un flag.
- Los flags se comprueban antes de ejecutar nada: un valor desconocido o una combinación que no puede funcionar, como `--provider neon` sin `--db postgres`, se rechaza con el motivo y el código de salida <RepositoryFact name="cliExitUsage" />.
- La salida está disponible en inglés, alemán, español, francés, italiano, japonés, polaco, portugués de Brasil y ucraniano, según `--locale` o el idioma de su sistema, y `--json` imprime un único documento JSON para scripts y agentes de programación.
- La generación de proyectos y la activación de licencias llegan en las siguientes versiones preliminares; hasta entonces, esos comandos lo indican y terminan con el código <RepositoryFact name="cliExitNotAvailable" />.

### create-saasyland

- Primera versión preliminar de `create-saasyland`: `npm create saasyland`, `bun create saasyland`, `pnpm create saasyland` y `yarn create saasyland` ejecutan `saasyland init` con los mismos flags.

### @saasyland/stack

- Nuevo punto de entrada: `@saasyland/stack/api`, el contrato de la API de licencias de saasyland.com a la que llama la CLI `saasyland`. Define las rutas de <RepositoryFact name="cliApiBasePath" />, las cabeceras, los esquemas de peticiones y respuestas, los códigos de error y los límites, y construye y lee cada petición y cada respuesta. Importar solo `@saasyland/stack` no carga nada de ello.
