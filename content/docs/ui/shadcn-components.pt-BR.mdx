As primitivas em `src/presentation/components/shadcn/` são componentes shadcn/ui construídos sobre React Aria Components. `input-otp`, `carousel`, `resizable`, `chart` e `sonner` encapsulam outras bibliotecas; as demais seguem o React Aria. `components.json` aponta o alias `ui` para esta pasta e `utils` para `~/src/lib/cn`. As telas importam as primitivas diretamente; não há componentes wrapper em volta delas.

## Props do React Aria

| Hábito do DOM ou do Radix     | Use aqui                              |
| ----------------------------- | ------------------------------------- |
| `onClick`                     | `onPress`                             |
| `disabled`                    | `isDisabled`                          |
| `open` em um diálogo          | `isOpen` com `onOpenChange`           |
| `checked`                     | `isSelected`                          |
| `value` em abas               | `selectedKey` ou `defaultSelectedKey` |
| `onSelect` em um item de menu | `onAction`                            |

`Input` mantém o evento nativo `onChange`. `Select` aceita um `fieldLabel` que renderiza o rótulo.

## Convenções

- **Botões pendentes**: passe o estado da mutação para `Button`: `<Button isPending={mutation.isPending} type="submit">`.
- **Links**: `LinkButton`, `TabsTrigger` e `SidebarMenuButton` aceitam um `href`. `AriaProvider` os encaminha pelo TanStack Router e adiciona o prefixo de idioma. Para dar aparência de botão a outros elementos, use `buttonVariants`.
- **Formulários**: `Field`, `FieldGroup`, `FieldLabel`, `Input` e `ValidationFieldError` com TanStack Form, como neste campo de `ResetPasswordDialog`:

```tsx
<Field data-invalid={isInvalid}>
  <FieldLabel htmlFor={passwordId}>{t("resetPasswordDialog.password")}</FieldLabel>
  <Input
    aria-invalid={isInvalid}
    autoComplete="new-password"
    id={passwordId}
    name={field.name}
    onBlur={field.handleBlur}
    onChange={(event) => {
      field.handleChange(event.target.value)
    }}
    type="password"
    value={field.state.value}
  />
  {isInvalid && (
    <ValidationFieldError
      message={fieldErrorMessage(field.state.meta.errors)}
      namespace="auth.validations"
      params={AUTH_VALIDATION_PARAMS}
    />
  )}
</Field>
```

- **Diálogos**: `Dialog` e `AlertDialog` são controlados com `isOpen` e `onOpenChange`; cada diálogo fica no próprio arquivo, como `admin/users/delete-user-dialog.tsx`.
- **Menus**: `DropdownMenuTrigger` envolve o `Button` que o aciona e o `DropdownMenu`; os itens executam `onAction` e usam `variant="destructive"` para ações perigosas.
- **Notificações**: chame `toast.success` ou `toast.error` do `sonner`; a rota raiz renderiza o `Toaster` dentro de `ThemeProvider`.
- **Anéis de foco**: estilize os gatilhos do React Aria com variantes `data-focus-visible:`, como fazem `checkbox`, `select`, `switch` e `radio-group`.
- **Nomes de classe**: use `cn` de `~/src/lib/cn` com a sintaxe de objeto para classes condicionais.

## Tamanho do CSS

`globals.css` exclui da varredura de fontes do Tailwind as primitivas que nenhuma tela usa, por meio de uma lista `@source not`. Quando você começar a usar uma delas, remova-a dessa lista, ou as classes dela vão faltar.
