- サイトは CLI が現在できることを販売するようになりました。各プランのカードは `src/data/marketing.ts` の `TIER_FEATURES` から機能を **提供中** と **提供予定** に分けて並べ、各機能は `FEATURE_STATUS` を持ちます。現在の CLI は端末上のライセンスキーの有効化、表示、解放ができ、プロジェクト生成、動画コース、コード解説、Discord チャンネル、チーム席、Figma ファイル、無制限のプロジェクトは提供予定です。ランディングページ、`llms.txt`、ブログは、プロジェクト生成が今後のリリースで提供予定であることを伝え、ページデザイナー、管理画面からの価格・ブログ・ドキュメントの編集、構成ツールのその他の構成を提供中として示さなくなりました。構成ツールはプロジェクト生成の最初のリリースが書き出すデフォルト構成に印を付け、リード文は質問の数を数えなくなりました。各ブログ記事の FAQ は frontmatter に一度だけ書かれ、`<PostFaq>` がそれを表示し、FAQPage の JSON-LD がそれを読み取ります。価格、端末の上限、各種の数値は ICU 引数です。新しいページとして、概要のドキュメントカードから開く [CLI ガイド](/docs/cli)と、`0.1.0-beta.0` と `0.1.0-beta.1` の [CLI のリリースノート](/docs/cli/releases)を追加し、[ロードマップ](/docs/project/roadmap)に提供予定の内容を載せました。ジャーニースイートは CLI の変数、終了コード、認証情報ファイルを `src/data/cli.ts` から取得し、動画 `scaffold-cli` はコマンドを `CLI_PACKAGE_SPEC` から入力します。アドバンテージは手入力ではなく算出されるようになりました。`src/data/head-start.ts` は生成されるデフォルトプロジェクトの内容を、行ごとのテンプレートレイヤーと手作業の時間の下限・上限とともに列挙し、Hero、Manifesto、Gate は `headStartHours` を表示します。これは下限の合計を切り捨て、サイトがこれまで掲げていた <RepositoryFact name="headStartClaimMaxHours" /> 時間を超えないよう上限を設けた値です。ShipFast と Better-T-Stack の記事は、プロジェクトに含まれない組織、マルチテナント、課金を数えていた表の代わりに `<HeadStartTable />` でこれらの行を表示し、Manifesto は課金に触れなくなり、ポーランド語の締めの一文は表記が一つにそろいました。ランディングページとプランのカードはカバレッジの数値を `coverageThreshold` から表示し、reactprojects.com の数値と価格の試算の時給は `src/data/marketing.ts` で一度だけ宣言され、そこから Core の価格が下回る時間数を計算します。事例セクションは reactprojects.com を、リンクなしの「リリース時に公開」として、同じスタックで動く本番品質の React ビルド 5 本の講座プラットフォームと紹介します。これは同サイト自身の説明どおりです。ランディングページのタイトル、説明、`llms.txt` は、SaaSy Land を TanStack Start 専用のキットとして示さなくなりました。TanStack Start は最初のスタックとして示し、説明には現在キットに含まれるものだけを、言語数とカバレッジのしきい値をコードから取って記載します。リリース記事のタイトルからもフレームワーク名を外しました。[ランディングページ](/docs/features/landing-page)を参照してください。
