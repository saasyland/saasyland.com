---
title: "管理画面のページを追加する"
description: "新しい管理画面ページのルート、サイドバーの項目、メッセージ、ウィジェットを登録します。"
---

管理画面のページは、`/admin` レイアウト（`src/routes/admin.tsx`）の下にあるフラットなルートファイルです。このレイアウトは `beforeLoad` で `requireAdmin` を実行し、サイドバー、パンくずリスト、コマンドパレットをレンダリングします。以下の手順では `/admin/reports` にページを追加します。完全な実例は `src/routes/admin.orders.index.tsx` です。

## 1. パスを追加する

パスを `src/routes.ts` のアルファベット順の位置に宣言します。これで `ROUTES` にパスが入ります。

```ts
export const ADMIN_REPORTS = "/admin/reports"
```

プロジェクトが外せるエリアに属するページなら、`scripts/areas.ts` のそのエリアの `names` にもその名前を追加します。こうすると `bun run check:areas` が、エリアと一緒に、そのパスとそれを名指しするすべての項目を削除します。

## 2. ルートファイルを作成する

`src/routes/admin.reports.tsx` を作成します。ルートが定義するのは、ページコンポーネント、`NAMESPACE`、ローダー、`head`、`pendingComponent` だけです。ルータージェネレーターがこのファイルを `src/routeTree.gen.ts` に登録します。

```tsx
import type { JSX } from "react"

import { createFileRoute } from "@tanstack/react-router"
import { useTranslations } from "use-intl/react"

import { loadPageMetadata, preloadNamespaces } from "~/src/integrations/use-intl/i18n.messages"
import { getCurrentLocale } from "~/src/integrations/use-intl/i18n.utils"

import { pageHead } from "~/src/lib/seo"

import { AdminPageHeader } from "~/src/presentation/components/custom/admin/admin-page-header"
import { AdminReportsPending } from "~/src/presentation/components/custom/admin/reports-pending"
import { ReportStats } from "~/src/presentation/components/custom/admin/reports/report-stats"

import * as ROUTES from "~/src/routes"

const ReportsPage = (): JSX.Element => {
  const t = useTranslations("pages.admin.reports")

  return (
    <div className="flex w-full flex-col space-y-8">
      <AdminPageHeader description={t("metadata.description")} title={t("metadata.title")} />

      <ReportStats />
    </div>
  )
}

const NAMESPACE = "pages.admin.reports"

export const Route = createFileRoute("/admin/reports")({
  component: ReportsPage,
  head: pageHead(ROUTES.ADMIN_REPORTS),
  loader: async ({ context }) => {
    const locale = getCurrentLocale()
    const [metadata] = await Promise.all([
      loadPageMetadata({ locale, namespace: NAMESPACE }),
      preloadNamespaces({ locale, namespaces: [NAMESPACE], queryClient: context.queryClient }),
    ])
    return { locale, metadata }
  },
  pendingComponent: AdminReportsPending,
  staticData: { namespaces: [NAMESPACE] },
})
```

ページに必要なクエリは、同じ `Promise.all` に入れます。例えば `src/routes/admin.users.all.tsx` では `context.queryClient.query({ ...getUsersQuery, staleTime: "static" })` を使っています。`pageHead` は、ローダーの `metadata` からタイトル、説明、正規 URL、代替ロケールへのリンクを組み立てます。`AdminReportsPending` はこのページ専用のスケルトンで、ナビゲーションに <RepositoryFact name="navigationPendingMs" unit="millisecond" /> より長くかかった場合にだけ表示されます。このスケルトンは、エリアのスケルトンファイル（ここでは新しい `custom/admin/reports-pending.tsx`）に、ヘッダーには `admin-page-header.tsx` の `AdminPageHeaderPending` を、それ以外には `pending-blocks.tsx` のブロックを組み合わせて、ページのレイアウトを再現するように書きます。管理画面レイアウトのスケルトンはルートからこのスケルトンを読み取るので、管理エリアの外から `/admin/reports` に入ったときにも表示されます。

[読み込み中のスケルトン](/docs/architecture/delivery-layer#loading-skeletons) を参照してください。

## 3. サイドバーの項目を追加する

`ADMIN_NAVIGATION`（`src/data/navigation.ts`）で、項目を表示したい位置、たとえば概要のグループのダッシュボードの後に、そのサイドバーのグループの `items` へ項目を追加します。項目には、`lucide-react` のアイコン、ラベルの完全なキー、パスを指定します。

```ts
{ icon: FileText, label: "navigation.reports.admin.reports", to: ROUTES.ADMIN_REPORTS },
```

すべてのロケールで、`messages/<locale>/navigation.reports.json` に `admin.reports` としてラベルを追加します。新しいグループには、`ADMIN_NAVIGATION_GROUP` の値、`ADMIN_NAVIGATION` のグループの中での位置、`pages.admin.sidebar` の `groups.<group>` も必要です。サイドバー、パンくずリスト、⌘K コマンドパレットはいずれも `ADMIN_NAVIGATION`（`src/data/navigation.ts`）を読み取るため、ページはこの 3 つすべてに表示されます。ランディングページはこのページを管理画面のセクションの 1 つとして数え、ランディングページの動画 `app-tour` の管理画面のレールには、動画を再レンダリングした後に表示されます（`remotion/README.md` を参照）。`/admin/reports/create` のような 3 番目の URL セグメントには、`breadcrumbs: { create: "navigation.reports.breadcrumbs.create" }` のように項目の `breadcrumbs` がラベルを指定していればパンくずが表示され、指定していなければ 3 番目のパンくずは表示されません。

## 4. ページのメッセージを追加する

すべてのロケールに `messages/<locale>/pages.admin.reports.json` を作成します。ローダーがドキュメントの head のために読み取るため、`metadata` は必須です。

```json
{
  "metadata": {
    "title": "Reports",
    "description": "Revenue and usage reports."
  }
}
```

## 5. ウィジェットを追加する

ウィジェット、ダイアログ、フォーム、テーブルのカラム定義は、それぞれ `src/presentation/components/custom/admin/reports/` 配下の個別のファイルに置きます。例えば `report-stats.tsx` や `report-columns.tsx` です。ウィジェットは `useTranslations("pages.admin.reports")` を呼び出し、自分のデータを `useSuspenseQuery` で読み取ります。ページはラベルもデータも渡しません。テーブルには `DataGrid` を使います。[データグリッドを追加する](/docs/guides/add-a-data-table) を参照してください。

## 6. 保護とテスト

- ページへのアクセスはレイアウトのガードが保護します。それでも、ページが呼び出すすべてのサーバー関数には `authorized(permission)` が必要です。[ロールと権限](/docs/guides/roles-and-permissions) を参照してください。
- `/admin` はプリレンダリングの対象外です。
- エリアのルートのテストは `src/routes/__test__/admin-<area>-routes.component.test.tsx` と `admin-<area>-loaders.test.ts` に、ウィジェットのテストは `src/presentation/components/custom/admin/__test__/` に追加し、ページを `e2e/data/<area>.pages.ts` に加えて、`bun run check:i18n` と `bun run test:coverage` を実行します。
