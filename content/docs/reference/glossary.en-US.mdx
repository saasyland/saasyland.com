---
title: "Glossary"
description: "Terms used throughout the SaaSy Land documentation."
---

- **AppError:** the single error class for server functions, carrying one of the `ERROR_CODES`.
- **Binding:** a Cloudflare resource passed to the Worker: `DB` (D1), `CACHE` (KV) or `ASSETS` (static assets).
- **Guard:** a `beforeLoad` function such as `requireAdmin` that redirects before a route loads.
- **Integration:** a folder in `src/integrations` that configures one vendor, such as Better Auth or Resend.
- **Layout route:** a route that renders an `Outlet` for its child routes and declares shared `NAMESPACES`, for example `admin.tsx`.
- **Locale prefix:** the `/<locale>` path segment for every locale except en-US, for example `/pl-PL`.
- **Middleware:** a function that runs before a server function handler: `withRequest`, `authorized` or `withRateLimit`.
- **Module:** a folder in `src/modules` that owns one database table and its use cases.
- **Mutation options:** the `mutationOptions` object exported next to a server function that changes data.
- **Namespace:** one translation file, named by its file name, for example `pages.admin.users`.
- **Page route:** a route that renders a page and declares one `NAMESPACE`.
- **Prerendering:** rendering public pages to HTML at build time so the Worker can serve them as static assets.
- **Query options:** the `queryOptions` object exported next to a server function that reads data. Loaders and components share it.
- **Root namespaces:** `common`, `components.*` and `errors*`, preloaded for every page.
- **Server function:** a typed RPC operation created with `createServerFn` that always runs on the server.
- **Use case:** one operation on a module's table, in `use-cases/<verb>-<noun>.ts`.
- **Wrangler environment:** one of `development`, `preview`, `production` or `test` in `wrangler.jsonc`, each with its own bindings and secrets.
