---
title: "Instalación"
description: "Instale las dependencias y genere los archivos locales."
---

Clone el repositorio y, a continuación, instale las dependencias desde su raíz con el lockfile incluido en el repositorio:

```sh
bun install --frozen-lockfile
```

A continuación, el script de ciclo de vida `prepare`:

1. Ejecuta `vp config --no-agent`, que instala el despachador de hooks de Git para `.vite-hooks/` (las comprobaciones de pre-commit y el hook del mensaje de commit).
2. Ejecuta `bun run generate:cn`, que genera las tablas de fusión de clases en `.source/cn-tables.ts`.
3. Ejecuta `bun run content`, que genera las colecciones de Fumadocs en `.source/`.

Si instala con `--ignore-scripts`, como hace la CI, ejecute después `bun run typegen`. Este comando también regenera `src/types/worker-configuration.d.ts` a partir de `wrangler.jsonc`.

## Extras opcionales

```sh
bun run test:e2e:install
bun run skills:sync
```

El primero instala Chromium y WebKit para Playwright; el segundo restaura las [skills para agentes](/docs/tooling/agent-skills).
