Il repository usa Bun come gestore di pacchetti ed esecutore di script e Vite+ (`vp`) per il server di sviluppo, le build, i test, il linting e la formattazione. Wrangler gestisce gli ambienti Cloudflare e le migrazioni, e Playwright esegue i test nel browser.

## In questo capitolo

- [Ambiente e binding](/docs/tooling/environment): ambienti Wrangler, secret e file di ambiente
- [Migrazioni del database](/docs/tooling/database): generare, applicare e ispezionare le migrazioni D1
- [Test](/docs/tooling/testing): progetti Vitest, helper e la soglia di copertura al 100%
- [Lint e formattazione](/docs/tooling/lint-format): oxlint, oxfmt e gli script di controllo
- [Vite+](/docs/tooling/vite-plus): la toolchain `vp` e i plugin
- [Playwright](/docs/tooling/playwright): test nel browser sul Worker di test isolato
- [Skill per agenti](/docs/tooling/agent-skills): skill dei fornitori per gli agenti di programmazione
- [CI/CD](/docs/tooling/ci-cd): controlli e deploy con GitHub Actions
- [Script del progetto](/docs/tooling/scripts): tutti gli script di `package.json`
- [Graphify](/docs/tooling/graphify): un knowledge graph facoltativo del codice
- [Conventional commits](/docs/tooling/conventional-commits): formato dei commit e hook delle emoji
