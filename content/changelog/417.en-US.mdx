- Changed: the admin dashboard, the products page, the billing page and the lessons send their first bytes without waiting for their slow data. Each statistic, panel, product grid, billing history and video player fills its own skeleton as its data arrives, in the same response, and the finished pages look exactly as before. Pages wait for Polar's catalogue no longer. See [Streamed sections](/docs/conventions/routes#streamed-sections) and [Performance](/docs/conventions/performance#request-rendered-pages-stream-their-slow-sections).
- Changed: for a signed-in visitor, the header now loads only the code of the admin console or the workspace ahead of a click, instead of running its server functions on every page. See [Performance](/docs/conventions/performance#the-headers-pages-load-before-a-click).
- Fixed: a search engine's crawler now gets every streamed section, such as a lesson's player, in place in the HTML, instead of a skeleton and a hidden copy that only a script moves into place. A patch of TanStack Router holds its stream until the page is ready. See [Dependencies](/docs/conventions/dependencies).
