## Richiedere un link

`/auth/forgot-password` mostra `ForgotPasswordForm`. Chiama `requestPasswordReset` (`src/modules/verification/use-cases/request-password-reset.ts`, limitata con `RATE_LIMITS.SENSITIVE`) con `redirectTo` impostato su `/auth/reset-password` nella lingua corrente. Better Auth chiama poi `sendResetPasswordEmail`, che invia il template `ResetPasswordEmail`.

## Impostare una nuova password

Il link ricevuto via email apre `/auth/reset-password?token=…`. Senza token, o con `?error=`, la pagina mostra il messaggio di link non valido e un link per tornare a `/auth/forgot-password`. Con un token, `ResetPasswordForm` chiama `resetPassword` (limitata con `RATE_LIMITS.TOKEN`) e naviga verso `/auth/sign-in`. Poiché `revokeSessionsOnPasswordReset` è attivo, tutte le sessioni esistenti di quell’utente terminano.

## Altri cambi di password

- Gli utenti autenticati cambiano la password in **Impostazioni → Sicurezza** ([Impostazioni](/docs/features/settings)).
- Gli amministratori impostano la password di un altro utente dalla tabella utenti ([Utenti (admin)](/docs/features/users-admin)).
