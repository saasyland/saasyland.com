title: "Añadir una cuadrícula de datos"
description: "Escribe un hook de columnas con filtros, columnas ocultas y fijadas y valores para el CSV, y renderízalo con DataGrid a partir de filas en el cliente o de una query en el servidor."
---

Todas las tablas nuevas se renderizan con `DataGrid` en `src/presentation/components/custom/data-grid.tsx` ([Cuadrícula de datos](/docs/ui/data-grid)). Trae la búsqueda, los filtros, la ordenación, el diseño que cada administrador puede reorganizar y conservar, la selección, la exportación a CSV, las filas esqueleto y los estados vacíos. Una tabla necesita un hook de columnas y un `<DataGrid />`. `/admin/orders` es el ejemplo completo: `src/presentation/components/custom/admin/payments/order-columns.tsx` y `src/routes/admin.orders.index.tsx`.

## 1. Escribe el hook de columnas

Crea `<entity>-columns.tsx` junto a los demás widgets de la página. Exporta un hook que lea las traducciones y los datos que ofrecen los filtros, y que devuelva las columnas memorizadas. Las celdas son componentes pequeños del mismo archivo que leen sus propias traducciones. Versión resumida de `order-columns.tsx`:

```tsx
const columnHelper = createColumnHelper<DataGridFeatures, OrderRow>()

export const useOrderColumns = (): DataGridColumn<OrderRow>[] => {
  const t = useTranslations()

  const { products } = useSuspenseQuery(orderFiltersQuery).data

  return useMemo(
    () =>
      columnHelper.columns([
        columnHelper.accessor("placedAt", {
          cell: PlacedCell,
          header: t("pages.admin.orders.table.headers.placedAt"),
          meta: { filter: { kind: DATA_GRID_FILTER.DATE_RANGE }, pinned: DATA_GRID_PIN.START },
          size: ORDER_COLUMN_SIZES.placedAt,
        }),
        columnHelper.accessor("description", {
          cell: ProductCell,
          enableSorting: false,
          header: t("pages.admin.orders.table.headers.product"),
          id: "product",
          meta: { filter: { kind: DATA_GRID_FILTER.MULTI_SELECT, options: products.map(({ id, name }) => ({ label: name, value: id })) } },
          size: ORDER_COLUMN_SIZES.product,
        }),
        columnHelper.accessor("refunded", {
          cell: RefundedCell,
          header: t("pages.admin.orders.table.headers.refundedAmount"),
          id: "refundedAmount",
          meta: { export: ({ refunded }) => exportedMoney(refunded), hidden: true },
          size: ORDER_COLUMN_SIZES.refundedAmount,
        }),
      ]),
    [products, t],
  )
}
```

- Las filas deben tener un `id` de tipo cadena, que se convierte en el identificador de fila para la selección.
- `header` es la etiqueta traducida como cadena. La cuadrícula la usa en la cabecera, los menús, los chips de filtro, sus anuncios y el CSV.
- `meta.filter` da a la columna un filtro de un tipo: <RepositoryFact name="dataGridFilterKinds" />. Una elección enumera sus `options` como `{ label, value }`.
- `meta.hidden` oculta la columna hasta que el administrador la muestra, `meta.pinned` la fija al `start` o al `end`, y `meta.export` escribe el texto de la columna en el CSV para una fila.
- `size` es el ancho inicial en píxeles. Guarda los tamaños en una constante en `src/data/<feature>.ts`, como `ORDER_COLUMN_SIZES` en `payments.ts`, para que el esqueleto de la ruta también pueda usarlos.
- Una columna por la que el servidor no puede ordenar fija `enableSorting: false`.

## 2. Renderízalo

Pasa las columnas, un `id` único, el `label` de la tabla y `data` o `query`:

```tsx
const OrdersPage = (): JSX.Element => {
  const t = useTranslations("pages.admin.orders")
  const columns = useOrderColumns()

  return (
    <DataGrid
      columns={columns}
      empty={t("empty")}
      id={ORDER_GRID_ID}
      label={t("title")}
      query={(request) => getOrdersPageQuery(orderZodSchemas.getOrders.parse(request))}
      search={t("filters.search")}
      selectable
    />
  )
}
```

Con `data`, la cuadrícula busca, filtra, ordena y pagina las filas en el navegador. Con `query`, envía `{ filters, pageIndex, pageSize, search, sorting }` y el servidor lo hace todo.

## 3. Lee la petición en el servidor

El esquema Zod del módulo toma la petición tal como llega. `filters` contiene las columnas filtradas por id con los valores descritos en [Cuadrícula de datos](/docs/ui/data-grid#filters), así que el esquema reutiliza los campos compartidos, de `src/modules/order/order.zod.ts`:

```ts
const orderFilters = zod.object({
  country: zod.array(countryCodeField).max(COUNTRY_CODES.length).optional(),
  customer: searchField.optional(),
  discount: idField.optional(),
  placedAt: dateRangeField.optional(),
  product: zod.array(idField).max(MAX_FILTER_VALUES).optional(),
  status: zod.array(choiceOf(ORDER_STATUSES)).max(ORDER_STATUSES.length).optional(),
  totalAmount: numberRangeField.optional(),
})

const getOrders = paginationSchema.extend({
  filters: orderFilters.default({}),
  search: searchField.default(""),
  sorting: sortingOf(ORDER_SORT_COLUMNS),
})
```

`numberRangeField`, `dateRangeField` y los límites `SEARCH_MAX_LENGTH`, `MAX_SORTED_COLUMNS` y `MAX_FILTER_VALUES` vienen de `src/modules/_core/utils/`, los mismos valores que usa la cuadrícula, de modo que el cuadro de búsqueda admite <RepositoryFact name="dataGridSearchMaxLength" /> caracteres y la cuadrícula ordena por hasta <RepositoryFact name="dataGridMaxSortedColumns" /> columnas. `getOrders` convierte cada filtro en SQL; un rango de importes compara cada pedido en su propia moneda con `inMinorUnits`.

Precarga la primera página en el loader de la ruta con `context.queryClient.query({ ...getOrdersQuery, staleTime: "static" })`; la primera petición de la cuadrícula se convierte en la misma clave de query.

## 4. Refléjalo en el esqueleto

El `pendingComponent` de la ruta renderiza `DataGridPending` de `data-grid-pending.tsx` con un esqueleto de celda y un ancho por cada columna visible, como hace `AdminOrdersPending` en `payments-pending.tsx`.

## 5. Mensajes

La barra de herramientas, los filtros, los menús, la paginación, la selección y los estados vacíos de la cuadrícula vienen de `components.custom.data-grid`, que cargan todas las páginas. Las etiquetas de columna, las opciones de filtro y el mensaje vacío pertenecen al espacio de nombres de la página, como `pages.admin.orders`.

Cuando una mutation cambia las filas, invalida las claves de query del módulo; la cuadrícula vuelve a cargar la página actual. Consulta [Añadir un caso de uso](/docs/guides/add-a-use-case).
