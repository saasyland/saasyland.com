---
title: Contributo
description: Come proporre modifiche all'avviamento.
---

1. Discutere grandi cambiamenti in un problema
2. Branch dalla linea principale
3. Seguire convenzioni + competenze
4. `bun run check` · test · costruzione
5. Aprire una PR con `feat`/`fix`/`docs` titolo

Mantenere pagine doc in sincronizzazione quando si aggiungono moduli o percorsi.
