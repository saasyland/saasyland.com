## Datos

`src/modules/category/category.schema.ts` define la tabla `category`: `name`, `description`, `kind` (`category` o `collection`), `visibility` (`public` o `hidden`), `icon` (`Archive`, `FolderOpen` o `Puzzle`) y marcas de tiempo.

Casos de uso en `src/modules/category/use-cases`, cada uno protegido por el permiso `category` correspondiente: `getCategories` (paginado, con `kind` opcional), `getCategory`, `createCategory`, `updateCategory` y `deleteCategory`. `createCategory` es la estructura de referencia para un caso de uso de mutación:

```ts
export const createCategory = createServerFn({ method: "POST" })
  .middleware([authorized({ category: ["create"] })])
  .validator((input: Category["createCategory"]) => categoryZodSchemas.createCategory.parse(input))
  .handler(({ data }) =>
    db
      .insert(category)
      .values({
        description: data.description ?? "",
        icon: data.icon ?? CATEGORY_ICON.FOLDER_OPEN,
        id: v7(),
        kind: data.kind,
        name: data.name,
        visibility: data.visibility ?? CATEGORY_VISIBILITY.PUBLIC,
      })
      .returning()
      .get(),
  )

export const createCategoryMutation = mutationOptions({
  mutationFn: (data: Category["createCategory"]) => createCategory({ data }),
  mutationKey: CATEGORY_MUTATION_KEYS.CREATE,
})
```

Los mensajes de error están en el espacio de nombres `category.errors`. Todavía ningún formulario edita categorías, así que sus mensajes de Zod tendrán un espacio de nombres `category.validations` con el primer formulario que los muestre.

## Pantalla de administración

Las pestañas **Categorías** y **Colecciones** de `/admin/products` muestran `CategoryGrid`, el `DataGrid` con `useCategoryColumns`, y `getCategoriesPageQuery` con el `kind` de la pestaña; el servidor busca en el nombre y la descripción, filtra por nombre, visibilidad y los días de creación y de modificación, y ordena por cada columna. Solo el listado está conectado: ninguna pantalla crea, edita ni elimina categorías. Los productos aún no tienen relación con las categorías, así que la tabla no muestra el número de elementos.
