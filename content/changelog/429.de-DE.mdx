Der Header lädt den Code der Dokumentation auf jeder Seite vor, und die Dokumentation gab die polnischen Begriffe, die die Glossarprüfung dem Leser überlässt, aus `glossary-terms.ts` aus, das beim Laden für jeden Glossarbegriff ein Muster kompiliert. Das Plugin `repositoryFacts` baut diese Begriffe und die Glossartabellen jetzt zur Build-Zeit, und die Tabellen, die nur die Dokumentation ausgibt, kommen aus einem eigenen Modul, `virtual:repository-tables`, statt aus dem Einstiegsskript jeder Seite, das mit gzip 26,0 KiB leichter ist. `scripts/verify-build.ts` lässt den Build fehlschlagen, wenn das Einstiegsskript sie wieder erreicht.
