- Modificato: un commento resta l’eccezione, ma quando serve davvero può essere una sola riga che, dopo poche parole, rimanda al punto in cui si trova il motivo: una pagina `https://` o un percorso `/docs/`. `code-style/no-comments` e `bun run check:comments` accettano questa forma e nient’altro. Vedi [Stile del codice](/docs/conventions/code-style#comments).
- Aggiunto: `bun run check:comments` legge anche i file YAML, e lì accetta solo il tag di versione dopo un’azione fissata a uno SHA di commit, come `# v4`.
