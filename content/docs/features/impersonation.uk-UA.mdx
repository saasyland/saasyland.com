## Статус

Випробувано через користувачів admin дії / use-cases з перевіркою дозволу.

## Правила

- Статус на сервери
- Очистити UI показання при порушенні
- Зареєструвати журнал перевірок, коли ви затвердили ops
- Ніколи не дозволяйте ескалації привілеїв за межами призначених робочих процесів підтримки
