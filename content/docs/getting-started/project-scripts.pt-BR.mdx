---
title: "Scripts do projeto"
description: "Os comandos que você usa todos os dias."
---

| Tarefa                                        | Comando                  |
| --------------------------------------------- | ------------------------ |
| Iniciar o servidor de desenvolvimento         | `bun run dev`            |
| Verificar formatação, lint, tipos e traduções | `bun run check`          |
| Executar todos os projetos do Vitest          | `bun run test`           |
| Executar a verificação de cobertura           | `bun run test:coverage`  |
| Executar o smoke test no navegador            | `bun run test:e2e:smoke` |
| Gerar uma migração                            | `bun run db:generate`    |
| Fazer o build do Worker de preview            | `bun run build`          |
| Servir o build mais recente                   | `bun run start`          |
| Fazer o deploy do preview                     | `bun run deploy:preview` |

Antes de abrir um pull request, execute a mesma sequência da CI:

```sh
bun run check
bun run test:coverage
bun run test:e2e:smoke
```

Use `bun run test`, e não `bun test`, para que o Vitest seja executado com o setup do projeto. Scripts que terminam com o nome de um ambiente, como `db:migrate:preview` ou `deploy:production`, atuam apenas nesse ambiente.

Veja [Scripts do projeto](/docs/tooling/scripts) para a lista completa.
