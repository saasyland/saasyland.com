title: "Routes"

Every path has a constant in `ROUTES` (`src/routes.ts`). Links use the constant, for example `<Link to={ROUTES.SIGN_IN}>`, and the router adds the locale prefix. Each page below is also served under every non-default locale prefix, for example `/pl-PL/terms`.

## Public pages

These pages use the `_landing` layout (navigation and footer), except blog and docs, which have their own layouts. All of them are prerendered except the newsletter pages.

| Path                      | Constant                 | Route file                            |
| ------------------------- | ------------------------ | ------------------------------------- |
| `/`                       | `HOME`                   | `_landing.index.tsx`                  |
| `/premium`                | `PREMIUM`                | `_landing.premium.tsx`                |
| `/licence`                | `LICENCE`                | `_landing.licence.tsx`                |
| `/privacy`                | `PRIVACY`                | `_landing.privacy.tsx`                |
| `/terms`                  | `TERMS`                  | `_landing.terms.tsx`                  |
| `/refunds`                | `REFUNDS`                | `_landing.refunds.tsx`                |
| `/affiliates`             | `AFFILIATES`             | `_landing.affiliates.tsx`             |
| `/newsletter/confirm`     | `NEWSLETTER_CONFIRM`     | `_landing.newsletter.confirm.tsx`     |
| `/newsletter/unsubscribe` | `NEWSLETTER_UNSUBSCRIBE` | `_landing.newsletter.unsubscribe.tsx` |
| `/blog`                   | `BLOG`                   | `blog.tsx`, `blog.index.tsx`          |
| `/blog/*`                 | none                     | `blog.$.tsx`                          |
| `/docs`                   | `DOCS`                   | `docs.tsx`, `docs.index.tsx`          |
| `/docs/*`                 | none                     | `docs.$.tsx`                          |

## Courses

The `/courses` layout (`courses.tsx`) has its own navigation and no guard: the server checks each lesson's access level (see [Courses](/docs/features/courses)). These pages read D1 on every request and are not prerendered.

| Path                         | Constant  | Route file                         |
| ---------------------------- | --------- | ---------------------------------- |
| `/courses`                   | `COURSES` | `courses.tsx`, `courses.index.tsx` |
| `/courses/<course>`          | none      | `courses.$course.index.tsx`        |
| `/courses/<course>/<lesson>` | none      | `courses.$course.$lesson.tsx`      |

## Authentication

The `/auth` layout (`auth.tsx`) has no guard; individual pages do.

| Path                    | Constant          | Route file                 | Guard                                                      |
| ----------------------- | ----------------- | -------------------------- | ---------------------------------------------------------- |
| `/auth/sign-in`         | `SIGN_IN`         | `auth.sign-in.tsx`         | `redirectIfSignedIn`                                       |
| `/auth/sign-up`         | `SIGN_UP`         | `auth.sign-up.tsx`         | `redirectIfSignedIn`                                       |
| `/auth/forgot-password` | `FORGOT_PASSWORD` | `auth.forgot-password.tsx` | none                                                       |
| `/auth/reset-password`  | `RESET_PASSWORD`  | `auth.reset-password.tsx`  | none                                                       |
| `/auth/two-factor`      | `TWO_FACTOR`      | `auth.two-factor.tsx`      | none                                                       |
| `/auth/verify-email`    | `VERIFY_EMAIL`    | `auth.verify-email.tsx`    | Redirects a `token` to Better Auth's verification endpoint |
| `/auth/callback`        | `AUTH_CALLBACK`   | `auth.callback.tsx`        | `redirectAfterAuth`                                        |

## API

API paths are never localized.

| Path          | Constant        | Route file      |
| ------------- | --------------- | --------------- |
| `/api`        | `API`           | `api/index.ts`  |
| `/api/auth/*` | `API_AUTH_BASE` | `api/auth.$.ts` |
| `/api/search` | none            | `api/search.ts` |

`ROUTES.API_AUTH` lists Better Auth endpoint paths relative to `/api/auth`; `auth.server.ts` uses them to exempt endpoints from rate limiting and to disable the Polar plugin's `/checkout` (`disabledPaths`), and `INPUT_POLICY` in `auth.hooks.ts` to validate the endpoints that accept a password, name, email or image. `API_AUTH_CUSTOMER_PORTAL` and `API_AUTH_VERIFY_EMAIL` are full paths to Better Auth endpoints. `AUTH` and `NEWSLETTER` have no page of their own; together with `ADMIN`, `APP`, `API` and `COURSES` they mark the areas that are never prerendered (`UNLISTED_ROUTES` in `vite.config.ts`).

## Media

`/media/<expiry>.<signature>/<videoId>/<file>` serves signed video files. It has no `ROUTES` constant and no route file: `src/server.ts` sends it to `serveMedia` before the locale middleware, so it is never localized. See [Cloudflare R2](/docs/integrations/cloudflare-r2).
