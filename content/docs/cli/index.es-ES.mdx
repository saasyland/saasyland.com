Una licencia de SaaSy Land es una licencia para la línea de comandos `saasyland`. Esta página describe la versión publicada en la etiqueta <RepositoryFact name="cliReleaseChannel" /> de npm, <RepositoryFact name="cliPackageSpec" />, y las [notas de la versión](/docs/cli/releases) recogen lo que cambió cada versión.

## Qué funciona hoy

- `activate`, `whoami` y `deactivate` gestionan tu clave de licencia en un dispositivo.
- `--help` y `--version` funcionan por completo, y todos los comandos aceptan `--json` y `--locale`.
- La generación de proyectos llega en una versión posterior. Hasta entonces, <RepositoryFact name="cliInit" /> comprueba sus flags y termina con el código <RepositoryFact name="cliExitNotAvailable" />, igual que `change`, `update` y `status`. El [configurador](/#cli) de la página de inicio marca lo que escribe la primera versión con generación de proyectos, el stack predeterminado con o sin autenticación, y la [hoja de ruta](/docs/project/roadmap) recoge lo que viene después.

## Ejecútala

Ejecuta la CLI desde la etiqueta <RepositoryFact name="cliReleaseChannel" /> con tu gestor de paquetes. No hace falta instalar nada de forma global:

<RepositoryTable columns={["Gestor de paquetes", "Comando"]} name="cliRunners" />

Sin la etiqueta, tu gestor de paquetes ejecuta la etiqueta `latest` de npm, que todavía contiene la versión provisional que reservó el nombre, y ninguno de sus comandos funciona. La CLI necesita Node.js <RepositoryFact name="cliNodeEngine" /> o Bun.

## Activa tu clave

1. Inicia sesión y copia tu clave desde [tu página de licencia](/app/license).
2. Ejecuta <RepositoryFact name="cliActivate" />. En una terminal, la CLI te pide la clave y la oculta mientras escribes.
3. En lugar de escribirla, puedes pasar la clave como argumento, que queda en el historial de tu shell, o definir <RepositoryFact name="cliLicenseKeyVariable" />, que no queda. Sin clave, `activate` usa la clave ya activada en este dispositivo.

`--label` da nombre al dispositivo en tu página de licencia; por defecto, el nombre es el del host. Si vuelves a activar un dispositivo, conserva la activación que ya tiene.

## Dispositivos

Cada dispositivo que actives ocupa una de las activaciones de tu licencia: <ActivationLimit tier="core" /> en Core, <ActivationLimit tier="complete" /> en Complete y <ActivationLimit tier="agency" /> en Agency.

- <RepositoryFact name="cliWhoami" /> muestra tu nivel, las activaciones en uso y el nombre de este dispositivo.
- <RepositoryFact name="cliDeactivate" /> libera la activación de este dispositivo y elimina de él la licencia.
- Para liberar la activación de un dispositivo que ya no usas, elimínalo en **Dispositivos** de [tu página de licencia](/app/license). El siguiente `whoami` o `deactivate` en ese dispositivo lo detecta.

Cuando todas las activaciones están ocupadas, `activate` enumera los dispositivos que las ocupan y te envía a tu página de licencia para liberar una.

## CI

Guarda la clave como secreto en <RepositoryFact name="cliLicenseKeyVariable" />. En <RepositoryFact name="cliCiProviders" />, cada ejecución de un mismo repositorio obtiene el mismo ID de dispositivo, así que el repositorio ocupa una sola activación por muchas veces que se ejecute, con el nombre del proveedor y del repositorio. En cualquier otro sistema de CI, o en un contenedor sin ID de dispositivo, define <RepositoryFact name="cliCiRepositoryVariable" /> con el nombre del repositorio.

## Dónde se guarda la licencia

La CLI guarda la licencia en <RepositoryFact name="cliCredentialsFile" />, que solo puede leer tu usuario (modo <RepositoryFact name="cliCredentialsFileMode" />), en tu directorio de configuración:

<RepositoryTable columns={["Sistema", "Directorio"]} name="cliCredentialDirectories" />

Si `XDG_CONFIG_HOME` no está definida, Linux usa <RepositoryFact name="cliCredentialsLinuxFallback" />. La CLI envía a saasyland.com un hash con clave del ID de este dispositivo, nunca el ID en sí. Cuando saasyland.com indica que la licencia se ha reembolsado o revocado, la CLI la elimina del dispositivo y te remite a tu página de licencia y al soporte.

## Variables de entorno

| Variable                                          | Qué define                                                                                                |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| <RepositoryFact name="cliLicenseKeyVariable" />   | La clave de licencia, para CI y para las sesiones que no pueden pedirla                                   |
| <RepositoryFact name="cliCiRepositoryVariable" /> | El nombre del repositorio en un sistema de CI que la CLI no reconoce                                      |
| <RepositoryFact name="cliLocaleVariable" />       | El idioma de la salida: primero `--locale`, luego esta variable y después el idioma de tu sistema         |
| <RepositoryFact name="cliApiUrlVariable" />       | Otro despliegue de saasyland.com, como una preview: una URL `https`, o una URL `http` en tu propio equipo |

## Scripts y agentes de programación

`--json` imprime el resultado o el error como un único documento JSON. En CI, en un agente de programación o sin terminal, la CLI nunca espera una entrada: `activate` sin clave se detiene con el código de salida <RepositoryFact name="cliExitUsage" /> e indica cómo pasarla.

| Código de salida                                  | Cuándo                                                                                                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <RepositoryFact name="cliExitSuccess" />          | El comando hizo lo que indica                                                                                                                                                   |
| <RepositoryFact name="cliExitFailure" />          | Algo falló dentro de la CLI                                                                                                                                                     |
| <RepositoryFact name="cliExitUsage" />            | Un flag o <RepositoryFact name="cliApiUrlVariable" /> no es válido, o falta la clave en una sesión que no puede pedirla                                                         |
| <RepositoryFact name="cliExitNotAvailable" />     | El comando aún no está disponible, no se puede leer el ID de este dispositivo, o el sistema no es Linux, macOS ni Windows                                                       |
| <RepositoryFact name="cliExitTemporaryFailure" /> | No se puede contactar con saasyland.com, o pide volver a intentarlo más tarde                                                                                                   |
| <RepositoryFact name="cliExitProtocol" />         | saasyland.com y esta versión de la CLI no se entienden; actualiza la CLI                                                                                                        |
| <RepositoryFact name="cliExitNoPermission" />     | No hay ninguna licencia activada aquí, se liberó la activación de este dispositivo, la clave no es válida, está revocada o reembolsada, o todas las activaciones están ocupadas |
| <RepositoryFact name="cliExitCancelled" />        | Cancelaste la pregunta con Ctrl+C                                                                                                                                               |
