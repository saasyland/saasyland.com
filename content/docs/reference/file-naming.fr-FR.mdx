Tous les fichiers et dossiers sont en kebab-case.

## Fichiers source

| Modèle                                                       | Signification                                                                                                                                         |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/routes/<segment>.<segment>.tsx`                         | Route basée sur un fichier ; les points sont des segments de chemin, `_` marque un layout sans chemin, `$` une route splat, `index` une route d'index |
| `src/routes/api/<name>.ts`                                   | Handler HTTP                                                                                                                                          |
| `modules/<table>/<table>.schema.ts`                          | Table Drizzle                                                                                                                                         |
| `modules/<table>/<table>.zod.ts`                             | Schémas Zod                                                                                                                                           |
| `modules/<table>/<table>.constants.ts`                       | Clés de query, clés de mutation et enums                                                                                                              |
| `modules/<table>/<table>.types.ts`                           | Types dérivés de la table                                                                                                                             |
| `modules/<table>/<table>.utils.ts`                           | Utilitaires purs pour la table                                                                                                                        |
| `modules/<table>/<table>.server.ts`                          | Utilitaires exclusivement serveur du module                                                                                                           |
| `modules/<table>/use-cases/<verb>-<noun>.ts`                 | Un cas d'usage                                                                                                                                        |
| `integrations/<vendor>/<prefix>.<concern>.ts`                | Configuration ou adaptateur d'un fournisseur, par exemple `auth.server.ts`                                                                            |
| `presentation/components/custom/<area>/<entity>-columns.tsx` | Colonnes d'un tableau de données                                                                                                                      |
| `presentation/emails/<name>.tsx`                             | Modèle d'e-mail qui exporte `<NAME>_NAMESPACE`                                                                                                        |
| `hooks/use-<name>.ts`                                        | Hook React partagé                                                                                                                                    |
| `providers/<name>-provider.tsx`                              | Provider de l'application                                                                                                                             |

## Tests

| Modèle                                | Exécuteur                   |
| ------------------------------------- | --------------------------- |
| `__test__/<file>.test.ts`             | Projet Vitest `node`        |
| `__test__/<file>.integration.test.ts` | Projet Vitest `integration` |
| `__test__/<file>.component.test.tsx`  | Projet Vitest `component`   |
| `e2e/specs/<flow>.spec.ts`            | Playwright                  |

Les fichiers de test portent le nom du fichier source qu'ils couvrent, par exemple `user.schema.test.ts` pour `user.schema.ts`.

## Contenu et messages

| Modèle                                    | Signification                                                 |
| ----------------------------------------- | ------------------------------------------------------------- |
| `messages/<locale>/<namespace>.json`      | Namespace de traduction, par exemple `pages.admin.users.json` |
| `content/docs/<path>/<page>.<locale>.mdx` | Page de documentation                                         |
| `content/docs/<path>/meta.<locale>.json`  | Navigation de la documentation                                |
| `content/blog/<slug>.<locale>.mdx`        | Article de blog                                               |
