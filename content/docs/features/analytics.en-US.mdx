## Admin screen (demo)

`/admin/analytics` shows five tab triggers (`overview`, `revenue`, `audience`, `retention`, `reports`); only **Overview** has content:

- `AnalyticsKpis` and `AnalyticsRevenueChart` render `ADMIN_ANALYTICS_KPIS` and `ADMIN_ANALYTICS_REVENUE_BARS` from `src/data/admin.ts`.
- `RegionsAndUpgrades` renders `ADMIN_ANALYTICS_REGION_ROWS` and `ADMIN_ANALYTICS_UPGRADE_ROWS` from `src/data/admin.ts`.
- The date picker button is not wired.

The revenue chart on the dashboard is a static SVG as well.

## What is collected

No analytics script is installed, and no events are stored. The only third-party script is Affonso's referral pixel, which loads only on a visit whose URL carries a referral parameter and only when `AFFONSO_PROGRAM_ID` is set ([Affiliate programme](/docs/features/affiliates)). `wrangler.jsonc` enables Workers `observability`, so Worker logs, including the `console.error` output of failed server functions, appear in the Cloudflare dashboard.
