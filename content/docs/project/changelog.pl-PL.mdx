title: "Historia zmian"
description: "Najważniejsze zmiany na przestrzeni czasu."
---

Każda sekcja wymienia zmiany, które trafiły do `main` danego dnia (UTC), od najnowszych, a każda zmiana kończy się linkiem do pull requesta, z którego pochodzi. Każde wdrożenie produkcyjne dostaje tag i jest publikowane jako GitHub Release z sekcją swojego dnia jako notatkami; zobacz [Wydania i tagi](/docs/tooling/ci-cd#releases-and-tags). Wydania samego CLI są opisane w [informacjach o wydaniach CLI](/docs/cli/releases). Każda zmiana dodaje własny wpis; zobacz [Wpisy w historii zmian](/docs/conventions/git-workflow#changelog-entries).
