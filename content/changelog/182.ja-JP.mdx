- フッターは GitHub リポジトリの隣に Instagram のプロフィール `APP_INSTAGRAM_URL` へのリンクを置き、GitHub のリンクと同じく新しいタブで開きます。ホームページは、Google がホームページに推奨しているとおり、JSON-LD で組織を説明します。名前、URL、連絡先アドレス、そして `sameAs` に GitHub と Instagram のプロフィールを持つ `Organization` です。ブログ記事は同じ組織を `publisher` として示します。リポジトリはプロフィールではないため、`sameAs` には GitHub の組織 `APP_GITHUB_OWNER_URL` を挙げ、`APP_GITHUB_URL` はそこから導出するようになりました。[検索エンジンとソーシャルプレビュー](/docs/features/seo#structured-data)を参照してください。
